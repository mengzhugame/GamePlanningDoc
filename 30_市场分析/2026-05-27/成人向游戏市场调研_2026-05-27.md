# 成人向游戏市场调研与个人开发者进入判断（2026-05-27）

> 本文件是 `30_市场分析/` 原始情报层，不是最终知识结论。后续若要变成长期方法论，需要 `/distill` 到 `40_知识/`。

## Core Question

用户是否应该把“成人向 / R18 游戏”作为新的赚钱路径来研究？如果做 HD2D / 像素 / 2.5D 成人向 Steam 或海外平台游戏，个人开发者是否可以进入？

## Short Answer

可以进入“研究 + 低成本验证期”，但不建议直接全职转向或直接制作可售成人内容。

核心判断：

- 成人向游戏是真市场，不是聊天吹出来的伪需求。
- 但它不是纯蓝海；Steam 成人标签已经非常拥挤，DLsite / FANZA 这类高意图平台更像“窄门高客单市场”。
- “玩家不在乎游戏性”只对一部分视觉小说、轻 SLG、CG 解锁型产品成立。更准确地说，玩家愿意降低系统深度要求，但会抬高对角色、CG 密度、标签命中、内容节奏、本地化和稳定更新的要求。
- 对中国境内个人或主体来说，直接制作、贩卖、传播露骨成人内容存在明确刑事风险；“规模小就不用担心”不是安全边界。
- 真钱赌博方向不建议个人开发者碰，除非先完成牌照、支付、KYC/AML、地区合规和法律主体设计。它和成人向不是一类风险。

## Key Findings

### 1. FANZA / DMM：成人同人平台规模巨大，但公开数据不是游戏专用

FANZA 同人 2025 report（Digital Commerce 发布）披露：

- 2025 年 FANZA 同人年访问者数超过 2.25 亿。
- 年销售本数超过 1.9 亿。
- 报告称女性用户比例上升，用户层在扩大。

注意：这组数据是 FANZA 同人整体，包括漫画、音声、CG、游戏等，不代表“游戏品类单独规模”。它证明的是成人同人购买场景成熟、付费心智强，不直接证明个人游戏一定能卖。

用户给的 DMM 页面是 `mens / game` 列表，本质上更接近 FANZA / DMM 的男性向成人同人游戏入口。这个入口是高意图入口，不是泛流量平台。

### 2. DLsite R18 游戏：头部销量足够大，且游戏形态不只有视觉小说

DLsite R18 2025 年“同人 游戏・動画ランキング”显示：

- 年榜第 1 名年度销售数为 91,675。
- 年榜前 10 的年度销售数大致在 34,775 到 91,675 之间。
- 可见品类包括动作、RPG、模拟经营 / SLG、冒险等，不只是 VN。
- 很多高排名作品同时具有“体験版 / demo”，说明先用试玩版筛选用户是常见做法。

DLsite 创作者页显示，截至 2023 年 10 月：

- DLsite 注册用户超过 1,100 万。
- 注册创作者超过 76,000。
- 平台作品超过 1,070,000。
- 支持海外创作者注册，并提供英文 / 中文 / 韩文支持。

这说明：R18 游戏在日系同人平台上有真实付费纵深。对个人开发者来说，DLsite / FANZA 比“泛 Steam 成人标签”更接近高意图货架。

### 3. Steam：成人游戏供给已经很密，不是蓝海

SteamDB tag release data 显示：

- `Adult Content` 标签：2025 年发布 1,744 款，2026 年截至采样时已发布 800 款，累计 7,779 款。
- `Hentai` 标签：2025 年发布 1,207 款，2026 年截至采样时已发布 575 款，累计 5,260 款。
- `Nudity` 标签：2025 年发布 1,769 款，2026 年截至采样时已发布 776 款，累计 9,736 款。

这意味着 Steam 成人向不是“没人做”，而是“供给非常多、质量跨度极大、发现机制拥挤”。Steam 更适合“玩法或美术本身足够像游戏”的成人向项目，而不是只有 CG 的小体量作品。

### 4. 平台政策风险在 2025 后明显变高

Steamworks 官方文档的 `What you shouldn't publish on Steam` 包含：

- 不能发布真实人物的裸露或性露骨图像。
- 成人内容必须正确标注并年龄门槛。
- 内容不能违反可售地区法律。
- 不能剥削儿童。
- 2025 后新增 / 强化了支付处理方、卡组织、银行、网络服务商规则相关限制，特别提到某些 adult-only content。

itch.io 在 2025-07-24 官方公告中称，因支付处理方审查压力，曾把所有 adult NSFW 内容从浏览与搜索页 deindex，并暂停 Stripe 对 18+ 内容的支付能力。

判断：成人向游戏最大的非制作风险不是“有没有人买”，而是平台、支付、法务、年龄门槛和地区可售性随时变化。

### 5. 中国法务风险不能靠“规模小”规避

中国人大网公开刑法条文包含第三百六十三条：以牟利为目的制作、复制、出版、贩卖、传播淫秽物品，可能构成犯罪并承担刑罚。

两高关于互联网、移动通讯终端传播淫秽电子信息的司法解释还把“视频文件数量、图片/文章数量、点击数、会员数、违法所得”等作为入罪或情节判断指标。

这不是法律意见，但对用户决策很关键：如果人、公司、收款、服务器、宣传、制作组织仍和中国境内强绑定，直接做可售成人色情内容不应被视为“创业捷径”。

## Fit With 用户能力

适配点：

- 用户有 Unity / 动作 Boss 战 / 微信小游戏经验，能做“真游戏”的底层交互。
- 成人向市场确实给了“美术、角色、题材钩子”更高权重，这和独立开发者避免卷 3A 画质的铁律一致。
- HD2D / 像素 / 2.5D 若走强风格化、猎奇、反差路线，能避开写实 3D 成本。

不适配点：

- 用户现有强项不是成人 CG 产能、角色设定、日语运营、R18 平台标签运营。
- 成人向项目的瓶颈会从“玩法开发”转移到“持续内容生产 + 标签命中 + 合规上架 + 收款”。
- 如果把它理解成“游戏性不用好，画几张 CG 就卖”，会撞上最拥挤的低质供给区。

## Iron Rule Check

### 铁律 1：差异化拷问

不能用“成人内容”本身当差异化。成人内容只是入场券。

需要回答：

- 和 DLsite / FANZA 头部动作 / SLG / RPG 成人游戏相比，3 个核心不同点是什么？
- 和 Steam 成人像素 / Hentai 标签游戏相比，前 3 秒能看出的差异是什么？
- 你的玩法是否制造了新决策压力，而不是只是 CG 解锁外壳？

### 铁律 2：美术差异化

HD2D 可以成立，但不能只是“像素 + 光照 + 成人 CG”。

更可行的方向是：

- 强风格化：极致像素、复古 JRPG、纸片剧场、黑暗童话、宗教哥特、都市怪谈等。
- 猎奇：题材或视觉第一眼就有记忆点，但必须避开违法、平台高危、未成年暗示、真实人物等红线。
- 反差：治愈/可爱外皮 + 暗黑成人世界观，或日常经营 + 隐秘成人目标。

### 铁律 3：1 个月 Demo

不应一上来做完整 HD2D 成人 RPG。

一个可控的 1 个月验证范围：

- Week 1：做非成人灰盒核心循环，验证移动、战斗 / 经营 / 解谜是否成立。
- Week 2：做 1 个场景、1 个角色、1 个核心反馈，用占位 CG 或非露骨图替代。
- Week 3：做 10-15 分钟可玩 demo，准备 Steam / DLsite 风格商店页文案草稿。
- Week 4：只在合规渠道做 18+ 用户调研；国内公开平台只测非露骨玩法、画风和题材，不发布成人内容。

## Recommendation

结论：个人开发者可以进入“成人向游戏方向的验证漏斗”，但要把它当作高风险高意图垂直品类，而不是快速致富捷径。

优先推荐路径：

1. 不直接做可售成人内容，先做“成人向可转化的非露骨玩法样片”。
2. 方向优先选择 `HD2D / 像素动作RPG / 轻SLG / 经营模拟`，而不是纯 VN。
3. 先以 DLsite / FANZA 的品类逻辑研究标签、价格、demo、CG量、销量，而不是先押 Steam。
4. 立项前必须做 3 个竞品拆解：1 个 DLsite 头部动作、1 个头部 SLG、1 个 Steam 成人像素游戏。
5. 如果未来要做可售 R18 版本，先完成主体、法务、收款、地区限制、年龄门槛、平台规则确认。

当前不建议：

- 不建议在中国境内直接制作、销售、传播露骨成人内容。
- 不建议把真钱赌博与成人向一起作为“快速致富路径”推进。
- 不建议做大体量 HD2D RPG；美术和内容量会把个人开发者拖死。
- 不建议用“小规模没人管”作为风险控制策略。

## Next Steps

建议下一步做一个更小的 `/category-dive 成人向像素动作RPG`：

- 采样 DLsite R18 年榜 / 月榜前 30。
- 采样 Steam `Adult Content + Pixel Graphics / Action / RPG` 前 30。
- 按核心机制分支统计：动作、SLG、经营、RPG、VN、解谜。
- 记录每个样本：价格、销量/评论、demo、CG/动画量、是否语音、本地化语言、核心卖点、平台标签。
- 最后只选 1 个可 1 个月验证的子方向。
