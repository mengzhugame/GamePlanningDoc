# 概念验证记录模板

> 使用方式：当某个创意通过初筛并开始制作 AI 玩法概念视频，复制本模板为 `创意名_概念视频数据记录.md`。  
> 这里记录“市场信号”，不要写完整项目策划；完整玩法讨论放在 `创意名_概念卡.md`。

```yaml
---
type: concept_validation
status: planning
idea_id:
idea_name:
created:
video_versions:
decision: 未决策
---
```

# 创意名概念视频数据记录

## 验证目标

| 问题 | 标准 |
| --- | --- |
| 玩家是否 3 秒看懂？ | 评论里能复述玩法，或主动讨论策略 |
| 玩家是否觉得想玩？ | 有“什么时候上线 / 想玩 / 下载 / 在哪玩”等评论 |
| 视频钩子是否成立？ | 收藏、转发、完播明显高于日常内容 |
| 是否值得做原型？ | 陌生玩家信号足够，不只靠朋友评价 |

## 数据记录节奏

| 时间点 | 要记录什么 | 是否做决策 |
| --- | --- | --- |
| 发布当天 T+0 | 视频版本、标题、发布时间、平台链接 | 不决策，只建档 |
| T+24h | 播放、完播/平均观看、点赞、收藏、评论、转发；记录第一批评论 | 不做最终判断，只判断“是否看懂” |
| T+72h | 各平台第二次数据；重点看评论、收藏、转发、是否有人追问 | 可做中期判断：继续观察 / 重做表达 / 暂停 |
| T+7d | 7 天累计数据和评论归类 | 主要决策点：进入下一步 / 再测一版 / 失败归档 |
| T+14d | 长尾数据，尤其是小红书收藏和评论回流 | 可选，只用于长尾复盘 |

## 决策规则

| 结论 | 参考条件 |
| --- | --- |
| 进入 7 天原型 / 铁律重审 | T+7d 出现明确想玩/在哪玩评论，且收藏/转发高于日常内容；玩家能复述玩法 |
| 再做一版视频 | 有题材兴趣，但评论看不懂玩法，或只夸画面不提操作 |
| 暂停/失败归档 | 两版视频都没有评论欲、收藏、想玩反馈，或看得懂但没人想玩 |
