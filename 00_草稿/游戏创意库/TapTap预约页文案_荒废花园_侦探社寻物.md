# TapTap 预约页文案 - 荒废花园 / 侦探社寻物

> 用途：两款创意视频上传 TapTap、依靠自然流量观察愿望单 / 关注意愿。
> 状态：概念验证期文案，不代表正式立项。

## 0. 使用注意

- 简介优先讲清类型、玩法和特色，前 50 字要直接打出核心循环。
- 开发者的话要有个人表达，不要和简介重复。
- 首页推荐语避免时效词、奖项、商业化宣传、极限词、无关玩梗。
- 简介 / 开发者的话里不要写外部群、外链、导流、邀请好评等内容。
- 如果后续开放下载或试玩，视频和截图需要尽量展示真实核心玩法，避免让玩家误以为概念演示就是已完成实机。

## 1. 荒废花园

### 推荐游戏名

**推荐使用：荒废花园**

理由：和已发布概念视频标题一致，第一眼能看懂“枯萎 → 复苏”的视觉钩子。

备选名：

| 名称 | 取向 | 备注 |
| --- | --- | --- |
| 荒园花店 | 更偏经营与订单 | 如果后续主循环强化“卖花 / 花束订单”，这个名字更聚焦 |
| 花园复苏计划 | 更偏治愈修复 | 稍微泛，需要靠封面和简介补玩法 |
| 花田重建日记 | 更偏轻叙事 | 适合慢节奏治愈，但商业识别弱一些 |

### 游戏简介

在枯萎的花园里，从种花和卖花开始重建花店。种植、浇水、收割、包装花束、完成限时订单，用赚来的金币扩建土地、清除杂草、解锁园丁和洒水器，让荒废的花园逐渐恢复生机。

你需要在顾客离开前补齐花束订单，也要处理不断扩散的杂草危机。随着花圃扩大，手动照料会逐渐变成自动化流水线：园丁帮你除草，洒水器复苏土地，更多花朵开满原本灰暗的角落。

### 简介短版

在枯萎的花园里种花、接单、扩建土地，用园丁和洒水器把荒废花园重新种回生机。

### 开发者的话

我想做一个“变化看得见”的治愈小循环：玩家不是只点升级，而是亲手把灰色土地变成会开花的地方。

这个方向目前还在概念验证期。我会先用核心玩法视频观察玩家是否真的想玩，再决定是继续推进，还是缩小范围重做玩法。希望这片荒废花园最后不是靠堆系统变热闹，而是靠每次种下、收获、交付和复苏带来清楚的反馈。

### 首页推荐语

推荐使用：

```text
种花接单，复苏枯萎花园
```

备选：

```text
枯萎花园，也能重新开花
```

```text
从杂草荒园开出花店
```

### 初始更新日志

```text
1. 公开荒废花园概念演示。
2. 展示种花、花束订单、土地扩建和花园复苏流程。
3. 后续将根据预约反馈评估 Demo 范围。
```

### 分类 / 标签建议

```text
模拟经营 / 休闲 / 治愈 / 种田 / 放置自动化 / 独立游戏
```

### 封面与视频首帧建议

- 首帧直接展示灰色枯萎花园和一小片已经复苏的花田，形成前后对比。
- 宣传图只放游戏名，不叠加“想玩请预约”“无广告”“福利”等额外文字。
- 视频前 3-5 秒优先展示核心操作：种花、交付订单、土地复苏，不要用纯 Logo 或纯氛围镜头开场。

## 2. 侦探社寻物

### 推荐游戏名

**推荐使用：怪案侦探社**

理由：比“侦探社寻物”更像正式游戏名，同时保留侦探、怪案、轻悬疑的题材钩子。

备选名：

| 名称    | 取向         | 备注                     |
| ----- | ---------- | ---------------------- |
| 证物侦探社 | 更强调“找证物”玩法 | 玩法表达更清楚，但题材气质稍弱        |
| 侦探社寻物 | 更利于内部识别    | 可以作为工作名，不太像上架名         |
| 雨夜侦探社 | 更偏氛围       | 适合强化 noir 风，但不直接说明寻物玩法 |

### 游戏简介

经营一家专接怪案的侦探社，在短局调查中使用放大镜、紫外灯等工具，从案发现场找出关键证物，再比对嫌疑人证词指认真凶。每个案件都围绕“找证物、破证词、作出指认”展开。

这里不是简单按清单找物品。每件证物都会指向一段矛盾：地毯下的怀表、酒杯上的痕迹、窗台边的脚印，都会影响你最后指认谁在说谎。倒计时结束前找齐证据，别被表面线索带偏。

### 简介短版

用放大镜和紫外灯找出关键证物，拆穿嫌疑人证词里的破绽，经营你的怪案侦探社。

### 开发者的话

这个方向想把传统寻物的爽感往前推一步：找到的不是清单物品，而是会改变指认结果的证据。

第一版会控制在短局、低惊吓、轻剧情的范围里，先验证玩家是否喜欢“找证物后破案”的节奏。侦探社经营只做轻包装，核心仍然是每个案件里那几次发现证物、串起矛盾、点下指认的瞬间。

### 首页推荐语

推荐使用：

```text
找证物，拆穿证词破绽
```

备选：

```text
案发现场，证物会说话
```

```text
放大镜下，藏着破案关键
```

### 初始更新日志

```text
1. 公开书房疑案概念演示。
2. 展示放大镜、紫外灯、证物收集和嫌疑人指认流程。
3. 后续将根据预约反馈决定案件内容和 Demo 范围。
```

### 分类 / 标签建议

```text
侦探 / 推理 / 寻物 / 解谜 / 轻悬疑 / 独立游戏
```

### 封面与视频首帧建议

- 首帧直接展示案发现场、放大镜、关键证物和嫌疑人卡片，不要只展示侦探社门头。
- 宣传图只放游戏名，避免额外大字报文案。
- 视频前 3-5 秒先出现“工具扫出隐藏证物”的操作反馈，再进入指认界面。
- 画面保持轻悬疑，不做写实血腥、重口伤害或真实犯罪素材。
