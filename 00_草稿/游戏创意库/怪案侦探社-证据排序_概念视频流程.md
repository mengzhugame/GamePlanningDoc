## 2. 工艺路径（标准 8 步）

1. **风格定调** — 生成证据卡、时间线 UI、真相演出三类图。
2. **关键帧扩展** — 红酒谋杀案先做 6 张卡：动机、红酒、椅子、怀表、窗台、口红印。
3. **UI 叠层生成** — 顶部案件名和疑点槽，中间时间线槽，底部证据池。
4. **UI 抠图** — 卡牌、红线、疑点槽、提示按钮单独抠出。
5. **PS 合成** — 组合拖卡过程、错位闪红、正确连线。
6. **图生视频** — 生成卡片拖动、红线点亮、真相剪影动画。
7. **剪映后期** — 加卡片吸附音、错误疑点音、真相揭露音效。
8. **封面 + 发布** — 封面用“6 张证据卡，谁才是真凶？”。

## 4. UI 提示词

### 主界面 UI

```text
复古侦探漫画风手游 UI，顶部显示案件名、3 格疑点槽、提示灯泡；中间是一排 3-8 个时间线卡槽，卡槽之间可出现红线；底部是证据卡池，卡牌有剪影图标和短句文字；右侧可有“无关线索区”；暗红和琥珀配色，无 logo、无水印、无多余按钮。
```

### 子界面 UI（真相 / 结算 / 提示）

```text
真相界面：漫画分镜剪影，红线连接证据；结算界面：破案成功印章、疑点槽剩余、星级、下一案按钮；提示界面：清空 1 格疑点、锁定首卡、锁定相邻卡、排除干扰卡。
```

### 抠出 UI 提示词

```text
去掉所有场景和角色，只保留时间线卡槽、证据卡、红线、疑点槽、提示按钮、破案成功印章，纯白色背景底图，方便抠图。
```

## 5. 视频脚本

### 视频 1 描述（红酒谋杀案）

```text
参考复古侦探漫画 UI，手机屏幕中间有 5 个时间线槽，底部有 5 张证据卡。玩家拖动卡片排序，一次放错后时间线闪红，再调整顺序。最后红线全部点亮，播放未婚妻下药、撞倒椅子、掉落怀表、从窗户逃离的真相剪影动画。
```

### 视频 1 字幕

```text
0-2s：5 张证据卡，还原一场谋杀案
2-5s：不限时，但提交错会增加疑点
5-8s：这张怀表，到底什么时候掉的？
8-11s：红线全亮，真相开始还原
11-15s：你能不看提示排对吗？
```

### 视频 2 描述

```text
展示第 10 关后的干扰卡。底部有 7 张卡，只有 5 张属于案件时间线。玩家把两张无关卡拖进无关线索区，并通过广告提示锁定一对相邻卡，最终完成排序。
```

### 视频 2 字幕

```text
0-2s：不是所有线索都有用
2-5s：把无关证据丢进旁边
5-8s：卡住时，只提示一对相邻卡
8-11s：剩下的顺序，还是你自己推
11-15s：真相免费揭晓，不挡破案爽感
```

### 视频 3 描述（可选）

```text
展示翻牌记忆变种。玩家先观察 15 秒，卡片随后翻面打乱，玩家凭记忆和推理排序。这个版本用于测试玩家是否喜欢记忆压力，不作为主玩法。
```

### 视频 3 字幕

```text
0-2s：15 秒，看清所有证据
2-5s：卡牌翻面，顺序打乱
5-8s：你还记得哪张在前吗？
8-11s：提交后，真相一张张翻开
11-15s：推理版和记忆版，你更想玩哪个？
```
