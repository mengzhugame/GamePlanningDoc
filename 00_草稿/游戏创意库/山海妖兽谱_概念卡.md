# 山海妖兽谱 概念卡

## 当前判断

这个方向已经从“山海经 Merge”转为：

> **山海经题材的放置孵化 + 异兽图鉴 + 自动巡山战斗。**

它不是纯 IAA 休闲小游戏，更接近中度放置挂机 / IAP+IAA 混变方向。当前只适合做概念视频验证，不进入原型制作。验证目标不是证明数值体系成立，而是先看玩家是否对“开混沌蛋孵化山海妖兽、吞噬进化、自动巡山变强”产生想玩冲动。

## 1. 一句话玩法

玩家离线巡山获得灵气和混沌蛋，开蛋孵化山海异兽，并在吞噬、上阵、放生和收藏之间做选择，让图鉴羁绊和战力不断增长，自动挑战更强的山海 Boss；战力卡住时可通过广告加速孵化、双倍离线收益或重roll蛋池。

## 2. 3 秒可懂画面

- 第一眼看到：古卷山海地图上显示“离线巡山 8 小时”，一堆混沌蛋在背包里发光。
- 角色 / 物件怎么动：玩家点击开蛋，蛋壳裂开，山海妖兽剪影从烟雾中显现；低阶妖兽被拖入吞噬槽，主妖兽体型变大。
- 最后 1 秒的反转或爽点：战力从 12,430 跳到 48,900，自动挑战山海 Boss，Boss 血条被一击打掉半管并解锁新地图。

## 3. 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 点击领取离线收益 / 点击开蛋 / 拖动妖兽到上阵、吞噬、放生、收藏槽 / 点击挑战 Boss |
| 目标 | 通过孵化和培养山海妖兽提升战力，解锁地图、图鉴和更高级蛋池 |
| 限制 | 蛋池品质、孵化时间、妖兽栏位、战力门槛、资源不足 |
| 失败条件 | 自动战斗打不过关卡 Boss，战力卡住，需要回到孵化、吞噬、图鉴羁绊补强 |
| 爽点 | 离线回来一键收菜、开蛋随机惊喜、稀有异兽金光、吞噬后战力暴涨、图鉴点亮、Boss 被秒 |
| 广告点 | 双倍离线收益 / 立刻孵化一个蛋 / 重roll一次蛋池 / 战斗失败后临时战力祝福 / 扩充妖兽栏位体验 |

### 核心循环

```text
离线巡山产出灵气和混沌蛋
→ 开蛋孵化异兽
→ 判断：上阵 / 吞噬 / 放生 / 收藏
→ 图鉴羁绊和战力提升
→ 自动挑战山海关卡
→ 解锁新地图、更高级蛋池和新异兽
→ 回到离线巡山
```

### 暂不解决的问题

| 问题 | 当前处理 |
| --- | --- |
| 是否纯 IAA | 暂不判断。大概率不适合纯 IAA，更适合 IAP+IAA 混变。 |
| 数值体系如何设计 | 视频阶段不做完整数值，只展示战力跳涨和卡关回流。 |
| 美术量如何控制 | 概念视频先用剪影、古卷图鉴、少量主异兽验证钩子。 |
| 是否做完整原型 | 只有视频预约、评论和 TapTap 数据明显强，才考虑 2 周数值灰盒。 |

## 4. 差异化拷问（立项铁律 3 条）

| 铁律 | 问题 | 回答 | 通过 |
| --- | --- | --- | --- |
| 1. 差异化 | 和最火同类相比，核心 3 个不同点是什么？最接近的 3 款竞品分别是？ | 竞品参考：《寻道大千》《跃动小子》《短命英雄》。差异点：(1) 核心抽取物不是装备/英雄，而是山海异兽蛋，视觉钩子更强；(2) 每只妖兽都有“上阵 / 吞噬 / 放生 / 收藏”四种处理，开蛋后有轻决策；(3) 图鉴羁绊以山海谱系组织，例如水族、羽族、凶兽、瑞兽，收集不是单纯堆稀有度。 | ☑ 概念视频阶段通过 |
| 2. 美术 | 美术上是否有风格化、猎奇或反差？避免和大厂卷画质？ | 走“山海古卷 + 怪诞异兽剪影 + 金光孵化”的风格化路线。重点不是精细原画，而是蛋壳裂开、异兽剪影、古卷图鉴、战力暴涨的仪式感。 | ☑ |
| 3. 速度 | 1 个月内能否做出 Demo 测试？ | 1 个月不能做完整中度放置，但可以做 2 周数值灰盒或 1 个月垂直切片：10 只异兽、3 个蛋池、3 个地图 Boss、离线收益假数据、上阵/吞噬/图鉴三条线。正式制作前必须重审体量。 | ☑ 仅限验证切片 |

**结论：** 可进入概念视频阶段；不等于正式立项。若视频数据不强，直接保留为中度题材资产。

## 5. 关卡成长预期

长线靠**离线收益、蛋池品质、异兽稀有度、吞噬进化、图鉴羁绊、境界突破、地图 Boss 和限时活动**避免重复。真正难点是数值和付费设计，不是核心展示。
