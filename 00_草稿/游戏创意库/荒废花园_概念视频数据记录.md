# 荒废花园概念视频数据记录

## 验证目标

| 问题 | 标准 |
| --- | --- |
| 玩家是否 3 秒看懂？ | 评论里能复述“种植/订单/复苏/自动化”任一核心玩法 |
| 玩家是否觉得想玩？ | 有“什么时候上线 / 想玩 / 下载 / 在哪玩 / 可以测试吗”等评论 |
| 视频钩子是否成立？ | 收藏、转发、完播明显高于日常内容 |
| 是否值得做原型？ | 陌生玩家信号足够，不只靠朋友评价 |

| --- | --- | --- | --- | --- |

## 视频脚本摘要

### V1 荒废花园复苏

| 时间 | 画面 | 验证点 |
| --- | --- | --- |
| 0-2s | 灰色枯萎花园，角色捡种子和水壶 | 玩家是否被“荒废”状态吸引 |
| 2-5s | 种下第一朵花并浇水 | 是否看懂种植 |
| 5-8s | 顾客订单需要白花 ×2 | 是否看懂订单 |
| 8-12s | 金币解锁地块，灰地变绿 | 复苏反馈是否成立 |

### V2 花束订单

| 时间 | 画面 | 验证点 |
| --- | --- | --- |
| 0-2s | 顾客订单和倒计时 | 是否有压力感 |
| 2-5s | 收割红花，种下蓝花 | 是否看懂资源调度 |
| 5-9s | 蓝花最后成熟，拖入花束台 | 是否有最后一秒紧张感 |
| 9-12s | 交付成功，金币爆出 | 成功反馈是否爽 |

### V3 杂草扩散

| 时间 | 画面 | 验证点 |
| --- | --- | --- |
| 0-2s | 黑色杂草向主花圃扩散 | 是否喜欢污染/危机 |
| 2-5s | 升级选择：园丁 / 洒水器 | 是否理解自动化升级 |
| 5-9s | 园丁自动清杂草 | 自动化是否有吸引力 |
| 9-13s | 洒水器一排扫除杂草，土地变绿 | 反杀和复苏反馈是否成立 |

## 决策

| 结论 | 条件 |
| --- | --- |
| 继续观察 | 7 天内数据还在增长，且出现明确想玩/在哪玩评论 |
| 再做一版视频 | 题材有人感兴趣，但评论看不懂玩法或只夸画面 |
| 进入铁律重审/7 天原型讨论 | 50+ 评论、100+ 收藏或明显高于日常内容，并能复述玩法 |
| 暂停/失败归档 | 两版视频都没有评论欲、收藏、想玩反馈，或看懂但没人想玩 |
