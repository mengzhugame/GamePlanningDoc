# 荒废花园概念卡

## 一句话玩法

玩家在荒废花园里种植、浇水、除草、收割花朵，再把花朵包装成花束卖给顾客；赚到的钱用于解锁地块、升级设备、雇佣园丁或小动物，让花园从枯萎状态逐步复苏。

## 3 秒可懂画面

- 第一眼看到：灰色、枯萎、杂草蔓延的花园。
- 玩家操作：角色种花、浇水、清杂草、收割花朵、交付订单。
- 爽点/反转：土地从灰色变绿，花朵连片开放，订单最后一秒完成。

## 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 点击移动、拖拽花朵/订单、购买升级 |
| 目标 | 通过卖花赚钱，修复荒废花园 |
| 限制 | 顾客倒计时、地块被杂草占据、产能不足 |
| 失败条件 | 顾客订单超时、杂草扩散压制产能、关键资源不足 |
| 爽点 | 一键收割花海、土地复苏、自动化园丁/小动物流水线 |
| 广告点 | 订单差 1 朵花、杂草快蔓延到主花圃、差一点金币解锁自动化 |

## 已形成的候选差异点

| 方向 | 价值 | 风险 |
| --- | --- | --- |
| 伐木式自动化花园 | 玩家从手动种植过渡到雇工/小动物自动种植、除草、收割、包装 | 需要证明中长期仍有爽感 |
| 一键收割花海 | 有可能产生“砍倒大树”级视听反馈 | 需要音效、粒子、金币爆出补偿操作感 |
| 杂草扩散/污染反转 | 能制造紧张感和反转画面 | 常见模拟经营也有类似机制，需做出差异 |

## 暂不做的事

- 不押美术合伙人。
- 不进入正式立项。
- 不做完整模拟经营系统。
- 不继续堆“花园世界已有”的功能，除非视频数据先证明玩家想玩。

## 触发重审条件

当视频数据接近或达到以下信号时，再重新做铁律拷问：

- 50+ 评论，且出现多条“想玩 / 在哪玩 / 什么时候出”。
- 100+ 收藏，且不是只夸画面。
- 玩家能复述“种植 → 订单 → 自动化 → 花园复苏”的玩法，而不是只被枯萎复苏画面吸引。
