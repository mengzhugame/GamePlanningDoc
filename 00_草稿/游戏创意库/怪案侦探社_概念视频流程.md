## 2. 工艺路径

1. **风格定调**：先生成 3 类图：证据桌、剖面房间小舞台、行动卡 UI。
2. **搭建关键帧**：每条视频先做 6-8 张关键帧，不直接长视频生成。
3. **UI 单独抠图**：时间轴、行动卡、证据板、重演按钮、红绿验证条单独出图，方便合成。
4. **PS / Figma 合成玩法画面**：优先保证“玩家在做什么”可读。
5. **图生视频**：让手指 / 鼠标拖动卡片、角色移动、小剧场播放。
6. **后期补强**：加鼠标光标、点击音、卡片吸附音、验证通过 / 失败音效。
7. **字幕解释**：15 秒内必须讲清“摆放 → 重演 → 矛盾 → 修正”。
8. **发布测试**：先测 A，再根据反馈决定是否做 B / C。

## 4. UI 提示词

### 主玩法 UI

```text
PC indie detective puzzle game UI, 16:9 screen. Center: a cutaway paper theater crime scene with 3-4 rooms. Top: horizontal timeline slots with small clock icons. Bottom: draggable role cards, item cards, and action cards with clear pictograms. Right side: evidence checklist with red/green verification states. Left side: compact case file panel with portraits and relationship lines. Warm amber paper texture, dark teal shadows, crimson evidence lines, clean readable layout, no logo, no watermark, no extra decorations.
```

### 重演验证 UI

```text
Crime reenactment playback UI, the central paper theater stage is slightly darkened, characters move along scripted paths, timeline cursor advances from left to right, evidence checklist on the right updates one by one. Failed evidence glows red with a short contradiction marker, valid evidence glows green with a satisfying check effect. Detective comic noir style, premium Steam puzzle game feel, clean and readable.
```

### 真相复盘 UI

```text
Truth reconstruction screen, detective corkboard and paper theater hybrid, all evidence nodes connected by crimson strings, culprit silhouette lowered head, action chain shown as small comic panels, warm desk lamp light, mysterious but not bloody, elegant indie puzzle game ending screen.
```

### 抠出 UI 提示词

```text
Remove all characters and background scene. Keep only UI elements: timeline slots, role cards, item cards, action cards, evidence checklist, red failed markers, green success markers, reenact button, truth stamp. Pure white background for easy cutout.
```
