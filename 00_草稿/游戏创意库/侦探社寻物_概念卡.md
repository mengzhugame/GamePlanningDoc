# 侦探社寻物 概念卡

## 当前判断

方向从"模拟经营 / 寻物 / 解谜摇摆"收束为：

> **侦探社是外壳和长线目标，核心玩法是短局"找证物破案"。**

第一版概念视频只展示关卡内真实核心玩法，不展示经营系统。模拟经营只作为关卡外包装：接委托、升级侦探社、解锁工具、装饰办公室。

## 1. 一句话玩法

玩家经营一家怪案侦探社，每个约 3 分钟的调查关卡里通过点击场景、使用放大镜和紫外灯找出 3 个关键证物，随后进入指认界面，根据证物和嫌疑人证词从 3 个嫌疑人中指出真凶；时间耗尽 / 找不到证物 / 指认错误时，可通过广告获得加时、提示或重新指认。

## 2. 3 秒可懂画面

- **第一眼看到**：复古书房案发现场，倒下的椅子、凌乱的书桌、鼓起的地毯
- **角色 / 物件怎么动**：放大镜扫过地毯掀开露出怀表 → 紫外灯扫红酒杯显出口红印 → 拉开窗帘发现窗台脚印
- **最后 1 秒的反转或爽点**：3 个证物集齐 → 弹出 3 个嫌疑人头像 + 证词 → 玩家从证词矛盾中指出真凶 → 盖章「凶手」

## 3. 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 点击场景物件 / 拖放大镜 / 拖紫外灯 / 点提示灯泡 / 点嫌疑人卡片 |
| 目标 | 3 分钟内找齐 3 个关键证物 → 根据证词与证物的矛盾点指认真凶 |
| 限制 | 3 分钟倒计时 + 紫外灯电量（10-15 秒恢复）+ 提示灯泡需广告 |
| 失败条件 | 3 分钟内未找齐证物（可广告加时）+ 指认错误超过 2 次（救助广告或星级降低） |
| 爽点 | 工具显出隐藏痕迹 + 进度 0/3 → 3/3 的递进 + 「差点选错凶手」的反转 + 盖章瞬间 |
| 广告点 | 找不到证物时点提示灯泡 / 指认错误后看广告获证词提示 / 紫外灯电量不足时充电 |

## 4. 差异化拷问

| 铁律 | 问题 | 回答 | 通过 |
| --- | --- | --- | --- |
| 1. 差异化 | 和最火同类（找不同 / 清单寻物 / 剧情寻物）的核心 3 个不同点？ | (1) 不是找不同，是找能证明谁说谎的证物 (2) 找的是证据链，证物会改变最终指认 (3) 主打短局压力：倒计时 + 误判 + 最后一秒翻案 | ☑ |
| 2. 美术 | 是否走风格化 / 猎奇 / 反差路线？ | 彩色黑色电影侦探漫画风（暖琥珀 + 青绿 + 紫外灯紫罗兰 + 证据猩红），跟大厂写实卡通拉开差距 | ☑ |
| 3. 速度 | 1 个月内能出 Demo 吗？ | 可以。Week 1 做 1 个书房场景 + 3 工具 + 进度 UI；Week 2 做 3 个场景；Week 3 做指认界面 + 通用结案动画；Week 4 录视频发布 | ☑ |

**结论：** 3 条全过 → 已复制 `04_概念视频流程模板.md` 为 `侦探社寻物_概念视频流程.md`，视频脚本已就绪。

## 5. 关卡成长预期

长线靠**新案件 + 新场景 + 新证物组合 + 轻 Meta 推进**避免重复。优势：题材钩子强 / 短视频好懂 / 适合小游戏新鲜感。风险：10-20 关后内容容易重复，需要变化维度（案件类型 / 场景主题 / 工具变化 / 证物逻辑 / 侦探社装饰 Meta），用模板表驱动避免每关重制。

## 附 A：关卡场景模型（视频后阶段才细做）

| 部分 | 内容 | 作用 |
| --- | --- | --- |
| 案发现场寻物 | 一个 2D 房间 / 街角 / 店铺 / 庭院场景，隐藏 3 个关键证物 | 主操作 + 短视频可视化 |
| 指认界面 | 中间 3 个嫌疑人头像卡 + 每人一句证词，底部证据板展示 3 个证物 | 推理选择 |
| 结算演出 | 文字真相 + 通用黑影低头 / 盖章 Spine 动画 | 控制量产成本 |

**第一关样例：书房疑案**
- 证物 1：地毯下的怀表（放大镜扫 → 显示时间矛盾）
- 证物 2：红酒杯口红印（紫外灯扫 → 显示女嫌疑人来过）
- 证物 3：窗台泥脚印（拉开窗帘 + 放大镜 → 显示非正门离开）
- 真凶：未婚妻（说"没碰过酒杯"但杯沿有她口红印）
- 嫌疑人：管家 / 未婚妻 / 收藏家（各一句证词）

## 附 B：内容量与留存风险

短期看：题材钩子强 + 短视频好理解 + 适合小游戏新鲜感。
长期风险：10-20 关后玩法重复，需变化维度撑场：

| 维度 | 例子 | 成本控制 |
| --- | --- | --- |
| 案件类型 | 证词矛盾 / 时间线错误 / 逃离路线 / 伪造现场 / 身份伪装 / 怪案异常 | 复用「3 证物 + 3 嫌疑人」结构 |
| 场景主题 | 书房 / 舞会厅 / 古董店 / 旅馆房间 / 剧院后台 / 雨夜街角 | 同场景可做日夜 / 破损 / 节日变体 |
| 工具变化 | 放大镜 / 紫外灯 / 录音机 / 脚印粉 / 温度计 | 第一版只做 3 工具 |
| 证物逻辑 | 怀表对应时间 / 口红印对应证词 / 脚印对应路线 | 模板表驱动，不做自由推理 |
| Meta 外层 | 侦探社升级 / 案件章节 / 装饰收藏 / 每日委托 | 轻量，不压过核心关卡 |

**视频验证目标不是证明它能玩一个月，而是：玩家是否愿意点开、看懂、并对「找证物后指认真凶」产生想玩冲动。**

## 附 C：失败规则细节（视频后阶段才细做）

| 阶段 | 情况 | 处理 |
| --- | --- | --- |
| 调查 | 3 分钟内未找齐 3 证物 | 失败面板：广告加时 60s / 重开 |
| 调查 | 找不到证物但还没超时 | 提示灯泡 → 看广告 → 圈出一个可疑区域 |
| 调查 | 紫外灯电量不足 | 等待恢复或广告充满 |
| 指认 | 第一次错 | 错误卡变灰 + 文本「证据不足，他不是凶手」+ 评价降低 |
| 指认 | 第二次错 | 看广告获证词提示 / 重新指认 |
| 指认 | 正确 | 真相还原 + 通关结算 |

通关评价 3 / 2 / 1 星，只影响金币 / 经验 / 装饰资源，不阻挡主线。
