# 侦探社寻物概念卡

## 当前判断

本轮讨论后，方向从“模拟经营 / 寻物 / 解谜摇摆”收束为：

> **侦探社是外壳和长线目标，核心玩法是短局“找证物破案”。**

第一版概念视频不展示复杂经营系统，只展示关卡内的真实核心玩法。模拟经营只作为关卡外包装：接委托、升级侦探社、解锁工具、装饰办公室。

## 一句话玩法

玩家经营一家怪案侦探社，在每个约 3 分钟的调查关卡里，通过点击场景、使用放大镜和紫外灯找出 3 个关键证物，随后进入指认界面，根据证物和嫌疑人证词从 3 个嫌疑人中指出真凶；时间耗尽、找不到证物或指认错误时，可通过广告获得加时、提示或重新指认机会。

## 核心循环

```text
接到委托
  → 进入 2D 案发现场
  → 3 分钟内找出 3 个关键证物
  → 顶部进度从“关键证物 0/3”推进到“3/3”
  → 底部工具栏隐藏
  → 弹出指认界面：中间 3 个嫌疑人头像卡 + 证词
  → 底部证据板展示 3 个证物
  → 玩家点击嫌疑人完成指认
  → 文字真相 + 通用黑影 / 盖章 Spine 动画结算
  → 回侦探社领取奖励并解锁下一案
```

## 关卡场景模型

每一关由两个部分组成：

| 部分 | 内容 | 作用 |
| --- | --- | --- |
| 案发现场寻物 | 一个 2D 房间 / 街角 / 店铺 / 庭院场景，隐藏 3 个关键证物 | 承担主要操作和短视频可视化 |
| 指认界面 | 中间 3 个嫌疑人头像卡 + 每人一句证词，底部证据板展示 3 个证物 | 承担推理选择 |
| 结算演出 | 文字真相 + 通用黑影低头 / 盖章 / 卡片变红 Spine 动画 | 控制量产成本，避免每关制作视频 |

## 玩家操作

| 操作 | 用途 | 视频表现 |
| --- | --- | --- |
| 点击场景物件 | 翻开抽屉、拉开窗帘、掀开地毯、打开盒子 | 无限使用，物件轻微弹动，出现隐藏区域或证物 |
| 拖动放大镜 | 检查细节：脚印、划痕、纤维、小物件 | 无限使用，1 秒短冷却，防止无脑狂扫 |
| 拖动紫外灯 | 扫描隐藏痕迹：指纹、口红印、暗纹、液体残留 | 使用电量条或 10-15 秒恢复节奏，不做“一次用错就失败” |
| 点击提示灯泡 | 广告救助，给卡关玩家提示 | 看广告后提示一个未找到证物的可疑区域 |
| 点击嫌疑人卡片 | 最后指认真凶 | 卡片震动，证物高亮，进入结算演出 |

## 关卡 UI 方案

### 调查阶段 UI

| 位置 | 内容 |
| --- | --- |
| 左上角 | 暂停按钮图标 |
| 顶部中间 | 倒计时横条，标准关显示约 `03:00`；概念视频可剪成 `00:59` 或最后几秒 |
| 顶部右侧 / 横条下方 | `关键证物 0/3`，找到证物后跳动为 `1/3`、`2/3`、`3/3` |
| 底部 | 只显示 3 个工具按钮：放大镜、紫外线灯、提示灯泡 |

底部不常驻显示 3 个证物槽。竖屏空间有限，调查阶段应把画面面积留给案发现场和可交互物件。

### 提示规则

| 提示层级 | 触发方式 | 效果 |
| --- | --- | --- |
| 弱视觉异常 | 默认存在 | 地毯鼓起、窗帘缝隙透光、酒杯颜色不自然，不直接发光 |
| 工具显现 | 玩家使用放大镜 / 紫外灯 | 脚印、口红印、指纹等证物显现 |
| 广告强提示 | 点击提示灯泡并看广告 | 圈出一个未找到证物的可疑区域；不要一次性高亮全部证物 |

### 指认阶段 UI

当 `关键证物 3/3` 后：

1. 底部 3 个工具按钮隐藏。
2. 场景背景压暗或虚化。
3. 弹出指认界面。
4. 屏幕中间显示 3 个嫌疑人头像卡片，每张卡片下方或卡片内显示一句证词。
5. 屏幕底部显示证据板，放入 3 个证物卡片。
6. 玩家根据证物和证词点击嫌疑人。

第一版可以不做复杂红线推理。证据板只需要让 3 个证物卡依次点亮，或用轻微猩红证据强调线表现“证据链成立”。

## 失败与重试规则

### 调查阶段失败

| 情况 | 处理 |
| --- | --- |
| 3 分钟内未找齐 3 个关键证物 | 弹出失败面板：可看广告加时 60 秒，或重新开始本关 |
| 找不到证物但还没超时 | 点击提示灯泡，看广告后提示一个可疑区域 |
| 紫外灯电量不足 | 等待恢复，或看广告立即充满 |

调查阶段的失败点主要服务广告救助，不建议让玩家因为一次工具用错直接失败。

### 指认阶段失败

| 情况 | 处理 |
| --- | --- |
| 第一次指认错误 | 错误嫌疑人卡片变灰，弹出“证据不足，他不是凶手”的短文本；玩家可继续指认，但通关评价降低 |
| 第二次指认错误 | 弹出“是否看广告获得一次证词提示 / 重新指认”的救助；不建议直接强制重玩整关 |
| 正确指认 | 进入真相还原 + 通关结算 |

三选一模式下，玩家最多错两次，第三次必然成功，所以它不是强重复通关设计。第一版接受这个休闲属性，用星级 / 奖励 / 广告救助承接，而不是强迫玩家重玩整关。

### 通关评价

| 评价 | 条件 |
| --- | --- |
| 3 星 | 不看提示、不指认错误、限时内完成 |
| 2 星 | 使用提示或指认错误 1 次 |
| 1 星 | 多次提示 / 多次指认错误后完成 |

评价只影响金币、侦探社经验、装饰资源，不阻挡主线推进。

## 真相还原方案

不做逐关视频文件，也不为每关制作完整动画短片。否则 30 关就需要 30 段视频或大量分镜，包体和制作量都会失控。

第一版采用低成本模板：

```text
证物卡点亮
  → 正确嫌疑人头像高亮
  → 3 秒极短真相还原
  → 通用黑影低头 / 案件盖章
  → 3-5 行文字真相
  → 通关结算
```

真相还原只使用当前场景、证物小图、嫌疑人黑影和少量 Spine / Tween 动画。例如书房疑案：

- 黑影把红酒杯放到桌上。
- 怀表掉到地毯边。
- 窗帘摆动，黑影从窗边离开。
- 弹出文字：`她说没碰过酒杯，但杯口留下了口红印。`

这样玩家能理解“到底发生了什么”，但每关只需要少量可复用动画模板。

## 内容量与留存风险

这类“寻物 + 指认”玩法的长期留存不是靠同一关反复玩，而是靠新案件、新场景、新证物组合和轻 Meta 推进。它的优势是题材钩子强、短视频好理解、适合小游戏新鲜感；风险是 10-20 关后容易重复。

可用的变化维度：

| 维度 | 例子 | 成本控制 |
| --- | --- | --- |
| 案件类型 | 证词矛盾、时间线错误、逃离路线、伪造现场、身份伪装、怪案异常 | 复用“3 证物 + 3 嫌疑人”结构 |
| 场景主题 | 书房、舞会厅、古董店、旅馆房间、剧院后台、雨夜街角 | 同一场景可做日夜 / 破损 / 节日变体 |
| 工具变化 | 放大镜、紫外灯、录音机、脚印粉、温度计 | 第一版只做放大镜 / 紫外灯 / 提示灯泡 |
| 证物逻辑 | 怀表对应时间，口红印对应证词，脚印对应路线 | 用模板表驱动，不做复杂自由推理 |
| Meta 外层 | 侦探社升级、案件章节、装饰收藏、每日委托 | 控制在轻量，不压过核心关卡 |

第一版验证目标不是证明它能玩一个月，而是验证：

> **玩家是否愿意点开、看懂、并对“找证物后指认真凶”产生想玩冲动。**

如果概念视频和 3 关 Demo 数据成立，再决定是否扩大到 20-30 关内容池。

## 第一关样例：书房疑案

场景是一个 2D 复古书房：倒下的椅子、书桌、地毯、酒杯、窗帘、保险柜、壁炉。为适配微信 / 抖音小游戏审核，画面避免真实尸体和重口血迹，用白色轮廓、红酒、墨水、破碎物件、异常光影表达案发感。

| 证物 | 怎么找 | 证明什么 |
| --- | --- |
| 地毯下的怀表 | 点击掀开地毯，再拖放大镜检查边缘 | 死亡时间与证词不一致 |
| 酒杯上的口红印 | 拖紫外灯扫酒杯 | 女嫌疑人来过现场 |
| 窗台泥脚印 | 点击拉开窗帘，再拖放大镜看窗台 | 凶手不是从正门离开 |

证据链：

```text
怀表时间 + 口红酒杯 + 窗台脚印
  → 未婚妻说“没进过书房”是谎言
  → 指认未婚妻
```

嫌疑人第一版不站在案发现场里，而是在集齐证据后以下方 UI 卡片形式出现。这样画面更清楚，也更适合 15 秒视频：

| 嫌疑人 | 证词 |
| --- | --- |
| 管家 | 我听到争吵，但没进房间。 |
| 未婚妻 | 我整晚都在客厅，没碰过酒杯。 |
| 收藏家 | 我从正门离开，没有靠近窗户。 |

## 美术方向

### 一句话美术钩子

> **彩色黑色电影侦探漫画：复古侦探社、暖黄台灯、青绿色阴影、猩红证据红线、紫外灯扫出的诡异隐藏痕迹。**

### 美术关键词

| 维度 | 选择 |
| --- | --- |
| 画风 | 2D 手绘侦探漫画 / 复古绘本 / 轻度 noir 氛围 |
| 视角 | 竖屏手机游戏截图，2D 场景，轻微俯视，适合寻物 |
| 色彩 | 暖黄灯光 + 青绿色阴影 + 猩红证据红线 + 紫色 UV 特效 |
| 角色 | 半写实漫画比例，表情夸张但不恐怖 |
| 氛围 | 悬疑、轻猎奇、可玩，不走写实血腥 |
| 禁区 | 不做真实凶杀照片、不做重口血腥、不做通用 3D 卡通 |

### 差异化拷问

| 对标类型 | 常见玩法 | 我们的不同点 |
| --- | --- | --- |
| 找不同 / 大家来找茬 | 两张图找 5 个不同点 | 我们不是找不同，而是找能证明谁说谎的证物 |
| 清单式寻物 | 按列表找到指定物品 | 我们找的是证据链，证物会改变最终指认 |
| 剧情寻物 / 装饰寻物 | 寻物后推进剧情或装修 | 我们主打短局压力：倒计时、误判、最后一秒翻案 |

## AI 概念视频制作总原则

- 视频比例：9:16 竖屏。
- 单条时长：约 15 秒。
- 只展示未来游戏里真实可做的核心玩法，不做假广告玩法。
- 关键帧画面不直接生成完整 UI，UI 另行生成后叠加。
- 每张关键帧预留顶部、底部 UI 安全区。
- 关键帧提示词统一要求：**no text, no logo, no watermark, no UI buttons, no interface text**。
