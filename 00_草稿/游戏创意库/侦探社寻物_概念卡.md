# 侦探社寻物概念卡

## 当前判断

题材新颖，但当前一句话玩法偏“寻物解谜”，赛道又写成“模拟经营”，两者存在冲突：

- 如果主循环是“限定时间找证物破案”，它更像短局寻物解谜。
- 如果主循环是“接委托、升级侦探社、雇助手、扩张业务”，它才是模拟经营。
- 两条路都可以，但第一版概念视频必须只选一个主循环。

## 一句话玩法候选

| 方向 | 一句话玩法 | 风险 |
| --- | --- | --- |
| 寻物解谜版 | 玩家在犯罪现场限定时间内找到关键证物，推理出真相并完成案件 | 关卡和美术量大，长线目标弱 |
| 侦探社经营版 | 玩家经营侦探社接委托，派侦探调查、收集线索、升级办公室并解锁更大案件 | 体量容易变大，核心操作可能不够爽 |

## 3 秒可懂画面

- 第一眼看到：凌乱的案发现场、嫌疑人剪影、证物轮廓。
- 角色/物件怎么动：玩家点击/拖动放大镜，在场景中找到被隐藏的证物。
- 最后 1 秒的反转或爽点：倒计时最后一秒找到关键证物，案件板上的线索连成真相。

## 核心规则草案

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 点击、拖动放大镜、选择线索 |
| 目标 | 找到关键证据并完成案件 |
| 限制 | 倒计时、误点次数、证物隐藏位置 |
| 失败条件 | 时间到、误判嫌疑人、关键证物未找到 |
| 爽点 | 最后一秒找到证据、线索板连线、真相反转 |
| 广告点 | 时间快到时给提示/放大镜/额外时间 |
