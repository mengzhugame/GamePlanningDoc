# 核心动词库

> 用途：只存放可以形成操作和爽点的核心动词。题材对象见 `01A_题材库.md`，组合方法见 `README.md` §4。

## 核心动词

| 类别 | 动词 | 适合的爽点 | 常见风险 |
| --- | --- | --- | --- |
| 整理秩序 | 收纳、分类、排序、分拣、解开、**自由搭配 / 装饰** | 从乱到整、最后归位、强迫症满足、自我表达 | 关卡设计量大，容易只有题材没有玩法 |
| 清洁修复 | 清洁、修复、擦除、点亮、翻新 | 前后对比、脏净反差、治愈感 | 互动太浅，容易变成只看视频 |
| 空间操作 | 填充、铺路、拼桥、旋转、摆放 | 差一格、刚好放下、救到目标 | 如果规则不 3 秒可懂会劝退 |
| 物理解压 | 切割、压碎、滚动、倾倒、反弹、**物理随机源（弹球反弹）** | 碎裂、连锁、倾泻、清屏、失控感×控制感 | 爽点强但长期目标弱 |
| 成长变强 | 合成、升级、吞噬、变大、倍增、**合成链进化（Merge）**、**开箱（高波动随机反馈）** | 数值暴涨、外观进化、战力碾压、合成主板永不变空、高奖励上瘾 | 同质化严重，需要强包装或机制差异 |
| 路径引导 | 画线、绘制、发射、引导、冲刺、**叙事解锁（合成推进剧情）** | 一笔成败、极限路线、精准命中、合成推剧情 | 后期关卡变种和公平性难 |
| 群体控制 | 聚集、圈地、包围、冲撞 | 人群变多、围住目标、淹没敌人 | 竞品多，视觉上容易像旧超休闲 |
| 决策构筑 | 三选一、布阵、抽卡、选择升级、**构筑（三选一技能组合）** | 每局不同、差一点通关、Build 成型、爆发流派局 | 系统容易膨胀，不适合轻量验证 |

## 动词扩充注解（2026-05 新增）

- **构筑（三选一技能组合）**：比通用「三选一」更具体到「构筑出爆发流派」。源自拆解《向僵尸开炮》：技能连携 build 是核心爽点。
- **合成链进化（Merge）**：和「合成」的区别 — Merge 是主板永不变空、东西越合越多越高阶；普通合成可能消除。源自拆解 Merge Gardens。**操作×长局留存格的核心动词**。
- **开箱（高波动随机反馈）**：间歇性高奖励比稳定中等奖励更上瘾。源自拆解《装备全靠转》。
- **自由搭配 / 装饰**：自我表达而非被动观看，是中国化女性向重要动词。源自拆解《我的小家》。
- **物理随机源（弹球反弹）**：弹球本身不可控、但摆放完全可控，失控感×控制感张力。源自拆解《噩梦守护战》。
- **叙事解锁（合成推进剧情）**：合成是推动剧情的唯一手段。源自 Gossip Harbor。可破除单纯合成的无趣感。

## 扩充规则

- 从游戏拆解中提取动词时，优先记录「玩家实际做了什么」，不要只写题材词。
- 每个动词最好补一个失败条件，否则很难形成可玩的关卡。
- 动词可以组合，但第一版概念视频只突出一个主动词。
