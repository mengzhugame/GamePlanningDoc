## 2. 工艺路径

1. 用 AI 给的美术风格提示词 + 画面 01 提示词，生成几张游戏的美术风格图（Nanobanana / ChatGPT / 即梦AI），挑选一张确定风格。
2. 在 Lovart / Nanobanana 中上传那一张美术风格参考图，然后生成其它美术关键帧。**关键帧上下预留 UI 安全区，不要生成 UI**。
3. 用第一张风格图，叠加生成 UI 图，觉得整体合适后抠图，生成纯白色只有 UI 的图，在 PS 里组合。
4. 在即梦AI / Lovart 中上传多张关键帧图，根据视频描述提示词生成 15s 视频。
5. 打开剪映，如果生成的视频没有背景音乐，添加符合游戏主题的背景音乐 + 字幕动画。
6. 设置封面，发布视频，先找 AI 要发布标题文案 + 标签。

## 4. UI 提示词

> 添加轻量手机游戏UI叠层：顶部保留一条浅色资源栏，左上角有金币图标和空白数字区域，右上角有小设置按钮；底部保留半透明操作区域。UI风格是圆润卡通、干净简洁、适合休闲手游。画面中出现一个半透明白色手指触控图标，用来表示玩家拖动操作。不要生成任何真实文字、汉字、英文单词、具体数字，所有文字和数字位置用空白圆角标签占位。

优化并重新设计这个界面的UI效果，尤其是顶部栏，去掉底部米白色背景层。底部的透明UI也需要优化。让UI层和整个画面更融合，也更美观

去掉所有场景和角色，只保留顶部左侧金币栏UI和右侧设置按钮，包括底部UI栏和4个按钮包括上锁的框和按钮，纯白色背景底图，方便抠图。

## 5. 视频脚本

### 视频 1 描述（荒废花园复苏）
参考图1，小园丁移动到种子袋和水壶旁，捡起种子和水壶，然后走到中央棕色小地块旁浇水。参考图2，中央土地开始出现一点绿色，小白花从苗床里慢慢长出。动作像真实手机游戏操作演示，节奏清晰。小园丁点击收获小白花，白花以轻快的飞行动画进入背包。然后小园丁走向左侧花店小摊，小园丁把两朵白花交给女顾客，参考图3。女顾客开心地点头，女顾客向下方走去，并离开。然后小摊附近出现少量金币，金币飞入左上方的金币栏，并且金币栏的数字跳动变化从1120-1950。小园丁从花店小摊走向中央棕色小地块旁，画面中弹出一个圆角扩建按钮，参考图4，同时白花周围相邻的灰色枯萎土地出现淡绿色高亮边框，表示这些土地可以扩建。 然后有一个画面中出现一个卡通白色手指（游戏新手引导手指），手指点击扩建按钮，按钮被按下，然后扩建按钮和淡绿色高亮边框消失。同时灰色土地逐渐变成鲜绿色，草地和花朵快速长出，一圈柔和绿色光波向外扩散，参考图5。画面有治愈感和成就感。
