# 90秒极限防线创意汇总

## 当前结论

该方向已否决。它没有制作完整 AI 概念视频，只制作过“最后一格防线”的关键帧提示词和战斗图尝试；当战斗图片出来后，判断核心玩法缺少创意，且短局塔防方向与多款现有产品重合。

## 原一句话玩法

把《光与朽》的塔防经验压缩成 60-90 秒短局：敌人进攻核心，波次间三选一卡牌放塔，玩家用激光塔、减速塔、弹射炮和冻结/打断技能极限防守。

## 否决原因

| 问题 | 判断 |
| --- | --- |
| 路线 A：传统短局塔防 | 容易变成缩水版《保卫萝卜》或同类塔防 |
| 路线 B：90 秒生存守关 | 接近《奔奔王国》《全境守卫》等守关生存产品 |
| 路线 C：弹射连锁塔防 | 接近已有弹射/连锁炮台产品，差异化不足 |
| 核心三不同点 | 答不上来 |
| 视频验证 | 未制作完整 AI 概念视频，只做过关键帧/战斗图尝试 |

## 可保留的资产

虽然方向否决，但旧关键帧文件里有一套可复用的 AI 概念视频制作结构：

1. 通用风格 prefix。
2. 通用负向提示词。
3. 4 张关键帧：危机首帧、选择帧、执行帧、爽点尾帧。
4. 图生视频运镜词：首帧到尾帧拆成 3 秒段落。
5. 剪映后期 UI 叠加清单。

这些结构以后可以迁移到其他创意的视频制作流程里，但不再保留旧长文提示词。

## 复盘教训

- 塔防方向必须先列出 3 个最接近竞品，再回答 3 个核心不同点。
- 不能因为“我能做出来”就进入视频制作；如果第一张图已经暴露同质化，应立刻止损。
- 已否决创意只在 `00_游戏创意总表.md` 保留结论，不继续占用概念验证工作区。
