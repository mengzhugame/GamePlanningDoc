# 50个超休闲小游戏创意

> 来源文件: `50个超休闲小游戏创意.docx`

---

核心動詞: 收集 (Collecting) + 題材: 武俠 (Kung Fu)

遊戲創意: 玩家扮演一位武林高手，在竹林或梅花樁上移動，收集四散的「武功秘籍」碎片。每收集一套，就能解鎖一種華麗的攻擊動畫。

问题和建议：题材不错，但是玩法太单调了，没有意思，可以增加其它核心动词再进行融合。

核心動詞: 伸長 (Stretching) + 題材: 食物 (Food)

遊戲創意: 扮演一個起司條或麵條人，手臂可以無限伸長，去夠取遠處的醬料或配料，同時要繞過滾燙的湯鍋或其他廚房危險。

问题和建议：那这个游戏应该改成玩家通过按住屏幕滑动来控制手臂来躲避障碍去拿到配料，但是感觉玩法还是比较单调。

核心動詞: 雕刻 (Carving) + 題材: 人群 (Crowd)

遊戲創意: 在一塊由密密麻麻小人組成的「人群方塊」上進行雕刻，用手指滑動來移除一部分小人，最終雕刻出指定的形狀或人物形象。

问题和建议：密集恐惧症玩不了这个游戏。

核心動詞: 傾倒 (Pouring) + 題材: 交通工具 (Vehicles)

遊戲創意: 類似於《Water Sort Puzzle》，但試管裡裝的不是液體，而是不同顏色的小汽車、飛機或輪船。玩家需要將它們分類傾倒到正確的停車場或機庫裡。

问题和建议：已经有这个小游戏了

核心動詞: 聚集 (Gathering) + 題材: 音樂 (Music)

遊戲創意: 控制一個核心音符，在五線譜上移動，觸碰並聚集其他散落的音符。聚集的音符越多，背景音樂的配器就越豐富，最終形成一首完整的交響樂。

问题和建议：音乐类型游戏不考虑。

核心動詞: 繪製 (Drawing) + 題材: 惡作劇 (Prank)

遊戲創意: 畫一條線，引導一顆水球或一個香蕉皮，讓它精準地落在目標人物的頭上或腳下，完成惡作劇。

问题和建议：这个可以，第一关画一条线，第二关画两条，但是需要考虑10关或者50关以后得关卡难度和变种玩法。

核心動詞: 合併 (Merging) + 題材: 街頭文化 (Street Culture)

遊戲創意: 在一個場地上合併相同的滑板、塗鴉噴漆罐或B-Boy舞者，進化成更酷、更高級的版本，並在最終的鬥舞或滑板比賽中獲得高分。

问题和建议：这个不好玩

核心動詞: 圈地 (Enclosing) + 題材: 寵物/動物 (Pets/Animals)

遊戲創意: 玩家畫出一個圍欄，把草原上四散奔跑的羊群或雞群圈起來，圈到的越多分數越高，同時要避開兇猛的野狼。

问题和建议：这个也是一个画圈的游戏，需要做碰撞检测，羊群或者野狼碰撞到围栏会停止奔跑，而且还需要考虑程序对羊群四散奔跑的设计（没考虑好），然后第一关羊群慢速奔跑，没有野狼，玩家直接画圈围住羊群。第二关羊群可以增加一点速度，野狼多一些，考验玩家画圈圈住的反应能力。但是这个游戏有个问题，如何计算失败？如果按照圈住数量计算的话，那后面关卡怎么办？数量会越来越多，游戏也会单一无趣。

核心動詞: 發射 (Launching) + 題材: 金錢 (Money)

遊戲創意: 用一個大砲將金幣發射出去，讓金幣通過帶有倍增或增加效果的門，最終落入一個巨大的存錢罐中，目標是裝滿它。

问题和建议：那就是玩家控制发射出来的金币的左右位移，来躲避倍增，增加或倍减等等障碍门，最终落到存钱罐中，装满则游戏胜利通关，但是失败的条件呢？金币的数量和发射次数吗？假设发射10次都没有填满则游戏失败。但是后续关卡的难度或者玩法升级呢？

核心動詞: 消除 (Matching) + 題材: 競賽 (Racing)

遊戲創意: 一個消除遊戲和賽車遊戲的結合體。玩家通過快速消除下方的方塊來為自己的賽車積攢氮氣，消除越快，賽車跑得越快。

问题和建议：这个创意不错，但是通过消除，赛车是自己一辆车跑1大圈，跑完则游戏通关胜利？最后统计每一关的计时再排行榜上？ 还有一个问题就是消除类型的游戏太多了。

核心動詞: 下落 (Falling) + 題材: 建造 (Construction)

遊戲創意: 從高空丟下各種形狀的建築模塊，通過旋轉使其在下落過程中完美契合到下方的地基上，像俄羅斯方塊一樣層層疊高，建造摩天大樓。

问题和建议：不考虑俄罗斯方块，这类游戏太多了

核心動詞: 攻擊 (Attacking) + 題材: 整理 (Sorting/Cleaning)

遊戲創意: 玩家控制一個清潔工，用手中的掃把或水槍（攻擊）來清除地面上不斷湧現的污漬或垃圾怪。

问题和建议：玩法太单一，不过清洁工用水枪清除污渍的创意点可以，需要增加一些别的玩法和创意，程序也不好实现控制。

核心動詞: 分裂 (Splitting) + 題材: 解謎 (Puzzle)

遊戲創意: 控制一個可以分裂成兩個或多個小個體的史萊姆，利用分裂來同時觸碰多個機關，或者穿過狹窄的通道，最終讓所有分裂體在終點匯合。

问题和建议：玩家如何控制多个史莱姆？玩家不控制的时候史莱姆就在原地吗？这个创意对玩家的操作性上有很大难度。如果是史莱姆自动往前移动，玩家控制史莱姆什么时候分裂什么时候合体，那这个玩法又有点简单。

核心動詞: 扇巴掌 (Slapping) + 題材: 物理 (Physics)

遊戲創意: 遊戲中有一排多米諾骨牌或布娃娃，玩家控制一隻大手，找准時機和角度扇出一巴掌，目標是利用物理連鎖反應擊倒盡可能多的物體。

问题和建议：如果每一关都是这样，会有点太单一的玩法。

核心動詞: 駕駛 (Driving) + 題材: 手工藝 (Crafting)

遊戲創意: 駕駛一輛帶有畫筆或刻刀的微型車，在一個木頭或畫布上按照指定的路線行駛，從而自動完成一幅畫或一件雕塑。

问题和建议：一幅画和一件雕塑太复杂，玩家如果控制一辆微型车，那车需要来来会会按照路线跑，太无聊。

核心動詞: 奔跑 (Running) + 題材: 數字/合併 (Numbers/Merging)

遊戲創意: 玩家控制一個帶有數字的角色向前奔跑，可以選擇吃掉比自己小的數字來增加自身數值，或者穿過帶有加法或乘法的門，最終到達一個需要用數值來擊敗的Boss面前。

问题和建议：已经有这类游戏了。

核心動詞: 跳躍 (Jumping) + 題材: IO

遊戲創意: 在一個不斷下沉的巨大平台上，所有玩家控制自己的角色跳躍，踩踏其他玩家可以將其暫時擊暈，目標是成為最後一個留在平台上的倖存者。

问题和建议：这个创意只适合马里奥派对那种，几个人在家里玩的小游戏

核心動詞: 堆疊 (Stacking) + 題材: 食物 (Food)

遊戲創意: 製作一個超高的漢堡或三明治。從上方會掉落麵包、肉餅、生菜等食材，玩家需要左右移動接住它們，堆疊得越高越穩，分數就越高。

问题和建议：这个创意只适合马里奥派对那种，几个人在家里玩的小游戏

核心動詞: 切割 (Cutting) + 題材: 音樂 (Music)

遊戲創意: 類似《Beat Saber》的簡化版，音符會從屏幕前方飛來，玩家需要跟隨節奏，在正確的時機滑動手指，像切水果一樣切割音符。

问题和建议：音乐类游戏太小众，不考虑

核心動詞: 畫線 (Line Drawing) + 題材: 戰鬥 (Combat)

遊戲創意: 畫出一條線作為你的軍隊（螞蟻、士兵等）的前進路線，讓他們繞開障礙，包圍並攻擊敵人的基地。

问题和建议：这个创意可以，包围攻击敌人基地，敌人是否会有士兵，是否会减少军队？如果有减少军队，那沿途也有增加军队数量的补给。如果是第一关可以绕开障碍，攻击1个基地，然后取得胜利，但是后面的关卡难度如何依次递增？游戏的失败条件又是什么？打光自己所有的士兵？那会产生一个问题，如何判断士兵的数量是否能打下这个基地？如何让玩家不会出现就绕开基地，不攻打呢？需要再延伸和完善这个游戏的想法。

核心動詞: 按壓 (Pressing) + 題材: 破壞 (Destruction)

遊戲創意: 屏幕上有一個液壓機，下方會不斷出現各種物品（水果、手機、汽車模型），玩家通過長按屏幕來控制液壓機下壓，享受將物品壓碎的滿足感。

问题和建议：这个创意美术效果做的好一点，是不错的，释放玩家的压力。但是如何判定游戏的胜负？玩家第一次和第二次玩会觉得不错，但是长时间玩，没有什么游戏的可玩性。需要再延伸和完善这个游戏的想法。

核心動詞: 解開 (Untangling) + 題材: 交通 (Traffic)

遊戲創意: 城市交通完全打結，玩家需要像解開繩結一樣，逐個點擊並引導汽車駛出混亂的路口，直到所有道路恢復通暢。

问题和建议：已经有类似的游戏了。

核心動詞: 吞噬 (Devouring) + 題材: 時尚/美容 (Fashion/Beauty)

遊戲創意: 控制一個黑洞，但吞噬的不是物體，而是T台上模特的過時服裝，每吞噬一件，就為其換上一件更時尚的新衣。

问题和建议：比较无聊，没有趣味性

核心動詞: 點擊 (Tapping) + 題材: 抽象 (Abstract)

遊戲創意: 畫面中有多種顏色的圓形在擴散和碰撞，玩家需要在不同顏色的圓形碰撞的瞬間點擊屏幕，觸發華麗的視覺效果和連鎖反應。

问题和建议：没有游戏性

射箭 (Shooting Arrows) + 寵物 (Pets): 射出帶有食物的箭，精准地餵給遠處移動的寵物。

问题和建议：这个创意只适合马里奥派对那种，几个人在家里玩的小游戏，然后比拼谁投喂的食物更多。

收集 (Collecting) + 惡作劇 (Prank): 在辦公室裡悄悄移動，收集同事的咖啡杯，堆成一座高塔而不被發現。

问题和建议：没有游戏性

滾動 (Rolling) + 數字 (Numbers): 滾動一個骰子，根據點數前進，並與路徑上的數字進行運算。

问题和建议：没有游戏性。

伸長 (Stretching) + 競賽 (Racing): 賽跑遊戲，但你可以伸長你的腿來跨越障礙或更快到達終點。

问题和建议：没有游戏性。

合併 (Merging) + 手工藝 (Crafting): 合併基礎的顏料來創造新的顏色，並用它來為陶器上色。

问题和建议：没有游戏性。

發射 (Launching) + 整理 (Sorting): 用彈弓把不同顏色的衣服精準地發射到對應顏色的洗衣籃裡。

问题和建议：这个创意只适合马里奥派对那种，几个人在家里玩的小游戏

繪製 (Drawing) + IO: 在一個共享的畫布上，通過繪製來圈地，把別人的畫作變成自己的顏色。

问题和建议：没有游戏性。

駕駛 (Driving) + 消除 (Matching): 駕駛一輛車在倉庫裡移動，將三個相同顏色的貨箱推到一起來消除它們。

问题和建议：有类似的游戏，而且别人没有你这么复杂，只是点击车，车就会去槽位，然后3个相同颜色的车就会消除

聚集 (Gathering) + 金錢 (Money): 控制一塊磁鐵，在城市裡滾動，吸附地上的硬幣，讓錢球越滾越大。

问题和建议：没有游戏性。

圈地 (Enclosing) + 物理 (Physics): 畫一個圈，圈住下落的物理小球，讓它們在你的圈內碰撞得分。

问题和建议：没有游戏性。

下落 (Falling) + 交通工具 (Vehicles): 控制一輛下落的汽車，在空中左右移動，穿過一層層的圓環。

问题和建议：没有游戏性。

雕刻 (Carving) + 食物 (Food): 在一個巨大的起司輪或黃油塊上，根據虛線雕刻出指定的形狀。

问题和建议：没有游戏性。

攻擊 (Attacking) + 音樂 (Music): 敵人會跟隨音樂節拍出現，你需要準確地在節拍點上點擊屏幕來攻擊它們。

问题和建议：不想做音乐类游戏

奔跑 (Running) + 繪畫 (Painting): 你的角色跑過純白的地面時，會留下彩色的足跡，目標是跑遍所有路徑，完成一幅巨大的畫。

问题和建议：没有游戏性。

跳躍 (Jumping) + 整理 (Sorting): 在傳送帶上跳躍，通過跳躍踩踏開關，將不同物品分流到正確的箱子裡。

问题和建议：如何通过跳跃踩踏开关，又如何将物品分流到正确的箱子里？需要再延伸和完善这个游戏的想法。

滑行 (Sliding) + 武俠 (Kung Fu): 在結冰的湖面上滑行，利用慣性撞擊敵人，有點像冰壺但主題是武俠。

问题和建议：没有游戏性。

堆疊 (Stacking) + 人群 (Crowd): 像啦啦隊一樣，將小人一個個向上拋，讓他們在空中堆疊成盡可能高的人塔。

问题和建议：没有游戏性。

傾倒 (Pouring) + 抽象 (Abstract): 將不同顏色的流沙從容器中傾倒出來，創造出富有層次感的沙畫藝術。

问题和建议：没有游戏性，但是有一个倒沙子的游戏，是利用水排序的玩法。

扇巴掌 (Slapping) + 競賽 (Racing): 與對手賽跑，但可以通過扇巴掌使其短暫眩暈，從而超車。

问题和建议：没有游戏性。

消除 (Matching) + 建造 (Construction): 消除特定顏色的方塊來獲取對應的建築材料，然後用這些材料來建造你的城市。

问题和建议：消除类游戏太多了。

分裂 (Splitting) + 跑酷 (Parkour): 在跑酷中遇到岔路時，可以將角色分裂成兩個，分別跑不同的路徑來收集所有獎勵。

问题和建议：没有游戏性。

點擊 (Tapping) + 寵物 (Pets): 屏幕上會快速出現地鼠洞，但鑽出來的是可愛的小貓小狗，點擊撫摸它們而不是敲打。

问题和建议：这不就是打地鼠吗？如果是抚摸，没有打地鼠的紧张刺激感。

按壓 (Pressing) + 食物 (Food): 模擬製作果汁，長按屏幕將水果壓入榨汁機，要注意不能按太久導致機器過熱。

问题和建议：没有游戏性。

畫線 (Line Drawing) + 街頭文化 (Street Culture): 畫出一條完美的塗鴉線條，一筆完成整個字母或圖案。

问题和建议：没有游戏性。

解開 (Untangling) + 物理 (Physics): 解開纏繞在一起的鏈條，解開時它們會因為重力而產生有趣的物理擺動。

问题和建议：有点像打个螺丝，那个游戏就是解开堆叠在一起不同形状的板，钉子颜色也不同，解开就是用颜色钉子消除，一层一层的解开木板，最后通关，也有物理摆动。

【題材：物理 + 惡作劇】 + 【核心動詞：發射】

遊戲創意： 玩家使用一個巨大的彈弓，計算角度和力道（物理），將奶油派、水球等物品發射出去，精準命中樓下路過的卡通角色，完成惡作劇。

问题和建议：这个创意只适合马里奥派对那种，几个人在家里玩的小游戏

【題材：漢字】 + 【核心動詞：建造 + 堆疊】

遊戲創意： 類似俄羅斯方塊，從上方掉落的是不同的漢字部首（如「亻」、「木」、「口」），玩家需要將它們正確地堆疊組合起來，拼成一個完整的漢字來消除。

问题和建议：汉字只能在同一水平线组合，只能是每个部首都是一个方块格子，然后组合方块格子消除，游戏性不强。

【題材：音樂】 + 【核心動詞：圈地】

遊戲創意： 一款IO遊戲，玩家控制一個音符在樂譜上移動。通過圈地來“佔領”一段旋律，被佔領的區域會持續播放音樂。最終，整個地圖會根據各玩家佔領的區域，交織成一首獨特的交響樂。

问题和建议：不做音乐类游戏

【題材：RPG + 三消】 + 【核心動詞：放置】

遊戲創意： 一款放置型RPG，戰鬥場景是一個會自動進行三消的寶石棋盤。英雄會根據消除的寶石顏色自動攻擊。玩家的核心玩法是「放置」和升級英雄，以及配置棋盤上不同寶石的掉落機率。

问题和建议：如何放置和升级英雄？英雄根据消除的宝石颜色自动攻击谁？如何配置棋盘上不同的宝石的掉落几率？没搞明白这款游戏的玩法是什么？
