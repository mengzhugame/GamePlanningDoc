## 2. 工艺路径（标准 8 步）

1. **风格定调** — 用 Nanobanana / ChatGPT / 即梦 生成 5-10 张候选风格图，挑 1 张确定。
2. **关键帧扩展** — 在 Lovart / Nanobanana 上传风格图，根据各画面提示词生成关键帧。**注意预留上下 UI 安全区，不要生成 UI**。
3. **UI 叠层生成** — 用风格图叠加生成完整 UI 图。
4. **UI 抠图** — 把生成的 UI 抠出来，生成纯白底 UI 图，方便 PS 合成。
5. **PS 合成** — 在 PS 里把关键帧 + 抠出的 UI 组合成完整画面。
6. **图生视频** — 在即梦 / Lovart 上传多张关键帧，按视频脚本提示词生成 15s 视频。
7. **剪映后期** — 添加背景音乐 + 字幕动画 + 转场。
8. **封面 + 发布** — 设置封面，让 AI 出标题/文案/标签，发布到 4 平台。
