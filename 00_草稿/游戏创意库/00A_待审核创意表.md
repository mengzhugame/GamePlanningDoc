# 待审核创意表

> 用途：每周或间隔一段时间由 AI 批量组合生成的创意，先进入这里。
> 这里是「人工筛选工作台」，不是永久总账。已否决、已通过、已合并的创意要从本表移走，并同步更新 `00_游戏创意总表.md`。
> 完整流转规则见 `README.md` §5。

## 审核三问

每条创意进本表前，先回答：
1. 3 秒钩子能讲清吗？
2. 跟最火同类的核心 3 个不同点能讲出来吗？
3. 1 个月能出 Demo 吗？

任一答不上 → 否决，直接进 `00_游戏创意总表.md`，不占用本表。

| 已通过初筛 | 已通过人工判断，可进入概念验证或原型前讨论 | 放入 `00B_已通过创意表.md` |
| 已上线 | 已制作并上线，等待复盘或继续运营判断 | 进入项目数据复盘 |
| 已上线失败 | 已上线但商业/留存/发行结果不理想 | 只作为失败样本和流程资产保留 |
| 已否决 | 当前不推进 | 只保留关键否决原因，避免重复踩坑 |
| 已合并 | 与其他创意重复或可作为子机制 | 合并到主创意或素材库 |

## 审核规则

- **否决**：从本表移除，在 `00_游戏创意总表.md` 保留一行「已否决 + 原因」。
- **通过**：从本表移除，加入 `00B_已通过创意表.md`，并复制 `02_创意卡模板.md` 补单独概念卡。
- **还没想清**：留在本表，但必须写清「卡住的问题」，不能长期只写「感觉不错」。卡 1 个月以上 → 转否决。
- **合并**：如果只是另一个创意的题材皮、广告点或子机制，标为合并并移动到总表对应创意的备注中。
