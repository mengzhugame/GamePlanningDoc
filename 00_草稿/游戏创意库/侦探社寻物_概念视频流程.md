## 1. 美术风格定调

### AI 提示词（9:16 竖屏，所有视频共用）

```text
9:16 竖屏手游概念美术，风格化的 2D 手绘侦探漫画风格，色彩鲜明的黑色电影式悬疑格调，营造复古侦探社的氛围；画面以温暖的琥珀色光线为主调，辅以青绿色阴影、点缀着深红色的关键物证，并泛着紫罗兰色的紫外光晕；隐藏物品场景设计简洁清晰、易于辨识；采用略带俯视视角的 2D 构图；细节丰富但不追求写实；风格适配休闲手游；构图具有电影感；画面上下预留空白安全区以便叠加 UI 界面；画面中不得包含任何文字、Logo、水印、UI 按钮或界面文本。
```

### 一句话美术钩子

> **彩色黑色电影侦探漫画：复古侦探社、暖黄台灯、青绿色阴影、猩红证据红线、紫外灯扫出的诡异隐藏痕迹。**

### 美术关键词

| 维度  | 选择                               |
| --- | -------------------------------- |
| 画风  | 2D 手绘侦探漫画 / 复古绘本 / 轻度 noir 氛围    |
| 视角  | 竖屏手机游戏截图，2D 场景，轻微俯视，适合寻物         |
| 色彩  | 暖黄灯光 + 青绿色阴影 + 猩红证据红线 + 紫色 UV 特效 |
| 角色  | 半写实漫画比例，表情夸张但不恐怖                 |
| 氛围  | 悬疑、轻猎奇、可玩，不走写实血腥                 |
| 禁区  | 不做真实凶杀照片、不做重口血腥、不做通用 3D 卡通       |

## 2. 工艺路径

1. 用 AI 给的美术风格提示词 + 画面 01 提示词，生成几张游戏的美术风格图（Nanobanana / ChatGPT / 即梦AI），挑选一张确定风格。
2. 在 Lovart / Nanobanana 中上传那一张美术风格参考图，然后生成其它美术关键帧。**关键帧上下预留 UI 安全区，不要生成 UI**。
3. 用第一张风格图，叠加生成 UI 图，觉得整体合适后抠图，生成纯白色只有 UI 的图，在 PS 里组合。
4. 在即梦AI / Lovart 中上传多张关键帧图，根据视频描述提示词生成 15s 视频。
5. 打开剪映，如果生成的视频没有背景音乐，添加符合游戏主题的背景音乐 + 字幕动画。
6. 设置封面，发布视频，先找 AI 要发布标题文案 + 标签。

## 4. UI 提示词

### 调查阶段 UI

```text
添加休闲手机游戏UI叠层，竖屏9:16移动端游戏界面，风格化的2D侦探漫画式UI设计，复古侦探案卷质感，整体设计简洁明快，符合移动端休闲游戏的阅读体验。
左上角有暂停按钮图标，顶部中间有倒计时横条，倒计时横条显示"00:59"，横条下方或右侧显示"关键证物 0/3"。底部有3个圆形工具按钮：放大镜工具按钮、紫外线灯工具按钮、提示灯泡按钮。按钮呈琥珀色，边框为深青绿色描边，工具图标带有紫罗兰色光晕效果，按钮有轻微立体高光和点击反馈感。

no logo, no watermark, no extra buttons, no messy decorations
```
