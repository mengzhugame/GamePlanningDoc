# 怪案侦探社 概念卡

## 当前结论

本创意从原来的 **侦探社寻物 IAA 小游戏** 和 **证据时间线排序小游戏**，重构为：

> **Steam 单机推理解谜游戏：玩家像导演一样摆放角色、物品和行动顺序，重演出唯一能解释所有证据的犯罪过程。**

旧方向处理：

| 旧方向 | 当前判断 | 保留内容 |
| --- | --- | --- |
| 寻物 + 指认真凶 | 不适合纯 IAA。50 关会带来大量新场景、新道具、新剧情和新美术，内容成本与广告收益不匹配 | 复古侦探漫画美术、证据高亮、指认爽点 |
| 证据时间线排序 | 不再作为主玩法。单纯拖证据卡排序画面感偏弱，但可以作为“案发重演”的底层逻辑和 UI 模块 | 时间线、证据约束、疑点槽、错误验证 |
| 单人剧本杀 / 音频时间线 | 排除。太像《Unheard》，且高质量音频与配音生产不稳定 | “还原本”的多角色、多时间、多动机结构 |
| 单人社交推理 RPG / 第一人称沉浸侦探 / 多人剧本杀 | 暂不推进。系统或内容量过大，超出个人开发首作可控范围 | 角色秘密、证词矛盾、封闭场景气氛 |

## 1. 一句话玩法

玩家经营一家专接怪案的侦探社。每个案件中，玩家根据证据、证词和现场结果，把角色、物品和行动卡摆到案发时间轴上，点击“重演”后观看犯罪小剧场；如果重演结果与证据不一致，系统逐条标红矛盾，玩家继续调整，直到还原出真正的作案过程。

## 2. 核心体验

### 玩家在做什么

不是找物品，不是选答案，也不是听系统讲故事。

> 玩家亲手搭建一个“犯罪过程模型”，让它跑起来，并用证据验证它是否成立。

### 核心循环

1. 接到怪案委托，阅读案情、人物关系和已知证据。
2. 进入案发重演界面：中间是 2D 案发舞台，底部是角色 / 物品 / 行动卡，右侧是证据约束。
3. 玩家把角色放入房间，把行动卡拖到时间线上。
4. 点击“重演”，系统按玩家安排播放一遍犯罪小剧场。
5. 证据逐条验证：成立则亮绿，不成立则标红并给出矛盾提示。
6. 玩家根据矛盾调整角色位置、行动顺序或物品归属。
7. 所有关键证据成立后，进入真相复盘，解锁侦探社主线。

### 关键爽点

| 爽点 | 说明 |
| --- | --- |
| 亲手还原 | 玩家不是填空，而是把凶案摆出来 |
| 错误可解释 | 不是简单“错了”，而是告诉玩家哪条证据无法成立 |
| 小剧场反馈 | 每次提交都会播放一段玩家自己搭出来的案发过程 |
| 逻辑闭环 | 最后所有证据同时亮绿，产生“原来是这样”的破案瞬间 |
| 怪案规则 | 每案加入一个异常规则，让案件不只是换剧情 |

## 3. 屏幕与操作

### 主界面布局

| 区域 | 内容 | 作用 |
| --- | --- | --- |
| 中央案发舞台 | 2D 剖面房间 / 纸剧场 / 桌游棋盘式现场 | 播放角色行动和案发重演 |
| 顶部时间轴 | 21:00、21:05、21:10 等时间槽 | 放置行动顺序 |
| 底部卡池 | 角色卡、物品卡、行动卡 | 玩家拖拽摆放的主要素材 |
| 右侧证据板 | 尸体位置、门锁状态、脚印、证词矛盾等 | 每次重演后逐条验证 |
| 左侧案件档案 | 人物关系、初始案情、已知限制 | 帮玩家推理 |

### 玩家输入

- 拖动角色到房间。
- 拖动物品给角色或放入房间。
- 拖行动卡到时间轴。
- 点击“重演”播放案发小剧场。
- 点击证据条查看矛盾原因。
- 调整顺序后再次验证。

### 不做什么

- 不做开放世界或大场景第一人称探索。
- 不做多人联机、语音社交或在线剧本杀。
- 不做自由文本询问 NPC。
- 不依赖大量 AI 配音音频。
- 不把核心玩法做成单纯证据卡排序。

## 4. 第一案纸面原型：雨夜书房密室案

### 场景

2D 剖面小舞台，4 个区域：

| 区域 | 用途 |
| --- | --- |
| 书房 | 死者倒地、红酒杯、保险柜、地毯、窗户 |
| 走廊 | 管家送酒、收藏家经过、门锁状态 |
| 餐厅 | 未婚妻与死者争吵后的起点 |
| 阳台 | 翻窗逃离、泥脚印来源 |

### 角色

| 角色 | 表面证词 | 隐藏信息 |
| --- | --- | --- |
| 未婚妻 | “我整晚都在餐厅，没有碰过酒杯。” | 她端过红酒，杯沿留下口红印 |
| 管家 | “我只把酒送到门口，没有进书房。” | 他知道备用钥匙位置 |
| 收藏家 | “我只是路过走廊，没见过怀表。” | 他偷过怀表，但不是凶手 |
| 死者 | 死亡时间约 21:15 | 死前改过遗嘱 |

### 卡牌素材

| 类型 | 卡牌 |
| --- | --- |
| 角色卡 | 未婚妻、管家、收藏家、死者 |
| 物品卡 | 红酒杯、毒药、怀表、备用钥匙、泥鞋 |
| 行动卡 | 进入、离开、送酒、下毒、交换、撞倒、掉落、锁门、翻窗、目击 |
| 异常卡（后续） | 影子行动、镜像反转、延迟显现 |

### 证据约束

| 证据 | 验证条件示例 |
| --- | --- |
| 酒杯上有口红印 | 未婚妻必须在作案前接触过酒杯 |
| 门从内侧反锁 | 有人必须在死者死亡后制造密室或使用备用钥匙 |
| 窗台有泥脚印 | 至少一名角色必须经由阳台 / 窗户离开 |
| 怀表掉在地毯旁 | 收藏家或未婚妻必须在书房附近掉落怀表 |
| 死亡时间 21:15 | 下毒 / 死亡触发不能早于关键目击证词 |
| 管家 21:10 在走廊被目击 | 管家同一时间不能出现在阳台 |

### 目标答案

玩家最终不只是选“谁是凶手”，而是完成三类答案：

| 问题 | 答案形式 |
| --- | --- |
| 谁是真凶？ | 指认角色 |
| 作案链条如何成立？ | 重演时间线全部通过验证 |
| 哪条证词是谎言？ | 点出对应证据和证词矛盾 |

## 5. 怪案规则扩展

每个正式案件都应有一个可被一句话解释的异常规则，避免只靠换剧情撑内容。

| 案件规则 | 玩法效果 | 视频钩子 |
| --- | --- | --- |
| 影子案 | 影子可以独立行动一次，必须把“影子行动卡”放进时间线 | 人没进书房，影子却偷走钥匙 |
| 镜中案 | 镜中房间左右相反，部分证词需要反向理解 | 监控里凶手从左门进，现实却是右门 |
| 时间错位案 | 某个角色的行动结果会延迟 10 分钟显现 | 21:05 打碎的杯子，21:15 才被听见 |
| 假死案 | 死亡时间被伪造，尸体状态会误导玩家 | 死者“死后”还移动过一次 |
| 双重身份案 | 一名角色伪装成另一名角色，行动轨迹互相覆盖 | 同一时间两个“管家”出现在不同房间 |

## 6. 差异化拷问

| 铁律 | 问题 | 当前回答 | 通过 |
| --- | --- | --- | --- |
| 差异化 | 和同类侦探 / 推理解谜游戏的 3 个核心不同点是什么？ | (1) 不是听音频或找物，而是摆放案发过程并让系统验算；(2) 不是单纯证据排序，而是角色、物品、行动、地点共同构成小剧场；(3) 每案有一个怪异规则，形成“案件机制差异”而不只是剧情差异 | 待纸面验证 |
| 美术 | 是否有风格化 / 猎奇 / 反差？ | 复古侦探漫画 + 纸剧场犯罪重演 + 猩红证据线 + 剪影角色。避免写实血腥，走“可爱桌游外观 + 黑暗案件逻辑”的反差 | 初步通过 |
| 速度 | 1 个月内能否做出可测 Demo？ | 可以做 1 案灰盒：4 房间、4 角色、10 行动卡、10 条证据约束、1 套重演验证 UI。不做完整剧情、不做多案、不做配音 | 初步通过 |

## 7. 商业定位

| 项 | 判断 |
| --- | --- |
| 平台 | Steam 优先，后续可考虑 itch.io / TapTap 试玩页 |
| 商业模式 | 小体量买断制，不按纯 IAA 小游戏设计 |
| 首版规模 | 1 个教学案 + 3 个正式案 + 1 个终章案 |
| 单案时长 | 教学案 10-15 分钟；正式案 30-60 分钟；终章可 60-120 分钟 |
| 核心卖点 | “像剧本杀还原本一样，把凶案亲手摆出来并验证” |
| 主要风险 | 谜题设计质量、验证系统复杂度、UI 是否足够易懂 |

## 8. 验证计划

### 纸面原型通过线

先不要进正式开发，先做“雨夜书房密室案”的纸面 / Figma / 表格原型。

| 验证项 | 通过标准 |
| --- | --- |
| 规则理解 | 陌生玩家 3 分钟内明白“摆行动 → 重演 → 看矛盾 → 调整” |
| 推理爽感 | 玩家通关时能说出“原来是这样发生的” |
| 失败反馈 | 玩家看到红色矛盾提示后知道下一步该调整什么 |
| 内容可写 | 你能连续写出 3 个不同案件规则，而不是只写出书房案 |
| 制作意愿 | 看完第一条概念视频后，你自己仍然想继续做第二条 |

### 下一步

1. 新建 / 更新 `怪案侦探社_概念视频流程.md`，按“案发重演”而不是“寻物指认”制作。
2. 做一版 15-30 秒概念视频：重点展示“摆错 → 重演矛盾 → 修正 → 证据全绿”。
3. 做一个 1 案纸面原型，找 3-5 个陌生玩家测试。
4. 如果纸面原型无聊，直接 Kill；如果 3 人以上主动说想玩 Demo，再考虑灰盒。
