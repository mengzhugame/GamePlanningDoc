> 使用方式：复制本文件，新建为 `创意名_概念卡.md`，放在 `00_草稿/游戏创意库/`。
> 进入条件：在 `00A_待审核创意表.md` 通过审核三问。
> 退出条件：5 段填完 + 第 4 段「差异化拷问」3 条铁律全过 → 复制 `04_概念视频流程模板.md` 进入视频阶段。

# 创意名

## 1. 一句话玩法

用一句话说明玩家做什么、为了什么、失败会怎样。三件事一句话说完。

> 填不出？回 00A 重审，创意没成型。

## 2. 3 秒可懂画面

- 第一眼看到什么：
- 角色 / 物件怎么动：
- 最后 1 秒的反转或爽点：

> 画不出？视频也做不出来，回 00A。

## 3. 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 例如点击、拖拽、画线、长按、左右移动 |
| 目标 | 例如装满、救出、清空、击败、修复 |
| 限制 | 例如倒计时、格子有限、次数有限、敌人逼近 |
| 失败条件 | 例如槽位满、时间到、目标死亡、基地被突破 |
| 爽点 | 例如刚好放下、清屏、倍增、前后对比 |
| 广告点 | 玩家差一点失败时，哪里可以插入复活/道具 |

> 6 个子字段，任一不成立 → 玩法不闭环，回 00A。

## 4. 差异化拷问（立项铁律 3 条）

> 来自 `40_知识/01_游戏设计/立项铁律_2026-05.md`。
> 配套 skill：`/iron-rule-check <方向名>` 让 AI 帮你拷问。

| 铁律 | 问题 | 回答 | 通过 |

| 1. 差异化 | 和最火同类相比，核心 3 个不同点是什么？最接近的 3 款竞品分别是？ |  | ☐ |
