# 游戏创意库

## 这是什么

这里存放游戏创意、玩法组合、题材库、灵感清单和待筛选方向。

## 文件入口

| 文件               | 用途                                              |
| ---------------- | ----------------------------------------------- |
| `00_游戏创意总表.md`   | 所有创意总账：汇总状态、判断、来源和下一步                           |
| `00A_待审核创意表.md`  | AI 批量生成或临时记录的创意筛选池                              |
| `00B_已通过创意表.md`  | 通过初筛、进入概念验证/项目/上线阶段的创意                          |
| `01A_题材库.md`     | 只存放游戏题材和对象                                      |
| `01B_核心动词库.md`   | 只存放核心动词、爽点和风险                                   |
| `01_游戏创意组合库.md`  | 组合公式、参考游戏拆解关键词、推荐组合池和使用纪律                       |
| `02_创意卡模板.md`    | 单个创意继续打磨时复制使用                                   |
| `03_概念验证记录模板.md` | 创意进入 AI 玩法概念视频验证时复制使用                           |
| `99_原始资料转写/`     | 旧 doc/docx/xlsx/txt 转成的 Markdown 原始资料，只作证据和素材来源 |

## 使用规则

- 粗糙想法可以先放这里。
- 被选中的方向，先用 `02_创意卡模板.md` 补齐一句话玩法、失败条件、差异化和视频钩子。
- 准备做 AI 玩法概念视频时，在本目录创建 `创意名_概念视频数据记录.md`。
- 通过概念验证后才进入 `20_项目/`。
- 否决的创意从待审核表移除，但必须保留在 `00_游戏创意总表.md` 中。

## 整理原则

- 根目录只放会反复打开的工作文件。
- 原始长文、历史清单、批量生成内容放入 `99_原始资料转写/`。
- 不把“题材不错”直接当成立项理由；每个创意必须写出失败条件和差一点通关的广告点。
