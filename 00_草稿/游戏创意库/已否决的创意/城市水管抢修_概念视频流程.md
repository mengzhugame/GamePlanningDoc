## 2. 工艺路径（标准 8 步）

1. **风格定调** — 先生成 4×4 医院关卡、6×6 消防关卡、漏水关卡三张静帧。
2. **关键帧扩展** — 每条视频展示 3 次拖拽和 1 次水流结果。
3. **UI 叠层生成** — 顶部目标设施状态和开闸次数，目标设施警报，底部三块管道。
4. **UI 抠图** — 管道块、格子、目标设施、开闸按钮、救助按钮分层。
5. **PS 合成** — 做出拖入前后状态和水流路径高亮。
6. **图生视频** — 水流沿路径流动、漏水喷出、目标变绿。
7. **剪映后期** — 加水流音、警报音、成功音效。
8. **封面 + 发布** — 封面用“医院供水断了，这条水管怎么接？”。

## 4. UI 提示词

### 主界面 UI

```text
微缩城市抢修手游 UI，顶部显示目标设施状态、星级、开闸验收次数；中间是 N×N 城市管网格子，左上入水口，目标设施有医院、消防栓、学校；底部固定显示 3 个不同形状的管道块；按钮为撤回、提示、替换管道、开闸验收；蓝色水流、红色警报、灰色道路，无 logo、无水印、无多余按钮。
```

### 子界面 UI（结算 / 救助）

```text
结算界面：城市目标变绿、三星评价、无提示通过、下一关按钮；救助界面：替换一个管道块、撤回 3 步、封住漏水点、增加 1 次开闸验收机会，按钮清晰。
```

### 抠出 UI 提示词

```text
去掉所有场景和建筑，只保留管网格子、底部三个管道块、目标状态、撤回按钮、提示按钮、替换管道按钮、开闸验收按钮，纯白色背景底图，方便抠图。
```

## 5. 视频脚本

### 视频 1 描述（医院缺水）

```text
参考微缩城市管网 UI，医院闪红等待供水。底部出现三个管道块，玩家拖动 L 形、直线和 T 形管道拼出从水塔到医院的路径。中途放错一块出现漏水预警，玩家撤回修正。玩家点击开闸验收，水流沿着管道冲到医院，医院红灯变绿。
```

### 视频 1 字幕

```text
0-2s：医院供水断了
2-5s：底部 3 块管道，拼出救援路线
5-8s：放错一块，开闸就会漏水
8-11s：想清楚后，点击开闸验收
11-15s：接通医院，城市抢修成功
```

### 视频 2 描述

```text
展示消防栓关卡。城市发生火灾，地图有两个出口，一个是喷泉，一个是消防栓。玩家必须用底部三块管道绕开障碍，接到消防栓，并通过加压泵让水流灭火。
```

### 视频 2 字幕

```text
0-2s：城市起火，水必须接到消防栓
2-5s：接错出口也算失败
5-8s：障碍挡路，只能绕行
8-11s：加压泵启动，水流冲过去
11-15s：灭火成功，这关你会怎么拼？
```

### 视频 3 描述

```text
展示漏水危机。玩家已经拼好大半路线，但中间有一节漏水管。水流即将启动，玩家通过救助按钮封住漏水，再放下最后一块弯管，成功接到学校。
```

### 视频 3 字幕

```text
0-2s：路线快接好了，但中间漏水
2-5s：直接开闸就会失败
5-8s：封住漏点，保住这局
8-11s：放下最后一块弯管
11-15s：是你自己把局面救回来
```
