# 城市水管抢修 概念卡

## 当前判断

三种玩法里选择第三种：

> **关卡制俄罗斯方块式管道拼接。**

它不做华容道，也不做普通旋转水管。核心差异是：底部给 3 个不同形状的管道块，玩家把它们拖进城市管网格子里。玩家可以不限时思考，直到自己点击“开闸验收”；如果当前管路断开、漏水、接错目标，或底部管道块已经无法继续放置，则关卡失败或进入救助。

## 1. 一句话玩法

玩家从底部 3 个管道块中拖拽拼接，在城市管网的 N×N 格子里连接入水口和医院、消防栓或学校出水口；玩家不限时思考并主动点击开闸验收，如果管路漏水、断路、接错目标或局面无解则失败，可通过广告替换管道、撤回数步或封住漏水点。

## 2. 3 秒可懂画面

- 第一眼看到：城市地图格子中左上角水塔断开，右下角医院闪红提示“等待供水”。
- 角色 / 物件怎么动：玩家从底部拖入 L 形、直线、T 形管道块，管道自动吸附到格子里，形成一条弯曲水路。
- 最后 1 秒的反转或爽点：水流冲出，沿着玩家拼好的管道一路点亮到医院，医院红灯变绿。

## 3. 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 从底部 3 个管道块中拖拽到 N×N 格子 / 旋转特殊块 / 点击撤回或提示 |
| 目标 | 用有限管道块把入水口接到指定目标设施，并点击开闸验收 |
| 限制 | 格子有限、底部 3 块必须处理、下一组三块不可预知、障碍格、部分管道不可旋转、开闸验收次数有限 |
| 失败条件 | 当前三块无合法摆放、系统判定目标已不可达、开闸后管道断路、漏水流到空格、接错出口 |
| 爽点 | 三块刚好放下、最后一格接通、整条管道亮起、水流冲到医院、城市危机解除 |
| 广告点 | 替换底部一个管道块 / 撤回 3 步 / 自动封住一处漏水 / 显示一格关键位置 / 增加 1 次开闸验收机会 |

### 与 Block Blast 的关系

| Block Blast | 城市水管抢修 |
| --- | --- |
| 目标是消行拿分 | 目标是接通水路救目标设施 |
| 无限局为主 | 关卡制谜题为主 |
| 方块只看占格 | 管道还看方向、连通和漏水 |
| 失败来自没地方放 | 失败来自无合法摆放、目标不可达、开闸验收失败 |

### 关卡变量

| 阶段 | 新鲜点 |
| --- | --- |
| 1-5 关 | 4×4 网格，只有直线、弯管，教学接通 |
| 6-10 关 | 加入障碍格和固定旧管，玩家需绕路 |
| 11-15 关 | 加入漏水管和封堵点，开闸验收时漏水会导致失败 |
| 16-20 关 | 加入单向阀、加压泵、不可旋转块 |
| 20 关后 | 双出口、优先级目标、限撤回次数、有限开闸验收次数、系统判定无解提示 |

## 4. 差异化拷问（立项铁律 3 条）

| 铁律     | 问题                                  | 回答                                                                                                                                                      | 通过  |
| ------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| 1. 差异化 | 和最火同类相比，核心 3 个不同点是什么？最接近的 3 款竞品分别是？ | 竞品参考：普通接水管、旋转水管、Block Blast。差异点：(1) 用 Block Blast 式三块输入做管道拼接，不是点格旋转；(2) 强目标救援，医院、消防栓、学校让接通有情绪目标；(3) 不用倒计时逼玩家，失败来自无合法摆放、目标不可达和开闸验收失败，更接近现代 puzzle 的局面压力。 | ☑   |
| 2. 美术  | 美术上是否有风格化、猎奇或反差？避免和大厂卷画质？           | 走“微缩城市抢修地图 + 红蓝危机 UI + 水流点亮”的清晰风格，不卷精美角色。核心视觉是红色危机城市被蓝色水流救活。                                                                                            | ☑   |
| 3. 速度  | 1 个月内能否做出 Demo 测试？                  | 可以做 10 关灰盒 Demo：4×4 到 6×6 网格、8 种管道块、3 种目标设施、基础水流模拟和广告救助点。完整上线可能需要 1-2 个月关卡打磨。                                                                           | ☑   |

**结论：** 可进入概念视频阶段，并有机会进入 IAA 灰盒验证。最大风险是关卡谜题是否能持续“刚刚好难”。

## 5. 关卡成长预期

长线靠**网格尺寸、障碍格、固定旧管、漏水、单向阀、加压泵、双目标、有限开闸次数、无解判定、每日挑战和星级评价**避免重复。它的核心不是题材，而是关卡阶梯和谜题量产能力。
