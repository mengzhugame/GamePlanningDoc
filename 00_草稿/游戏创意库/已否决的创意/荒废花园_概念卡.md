# 荒废花园概念卡

## 一句话玩法

玩家在一座荒废花园里清理地块、播种、浇水、除草、等待花开、收获并售卖花束；赚到的钱用于解锁新地块、升级工具、雇佣园丁或小动物照料花圃，并把枯萎花园逐步复苏和装扮成自己的治愈花园。

## 核心定位（2026-05-20 调整）

> **慢节奏种花收集 + 轻自动化扩园**。

《我的花园世界》作为主体验参考：种植、等待、收获、插花、售卖、装扮和长期收集是玩家的主要情绪来源。

《My Mini Mart》/《伐木高高手》只借用“从手动照料到逐步省心”的成长效率感，不把游戏做成高速鲜花工厂，也不把小动物和园丁做成搬货员工。

## 玩法核心循环

```text
清理荒废地块
→ 播种
→ 浇水 / 除草 / 等待
→ 收获花朵
→ 插花 / 售卖订单
→ 获得金币、种子或装扮材料
→ 解锁地块 / 升级工具 / 装扮花园
→ 雇佣园丁或小动物减少重复照料
→ 花园逐步复苏
```

核心体验不是“产线扩张”，而是“每天亲手照料一点点，荒废花园一点点变好”。自动化只负责降低重复操作，让玩家感到花园越来越有生命，而不是把花变成流水线商品。

## 玩法破局点：带复苏目标的种花经营

荒废花园的“复苏”不直接替代核心玩法，它是目标层、反馈层和情绪包装。真正的内在玩法仍然是种花经营。

> **不做“复苏玩法”，做“带复苏目标的种花经营”。**

核心微创新：花朵不是单纯商品，而是同时具备两种用途。

| 花朵用途 | 作用 | 玩家感受 |
| --- | --- | --- |
| 售卖给顾客 | 获得金币，用于升级工具、解锁设备、雇佣园丁/小动物 | 经营收益和扩张感 |
| 投入荒废地块复苏 | 推进枯井、破花亭、杂草小路、干枯花圃等区域恢复 | 花园被自己一点点救回来的情绪反馈 |

这样玩家会面对一个轻决策：

> 这批花是先卖掉赚钱升级水壶，还是先拿去复苏枯井？

这个决策比普通“种菜 → 收菜 → 卖钱”多了一层长期目标，但不把玩法扭复杂。

## 复苏地块任务

每个荒废区域都应该有清晰、低理解成本的小目标，且复苏后带来新收益。

| 荒废区域 | 复苏需求示例 | 复苏后收益 |
| --- | --- | --- |
| 枯井区 | 提交 3 朵蓝花 + 2 朵白花 | 解锁更高效浇水/自动补水能力 |
| 破花亭 | 提交 1 束玫瑰花束 | 解锁花束展示和装扮位 |
| 杂草小路 | 完成 5 单普通花订单筹钱清理 | 解锁新花圃连接路线 |
| 干枯花圃 | 连续浇水 3 次并提交基础花种 | 恢复为可种植地块 |

复苏不应该只是“点按钮修复”。玩家必须通过种花、照料、收获、售卖或提交花材完成复苏，让玩家理解：花园变好是我经营出来的。

## 订单结构

| 订单类型 | 作用 | 设计边界 |
| --- | --- | --- |
| 普通顾客订单 | 卖花赚钱，提供短期目标和金币来源 | 不要太密集，避免把慢节奏变成高压时间管理 |
| 复苏订单/花园愿望 | 把花交给荒废区域，推进地块恢复 | 必须可视化为“灰地变绿、建筑修复、花区解锁” |

普通订单负责经营收益，复苏订单负责长期情绪目标。两者共同构成“种花经营 + 花园复苏”的主循环。

## 3 秒可懂画面

- 第一眼看到：灰色、枯萎、杂草蔓延的花园。
- 玩家操作：角色清理小地块、播种、浇水、除草、等待花开、收割花朵、制作花束。
- 爽点/反转：卖出第一束花后，灰色土地变绿，新花圃解锁，小动物或园丁开始帮忙照料，花园从荒废状态逐步变美。

## 核心规则

| 字段 | 内容 |

| 玩家输入 | 点击移动、播种、浇水、除草、收获、拖拽花朵到花束/订单、购买地块和装扮升级 |

| 爽点 | 第一朵花开、花朵成熟收获、花束完成、灰地变绿、花圃扩建、园丁/小动物帮忙照料后变省心 |
| 广告点 | 订单差 1 朵花、花朵马上成熟但缺少浇水次数、差一点金币解锁新花圃/自动洒水器/小动物助手 |

## 已形成的候选差异点（2026-05-20 调整）

| 方向 | 价值 | 风险 |
| --- | --- | --- |
| 荒废花园复苏主线 | 不是完整花园里种花，而是从灰色荒地一格格恢复成可装扮花园，前后变化适合短视频表达 | 需要避免只停留在美术反差，必须让玩家理解复苏来自种花经营循环 |
| 慢节奏种花收集 | 更贴合女性向、治愈、植物玩家：等待、照料、收获、插花、收集花种 | 会直接对标《我的花园世界》/《QQ农场》，不能拼花种数量和社交运营 |
| 轻自动化照料 | 园丁、小动物、自动洒水器帮助浇水、除草、提醒成熟、少量采花，让后期更省心 | 自动化过重会滑向鲜花工厂，削弱治愈感 |
| 花束订单 + 装扮回流 | 售卖不是纯刷钱，而是把资源回流到地块复苏、花园装扮和主题花区解锁 | 订单如果太密集，会把慢节奏变成时间管理压力 |
| 花朵双用途 | 花既能卖钱，也能用于复苏荒废区域，形成“赚钱还是修花园”的轻决策 | 如果数值设计太抠，会让玩家觉得被卡资源 |

| 竞品/类型 | 玩家主要体验 | 荒废花园要拉开的点 |

| Gardenscapes / 合成花园 / 剧情装修类 | 通过三消、合成或剧情资源推动花园装修 | 不用外围玩法驱动修复，核心操作直接是种花、照料、收获、售卖和复苏 |

## 四方反对理由与破局解法

| 视角 | 最强反对理由 | 破局解法 |
| --- | --- | --- |
| 严厉投资人 | 内容型休闲经营美术量大、长线内容消耗快，差异化容易被复制 | 第一版不拼数百花种，只做少量花种 + 复苏区域模板，验证“复苏目标层”是否提升留存和回访 |
| 严厉发行商 | 素材可能能点，但游戏可能留不住；玩家为什么不直接玩《我的花园世界》 | 概念视频必须展示选择和循环：花是卖钱还是复苏地块，而不只拍“荒地变绿” |
| 竞品团队 | 荒废地块、小动物、自动洒水器都能被更大团队快速抄走 | 不赌单点护城河，建立低成本内容模板：荒废状态 → 需要的花 → 复苏动画 → 新功能 |
| 陌生玩家 | 看起来好看，但种花、浇水、收花、卖花我玩过很多 | 第一屏强调“不是现成花园种花，而是只剩一块活地的荒废花园”；第一分钟完成一次种花、售卖、复苏反馈 |

## 最小可测版本

第一轮不要做完整游戏，只测一个 5 分钟小循环：

```text
开局：1 块可种地 + 4 块荒废地
种白花 → 浇水 → 等待 30 秒 → 收获
选择 A：卖给顾客得金币
选择 B：交给枯地复苏 1 格
卖 2 单后升级水壶
复苏 3 格后解锁小蜜蜂
小蜜蜂让下一轮花多产 1 朵
```

要验证的核心问题：

> 玩家是否觉得“种花是为了复苏花园”，比普通种花收菜更有动力？

可观察信号：

- 评论“我想把整片花园修好”。
- 追问“后面还有哪些区域可以复苏？”
- 能复述“种花卖钱 / 交花复苏 / 解锁新地块”。
- 对小动物照料感兴趣，而不是只说画风好看。
- 主动问“什么时候能玩 / 能不能测试”。

## 自动化边界

- 园丁：帮忙浇水、除草、提醒成熟，不做高速搬运工。
- 小动物：小蜜蜂授粉、小猫提醒成熟、小兔少量采花，强调陪伴感。
- 设备：自动洒水器、温室、花架、堆肥箱，强调照料便利。
- 订单：顾客愿望单、花束委托、节日订单，服务于花园复苏和装扮回流。
- 扩建：不是单纯开更多格子，而是把荒废区域复苏成不同主题花区。

## 暂不做的事

- 不押美术合伙人。
- 不进入正式立项。
- 不做完整模拟经营系统。
- 不做高速鲜花流水线，不把小动物和园丁做成《My Mini Mart》式员工。
- 不拼《我的花园世界》的数百花种、强社交和长期运营内容量。
- 不继续堆“花园世界已有”的功能，除非视频数据先证明玩家想玩该具体体验。
