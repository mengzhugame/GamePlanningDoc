# 证据时间线排序 概念卡

## 当前判断

这个方向可以作为《怪案侦探社》的核心玩法变体，也可以单独做成短局 IAA 解谜小游戏。它比单纯寻物更有“推理”味道，但内容量风险更高。

第一版不做记忆翻牌，不做多人剧本杀，不做复杂文本推理。先验证：

> 玩家能不能通过 3-8 张证据卡的顺序，还原一场案件，并在最后看到真相验证自己的判断。

## 1. 一句话玩法

玩家把 3-8 张证据卡拖入正确时间线，还原凶手从动机、接近、作案、伪装逃离到露出破绽的完整过程；玩家可以不限时思考，但每次提交错误都会增加疑点槽，疑点槽满则案件陷入僵局，可通过广告获得线索、排除干扰卡或保留正确位置。

## 2. 3 秒可懂画面

- 第一眼看到：手机中间有一排空时间线槽位，底部散落“红酒杯、怀表、窗台脚印、未婚妻证词、倒下的椅子”等证据卡。
- 角色 / 物件怎么动：玩家拖动卡片排序，错误相邻关系会闪红，正确顺序会亮起红线连接。
- 最后 1 秒的反转或爽点：时间线全部点亮，播放案发真相演出：未婚妻下药、撞倒椅子、掉落怀表、从窗户逃离。

## 3. 核心规则

| 字段 | 内容 |
| --- | --- |
| 玩家输入 | 拖拽证据卡到时间线槽位 / 拖拽干扰卡到无关线索区 / 点击提示 |
| 目标 | 排列出正确犯罪时间线，还原案件真相 |
| 限制 | 卡片数量增加、干扰卡、无关线索区容量、部分卡片描述模糊、错误提交次数有限 |
| 失败条件 | 提交顺序错误会填充疑点槽；疑点槽满、关键卡连续放错或无关线索区判断错误过多则失败 |
| 爽点 | “我猜对了”的真相验证、红线逐段点亮、最后一张卡放对、案发动画还原 |
| 广告点 | 清空 1 格疑点槽 / 揭示第一张或最后一张 / 锁定一对相邻卡 / 排除 1 张干扰卡 / 失败后保留正确位置 |

### 屏幕布局

| 区域 | 内容 |
| --- | --- |
| 顶部 | 案件名、疑点槽、星级目标、提示按钮 |
| 中间 | 时间线槽位，3-8 个空格，玩家把关键证据卡拖入这里 |
| 底部 | 证据池，包含关键卡和后期出现的干扰卡 |
| 右侧或底部角落 | 无关线索区，第 10 关后出现，用来放干扰卡 |

### 案件模板

每关剧情不同，但底层结构复用 5 类卡：

| 模板卡 | 作用 | 样例 |
| --- | --- | --- |
| 动机 | 为什么会作案 | 未婚妻发现遗嘱被改 |
| 接近 | 凶手如何接近目标 | 她端来红酒 |
| 作案 | 凶手怎样下手 | 红酒杯中被下药 |
| 伪装 / 逃离 | 凶手如何制造假象或离开 | 她撞倒椅子后从窗户逃走 |
| 破绽 | 哪个细节暴露真相 | 怀表掉在椅子旁，杯沿有口红印 |

其它证据卡用于：

- 早期：全是关键卡，只需要排序。
- 中期：加入 1-2 张无关线索，玩家需要拖到无关线索区。
- 后期：加入相似卡和矛盾证词，例如“管家脚印”和“窗台泥脚印”。

### 真相奖励规则

真相动画 / 真相文字必须免费播放，不能用广告锁住。  
广告只能减少挫败，不能拿走破案爽感。

## 4. 差异化拷问（立项铁律 3 条）

| 铁律 | 问题 | 回答 | 通过 |
| --- | --- | --- | --- |
| 1. 差异化 | 和最火同类相比，核心 3 个不同点是什么？最接近的 3 款竞品分别是？ | 竞品参考：《FRAMED》《Storyteller》以及短视频平台常见卡片排序逃脱小游戏。差异点：(1) 不是单纯排序剧情，而是用证据还原犯罪时间线；(2) 每关有“真相验证”奖励，强化我猜对了的爽感；(3) 后期加入干扰卡和无关线索区，既考推理也考排除。 | ☑ |
| 2. 美术 | 美术上是否有风格化、猎奇或反差？避免和大厂卷画质？ | 走“复古侦探漫画 + 犯罪剪影 + 红线证据板”路线。卡片可用剪影、道具特写、短句证词降低美术量。 | ☑ |
| 3. 速度 | 1 个月内能否做出 Demo 测试？ | 可以。Week 1 做拖卡排序、提交判定和疑点槽；Week 2 做 5 关案件模板；Week 3 加干扰卡、提示广告点和真相演出；Week 4 发布微信小游戏或 TapTap/网页试玩收反馈。 | ☑ |

**结论：** 3 条全过，可进入概念视频阶段。它有机会成为 IAA 小游戏，也可以作为《怪案侦探社》的核心玩法模块。

## 5. 关卡成长预期

长线靠**案件模板、卡片数量、干扰卡、无关线索区、局部隐藏信息、错误提交压力、章节案件和侦探社轻 Meta**避免重复。真正风险是内容量和谜题质量，需要先做 5 关纸面谜题验证。
