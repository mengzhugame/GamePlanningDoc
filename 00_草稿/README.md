# 00_草稿

## 这是什么

这里是还没有变成正式项目或长期知识的创意与灵感区，负责接住“可能有价值，但还没验证”的东西。

## 子目录

| 路径 | 用途 |
|------|------|
| `游戏创意库/` | 游戏创意、题材、玩法组合、待审核表、已通过表、概念视频数据记录 |

## 使用规则

- 新创意先进入 `游戏创意库/`，不要直接放入项目区。
- 概念验证资料也统一放在 `游戏创意库/`，使用 `创意名_概念卡.md` 和 `创意名_概念视频数据记录.md`。
- 只有完成概念验证并获得明确市场信号后，才升级到 `20_项目/`。
- 验证失败的创意也要保留，记录失败原因，避免未来重复踩坑。
- 旧格式创意资料已经转写到 `游戏创意库/99_原始资料转写/`，后续只保留 Markdown。
