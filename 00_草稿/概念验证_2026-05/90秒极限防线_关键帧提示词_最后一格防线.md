# 视频4 最后一格防线 · 关键帧提示词

## 上游引用

- 母本分镜：[[90秒极限防线_视频验证#视频 1：最后一格防线]]
- 全局编号：视频4（《休闲小游戏立项流程》塔防赛道首条）
- 标题钩子：基地只剩 1 点血，还能守住吗？
- 总时长：12 秒（4 段 × 3 秒）

## 工具链

| 环节 | 工具 | 产出 |
|------|------|------|
| 关键帧生图 | ChatGPT Image 2 / 即梦 AI | 4 张静帧（首帧定调）|
| 图生视频 | Seedance 2.0 | 3 段 3 秒视频（帧1→帧2，帧2→帧3，帧3→帧4）|
| 后期合成 | 剪映 | 拼接 + UI 文字 + 血条 + 金币数字 + 字幕 |

> 制作纪律：不要一次性生 12 秒长视频，必须按段拆分。所有 UI 文字、数字、技能按钮都在剪映后期叠加，关键帧本体不画文字。

## 通用风格 prefix（每张关键帧前面都拼这段）

```
风格：竖屏 9:16 比例，2.5D 等距俯视镜头，明亮卡通休闲手游风格，
画面像微信小游戏里真实玩法的截图，不是宣传海报，不是电影感画面。
色调：明亮饱和、整体偏清爽童趣，但中央核心和激光塔有蓝紫科幻光感，整体黄昏暖光打底。
场景：俯视角下的方格化战场，三条蜿蜒路径从画面左上、正上、右上汇聚到屏幕中央偏上的核心防御塔，
路径用浅色石板砖铺设，路径之间是绿色草坪空格，可放置防御塔的位置标注为发亮高光圆圈。
画面构图：场景占画面上方约 70%，下方约 30% 留出干净草坪/低饱和过渡区（不要画任何 UI 元素）。
画风：圆润卡通造型、低饱和描边、柔和阴影，参考《植物大战僵尸2》《王国保卫战》的休闲塔防视觉。
固定镜头：所有 4 张关键帧使用同一个场景布局、同一个相机角度、同一套美术资产、同一个核心位置和路径走向。
```

## 通用负向提示词（每张关键帧都加）

```
不要：写实风格、电影镜头感、第一人称、过肩镜头、镜头推拉摇移、画面晃动；
不要：真实人物、真实文字、中文字符、英文字母、数字、UI 文字、按钮文字、水印、Logo；
不要：变形、扭曲、模糊、抽象、印象派、二次元日漫、像素风、3D 写实建模；
不要：血腥、恐怖、暴力、政治、宗教元素；
不要：场景布局变化、相机角度变化、画风切换、渲染风格切换、色温大幅跳变。
```

## 关键帧 1 — 1血基地

- **剧情位置**：第 0-2 秒首帧，画面定调
- **对应原分镜**：三条路径怪物冲向核心，核心 HP 显示 1/10
- **画面任务**：让观众 1 秒内看懂"基地快没了 + 怪物三路逼近"

**生图提示词**（拼在通用风格 prefix 之后）：

```
画面元素：
- 中央核心防御塔：圆润的水晶能量塔，塔身淡蓝水晶柱、底座银色金属，
  塔顶悬浮一颗发出微弱红光的能量晶核，暗示血量极低、即将熄灭，
  塔身周围有微弱裂纹和红色警戒光晕，光晕呈脉动状（用静帧的辐散光圈表现）。
- 三条进攻路径上的怪物：
  - 左路：3-4 只蓝色快速小怪，体型瘦小、修长腿、姿态前倾正在奔跑；
  - 中路：2 只紫色厚血怪，体型壮实、有甲壳、迈步沉重；
  - 右路：2 只绿色飞行怪，小型翼龙造型，低空滑翔，地面有阴影投射；
- 关键张力点：中路最近的一只厚血怪距离核心仅 1 格，即将撞击核心，
  整张图的视觉重心落在这只怪与核心之间的对峙。
- 路径上的塔位：所有防御格目前空空如也，仅在拐角处 4-5 个发亮的可放置高光圆圈，
  其中中路与左路交汇前的那个拐角格高光最强（暗示是关键放置点）。
- 整体光线偏黄昏暖色，但核心周围红色警戒光晕明显，营造"濒临崩溃"的紧迫感。
- 画面下方约 30% 是干净的浅绿草坪与轻微暗角过渡，完全不画 UI 元素。
```

## 关键帧 2 — 三张卡

- **剧情位置**：第 2-5 秒首帧
- **对应原分镜**：波次暂停，屏幕下方出现 3 张卡：激光塔、减速塔、弹射炮
- **画面任务**：让观众 1 秒内看懂"游戏暂停了，玩家要在 3 张卡里选 1 张"

**生图提示词**：

```
画面元素：
- 场景与关键帧 1 完全一致（同样的核心位置、三条路径走向、怪物种类与位置），但所有怪物呈"暂停凝固"状态：
  怪物身体覆盖一层淡淡的蓝白色冰晶光圈表示时间静止，姿态停留在跑步动作中段。
- 中央核心仍显示低血量红色脉动光晕，但脉动节奏明显减缓。
- 整个场景上方罩一层非常淡的蓝紫色"暂停"色调滤镜（轻微，不能掩盖主体颜色）。
- 画面下方 30% 区域：并排 3 张悬浮卡牌，对称居中、卡牌之间留约半张卡的间距，
  卡牌底部有柔和投影，营造"悬浮在屏幕底部 UI 层之上"的感觉：
  - 左卡：激光塔 —— 卡面是一座发蓝光的水晶塔，塔顶有红色激光发射镜头，卡牌底色科技蓝渐变；
  - 中卡：减速塔 —— 卡面是一座青色冰晶塔，塔体半透明像冰雕，周围漂浮冰晶颗粒，卡牌底色冰青；
  - 右卡：弹射炮 —— 卡面是一座金属机械塔，带反光弹射轨道和黄色子弹，卡牌底色橙金；
- 三张卡造型一致、尺寸相同、外框为浅金色描边，左卡（激光塔）外框略有更亮高光，
  暗示"被聚焦"，但所有卡牌都保持完整轮廓；
- 卡牌内部仅有插画，不写任何文字、数字、技能名称、属性图标、稀有度星标；
- 卡牌区域整体高度约占屏幕高度 18%，顶端略低于场景底部约 2%，留出过渡空间；
- 整体氛围：紧张但暂停，玩家正在思考"该选哪张"。
```

## 关键帧 3 — 激光塔放置

- **剧情位置**：第 5-9 秒中段
- **对应原分镜**：玩家拖激光塔到拐角空位，激光塔已落地、正在充能；最后一只怪即将撞上核心
- **画面任务**：让观众感受"决策已下、紧张感拉满，等下一秒发射"

**生图提示词**：

```
画面元素：
- 场景仍是同一塔防战场，核心、三条路径、美术风格完全一致，但波次已恢复进行：
  - 中路那只最近的厚血怪已推进到核心前 1 格（比关键帧 1 更近半格），即将撞击；
  - 左路、右路怪物整体也往前推进了约半格距离，营造"波次正在进行"的动态感；
  - 怪物身上的暂停冰晶光圈完全消失，回到正常奔跑姿态。
- 拐角空位（中路与左路交汇前的拐角格）矗立着一座新放下的激光塔：
  - 激光塔造型：高约 1.2 倍格子宽度，水晶蓝塔身、银色金属支架、
    塔顶有红色激光发射镜头朝向中路方向；
  - 激光塔脚下有刚刚落地的能量光波纹（一圈扩散的青色光环），表示刚被放置；
  - 塔顶红色镜头正在充能：从镜头位置向外辐射红色能量粒子，
    红色光圈逐渐变亮、能量在汇聚，但尚未发射；
  - 塔顶上方有 3-4 个上升的能量光点，暗示充能进度；
- 暂停滤镜完全消失，画面色调恢复关键帧 1 的正常黄昏暖色 + 红色警戒；
- 卡牌区域：激光塔卡已消失（被拖走），剩余 2 张卡（减速塔、弹射炮）轻微下移、轻微淡化（约 70% 不透明度），但仍可见；
- 视觉张力点：充能中的激光塔与逼近的厚血怪形成正面对峙，
  整张图的视线从激光塔顶射向那只即将撞击核心的怪物；
- 画面有写意尘土特效表示怪物奔跑（不要写实粒子）。
```

## 关键帧 4 — 激光清场

- **剧情位置**：第 9-12 秒尾帧（高潮）
- **对应原分镜**：激光贯穿整条路，怪物清空，金币飞入 UI，显示"极限防守成功"
- **画面任务**：让观众 0.5 秒内感受到"反杀爽点"，光感拉到最强烈
- **注意**："极限防守成功"文字后期叠加，关键帧不画

**生图提示词**：

```
画面元素：
- 场景仍是同一塔防战场，核心仍然存在并且完整无损，
  核心周围的红色警戒光晕已转为淡金色稳定光晕，表示守住了；
- 激光塔正在发射：塔顶射出一道粗壮的红色激光束，
  激光束水平横扫整条中路并延伸到左路尽头，
  激光宽度约 0.4 格，主体红色、边缘蓝白色高光、中段有粒子辐散；
- 激光路径上的怪物状态：
  - 中路：3 只怪物正在被激光命中，1 只爆裂成金色光粒子、1 只剩半透明残影、1 只刚开始崩解；
  - 左路：2 只蓝色快怪也被激光余波波及，化为金色光粒子；
  - 右路：飞行怪部分被波及，只剩 1 只在屏幕上半截外缓慢滑出（暗示"清空"但保留余味）；
- 屏幕中布满金色光粒子上升轨迹，以及大量金币从怪物消散位置飞出：
  - 金币：扁圆形金币，正面有四瓣花纹和高光，金币尺寸有大有小；
  - 金币数量：8-12 枚，沿抛物线轨迹从战场各处飞向屏幕右上角（预留的金币 UI 位置），
    金币有拖尾光轨迹，但不写数字；
- 在核心上空，有一道明显的"成功"金色光环正在爆开（从无到大到淡出的中段瞬间），
  光环呈纯光效圆环 + 放射光线，但绝对不画任何文字；
- 卡牌区域：剩余的 2 张卡此时已大幅淡化（约 30% 不透明度），几乎隐去，
  为后期叠加"极限防守成功"字幕留出干净空间；
- 整体氛围：从紧张迅速翻转到爆爽，色调金黄 + 红激光强烈对比，是 4 帧中光感最强烈的一帧。
```

## Seedance 2.0 图生视频运镜词（每段 3 秒）

每段使用上一帧作为首帧、下一帧作为尾帧（首帧/尾帧图生视频模式）。

### 段 1（关键帧 1 → 关键帧 2）

```
镜头：完全固定俯视，无任何相机移动、无推拉、无晃动。
动作（按时间序）：
- 0.0-1.0s：怪物沿三条路径继续向中央核心缓慢逼近，每秒约 0.3 格的位移；
- 1.0-1.4s：所有怪物身上自下而上漫起一层淡蓝白色冰晶光膜，动作逐步冻结，最终所有怪物完全静止；
- 1.4-2.0s：屏幕下方从底部缓慢上升 3 张卡牌（约 0.6 秒上升 + 轻微弹簧落定），
  3 张卡同步上升、对称排列；
- 2.0-3.0s：卡牌完全落定后保持悬浮，激光塔卡（左卡）外框出现轻微高光呼吸；
- 全程核心顶部红色脉动节奏减缓，呼应"暂停"时间感。
不要：相机推拉、画面晃动、画风切换、生成任何文字、改变怪物种类或位置。
```

### 段 2（关键帧 2 → 关键帧 3）

```
镜头：完全固定俯视，无任何相机移动。
动作（按时间序）：
- 0.0-1.2s：一团柔光高亮圆点（代表玩家手指）从左卡（激光塔）位置出发，
  沿对角线平移到中路与左路交汇前的拐角空位，移动过程带轻微残影轨迹；
- 1.2-1.5s：拐角空位浮现激光塔半透明预览，圆点松开瞬间激光塔实体落定，
  脚下产生一圈青色能量光波纹扩散（约 0.3 秒）；
- 1.5-1.9s：所有怪物身上的蓝色暂停光膜淡出消失，怪物恢复奔跑动作并继续向核心推进;
- 1.9-3.0s：激光塔顶部红色发射镜头开始充能，从暗到亮逐步加深，
  塔顶冒出 3-4 个上升能量光点（不发射、只蓄能）；
- 全程卡牌区：激光塔卡消失，剩余 2 张卡轻微下移并降至约 70% 不透明度。
不要：相机移动、改变核心位置、改变路径走向、改变光影色温、生成文字数字。
```

### 段 3（关键帧 3 → 关键帧 4）

```
镜头：完全固定俯视，无任何相机移动。
动作（按时间序）：
- 0.0-0.4s：怪物继续推进，中路最近的厚血怪逼近到核心前约 0.5 格，
  紧张感拉到最高；
- 0.4-0.55s：激光塔红色镜头充能完成，触发发射 ——
  一道粗壮红色激光从塔顶水平射出，0.15 秒内瞬间贯穿整条中路并延伸至左路；
- 0.55-1.0s：激光接触怪物逐只爆裂为金色光粒子（爆裂间隔约 0.05 秒），
  右路飞行怪部分被余波波及；
- 1.0-1.6s：激光逐渐淡出（持续约 0.6 秒余辉）；
- 1.6-2.4s：金币从怪物消散位置批量飞出（8-12 枚），沿抛物线轨迹向屏幕右上角飞行，
  金币带拖尾光轨迹；
- 2.4-2.7s：核心上空爆开一圈金色光环（从无到大到淡出，约 0.3 秒）；
- 2.7-3.0s：核心顶部红色脉动转为淡金色稳定光晕，剩余 2 张卡牌进一步淡化至几乎透明。
不要：相机推拉、镜头闪烁、画风切换、生成任何文字数字字幕、改变怪物路径。
```

## 后期 UI 叠加清单（剪映环节）

下表列出后期需要在剪映里手动叠加的元素，对应原分镜的 UI 信息。
关键帧本身不画这些，避免 AI 生成乱码字符。

| 时间 | 叠加元素 | 位置 |
|------|---------|------|
| 0-2s | 核心 HP "1/10" 红色数字 + 红色血条 | 核心正下方 |
| 0-2s | 顶部"波次 3/5"或"危机！" | 屏幕顶部居中（可选）|
| 2-5s | 3 张卡牌名称：激光塔 / 减速塔 / 弹射炮 | 各卡正下方 |
| 2-5s | 卡牌冷却 / 费用数字 | 各卡右上角（可选）|
| 5-9s | 倒计时数字 "3 2 1" | 屏幕顶部居中（可选）|
| 9-12s | 字幕"极限防守成功"金色大字 | 屏幕中央偏上 |
| 9-12s | 金币累计数字（如 "+128"）| 屏幕右上角 |

## 验证清单（产出前自检）

- [ ] 4 张关键帧都使用同一个场景布局（核心位置、三条路径走向、画风一致）
- [ ] 4 张关键帧都不出现文字、数字、字母、UI 控件
- [ ] 关键帧 1 → 2 → 3 → 4 视觉信息可以"无字幕看懂"剧情推进
- [ ] 关键帧 4 的视觉爽感强度 > 关键帧 1 的紧迫感强度（情绪曲线对得上"反杀")
- [ ] 段 1/2/3 运镜词中相机始终固定，无推拉摇移
- [ ] 后期 UI 叠加预留位置（核心下方、屏幕底部卡牌区、屏幕右上角）在关键帧中是空白
