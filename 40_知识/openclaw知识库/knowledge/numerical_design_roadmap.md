# 小龙儿的游戏数值专家进阶路线图 (Game Numerical Design Roadmap)

## 0. 基础入门篇 (Beginner) —— 建立数值直觉
**目标：掌握基础的游戏数值概念，能独立完成简单RPG/塔防的基础战斗公式推演。**
1. **必读数目/资料：**
   - 《游戏数值百宝书：成为优秀的数值策划》 (重点阅读前6章的战斗与经济步骤)
   - 《游戏设计艺术》(The Art of Game Design) 第11章 (关于平衡与数学)
2. **核心知识点：**
   - 战斗属性抽象 (HP, MP, ATK, DEF, SPD, CRI)
   - 基础伤害公式：减法公式 (DMG = ATK - DEF) vs 乘法/除法公式 (DMG = ATK * (1 - DEF/(DEF+C)))
   - TTK (Time to Kill) 的概念与应用
3. **实操任务：**
   - 用 Excel 搭建一个极简的回合制战斗模拟器，计算玩家打死1只怪需要的平A次数。

## 1. 进阶推演篇 (Intermediate) —— 战斗与成长曲线
**目标：能够用数学工具规划完整的玩家成长曲线，并平衡局内战斗节奏。**
1. **核心知识点：**
   - **VBA 与 Excel 进阶**：掌握 VLOOKUP, INDEX, MATCH 甚至宏（Macro）进行批量模拟。
   - **成长曲线建模**：经验值升级曲线（指数型、多项式型、对数型）。
   - **战力评估模型 (Combat Power)**：如何给不同属性（攻击、暴击、攻速）打分，最终换算成一个“综合战力评分”供匹配使用。
   - **阈值效应 (Breakpoint)**：精确计算在第几波时，玩家的攻击力能恰好做到“一击秒杀”杂兵，以制造割草爽感。
2. **实操任务：**
   - 继续优化《光与朽》的 V2.1 大招与波次成长曲线，输出每个波次的精确防线压力（总血池）与玩家期望DPS图表。

## 2. 资深经济篇 (Senior) —— 经济系统与概率博弈
**目标：构建复杂的局外养成、资源循环池，精通扭蛋/抽卡概率。**
1. **核心知识点：**
   - **水池模型 (Faucet & Sink)**：资源产出上限控制与通货膨胀抑制机制。
   - **等价交换物与时间标价**：1元人民币 = 多少钻石 = 多少金币 = 多少体力 = 多少挂机时间。
   - **概率学实战**：PRD (Pseudo-Random Distribution) 伪随机算法（如《Dota2》防非酋机制），保底机制（Pity System）的期望值计算。
   - **抽卡/掉落设计**：设计包含白、蓝、紫、金装备的掉落权重池，并计算玩家刷满一套金装所需的平均时长。
2. **实操任务：**
   - 为《光与朽》设计一套完整的“碎片-合成”科技树经济系统，确保玩家需要刚好30小时的自然时长才能全毕业。

## 3. 专家商业化篇 (Expert) —— IAA与混合变现收割机
**目标：将数值与心理学、商业化深度绑定，设计极致的赚钱系统。**
1. **必读数目/资料：**
   - 《游戏机制——高级游戏设计技术》(Game Mechanics: Advanced Game Design)
2. **核心知识点：**
   - **LTV 与 ROI 模型**：如何通过前3天的留存数据与ARPU推算玩家的生命周期价值。
   - **付费破冰与痛点前置**：如何利用数值卡点（Difficulty Spike）在玩家沉没成本最高时，推出“6元首充”或“关键广告复活点”。
   - **动态难度调节 (DDA)**：当检测到玩家即将流失时，后台暗中削弱怪物血量；当玩家太顺时，增加特殊词缀怪。
3. **实操任务：**
   - 彻底跑通《光与朽》的 IAA 点位体系，通过调整局内“差一点”暴毙的血量线，将广告转化率拉升50%。

### 学习进度更新｜2026-04-18
- 已完成进阶学习：**水池模型（Faucet & Sink）与局外资源闭环**
- 关键结论：经济平衡不是看“给了多少”，而是看 `净流量 = 产出(Faucet) - 消耗(Sink)` 是否长期可控；必须按分钟 / 局 / 日三层统计资源净增，并把升级、抽卡、合成、刷新、复活全部当作真实排水口统一核算。
- 对《光与朽》的直接要求：先定义主软货币、碎片、广告补偿三条流，再给每个资源建立 `库存上限 / 日净增目标 / 关键消耗点 / 反通胀阈值`，保证玩家30小时自然毕业目标可被验证，而不是拍脑袋。

### 学习进度更新｜2026-04-18（第2轮）
- 已完成进阶学习：**等价交换物与时间标价（1钻=多少金币=多少体力=多少分钟）**
- 关键结论：所有资源都必须先统一折算到同一把尺子上，优先用“时间价值”做底，再让钻石充当锚点；真正该算的是 `Value(resource) = 该资源节省的有效游戏时间 × 每分钟目标产出价值`，而不是拍脑袋定礼包价格。
- 对《光与朽》的直接要求：先定 `1分钟有效推进值`，再反推 `体力、金币、碎片、广告补偿、钻石` 的汇率；只要某个购买项能绕过正常时间链路太多，就会打穿经济，必须加倍率衰减、每日上限或用途隔离。
- 下一候选专题：**概率学实战：保底机制（Pity System）的期望值计算**

### 学习进度更新｜2026-04-19
- 已完成进阶学习：**概率学实战：保底机制（Pity System）的期望值计算**
- 关键结论：保底设计不能只看基础概率，必须同时核算 `E[X]`（平均出货次数）与 `Q90 / Q95`（多数玩家的实际出货区间）；真正影响玩家体感的不是均值，而是长尾黑脸是否被压住。
- 对《光与朽》的直接要求：核心 Build 组件、金装、稀有碎片掉落应优先采用“基础概率 + 软保底抬升 + 最终强保”的三段式结构，并把广告补偿、商店兑换、碎片合成统一折算成“保底进度价值”，保证中盘构筑不会因非酋长尾直接坐牢。
- 下一候选专题：**抽卡 / 掉落权重池设计（白、蓝、紫、金）与全毕业平均时长建模**


### 学习进度更新｜2026-04-29
- 已完成进阶学习：**概率学实战：PRD 伪随机分布（Pseudo-Random Distribution）**
- 关键结论：PRD 的价值不是“让玩家更欧”，而是**在不改长期均值的前提下压缩方差与黑脸长尾**；实现时必须用 `p_n = min(1, Cn)`，并通过 `1 / E[N] = p_target` 反解 `C`，绝不能偷懒写成 `C = p`。
- 对《光与朽》的直接要求：优先把**暴击、核心模块类别掉落、濒死救场/广告补命**改为 PRD 驱动，先稳住中盘成型和 Boss 压线体感，再决定哪些终局稀有物继续保留真随机锋利感。
- 下一候选专题：**LTV 与 ROI 模型：用前3日留存与ARPU反推《光与朽》生命周期价值**
