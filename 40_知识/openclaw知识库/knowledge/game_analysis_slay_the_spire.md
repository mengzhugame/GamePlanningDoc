# 热门游戏拆解：《杀戮尖塔》(Slay the Spire)

## 1. 核心定位
* **类型**: Roguelike Deckbuilding Game (DBG, 卡牌构筑游戏)
* **核心循环**: 选路 (地图) -> 战斗/事件 -> 获得奖励 (卡牌/遗物/药水) -> 卡组构筑与优化 -> 挑战Boss。

## 2. 核心系统拆解

### 2.1 卡牌系统 (Card Design)
* **卡牌分类**: 攻击(红)、技能(蓝)、能力(发光，全局生效)、状态/诅咒(污染牌库)。
* **能量限制**: 典型的“费用”机制，强迫玩家在有限资源内做出最优解。
* **卡牌精简**: DBG的核心不在于“多”，而在于“精”。游戏提供商店删牌、事件删牌，让玩家能打出高频combo（循环套路）。
* **视觉辨识**: 同类型卡牌色调一致（攻击偏红，格挡偏蓝），极大地降低了认知负荷。

### 2.2 遗物系统 (Relics)
* **被动增益**: 遗物是游戏局外成长（单局内）的核心。它们改变游戏规则（例如：每打出3张牌造成伤害、能量上限+1但无法看到敌人意图）。
* **质变点**: 遗物往往决定了这一局的最终流派走向。

### 2.3 敌人意图系统 (Intent System)
* **公开的信息**: 游戏最伟大的创新之一是“明牌”机制，公开怪物下回合的动作（攻击、防御、上buff）。
* **策略的基石**: 因为信息公开，玩家的思考从“猜他要干嘛”变成了“如何在当前手牌下最大化收益/最小化战损”。极大增强了策略深度。

### 2.4 地图与节点选择 (Map & Pathing)
* **风险与收益的博弈**: 
  - 精英怪(Elite) = 高风险 + 高收益(必掉遗物)。
  - 篝火(Campfire) = 回复(生存) OR 升级卡牌(成长)。
  - 问号(Event) = 随机事件，可能极好也可能极坏。
* **节奏控制**: 强制的前进路线，每层固定3个阶段和关底Boss。

## 3. 对《光与朽》的启发
1. **意图可视化**: 塔防游戏中的怪物路线和攻击目标已经是公开的，能否在特定高压波次，提前给玩家更明确的高危警告（类似明牌攻击）？
2. **局内构筑的“减法”**: 如果《光与朽》有局内升级，允许玩家“遗忘”某些低级塔或技能，提高高级塔/核心技能的抓取率，会增强构筑的爽感。
3. **改变规则的“遗物”**: 设计一些能从根本上改变玩法的全局Buff（例如：所有塔攻速翻倍，但射程减半），这种强力的被动效果能极大地提升重玩价值。
