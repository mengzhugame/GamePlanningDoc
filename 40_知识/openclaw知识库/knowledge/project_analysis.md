## 二、光与朽项目深度分析

### 核心信息
- **游戏名称**：光与朽 (Light vs Decay) / 霓虹赌塔
- **游戏类型**：肉鸽塔防弹幕休闲游戏
- **核心玩法**：玩家操作激光射击怪物，打完Boss通关
- **目标用户**：男性玩家，喜欢射击塔防、激光解压游戏
- **变现模式**：先IAA，后续转IAP混变

### 已完成的策划文档
1. GDD游戏设计文档（V1.0-V5.0）
2. 数值框架文档（V1.0-V2.0）
3. 技能系统设计案（V3.0）
4. 局内经济与中场循环设计（V1.0-V2.0）
5. Boss动作与技能设计
6. 科技树系统策划案
7. 装备组装系统策划案
8. 美术资产清单
9. 音效资产清单
10. 发行追踪表

### 平衡性优化方案（V2.0）核心内容
| 模块 | 优先级 | 内容 |
|------|--------|------|
| 数值膨胀 | 高 | 基础DPS从100→1000，让玩家感受数值成长 |
| 暴击系统重做 | 高 | 基础暴击5%，上限50%，Crit技能每级+8% |
| Gacha机制优化 | 中 | 删除空结果，添加负面保护，智能奖励池 |
| Focus技能重做 | 中 | 改为高能透镜，纯伤害+Boss额外伤害 |
| Chain技能新建 | 中 | 连锁反应，激光传导到附近敌人 |
| 波次调整 | 中 | 12波→8波，经验×2，目标18级 |
| 大招系统 | 低 | 超载模式：无敌+伤害×2+宽度×2+自动吸附 |

## 三、美妆叠叠乐项目分析

### 核心信息
- **游戏类型**：化妆品堆叠消除游戏
- **目标用户**：女性玩家
- **当前状态**：已上线微信小游戏，532用户
- **数据表现**：留存较低，次留波动大（1%-33%）
- **商业思路**：积累用户→品牌植入→活动变现

### 已有文档
- GDD设计文档（V1.0-V2.0）
- 关卡编辑器设计文档
- 40个化妆品设计
- 30关卡设计
- 商业计划
- 发行追踪

### 经验教训
1. 玩法不够创新，被吐槽"像抓大鹅但没有抓大鹅好"
2. 美术被批评"劣质"
3. 商业模式依赖用户量，但玩法无法支撑流量
4. **核心教训**：玩法优先，商业模式其次

## 四、创意库分析

### 筛选创意.txt 核心内容
记录了多个游戏创意的评估和问题分析：

1. **滚动+美容**：粉底球滚动上妆 - 需解决关卡障碍设计
2. **绘制+恶作剧**：画线引导水球 - 可行，需考虑50关后的难度
3. **圈地+宠物**：画圈圈羊群 - 需解决失败条件设计
4. **发射+金钱**：金币通过倍增门 - 需解决失败条件
5. **分裂+解谜**：史莱姆分裂解谜 - 操作难度高
6. **画线+战斗**：画路线包围敌人基地 - 可行，需完善

### 创意评估方法
- 核心动词 + 题材 = 游戏创意
- 评估维度：第一关玩法、难度递增、失败条件、长期可玩性
