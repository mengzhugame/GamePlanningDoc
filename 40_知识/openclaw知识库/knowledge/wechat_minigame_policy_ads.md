# 微信小游戏运营与买量指南

## 一、微信小游戏政策规范

### 上架资质要求

#### 个人开发者
需提交 **2个** 文档：
1. **《计算机软件著作权登记证书》**
2. **《游戏自审自查报告》**
   - 个人签名
   - 格式：jpg/jpeg/bmp/gif/png
   - 大小：不超过5M

#### 企业开发者
需提交 **4个** 文档：
1. **《广电总局版号批文》**
2. **《计算机软件著作权登记证书》**
3. **《文化部备案信息》**
4. **《游戏自审自查报告》**
   - 加盖公司公章
   - 格式：jpg/jpeg/bmp/gif/png
   - 大小：不超过5M

### 审核要求

#### 游戏内容介绍
- 场景、玩法、功能信息清晰完整
- 截图需保持尺寸、版本一致
- **玩法首张图必须包含**：
  - 健康游戏忠告
  - 适龄提示
  - 游戏名称

#### 隐私政策
- 明确收集、使用用户个人信息的类型
- 说明目的、方式
- 确保与隐私政策一致

### PC端激励政策（2025-2026）
- PC端广告金激励
- 需在获得后90天内用于投放
- 2025年3月PC激励金，需在4月1日起90天内使用

## 二、广告投放实操

### 微信广告类型

| 广告位 | 特点 | 适用场景 |
|--------|------|----------|
| **朋友圈广告** | 高质量用户、留存好、ROI高 | 精品游戏放量 |
| **Banner广告** | 成本低、量大 | 冷启动测试 |
| **激励视频** | 用户主动观看、转化高 | 高价值用户获取 |
| **插屏广告** | 强制展示、曝光高 | 品牌曝光 |

### 投放策略优化案例

#### 案例：《三国全明星》
**问题**：Banner广告为主渠道，ROI未达预期

**优化**：
- 数据分析发现朋友圈广告用户质量更高
- 首日ARPU和留存优于其他广告位
- 调整预算：朋友圈广告消耗增长至80%以上
- 使用"图片直跳小游戏"减少转化流失

**结果**：ROI显著提升

### 出价策略

#### 注册+首日变现ROI
- **优化核心**：ROI，不是注册成本
- **特点**：
  - 注册成本比"首次付费+ROI"高30%
  - 但7日ROI提高17%
  - 适合长期ROI优化

#### 首日付费+ROI
- **优化核心**：首日付费成本和首日ROI
- **特点**：
  - 首日表现好
  - 但长期ROI不如"注册+ROI"

### 买量阶段

#### 1. 冷启动期
- 小预算测试多组素材
- 测试不同广告位
- 收集转化数据

#### 2. 调优期
- 快速洞察投放环节问题
- 合理干预优化
- 提升ROI表现

#### 3. 放量期
- 找到盈利模型后加大预算
- 稳定日耗（如案例中日耗50万）

## 三、买量策略

### ROI计算模型（混变游戏）

#### 公式
```
ROIn = [iOS用户付费金额n + 安卓分成后付费金额n + 变现金额n × (1+广告金比例a×广告金折价系数)] / 成本
```
其中 n ≤ 30天

#### IAA部分计算
```
变现收入 = 广告收入 × (1 + 广告金比例)
```

#### IAP部分计算
- **iOS**：不分成，全额计入
- **安卓**：需扣除微信30%分成

### 关键指标优化

#### 留存优化
- 次日留存影响买量成本
- 7日留存决定LTV高低
- 14日留存（微信大盘>50%）

#### 变现优化
- 人均广告展示次数：3-10次/天
- eCPM：20-100元
- 广告点击率：1-5%

### 创意素材策略

#### 视频广告要点
1. **前3秒**：展示核心玩法亮点
2. **前15秒**：完整展示一个游戏循环
3. **结尾**：引导转化（"点击即玩"）

#### 素材类型
| 类型 | 适用 | 转化率 |
|------|------|--------|
| 玩法展示 | 核心玩法清晰的游戏 | 高 |
| 剧情向 | RPG、剧情类游戏 | 中 |
| 爽点爆发 | 割草、塔防 | 高 |
| 真人演绎 | 休闲、超休闲 | 中 |

### 数据回传优化

#### 关键事件配置
1. **注册**
2. **首日活跃**
3. **关卡完成**
4. **广告观看**
5. **付费**

#### 优化机制
- 按业务规则配置关键事件
- 探索量级与质量平衡
- 依属性筛选回传数据
- 定制买量模型
- 分析关键指标优化推广策略

## 四、光与朽买量建议

### 游戏定位
- **类型**：Roguelike塔防
- **变现**：IAA为主（可加入轻IAP）
- **目标用户**：休闲玩家、塔防爱好者

### 投放策略

#### 第一阶段：冷启动（1-2周）
- 预算：1000-5000元/天
- 目标：测试素材、找转化点
- 指标：注册成本<3元

#### 第二阶段：调优（2-4周）
- 预算：5000-20000元/天
- 目标：优化ROI
- 指标：3日ROI>0.3

#### 第三阶段：放量（稳定后）
- 预算：根据ROI决定
- 目标：规模化盈利
- 指标：7日ROI>1

### 素材方向
1. **激光割草爽感**：展示多激光穿透怪物
2. **技能组合**：展示Prism+Focus的强力组合
3. **Boss战**：展示Boss战的紧张刺激
4. **新手引导**：展示简单上手的过程

### KPI目标

| 指标 | 目标 | 优化方向 |
|------|------|----------|
| 注册成本 | <3元 | 优化素材、定向 |
| 次留 | >40% | 优化新手体验 |
| 3日ROI | >0.3 | 优化广告点位 |
| 7日ROI | >1 | 提升留存和变现 |
| LTV | >5元 | 增加内容深度 |
