## 游戏策划下一课题：游戏爽感设计 (Game Feel)

### 关键概念
- **击打感**：冲击力、声音、震动、视觉反馈的组合。
- **Hit‑stop**：在攻击命中瞬间短暂停帧，以增强冲击感。
- **屏幕抖动（Screen Shake）**：使用噪声函数或 Perlin Noise 产生自然的抖动，避免机械式摇动。
- **输入响应**：降低输入延迟至 30ms 以下，使用 Unity Input System 的 `Update` 与 `FixedUpdate` 同步。

### 最新案例（2024‑2025）
1. **《Hades》续作更新**：引入可自定义的 Hit‑stop 强度，玩家可通过设置面板微调冲击感。实现方式：在攻击判定后调用 `Time.timeScale = 0.92f` 持续 0.08s，随后恢复。
2. **《Tower of Ishal》**（2025 年学术案例）：通过 MDA 框架把 ``挑战`` 与 ``叙事`` 结合，使用屏幕抖动强化 boss 战的紧张感。抖动参数：`amplitude = 0.5f`，`frequency = 12Hz`，`duration = 0.3s`。
3. **《Neon Abyss》**：全程使用 2D 视觉冲击特效，结合粒子系统的 ``Burst`` 与 ``Collision`` 触发音效，实现瞬间视觉爆炸感。

### 实操干货
- **实现 Hit‑stop**：
  ```csharp
  IEnumerator HitStop(float scale=0.9f, float duration=0.07f){
      Time.timeScale = scale; 
      yield return new WaitForSecondsRealtime(duration);
      Time.timeScale = 1f;
  }
  ```
- **屏幕抖动脚本**（Unity C#）：
  ```csharp
  public class ScreenShake : MonoBehaviour{
      public IEnumerator Shake(float magnitude, float roughness, float fadeOut){
          Vector3 originalPos = transform.localPosition;
          float elapsed = 0f;
          while(elapsed < fadeOut){
              float x = Random.Range(-1f,1f) * magnitude;
              float y = Random.Range(-1f,1f) * magnitude;
              transform.localPosition = originalPos + new Vector3(x,y,0);
              elapsed += Time.deltaTime * roughness;
              yield return null;
          }
          transform.localPosition = originalPos;
      }
  }
  ```
- **输入优化**：使用 `InputSystem.OnActionTriggered` 替代 `Update` 中轮询，确保每帧唯一响应。

### 对光与朽的应用
- **塔防射击**：在激光塔命中敌人时加入 Hit‑stop，增强击打快感；配合微弱屏幕抖动提升激烈感。
- **随机事件**：使用粒子冲击与音效让玩家感知随机道具的价值提升。
- **玩家反馈**：每次升级后短暂的 UI 抖动，强化成就感。

以上即为本次学习笔记，供后续开发参考。

## 游戏策划下一课题：塔防与肉鸽的心流与随机性控制

### 为什么这就是下一个该攻的点
路线图里当前已在 `game_design.md` 沉淀的是【游戏爽感设计】；结合《光与朽》本身就是“塔防 × 肉鸽 × 激光射击”混合体，下一步最值钱的不是空谈理论，而是把“局内节奏、随机奖励、公平感、可复盘性”这组真正影响留存的设计骨架啃透。

### 一、核心结论：塔防肉鸽的爽，不靠乱，靠“可控的乱”
1. **随机性的职责不是制造惊喜，而是制造可适应的局面。**
   - Riot 在 GDC《Level Up Your Game: The Untapped Potential of Roguelikes》强调，Roguelike 的长期魅力来自：随机、并行成长、可学习技能、技能组合，共同驱动 mastery loop。
   - 《Spelunky》设计分析也证明：优秀 roguelike 不是让玩家背地图，而是逼玩家学习系统规律；玩家学会的是“系统语言”，不是固定答案。

2. **一旦随机结果无法转化成决策，心流就断。**
   - Game Developer《Solving RNG Abuse in Roguelikes》指出：RNG 一旦压低玩家 agency（主动性/控制感），玩家就会通过重开、刷开局、抱怨“这把没法玩”来对抗系统。
   - 对塔防来说，最糟糕的不是难，而是“抽不到核心塔 + 怪潮刚好克制你 + 资源还不够补救”，这会让玩家觉得自己输给了抽卡，不是输给了判断。

### 二、心流的本质：每 20~40 秒给玩家一个清晰决策点
塔防肉鸽的局内节奏，建议拆成四拍：
1. **读局势**：这波敌人是什么抗性、路径、数量结构？
2. **做选择**：升级塔、拿天赋、换模块、吃事件，最多给 2~4 个选项。
3. **看兑现**：新选择在下一波 10~30 秒内立刻见效。
4. **再抬难度**：系统再给新压力，让玩家重新思考。

如果一局里连续 60 秒只有机械清怪，没有新判断点，玩家会无聊；如果 15 秒内连续塞 5 次选择，玩家会疲劳。**最佳区间是“短战斗 + 短决策 + 立即反馈”的循环。**

### 三、随机性控制的 7 个硬招

#### 1) Bag / Deck RNG，别用纯均匀随机
- 很多奖励系统应使用 **weighted RNG / pseudo-random / bag model**，而不是每次独立均匀抽样。
- 含义：先把奖励按功能分桶，再从桶里抽，而不是把所有东西丢进一个池子乱抽。

**落地做法：**
- 奖励分为：输出塔、控制塔、经济塔、生存/护盾、通用强化、局外货币。
- 每 3 次升级奖励里，至少保证：
  - 1 个当前流派相关项
  - 1 个补短板项
  - 1 个转型项
- 连续两轮不再重复同一低价值白板奖励。

**结果：** 玩家仍觉得“每局不同”，但不会连续吃屎。

#### 2) 做坏运气保护，但别明说
行业里最常见也最有效的手段就是 **bad luck protection / pity logic**。

**适合《光与朽》的规则示例：**
- 连续 3 次升级没有出现“激光 / 反射 / 穿透 / 过热”任一核心标签 → 第 4 次至少保送 1 个相关词条。
- 连续 2 波漏怪且金币低于阈值 → 下波事件池提高“资源恢复 / 低费应急塔”权重。
- 玩家 90 秒内没获得任何 build-defining 选择 → 强制插入一次“高质量三选一”。

#### 3) 输入随机 > 输出随机
- **输入随机**：系统先给你一组条件，你再做判断。
- **输出随机**：你已经做了对的事，但结果还是靠脸。

塔防里应该多做输入随机，少做输出随机。
- 好随机：给玩家 3 个不同强化，自己选。
- 坏随机：塔命中后 20% 几率伤害翻倍、敌人 15% 几率无征兆闪避。

**输入随机创造策略，输出随机制造脏话。**

#### 4) 让后期掉落比开局掉落更决定胜负
《Solving RNG Abuse in Roguelikes》强调 item progression：让前期拿到什么，不要过度决定整局死活；真正影响胜负的关键构筑，应逐步在中后期成形。

**对塔防的启示：**
- 开局塔只负责“活下来”，不负责“这把已经定型”。
- 第 3~5 轮开始给构筑分叉；第 6~9 轮才让核心 synergy 真正爆发。
- 这样玩家不会因为开局没抽到神卡就立刻重开。

#### 5) 保证“确定锚点”，让高手有稳定策略
《Spelunky》虽然随机，但藏着大量**保证出现的锚点**，所以高玩能围绕这些锚点构建稳定策略，减少纯脸成分。

**塔防肉鸽也必须有锚点：**
- 固定轮次一定给商店 / 修复 / 重组选项。
- 固定 Boss 前一定能做一次成型调整。
- 固定轮次出现“保底资源包 / 保底天赋槽”。

这样玩家学到的是规划，不是求神拜佛。

#### 6) 难度曲线要跟 build 成型节奏绑定，不要跟时间死绑
塔防肉鸽最蠢的错误，就是怪越来越多，但玩家构筑不给力，于是难度不是“压迫”，而是“崩盘”。

正确做法：
- **敌人压力 = 基础波次成长 × 玩家当前战力修正 × 当前轮次容错修正**
- 若系统侦测玩家输出明显偏低、漏怪升高、经济断档，则降低下一波的克制性组合概率，优先给“可解的压力”，而不是致死无解题。

#### 7) 让玩家能“反制随机”
真正高级的设计，不是把 RNG 全部藏起来，而是给玩家工具去操纵它。

可用手段：
- 锁定 1 个奖励选项，下轮继承
- 消耗货币刷新商店 / 奖励
- “预言”系统：提前揭示下一波敌人标签
- 事件道具：把奖励池偏向激光 / 召唤 / 冻结 / 经济某一路
- Boss 前提供一次免费重构

这会显著提高 agency。玩家会觉得：虽然系统在摇骰子，但我能伸手去掰骰盅。

### 四、2025 年前后的案例与市场观察

#### 案例 1：《Tower Dominion》（2025）
中文行业观察提到，这款作品把**随机性直接做成塔防的主构筑轴**：敌人种类、增援资源、塔与升级选项都围绕每局重组，核心亮点不是传统摆塔，而是每轮如何从有限随机项里拼出解法。

**可学点：**
- 随机项足够多，但每轮只给少量关键选择，降低认知负担。
- 让“应对新局面”成为乐趣，不让“信息过载”成为惩罚。

#### 案例 2：《全境守卫》（2025，小游戏向案例）
行业报道提到它把建造决策进一步简化为**肉鸽三选一**，把原本拖沓的建造操作压缩成几秒内的高速判断，提升了白天建造与夜晚守城的衔接顺滑度。

**可学点：**
- 小游戏/轻中度用户不怕随机，怕的是拖。
- 把复杂部署压缩成“高质量短决策”，反而更容易形成连玩。

#### 案例 3：《Hades》《Risk of Rain 2》《Slay the Spire》《Dead Cells》
虽然不全是塔防，但它们提供了 Roguelike 设计的四个共识：
- 给玩家中途修正路线的机会；
- 用加权随机而非真随机；
- 早期决定方向，后期决定强度；
- 用局外成长或明确奖励，降低“白打了一把”的挫败感。

### 五、给《光与朽》的直接落地方案

#### 1. 把局内升级池改成“三层池”
- **核心流派池**：激光、反射、穿透、灼烧、过热、连锁
- **补短板池**：减速、控制、护盾、恢复、经济
- **转型池**：召唤物、临时炮台、一次性大招、特殊事件

每次三选一时，至少从三个池里各出一个，保证“稳、补、赌”并存。

#### 2. 建立 build 成型时间表
- 0~2 分钟：保生存、低门槛理解
- 2~5 分钟：出现第一波关键流派件
- 5~8 分钟：出现放大器与乘区件
- Boss 前：必须给一次明显的补救 / 重构窗口

#### 3. 给玩家一件“操纵随机”的主动技能
比如：
- 消耗能量，下一次升级奖励中激光词条概率翻倍；
- 消耗货币，预览下一波敌人抗性；
- 保留一个未选择词条到下一轮。

这会让《光与朽》从“抽卡塔防”升级成“控盘塔防”。

#### 4. 做隐藏保底，但前台只展示结果自然
不要写“保底机制已触发”。直接让玩家感觉：
“这把虽然前面歪了，但系统后面还是给了我一手能翻的牌。”

这种感觉最容易转化为：
- 愿意再来一把
- 愿意研究 build
- 愿意分享截图和打法

### 六、最终判断
**塔防肉鸽的顶级设计，不是谁随机得更疯，而是谁更会把随机驯成决策。**
做得烂，玩家会说“这把纯看脸”；做得好，玩家会说“这把真神，我硬是把烂牌打活了”。这中间，就是留存率的鸿沟。

## 2026-04-10｜游戏策划下一课题：经济系统与数值模型平衡（以《暗黑破坏神》《流放之路》为鉴）

### 一、为什么这才是下一课题
按照路线图顺序，当前在 `game_design.md` 里已经沉淀了【游戏爽感设计】和【塔防与肉鸽的心流与随机性控制】。因此，游戏策划维度下一个未攻克的细分课题，应顺延到【经济系统与数值模型平衡】。这也是《光与朽》现在最该补的硬骨头，因为我们后续所有局内成长、局外养成、广告复活、轻付费包，本质上都在吃“资源产出、消耗、保值、稀缺、断点”这套经济规则。

### 二、核心结论：好经济不是让玩家一直赚，而是让每份资源都有去处、有痛感、有选择
ARPG 经济系统里最蠢的死法有两个：
1. 资源只会涨，不会回收，最后通胀爆炸；
2. 资源虽然能花，但花法太线性，玩家只会机械堆数值。

顶级做法恰恰相反：
- **资源入口（Faucet）要稳定且可控**，让玩家知道靠玩能拿到什么；
- **资源出口（Sink）要持续存在**，避免货币和材料无限堆积；
- **资源价值要和决策绑定**，不是“攒够就升”，而是“现在升什么、放弃什么、赌不赌更大收益”；
- **数值成长必须卡断点**，让每次投入都可能跨过一个真实战斗阈值，而不是只涨面板小数点。

### 三、《暗黑4》与《流放之路》给出的三条铁律

#### 1）掉落要更少，但单件更值钱
Blizzard 在《Diablo IV: Loot Reborn》（2024）官方更新里明确做了三件事：减少掉落数量、提高单件装备的重要性、把复杂度从“看一地垃圾”转移到 Tempering 与 Masterworking 这类后期改造系统。

这背后的本质是：
**经济系统不是让玩家捡更多，而是让玩家更快判断“这个东西值不值我继续投入资源”。**

如果掉落量太大，玩家会进入“清包疲劳”；
如果改造系统太浅，玩家只会无脑换更高数值；
如果改造成本太狠，玩家又会因为试错痛苦直接弃坑。

所以 Diablo 4 后来的持续调整，本质都围绕一个目标：
**降低无意义筛选成本，提高有意义投入决策。**

#### 2）交易越容易，掉率和经济压力就必须反向收紧
《Path of Exile》Trade Manifesto 的设计哲学非常狠：物品必须重要，交易必须存在，但交易不能毫无摩擦。

GGG 说得很直白，若交易太容易：
- 玩家会更少依赖打怪获得升级；
- 有用物品获取速度会暴涨；
- 设计方就只能反向降低掉率，或者让内容变得更难；
- 机器人和自动化套利会把经济系统狠狠干烂。

这条铁律对我们特别重要：
**任何允许“资源互换”“广告换补给”“货币换重抽”的系统，都必须带摩擦与成本。**
不然玩家不是在做策略，而是在找最优套利脚本。

#### 3）市场便利性可以提升，但必须加新的交易成本与行为门槛
PoE 在 2024 年推出 Currency Exchange Market，本质不是“全面拍卖行化”，而是先把高频、标准化的货币交易做得更顺，但加上额外门槛来抑制自动化和无脑套利。结合官方说明与社区反馈，核心思路不是让一切都秒成交，而是把重复、低价值社交摩擦削掉，同时保留经济系统的控制阀。

这说明一个高级原则：
**你可以优化体验，但不能把经济控制权一起送出去。**

### 四、经济系统设计的 6 个硬公式

#### 1）先分清三种资源，不要一锅炖
一个健康系统至少拆成三层：
- **软货币**：高频产出，高频消耗，比如金币、波次晶体；
- **硬资源**：中频产出，中强决策，比如强化芯片、稀有模块；
- **稀缺门票**：低频产出，决定高价值行为，比如重构次数、Boss挑战券、定向刷新券。

如果三者混成一种货币，必然出问题：前期不敢花，中期通胀，后期失去意义。

#### 2）每种资源都必须同时有 Faucet 和 Sink
设计表里至少要写两列：
- **产出来源**：关卡、日常、广告、首胜、Boss、成就；
- **消耗去处**：升级、重抽、复活、重构、兑换、保底、合成。

只做产出不做回收，资源必炸。只做回收不做产出，玩家会觉得系统在抢钱。

#### 3）数值投入要盯“战斗断点”，不是盯百分比
做平衡时别看“+8%攻击很不错”，要看：
- 是否让某类敌人从 4 下击杀变成 3 下；
- 是否让激光持续时间刚好覆盖一整波精英；
- 是否让减速塔把 Boss 停留时间延长到第二轮主炮冷却转好。

也就是：
`战斗价值 ≠ 面板涨幅`
`战斗价值 = 是否跨过关键阈值`

#### 4）高价值投入必须允许失败，但失败不能纯坐牢
Diablo 4 的 Tempering / Masterworking 价值就在这里：
- 投入有期待；
- 有一定不确定性；
- 但长期看仍可通过重置、追加投入、材料循环继续追求最优。

这类设计比纯固定升级更耐玩，因为它创造了：
- 赌高收益的刺激；
- 材料回收的必要性；
- 中后期持续追求空间。

#### 5）经济系统要给“保底成长”，数值系统再给“天花板成长”
玩家必须同时感受到两件事：
- 我今天玩了，稳定有进步；
- 我今天如果打得更好、决策更狠，还能赚得更多。

前者保证留存，后者保证钻研。只做保底会无聊，只做天花板会劝退。

#### 6）赛季/版本制游戏一定要定期重置通胀压力
GGG 的长期经验很清楚，赛季之所以重要，不只是做新内容，更是：
- 重置经济；
- 重置顶级玩家的领先优势；
- 让新玩家有重新进入市场的窗口；
- 给设计师一次重新校准资源 faucet/sink 的机会。

如果《光与朽》未来做赛季、周常轮换或版本主题，经济重置不能只是“删库存”，而要绑定新词条、新模块、新资源出口，不然就是清档，不是更新。

### 五、给《光与朽》的直接落地方案

#### 1）局内经济要拆成三类
- **光能**：战斗内基础资源，用于摆塔、临时升级、应急修补；
- **棱镜碎片**：局内稀有资源，用于重抽三选一、Boss前重构、购买特殊事件；
- **圣痕核心**：局外稀缺资源，用于永久解锁、科技树节点、定向保底。

#### 2）三选一不要免费重抽，必须付“中痛感成本”
- 第一次重抽消耗少量棱镜碎片；
- 第二次重抽成本翻倍；
- Boss 前给一次半价重构窗口。

这样玩家会认真权衡，而不是把选择系统玩成刷脸工具。

#### 3）升级和词条定价，全部围绕断点来做
给每个核心词条建立内部评分，不按描述强弱排，而按它实际跨过的阈值排：
- 清杂效率断点；
- 精英击杀时间断点；
- Boss压制窗口断点；
- 生存容错断点。

这套表做完，广告奖励、局外成长、局内商店价格才不会瞎定。

#### 4）广告奖励只卖“纠偏权”，别卖纯数值
最适合的广告经济位置不是直接给钱，而是：
- 允许一次定向补核心词条；
- 允许一次低价重构；
- 允许一次局内资源应急包。

这比“+100金币”高级太多，因为它直接服务 build 与翻盘，而不是制造通胀垃圾。

#### 5）给后期玩家持续 Sink
如果后续要做长期留存，必须提前埋好资源回收口：
- 高阶模块重铸；
- 词条洗练；
- 局外科技树分支重置；
- 周期性主题商店；
- 限时 Boss 门票消耗。

不然老玩家三天就会资源爆仓，然后整个成长系统变笑话。

### 六、最终判断
**经济系统本质上不是“给多少资源”，而是“让玩家为了什么愿意花资源”。**
《暗黑4》告诉我们，垃圾掉落太多会毁掉判断力；《流放之路》告诉我们，交易太顺会毁掉掉落价值。对《光与朽》来说，最正确的方向不是堆更多货币和更多商店，而是把资源拆层、把消耗做深、把投入卡在真实战斗断点上。这样玩家花的每一份资源，都会感觉是在“塑造 Build”，不是在做流水线打卡。

## 2026-04-18｜游戏策划下一课题：上瘾模型（Hook Model）与玩家心理学，如何打造高留存率

### 一、为什么这就是现在该啃的硬骨头
现有 `game_design.md` 已覆盖：
1. 游戏爽感设计
2. 塔防与肉鸽的心流与随机性控制
3. 经济系统与数值模型平衡

按当前沉淀顺序，下一块最该攻的，就是【上瘾模型与玩家心理学，如何打造高留存率】。这不是“怎么把人骗回来”，而是怎么把《光与朽》的**局内爽点、局外成长、回流理由、长期目标**接成一个闭环。做不好，玩家会说“挺爽，但玩两把就算了”；做好了，玩家会说“再来一局，我差一点就成了”。

### 二、核心判断：现代游戏里的 Hook，不是“签到领奖”，而是“可预期目标 + 不可预期惊喜 + 玩家自己投入”
经典 Hook Model 是四步：
1. **Trigger（触发）**
2. **Action（行动）**
3. **Variable Reward（可变奖励）**
4. **Investment（投入）**

但放进 2024-2026 的游戏环境里，直接照搬会很蠢。现在真正有效的不是纯粹靠通知、倒计时、赌脸奖励把人拽回来，而是三层结构同时成立：

- **外部触发**：推送、活动、每日挑战、新内容上线；
- **内部触发**：玩家记住“我这套 Build 还没打成”“我这波差一点过 Boss”；
- **自我投入**：玩家自己做了选择、养成了配置、积累了未完成目标，因此更愿意回来继续。

一句话总结：
**高留存不是把奖励做得更花，而是让玩家留下“未完成的个人计划”。**

### 三、2024-2026 的行业共识：真正拉留存的不是单一奖励，而是“行为闭环”

#### 1）留存必须和具体行为绑定，不能只看安装日留存
GameAnalytics 2025 的 retention 文档给了一个非常值钱的方向：
**不要只盯 D1 / D7 安装留存，而要看“某个关键行为之后，玩家还回不回来”。**

比如：
- 完成新手教程后是否回流；
- 首次拿到核心装备后是否回流；
- 首次购买后是否继续登录；
- 首次接触 battle pass / feature 后，后续参与率是否抬升。

这意味着策划不能只设计“功能”，还得设计：
- 这个功能要把玩家送进哪个下一步；
- 玩家完成这一步之后，系统如何制造新的期待。

**对《光与朽》的启发：**
别只看“玩家装了没留”，要看：
- 完成第 1 次炮塔升级后的次日回流；
- 第 1 次拿到激光核心词条后的回流；
- 第 1 次被 Boss 差一点打死后的广告救援转化与次日回流；
- 第 1 次完成局外科技升级后的 3 日回流。

这才是能指导设计的 retention，不是废数据。

#### 2）FTUE 就要埋回流钩子，不能只负责教操作
Unity Learn 2025 明确强调：
**留存和 engagement 最好在概念阶段就设计进核心循环，而不是开发后期再补。**

它给的几个抓手很实：
- 每日/每周奖励要尽早出现，让玩家马上知道“明天回来还有东西”；
- 推送要短、轻、个性化，别像催债；
- 任务系统要分层，既给立刻能完成的小目标，也给中期目标；
- 社交、竞争、可展示内容会显著提高复访动机；
- 埋点与 A/B 测试必须前置，不然你根本不知道哪个环节在漏人。

**重点不是奖励本身，而是让玩家在第一天就形成“我明天回来能继续推进”的心理模型。**

#### 3）可变奖励依然有效，但前提是玩家能理解自己为什么有机会赢
关于 Hook Model 最大的误区，就是把 Variable Reward 理解成“纯随机”。这会把游戏做成赌场味。

最新 Roguelike / Roguelite 成功案例说明：
- 真正持久的可变奖励，是**可塑形的随机**，不是纯抽脸；
- 玩家必须能通过策略、构筑、资源管理去“驯服随机性”；
- 奖励最好制造“下一次更强”的期待，而不是一次性情绪刺激。

**Balatro** 在 2024-2025 的长线热度就是典型例子。外部看来它很随机，但核心乐趣其实是：
- 每局随机给你材料；
- 你不断识别组合；
- 你能主动修牌库、控风险、搏乘区；
- 随机没有被取消，但被你逐步驯化。

所以玩家会觉得“我还能再优化一轮”，而不是“我只是手气不好”。

**这就是高级 Hook：把不可预测性做成 mastery，而不是做成操控。**

### 四、案例拆解：2025 年仍然能打的留存机制，长什么样

#### 案例 1：《Survivor.io》
2025 年行业复盘提到，这游戏在上线三年后仍维持约 500-600 万美元月流水，并持续获得数十万月下载，关键不是单点爆款，而是整套闭环同时成立：

- **低门槛行动**：单手操作、自动攻击，进入成本极低；
- **局内可变奖励**：每次升级三选一，构筑即时变化；
- **局外投资系统**：英雄、装备、合成、章节推进持续抬高长期目标；
- **Live Ops 挂钩**：限时活动、排行、事件让“今天回来”有理由；
- **社区外溢**：玩家愿意讨论 build、榜单、活动打法。

这说明什么？
**短期爽感负责拉新，局内构筑负责 D1-D7，局外成长 + 活动节奏负责 D30 以后。**
少一层，都会塌。

#### 案例 2：《Balatro》
Balatro 的强，不是靠签到，而是靠：
- 每局都有新组合空间；
- 每局失败都像“差一点就成了”；
- 玩家很容易把失败解释为“策略还可优化”，不是“系统恶意坑我”。

这是一个特别关键的心理学点：
**人愿意反复回来的前提，不是一直赢，而是感觉下次能更聪明。**

对 Roguelike / 塔防尤其如此。只要失败能转化成学习，而不是羞辱，留存就有根。

#### 案例 3：伦理视角的反向提醒
2024 年关于 Ethical Game Design and Player Retention 的研究给了一个很硬的结论：
如果留存手段过度依赖剥削性 monetization、FOMO 压榨、逼氪和失控随机，玩家会因为厌恶感而流失，长期承诺反而下降。

更稳的方向是：
- 保护玩家自主性；
- 给明确目标与成长感；
- 强化社交连接与公平；
- 让奖励是“支持体验”，不是“绑架体验”。

这很重要，因为《光与朽》如果以后做激励广告、活动通行证、局外养成，很容易一步没踩稳就开始散发页游味。那就完蛋。

### 五、把 Hook Model 拆成《光与朽》可落地的 5 条设计法则

#### 法则 1：触发要分层，外部触发只负责叫人回来，内部触发才负责让人想回来
**外部触发**：
- 今日挑战刷新
- 限时事件开启
- 炮塔试炼 / Boss 悬赏
- 昨日未完成的 build 继续挑战

**内部触发**：
- “我这套激光反射流差一个核心件就成型了”
- “我卡在第 6 波，今晚我能过去”
- “我刚解锁新模块，还没试极限搭配”

落地原则：
**推送不能替代动机，只能唤醒动机。**
如果局内没有 unfinished business，再多通知也只是骚扰。

#### 法则 2：每局必须留一个“下一把理由”
每次 run 结束后，至少让玩家带走其中一个：
- 一个新模块 / 新词条认知
- 一次局外成长资源
- 一个未完成挑战
- 一个可复盘的失败原因
- 一个下次可验证的新搭配想法

如果玩家死了之后只得到“结算分数”，那就是垃圾闭环。

#### 法则 3：奖励设计遵循“稳奖励 + 赌奖励 + 成长奖励”三层结构
- **稳奖励**：金币、科技点、基础养成材料，保证不白打；
- **赌奖励**：随机强化、事件奇遇、隐藏词条，制造惊喜；
- **成长奖励**：解锁新塔、新模块、新流派入口，让玩家觉得账户真的在变强。

只给稳奖励，会打工味太重；
只给赌奖励，会像抽卡；
只有成长奖励，没有短期兑现，又会显得太慢。

三层同时存在，留存才稳。

#### 法则 4：Investment 不是“充值”，而是“玩家已经把自己放进系统里”
Hook Model 最值钱的一步其实不是 reward，而是 investment。
玩家一旦投入下面任意一种东西，回流概率都会上升：
- 自己命名或偏好的 build 路线；
- 自定义炮塔模块搭配；
- 对某个关卡/Boss 的个人攻略；
- 周任务进度条；
- 已积累但尚未兑现的通行证 / 活动进度；
- 和朋友比排名的记录。

所以系统要多创造“玩家留下个人痕迹”的位置。
这比单纯塞货币更值钱。

#### 法则 5：别做脏钩子，要做高质量复访理由
脏钩子：
- 强制签到断档惩罚过大
- 奖励倒计时逼迫上线
- 广告频率把人烦死
- 关键成长卡得太死，不看广告/不付费就废

高质量钩子：
- 每日挑战带来不同解法
- 限时事件提供独特规则，不只是多送币
- 失败后给一次 build 复盘提示
- 提供“明日可验证的策略假设”

**让玩家回来，是因为有新解法，不是因为怕损失。**
这两者长期留存差距极大。

### 六、《光与朽》的直接改造方案

#### 方案 A：把首日目标从“活下去”改成“做出第一次成型 Build”
当前很多独立塔防的问题，是首局只在教操作，没有给“流派觉醒时刻”。
《光与朽》首日必须确保玩家在 10-15 分钟内体验到一次：
- 激光反射成型
- 穿透清线成型
- 灼烧叠伤成型
- 控场拖延成型

只要第一次成型爽点没出来，玩家不会理解这游戏为什么值得留。

#### 方案 B：每日挑战不要只改数值，要改规则
比如：
- 今日所有激光塔初始自带穿透
- 今日精英怪移速更快，但死亡掉额外模块
- 今日只能从 3 种流派里选 1 条主路线
- 今日 Boss 会周期生成镜像护盾，逼玩家做拆盾构筑

这样玩家回来不是为了“领 50 金币”，而是为了“今天这把解法不一样”。

#### 方案 C：建立“差一点就过”的失败体验
失败页不要只写“你输了”。
应该展示：
- 你离通关只差多少伤害 / 生存 / 控场；
- 你这把 Build 已完成了哪 2 个核心、缺哪 1 个核心；
- 推荐你下局优先尝试什么方向。

把失败从挫败改成诊断，玩家才愿意再来一把。

#### 方案 D：局外成长要偏“开新打法”，少做纯数值堆叠
优先解锁：
- 新模块槽
- 新词条池
- 新事件分支
- 新炮塔专精
- 新挑战规则

少做：
- 单纯 +2% 攻击
- 单纯 +3% 血量

纯数值成长会让 Hook 变得廉价，因为玩家回来只是在补作业，不是在开新玩法。

#### 方案 E：广告与付费只放在“翻盘节点”，别污染主循环
最适合放激励广告的位置：
- Boss 前一次定向强化刷新
- 濒死后一次带代价复活
- 结算时一次双倍局外资源
- 限时事件里一次额外路线分岔

不要把广告做成：
- 每波都跳
- 常驻红点烦人
- 看广告才有正常构筑速度

**广告是救火器，不是氧气。**
一旦玩家觉得正常呼吸都得看广告，留存会被你自己打爆。

### 七、给策划的最终判断
**Hook Model 在游戏里真正该学的，不是“怎么让玩家上瘾”，而是“怎么让玩家总有一个属于自己的未完成目标”。**

《光与朽》这类塔防 × 肉鸽项目，最正确的方向不是签到和倒计时轰炸，而是：
- 局内每 20~40 秒给一次高质量判断；
- 每局结束留下一个明确可追的 build 假设；
- 局外成长解锁新打法，不只是加面板；
- 每日内容提供新规则，不只是发工资；
- 广告和付费只服务翻盘，不破坏公平。

做到这一步，玩家留下来不是因为被钩住，而是因为他真想把这套玩法玩明白。

### 八、可执行检查清单（给后续版本迭代）
- 首局 15 分钟内，是否能稳定体验一次流派成型？
- 每次失败后，玩家是否知道“下把怎么改”？
- 每日挑战是否改变解法，而不是只改奖励？
- 局外成长是否至少 50% 用于解锁新玩法，而不是纯数值？
- 激励广告是否只出现在高情绪、高价值节点？
- 埋点是否覆盖 tutorial_complete、first_build_online、boss_fail_close、first_meta_upgrade、ad_revive、daily_challenge_enter？
- 是否能按关键行为看回流，而不是只看安装留存？

## 2026-04-18｜游戏策划下一课题：MDA框架（机制、动态、美学）的实际应用

### 一、为什么这才是当前真正未攻克的课题
我先核过知识库，`game_design.md` 里已经写过：
1. 游戏爽感设计
2. 塔防与肉鸽的心流与随机性控制
3. 经济系统与数值模型平衡
4. 上瘾模型与玩家心理学

反而路线图里最前面的【MDA框架】还没系统沉淀。这个坑必须补，因为 MDA 不是学院派摆设，它本质上是**把“我想让玩家感受到什么”倒推回系统设计**的方法。对《光与朽》这种“塔防 × 肉鸽 × 激光爽感”混合项目尤其关键，不然功能会越做越多，体验却越来越散。

### 二、核心结论：别从功能清单开始，先从目标体验倒推系统
MDA 的经典定义来自 Hunicke、LeBlanc、Zubek：
- **Mechanics（机制）**：规则、数值、资源、操作、胜负条件。
- **Dynamics（动态）**：玩家在运行中实际产生的行为模式，比如拉扯、赌狗、囤资源、冒险转型。
- **Aesthetics（美学）**：玩家最终感受到的情绪和体验，不只是“画面好看”，而是紧张、掌控、惊喜、成就、探索、沉浸这些感受。

最关键的不是这三个词本身，而是**设计师做游戏时通常从 Mechanics 往外做，玩家体验游戏时却是从 Aesthetics 往里感受。**

所以真正专业的用法不是“把系统列完再看看好不好玩”，而是：
1. 先确定你要的核心体验；
2. 再定义会自然长出这种体验的玩家行为；
3. 最后才写规则、词条、数值和按钮。

一句话：
**MDA 逼你从“我要加什么功能”切换到“我要让玩家具体感觉到什么”。**

### 三、MDA 里最值钱的实战部分，不是分析，是倒推
经典八类美学目标常被总结为：
- Sensation（感官刺激）
- Fantasy（幻想代入）
- Narrative（叙事推进）
- Challenge（挑战征服）
- Fellowship（社交连接）
- Discovery（探索发现）
- Expression（表达自我）
- Submission（轻松沉浸/刷子放空）

很多策划会犯一个蠢错：想同时全要。结果就是系统什么都有，体验没有主心骨。

正确做法是：
- **先选 1 个主美学目标**，决定你的产品灵魂；
- **再选 1 到 2 个副目标**，增加层次；
- 其他统统让路。

对《光与朽》来说，最适合的不是 Narrative 优先，也不是 Submission 优先，而是：
1. **主目标：Challenge**，玩家要明显感到“我在解一局越来越凶的系统题”；
2. **副目标一：Sensation**，激光命中、穿透、反射、清屏时必须爽；
3. **副目标二：Discovery**，玩家每局都能发现一个新搭配或新解法。

这三个一旦咬合，产品定位会非常清楚。

### 四、2024-2026 的最新启发：MDA 不能只看理论，要和真实玩家动机绑死
#### 1）玩家真正记住的不是规则，而是体验标签
2025 年关于玩家美学感知的研究指出，玩家对“游戏美学”的理解远不只视觉和音效，还包括探索欲、社交感、故事氛围、互动反馈等复合体验。也就是说，**Aesthetics 不是美术部门的事，而是整个系统共同制造的情绪结果。**

这对独立项目非常重要。很多团队把“美学”理解成风格包装，结果外皮很酷，玩起来没感觉。真正有效的设计是：
- 视觉、音效、节奏、奖励反馈、关卡结构一起服务同一个情绪目标；
- 不让系统和表现各唱各的戏。

#### 2）现代留存设计越来越证明：自主、成长、连接，比单纯奖励更稳
2024-2025 关于自我决定理论（SDT）的研究与实践讨论反复强调，能长期拉动动机的核心仍然是三件事：
- **Autonomy 自主性**：我能做选择，我不是被推着走；
- **Competence 胜任感**：我越来越会，我在变强；
- **Relatedness 连接感**：我和别人、和角色、和世界有关系。

把它翻译成 MDA，就是：
- Aesthetics 里如果没有掌控感和成长感，Dynamics 很快会变成疲劳刷子；
- Mechanics 如果只会塞奖励，不会制造选择，玩家就会空心化。

#### 3）2024-2025 的爆款更像“高纯度美学机器”
《Balatro》是个非常好的当代案例。它的表层机制是扑克牌计分、Joker 组合、商店和重构，但玩家记住的体验其实是：
- **Challenge**：每回合都在算乘区、控风险、抉择路线；
- **Discovery**：总能挖到新联动；
- **Expression**：不同玩家会走出截然不同的牌组哲学；
- **Submission**：一旦理解系统，又会进入极强的“再来一把”节奏。

TouchArcade 对开发者 LocalThunk 的采访很关键，他明确提到 demo 期间的社区反馈和反复迭代，直接把游戏打磨成今天这个策略结构。这说明：
**MDA 不是开会脑补完就结束，必须拿真实玩家验证 Dynamics 是否真的长出来。**

### 五、把 MDA 真正用起来，要走这条四步法
#### 第一步：先写“体验句子”，别先写功能列表
错误写法：
- 做 8 种塔
- 做 30 个词条
- 做 3 个 Boss
- 做科技树

正确写法：
- 玩家应该在 3 分钟内感受到“激光流派开始成型”；
- 玩家应该在每波结束后做一次高价值取舍；
- 玩家应该在失败时觉得“我知道下把怎么优化”；
- 玩家应该在爆发时刻明显感到屏幕被自己掌控。

先把这些体验句子写对，后面系统才不会歪。

#### 第二步：把体验句子翻译成 Dynamics
比如《光与朽》目标体验是“高压解题 + 爽快清屏 + 搭配发现”，那应该对应的 Dynamics 是：
- 玩家会在敌人抗性和波次压力下临时换思路；
- 玩家会为了成型某条流派，主动做取舍而不是无脑全拿；
- 玩家会在某个 build 爆发后期待下一轮更夸张联动；
- 玩家失败时能定位问题是输出不足、控场不够还是经济崩了。

如果你设计出来的实际 Dynamics 是：
- 玩家只在等 CD；
- 玩家只在赌随机；
- 玩家看不懂输因；
那就说明 Mechanics 根本没服务到目标体验。

#### 第三步：最后才落 Mechanics
为了让上面的 Dynamics 成立，Mechanics 应该怎么配？
- 升级奖励必须三选一，保证取舍；
- 核心词条要有流派标签，保证 build 可理解；
- 敌人设计要有明确克制关系，逼玩家读局势；
- Boss 前必须给一次重构或补救窗口，避免纯脸死局；
- 爆发技能、音效、震屏、激光粗细变化要和关键强度阈值绑定，强化爽感识别。

注意重点：
**同一个 Mechanics，如果不能稳定导出你要的 Dynamics，它就是废机制。**

#### 第四步：用埋点和观察验证 Dynamics，不要靠拍脑袋
MDA 真正落地后，验证重点不该只是“玩家觉得好不好”，而是：
- 玩家有没有在第 5 分钟前做出第一次真正的取舍？
- 玩家失败后能否明确说出失败原因？
- 玩家会不会主动讨论 build，而不是只抱怨数值？
- 玩家在某一波是否出现明显的爽点峰值？

建议埋点：
- `first_build_branch_chosen`
- `first_core_synergy_online`
- `boss_fail_reason`
- `reroll_used`
- `screen_clear_peak`
- `daily_challenge_reentry`

### 六、给《光与朽》的直接应用方案
#### 方案 A：先定义《光与朽》的主美学，不准继续散
《光与朽》当前最该锁定的 MDA 目标：
- **主美学：Challenge**，这是骨架；
- **副美学：Sensation**，这是卖点；
- **副美学：Discovery**，这是复玩理由。

不建议当前阶段把 Narrative 放得太重。因为我们现在最缺的不是故事野心，是一套能让玩家持续想试下一把的可验证玩法闭环。

#### 方案 B：把每个核心系统写成 MDA 卡片
建议之后所有新功能都强制用一张小卡过筛：
- **Mechanics**：它具体改了什么规则？
- **Dynamics**：玩家因此会产生什么行为？
- **Aesthetics**：玩家最终感受到什么？
- **Risk**：可能带来的副作用是什么？

示例，激光反射模块：
- Mechanics：激光命中墙体后可反射 1 次，伤害衰减 20%。
- Dynamics：玩家更愿意卡角度摆位，尝试利用地形扩大覆盖面。
- Aesthetics：产生“聪明布阵”和“清屏连锁”的爽感。
- Risk：若角度收益过高，会导致其他流派失去存在感。

这张卡一写，功能是不是垃圾，一眼就看出来。

#### 方案 C：让“美学目标”决定版本优先级
如果一个新功能不能明显增强 Challenge、Sensation、Discovery 之一，就别急着做。

比如：
- 新塔只是换皮，不增强决策，不要；
- 新词条只是 +5% 攻击，不增强发现感，不要；
- 新 Boss 能逼出新构筑判断，可以做；
- 新事件能让玩家冒险转型，可以做。

**MDA 的真正价值，就是帮你在资源有限时砍掉那些看起来像内容、实际上只是噪音的东西。**

### 七、最终判断
**MDA 不是分析模板，它是项目防跑偏的总开关。**

对我们这种独立项目，最怕的不是点子不够，而是功能越来越多、体验越来越糊。MDA 的狠点在于，它逼你先回答：
- 玩家到底要爽在哪？
- 玩家到底要思考什么？
- 玩家到底为什么愿意再开一局？

只要这三个问题答不硬，系统做再多都是堆垃圾。

### 八、后续执行清单
- 给《光与朽》当前版本写出 1 份总 MDA 目标卡；
- 给塔、敌人、Boss、奖励、局外成长各写 1 张 MDA 卡；
- 每次新功能评审时，强制回答“它服务哪一种美学”；
- 用 3 到 5 名真实玩家测试，验证目标 Dynamics 是否真的出现；
- 若玩家实际行为和预期不一致，优先改 Mechanics，不要先怪玩家不懂。

## 2026-04-19｜补完课题：塔防肉鸽的局外成长与长期留存设计（Meta Progression & Retention Loops）

### 一、先说结论：路线图原始五课题其实已经全部点亮
我检查了 `five_dimensions_expert_roadmap.md` 与当前 `game_design.md`，发现游戏策划维度下原本列出的五个课题已经全部有沉淀：
- MDA 框架
- 游戏爽感设计
- 塔防与肉鸽的心流与随机性控制
- 经济系统与数值模型平衡
- Hook Model 与玩家心理学

所以这次不搞形式主义，直接进入**下一层最该学的延伸课题**：
**塔防肉鸽的局外成长与长期留存设计。**

为什么是它？因为《光与朽》现在最缺的不是再加一个花哨词条，而是把“打一局爽”升级成“愿意连打七天、愿意回来复盘、愿意为了下一次构筑再开一把”的留存骨架。

### 二、核心判断：局外成长不是送糖，是给失败赋值
做烂的局外成长，玩家会觉得：
- 失败也能变强，所以我只是刷数值；
- 前几局很痛苦，后面才开始好玩；
- 不肝就被卡死；
- 每次回主界面都像在领低保。

做得好的局外成长，玩家会觉得：
- 这把虽然死了，但我解锁了一个新方向；
- 我不是单纯变强，我是获得了新的理解工具；
- 下把我要试另一套 build；
- 失败不是浪费，是推进。

**重点不是“给多少奖励”，而是“失败后让玩家多出一个可执行的新选择”。**

### 三、2024-2026 的案例共识

#### 1）《Hades / Hades II》证明：局外成长最值钱的是“叙事回城 + 稳定小进展”
从 2025 年 Supergiant 围绕《Hades II》的公开访谈与 GamesRadar 总结可以看出，团队一直坚持高度迭代，而不是先写死一套冗长总设计。这背后有个关键：
**他们把主基地做成情绪缓冲区与叙事结算区。**

玩家回城后会获得三种补偿：
- 资源推进，哪怕输了也不是空手；
- 新对话、新关系、新目标，降低失败沮丧；
- 下一轮的轻微确定性提升，而不是无脑战力膨胀。

这套东西之所以狠，是因为它把“失败返回大厅”从惩罚，改成了**情绪再启动器**。

**对独立项目的启示：**
你不一定做得起《Hades》的海量文本，但必须学它的结构：
- 回城后一定有 1 个资源兑现；
- 一定有 1 个新信息或新目标；
- 一定有 1 个“下把可尝试的新方向”。

#### 2）《Balatro》证明：长线耐玩不一定靠重局外成长，关键是“持续开新理解”
TouchArcade 采访和 LocalThunk 的开发时间线都反复说明一个事实：
**《Balatro》真正抓人的不是传统意义上的重养成，而是源源不断解锁新 Joker、新牌组目标、新挑战，从而持续扩大玩家的“组合想象空间”。**

它很克制，没有把局外做成粗暴数值加法，而是做成：
- 新内容解锁；
- 新挑战难度；
- 新牌组实验机会；
- 玩家自己给自己立目标。

这说明一个非常重要的设计原则：
**局外成长可以不重数值，但不能不重“可能性密度”。**

玩家不一定需要 +20% 伤害，他们更想要：
- “这次我终于能玩折射流了”；
- “我想试试低经济高暴击打法”；
- “我知道这个稀有模块配哪个核心会爆”。

#### 3）《The Last Spell》证明：Meta 重做时，开发者真正修的是“开局可玩性”和“流派可达性”
《The Last Spell》在官方 Steam 公告里公开做过 Meta Rework，这个动作本身已经说明问题：
**局外成长不是越多越好，做坏了必须推倒重来。**

社区后续对新 Meta 的认可，集中在两个点：
- 早期武器和策略选择更快成型；
- Omen/局前修正让地图间的体验差异更明确。

也就是说，优秀的局外成长不是让你把旧问题刷过去，而是：
- 让你更早进入真正有趣的决策；
- 让不同路线更快可玩；
- 让每局前的准备本身就有策略味。

#### 4）《Tower Dominion》《Isle of Arrows》《Emberward》给塔防肉鸽的直接信号
结合我们知识库已有拆解和 2025 年公开资料，可以提炼出塔防肉鸽的几条现实规律：
- **《Tower Dominion》** 强在英雄/阵营/Doctrine 做开局流派锚点，证明塔防局外系统最值钱的是“起手方向”，不是纯数值；
- **《Isle of Arrows》** 强在模式、公会、每日挑战，把同一核心循环拆出高复玩结构；
- **《Emberward》** 的玩家反馈反而提醒我们，若天赋解锁过快或过浅，长期驱动力会掉，局外系统会显得“有，但不够撑”。

### 四、长期留存设计的 6 条铁律

#### 铁律 1：局外成长优先解锁“选项”，再解锁“强度”
正确顺序：
1. 新流派入口
2. 新修正工具
3. 新挑战规则
4. 最后才是基础数值加成

如果一开始就大量发基础攻击、血量、金币加成，短期舒服，长期会出两个问题：
- 新手以为自己在进步，其实只是系统帮打；
- 设计师后面只能继续加怪血，最终进入通胀地狱。

**更高级的做法**：
- 解锁新的核心模组
- 解锁 reroll、锁定、预览、定向掉落这类控盘权
- 解锁新地图规则、新事件、新敌人词缀

也就是说，先给玩家更多“脑子”，再给更多“面板”。

#### 铁律 2：每次失败后，必须至少兑现一种进展
失败结算页至少要给玩家 3 选 2 的感受：
- 我拿到了可见资源；
- 我解锁了新东西；
- 我获得了对失败原因的清晰解释。

只给资源，不解释失败，玩家会麻木；
只给解释，不给资源，玩家会空；
只给解锁，不让下把快速试，玩家会拖。

#### 铁律 3：首小时内必须出现第一次“未来想象”
玩家在前 30 到 60 分钟内，必须看到一个明显钩子：
- 某个未解锁流派轮廓；
- 某个强力模块剪影；
- 某种特殊地图或挑战模式；
- 某个明显能改变打法的局外节点。

**没有未来想象，就没有长期留存。**
玩家不会为了“再多 2 点攻击”留下来，但会为了“我快能玩到那套折射灼烧流了”留下来。

#### 铁律 4：局外树必须服务局内节奏，不许反客为主
局外系统的职责，是让玩家更快触达局内真正有趣的决策。

如果局外树让玩家在大厅里点 5 分钟、进局里打 8 分钟，那就是本末倒置。
对塔防肉鸽尤其如此，真正的爽点应该在战斗、构筑、读波次，而不是主界面点科技树。

#### 铁律 5：高价值节点要尽量提供“风格分化”而不是“纯效率提升”
差的节点：
- 初始金币 +50
- 基础伤害 +5%
- 建造价格 -3%

好的节点：
- 开局可携带一个流派核心
- 每局第一次刷新免费
- Boss 前额外获得一次重组选项
- 冰冻类词条出现概率提高，但灼烧类略降

后者会把玩家推向不同玩法身份，而不是都走同一条最优解。

#### 铁律 6：Daily / Weekly 挑战是独立团队最划算的长线留存器
重内容更新很贵，但固定题面挑战很便宜。
优秀的塔防肉鸽可以复用已有资源，做出：
- 每日固定波次组合
- 每周限定起手模组
- 固定地图词缀
- 排行榜或好友对比

这样既提高复玩，也给社区截图、讨论、复盘提供燃料。

### 五、给《光与朽》的直接落地方案

#### 方案 A：把局外成长拆成三层，不要混成一锅粥
**第一层，解锁层（长期目标）**
- 解锁新核心模组：折射、过载、灼烧、冻结、连锁
- 解锁新事件、新地图规则、新敌人词缀
- 解锁新挑战模式与每日试炼

**第二层，控盘层（中期留存）**
- 初始 1 次免费刷新
- 升级奖励锁定 1 个选项
- 预览下一波敌人标签
- Boss 前免费重构 1 次

**第三层，保底层（轻数值补偿）**
- 微量初始金币
- 微量基地护盾
- 微量资源掉落修正

重点：第三层只能当润滑剂，不能当主体。

#### 方案 B：把“失败返回”做成三连击
每次失败后主界面必须连续给到：
1. **资源到账**，让玩家知道这把没白打；
2. **失败诊断**，比如“第 7 波漏怪主因：AOE 不足 / 单体不足 / 路径效率差”；
3. **下把建议**，比如“建议尝试冻结系控制”或“建议先解锁免费刷新节点”。

这会极大提升复盘意愿。

#### 方案 C：把科技树从“数值树”改成“风格树”
建议《光与朽》的局外树优先围绕以下 4 个方向：
- **激光操控系**：折射、穿透、过热、共振
- **控场系**：减速、冻结、定身、聚怪
- **经济系**：资源转化、补给箱、事件收益、刷新优化
- **救场系**：护盾、应急炮台、Boss 前重构、残血补救

每个分支都应该改“玩法习惯”，而不是只改数值大小。

#### 方案 D：首周留存抓手，做这三个就够狠
1. **每日试炼**：固定地图 + 固定核心 + 排行榜
2. **周挑战词缀**：例如“激光反射次数 +1，但建造位 -2”
3. **局外收藏册**：记录已发现的核心组合、敌人克制、通关流派截图

这三件事都便宜，但能让玩家从“打一局”升级成“研究这个游戏”。

### 六、风险提醒
1. **别把局外成长做成硬门槛。** 如果玩家必须刷 10 局才有资格开始真正爽，那这设计就是垃圾。
2. **别让数值节点吞掉流派差异。** 一旦大家都只点通用攻击和金币，系统就废了。
3. **别让每日挑战只是重复上班。** Daily 必须有固定题面与可讨论性，不然只是例行公事。
4. **别让回城流程太长。** 失败后 30 秒内必须能再次开局，不然节奏断得厉害。

### 七、最终结论
**塔防肉鸽的长期留存，核心不是让玩家变得越来越强，而是让玩家越来越会玩、越来越想试、越来越能复盘。**

《光与朽》接下来最该补的，不是更多普通升级词条，而是：
- 开局流派锚点
- 失败后的清晰复盘
- 控盘型局外能力
- Daily / Weekly 挑战骨架

把这四刀砍对，我们的游戏才会从“能玩”跨到“能留”。

## 2026-04-24｜游戏策划下一课题：上瘾模型（Hook Model）与玩家心理学，如何打造高留存率

### 一、为什么这就是当前“下一个未攻克课题”
对照 `knowledge/five_dimensions_expert_roadmap.md` 的游戏策划路线，前面几个点里，`game_design.md` 已经沉淀了：
- MDA 框架应用
- 游戏爽感设计（Game Feel）
- 塔防与肉鸽的心流与随机性控制
- 经济系统与数值模型平衡
- 塔防肉鸽的长期成长与局外循环

因此，当前路线图下一个还没系统攻克的细分课题，顺位就轮到：
**【专家】上瘾模型（Hook Model）与玩家心理学，如何打造极高留存率。**

这课题值钱的原因很直接：
《光与朽》现在不缺“能玩”的底子，缺的是“为什么玩家第二天还回来、为什么输了还想再开一把、为什么愿意持续研究 build”。这不是单纯数值问题，而是**触发、行动、奖励、投入、复盘、身份感**这一整套心理回路问题。

### 二、核心判断：高留存不是把玩家困住，而是让玩家形成“低摩擦回访 + 持续成长预期”
Nir Eyal 的 Hook Model 本质是四步：
1. **Trigger（触发）**
2. **Action（行动）**
3. **Variable Reward（可变奖励）**
4. **Investment（投入）**

Amplitude 对这个模型的整理很清楚，重点不在一次性刺激，而在让用户逐渐从“外部提醒”切换到“内部触发”，也就是从“别人叫我来玩”变成“我自己会想回来看看”。

但游戏里如果只学“钩子”表皮，最后很容易做成垃圾黑盒子。真正能打长期留存的，是下面这条更硬的公式：

**留存 = 内部动机（我想玩） + 低摩擦回访（我容易回来） + 可解释成长（我知道自己在变强/变懂） + 适度不确定性（我期待下一次）**

少了任何一环，都容易塌：
- 只有奖励，没有成长理解，玩家会疲劳；
- 只有成长，没有不确定性，玩家会觉得枯燥；
- 只有 streak 和 loss aversion，没有真实价值，玩家会厌烦甚至反感；
- 只有随机爽点，没有长期投入位，留不住人。

### 三、心理学底层，不是“骗”，是三大需求的持续满足
根据 Self-Determination Theory（自我决定理论）及其在游戏研究中的延展，长期驱动玩家回来的核心不是单一奖励，而是三种心理需求被持续满足：

#### 1. 自主性（Autonomy）
玩家需要感觉“这是我自己做出的选择”，而不是被系统推着走。
- 三选一升级为什么常青？因为它在低理解成本下给了自主性。
- 可控刷新、奖励锁定、Boss 前重构，都是在提升自主性。

#### 2. 胜任感（Competence）
玩家必须感觉自己越来越会，而不是越来越麻。
- Hades 这类作品之所以强，不只是因为 repeated runs，而是因为每次死亡都会带来更高的系统理解和更稳定的推进感。
- Greg Kasavin 提到，roguelike 即使“全部重置”，玩家依旧会带走对系统的理解，这个“知识永久继承”就是胜任感的重要来源。

#### 3. 关联感（Relatedness）
即使是单机游戏，也能通过排行榜、挑战题面、流派分享、截图传播建立弱社交关联。
- 玩家不一定需要公会，但很需要“我这把思路很秀，值得发出来”。
- Daily/Weekly 挑战、流派图鉴、通关结算分享卡，本质都在做这个层面的轻社交拉力。

### 四、Hook Model 在游戏里真正该怎么用

#### 1. Trigger：别只靠推送，优先做“内部触发”
外部触发包括：
- 红点
- 推送
- 每日奖励
- 体力回满
- 限时活动

但真正强的是内部触发：
- “昨天那套激光反射 build 只差一点就成型”
- “我知道自己第 6 波死因了，想马上再试一把”
- “今天每日题面我想验证新解法”

**结论：推送只能拉回一次，未完成的心理闭环才能拉回很多次。**

#### 2. Action：回流后的第一步必须极短
玩家被拉回来后，如果要点 6 个界面、领 4 个包、关 3 个弹窗，热度立刻掉光。

高留存产品的共性是：
- 进入后 10 秒内能开玩
- 失败后 20~30 秒内能重开
- 奖励领取流程高度压缩

对《光与朽》来说，这意味着：
- 主界面不要堆太多运营入口
- 失败结算后优先给“再来一把”主按钮
- 科技树、装备、活动都必须让位于“快速回局”

#### 3. Variable Reward：奖励要有变化，但必须可解释
可变奖励不是简单“随机掉好东西”，而是让玩家在不确定中持续看到希望。

Nir Eyal 将变动奖励分为三类，这套框架非常适合游戏化：
- **Tribe（部落奖励）**：被看见、被认可、排行、晒成绩
- **Hunt（猎取奖励）**：掉落、资源、稀有词条、隐藏事件
- **Self（自我奖励）**：进度、 mastery、收藏完成、打法成型

真正强的游戏，往往三种一起用：
- 《Balatro》靠新 Joker、新乘区、意外联动驱动猎取奖励；
- 《Hades》靠剧情推进、角色反馈、神祇关系提供部落/叙事型奖励；
- Daily 挑战和榜单则强化外部比较与展示欲。

但有个铁律：
**奖励必须让玩家能复盘“为什么值”，否则就会从惊喜变成纯抽奖。**

#### 4. Investment：玩家每次离开前，都要留下点什么
Investment 不是单指充值，而是玩家在当前循环里留下对下一次有价值的投入。

可用的投入包括：
- 解锁一个新模块
- 收藏一个新组合
- 学会一个敌人克制关系
- 保存一套 build 思路
- 提升一次局外控盘能力
- 积累一次接近成功的心理张力

最烂的设计，是玩家打一局后什么都没留下。
最好的设计，是玩家退出时脑子里还有一句：
**“下把我已经知道要怎么打了。”**

### 五、2024-2026 可参考的最新案例与启发

#### 案例 1：《Balatro》
这游戏能把人狠狠干上头，不是因为它像赌博，而是因为它把“低门槛行动 + 高频可变奖励 + 清晰的乘区理解”焊死在一起。
- 进局快，决策快，结算快；
- Joker 和强化牌不断制造“下一张可能翻盘”的期待；
- 每次爆分都能清晰理解是哪个组合生效，不是纯玄学；
- Run 失败后，玩家仍带走对牌型、乘区、商店节奏的理解。

**可学点：** 可变奖励必须绑定“我能学会它”，这样玩家才会把随机当成研究，而不是当成彩票。

#### 案例 2：《Hades》与《Hades II》迭代思路
Supergiant 的强点不是“重复跑图”，而是把每次失败都改造成叙事推进与知识沉淀。
- Boss 和记住你上次的表现，形成连续感；
- 死亡不只是失败，而是剧情节点；
- 局外对话、角色关系、武器尝试，让回城本身也有奖励。

Greg Kasavin 明说过，roguelike 虽然重置一切，但玩家会带着对系统的知识继续前进。**这说明高留存的关键不是“保留资源”，而是“保留意义”。**

#### 案例 3：Duolingo 的 streak 机制（跨行业可借鉴）
虽然不是游戏，但它对“每日回访”的研究非常狠。
- streak 让连续行动被可视化；
- streak freeze / repair 这类 forgiveness 机制，避免一次断签直接把人劝退；
- 小胜利动画、即时反馈、每日目标自定义，共同降低挫败感。

公开案例提到，类似 streak wager 的设计能明显提升短中期留存，但 2025 年不少分析也在强调：**如果只剩 loss aversion，产品就会从“习惯”滑向“负担”。**

**可学点：** 连续登录奖励可以做，但必须配“补签、缓冲、可恢复”机制，别把玩家辛苦培养成怨种。

#### 案例 4：2025 年关于 hot streak 伦理设计的讨论
UX Magazine 2025 的文章专门提醒了一点，特别重要：
- streak 的力量来自 loss aversion，玩家害怕失去已经积累的东西；
- 但目标应该是 sustainable habit formation，而不是 psychological dependence。

这句话翻成人话就是：
**好设计让玩家因为“我还想继续”回来，坏设计让玩家因为“我不敢断掉”回来。**

我们应该学前者，不碰后者。

### 六、把高留存拆成 6 条可执行铁律

#### 铁律 1：每次回流后，10 秒内必须进入有效玩法
- 打开游戏 -> 立刻看见继续 / 开始 / 今日挑战
- 不要先塞签到、礼包、弹窗、公告
- 任何运营入口都不能挡在主玩法前面

#### 铁律 2：每一局都要留下“下一局理由”
局内结束时，至少要给到以下之一：
- 我解锁了新东西
- 我发现了新组合
- 我明白了这把怎么死的
- 我知道下把该试什么

如果四个都没有，这局基本白打。

#### 铁律 3：随机奖励必须服务流派想象，而不是服务抽卡刺激
好的随机奖励会让玩家想：
- “这把能不能走反射灼烧流？”
- “如果下轮再来一个穿透，我就成了。”

坏的随机奖励只会让玩家想：
- “看脸吧。”

#### 铁律 4：连续奖励必须有“宽恕机制”
- 连签断了能补
- 周挑战漏一天不至于报废
- 日常任务可以囤一点，不要日清零过猛

宽恕机制不是心软，是降低流失。

#### 铁律 5：失败后优先给“解释”，再给“资源”
资源只能短暂安慰，解释才能提升胜任感。
结算页最好直接告诉玩家：
- 漏怪主因是什么
- 当前 build 短板是什么
- 推荐下把尝试什么方向

#### 铁律 6：让玩家能展示自己的理解
- 每日题面通关截图
- Build code / 流派总结
- 结算页高光数据
- 周榜单与好友排行

人会因为“我这把很秀”而回来，也会因为“我想证明我会玩”而回来。

### 七、给《光与朽》的直接落地方案

#### 方案 A：把回访触发从“签到”改成“未完成 build”
现在最值得做的不是重签到，而是：
- 上局失败后在结算页标记“差一件即可成型”的核心词条
- 回到大厅时展示“推荐继续尝试：反射 / 穿透 / 冻结控场”
- 给一个“沿用上把思路再开一局”的快捷入口

这会比生硬签到更高级。

#### 方案 B：做轻量 streak，但一定配宽恕
可做：
- 连续挑战奖励
- 3 日 / 7 日 / 14 日小目标
- 每周试炼进度

必须同时做：
- 补签一次
- 漏一天不崩盘
- 部分进度自动保留到周末

否则就是逼退轻度玩家。

#### 方案 C：失败结算页改成“复盘页”
至少补三块：
1. 本局最高伤害来源
2. 本局崩盘主因（AOE 不足 / 单体不足 / 控场不足 / 经济断档）
3. 下局推荐流派或补丁建议

这会直接提升胜任感和复玩率。

#### 方案 D：Daily / Weekly 挑战优先上“固定题面”
别只做重复任务，做：
- 固定地图
- 固定起手塔
- 固定核心词条
- 特殊词缀限制

这样玩家回来不是打卡，而是解题。

#### 方案 E：把局外成长分成“控盘层”与“数值层”
优先升级的应该是：
- 奖励锁定
- 刷新优化
- 波次预览
- Boss 前重构

这些会提高自主性与策略感；
纯攻击、防御、金币加成只能做润滑，不能做主菜。

### 八、最大风险提醒
1. **别把留存理解成日活绑定。** 日活只是结果，不是设计目标。
2. **别迷信 loss aversion。** 它能拉回人，也能把口碑狠狠干烂。
3. **别让随机奖励失去解释性。** 一旦玩家感到全看脸，留存会塌。
4. **别让大厅比局内更忙。** 真正的粘性来自玩法，不来自运营噪音。
5. **别把长期投入全做成数值树。** 真正能留人的，是流派身份与 mastery，不是攻击+3%。

### 九、最终结论
**高留存游戏的本质，不是让玩家被迫回来，而是让玩家每次离开时都带着一个“我下次还想验证的念头”。**

对《光与朽》来说，当前最该补的不是更重的签到系统，而是这四刀：
- 失败复盘
- 未成型 build 提示
- 可控随机的局外能力
- 固定题面的 Daily / Weekly 挑战

把这四件事做好，我们拿到的不是廉价日活，而是更健康的中长期留存。

## 2026-04-25｜游戏策划下一课题：首局教学与首小时可玩性（FTUE & First-Hour Session Loop）

### 一、为什么这就是当前真正该啃的“下一个未攻克课题”
我先对照了 `knowledge/five_dimensions_expert_roadmap.md` 和现有 `game_design.md`。
路线图原始五个课题——MDA、爽感、塔防肉鸽随机控制、经济系统、Hook Model——实际上都已经有沉淀。继续假装“下一个还是原路线图里的旧点”，那就是自欺欺人。

所以这次我直接往**游戏策划维度的下一层延伸能力**推进：
**首局教学与首小时可玩性（FTUE & First-Hour Session Loop）**。

原因很简单：
- 《光与朽》现在不是没有系统，而是**系统价值暴露得太慢**；
- 玩家不是没耐心，而是**前 10 分钟没看到“这游戏真正好玩的地方”**；
- 后续无论做买量、陌生用户测试、Demo 转化，最先决定生死的都不是深度，而是**首小时能不能让人看懂、爽到、想再来一把**。

一句话：
**首小时不是教学阶段，而是你向玩家证明“这游戏值得继续玩”的唯一窗口。**

### 二、核心判断：FTUE 不是把按钮教完，而是让玩家在最短时间内形成“我会、我爽、我想再试一次”
很多独立游戏把新手引导做成说明书，这是最蠢的死法。
真正有效的 FTUE，至少要同时完成三件事：

1. **理解成本被压低**：玩家知道自己现在该干嘛；
2. **价值时刻提前出现**：玩家在首局内看见一次系统成型或翻盘；
3. **失败后还能自我解释**：玩家输了也知道“下把该怎么改”。

所以首小时设计的本质不是“教学”，而是三段式：
- **教最少的必要规则**；
- **尽快给一次高质量结果反馈**；
- **让下一局理由自然生成**。

如果玩家打完首局只得到“我懂操作了”，那还不够；
必须让他得到：
**“卧槽，我已经看到这游戏后面会好玩在哪。”**

### 三、2024-2026 的最新案例与启发

#### 案例 1：Unity 对早期留存设计的提醒——留存要在概念期就内建，不是上线后补丁
通过 DuckDuckGo 检索到 Unity Learn 的教程 *How to build in retention and player engagement as part of your early concept*，其摘要非常明确：
> 在主开发阶段之前，就要先理解玩家参与度与留存，把这些指标和功能直接写进概念设计里。

这句话值钱的点在于：
**早期留存不是运营层补丁，而是核心循环结构问题。**

翻成人话：
- 如果首局没有“明天回来还有推进”的心理预期，后面再加签到都很难救；
- 如果首小时没有形成一个可记忆的系统爽点，再多活动都只是遮羞布；
- 如果新手阶段没有埋点，你根本不知道玩家是看不懂、嫌慢、还是爽点来得太晚。

对我们特别关键的启发：
**从立项开始就要定义“首小时成功条件”。**
不是“完成了教程”，而是：
- 是否完成第一次有效构筑？
- 是否经历一次明确翻盘？
- 是否理解一种核心打法标签？
- 是否愿意马上开第二局？

#### 案例 2：《Hades II》——优秀首小时不是短，而是“随时能快速进入有效玩法”
我读取了 `Hades II` 的 Steam News Feed。Supergiant 在 2025 年相关公告里反复强调一件事：
> 他们希望《Hades II》是那种“可以很快拿起来开玩，无论只玩几分钟还是长时间游玩都成立”的游戏。

这不是宣传废话，而是极硬的设计哲学：
**首局和回流都必须低摩擦。**

更狠的是，后续补丁里他们持续在修这种“低摩擦理解”：
- `Resources obtained using Gathering Tools now offered more consistently`
- `Reward preview icon when entering Locations just before a Region's Guardian`
- `Updated Path of Stars menu selection art to make unpicked upgrades easier to see`
- `You may now skip most of the narrated Homer outcomes after a successful clear`

这几条合起来说明什么？
不是单纯优化 UI，而是在做四件事：
1. **降低信息识别成本**；
2. **提前暴露关键回报**；
3. **减少结算与叙事对重开节奏的阻塞**；
4. **让“继续玩”比“看说明”更顺手。**

也就是说，顶级产品连中后期补丁都还在狠狠干首小时体验。

#### 案例 3：《The Last Spell》——首小时要尽快建立“有差异的解法”，而不是让玩家只会重复一种防守
我读取了 `The Last Spell` 的 Steam RSS。2026 年 1.3 大更新里有几条非常值钱：
- 开发者直说：过去防御建造有些 **too one-dimensional**；
- 为此把 Ballista 从单一路线，改成了 **Mounted / Heavy / Split** 三种不同强化；
- 同时加入全局防御升级，让防御手段在后期依旧能扩展；
- 还重做了 `Corpse Piles vs Panic`，避免玩家为了收益采用反直觉玩法；
- 并提升了 B/S 夜晚奖励，使前中期投入更快得到正确回报。

这背后的设计逻辑非常硬：
**首小时最怕的不是内容少，而是“解法单一 + 奖励信号错误”。**

如果玩家前几局学到的是：
- 只要堆同一种防御；
- 反直觉行为反而收益更高；
- 不知道系统为什么给这个奖励；
那他首小时建立起来的就是坏模型，越玩越歪。

所以优秀首小时不是把系统藏着慢慢给，而是尽快让玩家看到：
**“哦，原来不同选择真的会导向不同打法。”**

#### 案例 4：结合我们既有知识，对《Balatro》的补充理解——首小时必须尽快出现“规则理解换来高回报”的时刻
虽然这次外网抓取对部分站点受限，但结合知识库里已积累的《Balatro》相关资料，可以提炼出一条很关键的规律：
《Balatro》首小时抓人的核心，不是内容量，而是：
- 规则入口极窄；
- 决策回报极快；
- 很早就能打出一次“我好像悟了”的乘区爆发；
- 失败后不是羞辱，而是留下改法。

这正说明：
**首小时最值钱的体验，不是把所有深度讲完，而是给玩家一次“我理解系统后，结果真的变强了”的证据。**

### 四、首小时设计的 6 条铁律

#### 铁律 1：首局只教“活下来并看到爽点”所必须的东西
不要在首局塞：
- 全部塔种
- 全部词条机制
- 全部局外系统
- 全部敌人说明

首局真正该教的只有：
- 我现在怎么活；
- 我这次选择为什么重要；
- 什么叫一次有效 build 成型；
- 爆发反馈长什么样。

**先让玩家爽着理解，别让玩家理解着犯困。**

#### 铁律 2：首 5~10 分钟必须出现一次“系统价值被看见”的时刻
对动作游戏来说可能是一次反杀；
对卡牌游戏是一次高乘区；
对塔防肉鸽，则应该是：
- 某条流派第一次明显成型；
- 某种防守布局第一次明显奏效；
- 某次高压波次被漂亮化解。

没有这个时刻，玩家只会觉得自己在做准备，而不是在玩核心乐趣。

#### 铁律 3：首小时必须尽快建立“至少两种可感知解法”
如果玩家首小时只学会一种正确玩法，他后面很容易把游戏理解成死题。

首小时应该尽快让玩家感知到：
- 这是输出路线；
- 这是控场路线；
- 这是稳扎稳打路线；
- 这是高风险高收益路线。

不一定全部开放，但至少要让玩家看到“不同选择确实会导向不同结果”。

#### 铁律 4：奖励必须服务理解，不要制造误导
错误奖励：
- 奖励了反直觉行为；
- 奖励只给数值，看不出原因；
- 玩家拿了好东西却不知道为什么强。

正确奖励：
- 奖励和当前策略明确挂钩；
- 奖励能立刻在下一波体现；
- 玩家能说出“这次变强是因为什么”。

#### 铁律 5：失败后 30 秒内必须能再开，并且知道下把该改哪
顶级产品都在做“低摩擦重开”。
玩家死后不能经历：
- 一长串教学结算；
- 一堆无意义领奖；
- 一堆看不懂的成长树；
- 一堆只会拖慢重开的 UI。

失败页最值钱的是三样：
1. 失败原因；
2. 本局最强环节；
3. 下局建议。

#### 铁律 6：首小时埋点要盯“关键行为”，不是只盯 D1 留存
至少要看：
- 是否完成首个 build 分叉；
- 是否打出首个高光波次；
- 是否用了刷新 / 重构；
- 是否在首败后重开；
- 是否在 15 分钟内进入第二局；
- 玩家首退点在第几分钟、第几波。

不看这些，首小时优化全是瞎猜。

### 五、给《光与朽》的直接落地方案

#### 方案 A：把首局目标从“教学通过”改成“10 分钟内体验一次成型 Build”
建议首小时强制保证玩家至少见到以下之一：
- 激光反射连锁
- 穿透清线
- 灼烧叠伤
- 冻结控场拖波

不是每种都要见到，而是至少见到一种明确成型。

#### 方案 B：把早期升级改成“稳 / 补 / 赌”三栏
每次三选一尽量固定为：
- 1 个当前路线强化
- 1 个补短板选项
- 1 个转型或高风险选项

这样首小时就会出现“我在构筑”，而不是“我在领工资”。

#### 方案 C：第一个 Boss 前必须给一次清晰重构机会
首小时最怕死于坏随机。
Boss 前建议固定给：
- 一次免费刷新；
- 或一次词条锁定；
- 或一次低成本重组选项。

让玩家觉得自己是在解题，不是在等死。

#### 方案 D：失败页必须改成复盘页
至少展示：
- 漏怪主因（AOE不足 / 单体不足 / 控场不足 / 资源断档）
- 本局最高贡献模块
- 推荐下一局优先方向

这会直接把“首败流失”改成“首败再试”。

#### 方案 E：大厅到重开全流程压到 20~30 秒内
目标不是花哨，而是：
- 失败 -> 结算 -> 复盘 -> 再来一局
一路没有废步骤。

如果以后做活动、任务、养成，也必须让位于“先开局”。

### 六、给我们当前项目的最终判断
**《光与朽》现在最该补的，不是再加一个新词条，而是把首小时变成“看得懂、打得爽、输得明白、愿意重开”的闭环。**

我建议版本优先级直接这么排：
1. 首局 10 分钟内保底成型一次流派
2. 失败复盘页
3. Boss 前重构窗口
4. 首小时关键行为埋点
5. 大厅到重开流程瘦身

这五刀砍完，再谈更深的长期留存。首小时烂，后面全白搭。

## 2026-04-27｜游戏策划下一课题：遭遇设计与难度曲线编排（Encounter Design & Difficulty Pacing）

### 一、为什么这就是当前真正该补的“下一个未攻克课题”
我先核过现有知识：`game_design.md` 已经覆盖 MDA、爽感、塔防肉鸽随机控制、经济系统、Hook Model、局外成长、FTUE/首小时可玩性。再往下走，最缺的就不是“再加一个理论词”，而是把**每一局到底怎么起、怎么抬压、怎么给喘息、怎么进 Boss、怎么让失败可复盘**这套遭遇编排骨架补齐。

这点对《光与朽》尤其关键。我们现在真正缺的，不是玩法标签，而是：
- 前 3 波怎么保底出爽点；
- 第 4~7 波怎么逼出真正决策；
- Boss 前怎么给一次补救窗口；
- 后期怎么抬难度而不把前期一起搞死。

一句话：
**玩法决定你是什么游戏，遭遇编排决定玩家愿不愿意连续再开三把。**

### 二、核心结论：难度曲线不是一路上扬，而是“压力峰谷 + 学习窗口 + 决策兑现”
结合近期行业资料，遭遇设计有三个硬结论：

#### 1）好曲线几乎都不是直线，而是锯齿曲线（saw curve）
Mobile Game Doctor 在 2025 年关于关卡制作的文章里讲得很直接：很多团队会把进程设计成 **peaks and valleys**，也就是一段抬压、一段释放，再一段更高压；Boss 是峰值，新机制引入后应给一两个低压学习关。

这条看似基础，实际上值千金：
- 如果只往上抬，玩家会疲劳；
- 如果一直平，玩家会无聊；
- 如果峰后不回落，玩家学不到东西，只会觉得系统在掐脖子。

**节奏不是“越来越难”，而是“越来越会，同时越来越敢给你更狠的题”。**

#### 2）Roguelike / Roguelite 常见的是“逆向难度曲线”，所以基础盘绝不能乱动
Game Developer 关于逆向难度曲线的分析指出，很多 roguelike/随机游戏其实是**开局最脆、知识最少、容错最低**，随着玩家理解与构筑成型，体感难度反而下降。

最要命的坑在这里：
- 如果你为了打击后期强度，去全局提高惩罚；
- 这些改动会先狠狠干死新手和前期；
- 最后后期老玩家照样能靠知识和成熟 build 扛住，只有前期体验被毁。

文章用《Darkest Dungeon》的平衡问题举例，本质是在提醒：
**先锁定开局基础盘，再用中后段额外变量、Boss 机制、精英波次、后期词缀去拉高上限。别动不动全局加压。**

#### 3）遭遇的价值，不只是难，而是逼出不同解法
《The Last Spell》在 2026 的 1.3 更新里，开发者直接承认过去的防御建造有些 **too one-dimensional**，于是把 Ballista 拆成 Mounted / Heavy / Split 三条路线，并重做若干策略信号，避免玩家学到单一正确答案。

这说明一个很硬的原则：
**遭遇设计的目标不是证明系统很难，而是证明不同选择真的会导向不同胜法。**

如果玩家每一局都只学会：
- 同一种摆法；
- 同一种保命节奏；
- 同一种升级优先级；
那不是“稳定”，那是废了。

### 三、2025-2026 可直接拿来用的行业启发

#### 案例 1：Hades II 的可读性与重开节奏优化
近期 Hades II 补丁说明里，有几条特别值钱：
- 新增 **Reward preview icon when entering Locations just before a Region's Guardian**；
- 不断优化未选升级的可读性；
- 强调玩家能很快拿起就开玩。

这不是普通 UI 打磨，而是在做遭遇前置信息设计：
- 玩家在高压节点前先知道下一次冒险值不值；
- 关键奖励不藏着掖着；
- 进高压关前，预期先被建立起来。

**对塔防肉鸽的启示：Boss 前必须让玩家知道“我接下来在赌什么”。**
不是把人闷头推进去，而是让他带着判断进入风险。

#### 案例 2：Balatro 的“学习型压力”
Balatro 相关访谈与社区讨论反复说明一个事实：它的乐趣不是简单涨难度，而是把压力设计成“你理解乘区、牌库、商店节奏后，原本致命的关卡开始变成可计算的题”。

这类设计最值钱的地方在于：
- 玩家输了，但会怪自己决策还不够优；
- 玩家赢了，会明确知道赢因；
- 难度上升和理解深化是同步的。

**最好玩的压力，不是把人打死，而是让人觉得‘我差一点就解出来了’。**

#### 案例 3：Tower Dominion 的三选一波后结构
从 2025 年公开评测和玩家讨论里能看到，Tower Dominion 的波后奖励核心不是“给很多内容”，而是**每波后只给少量关键升级包 / 蓝图 / doctrine 选择**，迫使玩家把地形、路径、塔位和构筑一起考虑。

这说明塔防肉鸽里的遭遇节奏，最怕的是：
- 波与波之间没有结构变化；
- 奖励和下一波压力没有因果；
- 玩家无法把“上一轮拿的东西”立刻用于“下一轮的题”。

真正高级的做法是：
**每次奖励都像给一把工具，下一波马上就让你用。**

### 四、遭遇设计的 7 条铁律

#### 铁律 1：前 90 秒必须出现第一次“可控胜利”
开局不能只是苟活。
玩家必须在极短时间里感受到：
- 某个摆位是对的；
- 某个升级马上见效；
- 某波敌人被自己漂亮化解了。

对《光与朽》来说，这个可控胜利可以是：
- 激光第一次稳定横扫一排；
- 控场塔第一次把快怪拖死；
- 一次低成本补塔成功止血。

如果开局全是被动防守，没有“我做对了”的证据，首局价值就废一半。

#### 铁律 2：每一次新压力，都要配一个学习窗口
峰值前先给理解，理解后再抬压。
例如：
- 先让玩家见到高速怪少量版本；
- 再在下一轮混入高速怪 + 肉盾怪；
- 再进入真正高压波。

别一上来就把克制组合狠狠干脸上。那不叫挑战，那叫蠢。

#### 铁律 3：Boss 前必须有一次“明确补救”
Boss 最适合成为难度峰值，但峰值前一定要给修正口：
- 免费刷新一次奖励；
- 保留一个核心词条；
- 预览 Boss 标签；
- 给一次低成本重构。

这不是放水，这是让失败更像决策失败，而不是随机宣判。

#### 铁律 4：遭遇变化优先改“题型”，再改“血量”
最廉价的难度提升，就是：
- 怪更肉；
- 怪更多；
- 怪更快。

这种东西能用，但只能当底噪，不能当主菜。
更好的题型变化包括：
- 路径分流；
- 护盾怪 + 快怪组合；
- 逼玩家补单体的精英；
- 逼玩家做范围覆盖的散怪波；
- 短窗爆发题和长线续航题切换。

**好遭遇考的是结构理解，不是单纯 DPS 体检。**

#### 铁律 5：峰值后必须回落，但回落不能空
打完一波高压后，要给：
- 轻松一波；
- 明确奖励；
- 构筑兑现；
- 信息整理时间。

回落的职责不是“休息”，而是让玩家重新接线：
“我刚才靠什么活下来，下一步我要押什么。”

#### 铁律 6：后期难度提升要尽量局部化
如果后期太容易，优先加：
- 新敌人机制；
- Boss 多阶段；
- 组合波次；
- 可选危险事件；
- 更苛刻的地图词缀。

少做全局惩罚，不然前期一起陪葬。

#### 铁律 7：失败页必须能映射回遭遇问题
结算别只写“你输了”。
至少要告诉玩家：
- 是哪一类波次压死你的；
- 你缺的是清杂、单体、控场还是经济；
- 你在哪个峰值前没有补齐关键能力。

这样下一把玩家不是盲试，而是带着假设重开。

### 五、给《光与朽》的直接落地方案

#### 方案 A：把前 8 波硬切成“稳—压—喘—Boss前校准”四段
建议先做一版粗骨架：
- **1~2 波：稳** —— 教读局势，保底第一次清屏爽点；
- **3~4 波：压** —— 引入第一个克制结构，逼玩家第一次补短板；
- **5~6 波：喘** —— 给一次中等强度兑现波 + 一次较明显奖励波；
- **7 波：Boss前校准** —— 预览 Boss 标签 + 给一次刷新/锁定/重构；
- **8 波：Boss** —— 单点压力，检验 build 是否成型。

这样首局不是一坨平均难，而是有戏剧张力。

#### 方案 B：给每波敌人贴“出题标签”
内部设计表建议每波强制打标签：
- 清杂题
- 单体题
- 控场题
- 路径覆盖题
- 资源压缩题
- 爆发窗口题

每连续两波不能完全同题型；每个 Boss 前至少提前两波埋一次预告题。

这样后面调平衡时，你调的是题型密度，不是瞎拧数值。

#### 方案 C：把奖励与下一波绑死
升级三选一别只看“这个词条强不强”，要看：
- 它能解下一波什么题？
- 它是补短板，还是放大现有优势？
- 玩家拿完后能否在 30 秒内看到价值？

如果一个奖励两三波后才体感生效，前期就太慢。

#### 方案 D：Boss 前展示“风险—收益—缺口”
进入 Boss 前，界面直接给三个信息：
- Boss 主标签（高速/护盾/召唤/分裂/穿透抗性等）
- 当前 build 优势
- 当前 build 缺口

这是最便宜、最狠的可读性升级。

#### 方案 E：陌生用户测试只看 4 个节点
做 7 天垂直切片测试时，重点记录：
1. 第一次爽点出现在第几秒；
2. 第一次真实压力出现在第几波；
3. 第一次补救窗口有没有被理解和使用；
4. 首败后玩家能不能说出“我为什么死”。

这四个比泛泛问“好不好玩”强太多。

### 六、最终判断
**遭遇设计不是填波次表，而是在安排玩家的情绪、理解和决策。**

《光与朽》现在最该补的不是更多塔，而是把每局的压力曲线做成：
- 开局快速给证据；
- 中段逼出取舍；
- 峰值前给补救；
- 峰值后给复盘理由。

做到了，玩家会说“这把真有戏，我再试一把”；做不到，再多词条都是噪音。

## 2026-04-30｜游戏策划下一课题：敌人题型可读性与反制设计（Enemy Telegraphing & Counterplay Readability）

### 一、为什么它是“下一个未攻克点”
前一层我们已经补到“遭遇设计与难度曲线编排”：知道一局该怎么分峰谷、怎么安排压迫与喘息。但这还不够，因为**波次节奏只回答了“什么时候出题”，没有回答“玩家是否看得懂题、来不来得及做出反制”**。

所以当前真正该继续往下啃的细分课题，不是再泛讲留存，不是再泛讲爽感，而是：
**敌人题型可读性与反制设计（Enemy Telegraphing & Counterplay Readability）**。

它研究的是三件事：
1. 敌人在“出题”前，是否给了足够明确的预告；
2. 玩家是否能在有限认知负荷内，判断“这波危险来自哪里”；
3. 奖励、炮塔、走位、资源重分配，是否真的形成了可执行的反制答案。

这一步对《光与朽》尤其关键。我们现在最怕的不是玩家输，而是玩家**输得糊涂**：看不懂为什么崩、也不知道下把该怎么改，那就不会重开。

### 二、核心结论：难度不等于伤害数值，难度=识别时间 × 决策时间 × 执行窗口
一个敌人或一波怪是否“公平”，不能只看 DPS，而要看三段链路：
- **识别时间**：玩家多久看出这是什么题；
- **决策时间**：玩家多久决定该补哪种短板；
- **执行窗口**：玩家还有没有机会完成操作并看到结果。

只要这三段里有一段太短，玩家体感就不是“我菜”，而是“这游戏阴我”。

换句话说：
**高压可以有，偷袭感不能乱给；失败可以痛，但必须让人复盘得出因果。**

### 三、外部案例与最新启发

#### 1）Game Developer《Enemy Attacks and Telegraphing》
这篇文章给的关键点很硬：**telegraph（预告）不是单一动画，而是动画、音效、语音、特效、震动等多通道共同传递的信息。**

这意味着设计敌人时，不能只在脑子里想“我做了个前摇”，而要问：
- 视觉上是否一眼能区分；
- 音效上是否有危险提示；
- 屏幕忙乱时是否仍能被识别；
- 玩家是否知道“这是该优先处理的东西”。

结论：
**可读性不是美术收尾，而是机制的一部分。**

#### 2）Hades II 官方 Steam 更新（2025-2026 持续迭代）
从其公开更新说明里，能看到 Supergiant 持续在做几类修正：
- 新增进入地点、击杀守关者等信息提示动画；
- 让玩家在选 Boon 时看到更多关键状态信息；
- 给环境伤害与陷阱伤害使用更独立的颜色；
- 明确写出“在激烈战斗中继续提升 visual clarity（视觉清晰度）”。

这说明一个非常重要的事实：
**顶级动作肉鸽到后期仍然把“战斗读懂速度”当核心迭代项。**
不是因为玩家笨，而是因为当构筑、特效、召唤物、场景机关叠起来后，认知负荷会天然爆炸。

对我们最值钱的启发是：
- 后期混乱不是理由；
- 信息层必须分级；
- “当前最危险的东西”必须比“其他热闹信息”更显眼。

#### 3）与上一课“遭遇设计”的衔接
上一课我们已经得出：每波怪都应该有题型，不该只是平均堆数值。
而这一课补的是：
**同样是一道题，玩家如果在 1 秒内看不出题面，就不会把它当策略题，而会把它当事故。**

因此，遭遇编排和可读性必须打包设计：
- 先决定这一波考什么；
- 再决定如何让玩家在最短时间内看懂；
- 最后决定失败后能不能说清自己错在哪。

### 四、可执行设计框架：四层题型可读性模型

#### 第一层：敌人身份可读性（Who）
玩家必须一眼知道“这玩意是什么角色”。

建议按功能而不是按美术主题分敌人原型：
- 冲线型：高速、低耐久、专门偷漏；
- 厚血型：低速、高耐久、吃持续输出；
- 召唤型：自己不一定强，但会拉长战线；
- 护盾型：逼玩家切换伤害结构；
- 远程骚扰型：逼玩家处理后排或覆盖盲区；
- 干扰型：减速、沉默、禁疗、路径污染等。

每一种原型都必须在以下至少两项上形成稳定识别：
- 轮廓
- 主色
- 移动姿态
- 音效
- 血条/状态图标

不要幻想玩家会读百科。**首局能认，才算设计成立。**

#### 第二层：危险来源可读性（What）
玩家不仅要知道“它是谁”，还要知道“它危险在哪”。

比如：
- 高速怪的危险不是血厚，而是穿线；
- 盾怪的危险不是伤害，而是拖时间；
- 召唤怪的危险不是本体，而是把你的火力配比拖垮。

所以危险提示要直指后果：
- 高速怪：前方路径、速度感、冲刺前摇明显；
- 护盾怪：盾牌图标、盾破前后的受击反馈差异明显；
- 召唤怪：召唤倒计时、生成区域、召唤完成前的处理窗口明显。

原则：
**不要只告诉玩家“它厉害”，要告诉玩家“它会怎样把你弄死”。**

#### 第三层：反制答案可读性（How to answer）
真正高水平的可读性，不是让玩家看懂危险，而是让玩家看懂“能怎么解”。

也就是说，系统要主动给出可联想的因果：
- 漏怪太快 → 需要减速/覆盖/瞬时爆发；
- 盾怪太多 → 需要破盾标签/高频段伤害；
- 召唤链太长 → 需要前置斩首或范围清杂。

如果玩家拿到升级后，无法在脑内迅速映射“这能解下一波什么题”，升级就只是文本噪音。

因此升级设计要绑定题型语言：
- “对护盾单位额外伤害”
- “对首次命中的高速单位施加减速”
- “击杀召唤者时爆炸波及其召唤物”

这类词条比抽象的“+12%伤害”更像真正的策略答案。

#### 第四层：失败复盘可读性（Why I lost）
玩家死亡后能不能一句话说出原因，是留存分水岭。

理想复盘句式是：
- “我漏的是高速怪，不是输出不够。”
- “我死在盾怪拖时，不是 Boss 伤害太离谱。”
- “我把升级拿去贪输出了，没补路径覆盖。”

如果玩家只能说“突然就没了”，那局内设计再复杂都白搭。

### 五、给《光与朽》的直接落地方法

#### 方案 A：先给所有敌人做“题型身份证”
内部表格别再只写：生命、速度、护甲、赏金。
必须新增四列：
- 题型标签
- 主要威胁
- 推荐反制
- 首次出现波次

比如：
- 小飞虫：冲线题 / 威胁=漏怪 / 反制=减速+前置覆盖 / 首现第2波
- 盾兵：拖时题 / 威胁=火力被锁 / 反制=破盾或高频段 / 首现第4波
- 母体怪：扩线题 / 威胁=召唤拉长战线 / 反制=斩首 / 首现第6波

这样你后面调波次时，调的是题型组合，不是纯数字。

#### 方案 B：同波只保一个“主威胁”
一波里可以有很多单位，但**只能有一个主要学习目标**。

如果同一波同时塞：高速漏怪、远程骚扰、护盾拖时、召唤扩线，首局用户根本学不会，只会觉得吵。

建议首局前 8 波这样控：
- 每波主题只考 1 个；
- 次要干扰最多 1 个；
- 新题型首次登场时，旧题型强度要稍微退后；
- Boss 前两波一定先预告 Boss 所考的题。

#### 方案 C：用“红灯信息层”突出当前最危险对象
屏幕信息分三层：
- 常规层：普通敌人、普通伤害；
- 关注层：精英、异常状态、关键掉血；
- 红灯层：即将漏线、即将召唤、即将触发高危技能。

红灯层必须拥有最稳定的差异：
- 独特边框/描边
- 独特音效
- 更强的前摇或提示线
- 更少但更狠的屏幕提示词

不要平均提醒。**平均提醒=没有提醒。**

#### 方案 D：升级三选一改成“解题提示器”
每次升级要偷偷回答玩家：
“你刚才差点死在哪，接下来该补什么？”

做法不是强控，而是加权：
- 最近两波若高速怪造成主要漏怪，则更易刷出减速/前置覆盖；
- 最近两波若盾怪拖时明显，则更易刷出破盾/穿透；
- 若当前 build 已明显偏单体，则适度提高范围补短板项权重。

这会显著提高“我被系统理解了”的体感。

#### 方案 E：陌生用户测试只问三个问题
试玩后不要泛问“好玩吗”，直接问：
1. 你觉得刚才最危险的怪是哪种？
2. 你觉得自己这把输的主因是什么？
3. 下一把你准备改什么？

如果答不出来，说明不是玩家问题，是题型语言没立住。

### 六、我对《光与朽》的狠判断
《光与朽》现在最缺的，未必是更多塔、更多技能、更多词条。
**更可能缺的是：系统没有把“危险—答案—结果”这条因果链，讲得足够清楚。**

玩家愿意重开，不是因为输了，而是因为：
- 他看懂自己怎么输；
- 他相信下把有明确修正空间；
- 他知道系统不是乱杀，而是在出题。

如果这条链成立，输也会上头；
如果这条链不成立，赢了都未必想继续。

### 七、接下来最值得继续深挖的下下题
如果这一课落实完，下一层最值得深挖的是：
**升级池导演系统（Directed Upgrade Pool / Adaptive Offer Design）**。
也就是：系统如何根据玩家上一波暴露出的缺口，动态提高“可用答案”出现率，同时不破坏肉鸽随机乐趣。

这是把“可读性”进一步推进到“系统共创策略感”的关键一步。
