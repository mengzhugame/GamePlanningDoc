# 游戏用户获取与运营指南 (User Acquisition & Operations Guide)

## 核心课题：休闲游戏/小游戏的 LTV 与 CAC 计算模型

### 1. 核心概念与关系
*   **CAC (Customer Acquisition Cost)**: 获客成本。= 总市场营销费用 / 新增付费用户（或新增激活用户）数。在买量市场，这通常等于 CPA/CPI。
*   **LTV (Life Time Value)**: 用户生命周期总价值。即一个用户从注册到流失，在游戏内贡献的总收入（包括IAP内购和IAA广告变现）。
*   **黄金法则**: LTV > CAC。在成熟的游戏商业模式中，通常要求 **LTV > 3 * CAC** 才能保证足够的利润空间和抗风险能力。对于休闲/超休闲小游戏，**LTV/CAC > 1.2 ~ 1.5** 且回本周期极短（如 3-7 天）即可开始大规模买量。

### 2. LTV 的计算与预测模型

预测LTV的核心在于预测留存率和日均ARPU。

#### 模型 A：简单经验乘数法（适合极早期快速估算）
*   公式：`LTV = ARPU(日均活跃用户收益) * LT(平均生命周期天数)`
*   假设：前期7天收益曲线与终生曲线成固定比例。例如，测出7天LTV为 $1.0，根据同类游戏经验（如7天LTV占总LTV的50%），则预估总LTV为 $2.0。

#### 模型 B：留存率曲线积分法（行业通用标准）
*   公式：`LTV = 第一天ARPU + 第二天留存率*第二日ARPU + ... + 第N天留存率*第N天ARPU`
*   **实操进阶：幂函数拟合留存**
    *   游戏用户的留存曲线通常符合幂律分布（Power Law）：`R(t) = a * t^b` (其中 a, b 为常数，b < 0)。
    *   通过前3天或前7天的真实留存数据，拟合出公式，预测出30天、60天甚至180天的留存率。
    *   将预测出的每一天留存率乘以预估的每日ARPU（通常初期较高，后期趋于稳定），累加求和即得准确的预测 LTV。

### 3. 小游戏/休闲游戏的实操策略

1.  **极速测算回本周期 (Payback Period)**：
    *   对于依赖 IAA (广告) 的小游戏，重点关注首日ROI (Return on Investment) 和 7日ROI。
    *   如果 首日ROI > 40-50%，7日ROI > 100% (即7天回本)，就可以认定该买量渠道有效，准备放量。
2.  **分层计算与精细化运营**：
    *   不要只算一个总平均的 LTV 和 CAC。必须按 **渠道 (如抖音、微信、Facebook)**、**操作系统 (iOS/Android)**、**国家/地区** 进行拆分测算。iOS用户的LTV通常远高于安卓用户，但其CAC也高。
3.  **压低 CAC 的核心：素材创意 (CTR) 和 转化率 (CVR)**：
    *   在竞价广告中，`eCPM = 出价 * 预估CTR * 预估CVR * 1000`。
    *   要想以较低的实际出价 (CAC) 胜出，必须提高广告素材的点击率 (CTR)（例如制造抓人眼球的失败/擦边/猎奇创意，也就是常说的“副玩法”或“吸睛素材”）。

### 4. 给光与朽的实战应用建议
*   《光与朽》作为有深度的塔防游戏，应该看重长线留存（如30日LTV）。
*   测试期先花小预算（几千元）投放，获取真实的次留、3日留存、7日留存和ARPU，建立基准数据。
*   利用留存曲线快速拟合出 LTV，对比测试渠道的 CAC。若LTV>CAC，说明商业模型跑通，可以筹备大规模发行的资金。

## 【初级】休闲游戏/小游戏的 LTV 与 CAC 计算模型实操

**1. 核心概念与公式**
*   **CAC (Customer Acquisition Cost) 获客成本**: 获取一个新玩家的平均成本。
    *   **公式**: `CAC = 总广告花费 / 新增注册玩家数` (或者 CPA: Cost Per Action)。
    *   在小游戏生态（微信/抖音），CAC主要受CTR(点击率)和CVR(转化率)影响。
*   **LTV (Life Time Value) 生命周期总价值**: 玩家在流失前，平均为游戏带来的总收入（包含广告变现IAA + 内购IAP）。
    *   **公式推导法**: `LTVN = Σ(第i日活跃用户留存率 * 第i日ARPU)`。
    *   小游戏通常看 LTV3, LTV7, LTV30。

**2. 核心指标的商业逻辑**
*   **黄金法则**: `LTV > CAC` 才能赚钱，通常要求 `LTV / CAC > 3` 才算健康（覆盖运营与研发成本）。
*   **回本周期 (Payback Period)**: 休闲游戏因为生命周期短，极其看重“首日ROI”和“7日回本率”。如果投放初期 LTV7 无法覆盖 CAC，必须果断停投或调整模型。

**3. 实操与优化指南（针对小游戏/休闲）**
*   **降低CAC**: 依靠吸睛的短视频素材买量，提高点击率CTR；通过简化注册流程（一键授权）提高转化率CVR。
*   **提高LTV**: 前期增加频次合理的激励视频（复活、双倍奖励）提升ARPU，同时优化核心玩法的“成瘾性”提高留存率（留存率是LTV公式的乘数因子）。

## 【中级】IAA（广告变现）最佳植入策略与频次控制

### 1. 广告类型特性与差异化应用

#### 激励视频 (Rewarded Video)
*   **核心特点**: 玩家主动选择观看，获取游戏内奖励（复活、双倍金币、额外生命等）
*   **eCPM最高**: 通常为插屏广告的2-3倍，玩家完成率高
*   **最佳植入场景**:
    *   **失败复活**: 玩家最愿意观看的场景，情绪价值高
    *   **奖励翻倍**: 关卡结算时，让玩家选择2倍或3倍奖励
    *   **资源补充**: 金币/道具不足时，提供免费获取机会
    *   **跳过等待**: 跳过建筑升级、角色培养等待时间
*   **转化心理学**: 利用"损失厌恶"心理，让玩家觉得"不看广告会损失机会"

#### 插屏广告 (Interstitial)
*   **核心特点**: 强制展示，高曝光但易引起反感
*   **植入策略**:
    *   **自然中断点**: 关卡切换、场景加载、主菜单返回时
    *   **避免核心流程**: 绝对不能在战斗进行中、重要操作时弹出
    *   **时长控制**: 可关闭广告优于强制观看，5-10秒后提供跳过选项
*   **留存率影响**: 研究表明，插屏广告频次每增加1次，次日留存率下降2%-4%

#### 横幅广告 (Banner)
*   **核心特点**: 持续展示，低干扰但收益较低
*   **最佳位置**: 游戏界面顶部或底部固定区域
*   **适配策略**: 自动适配设备尺寸，避免遮挡UI操作区域

### 2. 频次控制 (Frequency Capping) 最佳实践

#### 用户分层频控策略
*   **新手保护期 (前30分钟)**:
    *   插屏广告: 0-1次，让玩家充分体验游戏核心乐趣
    *   激励视频: 不限制，但提供明确价值引导
*   **核心活跃期 (1-7天)**:
    *   插屏广告: 每30分钟1-2次，每关卡1次
    *   激励视频: 自然触发，不强推，保持玩家自主选择权
*   **长期用户 (7天以上)**:
    *   可根据用户行为画像个性化调整频次
    *   高价值玩家减少干扰，低价值玩家适度增加

#### 智能触发算法
*   **情绪状态判断**: 玩家连续失败时，优先提供激励视频复活而非插屏广告
*   **游戏节奏感知**: 高节奏战斗后给予玩家缓冲期，避免广告打断心流
*   **付费倾向识别**: 对有IAP消费记录的玩家减少广告打扰，保护付费体验

### 3. 用户体验与收益平衡公式

#### 收益计算公式
```
总收益 = Σ(广告展示次数 × eCPM/1000)
```

#### 用户容忍度模型
*   **插屏广告**: 每30分钟 ≤ 3次为安全阈值
*   **激励视频**: 无硬性上限，但单次游戏session建议 ≤ 10次
*   **用户流失率与广告收益的平衡点**:
    *   休闲游戏: 广告ARPU提升$0.01 = 可容忍1%的次日留存下降
    *   中度游戏: 广告ARPU提升$0.02 = 可容忍1%的次日留存下降

### 4. 技术实现与A/B测试

#### 多广告平台Waterfall配置
*   **竞价层**: 设置eCPM从高到低的多个广告平台
*   **瀑布流优化**: 实时调整排序，优先高eCPM平台
*   **填充率保证**: 至少接入3家广告平台，确保95%+填充率

#### A/B测试框架
1.  **对照组**: 基础频控策略（30分钟2次插屏）
2.  **实验组A**: 激进策略（30分钟4次插屏）
3.  **实验组B**: 保守策略（仅激励视频，无强制插屏）
4.  **核心指标**: LTV7, 次留, 7留, 广告ARPU

#### 数据监控与优化循环
```
数据采集 → 频控调整 → A/B测试 → 效果分析 → 策略迭代
循环周期: 每周一次
```

### 5. 给光与朽的实战应用建议

1.  **塔防特性适配**:
    *   激励视频: 防御塔升级加速、特殊塔解锁、关卡重试
    *   插屏广告: 仅在关卡胜利/失败结算时展示
    *   避免战斗中断: 绝对不在波次进行中弹出广告

2.  **渐进式频控**:
    *   新手教程期: 0广告，纯体验
    *   前5关卡: 仅激励视频，无强制广告
    *   5-10关卡: 每2关1次插屏
    *   10关后: 每关1次插屏，但提供"观看激励视频跳过一次"选项

3.  **价值交换设计**:
    *   让玩家感觉"广告有价值": 复活机会、双倍金币、特殊塔体验
    *   避免"广告是惩罚": 失败时不强制插屏，而是提供激励复活选项

4.  **技术实施要点**:
    *   使用Unity Ads或AdMob的频控API
    *   实现用户分层频控逻辑
    *   建立实时数据监控面板

## 【资深】出海买量策略：Facebook / Google Ads / TikTok 的素材差异

### 1. 为什么这个课题现在必须补
运营与发行维度里，前面已经打了 **LTV/CAC → IAA植入 → 混合变现** 三层地基；下一个该啃的，按路线顺序就是 **出海买量策略：Facebook / Google Ads / TikTok 的素材差异**。原因很简单：
- 前三课解决的是“游戏值不值得买量、怎么回本、怎么提高LTV”；
- 这一课解决的是“同一个游戏，到了不同平台，素材该怎么长得不一样，才不会白烧钱”。

如果还拿一套素材同时砸 Meta、Google、TikTok，那不是省事，是犯蠢。2025-2026 的行业共识已经非常清楚：**平台分发逻辑不同，用户心智不同，算法吃的信号也不同，素材结构必须平台化。**

### 2. 2025-2026 行业共识：平台不是流量池，是三种完全不同的机器
根据本次网络调研与行业资料：
- **Meta（Facebook/Instagram）** 仍然是多数手游品类最稳定、最能放量的核心渠道，尤其在转化优化、广泛定向和 Reels/Stories 短视频分发上依旧强势。
- **Google App Campaigns（UAC）** 更像“资产组合机器”：它会把文本、图片、横版/竖版/方版视频、YouTube、Display、Search 信号混合起来自动找量，核心不是单条爆款素材，而是**完整素材包 + 稳定学习周期**。
- **TikTok** 的核心不只是买量，而是“内容感买量”。它明显更偏好 **0.5-2 秒强钩子、原生感、UGC/假测评/挑战感/反差感** 的创意，强依赖首屏情绪和停留。

一句话总结：
- **Meta 吃“可复制的转化素材系统”**
- **Google 吃“多资产喂养 + 稳定机器学习”**
- **TikTok 吃“像内容不是广告的高钩子视频”**

### 3. 三大平台素材差异：别再一稿打天下

#### A. Meta（Facebook / Instagram）
**平台特征：**
- 仍然适合做规模化放量和稳定 ROAS 优化。
- Reels / Stories / Feed 并行，竖版短视频表现越来越重要。
- 算法擅长从大样本里找高转化用户，因此适合持续测试“结构相似、变量不同”的素材矩阵。

**Meta 赢素材的典型结构：**
1. **前1秒直接给冲突或收益**：例如“这关99%的人守不住”“这塔组合竟然能秒Boss”。
2. **中段快速交代玩法闭环**：让用户知道自己装进来后要做什么。
3. **结尾明确 CTA**：如“马上试试”“现在开局”“看看你能撑几波”。

**更适合 Meta 的素材风格：**
- 竖版 Reels / Stories 优先；
- 真 gameplay + UI 叠字；
- “失败反转”“极限翻盘”“高压局面破局”这类清晰冲突；
- 可以接受稍微“广告味”一点，但转化逻辑必须直给。

**Meta 不适合的坑：**
- 只有情绪，没有玩法；
- 开头铺垫太久；
- 创意过度依赖主播脸和长段口播；
- 首屏看不出游戏类型。

**对《光与朽》的 Meta 素材建议：**
- 重点做“激光折射 + 波次压迫 + 差1秒守住”的战斗高压感；
- 画面上直接叠字：`这套激光塔能不能守到第20波？`
- 同一脚本快速拆 5-8 个变体：敌潮密度、Boss压线、激光弹射角度、字幕钩子、结尾 CTA 各改一个变量。

#### B. Google Ads（App Campaigns / UAC）
**平台特征：**
- Google 不是单一广告位，而是 Search、YouTube、Display、Play 商店等多入口联合投放。
- 它不像 Meta 那样靠你精细拆广告组，它更吃 **少量强 campaign + 足够丰富的素材资产**。
- 过度频繁换目标、换素材包、换出价，会把学习阶段打断。

**Google 赢素材的底层逻辑：**
1. 提供足够多的资产给系统组合；
2. 让系统从早期高价值事件中学到“什么用户值得买”；
3. 用多比例、多长度素材覆盖不同库存。

**实操要点（本次调研里最硬的干货之一）：**
- 每个国家/相近国家簇，先上 **1-2 个核心 campaign**，别乱拆；
- 事件优先级从 `安装 → 教学完成 → D1留存/关卡完成 → 付费` 逐步抬高；
- 素材包至少准备：
  - 5 条横版视频
  - 5 条竖版视频
  - 5 条方版视频
  - 5 张图片
  - 5 条短文案
  - 有能力再补 HTML5 playable
- 创意迭代不要一次全换，只替换 **1-2 个素材**，避免学习重置；
- 放量时预算提升以 **20%-30% 小步加** 最稳。

**更适合 Google 的素材风格：**
- 解释更完整的 15-30 秒 gameplay；
- 多方向多比例素材并行；
- Playable 对轻玩法、Puzzle、Merge、Idle 特别强；
- 不必每条都很炸，但必须“可被机器拼装和组合”。

**Google 不适合的坑：**
- 只有竖版短视频，没有横版和方版；
- 只有视频，没有图和文案；
- 三天两头换优化目标；
- 刚起量就大幅提预算，导致 CPI 飙升。

**对《光与朽》的 Google 素材建议：**
- 做一套“资产包思维”而不是“单爆款思维”；
- 横版重点展示完整一局：布塔 → 激光连线 → 波次压力 → Boss残血翻盘；
- 竖版重点切高能片段；
- 方版与截图突出“塔组合”“关卡地图”“局内三选一成长”；
- 如果后续验证玩法清晰，可以做简化版 playable：让玩家拖拽塔位、触发一次激光连锁清怪。

#### C. TikTok
**平台特征：**
- 用户不是来“看广告”的，是来刷内容的。
- 所以 TikTok 创意的核心不是传统广告逻辑，而是 **前0.5秒抓人 + 原生内容感 + 明确情绪刺激**。
- 对手游来说，TikTok 最怕“像一支剪得很规整的广告片”，那种东西往往死得很快。

**TikTok 赢素材的典型结构：**
1. **0.5-2秒强钩子**：失败、嘲讽、挑战、反差、不可思议结果；
2. **中段极速给 payoff**：马上看到爽点或灾难；
3. **字幕、配音、音效强化节奏**；
4. **整体像原生短视频，不像广告部产物。**

**更适合 TikTok 的素材风格：**
- UGC / fake review / reaction 结构；
- `我不信有人能过这关`、`这塔摆错一格直接崩盘` 这类挑战式表达；
- 极短、快切、竖屏、粗字幕；
- 适合把“错误操作 → 惨死 → 正确操作 → 爽翻”做成高反差。

**TikTok 不适合的坑：**
- 品牌感太重、包装太正经；
- 开头 2 秒还没进入冲突；
- gameplay 看不懂；
- 一味追低 CPI，不看留存和 LTV，结果买来一堆烂量。

**对《光与朽》的 TikTok 素材建议：**
- 主打三类：
  1. **挑战型**：`你能守过第12波吗？`
  2. **翻车型**：`我以为稳了，结果一只漏怪全炸了`
  3. **教学型伪UGC**：`别再乱摆塔了，激光要这样折射才对`
- 前 1 秒必须直接给“快死了 / 快赢了 / 出大事了”；
- 配上大字幕和夸张反馈音效；
- 可以加“真人吐槽口吻”，但别拖，脸不是主角，翻盘画面才是。

### 4. 2025-2026 创意趋势：哪些东西在变强
根据本次调研，几条趋势已经很明显：

#### 趋势 1：视频仍是绝对主力，但“视频 + playable”组合越来越强
- 2025 年全球手游买量创意里，视频仍占绝对大头。
- 但对 Puzzle / Hybrid-casual / Idle 等类型，**video + playable 组合**正在快速变强，因为它兼顾了情绪勾子和交互理解。
- 对轻玩法产品，playable 经常能拉高 D1 留存并压低 CPI；但对深度策略产品，playable 要做“极简核心体验切片”，不能妄想把整个复杂系统塞进去。

#### 趋势 2：AI 创意不是噱头，而是提速器
- 行业案例已经在用 AI 角色、AI 配音、AI 动画、AI 多语言本地化来拉高素材产能；
- 真正值钱的不是“AI生成了什么”，而是 **让同一脚本快速裂变 20-50 个可测版本**；
- 对小团队来说，AI 最大价值是把“创意产能瓶颈”砍掉。

#### 趋势 3：创意本地化不等于只翻译文案
- 南美、东南亚、欧美对节奏、画面拥挤度、字幕密度、角色审美容忍度都不一样；
- 真正的本地化要改的是：节奏、字幕、配音、情绪表达、题材包装，甚至失败/成功镜头的停留时长。

### 5. 平台对照：一句话打穿差异
| 平台 | 核心分发逻辑 | 最适合素材 | 不该犯的错 | 适合《光与朽》的切法 |
|---|---|---|---|---|
| Meta | 稳定转化优化 + 广泛放量 | 竖版 gameplay + 明确冲突 + 直给 CTA | 开头慢、玩法不清 | 激光折射翻盘、Boss压线、守线挑战 |
| Google UAC | 多资产组合 + 机器学习 | 多比例视频 + 图片 + 文案 + playable | 乱拆 campaign、频繁重置学习 | 一局完整体验拆成横/竖/方三套资产 |
| TikTok | 内容流停留竞争 + 情绪钩子 | 极短竖屏、UGC感、挑战/翻车/反差 | 太像广告、前2秒没钩子 | 翻车、极限守线、伪教学短视频 |

### 6. 《光与朽》现阶段的出海买量落地方案
别一上来全球乱投，先按 **平台 × 素材结构 × 目标国家** 做最小验证。

#### 第一阶段：验证素材-平台匹配（小预算）
- 国家先别贪，优先选 2-3 个英语市场或低 CPI 测试市场；
- 每个平台只上 3 个核心方向：
  - Meta：高压翻盘型 / 爽感清屏型 / 守线挑战型
  - Google：完整战斗说明型 / 高能剪辑型 / Playable（如能做）
  - TikTok：翻车型 / 挑战型 / 伪UGC教学型
- 先看：CTR、IPM、安装率、教程完成率、D1 留存、广告 ARPU。

#### 第二阶段：验证“低 CPI 不是烂量”
- TikTok 和某些短视频渠道容易给你很好看的 CPI，但那不代表有价值；
- 必须拉上创意级别的 D1 留存、7日留存、广告观看次数、首购率一起看；
- **低 CPI + 低留存 = 垃圾流量，不要被骗。**

#### 第三阶段：建立创意工厂，而不是赌单素材
《光与朽》最该建立的是这条流水线：
1. 每周产出 10-20 条新素材；
2. 每条只改 1 个核心变量（钩子、镜头顺序、字幕、CTA、关卡难度表现）；
3. 48-72 小时看早期信号；
4. 胜出脚本再做平台化改编，而不是原样复制。

### 7. 小团队最该记住的狠话
- **Meta 不是拿来拍“剧情片”的，是拿来测转化的。**
- **Google 不是让你秀创意灵感的，是让机器吃资产包的。**
- **TikTok 不是广告位，是内容战场。**
- **别迷信低 CPI，留存和 LTV 才是你爹。**
- **不要做“一条素材投三平台”的穷鬼式偷懒，这种省下来的不是钱，是回本机会。**

## 【高级】混合变现（IAA + IAP）的设计节点与破冰付费

### 1. 这玩意的本质，不是“广告加内购”这么简单
混合变现的核心不是把广告和商城硬塞到同一个游戏里，而是**把不同付费意愿的用户分层收割，同时尽量不互相伤害**：
- **零付费用户**：主要靠激励视频、插屏、Offerwall 等 IAA 变现。
- **轻付费用户**：主要吃首充包、去广告包、限时特惠包。
- **中重付费用户**：主要吃长期养成、通行证、成长基金、活动礼包。

真正成熟的设计目标不是单看 ARPPU，而是三件事一起拉：
1. **提高整体 LTV**
2. **缩短回本周期**
3. **避免广告把潜在付费用户吓跑**

根据知识库中已有 LTV/CAC 框架，混合变现最适合用来做两件事：
- 用 IAA 尽快回收非付费人群价值，撑住早期 ROI；
- 用 IAP 吃掉高意愿用户的额外支付空间，把 LTV 天花板顶上去。

### 2. 最新行业共识：2025 年以后，纯 IAA 或纯 IAP 都开始显得蠢
根据网络搜索到的 2025 行业资料：
- **Tenjin 2025 广告变现基准报告**明确指出，越来越多移动游戏正在采用 hybrid monetization（IAA + IAP）。
- **ThinkingData 2025 案例总结**强调，休闲/解谜类产品常见做法是：用激励视频承接失败复活、体力补充、加速奖励，同时用礼包/去广告包承接更高价值用户。
- **AppSamurai 2025 文章**给出的行业判断更直白：混合变现对 LTV 和 ROAS 通常优于单一 IAA 或单一 IAP，尤其适合 hybrid-casual 和有 meta 成长的产品。
- **Unity 2025 商业案例**显示：当买量优化目标开始把广告收入也算进 ROAS 后，UA 放量空间会明显扩大；这意味着产品如果只盯内购回收，容易低估真实回本能力。

结论很直接：
**小游戏和轻中度手游的商业模型，已经从“广告 or 内购二选一”，进化到“广告负责回收底盘，内购负责抬高天花板”。**

### 3. 混合变现的五个关键设计节点

#### 节点 A：失败瞬间 —— 用激励广告承接情绪，不要先弹付费
失败后的玩家情绪最强，但也是最脆弱的时候。
正确顺序：
1. **先给免费复活/补救（Rewarded Video）**
2. 看完广告后，如果资源仍然不够，再弹“更稳定、更永久”的付费方案

原因：
- 失败当下先卖礼包，像趁火打劫，容易反感。
- 先用广告建立“系统愿意帮我”的感知，再卖“永久省事”的付费，会顺得多。

典型设计：
- 第一次失败：免费激励复活
- 当天第 2~3 次失败：继续给广告，但奖励略减
- 广告次数打满后：给出“应急补给包 / 今日战术包 / 去广告+额外复活次数”

#### 节点 B：首次爽点兑现 —— 在玩家刚尝到甜头时做首充破冰
破冰付费（first purchase break）最有效的时机，不是冷启动首页，而是**玩家刚感受到成长价值之后的 3~10 分钟内**。

最佳窗口：
- 首次通关一个略难关卡后
- 首次解锁稀有塔/角色/技能后
- 首次体验双倍奖励、快节奏成长后

此时适合推出：
- **新手超值包（Starter Pack）**：￥6 / ￥12 / ￥18 档最稳
- **限时倒计时礼包**：15 分钟~24 小时
- **内容结构**：软货币 + 稀缺强化材料 + 去广告或跳过一部分广告权益

2025 年多篇行业文章都在重复同一件事：
**首购包卖的不是“便宜”，而是“让用户立刻明白：付费比看广告更省时间、更稳定、更体面”。**

#### 节点 C：重复需求场景 —— 广告给“临时解决”，内购给“永久解决”
这是混合变现里最关键的结构。

好设计：
- 金币不够 → 可看广告补一次；也可买资源包永久缓解
- 体力不够 → 可看广告补一点；也可买月卡/体力包
- 道具短缺 → 可看广告白嫖少量；也可买养成礼包直接拉满
- 广告很多 → 可继续看；也可买 Remove Ads/No Ads Pass

坏设计：
- 广告和内购卖的是同一件事，且价格关系混乱
- 看 1 次广告价值过高，直接把小额付费打死
- 付费后仍被大量广告骚扰，逼得轻付费用户直接流失

一句话：
**IAA 负责给穷人一条路，IAP 负责给急的人一部电梯。**

#### 节点 D：中期留存阶段 —— 通行证/成长基金接管长期价值
当用户跨过首日和前几关之后，只靠零散礼包会开始疲软，必须上长期付费结构：
- **Battle Pass / Season Pass**：适合有章节、任务、活动循环的产品
- **成长基金**：适合数值成长感明显、关卡推进明确的产品
- **订阅/月卡**：适合每天都要上线、有持续资源领取逻辑的产品

为什么这一步重要：
- IAA 解决的是每次 session 的变现；
- 通行证/基金解决的是 7 天、30 天的长期 ARPU。

2025 年行业趋势里很明确：
**ads + IAP + pass** 正在成为比“ads + 单次礼包”更强的组合，因为它更能把留存和收入绑死。 

#### 节点 E：高广告用户识别 —— 把“愿意看广告的人”转成“愿意花小钱的人”
真正厉害的混合变现，不是无限喂广告，而是识别：
- 某用户每天看 15 次激励视频
- 经常点双倍奖励
- 经常体力不够
- 但从未付费

这类用户不是没需求，而是**还没被正确报价**。
对这群人最适合的不是大礼包，而是：
- 首次去广告特惠
- 一键领取双倍奖励通行证
- 低价周卡（含自动扫荡、额外复活、跳过广告）

也就是把“高广告消耗用户”识别成“潜在轻付费用户”。这一步能明显提高付费渗透率。

### 4. 混合变现的定价与权益设计原则

#### 原则 1：广告是可忍受的麻烦，内购是永久省事
因此定价逻辑应满足：
- 看广告能解决，但麻烦、慢、次数有限
- 付费能永久解决，或者显著更省时间

如果广告给得太爽，IAP 会死；
如果广告给得太恶心，留存会死。

#### 原则 2：Remove Ads 不能只是“去插屏”
2025 年大量产品已经把“去广告包”升级成复合权益：
- 去强制插屏
- 保留可选激励视频
- 送每日资源
- 增加扫荡/快速结算/自动领取

因为单纯 Remove Ads 很容易价格感知太弱；
而“去广告 + 每日小特权”更容易让用户觉得值。

#### 原则 3：首购价格要低到不需要思考
对轻度和小游戏，首充破冰价位通常应该非常克制。
建议：
- 中国区：￥6 / ￥12 / ￥18 是最稳的三档
- 海外区：$0.99 / $1.99 / $2.99 是最稳的三档

第一单的目标不是赚钱，是**把用户从“白嫖脑”切换成“付费脑”**。

### 5. 关键数据指标：不盯这些，混合变现就是瞎搞
除了常规留存、ARPDAU、LTV 之外，混合变现必须额外盯：

#### IAA 侧
- Rewarded Video Opt-in Rate（激励广告主动观看率）
- Rewarded Completion Rate（激励广告完成率）
- Interstitial Impressions / DAU
- Ad ARPDAU
- Ads-impaired Retention（广告导致的留存损伤）

#### IAP 侧
- First Purchase Conversion Rate（首购转化率）
- Time to First Purchase（首次付费所需时长）
- Starter Pack Take Rate
- Remove Ads Purchase Rate
- Battle Pass Attach Rate

#### 联动指标
- 每日高广告用户中转付费的比例
- 付费用户的人均广告曝光下降幅度
- 去广告包购买后 D7 / D30 留存变化
- 按渠道拆分的 Ad ROAS + IAP ROAS + Total ROAS

### 6. A/B 测试优先级：先测这四个，别瞎开一堆实验
1. **首购包触发时机**
   - 通关后弹
   - 首败后弹
   - 解锁稀有内容后弹

2. **去广告包权益结构**
   - 纯去插屏
   - 去插屏 + 每日奖励
   - 去插屏 + 自动双倍 + 每日奖励

3. **广告上限与付费替代关系**
   - 每日 5 次激励后弹轻付费包
   - 每日 8 次后弹
   - 完全不弹

4. **首购价格带**
   - ￥6 vs ￥12 vs ￥18
   - 看首购率，也看 7 日总收入，不要只盯单笔客单价

### 7. 《光与朽》的落地打法：别做纯广告塔防，那太蠢
《光与朽》更像轻中度塔防肉鸽，不适合走纯超休闲广告逻辑。更合理的是：

#### 第一层：IAA 负责保底回收
- 失败复活
- 战后双倍结算
- 稀缺材料补给
- 局外养成加速

#### 第二层：低门槛 IAP 负责破冰
- **6 元新手战术包**：钻石 + 稀缺图纸 + 3 天免插屏
- **12 元去广告特权包**：去插屏 + 每日补给 + 保留激励视频
- **18 元成长包**：前 3 章阶段性返利

#### 第三层：长期 IAP 负责拉高 LTV
- 赛季通行证：章节挑战、特殊皮肤、局外资源
- 周卡/月卡：每日图纸、额外扫荡、额外复活币

#### 第四层：把广告重度用户导向轻付费
如果某玩家连续 3 天：
- 每天看激励广告 ≥ 8 次
- 多次点击双倍奖励
- 有复活需求

那就别再狠狠干广告了，直接弹：
**“指挥官补给证：12 元，7 天内免插屏 + 每日战术箱 + 额外复活次数。”**

这才是商业脑子，不是流氓脑子。

### 8. 我给主人的最终判断
混合变现最难的，不是接广告 SDK，也不是开商城。
**最难的是把“免费解法”和“付费解法”设计成前后衔接、各司其职，而不是互相打架。**

对《光与朽》来说，最优路线不是“广告插满”，而是：
- 用激励广告吃免费用户；
- 用低价首购包和去广告权益打破第一次付费；
- 用通行证和成长包吃长线价值；
- 用数据识别高广告用户，把他们转成轻付费用户。

这套打通，LTV 才会真的抬起来。

## 【专家】如何利用口碑与社区（Discord / 小红书 / Reddit）做零成本冷启动

### 1. 这课的核心，不是“发社区内容”，而是先造第一批会替你说话的人
零成本冷启动最蠢的做法，是把社区当免费广告位，天天发“我们游戏上线了快来玩”。那种内容没人 care。

真正有效的思路是：
- **先做可讨论的具体东西**，再做传播；
- **先收集种子用户**，再求规模；
- **先让玩家参与感变强**，再谈转化。

一句话讲透：
**冷启动不是自己喊得多响，而是能不能尽快养出一小撮愿意帮你扩散、试玩、给反馈、替你解释产品价值的人。**

### 2. 2025-2026 的平台现实：Discord、Reddit、小红书，各自扮演不同角色
根据本轮调研，三类社区渠道在冷启动里不是互相替代，而是分工不同。

#### Discord：核心用户池与试玩组织中心
Discord 适合承接最早那批高意愿玩家。
它的价值不在“拉人数”，而在：
- 组织封测/试玩；
- 收集高密度反馈；
- 让开发者和玩家直接对话；
- 把高频用户沉淀成长期传播节点。

根据近期独立开发者复盘与社区经验贴，真正有用的拉群理由不是“进群支持我们”，而是：
- 抢先试玩资格
- 投票决定新内容
- 开发者直接答疑
- 每周 build 更新与 patch note
- 社区挑战赛 / giveaway / 榜单活动

也就是说，**Discord 不是粉丝群，是内测作战室。**

#### Reddit：外部验证与爆点扩散器
Reddit 不适合硬广，但非常适合“展示真实过程、真实问题、真实变化”。
有效内容通常不是“来玩我的游戏”，而是：
- 一段前后对比 GIF
- 一个失败后修正的设计迭代
- 某个机制为什么改
- 美术/玩法 Demo 被玩家评价后的更新结果

Reddit 的底层逻辑是：
**你先提供值得讨论的观察、教训或惊喜，流量才会顺手流向你的游戏。**

对于独立游戏最有价值的不是一次爆帖本身，而是：
- 帖子评论区帮你验证卖点是否真的清晰；
- 被 upvote 的内容类型，可以反向变成广告素材与商店文案；
- 爆帖后把用户导向 Steam 愿望单 / Discord / demo 下载页。

#### 小红书：破圈心智场，不是纯转化场
小红书这两年对游戏内容越来越友好，很多行业观察都提到它已经成了新游宣发的必选补充渠道之一，尤其适合：
- 有风格感的美术包装
- 有话题性的开发幕后
- 玩家体验、避坑、推荐清单
- 女性向、审美向、生活方式向的破圈传播

但要说清楚一个残酷事实：
**小红书更像“种草和心智建立”平台，不像 Steam / TapTap 那样天然承接转化。**
所以打法不能是“发完就等下载”，而应该是：
- 先打认知标签；
- 再把用户导到可承接的平台（Steam、TapTap、Discord、预约页）。

### 3. 零成本冷启动的四步法

#### 第一步：先做“内容钩子”，别先做宣发
每个平台都需要一个能反复拆解的固定钩子，不然内容很快枯竭。

适合游戏项目的四类高性价比钩子：
1. **前后对比**：旧版本 vs 新版本
2. **翻车修复**：玩家吐槽后我们怎么改
3. **开发内幕**：某个机制/怪物/美术是怎么定出来的
4. **挑战展示**：你能不能过这关 / 这套 build 能不能守住

这四类内容有个共同点：
它们不是“宣传语”，而是**能引发评论和转发的证据型内容**。

#### 第二步：把所有社区动作都指向一个承接点
冷启动最怕流量散掉。
所以必须只有一个主承接点，其他平台只是导流辅助。

常见主承接点优先级：
- Steam 愿望单页
- Discord 社区
- 测试资格表单
- TapTap / 预约页

不要犯这种蠢：
今天让人加微信群，明天让人点 Steam，后天又让人填问卷。
**一个阶段只推一个主动作。**

#### 第三步：给种子用户“参与权”，不是只给观看权
真正会替你传播的人，往往不是最早看到你的人，而是最早“参与塑造你”的人。

最值得做的低成本参与机制：
- Discord 投票选新塔 / 新怪 / 新皮肤
- Reddit 发版本对比，征求优先修改项
- 小红书让用户评论想看哪类 Build 或哪类视觉风格
- 给首批玩家冠名、头像框、测试资格、鸣谢名单

玩家一旦觉得“这游戏我也有份”，传播意愿会明显抬升。

#### 第四步：把社区反馈重新包装成下一轮传播素材
这一步最关键，也最容易被忽略。

正确循环应该是：
1. 发内容
2. 收评论/反馈
3. 真改一部分
4. 把“我们根据你们的反馈改了什么”再发出去

一旦形成这个闭环，社区会认为你不是在自说自话，而是在共同开发。
这会显著提高评论率、收藏率、转发率和二次传播意愿。

### 4. 三个平台的实操打法

#### A. Discord 实操
目标：沉淀 100 个真玩家，比灌 1000 个死群友值钱十倍。

**推荐结构：**
- `#announcements`：只发版本与重要消息
- `#playtest-signup`：测试入口
- `#feedback`：统一收问题
- `#build-sharing`：鼓励晒配置与通关思路
- `#devlog`：开发进展

**关键动作：**
- 每周固定一次开发更新
- 每两周一次小范围 playtest
- 把积极反馈玩家标记成 tester / veteran / advisor
- 对高质量建议，公开回复并在更新日志点名感谢

**判断标准：**
- 不是看群人数
- 是看 7 日内发言人数、试玩报名率、反馈有效率、回流率

#### B. Reddit 实操
目标：用单条高价值帖子测试卖点，再把赢面最大的表达方式复制到其他平台。

**适合发的主题：**
- “玩家都说这关太难，所以我把塔防地图从 X 改成 Y”
- “这是我把某个系统重做前后的效果对比”
- “你们觉得哪个视觉版本更抓眼？”
- “我做了一个激光塔防，发现玩家最爽的不是数值，而是折射那一下”

**关键动作：**
- 一帖只讲一个点
- 首图/GIF 前 1 秒必须看得懂
- 正文讲过程、问题和变化，别像招商会
- 评论区认真回，尤其是负反馈

**判断标准：**
- 收藏与评论质量，比裸浏览更值钱
- 被反复提到的关键词，就是你该强化的卖点

#### C. 小红书 实操
目标：让《光与朽》先成为“有辨识度的东西”，再去承接转化。

**适合发的内容结构：**
- 美术感：角色/塔/场景概念图对比
- 爽点感：一段 10 到 20 秒高能翻盘录像
- 幕后感：为什么这个 Boss 改了三版
- 观点感：塔防为什么很多人做着做着就无聊了

**标题方向：**
- “我们把塔防的激光折射做疯了，结果玩家最爱这一秒”
- “独立游戏开发第 X 天，我终于把最蠢的怪物删了”
- “如果塔防的爽点不是堆数值，那该是什么？”

**关键动作：**
- 封面先抓审美或冲突
- 文案多讲判断与取舍，少讲官话
- 评论区把用户往试玩、预约、Discord 导

### 5. 冷启动最重要的三个指标
别被虚荣指标骗了。
真正该盯的是：
1. **有效评论率**：评论里有没有真实观点，而不是“加油”
2. **承接转化率**：看内容后，有多少人进 Discord / 点愿望单 / 报名试玩
3. **反馈回流率**：来过一次的人，下一次更新还会不会回来

零成本阶段，不追求大而空的曝光，追求可持续复利的社区密度。

### 6. 《光与朽》的直接落地方案
《光与朽》非常适合走“高辨识度机制 + 社区共创”冷启动，而不是假装自己是大厂新游。

**建议直接执行这套：**
- **Discord**：作为核心测试池，只拉最愿意给反馈和愿意反复打 build 的玩家。
- **Reddit**：主打“激光折射塔防”的机制对比、翻盘视频、设计取舍。
- **小红书**：主打视觉辨识度、开发幕后、Boss/塔设计迭代、爽感片段。

**每周固定产出 3 类内容：**
1. 一条高能战斗短视频
2. 一条版本迭代前后对比
3. 一条开发判断/踩坑复盘

**主承接动作只放一个：**
现阶段优先导向 **Discord 内测群 / 测试报名**，别同时分流到十个地方。

### 7. 我给主人的最终判断
零成本冷启动的核心不是“免费渠道”，而是**高频内容 + 单点承接 + 共创反馈循环**。

说得再狠一点：
- Discord 负责留住铁粉；
- Reddit 负责试错表达；
- 小红书负责破圈认知；
- 真正让口碑滚起来的，不是你发得勤，而是你改得快、回得真、内容有证据。

对《光与朽》来说，现在最值钱的不是硬凹“预约量”，而是先养出第一批会说这句话的人：
**“这游戏开发者真在听，而且这个激光塔防机制确实有点东西。”**

## 【专家进阶细分】零成本冷启动里的“试玩闭环设计”：如何把围观变成愿望单、进群与有效反馈

### 1. 为什么这才是运营与发行维度下一个该啃的点
运营与发行主线的五个大课题，知识库里其实已经都打过地基了。但还差一个真正决定成败的细分能力：
**你把人吸过来之后，怎么承接？**

很多团队死在这里。内容有了，帖子也爆了，试玩也有人下，但：
- 没人加愿望单
- 没人进 Discord
- 反馈是碎的、脏的、没法改
- 热度过后什么都没留下

所以这一轮我把“专家课题”继续往下钻，聚焦成更实战的细分专题：
**试玩闭环设计（Discovery → Demo → Discord/反馈 → 修正 → 二次传播）**。

### 2. 2025-2026 的最新共识：社区冷启动不是发内容，而是做承接链路
根据 Discord 官方 2025《The Game Developer Playbook》、Steamworks 2026 Steam Next Fest 文档、Reddit 2025-2026 独立游戏案例，以及 2025 年关于小红书游戏生态的行业观察，可以确认一个非常清楚的结论：

**冷启动真正值钱的不是“曝光量”，而是“有多少用户被你带进下一步动作”。**

也就是说，任何社区动作都要回答四个问题：
1. 用户现在看到什么钩子？
2. 用户下一步该点哪里？
3. 点进去之后，能不能立刻试玩或表达反馈？
4. 你能不能把这批人沉淀成下一波内容与版本迭代的燃料？

如果做不到这四点，那内容再热，也只是白嫖流量。

### 3. 三个平台在试玩闭环里的分工，不要混

#### A. Discord 负责“高意愿承接”和“结构化反馈”
Discord 官方在 2025 年给游戏开发者的建议非常明确：
- 测试社区的原则应该保持极简，目标就是让玩家**容易试玩、容易反馈**；
- 频道结构不要堆太多，先保留几类核心频道：`#announcements`、`#patch-notes`、`#build-feedback`、`#report-issue`、试玩语音房；
- 用 `Scheduled Events` 安排试玩时段，自动解决时区问题；
- 用 `Forum Channels` 或统一格式收集问题，避免反馈淹死在闲聊里；
- 新成员最好先过规则和权限门槛，避免泄露和噪音。

这说明 Discord 最适合承担的不是“宣传群”，而是：
- 邀请第一批高意愿玩家
- 组织定时试玩
- 收集可复现 bug 和可行动建议
- 把版本更新公开，让玩家看到“你们真的在改”

**关键判断：Discord 的核心产出不是聊天热度，而是高质量反馈密度。**

#### B. Steam Demo / Next Fest 负责“公开转化入口”
Steamworks 的 Next Fest 文档给了几个特别硬的点：
- 试玩版必须提前上线，最好赶在媒体预玩窗口前；
- 商店页必须把 demo 下载按钮做成显眼入口；
- demo 内部要直接放反馈入口，能链接到 Steam 子论坛、Discord、bug 工具或你自己的反馈页；
- 如果要直播，必须提前多次测试，聊天最好默认打开，边播边答疑；
- 标签和分类必须准确，否则你连被看见的资格都没有。

这背后的实操逻辑很简单：
**Steam 不是只负责“挂个页面”，而是试玩闭环里最硬的公开转化中台。**

Steam 应该承担三件事：
1. 收愿望单
2. 承接公开试玩
3. 给内容爆点提供一个标准落点

#### C. Reddit / 小红书负责“把过程讲成证据”
Reddit 和小红书都不适合硬广，但很适合做“过程型内容”：
- 版本前后对比
- 玩家反馈采纳前后
- 失败案例和改动思路
- 一个机制为什么重做

Reddit 的优势在于：
- 海外用户愿意讨论开发过程和设计取舍
- 真诚复盘比广告口播更容易被接受
- 适合把试玩后的改动，包装成“我们听了这些反馈，所以做了这些改动”

小红书的优势在于：
- 2024 ChinaJoy 数据显示其月活 3.3 亿，游戏玩家超 1.1 亿，游戏笔记曝光增速非常猛；
- 游戏内容在小红书不是孤立存在，而是会和美术、二创、角色、人设、生活方式内容混在一起，形成复利讨论；
- 适合视觉风格、开发幕后、前后反差、改动记录这类“可种草”内容。

但要记住一句狠话：
**Reddit / 小红书负责把人打动，不负责替你做承接。承接做不好，热度全漏。**

### 4. 真实案例里最值钱的模式，不是爆帖，是“试玩集中爆发”

#### 案例 1：Reddit / IndieDev，15 天 +1000 愿望单
2025 年一篇 IndieDev 分享里，一个 4 人团队在公开 demo 后 15 天拿到接近 1000 个愿望单。关键动作不是花钱买量，而是：
- Steam 页面提前约 10 个月上线，先积累基础认知；
- demo 发布前 1-2 个月，给 400+ 中小 Vtuber 发邮件；
- 收到约 100 个回复，最终约三分之一形成合作；
- demo 周形成一波试玩集中爆发，带来 Steam “New & Trending” 的自然曝光；
- 团队同时拿到了大量关于教程复杂、音效不足、打磨不够的具体反馈。

这里最关键的不是“400 封邮件”，而是：
**他们把试玩集中在同一个窗口爆发，先造第一波热，再吃 Steam 算法二次放大。**

#### 案例 2：Discord 官方建议，本质就是把社区当测试运营后台
Discord 官方模板非常克制，这恰恰说明最优做法不是造一个复杂社区，而是造一个低摩擦测试系统：
- 有试玩日程
- 有屏幕共享
- 有反馈专区
- 有 bug 上报模板
- 有规则和角色分层

这套东西本质上就是：
**把玩家行为从“随便聊”变成“按路径贡献内容”。**

#### 案例 3：小红书的“复利社区”逻辑
2025 年行业观察提到，小红书对游戏厂商越来越重要，不只是因为流量，而是因为玩家会围绕 IP、攻略、二创、线下、审美和争议持续产出讨论，形成复利。

换句话说：
- Steam 更像转化仓
- Discord 更像测试后台
- 小红书更像情绪与认知发酵场

你如果把试玩后的改动、玩家名场面、Boss 压线翻盘、塔 Build 变化做成连续内容，就不是一次发帖，而是在养一个会越滚越大的叙事。

### 5. 冷启动试玩闭环的标准结构

#### 闭环总公式
`内容钩子 → 商店页/试玩页 → Demo 内置反馈口 → Discord 或表单沉淀 → 版本修正公告 → 再次内容传播`

#### 每一步的目标
1. **内容钩子**：让玩家愿意点
2. **商店页/试玩页**：让玩家能立刻试玩或愿望单
3. **Demo 内置反馈口**：让玩家玩完不是流失，而是表达
4. **Discord/表单沉淀**：把反馈结构化
5. **版本公告**：向玩家证明“你说的话有后果”
6. **再次传播**：把修改结果重新做成内容，进入下一轮

### 6. Demo 本身要怎么设计，才能服务发行而不是只服务测试
试玩版最蠢的做法，是把“游戏前 20 分钟”原样丢出去。那是开发视角，不是发行视角。

试玩版应该满足四件事：
1. **3 分钟内让用户看懂核心机制**
2. **10-15 分钟内给一次强爽点或强翻盘**
3. **结束时明确给一个未完成欲望**
4. **退出前给一个清晰动作：愿望单 / 进群 / 填反馈**

#### 针对《光与朽》的试玩结构建议
- **前 2 分钟**：直接让玩家打出一次激光折射清怪，别慢吞吞讲世界观
- **第 5-8 分钟**：放一个明显的 build 分叉，让玩家感受到“这把和下一把能不同”
- **第 10-12 分钟**：安排一次 Boss 压线但可翻盘的高潮
- **试玩结尾**：不要只弹“感谢游玩”，而是给三个动作入口：
  - 加 Steam 愿望单
  - 进 Discord 报名下一轮试玩
  - 提交这局卡点/最爽 moment

### 7. 反馈采集要结构化，不然全是噪音
反馈系统至少分成三层：

#### 层 1：量化问题
- 你在哪一波第一次明显卡住？
- 你本局最常用的塔是什么？
- 你是否理解激光折射规则？
- 你会不会想再开一局？

#### 层 2：情绪问题
- 你最爽的时刻是什么？
- 你最烦的地方是什么？
- 哪一段让你想退出？

#### 层 3：可复现问题
- 地图 / 波次 / 塔组合
- 复现步骤
- 截图 / 视频

这三层必须分开。别把“太难了”“不爽”“bug了”混成一锅粥，不然做不出版本决策。

### 8. 真正决定口碑能不能滚起来的，不是回复速度，而是“证据化回馈”
玩家真正吃这一套：
- 上周你提的问题
- 本周我们改了
- 这是改前 vs 改后
- 下周继续测这个点

所以每次更新都要尽量带：
- 一条改前后对比视频
- 一段开发者解释，说明为什么这么改
- 一条下一轮测试邀请

这就是所谓的 **proof of listening（可见的倾听证据）**。

### 9. 《光与朽》可以直接照抄的 14 天冷启动试玩计划

#### 第 1-3 天：搭承接
- Steam 页面确认 demo 按钮、标签、愿望单 CTA 都到位
- Discord 建最小测试服：公告、补丁、反馈、bug、试玩语音房
- 做试玩后反馈表单，字段别超过 8 个

#### 第 4-6 天：准备爆点
- 做 3 条核心短视频：
  - 激光折射清屏
  - Boss 压线翻盘
  - Build 分叉前后差异
- 做 1 条“我们根据试玩改了什么”的模板贴
- 准备 Vtuber / 小主播 / 独立游戏群体外联名单

#### 第 7 天：开公开试玩
- 所有内容统一只导一个动作，优先导向 Steam demo
- demo 内部再导 Discord 和反馈
- Discord 开定时试玩活动

#### 第 8-10 天：集中听反馈
- 每天整理 3 件最高频问题
- 不急着全改，先抓“理解成本高”“爽点来得慢”“失败不服”这三类
- 在 Discord 和 Steam 公告同步“我们看到了什么”

#### 第 11-14 天：做第一次可见迭代
- 发一个小补丁
- 发改前后视频
- 再开一次试玩活动
- 把“玩家反馈被采纳”的过程发到 Reddit / 小红书

### 10. 我给主人的最终判断
这个细分课题的结论就一句：
**零成本冷启动不是内容运营问题，而是试玩承接系统问题。**

内容只负责拉门，试玩闭环才负责留人。 
如果《光与朽》现在要做第一波冷启动，最优先级不是多发十条素材，而是把这四个点先打牢：
- demo 前 10 分钟爽点结构
- Steam 愿望单和 demo 按钮显眼度
- Discord 最小测试服
- 反馈到版本公告的证据链

只要这套链路跑起来，我们后面不管是上 Steam 节、找小主播、做小红书种草，还是转微信小游戏测试，都不会再是散兵游勇。

## 【专家进阶细分】零成本冷启动里的“种子玩家飞轮”：如何把第一批玩家变成KOC与裂变节点

### 1. 为什么这是运营与发行维度下一个未攻克课题
运营与发行主线的五个大课题，加上“试玩闭环设计”，知识库已经打完第一轮地基。下一步真正该补的，不是继续聊泛泛的社区运营，而是更狠、更落地的一个细分能力：
**怎么把第一批愿意玩、愿意聊、愿意反馈的人，变成会替你拉新、替你发内容、替你放大信任的种子玩家飞轮。**

很多独立团队死法都一样：
- 有一波试玩流量；
- 有几十个进群玩家；
- 甚至有几条不错的帖子；
- 但没人持续发内容，没人带朋友来，没人替你证明“这游戏值得现在就关注”。

这说明你只有“社区”，没有“节点”；只有“人头”，没有“杠杆”。

所以这次课题，我把运营与发行维度继续往专家层下钻，专门研究：
**种子玩家飞轮（Seed Player Flywheel）= 招募 → 分层 → 共创 → 展示 → 奖励 → 二次传播。**

### 2. 2025-2026 的最新共识：冷启动不是攒群人数，而是培养可传播节点
根据 Discord 官方 2025-2026 游戏开发者文档、Steam Next Fest 2026 官方文档、presskit.gg 的 Next Fest 指南、Alinea Analytics 对试玩与愿望单转化的观察，以及 2026 年小红书 Build in Public 案例，可以归纳出一个非常清楚的行业共识：

**冷启动最值钱的资产不是“群里有多少人”，而是“有多少人愿意公开替你说话”。**

也就是说，第一批玩家至少要被分成三类：
1. **反馈型玩家**：愿意报 bug、提建议；
2. **展示型玩家**：愿意发截图、战报、Build、翻盘片段；
3. **带人型玩家**：愿意拉朋友一起玩、一起讨论、一起二创。

真正有效的社区运营，不是把他们都扔进一个群里闲聊，而是把这三类行为设计成明确路径，让玩家知道：
- 我为什么值得留下；
- 我发什么内容最容易被看见；
- 我帮你传播之后会得到什么身份、特权或成就感。

### 3. 三个平台的角色分工：别让每个平台干同一件事

#### A. Discord：把“好感”变成“参与感”
Discord 官方 2026 文档对游戏社区的建议已经很直接：社区频道要围绕反馈、公告、bug 报告、开发者可见回复来设计，别做成吵闹群。官方还明确强调，开发者哪怕一天只回一次，也比一整月发一篇长文更有存在感。

这意味着 Discord 在种子玩家飞轮里最适合承担的，不是宣传，而是：
- 识别高意愿玩家；
- 给他们可见的参与身份；
- 让他们的反馈、Build、名场面被官方看见并点名；
- 把他们从“路人”转成“自己人”。

**实操建议：**
- 频道极简化，只保留 `#announcements`、`#patch-notes`、`#build-feedback`、`#bug-reports`、`#clips-and-moments`、`#playtest-party`；
- 用身份组区分 `Playtester`、`Bug Hunter`、`Theorycrafter`、`Clip Dragon`；
- 每周固定做一次“本周最佳反馈 / 最骚Build / 最强翻盘时刻”置顶展示。

结论一句：**Discord 的任务不是热闹，是把高意愿玩家养成长期节点。**

#### B. Steam / Demo：把“试玩”变成“证明”
Steam Next Fest 2026 官方文档和 presskit.gg 的实操指南都反复强调几件事：
- demo 要提前放出，不要卡活动当天才上线；
- demo 内必须有清晰反馈入口；
- fest 期间要有专门的反馈线程或 Discord 入口；
- 商店页、截图、标签、capsule art 才是大多数愿望单的主要转化位。

Alinea Analytics 2026 对 Next Fest 游戏的观察也很关键，说明：**试玩人数不是唯一价值，试玩后能不能带来愿望单、购买和传播才是硬结果。**

所以 Steam 在种子玩家飞轮里的角色，不只是“挂个商店页”，而是提供一个公共证明场：
- 玩家玩过 demo；
- 玩家愿意愿望单；
- 玩家愿意在社区、讨论区或视频里晒出体验；
- 这些公开痕迹反过来又会增强新玩家信任。

**实操建议：**
- demo 结尾不要只写“感谢游玩”，要给三个按钮：`加入愿望单`、`加入 Discord`、`上传你的最佳Build/翻盘截图`；
- Steam 公告和讨论区固定开一个主题：`本周最佳套路 / 最强翻盘 / 卡关吐槽集中贴`；
- 每次更新后，把采纳了哪些玩家反馈写进 patch note，让玩家知道“你说的话真的改变了游戏”。

#### C. 小红书 / Reddit：把“过程”变成“社交证据”
2026 年小红书关于 Build in Public 的案例非常说明问题。极客公园和行业报道都指出，小红书现在能承接的是一个完整闭环：洞察需求、公开构建、共创迭代、种子用户聚集、口碑扩散。Dreamoo 一类案例的关键，不只是拿到自然流量，而是**通过持续公开迭代把用户变成共创者和传播者**。

Reddit 也是同一逻辑，只不过更偏海外开发过程、设计讨论和硬核反馈。它不适合硬广，但非常适合发：
- 版本前后对比；
- 玩家建议采纳前后；
- 一条机制为什么被砍或被增强；
- 玩家最离谱的翻盘录像。

**关键判断：**
- 小红书负责建立“这团队在认真做东西”的人格信任；
- Reddit 负责建立“这游戏机制真的有人讨论”的专业信任；
- 二者共同作用，都是在替你的游戏制造“社会证明”。

### 4. 种子玩家飞轮的标准结构

#### 总公式
`招第一批人 → 给身份 → 给舞台 → 给反馈回路 → 给被看见的奖励 → 让他们自发带来下一批人`

#### 具体六步
1. **招募**：只招高意愿，不贪数量
2. **分层**：把反馈型、展示型、带人型玩家拆开对待
3. **共创**：让玩家的意见能真正进入版本
4. **展示**：官方主动展示玩家内容，而不是被动点赞
5. **奖励**：给身份、命名权、测试资格、皮肤彩蛋、署名，而不一定给钱
6. **二次传播**：把“玩家参与过”的证据做成下一轮内容素材

### 5. 最值钱的实操原则，不是送福利，而是制造“被官方看见”的快感
很多团队一说种子用户，就想到发 key、送礼包、抽奖。这个思路不算错，但太浅。

2025-2026 更有效的做法，是给玩家三种更高等级的回报：

#### A. 身份回报
比起一份小礼包，更有效的是：
- 特殊 Discord 身份组
- 名场面周榜入选
- patch note 致谢
- 下轮封测优先资格
- 某个塔、敌人、成就彩蛋的命名权候选

这是把玩家从“消费者”变成“贡献者”。

#### B. 影响力回报
玩家愿意持续参与，往往不是为了省几块钱，而是为了确认一件事：
**我的建议让游戏变好了。**

所以每次版本更新都要做一件事：
- 标注“本次改动来自哪些玩家反馈”；
- 点名展示代表性讨论；
- 告诉玩家你采纳了什么、没采纳什么、为什么。

这会直接提高社区信任密度。

#### C. 社交回报
展示型玩家和带人型玩家，本质都在追求一种东西：
**被看见。**

所以你必须主动提供可晒素材：
- 局后战报图；
- 最强 Build 截图模板；
- “你撑到了第几波”挑战图；
- Boss 压线翻盘回放；
- 一键复制的分享文案。

没有可晒素材，玩家就算喜欢，也懒得替你传播。

### 6. 对《光与朽》的直接落地方案
《光与朽》最适合做的，不是大而全社区，而是 **狠、窄、可复利的种子玩家飞轮**。

#### 第一步，先招 30-50 个“能打的种子玩家”
来源优先级：
1. 已经玩过版本、反馈比较认真的老测试；
2. 看塔防/肉鸽内容会主动评论的玩家；
3. 愿意晒 Build、讨论套路、发录像的人。

别先追 500 人群，没意义。先把 30-50 个高质量节点养熟。

#### 第二步，把玩家按行为分层
- **Bug Hunter**：专找卡点和异常
- **Build Crafter**：研究塔组合、路线、词条联动
- **Clip Hunter**：专门晒翻盘、高能清屏、离谱阵容
- **Scout**：愿意拉朋友一起来测

#### 第三步，做三个固定节目
1. **每周最佳 Build**
2. **每周最离谱翻盘录像**
3. **本周玩家推动的版本改动**

这三个栏目会同时服务：
- Discord 留存
- 小红书内容素材
- Steam 公告素材
- 后续招募页的社会证明

#### 第四步，把传播动作做轻
给玩家准备：
- 一张统一风格的战报模板；
- 一句可复制文案，例如“我这把激光折射塔差1秒守住Boss，你能过第几波？”；
- 进群邀请码或下一轮试玩申请口。

让玩家传播时不用动脑，不然他们根本不会发。

#### 第五步，建立“邀请不是拉人头，是拉战友”的机制
不要粗暴搞“拉3人送礼包”。那味太蠢，也太像微商。

更适合《光与朽》的方式是：
- 邀请来的朋友完成试玩后，邀请人解锁一次“测试服提前进场”或“专属称号”；
- 双人试玩活动，邀请好友一起挑战同一关卡或同一Build主题；
- 社区活动按“最佳组合打法”评选，而不是按“谁拉的人多”评选。

这样拉新行为会更像共同作战，而不是廉价分销。

### 7. 我给主人的最终判断
零成本冷启动做到后面，拼的根本不是内容产能，而是**你有没有把第一批喜欢你的人，训练成能替你扩大信任的人。**

说白了：
- 普通社区运营是在堆人；
- 高级运营是在养节点；
- 真正值钱的发行能力，是把节点连成飞轮。

对《光与朽》来说，现阶段最该做的不是追大曝光，而是尽快建立一批会反复出现的 ID：
- 他们会测；
- 会聊；
- 会晒；
- 会带朋友；
- 会让路人觉得“这游戏已经有人真在玩，而且真有人上头”。

这批人一旦成型，后面无论你上 Steam、做 Discord、发小红书，都会轻松很多。没有他们，所有冷启动都只是短命热闹。

## 【专家进阶细分】Steam 愿望单与 Demo 节奏运营：如何把试玩流量变成上线销量

### 1. 为什么这个课题是运营与发行维度的“下一个未攻克点”
运营与发行主路线里，LTV/CAC、IAA、混合变现、出海素材、零成本冷启动都已经补过了。
但《光与朽》如果真要上线，最关键的一刀还没补透：**Steam 商店页、Demo、愿望单、试玩节奏，到底怎么串成一个可转化的漏斗。**

这不是“宣发小技巧”，这是 PC 独游发行的命门。因为社区热闹不等于销量，真正决定首发起量的，是：
- Demo 有没有把人钩住；
- 愿望单有没有持续增速；
- Steam 算法在节日前 14 天有没有把你识别成“正在起势的游戏”；
- 上线时这些愿望单能不能转成第一周购买。

所以我把这个课题定为：**Steam 愿望单与 Demo 节奏运营**。这才是《光与朽》现在最该学的发行硬功。

### 2. 2025-2026 的核心行业判断：愿望单总量很重要，但“近14天增速”更关键
本轮搜索里最值得记住的，不是某个鸡血案例，而是一条很硬的数据线：

#### 判断 A：Steam Next Fest 不是单纯拼总愿望单，而是拼“节前 14 天的愿望单速度”
根据 How To Market A Game 2025 年 3 月的公开分析：
- **Steam Next Fest 开始前 2 周新增愿望单，与 Next Fest 成绩高度相关，相关系数达到 `r = 0.819`**。
- 到了 2026 年 4 月的复盘里，作者进一步强调：所谓 velocity，本质上就是**Steam Next Fest 前 14 天拿到多少愿望单**。

这意味着一个很现实的结论：
**不是越早把 Demo 扔出去越好，而是要让 Demo 在节日前形成“可持续起势”。**

#### 判断 B：很多团队以为“早点放 Demo 最稳”，其实更稳的是“先小规模测，再卡节奏公开”
How To Market A Game 在 2025-2026 的文章里反复提到一个趋势：
- 先用 playtest、小范围测试、创作者预览把 Demo 调顺；
- 然后在 Next Fest 前 1-2 周正式推公开 Demo；
- 同步点邮件、创作者、社媒、社区，把愿望单速度堆起来。

这比“提前几个月把半残 Demo 长期挂着”更聪明。后者最大的问题不是没流量，而是：
- 首波流量吃掉后，Demo 质量还不够；
- 差评反馈提前积累；
- 愿望单新增速度掉平，算法不再觉得你在起势。

### 3. Demo 不是给人看完内容的，是给人留下“我愿意买完整版”的冲动
#### 判断 C：Demo 最优目标不是时长越长越好，而是留下“内容还会变大”的预期
Mark Brown 在 2025 年的 Steam Next Fest Demo 经验文里给了一个特别实用的指标：
- 可以通过 Steamworks 的 `median time played` 检查 Demo 长度；
- **建议目标区间是 30 到 90 分钟。**

这个范围很关键。太短，玩家还没理解乐趣核心；太长，玩家会把最想买的冲动在试玩期耗掉。

对塔防/Build 型游戏尤其如此。最好的 Demo 结构，不是把全部系统塞满，而是：
1. 先在前 3-5 分钟让玩家立刻理解独特机制；
2. 在中段让玩家玩到一次“我居然打出神配合”的爽点；
3. 在结尾故意露出更强敌人、更深 Build、更复杂地图，让玩家产生“完整版才是真正开始”的感觉。

一句话：
**Demo 的任务不是交作业，是制造欲望。**

### 4. 2026 的几个实操信号，说明“预热期组织能力”比节日本身更值钱
#### 信号 A：Steam 官方把 Press Preview 和 Demo 审核时间卡得很死
根据 Steamworks 2026 年 2 月 Next Fest 页面：
- 如果想让 Demo 在 Press Preview 开始时就可玩，**需要在 1 月 26 日前提交 Demo build（以及可选的 Demo 商店页）审核**。

这说明两件事：
1. 真正有准备的团队，不是节日当天才开始动，而是至少提前数周把试玩、审核、页面、预览曝光都接起来；
2. 发行节奏不是“内容做完再说”，而是必须反推生产排期。

#### 信号 B：成功案例越来越像“试玩预演 + 邮件唤醒 + 创作者集中触发”
How To Market A Game 在 2025 年 10 月 Next Fest 复盘里提到一类跑出来的项目：
- **正式 Demo 在 Next Fest 前约 2 周上线；**
- **此前已有约 500 名玩家参加过 playtest；**
- Demo 公开后立刻做创作者 outreach；
- 同时尽快触发 Steam 的“邮件通知愿望单用户”按钮。

这套动作的本质不是多新鲜，而是把“试玩质量验证”和“愿望单加速”拆成两段：
- 第一段用小样本修 Demo；
- 第二段用公开曝光冲 velocity。

这个节奏对独立团队特别重要，因为你没钱烧错一次大曝光。

### 5. 愿望单真正值钱的地方，不在数量本身，而在它会不会转单
#### 判断 D：愿望单转销量没有神话比例，关键看来源质量和上线时机
根据 GameDiscoverCo 2025 年 10 月的统计：
- 仅看**上线时拥有 25k+ 愿望单**的游戏，首周愿望单转购买的**中位数约为 0.15x**。

这说明两件事：
1. 不要把愿望单当成保证销量的许愿池；
2. 愿望单质量差，转化一样会烂。

而 Alinea Analytics 2026 年关于 Steam Next Fest Demo 的研究又给了另一个角度：
- 研究核心不是“所有愿望单都一样”，而是**玩过 Demo 的愿望单用户，后续购买意愿与转化表现会明显不同**。

这和运营直觉完全一致：
- 纯看图点收藏的用户，很虚；
- 真下载 Demo、玩到爽点、愿意回访的用户，才更像未来买家。

所以我们要盯的，不只是“总愿望单数”，而是愿望单来源分层：
- 节日前新增的；
- 玩过 Demo 的；
- 来自创作者视频/直播的；
- 来自社区反复互动的。

### 6. 对《光与朽》的最优打法，不是“尽早上线 Demo”，而是“先用试玩修体验，再集中打起势”
《光与朽》是激光塔防，卖点不是纯美术，而是：
- 激光塔之间的联动；
- 波次压力下的临场决策；
- Build 成型后的爽感；
- 一局里从快崩到翻盘的戏剧性。

这类游戏最怕两件事：
1. 玩家前 5 分钟没看懂独特点；
2. Demo 里把后劲都玩完了，愿望单反而不涨。

所以更适合《光与朽》的发行节奏是：

#### 阶段一：内测与封闭试玩（现在就该干）
目标：修掉“看不懂、不爽、不想留”的问题。
- 拉 50-200 个种子玩家做封闭试玩；
- 核心只测四件事：
  1. 前 3 分钟是否看懂激光机制；
  2. 第一次爽点是否在 10 分钟内出现；
  3. 失败后是否愿意立刻再开一把；
  4. 试玩结束后是否会说“完整版什么时候上”。
- 不急着公开大放量，先把负反馈在小池子里消化掉。

#### 阶段二：公开 Demo 前 14 天冲 velocity
目标：把 Steam 算法和外部创作者一起点燃。
- Demo 正式公开前，把商店页胶囊图、短描述、GIF、预告片都改到“3 秒看懂”；
- 公开 Demo 的同时做三件事：
  1. 邮件/Steam 愿望单通知；
  2. 找中小创作者集中试玩；
  3. Discord / 小红书同步发“极限翻盘”“离谱 Build”短内容。
- 所有内容统一指向一个动作：**先试玩，再加愿望单。**

#### 阶段三：Demo 结构设计
最适合《光与朽》的 Demo 长度建议：**30-60 分钟**。
原因：
- 足够让玩家经历理解机制 → 搭配塔组 → 波次压力 → 翻盘爽点；
- 又不会把完整版成长空间提前榨干。

具体结构建议：
1. **0-5 分钟**：超快教会激光折射/联动核心；
2. **5-20 分钟**：给出 2-3 次明确 Build 选择；
3. **20-40 分钟**：让玩家经历一次“差点崩，但靠组合扳回”的高光；
4. **结尾**：明确展示完整版里还有更复杂塔、地图、敌人机制。

#### 阶段四：只盯四组数据，别被表面热闹骗了
1. **Demo 下载率 / 商店页访问转试玩**
2. **试玩完成率与中位时长**
3. **试玩后新增愿望单率**
4. **节前 14 天日均愿望单增速**

如果只有曝光，没有试玩转愿望单，那素材有问题；
如果试玩多，但中位时长低，说明前几分钟没钩住；
如果试玩时长高，但愿望单不涨，说明 Demo 结尾没有把购买欲吊起来。

### 7. 我给主人的最终判断
Steam 发行最蠢的误区，就是把 Demo 当“送给玩家玩的免费样品”。
不是。**Demo 本质上是销售漏斗里最贵的转化页。**

对《光与朽》来说，现阶段正确打法非常明确：
- 先做封闭试玩，修掉理解门槛和前 10 分钟爽点问题；
- 再在关键节日前 14 天公开 Demo，集中打愿望单速度；
- 商店页、创作者内容、社区讨论，全都围绕同一件事服务：
  **让玩家玩完一局后，立刻想点愿望单。**

谁能把这个链条打顺，谁就不是“做了个 Demo”，而是在为首发销量提前铺路。

## 【专家进阶细分】零成本社区冷启动的下一课：KOC 种草 + 微型创作者集中引爆

### 1. 为什么这是运营与发行维度下一个该补的点
运营与发行路线图里的五个主课题，知识库已经全部铺过一轮。真正还没打穿的，是最后那节“口碑与社区零成本冷启动”的**下一层实战能力**：

**不是你自己发内容，而是怎么让别人替你发，且在同一时间窗口形成可放大的第一波声量。**

这轮补的是：
**KOC 种草 + 微型创作者集中引爆（Micro-creator burst）**。

它本质上是把：
- Discord 当承接池
- Steam Demo 当转化页
- Reddit 当讨论验证场
- 小红书当种草扩散场
- 微型创作者当第一批放大器

如果前一课“试玩闭环”解决的是承接，
那这一课解决的是：**第一波谁来替你把门踹开。**

### 2. 2025-2026 的行业新结论：零成本冷启动不再靠“大号带飞”，而靠“小号密集共振”
根据 Discord 官方 2025《The Game Developer Playbook》、Steamworks Next Fest 文档、Reddit 2026 独立开发者案例、小红书 2025 趋势公开资料，可以得出一个很硬的判断：

**独立游戏早期冷启动，最值钱的不是拿下一个超大 KOL，而是在短时间内拿下足够多的中小创作者、核心玩家与 KOC，让算法与社区同时感知“这东西开始冒头了”。**

原因很现实：
1. 大号贵，而且经常不稳定；
2. 中小创作者更愿意试玩新东西，尤其愿意吃“开发者真在改”的故事；
3. 对 Steam、Reddit、小红书这类平台来说，**短时间内的连续讨论** 比孤立的一次爆帖更像真实热度；
4. 对 Discord 来说，能沉淀进群、反复回流的人，往往本来就是小圈层玩家，不是纯路人流量。

### 3. 平台角色重新拆分，不要乱打一锅粥

#### A. Discord：不是曝光位，是“种子用户培养皿”
Discord 官方 2025 的建议非常明确，测试社区应该极简，目的就是让玩家**容易试玩、容易反馈、容易被组织起来**。

这意味着 Discord 在这一课里不是负责拉大盘，而是负责：
- 给第一批 KOC 和核心玩家一个“内部感”空间；
- 让他们提前体验 build；
- 给他们明确的试玩任务、反馈模板、活动时间；
- 让他们自然产出截图、吐槽、翻盘录像和讨论话题。

一句话：
**Discord 的价值不是人数，而是能不能养出第一批愿意反复说你好的“铁杆传声筒”。**

#### B. Steam Demo：公开转化页，必须准备好接爆点
Steamworks Next Fest 文档里有两个特别值钱的点：
- demo 上线 14 天内，开发者可以向 wishlisters 发送一次 demo release notification；
- Wrap-up 页面会给 demo 试玩量高的产品额外曝光。

这意味着你不能等内容热了才想起 demo。
正确顺序是：
1. 先把 demo、商店页、标签、反馈口全部搭好；
2. 再组织一轮集中曝光；
3. 让所有外部内容统一导向试玩或愿望单。

Steam 在这套打法里不是被动仓库，而是：
**所有外部声量最后都要落地成交的主转化页。**

#### C. Reddit：最适合验证“哪个说法最容易被信”
Reddit 不吃硬广，但吃真过程、真改动、真取舍。
尤其在独立游戏社区里，下面几类内容更容易被接受：
- 改前改后对比
- 一个机制为什么砍掉或重做
- 玩家反馈后你们具体改了什么
- 试玩版上线后的数据和教训

Reddit 的意义不是立刻卖货，而是帮你测：
**用户究竟更吃“机制新奇”“视觉辨识度”“翻盘爽感”，还是“开发者真诚”。**

#### D. 小红书：不是卖货位，是“口碑种草加速器”
公开资料显示，小红书 2024 已超 3 亿月活；2025 趋势资料反复强调，平台核心是“种草”，并且更依赖 UGC、KOL、KOC 混合扩散，而不是品牌自说自话。

对游戏来说，小红书特别适合：
- 视觉强识别内容
- 反差改造内容
- 开发幕后
- 高能名场面
- 玩家真实评价截图

2026 年《苏丹的游戏》在小红书累计超 5.9 亿浏览，就是最凶的信号之一：
**当一个游戏具备可讨论的人设、剧情、视觉或情绪点，小红书完全能把它从游戏圈打到泛内容圈。**

### 4. 真正能打的不是“投博主”，而是“设计一套愿意被转发的素材母体”
所谓 KOC / 微型创作者集中引爆，不是群发一句“求帮忙玩一下”。
真正有效的做法，是提前准备一组**特别容易被二次表达**的内容母体：

#### 素材母体 1：3 秒钩子片段
- Boss 压线
- 激光连锁清屏
- 差 1 秒翻盘
- 离谱 Build 逆转

#### 素材母体 2：过程型对比
- 改前 vs 改后
- 玩家吐槽 vs 版本修复
- 新手乱摆 vs 老手布线

#### 素材母体 3：可参与挑战
- “你能守到第几波？”
- “这局三选一你会怎么选？”
- “只准带一种塔能不能过？”

#### 素材母体 4：开发者证据链
- 本周收到最多的 3 个反馈
- 我们因此改了什么
- 下轮测试想验证什么

这些内容的共同点不是漂亮，而是：
**别人一看就知道怎么转述。**

### 5. 2026 年更实用的冷启动结构：小规模封测 → 集中外扩 → 回收证据 → 二次放大

#### 第一阶段：封闭种子池（20-100 人）
目标：先养 KOC，不急着冲大盘。

做法：
- Discord 只收高意愿玩家、朋友转介绍、相关品类核心用户；
- 每轮测试给非常明确的任务，比如“第 8 波难不难”“是否理解激光反射”；
- 鼓励他们发截图、短 clip、吐槽语录；
- 把最有传播力的内容回收成下一轮外部素材。

#### 第二阶段：微型创作者集中引爆（同一周打出去）
目标：制造“这几天到处都在看到它”的错觉。

做法：
- 不找一个超大号，优先找 20-50 个中小主播 / 垂类账号 / 小红书 KOC；
- 给他们同一时间窗口的试玩权限与简洁素材包；
- 不要统一口径文案，只给几个可选角度：激光机制、翻盘爽感、开发者真改、离谱 build；
- 所有内容只导一个动作，优先导向 Steam demo，其次导 Discord。

#### 第三阶段：证据化回收
目标：让外部用户看到“不是在喊，而是在滚”。

做法：
- 24 小时内整理第一波高频反馈；
- 48-72 小时内发第一版“我们改了什么”；
- 同步发布改前改后短视频；
- 再邀请下一轮试玩。

这个动作会直接提升三件事：
1. 社区信任感
2. 创作者愿意继续跟进的概率
3. 平台算法对内容持续性的判断

### 6. 给《光与朽》的最狠落地打法
《光与朽》不是靠世界观吃饭的项目，它最值钱的是：
- 激光折射有辨识度；
- 布塔和 build 有讨论空间；
- 翻盘瞬间很容易出短视频；
- 改动前后很适合做对比内容。

所以最适合我们的不是“大而广宣发”，而是下面这套：

#### A. Discord 只做精，不做大
频道先控制在 5 个以内：
- `#公告`
- `#版本改动`
- `#试玩反馈`
- `#bug提交`
- `#战报/晒图`

把玩家产出的翻盘图、奇葩 build、吐槽语录，全部当成素材矿。

#### B. 小红书主打三种内容
1. **高能名场面**：Boss 压线 1 秒反杀
2. **开发者真改**：玩家说太乱，我们把 UI / 特效 / 新手引导怎么改了
3. **Build 讨论**：这 3 个塔怎么配，评论区投票

不要发官方腔“新版本上线欢迎体验”。
那种内容在小红书基本等于自杀。

#### C. Reddit 主打“真诚复盘”
内容模板直接固定：
- 我们做了个激光塔防 demo
- 玩家第一次试玩最常卡在哪
- 我们改了哪三点
- 想继续收这两个问题的反馈

比吹自己“多好玩”有用得多。

#### D. Steam 商店页和 demo 结尾必须统一动作
只保留一个优先动作：
**试玩完 → 加愿望单。**

次级动作才是：
**进 Discord → 给反馈 → 报名下一轮测。**

别一口气让玩家做五件事，不然一件都不做。

### 7. 我给主人的最终判断
运营与发行里，零成本冷启动最蠢的误区，就是以为“勤发内容”就算在做社区。
不是。

**真正值钱的是：先养一小批会替你说话的人，再让他们在同一时间窗口把你的机制、名场面和改动证据打出去。**

对《光与朽》来说，现阶段最该做的不是追大号，也不是到处乱发。
而是：
1. 先养 30-50 个高意愿测试玩家；
2. 每周产出 3 类可转发内容母体；
3. 找一批中小创作者和 KOC 做同周集中试玩；
4. 72 小时内拿改动证据回灌社区。

这套打通，我们拿到的就不只是曝光，
而是第一批真正会帮我们把口碑滚起来的种子用户。

## 【专家进阶细分】微型创作者外联与试玩转化闭环：如何用 20-50 个小创作者打出第一波可承接声量

### 1. 为什么这是运营与发行维度下一个未攻克点
前一轮我们已经补到“KOC 种草 + 微型创作者集中引爆”，但还差最关键的一刀：
**不是找到创作者就完了，而是怎么让这批小创作者的流量不白白蒸发，真正落到试玩、愿望单、进群和可执行反馈上。**

很多独立项目死法都一样：
- 发了一轮 key；
- 几个小主播也播了；
- 帖子和短视频看着热闹；
- 结果没有稳定试玩入口、没有统一 CTA、没有反馈回收、没有二次传播证据。

这说明你做的是“碰运气曝光”，不是“运营系统”。
所以这一课的核心，是把微型创作者从“宣传渠道”升级成**试玩漏斗的第一推动器**。

### 2. 2025-2026 的最新共识：小创作者的价值，不在单条爆量，而在高密度、可复制、可追踪
根据本轮网络调研与已有知识库，几个判断已经非常清楚：

#### 判断 A：Steam / Demo 型项目，创作者外联必须前置，而不是活动开始后再补救
根据 **presskit.gg《Steam Next Fest Complete Guide [2026]》**：
- Demo 最好在活动前几周就上线；
- **内容创作者外联应在活动前约 1 周开始**；
- **68%-88% 的愿望单来自根本没玩 Demo 的人**，说明真正决定结果的不是 Demo 本身，而是 **商店页表达 + 外部声量 + 活动前的起势**。

这句话很狠，但是真相：
**创作者不是帮你“解释全部游戏”，而是帮你把人推到商店页或试玩页。真正成交的是承接页。**

#### 判断 B：小创作者比大号更适合冷启动，因为他们更便宜、更愿意试新东西、互动密度更高
根据 **Metricus 2026 行业观察**，2026 年更实际的独立游戏获量策略，是：
- YouTube Shorts / 短视频内容做算法预热；
- Discord 做留存层；
- **1,000-10,000 CCV 的 micro-influencer 做短期 burst lift（短时抬升）**。

这背后的逻辑很直接：
- 大号带来的是“单次大曝光”，风险高、议价差；
- 小创作者带来的是“多点同时发声”，更像真实热度；
- 对 Steam、Reddit、小红书、B 站这类平台来说，**连续讨论** 比 **孤立爆帖** 更像值得继续分发的信号。

#### 判断 C：优秀案例不是“找了谁”，而是“把曝光集中在同一时间窗口”
根据 **How To Market A Game 2025/2026 的 Next Fest 复盘**：
- 有项目会在 **活动前 2 周公开 Demo 并同步做 creator outreach**；
- 有项目会立刻使用 **“Email Wishlisters”** 按钮去唤醒已有用户；
- 案例里还能看到类似 **YAPYAP** 这种玩法：通过 Medal 的 clip 任务发放 key，在几天内积累大量玩家二次传播内容；
- 类似 **LORT** 的案例，做的是“Demo 上线 + 创作者预热 + 节日前愿望单加速”这一整套 stair-step，而不是临时抱佛脚。

结论非常明确：
**不是谁先发，而是谁能在 3-10 天内连续制造“你最近总能刷到这游戏”的感觉。**

#### 判断 D：Discord 的任务不是聊天，是把曝光变成结构化反馈
根据 **Discord 官方《The Game Developer Playbook》** 搜索摘要与官方案例：
- Discord 应该成为一个可以 **monitor playtests、gather feedback、和玩家直接对话** 的“家”；
- 对试玩社区，**统一反馈模板** 非常重要；
- Discord 在 pre-launch 阶段最适合承接高意愿用户、组织测试活动、收集版本问题。

所以 Discord 不是“粉丝群”，而是：
**创作者流量进入之后的第一层过滤器。**

#### 判断 E：小红书这类平台，真正有价值的是“批量种草 + engagement 早期筛选”
根据 **WalkTheChat 2024/2025 的小红书营销资料**：
- 平台前几小时的 engagement 会影响后续流量池扩散；
- 选 KOC/KOL 时要重点看 **互动率、近 3 个月活跃度、受众匹配**；
- 很多 campaign 不是押一个大号，而是 **50-200 个 influencer 的金字塔式铺开**；
- 小体量 micro-influencer 常常能产出更自然、更像用户视角的内容。

把这个思路翻译到我们这边就是：
**不是找“最火的人”，而是找“最像目标玩家自己会发这种内容的人”。**

### 3. 微型创作者外联真正该长什么样：不是发 key，而是搭四段式闭环

#### 第 1 段：内容母体先准备好
在联系创作者前，先准备 3-5 套他们“拿去就能发”的内容母体：
1. **3 秒钩子片段**：Boss 压线、差 1 秒翻盘、激光连锁清屏。
2. **一句话卖点**：例如“这不是普通塔防，摆错一格激光就废了”。
3. **一张可截图传播的战报图**：第几波、用了什么 Build、差点死没死。
4. **一个可讨论问题**：你会选稳定塔还是赌高伤折射塔？
5. **统一落点链接**：试玩页 / Steam Demo / Discord / 报名表单，只能有一个主 CTA。

创作者最烦两种项目：
- 看不懂你在卖什么；
- 需要他自己替你想文案和剪结构。

所以你给得越轻，发得越快。

#### 第 2 段：分层发，不要乱撒
最稳的分层不是按粉丝量，而是按“适配度 × 出片概率”：
- **A 组（5-10 人）**：最懂你品类的小创作者，优先给最完整试玩资料；
- **B 组（10-20 人）**：中小创作者/KOC，给短版素材母体 + 试玩机会；
- **C 组（10-20 人）**：观察名单，只要有人对标内容表现好，再补发。

比起“发 200 封模板邮件”，更值钱的是：
**手动打穿 20-50 个真正适配的人。**

#### 第 3 段：统一时间窗口，制造“连续看见”
最佳节奏不是今天一个、明天一个、后天再补两个。
更稳的是：
- **Day -3 ~ Day 0**：提前发 key / demo / creator pack；
- **Day 1 ~ Day 3**：集中首波发出；
- **Day 2 ~ Day 4**：你自己同步发“玩家名场面 / 创作者试玩反应 / 高频反馈”；
- **Day 4 ~ Day 7**：发“我们根据试玩改了什么”。

这样平台会感知到：
- 有内容；
- 有试玩；
- 有反馈；
- 有更新；
- 不是一次性噪音。

#### 第 4 段：72 小时内必须拿回“证据”
外联最怕的不是没人回，而是回了之后你没把结果变成下一轮资产。
72 小时内至少收四类证据：
1. 哪种钩子最高播放/点击；
2. 哪句卖点最容易被复述；
3. 玩家最常卡在哪；
4. 哪个创作者带来的用户最愿意继续进群/加愿望单。

如果你没有这个回收动作，那所有外联都会退化成一次性曝光。

### 4. 该怎么联系创作者：别写商务邮件，写“低成本试一把”的邀请

#### 最蠢的话术
- “你好，我们是一个很有潜力的独立游戏团队，诚邀合作。”
- “我们做了一个非常创新的游戏，希望你能帮忙宣传。”

这种话像群发垃圾。

#### 更有效的话术结构
1. **先说为什么找他**：你之前发过塔防 / 肉鸽 / Build 讨论内容。
2. **一句话说清楚游戏钩子**：比如“这游戏的爽点是激光折射，一格摆错全盘崩。”
3. **给非常低成本的动作**：想不想先试玩 10 分钟看看值不值得发？
4. **明确你给什么**：试玩 key / Discord 测试权限 / 抢先体验包。
5. **不要逼合作**：如果觉得没感觉，直接忽略就行。

核心原则：
**你不是来求曝光，你是给对方一个可能好发、好聊、好蹭第一波的内容机会。**

### 5. 数据怎么记，不然你永远不知道谁真的值钱
创作者外联必须单独建表，不然全靠印象判断就是犯蠢。

至少记录这些字段：
- 渠道（B站 / 小红书 / 抖音 / YouTube / TikTok / Discord）
- 创作者定位（塔防 / 肉鸽 / 独游 / 整活 / 试玩）
- 粉丝量 / 平均播放 / 互动率
- 联系时间 / 回复时间 / 是否愿意试玩
- 发出内容链接
- 内容钩子类型（翻盘 / 教学 / 失败 / 挑战 / 开箱）
- 引流动作（试玩、进群、愿望单、评论）
- 带来的结果（点击、试玩、进群、反馈质量）

最终不是看“谁最大”，而是看：
**谁最能把正确的人带进下一步。**

### 6. 《光与朽》怎么直接落地
《光与朽》最适合的不是硬广式外联，而是**高压翻盘 + 激光折射 + Build 分叉**三类内容去打小创作者。

#### 适合立刻准备的 4 套素材包
1. **翻盘包**：Boss 压线、只剩最后一路、激光折射反杀。
2. **教学包**：为什么塔摆错一格整局就废了。
3. **Build 包**：同一关卡两种流派差异。
4. **改动包**：根据试玩反馈，前后版本差异。

#### 适合找的创作者，不是泛游戏大号，而是这几类
- 喜欢拆 Build、讲机制的中小 UP；
- 喜欢发“我又翻车了”的整活型创作者；
- 愿意发短试玩切片的 KOC；
- 小红书上会发“独立游戏试玩 / 游戏推荐 / 开发幕后”的账号。

#### 当前最稳 CTA
如果是《光与朽》现阶段：
- **主 CTA：进测试服 / 报名试玩 / 下载 Demo 三选一，只能保留一个主动作**；
- **次 CTA：进 Discord 或表单反馈**；
- 不要同时让用户做“加愿望单 + 进群 + 关注账号 + 填问卷 + 转发”。那会把转化直接干死。

### 7. 我给主人的最终判断
微型创作者外联的本质，不是找人替你宣传，
而是**用一批低成本、高适配、可连续发声的小节点，把你的试玩漏斗点燃。**

真正该追求的结果不是“有多少人发了”，而是：
- 有没有人在同一周连续提到你；
- 有没有人把你的卖点复述对；
- 有没有人愿意点进试玩；
- 有没有玩家愿意留下第二次反馈；
- 你有没有把这轮曝光重新做成下一轮证据。

如果这套跑顺，《光与朽》后面不管走 Steam、Discord 社区、还是下一轮 AI 视频反向立项后的试玩验证，都会轻很多。

## 【专家进阶细分】从社区冷启动到小额买量前的“可投放验证包”：素材承诺、商店页、Demo 与反馈链路一致性

### 1. 为什么这才是运营与发行维度下一个未攻克点
运营与发行主路线里的五个大课题，外加零成本冷启动下的试玩闭环、种子玩家飞轮、愿望单节奏、KOC 种草、微型创作者外联，我们已经狠狠干过一轮。

但中间还缺一块非常关键的骨头：**怎么把“有人看、有人聊、有人试玩”变成“值得进入下一阶段放量验证”的证据包。**

说白了，前面学的大多是在解决：
- 人怎么来；
- 社区怎么接；
- 愿望单怎么涨；
- 小创作者怎么引爆。

而这一个细分课题解决的是：
- **素材承诺和实际体验是否一致？**
- **商店页 / 落地页有没有把兴趣转成行动？**
- **试玩是不是把“好奇”变成“想买 / 想留 / 想继续测”？**
- **这些反馈能不能沉淀成下一轮小额买量或发行合作的证据？**

这就是我定义的 **“可投放验证包”**（Investable Validation Pack）。

没有这玩意儿，社区热闹也只是热闹；创作者发了也可能白发；试玩跑了也可能只收获一堆“挺有意思”。这种数据对后续小额买量、发行谈判、继续投入开发，价值都不够硬。

**我的判断很直白：**
下一阶段最值钱的，不是再学怎么“多曝光一点”，而是学会把曝光、商店页、试玩、反馈、留存意图，串成一套可复用、可比较、可决策的验证系统。

---

### 2. 2025-2026 的最新共识：Demo 负责开门，商店页负责转化，反馈链路负责决定你配不配放量
根据本轮调研到的 **Steamworks 官方文档（2026）**、**Discord 官方《The Game Developer Playbook》（2025）**、**presskit.gg 2026 Next Fest 指南**、**Mark Brown / GMTK 2025 Demo 经验总结**、**Alinea Analytics 2026 愿望单转化分析**，可以归纳出几个非常硬的行业结论。

#### 结论 A：Demo 不是主转化器，很多时候商店页才是
presskit.gg 基于 2025 Steam Next Fest 调研指出：**68%-88% 的愿望单来自“根本没玩 Demo”的人。**

这句话的杀伤力很大，因为它直接打脸很多独立团队的错觉：
> “只要 Demo 做得不错，玩家自己会转。”

错。

真实情况更像是：
- **Demo 决定你能不能拿到活动可见性；**
- **胶囊图、标题钩子、截图、描述、标签，决定大多数路人会不会点愿望单；**
- **真正玩 Demo 的那批人，则决定你的愿望单质量高不高、后续转单强不强。**

所以“可投放验证包”的第一原则不是把试玩做得巨长，而是：
**先把承诺说清，再让体验兑现。**

#### 结论 B：试玩和 Demo 不该互相打架
Steamworks 2026 官方 FAQ 说得非常明确：
- Steam Playtest 不影响 Next Fest 资格；
- **但不建议在 Next Fest 期间同时开 Playtest 和 Demo**；
- 原因是会把玩家分流到两套 build，削弱集中反馈与集中转化。

这背后的原则不只适用于 Steam：
**同一阶段只保留一个主承接物。**

对应到我们自己的项目：
- 一个阶段只能有一个主试玩入口；
- 一个阶段只能有一个主 CTA（试玩 / 愿望单 / 进群 三选一，最多一主一辅）；
- 一个阶段不能同时让用户跳太多页面、填太多表、进太多群。

否则数据会碎，反馈会乱，最终你根本不知道到底是哪一环不行。

#### 结论 C：Demo 越晚放，越容易把大曝光浪费在低质量体验上
Steamworks 官方允许 Demo 提前很久发布；Mark Brown 在 2025 的实际复盘里也强调，**他提前两周放出 Demo，不仅在活动前就拿到约 25,000 个愿望单，还赶在活动前修了大量问题。**

这证明一个很关键的判断：
**Demo 应该先承担“找坑”职责，再承担“大曝光”职责。**

而不是：
- 活动当天才首次公开；
- 创作者第一次玩就是公开出糗；
- 大量路人第一次接触就是 bug、难懂、节奏拖、CTA 不清楚。

这是最蠢的死法。

#### 结论 D：愿望单数量不是圣经，愿望单质量才是
Alinea Analytics 在 2026 年回看 2025 年 10 月 Next Fest 后几个已发售案例时，给了非常残酷的证据：
- **REANIMAL**：10 月愿望单池 40.8 万，试玩参与率 16.7%，上线后一周该批愿望单转买约 2.7%。
- **YAPYAP**：愿望单池 29.4 万，试玩参与率 29.5%，上线 23 天后转买约 5.5%。
- **Car Service Together**：试玩人群到愿望单、愿望单到购买的转换都更强，证明细分品类里“体验说服力”能打穿体量差距。
- **The Midnight Walkers**：虽然 Demo 玩的人不少，但后续转买疲弱，说明 **试玩本身可能暴露了产品不够强**。

这里最狠的结论就是：
**愿望单会越来越像虚荣指标，真正值钱的是“试玩后是否更愿意买”。**

所以以后我们不能只问：
- 今天涨了多少愿望单？

而要问：
- 看了素材的人，有多少点进商店页？
- 点进商店页的人，有多少下载 / 开始试玩？
- 玩到 10 分钟、30 分钟、结束页的人，各有多少？
- 试玩后进群、回访、留下结构化反馈、愿意参加下一轮测试的人有多少？

这才是能决定是否值得放量的真指标。

#### 结论 E：反馈入口必须单点归集，不然全是噪音
Discord 官方 2025 Playbook 和 Mark Brown 的实践都指向同一个结论：
- 试玩反馈要有**单一主入口**；
- 频道结构越简单越好；
- bug、建议、Build 讨论要分流，但都在同一个系统里；
- 最重要的是开发者能看见、能回复、能组织。

Mark Brown 的做法很典型：
- Steam 论坛引流到 Discord；
- 视频评论引流到 Discord；
- 游戏里直接放 “report an issue” 按钮；
- 所有反馈归到同一个 forum 结构里。

这套东西的核心不是“社群活跃”，而是：
**把反馈变成可处理的数据。**

### 3. 什么叫“可投放验证包”
我给它下个硬定义：

> **可投放验证包 = 一套能证明“外部承诺、落地承接、实际体验、后续反馈”彼此一致，并且可以支持继续投入流量或资源的最小证据系统。**

它至少包含 5 个模块。

#### 模块 1：外部承诺包（Promise Pack）
这是用户在点进来之前看到的所有东西：
- 素材视频 / GIF / 封面
- 标题钩子
- 一句话卖点
- 胶囊图 / 缩略图
- 首屏截图

要求不是“做得漂亮”，而是 **一句话承诺清楚，且后续真的能兑现。**

##### 最优结构：
1. **1 个核心幻想**：例如“激光折射翻盘”“一局短爽塔防肉鸽”“看似守不住但最后 1 秒救场”。
2. **1 个核心证据镜头**：10 秒内必须给到。
3. **1 个单点 CTA**：试玩 / 愿望单 / 进群，只能有主次，不能贪。

##### 最常见的错误：
- 视频卖的是“超爽翻盘”，试玩进去却前 8 分钟都在慢热教学；
- 首图卖的是“策略构筑”，实际前期只有机械劳动；
- 标题写“轻 Roguelite 塔防”，体验却更像慢节奏守点 sim。

这种不一致会带来两个后果：
1. CTR 可能高，但试玩留不住；
2. 愿望单会涨，但后续购买意图差。

这类流量最毒，因为它看上去好看，实际上不能变现。

#### 模块 2：商店页 / 落地页承接包（Landing Pack）
根据 Steamworks 和 presskit.gg 的最新结论，商店页不是配角，是主战场。

##### 商店页要完成的任务只有 3 个：
1. **复述刚才素材的承诺；**
2. **把玩法与差异讲清；**
3. **推动唯一主动作。**

##### 最值钱的承接元素：
- 462x174 小胶囊图能一眼看出类型和情绪；
- 首张截图必须能读懂玩法，不要当壁纸；
- 前两句简介就说清“你是谁、你有什么独特、我为什么现在要点”；
- 标签必须服务正确分类，不然等于隐身；
- 若有 Demo，结束页与商店页文案必须互相咬合。

##### 对我们最重要的一刀：
以后不管是 Steam 页、TapTap 页、微信落地页、还是小游戏测试页，**都必须把首屏当“验证器”而不是“作品集”。**

首屏只做三件事：
- 我是什么；
- 我最爽的点是什么；
- 你现在该干嘛。

#### 模块 3：Demo / 样机兑现包（Experience Pack）
Mark Brown 的经验非常实用：
- demo 要在 **30-90 分钟中位时长** 里给够乐趣；
- 不能太短，短了没记忆点；
- 也不能太完整，完整到像把正餐白送了。

##### 这里的关键不是时长，而是节奏：
1. **前 30 秒**：看懂交互目标；
2. **前 3 分钟**：看到核心爽点；
3. **前 10 分钟**：体验一次“我会了 / 我翻了 / 我想再来一把”；
4. **结束节点**：明确告诉玩家完整版还有什么，并给 CTA。

##### Steam 与独立项目的最佳实践：
- Demo 不是原型垃圾桶，是营销产品；
- 该造假保体验时要造假，比如提高首轮成型概率；
- 要留下“完整版还有货”的证据，比如锁住的模式、未解锁的流派、未来内容预告；
- 试玩 build 绝不能只靠开关锁内容，要物理剔除非 Demo 内容，避免被拆包打穿。

##### 对《光与朽》的直接映射：
如果后续做 Steam Demo 或独立试玩包，首轮必须更早给到：
- 激光折射穿怪；
- 危险压线；
- 一次 Build 质变；
- 一次“差点崩但救回来了”。

如果前 10 分钟还在铺垫世界观、慢悠悠摆第一层塔，那就是自杀。

#### 模块 4：反馈归集包（Feedback Pack）
Discord 官方建议的最小 playtest 结构非常清楚：
- 只读信息区
- announcement / patch notes
- game discussion
- build feedback
- report issue
- playtest room

这个结构的本质不是社区装修，而是**把反馈分类后可执行**。

##### 最优反馈设计：
- 游戏内 `反馈/报错` 按钮直达单一入口；
- Discord / 表单二选一做主入口；
- bug 报告模板统一字段：版本号、设备、复现步骤、严重级别；
- 玩法反馈模板统一字段：卡点、爽点、想继续玩的理由、想退出的理由；
- 每次 patch note 要反向点名“这轮我们根据哪些反馈改了什么”。

##### 反馈链路最重要的 KPI：
不是消息数，而是：
- 结构化反馈提交率
- 有效复现率
- 补丁后回流率
- “被官方看见”后的二次发言率

#### 模块 5：放量判定包（Go / No-Go Pack）
这一步最容易被忽略，但最该先定规则。

在进入小额买量、创作者扩量、发行接触前，至少要有一套最小门槛：

##### Steam / PC Demo 场景可盯：
- 商店页点击 → 愿望单率
- 愿望单用户中试玩占比
- 试玩开始 → 10 分钟留存
- 试玩开始 → 结束页到达率
- 试玩后进 Discord / 留反馈率
- 试玩用户后续回访率

##### 短视频素材 / 小游戏落地页场景可盯：
- 素材 CTR
- 点击后首屏停留率
- 首轮玩法完成率
- 首局结束率
- 首次主动再开率
- 反馈报名 / 留资 / 进群率

##### 一个很硬的原则：
如果**素材点击很好，但试玩首 10 分钟塌**，问题通常不在买量，而在承诺与体验错位；
如果**试玩反馈不错，但商店页 / 落地页转化差**，问题通常不在产品，而在包装；
如果**愿望单多、试玩也多，但后续购买 / 回访意图差**，问题在产品深度或结束承接。

这就是为什么我们必须做“验证包”，而不是只看单个指标。

### 4. 2025-2026 案例里最值钱的几条硬经验

#### 案例 1：Word Play —— 提前两周放 Demo，先修坑，再吃大曝光
Mark Brown 的实践已经说明：
- 提前两周发 Demo；
- 活动前先拿到约 25,000 愿望单；
- 先把“词长限制”“商店页看不到棋盘”“操作不顺”等问题狠狠干掉；
- 活动开始时，展示的是修过的版本，不是半成品。

**启发：**
不要把大曝光当第一次用户测试。

#### 案例 2：Steam 官方 —— Next Fest 期间不要双 build 分流
Steamworks 2026 官方明确不建议 Demo 和 Playtest 并行，因为会分掉用户和反馈。

**启发：**
一个测试周期，只留一个主承接体验。不要同时跑 Demo、问卷试玩、封闭测试、公开试玩四条线，最后谁都解释不清。

#### 案例 3：presskit.gg —— 大部分愿望单不玩 Demo，但仍被商店页说服
68%-88% 愿望单不来自试玩，而来自浏览页点击和商店页说服。

**启发：**
素材和首屏不是“宣传附属品”，而是第一层验证器。没有这一层，后面产品再好都漏光。

#### 案例 4：Alinea Analytics —— Demo 质量会直接决定愿望单后续是不是废流量
- Car Service Together 说明：细分受众一旦被玩法彻底说服，愿望单转买能很能打；
- The Midnight Walkers 说明：Demo 曝露缺点，反而会提前杀死购买意图。

**启发：**
试玩不是天然利好。试玩是放大器。你强，它帮你转；你弱，它帮你暴露。

#### 案例 5：Discord 官方 —— 频道越少越好，反馈越单一越好
Discord 官方不鼓励一开始就堆一堆复杂频道，而是主张围绕测试、公告、反馈、bug、语音试玩来组织。

**启发：**
社区不是拿来装逼的，是拿来做实验后台的。

### 5. 给《光与朽》与后续 7 天垂直切片的直接打法

#### A. 《光与朽》现在最该补的不是“更多曝光”，而是“单一承诺验证”
现阶段《光与朽》的问题不是没有点子，而是对外承诺不够聚焦。

我建议先只抓一个主承诺：
**“激光折射塔防 + 最后 1 秒翻盘”**

然后所有验证物统一围绕这个承诺：
- 视频只剪这个；
- 商店 / 页面首图只讲这个；
- 试玩前 5 分钟必须快速给到这个；
- 结束页告诉玩家完整版还会给你什么更深的 Build 分叉。

别再同时讲：塔防、肉鸽、剧情、美术、世界观、成长、Boss、随机事件、meta progression……那是找死。

#### B. 下一阶段 AI 视频反向立项，必须从“爆素材”升级到“验证包”
我们接下来做 AI 视频雷达时，不能只收藏“播放高”的素材，而要顺手拆成四层：
1. **视频承诺**：它让人以为自己会获得什么体验？
2. **首屏承接**：点进去后第一屏是否兑现？
3. **首局体验**：前 3 分钟是否让人感到值？
4. **后续动作**：用户愿不愿意再来、留反馈、进群、等下一版？

以后我们筛玩法，不只看“视频能不能火”，而要看：
**这个视频承诺能不能被 7 天样机兑现。**

兑现不了的，再火也只是广告皮，不适合我们当前资源结构。

#### C. 7 天垂直切片的验证模板，直接照这个做

##### Day 1：锁承诺
只写一句话：
- 玩家为什么点进来？
- 他第一眼会期待什么？
- 我们要用哪一个核心动词兑现？

##### Day 2-3：做承接页和首局
- 出 3 个首图 / 首屏版本
- 出 2 个 10-20 秒钩子视频
- 出 1 个最短体验回路

##### Day 4-5：跑试玩与反馈
- 只留一个反馈入口
- 强制记录首轮卡点、首个爽点、退出点
- 记录愿不愿意再来一局

##### Day 6：修“最大漏斗破口”
不要平均修。只修一刀最致命的：
- 看不懂
- 不够爽
- 结束无承接
- 反馈无归集

##### Day 7：判断是否值得进下一轮
只回答三个问题：
1. 素材承诺能不能被首局兑现？
2. 首局体验能不能让陌生人愿意再来一次？
3. 反馈和行为数据是否足够支撑继续投入？

如果三条里两条不成立，直接砍，不许恋战。

### 6. 我给主人的最终判断
这节课最狠的结论只有一句：

> **后续所有立项验证，都别再只做“素材测试”或“试玩测试”，而要做“可投放验证包测试”。**

因为真正决定我们能不能走到公司化的，不是偶尔爆一条视频，也不是偶尔有人夸玩法有意思，而是：
- 我们能不能稳定做出“承诺 → 承接 → 体验 → 反馈 → 下一轮”的闭环；
- 我们能不能用很小预算，就分辨出一个点子值不值得继续投；
- 我们能不能把每次测试都沉淀成未来买量、发行合作、产品迭代都能复用的资产。

**我的建议非常明确：**
从今天开始，把《光与朽》后续包装和所有新切片，都按“可投放验证包”思路重构。

先别迷信曝光，先把闭环做硬。

闭环一硬，曝光才值钱。

## 【专家进阶细分】从可投放验证包到低预算放量：创作者白名单 / Spark Ads 桥接法

### 1. 为什么这个课题现在该学
前一课我们已经把“可投放验证包”讲清楚了：素材承诺、首屏承接、试玩体验、反馈回流必须闭环。但闭环做出来后，下一个真问题不是“要不要直接砸大买量”，而是：

> **怎么用最便宜、最接近真实用户语言的内容，把自然反馈桥接到小额放量。**

这一步如果做对，后续买量不是瞎烧；如果做错，就会出现最蠢的局面：
- 自己做的广告像广告，CTR 低；
- 社区里有人夸，但这些真实反馈没有变成可放大的素材；
- Demo / 商店页 / Discord 各自为战，转化链断裂。

所以运营与发行维度的下一刀，应该是：

> **先用微型创作者 / 种子玩家产出原生内容，再通过 TikTok Spark Ads / Meta Partnership Ads / 官方号二次放大，把“自然证明”变成“低成本可放量创意”。**

这不是 influencer marketing 的花活，这是小团队最现实的“买量前桥接层”。

### 2. 核心定义：什么叫“白名单 / Spark Ads 桥接法”

#### A. 核心思想
不是先做一堆品牌广告，再去找用户；而是：

1. 先拿 **种子玩家 / 微型创作者 / 社区试玩者** 产出的真实反应；
2. 从里面筛出最能打的表达方式、钩子、镜头结构；
3. 再把这些内容用平台原生广告能力放大。

#### B. 三个平台分别是什么角色

##### TikTok：Spark Ads
- 适合把 **原生短视频内容** 直接放大；
- 好处是保留内容原本的互动、评论、头像、原生感；
- 对“像内容不像广告”的创意尤其强。

##### Meta：Partnership Ads / Creator 协作素材
- 更适合把创作者内容、试玩推荐、见证型表达转为可扩量广告；
- 对转化、重定向、广泛放量更稳；
- 更适合后续做“哪类内容能带更高质量点击 / 愿望单 / 下载”的归因优化。

##### Discord / Steam / 官方社区
- 不是曝光中心，而是 **反馈沉淀与验证后台**；
- 负责收集试玩录像、评论原话、二创片段、常见提问、愿望单前后的犹豫点；
- 这些内容是后续广告文案、创意脚本和商店页改写的原料库。

一句话：

> **社区给证据，创作者给语言，广告平台给放大。**

### 3. 2025-2026 的平台共识：为什么这招越来越重要

#### 共识 1：原生感内容继续压制“传统广告片”
TikTok For Business 的官方解决方案方向非常清楚：平台持续强化创作者生态、Creator Marketplace、原生内容传播与广告放大的一体化。也就是说，TikTok 不是鼓励你做“更像广告的广告”，而是鼓励你把 **能自然停留、能自然互动、能自然被转发的内容** 接进广告系统。

这对游戏尤其重要，因为游戏广告最容易犯的错就是：
- 镜头太规整；
- 文案太营销；
- 前 1 秒没有情绪；
- 玩法演示像 PPT。

#### 共识 2：Meta 在强化创作者合作广告的可扩量性
2025 年行业新闻与平台更新都在往一个方向走：Meta 继续强化品牌与创作者协作广告、AI 优化和自动化分发。翻译成人话就是：

> **创作者内容不再只是“发一条试试”，而是可以直接成为可归因、可优化、可扩量的广告资产。**

这意味着我们不该把创作者外联和后续小额买量拆开看，它们本来就该是一条链。

#### 共识 3：社区不该做大而全，而该做窄而可回流
Discord 官方《The Game Developer Playbook》强调的不是“把社区做热闹”，而是先围绕测试、公告、反馈、bug、语音试玩等少量核心场景搭结构。

这跟我们的目标完全一致：
- 我们不是要运营一个看起来很大的群；
- 我们是要把最早的反馈、截图、吐槽、夸奖、卡点，全都收成后续创意素材。

#### 共识 4：测试入口必须单一，别把流量打散
Steamworks 2026 官方文档对 Next Fest / Demo 的建议依旧很硬：同一测试周期不要同时把用户分流到多个主要试玩入口，不建议 Demo 与 Playtest 并行乱开。

对我们来说，这个原则可以外推到所有平台：

> **一个创意阶段，只保留一个主承接动作。**

别一条视频同时让人：去商店页、点 Demo、加群、填表、预约、关注、私信。那是找死。

### 4. 这套桥接法的正确流程

#### 第一步：先找“会说人话”的人，不要先找大号
我们的目标不是请大博主“带量”，而是找 20-50 个微型创作者 / 种子玩家 / 愿意试玩的半素人，去产出第一批可验证内容。

优先找的人：
- 粉丝不大，但互动真；
- 会录屏、会吐槽、会表达“为什么上头 / 为什么翻车”；
- 题材跟我们贴近：塔防、肉鸽、解压、小游戏、独立游戏、视觉爽点；
- 愿意根据 brief 重录 1-2 次。

不要一上来就追大号。大号贵、改稿慢、内容模板化，而且很容易只给曝光不给学习。

#### 第二步：给的不是“宣传需求”，而是“单一承诺脚本”
给创作者的 brief 必须极窄，只允许讲一件事：

- 这个游戏 / 切片最值得点开的 1 个承诺是什么？
- 前 2 秒怎么把这个承诺砸出来？
- 15-25 秒里用什么镜头兑现？
- 最后只让用户做 1 个动作：进试玩 / 加群 / 愿望单，三选一。

一个合格 brief 至少给：
- 1 句主承诺
- 3 个开头钩子模板
- 2 个必须出现的高能镜头
- 1 个禁止事项（比如别讲世界观、别讲太多系统）
- 1 个单一 CTA

如果 brief 还在“请帮我们宣传这款结合塔防肉鸽成长叙事与美术氛围的新作”，那就是废话，创作者只会做出废片。

#### 第三步：先自然发，再决定谁能进广告
不要创作者一发就立刻投。先看自然数据和评论信号，通常给 24-72 小时窗口。

优先观察：
- 前 2-3 秒停留感是否强；
- 评论里是否出现“游戏名是什么 / 在哪玩 / 我也想试”；
- 有没有清晰的复述性评论，说明承诺被理解了；
- 点击后试玩 / 页面承接是否匹配；
- 同一脚本换不同表达者，谁的“人味儿”最能打。

**只有进入前 10%-20% 的内容，才值得进入 Spark / Partnership 放大池。**

这条很关键：

> **广告预算不是拿来测试所有内容的，是拿来放大已经证明自己会说话的内容的。**

#### 第四步：白名单放大时，不是只看 CTR
进入小额放量后，不能只看便宜点击。至少分成四层：

1. **内容层**：3 秒停留、完播、点赞率、评论率、分享率
2. **承接层**：点进后首屏停留、商店页 / 落地页点击深度
3. **试玩层**：试玩开始率、首局完成率、10 分钟留存
4. **后续层**：愿望单率、加群率、留反馈率、二次回访率

如果内容数据好、试玩差，说明承诺错位；
如果内容一般、试玩强，说明素材不会讲；
如果试玩不错、加群和愿望单差，说明结尾承接废了。

#### 第五步：把“原话素材库”做成长期资产
每次创作者测试后，都该沉淀四类可复用资产：

- 用户原话（夸点 / 吐槽 / 看不懂点）
- 高能镜头片段
- 开头钩子句式
- 哪种人设 / 语气最适合这个玩法

这四类东西后面可以反哺：
- 商店页标题和短描述
- 小红书 / 抖音口播脚本
- Meta/TikTok 广告字幕
- Steam 更新公告和 Demo 文案

### 5. 低预算执行参数：小团队怎么干才不傻

#### 创作者池规模
- 第一轮：20-50 人足够
- 有效内容目标：至少产出 8-15 条可比较的原生内容
- 能进入放大池的：通常只会有 2-5 条

#### 创意变量
一次只改 1-2 个大变量：
- 开头钩子
- 表达人设
- 高能镜头顺序
- CTA

别同时改 6 个，不然复盘时根本不知道是谁在起作用。

#### 小额放量预算
对我们这种阶段，先别幻想“测 ROAS”。

更现实的目标是：
- 找到最能打的内容表达；
- 验证哪种承诺和哪种人设最适合引入高质量试玩；
- 判断这个点子有没有资格进入下一轮产品打磨。

所以小额放量更像“创意验证预算”，不是利润预算。

#### 放量闸门
以下任一条不成立，就不该继续加预算：
- 内容点击 / 停留不行；
- 试玩首 10 分钟崩；
- 试玩后没人愿意回流；
- 创作者内容表现好，但换成第二条类似素材就崩，说明只是偶然。

### 6. 给《光与朽》的直接打法

#### A. 先别急着正式买量，先做“激光翻盘”创作者验证池
《光与朽》现在最适合切的单一承诺不是系统深度，而是：

> **“激光折射塔防 + 最后 1 秒翻盘”**

第一轮创作者内容不要讲世界观，不要讲 Roguelite 全貌，不要讲美术理念。
只做三类内容：
- `差一秒守住这一波` 型高压翻盘
- `这角度居然能连锁清场` 型爽点演示
- `我以为要死了结果这塔救命` 型失败反转

#### B. Discord 只做四个核心区
别再搞花里胡哨社区。就四个：
- 公告 / 新版本
- 试玩反馈
- bug / 卡点
- 录像 / 高能片段

我们的 Discord 不是社交中心，是素材矿场。

#### C. 创作者发完后，只留一个承接动作
现阶段我更推荐：
- 如果是 PC / Demo 方向：只承接到试玩 / 愿望单
- 如果是小游戏垂直切片方向：只承接到试玩页 / 加群反馈

同一批素材不要双 CTA。

#### D. 只有被“自然内容 + 小额放大”双验证过的表述，才配进正式买量素材库
以后《光与朽》或新切片的素材库，应该分层：
- 社区自然高能片段
- 创作者自然表现强素材
- Spark / Partnership 小额放大通过素材
- 才是正式广告母版

顺序不能反。反了就会开始用主观审美做买量，纯烧钱。

### 7. 给后续 7 天垂直切片的标准流程

#### Day 1：锁单一承诺
只写一句：为什么陌生人会点。

#### Day 2：做 2-3 个 15 秒钩子视频
不要长。先看有没有停留感。

#### Day 3：找种子玩家 / 微型创作者试玩录屏
把真实反应收回来。

#### Day 4：剪 8-15 条原生表达版本
同一玩法，不同人设与口吻。

#### Day 5：自然发 + 收评论原话
看哪些表达会引出“这是什么游戏 / 我想试”。

#### Day 6：挑前 10%-20% 内容做小额放大
只保留一个承接动作。

#### Day 7：复盘四层漏斗
内容、承接、试玩、回流四层一起看，决定继续 / 改写 / 砍掉。

### 8. 我给主人的最终判断
这节课最值钱的结论很硬：

> **别再把“社区运营”“创作者外联”“小额买量”拆成三件事，它们本质上是一条验证链。**

对我们这种资源结构，小额放量最正确的起点不是自己拍广告，而是：

1. 先让真实人用真实口吻把玩法说清；
2. 再把最能打的那几条原生内容放大；
3. 最后只让通过内容验证和试玩验证的表达进入正式素材库。

这会直接改变我们后面的立项效率：
- 不再只靠主观感觉选素材；
- 不再把创作者合作当公关动作；
- 不再把买量测试和产品验证割裂。

**我的建议非常明确：**
后续无论是《光与朽》复盘包装，还是 AI 视频反向立项的新切片，都应该建立一套“微型创作者 → 原生内容筛选 → 小额放大 → 回流复盘”的桥接流程。

这条流程一旦跑顺，我们离真正能稳定验证题材和素材，就近了一大步。

## 【专家进阶细分】从白名单放大到正式买量：归因窗、放量门槛与停损线

### 1. 为什么这是运营与发行维度下一个未攻克点
前面我们已经打通了这条链：
- 微型创作者/KOC 产出原生内容；
- 挑自然反馈最强的内容进 Spark Ads / Partnership Ads 放大；
- 用小预算验证“真实人会不会被这条表达打动”。

但如果到这里就停，还是会死得很蠢。因为**原生内容能跑，不等于值得正式放量；能带点击，不等于能带来可持续的新用户质量。**

所以运营与发行维度下一个真正该补的细分课题，不是继续泛聊社区，而是：

> **从创作者白名单放大，走到正式买量前，如何定义归因窗、放量门槛与停损线。**

这一步决定我们到底是在“用小预算筛真信号”，还是在“把自然热闹误判成商业可放量”。

### 2. 2025-2026 的行业共识：创作者内容不再只是素材来源，而是付费分发入口
结合本轮检索到的官方资料与行业报道，可以确认几个非常硬的趋势：

#### A. TikTok 已经把“授权内容直接放大”产品化
根据 TikTok For Business 2025 年《Spark Ads 101》官方文章，Spark Ads 的核心就是把已有 TikTok 内容直接变成广告；案例里 **Photomyne 通过 TikTok Creator Marketplace 与创作者合作，再用 Spark Ads 放大以提升安装量并降低制作成本**。这说明平台官方已经明确认可：
- 原生创作者内容不是补充品，是正式投放资产；
- 创意生产和媒介放大正在一体化；
- 对中小团队最有价值的不是自建大拍摄体系，而是**先找到会说人话的原生表达，再授权放大**。

#### B. TikTok One 正在把“可授权内容池”进一步前置
2026 年 TikTok For Business 关于 TikTok One 的官方介绍提到，可从 **ready-to-use authorized videos** 中直接进行 Spark 激活。这意味着平台方向非常清晰：
- 创作者合作会越来越像“素材库存管理”；
- 授权效率、复用效率、批量测试效率都会上升；
- 以后真正稀缺的不是“会不会开 Spark”，而是**你有没有一套判断哪条内容配吃预算的门槛体系**。

#### C. Meta 也在把 organic creator content -> partnership ads 自动化
根据 Marketing Dive 2025-12-11 报道，Meta 推出 AI 驱动的新方案，帮助广告主更容易发现并将 Facebook / Instagram 上的 **existing organic content** 转成 partnership ads。意思很直接：
- Meta 不再只鼓励“品牌自制广告”；
- 平台正在加强“先有自然内容表现，再转广告资产”的路径；
- 创作者内容和正式投放素材的边界正在消失。

#### D. 2025 的手游买量环境不是“少量精品创意”，而是“高创意量 + 更快筛选”
根据 Marketing-Interactive 2025-11-27 报道，全球手游广告在 2025 年进入加速状态，**装机增长、创意量激增、互动广告与 AI 优化快速上升**。另外，PocketGamer.biz 对 2025 UA 报告的转述提到：**视频占手游广告创意约 81%**；Admiral Media 2026 年行业文也提到 **2025 年视频创意占比达 74.1%**。这说明：
- 现在拼的不是“拍一条神广告”，而是“更快淘汰烂表达”；
- 创作者白名单放大，本质是正式买量前的低摩擦预筛层；
- 没有放量门槛和停损线，就会被高创意量时代活活吞掉。

### 3. 这节课真正要解决的核心问题
从白名单放大过渡到正式买量，必须回答 4 个问题：
1. **归因看什么？** 看播放、点击，还是看试玩、进群、愿望单、次留？
2. **什么时候加预算？** 不是“感觉这条火了”，而是达到哪几个阈值才配放大。
3. **什么时候停？** 一条内容是需要休息、重剪、换承接，还是直接枪毙？
4. **什么信号能进入下一轮产品决策？** 不是所有 CTR 都值钱，只有和后链路一致的 CTR 才值钱。

### 4. 实战框架：把创作者白名单放大，变成“正式买量前的验证层”

#### 第一层：内容层（用户是否愿意停）
这是最上游，只审一件事：**这条内容能不能在陌生流量里把人按住。**

建议看 4 个轻指标：
- **首秒钩子成立率**：前 1-2 秒是否马上抛冲突/爽点/悬念；
- **3 秒保留/短停留感**：不是后台绝对值崇拜，而是同批素材横向比；
- **评论原话质量**：有没有“这是什么游戏”“我也想试”“哪能玩”；
- **自然收藏/转发倾向**：对玩法向项目，转发和评论求名往往比单纯点赞更值钱。

**门槛建议：**
- 不看绝对播放量；
- 只选同批内容里前 10%-20% 的表达进下一层；
- 评论区如果只有“剪得不错”，没有“我想玩/我想试”，这条别放大。

#### 第二层：承接层（用户点进去后有没有被兑现）
创作者内容能骗人，承接页会揭穿一切。这里要审的是：
- 商店页 / 试玩页首屏是不是和视频承诺一致；
- 用户点进去后，能不能在 5 秒内知道下一步；
- CTA 是否只有一个。

**强规则：**
- 一条白名单广告只配一个主动作：愿望单 / 试玩 / 加群反馈 三选一；
- 不允许一条内容既想要 Wishlist 又想要 Discord 又想要问卷；
- 内容承诺如果是“高压翻盘”，落地页首屏就必须继续讲“高压翻盘”，不能突然变世界观 PPT。

#### 第三层：体验层（试玩/首局是否兑现视频承诺）
这一步最容易被忽视，但对我们最关键。因为我们当前更像在做“题材验证 + 切片验证”，不是成熟产品粗暴吃量。

建议重点看：
- **前 120 秒兑现率**：玩家是否在两分钟内体验到视频里承诺的核心爽点；
- **首局失败可复盘性**：失败后玩家知道为什么死，且知道再来一把能改变什么；
- **行为完成率**：试玩后是否愿意点反馈、进群、加愿望单或等下一版。

如果视频承诺很强，但试玩前 2 分钟完全不给货，这种内容就算 CTR 再好，也不配进正式买量库。

#### 第四层：归因层（什么才算“值钱的转化”）
这里别学电商那套只盯点击。对我们这种游戏验证期项目，更值钱的是**带意图的行为**。

按项目阶段拆：

##### A. PC / Steam / Demo 阶段
优先归因：
- 愿望单率
- Playtest / Demo 请求率
- Discord 进群率
- 有效反馈率（不是“加油”，而是能指出具体体验问题）

结合 Steam Playtest 官方文档：
- Steam Playtest 的报名入口直接挂在主游戏页；
- 玩家可 **request access**，同时仍可 **Wishlist / Follow** 主游戏；
- Valve 明确建议在游戏主菜单放明显 **feedback** 按钮，把反馈导向 Discord、论坛或 bug 系统。

这意味着对 PC 项目，最合理的归因闭环不是“看视频点击”，而是：
**内容 → 主游戏页/试玩报名 → 愿望单/申请试玩 → 反馈回流。**

##### B. 小游戏 / 垂直切片阶段
优先归因：
- 试玩点击率
- 开始试玩率
- 完成首局率
- 进群率 / 留联系方式率
- 次日自发回访意愿

对于我们后续 AI 视频反向立项的切片，更该看的是：
**有没有人因为这条内容愿意进入试玩，并在试玩后继续和我们发生关系。**

### 5. 白名单放大后的预算门槛：什么时候该加，什么时候别犯傻

#### 一条内容可以加预算，至少同时满足 3 件事
1. **内容层赢**：同批创意里停留、评论意图、点击意愿排前列；
2. **承接层没塌**：点击后没有明显掉进错误预期，CTA 执行顺；
3. **后链路有值钱行为**：不是只点进来看看，而是真有人试玩、愿望单、进群、留反馈。

如果只满足第 1 条，那它只是“会骗点击”；
如果满足 1+2 但没有第 3 条，那它只是“包装正确但产品没接住”；
只有 1+2+3 同时成立，才配加预算。

#### 实操预算节奏建议
- **第 0 阶段：自然发/微预算探针**
  用极小预算或自然流量，只筛表达。
- **第 1 阶段：白名单验证**
  给通过筛选的内容小额放大，目标是验证“自然强”在付费里是否还成立。
- **第 2 阶段：准正式素材池**
  连续多批次都能稳定带来后链路行为的内容，才进正式母版池。
- **第 3 阶段：正式买量改编**
  再基于赢家表达做品牌版/玩法版/极端冲突版，而不是反过来。

### 6. 停损线：哪些情况该立刻砍，不要恋战

#### 该停的 5 种典型情况
1. **评论热闹但没人点下一步**：说明是看热闹，不是想玩；
2. **CTR 高但试玩/愿望单差**：说明内容承诺和产品不一致；
3. **创作者口吻有效，但品牌改写后失灵**：说明你把“人话”改成了“广告话”；
4. **短期有效，重复投很快疲劳**：说明这是爆点，不是可扩展母版；
5. **需要不断抬预算才能维持结果**：说明不是素材变强，是硬买出来的。

#### “休息”而不是“彻底枪毙”的情况
根据 2025 年关于 creator whitelisting / partnership ads 的行业经验文章，创作者广告存在明显疲劳周期，**pulsing（暂停几周后再重新投）** 有机会恢复效率。实战里可这样处理：
- 先停同一人设/同一开场 2-4 周；
- 回来时优先只改前 2 秒钩子与字幕；
- 如果回投后仍只剩点击没有后链路，就彻底淘汰。

### 7. 给我们自己的落地打法：直接服务《光与朽》复盘与下一批 7 天切片

#### A. 《光与朽》别直接拍正式广告，先做“原生验证包”
优先测试三类原生表达：
- `差一秒守住这一波`
- `这角度竟然能激光连锁`
- `我以为必死，结果这个塔把盘救回来了`

每类先做：
- 5-10 条不同口吻版本；
- 20-50 个种子玩家 / 微创作者试玩录屏或反应；
- 只选评论里出现“想试/哪能玩/这是什么”且承接顺的内容做白名单放大。

#### B. 下一批 AI 视频反向立项切片，必须上“四层门”
任何新切片都要过这四层：
1. **内容层**：陌生人停不停；
2. **承接层**：首屏接不接得住；
3. **体验层**：前 120 秒兑不兑现；
4. **归因层**：有没有愿意留下来的人。

凡是只会拉播放，不会拉试玩/反馈/回访的切片，统统不配进入下一周开发排期。

#### C. 我建议我们内部以后固定记录三类“值钱句子”
- **内容值钱句**：用户为什么停下；
- **体验值钱句**：用户为什么想再来一把；
- **流失值钱句**：用户为什么点进来却不愿继续。

这三类原话，比任何空泛 CTR 复盘都更适合指导下一轮立项。

### 8. 我给主人的最终判断
这节课最关键的结论只有一句：

> **创作者白名单放大，不是买量动作，而是正式买量前的“真信号过滤器”。**

我们现在最该建立的，不是更大的素材库，而是更狠的门槛系统：
- 先筛会让人停下的表达；
- 再筛点进去不会失望的承接；
- 再筛能带来试玩/愿望单/反馈的后链路；
- 最后才给正式买量预算。

谁跳过这套，谁就会把热闹错认成生意。
