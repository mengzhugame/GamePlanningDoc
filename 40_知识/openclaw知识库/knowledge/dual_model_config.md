# 双模型配置说明

**配置时间**: 2026-02-09  
**配置文件**: `~/.openclaw/openclaw.json`

---

## 🎯 配置目标

**降低成本**: 从30元/天降至0-10元/天  
**策略**: 简单任务用免费模型，复杂任务用付费模型

---

## 🤖 可用模型

### 1. DeepSeek R1 8B (免费) - 默认模型
**别名**: `deepseek`  
**用途**: 日常简报、简单搜索、提醒、基础问答  
**特点**:
- ✅ 完全免费
- ✅ 推理能力不错
- ✅ 32K上下文
- ⚠️ 复杂代码能力有限

**使用命令**:
```
/deepseek 你的问题
```

### 2. Qwen 2.5 7B (免费) - 备选
**别名**: `qwen`  
**用途**: 快速问答、简单任务  
**特点**:
- ✅ 完全免费
- ✅ 响应速度快
- ✅ 中文理解好

**使用命令**:
```
/qwen 你的问题
```

### 3. Kimi K2.5 (付费) - 高质量模型
**别名**: `kimi`  
**用途**: 代码分析、复杂推理、深度研究、创意写作  
**特点**:
- ✅ 代码能力最强
- ✅ 256K超长上下文
- ✅ 推理深度最好
- 💰 按量付费

**使用命令**:
```
/kimi 你的问题
```

## 💡 快速切换模型

### 方式1: 使用别名命令
```
/deepseek 分析这个游戏的玩法
/kimi 帮我重构这段代码
/qwen 快速回答这个问题
```

### 方式2: 设置默认模型
```
/model deepseek    # 切换到DeepSeek
/model kimi        # 切换到Kimi
/model qwen        # 切换到Qwen
```

### 方式3: 针对单条消息
```
@deepseek 这个问题用DeepSeek回答
@kimi 这个问题用Kimi回答
```

## ⚠️ 注意事项

1. **免费模型限制**: 
   - 可能有速率限制
   - 高峰期可能响应慢
   - 复杂任务可能"降智"

2. **自动回退**: 
   - 如果DeepSeek失败，会自动回退到Kimi
   - 确保重要任务不会中断

3. **API Key安全**:
   - SiliconFlow Key已保存在配置中
   - 不要分享配置文件
