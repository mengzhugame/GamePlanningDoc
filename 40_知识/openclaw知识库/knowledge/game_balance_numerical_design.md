# 游戏数值设计学习笔记 - 塔防/Roguelike

## 一、经典塔防数值参考

### Kingdom Rush 数值特点
- **三档难度**：普通/困难/英雄，敌人血量按比例增加（如533/666/799）
- **敌人分类**：普通、快速、巨大，形成三角克制
- **赏金机制**：击杀奖励与难度挂钩

### 植物大战僵尸 关卡节奏
- **难度公式**：y = kx + b（线性递增）
- **设计原则**：杀死波次时间 ≈ 僵尸走到防线时间
- **节奏控制**：简单题和难题穿插，保持心流

## 二、光与朽数值分析

### 基础敌人配置

| 敌人 | 生命值 | 速度 | 质量 | 击杀时间 | 经验 |
|------|--------|------|------|----------|------|
| Slime | 1000 | 0.8 | 1 | 10s | 10 |
| Rusher | 400 | 1.5 | 0.5 | 4s | 8 |
| Tank | 8000 | 1.2 | 8 | 80s | 50 |

### 数值公式汇总

**升级经验公式**：
```
UpgradeCost = expBase + (Level - 1) * expGrowth
= 100 + (Level - 1) * 50
```

**单次伤害**：
```
DamagePerTick = baseDPS * tickRate
= 100 * 0.1 = 10点/次
```

**击杀时间**：
```
KillTime = enemyHealth / (baseDPS * skillMultiplier)
```

### 设计建议

1. **Tank奖励调整**：经验从50→80，突出高价值
2. **增加血量成长**：每关敌人血量增加10-15%
3. **波次节奏**：前几波以Rusher/Slime为主，中间插入Tank制造压力

## 三、Roguelike数值平衡要点

### 技能平衡原则
- **DPS等价原则**：不同build理论输出应接近
- **操作难度补偿**：操作复杂的技能应该有更高上限
- **风险收益平衡**：高风险build应该有高回报

### 光与朽技能DPS计算

**基础DPS**：100/秒

**Prism（分裂）**：
- 主激光：100% DPS
- 2条副激光：各30% DPS
- 总DPS：160%

**Focus（穿透）**：
- 单体：150% DPS（假设）
- Boss伤害加成：额外30%

**需要平衡**：确保Prism和Focus在各自场景都有竞争力
