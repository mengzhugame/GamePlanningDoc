### 2026-04-10 龙儿的 Claude Code 大师课

## 2026-04-10｜龙儿的游戏数值大师课

## 2026-04-11｜六维全能合伙人｜美术专家：ComfyUI ControlNet 深度应用
主人，今天这块很值钱。ControlNet 不是拿来“让图更像”，而是拿来锁死结构。做《光与朽》时，图标和炮塔优先用 Canny 或 Lineart，先保住轮廓；场景宣传图优先用 Depth，先锁前后空间；角色动作或买量演示图用 DWPose，先锁姿态。多路 ControlNet 别瞎堆，正确做法是链式叠加，一个主控，一个辅控，强度先从 1.0 + 0.6 起步，再固定 seed 做 AB 测试。你真正要建的不是一张神图，而是一套“草图进来，稳定出货”的可复制美术流水线。

## 2026-04-18｜龙儿的游戏数值大师课：等价交换物与时间标价
主人，别再把钻石、金币、体力分开拍脑袋定价了，统一按“时间价值”算。先定《光与朽》1分钟有效推进值：假设自然毕业30小时，总毕业成本18万金币+900碎片，若1碎片≈150金币，则每分钟价值约175金币等价。接着反推1钻能买几分钟进度，再统一换算金币包、碎片包、体力包、广告复活。核心公式就一句：`资源价值 = 节省时间 × 每分钟推进值`。凡是某个购买项一次性跳过太多正常成长链路，比如一条广告顶15分钟以上，或者1钻直买5分钟收益，这玩意就会打穿经济，必须加递减、上限或用途隔离。

## 2026-04-18｜龙儿的理财专家课：芒格的多元思维模型
主人，真正拉开财富差距的，不是多会猜涨跌，而是有没有一套**不犯大错的决策系统**。芒格最狠的三把刀：第一，**反向思考**，先问“这事会怎么把我狠狠干死”，先排雷再下注；第二，**能力圈**，只赚自己看得懂的钱，不懂的热闹再大也别碰；第三，**看激励**，别听别人怎么说，要看他靠什么赚钱。以后你做个人投资也好，做游戏公司决策也好，都先过这三关。财富的下限，永远由认知和纪律决定，不由运气决定。

## 2026-04-19｜龙儿的 Claude Code 大师课
主人，Git 这块别再把 Claude Code 当自动提交机。正确姿势是：**先 `git status`，再 `git diff --cached` 让它读懂本次改动，再让它写 commit message 和 review 摘要。** 提交前让它回答三件事：改了什么、为什么改、风险在哪。小改动可直接让它生成描述性 commit；大改动先按 diff 做 code review，再决定是否拆成多个提交。核心原则就一句：**先审 diff，再写提交，最后再推远端**，这样历史才干净，回滚也不痛苦。

## 2026-04-19｜龙儿的游戏数值大师课：保底机制的期望值计算
主人，做《光与朽》核心碎片掉落，别只写“2%概率、50次保底”就收工。你必须同时算**期望次数**和**90/95分位数**，不然玩家体感会被长尾黑脸狠狠干碎。实战上，把核心组件池做成“基础概率 + 软保底抬升 + 最终强保”：比如前30次2%，31次后每次+3%，50次必出。这样平均约26次出货，40次内约93%玩家能拿到，既保住随机惊喜，又不让中盘构筑坐牢。广告补偿、商店兑换、碎片合成都必须统一按“保底进度价值”定价，不然经济一定被打穿。

## 2026-04-19｜龙儿的项目管理专家课：关键路径与依赖管理

## 2026-04-20｜游戏行业大盘简报
主人，今天盘面给你一句话：**行业总收入在涨，但钱和岗位还在收缩，真正活得好的方向更集中在“中国供给 + 小团队高效率 + 可验证的细分品类”。**

2. **中国与亚洲供给继续吃份额**：同一报告点名 **“China is eating the video games industry”**，并指出 2025 年成功的新移动游戏发布仍由亚洲主导。对我们这种要做高效率产品的人，这是利好，不是坏消息。
3. **就业面还在出血**：PocketGamer.biz 4 月 17 日报道，Skillsearch《Games and Immersive Salary & Satisfaction 2026》显示，**55% 被裁游戏从业者仍未找到新工作**，**44% 正考虑离开行业**。结论很残酷，团队扩张要更谨慎，能用系统和 AI 顶掉的人效问题，就别靠招人硬扛。

5. **独立小团队仍有爆发窗口**：GamesRadar 3 月 17 日报道，独立塔防游戏 **Tangy TD** 开发者在 Steam 开卖一周收入约 **25 万美元**。这不是让你做梦，这是提醒你，**只要题材抓得准、商店页能打、前期体验不烂，小团队依然有穿透市场的机会。**
6. **国内监管节奏平稳**：我今早查了国家新闻出版署游戏审批结果页，**截至 4 月 20 日公开可见的最新批次仍是 3 月国产网络游戏审批信息（3 月 24 日）**，说明 4 月新一批版号至少在今天早上还没挂出来。国内并没有突发收紧信号，节奏上仍属常态。
