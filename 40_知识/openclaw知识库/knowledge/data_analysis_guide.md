## 一、游戏数据分析核心指标体系

### 1.1 五大核心指标

| 指标类型 | 关键指标 | 计算方式 | 目标值 | 监测频率 |
|---------|----------|----------|--------|----------|
| **获客** | CPA（获客成本） | 广告花费/激活用户数 | <1.5元 | 每日 |
| **活跃** | DAU（日活跃用户） | 当日登录用户数 | 稳定增长 | 每日 |
| **留存** | 次日留存率 | D1留存用户/新增用户 | >20% | 每日 |
| **变现** | ARPU（人均收入） | 总收入/活跃用户 | >0.1元 | 每日 |
| **传播** | K因子 | 邀请成功数/邀请用户数 | >1（自增长） | 每周 |

### 1.2 转化漏斗指标

```
广告曝光 → 点击 → 激活 → 登录 → 游戏 → 留存 → 付费
   ↓       ↓      ↓      ↓      ↓      ↓      ↓
  CTR    CVR    激活率  登录率  活跃率  留存率  付费率
```

**《光与朽》关键转化**:
- 广告点击→激活: 60%（正常）
- 激活→首次游戏: 80%（目标）
- 首次游戏→通过第3波: 70%（目标）
- 通过第3波→次日回来: 30%（目标）

## 二、AARRR增长模型

### 2.1 模型概述

**AARRR**（海盗模型）五个阶段：
1. **Acquisition**（获取用户） - 买量、SEO、ASO
2. **Activation**（激活用户） - 新手引导、首次体验
3. **Retention**（提高留存） - 持续玩、重复玩
4. **Revenue**（获取收入） - 广告、内购
5. **Referral**（自传播） - 分享、邀请

**核心公式**:
```
LTV（用户生命周期价值）>> CAC（获客成本）
```

只有当LTV远大于CAC时，买量才可持续。

### 2.2 各阶段关键策略

#### A1 - Acquisition（获取）

**关键指标**:
- CPA < 1.5元（《光与朽》）
- 渠道质量（看后续留存）

**策略**:
- 朋友圈广告（高质量用户）
- Banner广告（低成本量）
- 自然流量（社交裂变）

#### A2 - Activation（激活）

**关键指标**:
- 首次游戏率: >80%
- 前3波通过率: >70%
- 首次游戏时长: >5分钟

**策略**:
- 简化新手引导（<1分钟）
- 降低前3波难度
- 强化即时反馈（音效、特效）

#### R1 - Retention（留存）

**关键指标**:
- 次日留存: >20%
- 7日留存: >5%
- 30日留存: >2%

**策略**:
- 每日任务（给理由回来）
- Build多样性（每次不同体验）
- 社交功能（排行榜、挑战）

#### R2 - Revenue（收入）

**关键指标**:
- D1 ARPU: >0.1元
- 广告填充率: >90%
- eCPM: >30元

**策略**:
- 复活广告（关键时刻）
- 双倍奖励广告
- 每日礼包广告

#### R3 - Referral（推荐）

**关键指标**:
- K因子: >0.5（理想>1）
- 分享率: >5%

**策略**:
- 战绩分享（通关截图）
- 邀请奖励（双向激励）
- 排行榜挑战

## 三、留存率深度分析

### 3.1 留存率类型

#### 日留存率
```
D1留存率 = 第1天新增且在第2天登录的用户数 / 第1天新增用户数
D7留存率 = 第1天新增且在第8天登录的用户数 / 第1天新增用户数
D30留存率 = 第1天新增且在第31天登录的用户数 / 第1天新增用户数
```

#### 周留存率
```
W1留存率 = 第1周新增且在第2周登录的用户数 / 第1周新增用户数
```

#### 加权留存率
```
加权留存 = (D1留存×0.5 + D3留存×0.3 + D7留存×0.2)
```

**适用场景**: 综合评估游戏留存健康度

### 3.2 留存曲线分析

**健康留存曲线**:
```
D1: 40%
D2: 25%
D3: 18%
D7: 10%
D14: 7%
D30: 5%
```

**《光与朽》目标曲线**:
```
D1: 25% （目标）
D3: 15%
D7: 8%
D14: 5%
D30: 3%
```

**曲线类型判断**:
- **快速衰减型** (D1>50%, D7<5%) - 新手体验差
- **平缓衰减型** (D1=30%, D7=10%) - 健康状态
- **长尾型** (D30>5%) - 核心用户稳定

### 3.3 留存率优化策略

#### 提升次日留存（D1）

**问题诊断**:
| D1留存区间 | 问题诊断 | 优化方向 |
|-----------|----------|----------|
| <10% | 致命问题，核心玩法有缺陷 | 重做/大改 |
| 10-20% | 体验问题，新手引导不足 | 优化引导、降低难度 |
| 20-30% | 正常，可优化空间 | 增加钩子、每日任务 |
| >30% | 优秀 | 保持并放量 |

**优化手段**:
1. **新手保护机制** - 前3关可复活
2. **首日奖励** - 明天登录领取
3. **进度保存** - "你上次死在第8波"
4. **推送提醒** - 24小时后推送

#### 提升7日留存（D7）

**流失节点分析**:
```
Day 1: 100人新增
Day 2: 25人回来（D1留存25%）
Day 3-7: 逐步流失
Day 8: 8人回来（D7留存8%）

流失原因：
- 内容不够（玩腻了）
- 难度太高（卡关了）
- 缺乏目标（不知道玩啥）
```

**优化手段**:
1. **外围系统** - 天赋树、成就系统
2. **每日任务** - 给理由回来
3. **难度分级** - 简单/普通/困难
4. **社交功能** - 排行榜、好友挑战

#### 提升30日留存（D30）

**长线运营策略**:
- 版本更新（新关卡、新技能）
- 限时活动（周末挑战）
- 赛季系统（每月重置排行榜）
- 社交沉淀（公会、组队）

## 四、LTV计算与提升策略

### 4.1 LTV计算方法

#### 方法1: 简化公式
```
LTV = ARPU × 用户生命周期（天）

其中:
用户生命周期 ≈ 1 / (1 - 平均留存率)
```

**示例**:
```
假设:
- D1 ARPU = 0.15元
- 平均留存率 = 15% (0.15)
- 用户生命周期 = 1 / (1 - 0.15) = 1.18天

LTV = 0.15 × 30（假设30天观察期） × 15% = 0.67元
```

#### 方法2: 累积法（最准确）
```
LTV = D1收入 + D2收入 + D3收入 + ... + D30收入

示例:
D1: 100人新增，收入15元，D1 ARPU=0.15元
D2: 25人留存，收入3元，D2 ARPU=0.12元
...
D30: 3人留存，收入0.3元，D30 ARPU=0.10元

LTV = (15+3+...+0.3) / 100 = 1.2元（示例）
```

#### 方法3: Cohort群组分析
```
按注册日期分组，追踪每组用户的累积收入

示例表格:
| 注册日期 | 新增用户 | D1收入 | D7收入 | D30收入 | LTV |
|---------|---------|--------|--------|---------|-----|
| 2.1     | 100     | 15     | 25     | 35      | 0.35|
| 2.2     | 120     | 18     | 30     | 40      | 0.33|
```

**优势**: 可以对比不同时期用户质量

### 4.2 影响LTV的关键因素

| 因素 | 影响方式 | 提升策略 |
|------|----------|----------|
| **留存率** | 留存↑ → 生命周期↑ → LTV↑ | 优化游戏体验 |
| **ARPU** | 单日收入↑ → LTV↑ | 优化广告场景 |
| **付费率** | 付费用户↑ → ARPU↑ → LTV↑ | 内购商品设计 |
| **游戏时长** | 时长↑ → 广告曝光↑ → ARPU↑ | 延长单局时间 |

### 4.3 提升LTV的三大策略

#### 策略1: 提升留存（治本）

**核心逻辑**: 留存提升10% → LTV提升15-20%

**具体方法**:
- 每日任务（签到奖励）
- 成长系统（天赋树）
- 社交功能（排行榜）
- 内容更新（新关卡）

#### 策略2: 提升ARPU（治标）

**核心逻辑**: 单日收入提升 → LTV直接提升

**具体方法**:
- 增加广告场景（复活、双倍奖励）
- 提高广告填充率（对接多家广告平台）
- 优化eCPM（选择高价广告主）
- 增加单日游戏次数（缩短单局时间）

#### 策略3: 用户分层运营（精细化）

**核心逻辑**: 针对不同价值用户差异化运营

**分层方法**:
- 高价值用户（LTV>2元）：保留、少打扰
- 中价值用户（LTV 0.5-2元）：推送、活动
- 低价值用户（LTV<0.5元）：激励观看广告

## 五、用户分层与分群

### 5.1 RFM模型

**定义**:
- **R**（Recency）: 最近一次登录时间
- **F**（Frequency）: 登录频率
- **M**（Monetary）: 收入贡献（或游戏时长）

**游戏领域适配**:
```
R = 最近一次玩游戏的时间（天）
F = 过去30天游戏次数
M = 过去30天游戏总时长（或广告收入）
```

#### RFM用户分类（8类）

| 类型 | R | F | M | 特征 | 策略 |
|------|---|---|---|------|------|
| **重要价值** | 高 | 高 | 高 | 最近玩、频繁玩、时长长 | VIP待遇，减少打扰 |
| **重要保持** | 低 | 高 | 高 | 很久没玩、但曾经是核心用户 | 召回活动，推送新内容 |
| **重要发展** | 高 | 低 | 高 | 最近玩、不频繁、但单次时长长 | 增加登录频率激励 |
| **重要挽留** | 低 | 低 | 高 | 很久没玩、不频繁、但曾经贡献高 | 强力召回，问卷调查 |
| **一般价值** | 高 | 高 | 低 | 最近玩、频繁玩、但时长短 | 延长单次游戏时长 |
| **一般保持** | 低 | 高 | 低 | 很久没玩、曾经频繁 | 常规召回 |
| **一般发展** | 高 | 低 | 低 | 最近玩、不频繁、时长短 | 新手培养，引导 |
| **一般挽留** | 低 | 低 | 低 | 低价值流失用户 | 放弃或低成本召回 |

#### 《光与朽》RFM设置

**R（最近登录）**:
- 高: <3天
- 低: >3天

**F（30天登录次数）**:
- 高: >10次
- 低: <10次

**M（30天游戏时长）**:
- 高: >2小时
- 低: <2小时

### 5.3 用户生命周期阶段

**四阶段模型**:
```
新手期 → 成长期 → 成熟期 → 流失期
 (D1-3)  (D4-7)  (D8-30)  (>30)
```

| 阶段 | 特征 | 目标 | 策略 |
|------|------|------|------|
| **新手期** | 刚注册，体验核心玩法 | 提升D1留存 | 引导、降低难度、即时奖励 |
| **成长期** | 熟悉玩法，探索Build | 提升D7留存 | 解锁新技能、排行榜、每日任务 |
| **成熟期** | 核心玩家，稳定活跃 | 提升LTV | 高难度挑战、社交、赛季 |
| **流失期** | 停止登录 | 召回 | 推送、新版本通知、奖励 |

## 六、漏斗分析

### 6.1 新手漏斗分析

**《光与朽》新手转化漏斗**:
```
广告点击 → 激活 → 首次游戏 → 通过第3波 → 通过第10波 → 次日回来
  1000      600      480         336          134           34
  100%      60%      80%         70%          40%           25%
```

**转化率计算**:
- 激活率: 600/1000 = 60%
- 首次游戏率: 480/600 = 80%
- 第3波通过率: 336/480 = 70%
- 第10波通过率: 134/336 = 40% （流失大户！）
- 次日留存: 34/134 = 25%

**优化策略**:
- **第3波通过率70%** - 合格，继续观察
- **第10波通过率40%** - 问题严重，需降低难度
- **次日留存25%** - 达标，但可优化

### 6.2 付费漏斗分析（IAA）

**广告变现漏斗**:
```
看到广告 → 点击广告 → 完整观看 → 获得奖励
  1000       30         25          25
  100%       3%         83%         100%
```

**关键指标**:
- **广告展示率**: 多少玩家看到广告位
- **广告点击率**: 3%（行业平均2-5%）
- **完整观看率**: 83%（视频广告）
- **eCPM**: 单千次曝光收入

**优化策略**:
- 提高展示率 → 增加广告场景（复活、双倍）
- 提高点击率 → 优化按钮文案、位置
- 提高完整观看率 → 减少跳过选项、奖励吸引

## 九、《光与朽》数据分析实战

### 9.1 上线第1周：新手体验监测

**重点指标**:
- 首次游戏率 >80%
- 第3波通过率 >70%
- 第10波通过率 >40%
- 次日留存 >20%

**数据表格**:
```
| 日期 | 新增 | 首次游戏 | 通过3波 | 通过10波 | D1留存 |
|------|------|----------|---------|---------|--------|
| 2.22 | 100  | 85 (85%) | 60 (71%)| 22 (37%)| 20 (20%)|
| 2.23 | 120  | 96 (80%) | 68 (71%)| 25 (37%)| 24 (20%)|
```

**发现问题**:
- ✅ 首次游戏率达标
- ✅ 第3波通过率达标
- ❌ 第10波通过率37%<40%，需优化
- ❌ 次日留存20%刚达标，可提升

**优化措施**:
1. 降低第9-10波难度（敌人血量-20%）
2. 添加每日任务（提升次日留存）
3. 观察3天后重新评估

### 9.2 上线第2周：Build平衡性监测

**发现问题**:

- Frost+Shatter太弱（20%使用率，18%留存）

1. Chain+Prism削弱（伤害-10%）
2. Frost+Shatter增强（伤害+20%，冰冻时间+30%）

### 10.1 案例1: 第10波难度调整


**决策**: 降低第9-10波难度
- 第9波敌人血量-20%
- 第10波敌人血量-15%

**验证**:
```
优化后:
| 波次 | 死亡率 | 累积死亡率 |
|------|--------|-----------|
| 10   | 25%    | 45%       |（下降15%）
```

### 10.2 案例2: 广告场景优化

**问题**: D1 ARPU仅0.10元，低于目标0.15元

**数据分析**:
```
| 广告场景 | 展示率 | 点击率 | 人均观看次数 |
|---------|--------|--------|-------------|
| 复活广告 | 60%    | 80%    | 1.2次       |
```

2. 开宝箱观看广告

```
优化后:
人均观看次数: 1.2 + 0.8 + 1.0 = 3.0次
D1 ARPU: 3.0次 × 0.05元/次 = 0.15元 ✅
```
