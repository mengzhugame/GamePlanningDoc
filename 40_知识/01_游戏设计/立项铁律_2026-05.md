## 三条铁律（原文）

### 铁律 1：差异化拷问

> **这个游戏和市面上最火的同类，最核心的 3 个不同点是什么？答不上来就不做。**

**为什么这条最重要**

90 秒极限防线塔防项目就是这条铁律砍掉的：
- 路 A（传统短局塔防）≈ 缩水版《保卫萝卜》《合金战线》
- 路 B（90 秒生存守关）≈ 已有《奔奔王国》《全境守卫》
- 路 C（弹射连锁塔防）≈ 已有《超能下蛋鸭》

3 条路全部撞上现成成功游戏，"3 个核心不同点"答不出来 → 项目当场否决。

**回看美妆叠叠乐的失败原因**

立项时差异化定位是"三消（广泛）+ 空间整理（独特）"的特洛伊木马策略，但发行商反馈是"玩法老、美术差"。**3 个不同点说不清楚**——既不比《羊了个羊》更社交裂变，也不比《Goods Sort》更解压，最后被 32 家发行商拒绝。

**如何答**

| 同类爆款 | 我们的不同 |
|---------|-----------|
| [对标游戏 1] | [可被一句话描述的不同点] |
| [对标游戏 2] | [...] |
| [对标游戏 3] | [...] |

3 个不同点必须满足：
1. **可被陌生玩家在一句话内复述**（不是"画风更精致""手感更舒服"这种主观描述）
2. **能成为短视频钩子**（前 3 秒就能拍出来的差异）
3. **不依赖大厂资源**（不是"我有 IP""我能买量""我有团队"，而是机制层面的真差异）

如果 3 条不全满足，回去想，或者直接放弃这个方向。

---

### 铁律 2：美术走"风格化/猎奇/反差"路线，避免和大厂卷画质

> **美术必须走风格化/猎奇/反差路线，避免和大厂卷画质。**

**为什么**

光与朽就是用 Shader/激光视觉做差异化，TA（技术美术）背景在这条路上是真护城河。这是对的方向，但执行上还是被卷——因为整体美术包没走"风格化/猎奇/反差"，只是"激光做得不错"，不够极端。

**3 个具体路径**（参考 `超休闲游戏设计方法论.md` 美术趋势）

1. **风格化**：高饱和度 2D 扁平 / 精致像素 / 强烈文化基因（国画风、维多利亚风）—— 用风格识别度替代画质
2. **猎奇**：题材或视觉怪异到看一眼就停下（《超能下蛋鸭》的鸭蛋、《羊了个羊》的"省份排名"、《遗弃之地》的非遗剪纸风）
3. **反差**：可爱外皮 + 暗黑内核 / 治愈题材 + 紧张机制 / 复古像素 + 现代光影

**禁区**

- ❌ 写实风（独立开发者打不过 3A）
- ❌ 通用 3D 卡通（红海，制作成本拼不过大厂）
- ❌ "差不多就行"的 2D（无识别度等于无）

**如何答**

立项时必须能用一句话描述美术钩子：
> "这游戏看一眼，你会马上想到 [某种猎奇/风格化的视觉印象]，比如《XXX》给你的第一眼震撼。"

如果回答是"画风比较 [可爱/精致/酷]"，**说明没找到差异化美术方向**，回去想。

### 铁律 3：开发周期压缩到 1 个月内出 Demo 测试，用速度换容错

> **开发周期压缩到 1 个月内出 Demo 测试，用速度换容错。**

**为什么**

美妆叠叠乐和光与朽都犯了同样的错：
- 美妆叠叠乐：2 个月才联系发行商，差异化没验证就投入完整开发
- 光与朽："逃避发布心理"——不断加功能（赌博系统、12 波 + Boss、属性升级），但**核心玩法是否吸引人都没验证**就做完了

教训：**完整开发耗 3-6 个月，赌错代价是几个月时间**；如果 1 个月内出可玩 Demo 拿陌生玩家测试，赌错代价是 1 个月，且可以快速 pivot。

**为什么是"1 个月"不是"3 个月"或"7 天"**

- 7 天垂直切片只能做"一个机制"，不够给陌生玩家测试完整体验
- 3 个月已经是"半完整游戏"，止损成本太高
- 1 个月可以做出"核心循环 + 3 关 + 基础美术 + 可上传 itch.io / 发小红书"的版本，**够玩家给真反馈**

**如何答**

立项前必须能拆分出"1 个月可达"的 Demo 范围：
- Week 1：核心机制（用方块/圆形代替美术，验证有没有趣）
- Week 2：基础美术 + 3 个关卡 + 简单 UI
- Week 3：上传 itch.io / 录制 15 秒玩法视频发小红书 / 抖音 / B 站
- Week 4：收集陌生玩家反馈 + 决定 pivot 还是 push

**如果"1 个月可达"答不出来**，说明范围太大，砍功能直到能 1 个月做完。**不能因为"我还想加 XX"就把周期拖到 3 个月**——这就是逃避发布心理。

## 三条铁律的执行流程

```
新游戏方向冒出来
    ↓
铁律 1 检查：3 个核心不同点能写出来吗？
    ├─ 能 → 进入铁律 2
    └─ 不能 → 砍掉，回到创意收集
    ↓
铁律 2 检查：美术差异化路径选定了吗？
    ├─ 是（风格化/猎奇/反差）→ 进入铁律 3
    └─ 否（"差不多就行"）→ 砍掉或重新选风格
    ↓
铁律 3 检查：1 个月能出可测 Demo 吗？
    ├─ 能 → 进入概念视频 + AI 验证流程（参见 40_知识/00_工作流/休闲小游戏创意验证流程_v1.md）
    └─ 不能 → 砍范围或砍掉这个方向
    ↓
铁律全过 → AI 概念视频 → 陌生玩家调研 → 1 个月 Demo → 数据决策
```

铁律在流程里分两层使用：

- **创意萌芽期**：用铁律做红牌预审，砍掉核心循环说不清、明显撞车、完全不可做的方向；如果创意新、核心动词清楚、失败条件大致成立，可以进入低成本概念视频观察期。
- **数据达标、准备立项期**：三条铁律必须硬通过。答不上 3 个核心不同点、没有风格化/猎奇/反差美术钩子、1 个月 Demo 范围拆不出来，就不能进入 7 天切片或正式 Demo。

**铁律不是品类黑名单。** Match、Merge、塔防、寻物、经营等方向都不是永久禁止项；禁止的是“换皮撞车、差异说不清、还没验证就完整开发”。同一品类只要出现新的核心钩子、可执行美术路线和陌生人数据，可以重新进入漏斗。

## 铁律预审与正式立项审查要分层

90 秒极限防线被否决的核心原因不是“塔防不能做”，而是三条备选路线都撞上已有成功游戏，且无法回答最核心的 3 个不同点。这个案例适合作为正式立项审查的硬标准。

但在创意收集和 AI 概念视频阶段，铁律不应该把所有新想法提前杀死。更合理的判断是：

| 阶段 | 铁律作用 | 动作 |
| --- | --- | --- |
| 创意初筛 | 排除明显红牌 | 核心循环说不清、失败条件不存在、完全撞车的方向先停 |
| 概念视频观察 | 测“看得懂、想不想玩” | 创意新且大致可玩时，可低成本做 1-3 条真实玩法视频 |
| 数据达标后 | 硬性立项审查 | 三条铁律必须全过，才能进入切片 / Demo |

## 不要把品类判断误写成永久禁令

“Match ≠ Merge”提醒了一个重要边界：失败项目带来的教训不能粗暴变成“某个品类永远不做”。真正要否决的是缺少差异化、缺少市场信号、缺少可控开发范围的具体方案。

下一款游戏不是在《光与朽》路线和《美妆叠叠乐》路线之间二选一，而是在更大的创意漏斗里筛选：

```
市场/用户痛点 -> 创意组合 -> 概念卡 -> AI 概念视频 -> 陌生人数据 -> 铁律硬审 -> 可玩切片
```

品类可以被重新打开，但每次重新打开都必须带着新的钩子、新的数据和新的执行范围。

## 机制差异必须制造新的决策压力

城市水管抢修的否决补充了铁律 1 的判定口径：差异化不能只看“界面上多了什么”，要看它是否改变玩家决策。

有效机制差异至少要满足其中一类：

- 改变资源约束：玩家不能无限拿、无限改、无限试。
- 改变顺序压力：先放哪一个会影响后续空间或结果。
- 改变失败条件：新机制让玩家以不同方式输。
- 改变高光表达：3 秒视频能看出“这不是同类换皮”。

底部 3 个输入位本身不是差异。只有当它像 Block Blast 一样制造空间规划、不可回退、组合选择或失败压力时，它才是机制；否则只是 UI。

同一天的荒废花园讨论也补充了一个判断：情绪包装不是核心玩法。`荒废花园被复苏` 是长期目标、视觉反馈和情绪钩子；真正要被验证的核心仍然是种植经营循环。能成为差异的，是“花既能卖钱，又能投入复苏地块”的资源两难，而不是“花园很治愈”。

证据时间线排序被否决为独立方向，也属于同一规则：如果一个玩法更适合作为怪案侦探社里的子模块，就不要为了新鲜感把它强行立成完整项目。
