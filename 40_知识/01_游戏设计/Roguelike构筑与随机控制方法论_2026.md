# Roguelike 构筑与随机控制方法论 2026

## 来源: `10_流水/游戏拆解/batch_019_march_2026.md` · 提取日期 2026-05-25

## 热门前瞻只提炼机制杠杆，不直接变成立项方向

批次 019 里提到的暗黑魔咒构筑、体素物理破坏、多人混乱和 UGC 生态，适合当作“机制杠杆”而不是新项目题材清单。

对小团队有价值的抽象：

| 前瞻信号 | 可复用机制 | 不该误读成 |
| --- | --- | --- |
| 魔咒组合 | 多个低成本技能件形成连锁 Build | 立刻做完整暗黑动作 Roguelike |
| 哥特微恐 | 视觉风格放大玩法记忆点 | 只换皮成微恐题材 |
| 体素破坏 | 玩家改变场景结构，制造可传播结果 | 先做高成本物理引擎 |
| 多人混乱 | 玩家之间制造不可预测故事 | 单人项目强行加联机 |
| UGC / Mod | 规则本身能被社区再组合 | 早期版本就承诺创作生态 |

如果一个元素无法在 7-14 天内做成可感知的核心体验切片，就先保留为素材/题材观察，不进入当前立项。

## 构筑协同要让视觉、规则和数值指向同一个核心体验

批次 020 的几个独立游戏前瞻提供了同一个判断：强差异化不是单独来自系统、美术或题材，而是三者互相解释。

可复用到塔防 / Roguelike 的设计原则：

| 案例信号 | 抽象原则 | 《光与朽》可借鉴 |
| --- | --- | --- |
| Slay the Spire 2 | 卡牌 / 技能之间要有可解释协同 | 激光塔、插件、陷阱之间形成 Combo，而不是单点加数值 |
| Blighted | 战斗节奏和视觉风格要统一 | 清屏、击杀、Boss 阶段变化必须有强光暗反馈 |
| The Midnight Walk | 独特材质可成为记忆资产 | 精英怪或章节主题可用强材质差异，而不是全局换皮 |
| Solasta 2 | 环境规则可进入数值系统 | 光区加速、暗区易伤、地形光暗变化影响战局 |

一个构筑件的最低标准：玩家选它以后，不只面板改变，画面、行为和战斗策略也能一起改变。

## 伪随机不是降低难度，而是帮助玩家把流派做成

Tower Dominion 和 Monsters Are Coming 的共同启发是：Roguelike 的随机不能只追求“公平随机”，还要服务玩家的成型爽感。系统可以根据玩家已选流派，轻微提高相关组件出现概率，让玩家更容易凑出“大成”阵容。

设计边界：

| 做法 | 价值 | 风险 |
| --- | --- | --- |
| 根据已有核心件调高同系词条 | 玩家感觉“这局有戏” | 过强会像系统自动喂牌 |
| 英雄 / 塔 / 模组带明确流派标签 | 便于玩家理解构筑方向 | 标签太多会学习成本过高 |
| 羁绊产生质变而非小加成 | 构筑完成有爆发点 | 质变不可解释会像随机开挂 |
| 反向保底冷门流派 | 避免玩家连续臭局 | 不能破坏重开差异 |

伪随机的目标是减少“我知道想玩什么但完全抽不到”的挫败，不是保证每局都毕业。

## 知识成长可以成为 Roguelite 的长期进度

《Blue Prince》的核心价值是把 Roguelite 的长期成长从数值和解锁，转到“玩家理解”。庄园每日重置，地图和路径会消失，但玩家对房间、密码、资源路线和谜题关系的理解会留下。

可复用原则：

- 局内随机负责制造局面，局外知识负责形成长期进度。
- 多目标并行能缓冲坏随机：A 目标卡住时，玩家还能推进 B/C/D。
- 资源门槛要制造路线取舍，不能反复阻断玩家已知解法。
- 信息复杂时，界面必须外部化：词条、波次、路线、构筑记录和回顾都要帮玩家记。

知识型成长适合解谜、探索、塔防波次规律和怪物反制逻辑。它比纯数值成长更耐玩，但也更依赖信息呈现。

## 极端角色和可控随机，是短局 Roguelite 的重玩核心

《Brotato》的结构很克制：移动躲避 + 自动攻击 + 波间商店。它的深度来自极端角色、多武器挂载、属性取舍和可控随机。

可复用原则：

| 设计点 | 作用 | 复用提醒 |
| --- | --- | --- |
| 极端角色 | 迫使玩家围绕缺陷和长板构筑 | 不要每个角色都做成平均人 |
| 6 武器挂载 | 让构筑空间指数级放大 | 数量多时必须有合成/品质规则收束 |
| 收获 / 幸运 | 把经济成长变成流派选择 | 贪经济必须承担生存压力 |
| 同类武器概率提升 | 让玩家能把想法做成 | 仍要保留临场变招空间 |
| 固定短波次 | 降低失败成本，刺激再来一局 | 每波怪物职责要不同 |

短局 Roguelite 的爽感来自“这把我想玩一个极端东西，而且系统允许我把它做出来”。随机性负责提供分叉，不该负责反复否决玩家意图。

## 节奏奖励可以让同一关卡支持两种心流

《Dead Cells》的限时门和无伤门，把同一张地图拆成两种玩家策略：快速推进和稳扎稳打。它没有强制所有玩家用同一种方式“最优”，而是给不同节奏都配上奖励。

可复用原则：

| 节奏目标 | 奖励方式 | 设计价值 |
| --- | --- | --- |
| 快速推进 | 限时奖励、速通门、提前抵达奖励 | 鼓励高风险高速度 |
| 稳定清图 | 无伤奖励、连杀奖励、完美波次奖励 | 鼓励高掌控和低失误 |
| 高压反击 | 受击后短窗口补偿或反击收益 | 把受伤后逃跑转成进攻机会 |

对塔防 / Roguelike，类似结构可以变成“限时清波奖励”和“无漏怪奖励”。两者同时存在，玩家才会觉得自己是在选择风格，而不是被系统单一路线牵着走。

## 手工模块加程序拼接，比纯随机更适合保证战斗质量

《Enter the Gungeon》的房间内部是手工设计，楼层连接由程序拼接。这种结构让每个战斗房有最低质量，同时保留 Roguelike 的路径新鲜感。

对小团队尤其有用：

- 先手工做少量“高质量压力模块”：快速波、坦克波、远程压迫、Boss 前补给、奖励房。
- 再用程序按节奏曲线排列，而不是让生成器随机乱抽。
- 每个模块要有明确职责，避免只是怪物数量不同。
- 隐藏协同可以少量存在，用来制造发现感，但必须可测试、可解释。

随机生成不是为了省设计，而是为了重组已经被设计过的好片段。

## 构筑要同时有加法、减法和规则改写

《Slay the Spire》的构筑深度来自三件事：加卡获得新能力，删牌提高核心牌出现率，遗物改变整局规则。只做“奖励越来越多”的 Roguelike 很快会变成噪音池。

可复用到非卡牌游戏：

| 构筑动作 | 卡牌游戏表达 | 塔防 / 动作表达 |
| --- | --- | --- |
| 加法 | 获得新卡 | 新塔、新技能、新插件 |
| 减法 | 删牌、净化诅咒 | 排除低级奖励、锁定流派、回收不合适模块 |
| 规则改写 | 遗物改变能量、抽牌、敌人意图 | 全局 Buff / 代价契约 / 波次规则改变 |

敌人意图公开也是核心：当玩家知道下一回合或下一波的压力，策略才是“怎么应对”，而不是“猜系统会不会坑我”。

## 来源: `10_流水/游戏拆解/game_breakdown_isaac.md` · 提取日期 2026-05-25

## 失控构筑要用代价入口约束，而不是用均衡抹平

《The Binding of Isaac》的道具系统说明：Roguelike 的爽感不一定来自精密平衡，很多时候来自“这局组合彻底变异了”。关键是失控不能白送，而要通过血量、钥匙、炸弹、商店、诅咒房、恶魔房等代价入口让玩家主动承担风险。

可复用原则：

| 设计点 | 价值 | 风险控制 |
| --- | --- | --- |
| 道具改变攻击形态 | 让构筑有肉眼可见的质变 | 不只加面板，必须改变行为 |
| 反协同/负面词条 | 让选择有赌性和故事 | 负面要可理解，不要暗坑 |
| 血量/资源交易 | 把贪心做成核心决策 | 高收益节点要提前可见 |
| 允许破局 Build | 形成传播和重玩记忆 | 用稀缺入口控制频率 |

对塔防肉鸽来说，激光塔、陷阱和插件可以有明显代价：射程缩短、过热更快、占格更大、误伤风险或维修成本更高。不要把所有奖励磨成温和加成，否则玩家不会有“这把离谱了”的记忆。

## 第二压力条能制造长期紧张，但必须给恢复出口

《Darkest Dungeon》的压力系统把失败从“血量归零”扩展到“精神崩溃”。它的启发不是简单加惩罚，而是让玩家同时管理短期战斗损伤和长期队伍状态。

可复用到塔防 / Roguelike 的方式：

| 压力资源 | 可能表达 | 必要出口 |
| --- | --- | --- |
| 塔过热 | 连续攻击后效率下降或停机 | 冷却、手动停火、维修 |
| 核心污染 | 防线承压后全局规则变差 | 净化、牺牲资源、阶段结算 |
| 队伍士气 | 单位被击破后连锁减益 | 替补、恢复房、撤退 |
| 光暗压力 | 暗区收益更高但风险增加 | 火把/照明/安全路线 |

第二压力条最怕变成“越输越输”的纯负反馈。设计时要确保玩家能提前读到压力、主动释放压力，并在失败后知道下一局如何改善。

## 高密度系统需要思考窗口，否则策略会退化成手忙脚乱

《FTL》的实时暂停把氧气、火灾、破舱、船员、护盾、武器和能量分配变成可思考的策略题。没有暂停，这些系统联动很容易只剩反应速度；有了暂停，玩家会觉得自己是在当船长调度灾难。

可复用原则：

- 当局面同时要求处理 3 个以上系统时，给暂停、慢动作或波间战术窗口。
- 系统联动必须显示因果：什么坏了、谁在修、多久恢复、下一次危险何时到来。
- 推进压力要存在，防止玩家无限拖延，但不能快到来不及理解。
- 多用途资源比多种孤立资源更有策略痛感，例如同一资源同时用于维修、升级和购买。

对《光与朽》，如果后期要同时做 Boss 技能、塔过热、维修、资源转化和路线压力，应该先设计“玩家什么时候能停下来想”。策略密度不是让玩家同时按更多键，而是让玩家在压力下做更好的取舍。

## 空间容量和开局锚点，可以让塔防构筑更早成型

《Monster Train》把卡牌构筑放进三层车厢，容量和楼层职责让每张单位牌都有空间含义。它的另一个关键是 Champion：玩家从开局就有一个流派锚点，随机奖励围绕它展开时更容易形成方向感。

可复用原则：

| 结构 | 价值 | 小团队降维用法 |
| --- | --- | --- |
| 多层/多线防守 | 让单位有前排、清杂、爆发、承伤等职责 | 先做两层或前后排，不必一开始三层 |
| 容量限制 | 避免只用金币堆满最优解 | 每层格子、供能或重量上限 |
| 双阵营/双模块 | 提高构筑组合数 | 主塔流派 + 副插件流派 |
| Champion 锚点 | 降低早期随机挫败 | 开局核心塔/英雄/圣物明确路线 |
| 强升级 | 允许 PvE 出现过强 Build | 用 Boss 和难度层级承接 |

塔防肉鸽如果只有“抽塔 + 摆格子”，很容易变成随机商店。加入空间容量和开局锚点后，玩家会更早产生“这把我要围绕某个东西建防线”的意图。

## 涌现式构筑来自少量基础规则的可组合，而不是堆随机事件

《Noita》的像素物理和魔杖系统说明：真正强的涌现感不是写很多特殊事件，而是让少量规则互相作用。水导电、油燃烧、酸腐蚀、地形可破坏、法术从左到右执行，这些基础规则组合起来，才会出现玩家意想不到的连锁。

对 Roguelike / 塔防可复用：

| 基础规则 | 组合价值 | 小团队降维方式 |
| --- | --- | --- |
| 材质相克 | 环境能参与战斗 | 做 3-4 种稳定元素反应即可 |
| 地形可变 | 路线和战斗空间可被玩家改写 | 波间地形改造，不必实时物理 |
| 触发器 | 技能之间形成链式执行 | 击中、击杀、破盾、过热触发后续效果 |
| 顺序执行 | 构筑像写小程序 | 插件顺序影响激光效果 |

涌现系统的底线是可读。玩家可以被自己制造的危险反杀，但必须知道危险从哪里来。

## 来源: `10_流水/游戏拆解/hades_breakdown.md` · 提取日期 2026-05-25

## 死亡可以成为回家循环，而不是单纯失败结算

《Hades》把 Roguelite 的死亡处理成叙事、局外成长和角色关系推进。玩家死后不是回到空菜单，而是回到冥王神殿，对话、升级、解锁武器和理解世界。

可复用原则：

- 失败后给玩家可感知的回收：资源、文本、图鉴、模块线索或新目标。
- 局外成长用于降低重复挫败，但不要完全替代操作进步。
- 死亡原因可以进入下一次反馈，例如“被哪类 Boss 技能打死”触发提示或日志。
- 如果叙事产能有限，可以用少量条件文本和战斗复盘替代大规模剧情。

对小团队来说，重点不是复制海量动态对话，而是避免“死了只剩重新开始”的冷冰冰结算。

## 规则破坏要先建立规则，再给玩家短暂作弊权

《Inscryption》的破格道具、密室解谜和 Meta 叙事之所以有效，是因为玩家先相信了牌桌规则：献祭、格子、伤害和道具都有稳定预期。随后游戏再允许拔牙、拿眼球、用局外谜题反哺牌局，玩家会觉得自己获得了“合法作弊权”。

可复用到 Roguelike：

| 步骤 | 设计目标 |
| --- | --- |
| 先建立稳定规则 | 玩家知道正常情况下怎么赢 |
| 再给破格入口 | 道具、事件、契约或隐藏房改变规则 |
| 破格要有代价或稀缺性 | 避免常态化后失去惊喜 |
| 破格要服务题材 | 不只是强，而是符合世界观 |

规则破坏不是乱改规则，而是让玩家在理解系统后，短暂站到系统之上。

## 来源: `10_流水/游戏拆解/loop_hero.md` · 提取日期 2026-05-26

## 玩家自选风险，比系统硬塞难度更有参与感

《Loop Hero》的逆向塔防结构说明：风险收益可以由玩家亲手放到地图上。玩家放地形、生成怪物、制造危险，是为了换资源、装备和后续成长；但放太多又会让英雄暴毙。

可复用原则：

| 设计方式 | 玩家感受 | 风险 |
| --- | --- | --- |
| 强化敌人换奖励 | 我在主动贪 | 奖励和风险要可预估 |
| 增加支路换资源 | 我在塑造局面 | 支路压力不可突然无解 |
| 召唤精英换稀有模块 | 我在赌高收益 | 精英能力要提前明牌 |
| 撤退保资源 | 我能见好就收 | 撤退点不能太隐蔽 |

系统难度上升会让玩家被动承受；自选风险会让玩家觉得失败也是自己贪出来的。

## 来源: `10_流水/游戏拆解/lucky_defense.md` · 提取日期 2026-05-26

## 高波动随机要配“废件回收”和“情绪缓冲”

《Lucky Defense》的随机召唤之所以能撑住移动端留存，不是因为它足够公平，而是因为它提供了修正口：低阶单位能合成，没用单位能卖，核心单位有追逐目标，合作队友还能替玩家缓冲手臭。

对塔防肉鸽可复用：

- 重复/低级奖励不能真垃圾，要能分解成刷新币、升级材料或核心充能。
- 随机升阶要有开奖反馈，但不要让失败完全无收益。
- 合作或共享目标适合稀释随机挫败，比一上来做 PvP 更稳。
- 可以有少量超模核心，但要靠轮换、词条或章节特攻避免模板永久固化。

随机负责戏剧性，回收机制负责让玩家觉得“这把还没完全白费”。

## 触发链是后期爽感放大器，但必须有系数和冷却

《Risk of Rain 2》的道具系统最爽之处是伤害触发道具，道具伤害又能触发其他道具，最终形成闪电、导弹、爆炸、暴击和死亡连锁。它的底层依赖触发系数，避免高频攻击天然碾压一切。

可复用到塔防 / 动作：

| 触发层 | 示例 | 控制手段 |
| --- | --- | --- |
| 主攻击 | 激光命中、塔弹命中 | 触发系数、命中间隔 |
| 次级特效 | 电弧、爆炸、燃烧 | 独立冷却、递减触发率 |
| 击杀效果 | 死亡爆炸、金币飞溅 | 同屏上限、范围衰减 |
| 规则改写 | 暴击触发冻结、破盾触发连锁 | 稀有度和条件限制 |

触发链的目标是让玩家看到“我搭的系统自己运转起来了”。如果所有东西都能无限触发，爽感很快会变成性能和可读性灾难。

## 长期解锁不能污染卡池，构筑需要收缩权

《Rogue Tower》的卡牌升级让塔防有了构筑重玩性，但也暴露了一个常见问题：解锁越多，关键牌越难抽到。玩家甚至可能希望重置进度，让卡池重新变窄。

设计原则：

- 长期解锁不应只增加随机池宽度，也要增加定向能力。
- 玩家需要流派标签、锁卡、 ban 卡、刷新、保底或开局倾向。
- 早期卡池要窄，先让玩家体验成型；后期再开放复杂组合。
- “更多内容”如果降低核心流派成型率，就不是成长，而是污染。

对《光与朽》这样的模块/词条构筑，局外成长应优先解锁“选择权”，而不是简单把更多词条塞进池子。

## 涌现死亡要让玩家学到规则，而不是只感到倒霉

《Spelunky》的关键是统一规则集：敌人、陷阱、道具、商店和地形都遵守同一套物理/交互逻辑。玩家被复杂连锁害死时，如果能复盘出“是我触发了这条规则”，死亡就会变成知识成长，而不是随机恶意。

设计原则：

- 先做少量稳定规则，再允许它们互相作用。
- 事故必须能被玩家追溯因果：谁触发了陷阱、哪里爆炸、为什么商人敌对。
- 限时压力适合防拖延，但要给明确预告和逃生路线。
- 通用资源比专用资源更有策略味，例如同一炸弹既能开路、杀敌、救场，也能贪宝。

对塔防肉鸽来说，反射体、路障、敌人技能、塔攻击和奖励物最好共享一批可学习规则。这样每个新增模块都能进入组合网络，而不是变成孤立脚本。

## 自动攻击也需要目标追逐，时间轴和进化配方负责保持参与

《Vampire Survivors》把操作简化到移动，但并没有把玩家变成纯旁观者。经验宝石、三选一升级、武器进化和分钟刷怪时间轴共同提供目标：这一分钟要活下去，这几级要凑进化，这一波要赶上 DPS。

可复用框架：

| 结构 | 作用 | 风险控制 |
| --- | --- | --- |
| 时间轴刷怪 | 给局内成长设 deadline | 波次变化要能被看见 |
| 经验拾取 | 让移动仍有主动性 | 磁铁/拾取范围缓解漏捡焦虑 |
| 武器 + 被动进化 | 把随机选择变成追目标 | 配方不能太黑 |
| 宝箱强化 | 给构筑质变开奖 | 演出不要过长打断节奏 |

对《光与朽》，最适合学习的是“时间轴压力 + 明确进化配方”，而不是全自动攻击。主激光仍由玩家掌控，副武器或芯片可以自动化，形成主操作和自动系统的分层。

## 刷宝构筑要把“掉落刺激”和“筛选目标”同时做清楚

《英雄没有闪》把暗黑 Like 的刷宝压成竖屏自动战斗，说明构筑深度不一定依赖复杂操作。装备随机词条、符文、套装和技能流派负责长期目标，光柱掉落和自动对比负责短期反馈。

可复用原则：

| 结构 | 作用 | 风险控制 |
| --- | --- | --- |
| 光柱/稀有掉落 | 给自动战斗持续多巴胺 | 稀有反馈不能泛滥 |
| 自动分解/对比 | 降低海量装备管理疲劳 | 目标词条要可锁定 |
| 套装 + 符文 | 让装备服务流派 | 不要只有战力数字 |
| 副本层级 | 给流派验证场景 | 高难要测构筑，不只是测充值 |

对《光与朽》，如果做模块掉落或局外装备，重点不是增加背包数量，而是让玩家看见“这个模块能让我的激光流派成型”。掉落必须服务流派，不要让玩家在大量无意义词条里做清洁工。

## 可控随机要让玩家形成计划，而不是只等待开奖

塔防肉鸽的随机性最重要的不是“真随机”，而是让玩家在 20-40 秒内不断经历：读局势、做选择、看到回报、迎接更高压力。随机如果只负责出结果，玩家会觉得看脸；随机如果给玩家可操控的工具，就会变成构筑研究。

可控随机的 7 个阀门：

| 阀门 | 作用 |
| --- | --- |
| Bag / Deck 随机 | 避免连续极端臭手 |
| 隐藏保底 | 防止核心流派长时间完全断供 |
| 输入随机优先 | 随机给选项，结果由玩家执行，而不是随机决定胜负 |
| 后期权重更高 | 关键转型和补短板机会不要全部押在开局 |
| 保底锚点 | 至少给一个当前路线、一个补短板、一个转型/高风险选项 |
| 构筑时序 | 0-2 分钟保命，2-5 分钟成第一块，5-8 分钟给乘区和重构 |
| 操控工具 | 锁定、刷新、预览、偏置卡池、Boss 前重构 |

局外成长也应优先强化“选择权”：奖励锁定、刷新优化、波次预览、Boss 前重构，比单纯攻击 +3% 更能增加自主性和策略感。随机负责分叉，不该反复否决玩家已经形成的计划。

## 高留存来自未完成的下一局假设

Roguelite 的留存不是签到把玩家绑回来，而是让玩家每次离开时都带着一句“下把我想验证这个”。有效回访循环包含四层：

| 层级 | 设计问题 |
| --- | --- |
| 内部触发 | 玩家是否记得上局差哪一件成型、死在哪个缺口 |
| 低摩擦行动 | 回到游戏后 10 秒内能否进入有效玩法 |
| 可变奖励 | 随机奖励是否能被复盘为流派想象，而不是抽奖 |
| 投入留痕 | 玩家是否留下新解锁、新理解、新图鉴或新构筑计划 |

失败后最该给的不是一串资源，而是复盘：最高伤害来源、崩盘主因、当前 Build 短板和下一局建议。资源安慰只能短期止痛，解释和假设才会驱动下一局。

## 三类奖励箱对应三种玩家心理

《光与朽》旧版完整策划里的三色箱子值得抽象成 Roguelike 奖励选择模型：同一轮选择里同时提供稳健、博弈和交易三种心理。

| 奖励类型 | 玩家心理 | 适合内容 | 风险控制 |
| --- | --- | --- | --- |
| 稳健型 | 我需要安全感 | 回血、护盾、补短板、保底资源 | 收益上限低，避免成为唯一最优 |
| 博弈型 | 我想赌一把 | 随机大奖、空结果、小负面、稀有强化 | 必须有坏运气保护 |
| 交易型 | 我愿意付代价换强度 | 扣血、扣盾、降防换伤害/暴击/副武器 | 代价要可读，可被玩家主动承担 |

这套结构的价值不是颜色，而是情绪分工。每次三选一如果都只是“伤害 +5%、范围 +5%、生命 +5%”，玩家不会形成构筑记忆；但如果三个选项分别回答“保命、赌博、献祭”，选择本身就变成剧情。

设计要点：

- 稳健选项负责不让低水平玩家马上崩盘。
- 博弈选项负责制造高方差和短视频高光。
- 交易选项负责让高手表达自信和风险偏好。
- 保底机制要隐藏在系统里，保护体验，不要让玩家觉得系统在发福利表。

奖励 UI 必须直接写明代价和收益，特别是交易型选项。玩家可以承受高风险，但不能接受被系统偷扣资源。

## Roguelike 上瘾点来自“高压、转机、复盘”的可解释循环

Roguelike 的随机奖励不能只理解成抽奖。更稳定的体验循环是：高压局面让玩家进入紧张，随机奖励提供转机，失败后还能把原因复盘成下一局假设。

| 体验环节 | 设计作用 | 风险 |
| --- | --- | --- |
| 不确定奖励 | 让玩家期待“这次会不会成型” | 纯看脸会让玩家觉得被系统否决 |
| 逆境转机 | 在血量、怪潮和奖励间制造绝处逢生 | 没有翻盘工具会变成单纯折磨 |
| 死亡价值 | 失败后留下成长、解锁或理解 | 只有资源安慰会很快变成刷数值 |
| Build 协同 | 让两个普通选择组合后质变 | 协同不明显会变成堆属性 |

有效的死亡结算要回答三个问题：这局为什么崩、差哪一件成型、下一局可以尝试什么。留存来自未完成的构筑假设，而不是只靠局外成长数值。

## 塔防肉鸽随机要先保护战斗心流

Action / Tower Defense Roguelike 最怕随机奖励把战斗节奏切碎。随机系统应该服务连续压力和高频抉择，而不是频繁用全屏 UI 或长演出把玩家从战场拉走。

随机可以分三层控制：

| 随机层 | 作用 | 设计边界 |
| --- | --- | --- |
| 资源随机 | 三选一、掉落、宝箱 | 给构筑分叉，不连续否决玩家意图 |
| 模式 / 事件随机 | 特殊房间、奖励关、事件波 | 调剂中期节奏，不破坏主循环 |
| 怪物随机 | 刷怪组合、精英、压力点 | 产生未知压迫，但必须可预警和可反制 |

波次不要做成匀速自来水。每一波内部也要有波峰和波谷：波峰制造精英怪海或 DPS Check，波谷给玩家拾取、补强、读局势和期待下一次升级。

如果需要做工具化验证，可以把刷怪配置转成心流曲线：统计每秒怪物数量、血量总和、经验供给和升级触发点，检查是否存在过长死区、连续高压无补给，或整局没有明显波峰波谷。

## 前置标签是控制技能池污染的低成本办法

Roguelike 技能池扩张时，最危险的不是内容少，而是“寄生技能”过早进入随机池。寄生技能只有在玩家已经选择某个基础机制后才有意义，提前出现会污染三选一。

更稳的结构是前置标签：

| 层级 | 例子 | 作用 |
| --- | --- | --- |
| 基础技 | Frost / Fire / Chain | 初始池可见，决定流派入口 |
| 衍生技 | 冰冻传染、点燃蔓延、连锁强化 | 只有拿到对应标签后入池 |
| 终结技 | 碎冰爆发、爆燃、引雷 | 让流派在中后期出现质变 |

这套结构能同时解决两个问题：早期卡池保持可读，后期又能让玩家感觉自己在“养成一条路线”。它比一次性把所有组合件塞进池子更适合个人开发的短局 Demo。
