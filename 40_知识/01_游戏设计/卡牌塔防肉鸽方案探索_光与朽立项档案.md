# 卡牌塔防肉鸽方案探索（光与朽立项档案）

> **这是光与朽 2025-Q3 立项前的早期方案探索记录**。光与朽最终采用了不同结构（旋转激光塔防 + 黑油怪），这里的方案 1/2/3 没有直接落地，但提炼出的方法论仍对未来「卡牌 + 塔防 + 肉鸽 + 合成 / 微操」类游戏有参考价值。
>
> **为什么保留**：当时探索的「轻量微操」「战斗中合成」「房间推进」三类设计思路是同赛道的通用经验，不绑死光与朽。
> **如何使用**：未来做相同赛道时直接参考；不参考时不要照搬，因为这是探索期方案不是验证后结论。

---

## 探索背景

光与朽立项前评估「Habby 系自动战斗 RogueLite」赛道（参考 Archero / 向僵尸开炮）。当时纠结的是：在「自动战斗 + 卡牌升级」基础上要不要加更多互动维度。探索了 3 个方案：
1. **轻量微操**：自动战斗 + 玩家少量走位避招
2. **炮塔合成**：童话机械题材 + 战斗中合成炮塔单位
3. **符石合成**：战斗中合成元素符石释放技能

光与朽最终没用这 3 个方案，转向纯激光塔防方向。但方案中的几个设计思路有通用价值，本档案提炼。

---

## 方案 1 设计思路：轻量微操（点划移动 + 自动锁敌）

### 核心思路
在现有自动战斗基础上，玩家拥有「点击位移 / 短滑动」的轻量走位能力，AI 仍自动锁敌攻击。**目的：增加技术性生存的成就感，不增加操作疲劳**。

### 关键设计点

| 设计点 | 具体做法 | 为什么 |
|--------|---------|--------|
| 走位方式 | 点击或短滑动屏幕，英雄向该方向短距离位移（类似闪避） | 避免摇杆遮挡 + 操作疲劳；竖屏单手友好 |
| 自动锁敌 | 玩家移动不中断自动攻击；移动中略降攻击频率但不停 | 走位 ≠ 风筝；保持战斗节奏 |
| 停留惩罚/激励 | 长时间站定输出伤害提升但更危险；适度移动则提升生存 | 鼓励玩家权衡走位频率 |
| 移动冷却 | 走位有短冷却（耐力槽） | 限制无脑走位空转 |
| 卡牌联动 | 静止系英雄（狙击）站定时伤害提升；移动系英雄（刺客）移动后暴击率提升 | 卡牌构筑产生「静动搭配」策略空间 |
| 房间推进 | 每个房间完成后出分叉路线，玩家手动走位进入下一房间 | Roguelite 探索感 + 喘息空间 |
| 边界限制 | 房间面积有限 + 超界提示 | 防止无限风筝 |

### 防坑要点

- **避免无目标空转**：玩家跑动导致瞬间无敌人时，英雄朝最后敌人方向预射击 / 警戒姿态。
- **距离判定**：位移后 AI 即时重新判定目标和方向，不出现攻击空窗。
- **怪物追踪算法**：竖屏小范围内优化转向，不卡拐角。

### 适用场景

适合「自动战斗 + 想加技术性」的赛道，但不适合「纯放置」（操作上限会破坏放置体验）。光与朽走的纯塔防路线就**不适合**叠加这套微操——塔不会走，加位移没意义。

## 方案 2 设计思路：战斗中合成（炮塔合成 + 童话机械题材）

### 核心思路
战斗中玩家可拖拽相同等级的防御单位合成更高阶单位（参考自走棋）。**关键差异**：合成是战斗内即时操作，不是关卡间养成。

### 关键设计点

| 设计点 | 具体做法 |
|--------|---------|
| 合成机制 | 场上两个相同等级炮塔，拖动叠加 → 合成二级 |
| 自动战斗 | 角色和召唤单位自动攻击邻近敌人 |
| 卡牌召唤 | 玩家通过卡牌召唤童话生物伙伴或机械炮台 |
| Roguelite 升级 | 击败一定数量敌人后三选一 Buff |
| 永久成长 | 工坊建造 + 卡牌池升级 + 工程师英雄装备 |
| 关卡结构 | 10-15 房间组成单次闯关（战斗/宝箱/商店/Boss），15-20 分钟一局 |

### 美术钩子（适合题材）

童话 + 蒸汽朋克 2D Q 版（小红帽戴护目镜操纵机甲、老虎机甲拉南瓜炮车）。**关键判断**：题材辨识度强 + 制作成本可控 + 跨地域审美友好。

### 适用场景

适合「想做 RogueLite + 自走棋元素」但又不想做完整自走棋的赛道。**核心爽点**：合成进化的即时视觉反馈 + 「资源调配」的微策略。

## 方案 3 设计思路：战斗中合成（元素符石 + 实时决策）

### 核心思路
怪物掉落元素符石（火/冰/雷/毒），玩家在战斗间隙拖拽合成符石释放强力技能。**关键差异**：合成对象是「技能」而非「单位」。

### 关键设计点

| 设计点 | 具体做法 |
|--------|---------|
| 符石掉落 | 怪物死亡概率掉落元素符石，存到屏幕下方合成槽 |
| 合成方式 | 拖拽相同元素符石，2 个或 3 个合成更高级 |
| 即时释放 | 合成后立刻释放技能（火海 / 雷击 / 召唤） |
| 策略权衡 | 战斗紧张时立即用低级符石救急；空闲时攒高级符石 |
| 卡牌构筑 | 携带「炼金石」道具改变掉落（提升某元素符石掉率） |
| 关卡节奏 | 每几波怪后短暂安全时段供合成；合成奖励房作为整理空间 |
| 元素克制 | 怪物有元素抗性，鼓励玩家用「克制元素」符石 |

### 防坑要点

- **AI 助手**：玩家专注合成时检测 2 秒无指令，英雄自动走位 / 防御姿态。
- **快合成按钮**：足够组成高阶时一键合成最高级，避免拖拽浪费时间。
- **半透明合成界面**：平时不遮挡战斗视野，点击展开。
- **拖拽自动吸附**：相同元素拖近即可，无需精确重叠。
- **掉落上限**：合成槽最多 5 个，超出自动合成更高阶防卡顿。

### 适用场景

适合「想做技能驱动型 RogueLite」的赛道。**风险**：操作复杂度比方案 1/2 高，对玩家分神能力要求大。可考虑提供「简单难度自动减速 50%」的辅助。

## 三个方案的对比

| 维度 | 方案 1 微操 | 方案 2 炮塔合成 | 方案 3 符石合成 |
|------|-----------|--------------|--------------|
| 主要互动 | 走位避招 | 拖单位合成 | 拖符石合成 |
| 操作复杂度 | 中 | 中 | 高 |
| 美术成本 | 中（单位+场景） | 高（童话+蒸汽朋克） | 中（符石图标 + 技能特效） |
| 留存机制 | 走位技术 + 卡牌养成 | 合成进化 + 工坊建造 | 元素流派 + 符石养成 |
| 适合人群 | 想要轻技术感的中度玩家 | 喜欢自走棋的策略玩家 | 喜欢技能 build 的玩家 |
| 风险 | 跑位空转 / AI 失灵 | 美术量大 / 题材门槛 | 操作分神 / 学习成本 |

## 从光与朽实际选择反推的方法论

光与朽最终**没选这 3 个方案**，选了「**旋转激光塔防 + 黑油怪 + 三选一构筑**」。反推决策原因：

1. **方案 1 微操** 太接近 Archero / 向僵尸开炮，没有差异化壁垒
2. **方案 2 炮塔合成** 美术量太大，单人 TA 团队做不了童话+蒸汽朋克双风格融合
3. **方案 3 符石合成** 操作复杂度高，跟「光与朽 = 解压爽游」定位冲突

**普世结论**：「卡牌 + 塔防 + 肉鸽」是个**好赛道但拥挤**，必须在「核心动词」上做差异化才能立项。光与朽用「旋转激光的视觉特效差异化」+「黑油怪的题材猎奇差异化」过铁律 1，是更适合 TA 出身单人开发者的路径。
