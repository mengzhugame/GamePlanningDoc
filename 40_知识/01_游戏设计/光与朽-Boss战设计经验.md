# 光与朽·Boss 战设计经验

> 来源：《光与朽》VolcanoBoss 与 GlacialBoss 的设计、实现和调试记录。用于沉淀“Boss 技能如何既可读、可调，又能落到 Unity 状态机里”。

## Boss 受击反馈要区分护甲、核心和阻挡物

Boss 反馈不能只问“有没有飘字 / 有没有白闪”，要先区分命中语义：

| 命中对象 | 玩家理解 | 推荐反馈 |
| --- | --- | --- |
| 护甲 / 外壳 | 打到了，但不是最优伤害 | 灰色小飘字，弱反馈或无白闪 |
| 核心 / 眼睛 | 打到弱点，产生有效伤害 | 红色大飘字，强白闪，音效峰值 |
| 熔浆液 / 阻挡物 | 激光被挡住，Boss 没受伤 | 阻挡物本身要有命中反馈，避免误判为 Boss 漏飘字 |

VolcanoBoss 的白闪触发本身只在 `TakeCoreDamage()`，方向是对的；问题在于白闪材质组抓得太宽，把 body02 岩石护甲也一起闪白，导致“打到核心”和“打到身体”的视觉差异被抹平。

可复用规则：**Boss 的反馈层级要和玩家策略一致。** 如果玩家应该追求打核心，就必须让核心命中的反馈明显强于护甲命中。

## Boss 技能要先定义战术职责，再映射到状态机

GlacialBoss 的实现价值在于：每个技能都有明确战术职责，然后再映射到 `BaseBossController` 的状态或自定义协程。

| 技能 | 战术职责 | 实现映射 |
| --- | --- | --- |
| 冰墙构建 | 制造路径阻断和输出损耗 | `BossState.Summon` + 召唤 IceWall |
| 冰封射线 | 打断玩家输出节奏 | 自定义协程，Boss 停止移动，射线扫屏 |
| 极寒冲撞 | 迫使玩家处理位移压力 | `BossState.Charge` |
| 绝对零度 | 高优先级惩罚技，制造打断目标 | 独立触发器，中断当前状态并覆盖协程 |

Boss 技能不要从“我想加一个酷技能”开始，而要从“它给玩家制造什么决策”开始。状态机只是落地方式。

## 高优先级技能必须能安全中断当前技能

“绝对零度”是一个典型高优先级技能：它要在冷却就绪、阶段满足时打断当前行为，进入蓄力、可被打断、失败惩罚的完整流程。

实现层的关键点：

1. 触发前记录当前 Boss 状态和关键计时器。
2. 停止当前 `stateCoroutine`，避免两个技能并行抢控制。
3. 蓄力开始时记录 HP 快照。
4. 每帧检测蓄力期承伤是否达到打断阈值。
5. 打断成功和失败走两套明确结算。
6. 结算后回到 Idle 或统一状态入口。

这类技能的风险不是写不出来，而是状态清理不干净：移动没停、协程叠加、伤害快照重复结算，都会让 Boss 行为变成随机事故。

## Boss 阶段变化要改变行为组合，不只是加数值

GlacialBoss 使用 HP 阈值切阶段：

| 阶段 | HP 阈值 | 行为变化 |
| --- | --- | --- |
| Phase 1 | >65% | 基础技能池 |
| Phase 2 | 30%-65% | 额外定时召唤 FrostTank |
| Phase 3 | <=30% | 绝对零度冷却缩短 |

这比单纯提高攻击力更可读。玩家能感受到“Boss 进入新阶段”，也能学习新的处理重点。

可复用原则：

- Phase 1 教技能。
- Phase 2 叠加压力，但不完全换规则。
- Phase 3 缩短关键技能节奏，制造终局压迫。

阶段变化应优先改“技能频率、组合方式、召唤物、打断窗口”，最后才考虑简单加伤害。
