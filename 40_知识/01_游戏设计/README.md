# 01_游戏设计

## 这个分区放什么

游戏**机制与体验**层面的知识。包括但不限于：

- 核心循环与留存设计
- 关卡节奏、Boss 战、新手引导
- 玩法系统（叠放、动作、解谜、Roguelike 等）
- 付费点与情感驱动
- 数值与经济的设计哲学（纯数值公式放 `05_数值与经济`）
