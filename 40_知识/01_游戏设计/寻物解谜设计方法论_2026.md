# 寻物解谜设计方法论 2026

> 适用对象：以“找物 / 找茬 / 证物链 / 指认”为核心的轻推理休闲游戏。重点不是写完整侦探剧本，而是把“找到了什么、它证明了什么、玩家如何做出判断”压缩成可低成本量产的关卡结构。

## 来源: `10_流水/2026-05/2026-05-06.md` · 提取日期 2026-05-17

## 核心玩法：侦探社是外壳，找证物破案是内核

侦探社、委托、办公室升级都只能作为外层包装。第一版真正要验证的是短局“寻物解谜”：

```
现场调查 -> 找到关键证物 -> 形成证据链 -> 从嫌疑人中指认真凶 -> 真相揭示
```

最小可玩模型：

| 模块 | 最小配置 | 作用 |
| --- | --- | --- |
| 案发现场 | 1 个 2D 房间 / 街角 / 店铺场景 | 承载寻物操作 |
| 关键证物 | 3 个 | 让进度从 0/3 到 3/3 清晰可见 |
| 工具 | 普通点击、放大镜、紫外灯 | 增加“我发现隐藏线索”的爽点 |
| 指认界面 | 3 个嫌疑人 + 每人一句证词 | 把寻物转成轻推理选择 |
| 结算 | 文本真相 + 通用剪影 / 盖章动画 | 控制内容量产成本 |

一句话玩法：

> 玩家经营一家怪案侦探社，在每个案发现场通过普通点击、放大镜和紫外灯找出关键证物，把证物组成证据链，最后从 3 个嫌疑人中指认真凶；找错或超时则误判案件。

第一关样例可以用“书房疑案”：怀表、红酒杯口红印、窗台泥脚印三件证物，对应管家、未婚妻、收藏家三个嫌疑人。关键是每件证物都必须改变玩家对嫌疑人的判断，而不是只当收集品。

## 关卡 UI 与工具规则

60 秒适合概念视频，不适合真实版本。可玩 Demo 建议先用 3 分钟倒计时，后续再根据测试扩到 4-5 分钟。

调查阶段 UI：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 | 暂停、倒计时 / 进度条、`关键证物 0/3` | 让目标和压力一直可见 |
| 中部 | 大场景 | 不被证物槽挤压，保证找物空间 |
| 底部 | 放大镜、紫外灯、提示灯泡 | 只保留 3 个工具按钮 |

工具规则：

| 工具 | 设计 |
| --- | --- |
| 普通点击 | 无限使用，负责基础可见物品 |
| 放大镜 | 无限使用但有约 1 秒冷却，负责细节检查 |
| 紫外灯 | 有能量和恢复，可通过广告补满 |
| 提示灯泡 | 广告触发，给分层提示，不直接把全部答案亮出来 |

提示应分三层：

1. 场景里有弱视觉异常，例如地毯鼓起、窗帘微开。
2. 工具揭示更强信息，例如紫外灯显示口红印。
3. 广告提示圈出可疑区域或给文字方向，但不替玩家完成全部推理。

指认阶段在 3/3 证物后才出现。此时隐藏调查工具，中间展示 3 张嫌疑人卡和证词，底部展示证物板。红线连证物不是必须，可以用证物卡点亮、嫌疑人证词高亮来替代，减少美术和动画成本。

结算不要每关做专属动画。优先使用“文本真相 + 通用黑影 / Spine 动作 + 案件盖章”的模板，把产能留给场景、证物图标和嫌疑人信息。

## 内容驱动风险与平台分路

“3 个证物 + 3 个嫌疑人”的侦探寻物，本质是内容驱动体验。它的长期留存不靠重复操作本身，而靠新案件、新场景、新证物逻辑、叙事反转和美术包装。

这会带来两个完全不同的产品方向：

| 路线 | 适合形态 | 设计要求 | 风险 |
| --- | --- | --- | --- |
| Steam / TapTap 买断 | 12-20 个案件、3-5 小时体验、强美术与叙事包装 | 案件质量、愿望单、Demo、定价与长尾销售 | 内容成本高，不能只做 2 小时轻内容 |
| 微信 / 抖音 IAA | “侦探找茬王 / 找 10 个破绽”短局 | 每关 8-15 个异常点，高频提示、加时、跳过、答案广告 | 推理味会变轻，更像找茬 / 寻物爽点 |

最危险的是中间态：按 Steam 的内容成本做精致侦探案件，却只用小游戏 IAA 的广告收入回收。项目在立项前必须先决定商业模型，再反推关卡数量、证物密度、动画成本和广告点。

AI 视频验证也应分路测试：

| 视频定位 | 标题方向 | 测试问题 |
| --- | --- | --- |
| Steam 向 | 我做了一款侦探寻物推理游戏，你会买吗？ | 玩家是否愿意为题材、画风和案件体验付费 |
| IAA 向 | 找出现场 10 个破绽，你能破案吗？ | 玩家是否愿意在短时间内找更多异常点，并接受提示广告 |

如果视频 A 验证的是搜索过程，视频 B 就不要重复搜索。视频 B 更适合集中拍“误判 -> 反证 -> 改判 -> 真相揭示”，让玩家看到证物如何改变判断。

## 可复用检查清单

- 第一版只验证关卡内玩法，不先做侦探社经营系统。
- 每件证物都要能改变嫌疑人判断，否则只是装饰性收集。
- 调查阶段不在底部塞证物槽，避免压缩找物空间。
- 广告提示要解决当前卡点：找不到、时间不够、工具能量不足、指认失误。
- IAA 版本要提高异常点数量，买断版本要提高案件质量和叙事包装。
- 不在商业模型未定时同时承诺“精致推理内容”和“高频广告短局”。
