# 遭遇设计与敌人题型可读性方法论

## 来源: `10_流水/Openclaw知识库文件/game_design.md` · 提取日期 2026-05-26

## 遭遇设计不是填波次表，而是安排压力峰谷

难度曲线不应一路线性上扬。好的一局更像锯齿：抬压、释放、再抬更高压。峰值负责制造挑战，谷值负责让玩家理解刚才发生了什么，并把奖励转成下一次选择。

遭遇编排要同时完成三件事：

| 任务 | 设计含义 |
| --- | --- |
| 压力峰谷 | 高压后必须回落，但回落不能空，要给奖励、复盘或构筑兑现 |
| 学习窗口 | 新机制先少量出现，再和旧压力混合，最后进入真正高压 |
| 决策兑现 | 上一轮奖励或选择，要能在下一轮看见效果 |

对塔防肉鸽，前 8 波可以先用粗骨架：

| 波段 | 作用 |
| --- | --- |
| 1-2 波 | 稳，建立操作和第一次清屏证据 |
| 3-4 波 | 压，引入第一个克制结构，逼玩家补短板 |
| 5-6 波 | 喘，给中等强度兑现波和明显奖励波 |
| 7 波 | Boss 前校准，预览标签并给刷新/锁定/重构 |
| 8 波 | Boss，检验 Build 是否成型 |

遭遇变化优先改题型，再改血量。路径分流、盾怪 + 快怪、召唤扩线、爆发窗口、长线续航题，比单纯“更多更肉更快”更能证明系统有深度。

## 每波敌人都要有题型标签

内部波次表不要只写生命、速度、赏金，还要新增：

| 字段 | 用途 |
| --- | --- |
| 题型标签 | 清杂、单体、控场、路径覆盖、资源压缩、爆发窗口 |
| 主要威胁 | 漏怪、拖时、召唤扩线、后排骚扰、护盾消耗 |
| 推荐反制 | 减速、范围、破盾、斩首、穿透、高频段伤害 |
| 首次出现波次 | 控制学习窗口，避免首局过早混乱 |

同一波可以有多个单位，但首局前段最好只保一个主要学习目标。新题型首次登场时，旧题型强度要退后；Boss 前两波要提前预告 Boss 会考什么。

## 难度等于识别时间、决策时间和执行窗口的乘积

玩家是否觉得公平，不只看伤害和血量，而看三段链路：

| 链路 | 问题 |
| --- | --- |
| 识别时间 | 玩家多久看出这是什么敌人、什么危险 |
| 决策时间 | 玩家多久判断该补哪种短板 |
| 执行窗口 | 玩家还有没有机会调整塔、技能、刷新或走位 |

任何一段过短，玩家都会觉得被偷袭。高压可以有，但必须给预告；失败可以痛，但必须能复盘。

## 敌人可读性分四层

敌人不是做出一个美术造型就结束，而要让玩家在战斗混乱中看懂“谁危险、危险在哪、怎么解、为什么输”。

| 层级 | 设计要求 |
| --- | --- |
| 身份可读性 | 轮廓、主色、移动姿态、音效或图标至少两项稳定区分 |
| 危险来源可读性 | 高速怪强调冲线，盾怪强调拖时，召唤怪强调扩线 |
| 反制答案可读性 | 升级和 UI 能映射到解题答案，例如破盾、减速、斩首 |
| 失败复盘可读性 | 结算能说清死于清杂不足、单体不足、控场不足或经济断档 |

升级三选一也可以成为“解题提示器”。如果最近两波高速怪造成主要漏怪，系统可提高减速、前置覆盖和瞬时爆发选项权重；如果盾怪拖时明显，则提高破盾和穿透选项权重。这样随机仍然存在，但玩家会感觉系统给了可用答案。

## 测试时只问能否复盘题型

陌生用户试玩后，优先问三个问题：

1. 刚才最危险的怪是哪种。
2. 你觉得这把输的主因是什么。
3. 下一把你准备改什么。

如果玩家答不出来，问题通常不是数值太复杂，而是题型语言没有立住。玩家愿意重开，不是因为失败轻，而是因为他相信失败可理解、下把可修正。

## 节奏设计要安排紧张与释放，不是一路加压

关卡节奏的底层目标是让玩家持续待在心流通道里：压力太低会无聊，压力太高会焦虑。波次设计只是节奏控制的一种手段。

可复用节奏工具：

| 工具 | 用法 |
| --- | --- |
| 高低交替 | 高压战斗后给短暂奖励、选择、补给或复盘 |
| 慢启动 | 关卡初期低风险，让玩家熟悉操作和识别规则 |
| 空间收放 | 狭窄区域制造压迫，开阔区域降低心理负担 |
| 波次间隙 | 让玩家有时间整理 Build、读取奖励、准备下一波 |
| 动态备用波 | 根据血量、击杀速度或资源状态调整备用压力 |

对塔防肉鸽，波次递进不应只增加数量，而要改变玩家题型：

1. 基础近战怪建立清杂。
2. 远程 / 高速怪逼迫覆盖和走位。
3. 盾怪 / 坦克怪检查单体和破盾。
4. 精英怪制造短期高压点。
5. Boss 把前面学过的题型组合成最终考试。

每次高压后都要让玩家看见“我刚才选的技能产生了作用”，否则节奏会变成疲劳而不是成长。
