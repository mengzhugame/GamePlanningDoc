# 爽感设计系统

> 来源：《光与朽》上线后玩家反馈驱动的迭代经验。核心认知：爽感问题 90% 来自视觉/听觉反馈不足，而非数值强度不够。

---

## 核心认知：爽感 ≠ 数值强度

**错误归因**：玩家说"没有爽感" → 开发者调高伤害数值
**正确归因**：爽感来自感知层，不来自数值层

```
爽感三要素：
1. 视觉反馈清晰（能看出效果在生效）
2. 音效响应及时（击中/击杀有声音峰值）
3. 质变节点明确（达到某个阶段，体验发生质的跳跃）
```

**光与朽案例**：
- 极寒光束 Lv1–4：减速效果有数值，但视觉无法感知 → 玩家认为"没用"
- 广域透镜：激光变宽了，但"宽"的感知不明显 → 玩家认为"没有用感觉"
- 修复方向：加冰晶粒子、冷雾、怪物染色+发光粒子，不是加数值

---

## 稀有度质变：金色技能必须是质变，不是加强版

**反模式**：金色技能 = 数值更高的普通技能（仍是同一种体验）
**正确模式**：金色技能（Lv5 满级）= 全新的操作体验质变

### 质变设计框架

```
Lv1–4：技能逐渐增强（量变）
Lv5（满级/金色）：触发全新机制（质变）→ 玩家形成"我要升到满级"的目标感
```

**光与朽 Lv5 质变方向**（5 个核心技能）：
| 技能 | Lv1-4 | Lv5 质变目标 |
|------|-------|-------------|
| 连锁反应 | 击杀后连锁 | 连锁可以穿越障碍物 |
| 极寒光束 | 减速 | 冻结 + 冰裂范围爆发 |
| 广域透镜 | 激光变宽 | 宽激光产生推开力场 |
| 分裂激光 | 多束分裂 | 分裂后各自追踪 |
| 聚能透镜 | 高单体伤害 | 击杀触发爆炸链 |

---

## 连杀/FRENZY 系统：纯视听，不加伤害

**为什么不加伤害**：数值提升会破坏已经平衡的战斗数值体系，且难以回收

**正确做法**：连杀 = 纯粹的视听奖励层，不触碰数值层

```
连杀反馈分级（建议）：
× 3 击杀：音效升调 + 屏幕轻闪
× 5 击杀：COMBO 文字弹出 + 暗角收缩
× 10 击杀：FRENZY 状态 + 慢动作 0.3 秒 + 专属音效
```

**COMEBACK 状态**：血量极低时触发视听强化（不给伤害加成），制造"绝地反击"感。

---

## 关卡节奏：3 段式重构

**问题**：10 分钟单一操作 → 手指疲劳、注意力流失
**根因**：不是"操作难度高"，而是"没有节奏感"

**解法：3 段式结构**（利用已有系统，无需新增功能）

```
段 1（0–3 分钟）：正常战斗 → 波次结束
段间（20–30 秒）：复用无人机三选一系统（决策 + 喘息）
段 2（3–6 分钟）：正常战斗 → 波次结束
段间（20–30 秒）：无人机三选一
段 3（6–9 分钟）：高强度收尾 → Boss 或终局
```

**关键**：段间停顿复用现有 DroneChoiceTipsPresenter / DroneRewardConfig，不是新系统，只是节奏重排，开发成本极低。

---

## 大招蓄力：双因子填充

**双因子设计**（避免纯时间等待的无聊感）：
- 时间因子：50% 填充速度
- 击杀因子：50% 填充速度

**释放设计**：
- 自动锁定一个方向（减轻操作负担）
- 不是全自动索敌（保留差异化的激光旋转手感）
- 对敌人分层伤害（保留挑战性，避免"一招清屏"破坏数值生态）

---

## 技术选型：视觉反馈的避坑

| 需求 | ❌ 避坑 | ✅ 正确路线 |
|------|--------|-----------|
| 减速/冻结视觉 | 流体 RT（不支持速度残影+Shader 覆盖） | 纯粒子路线（冰晶粒子、冷雾） |
| 怪物受击感 | Shader 全体替换 | 怪物染色+发光粒子补强 |
| 连杀反馈 | 加伤害倍率 | 纯音效+屏幕后处理（慢动作、暗角） |

---

## 爽感迭代优先级原则

**比起加功能，先修感知**：

1. 检查现有技能的 Lv5 是否有质变（先补，再加新技能）
2. 检查所有受击/击杀/升级事件是否有专属音效峰值
3. 检查视觉反馈是否"肉眼可见"（5 秒内能察觉到差别）
4. 最后才考虑加新机制或调数值

**一句话原则**：让玩家的眼睛和耳朵先爽，数字只是辅助证明。

## 爽感优先级：先修“看得懂”和“摸得顺”

上线反馈里，爽感不足并不只来自技能特效弱，还来自三个更底层的问题：

| 层级 | 问题 | 为什么影响爽感 |
| --- | --- | --- |
| 操控手感 | 旋转激光不够顺手 | 核心操作不顺，任何特效都会被抵消 |
| 视觉辨识 | 怪物与背景糊成一团 | 玩家看不清目标，就无法感受击杀反馈 |
| 差异化场景 | 侧翼来敌不够早、不够明显 | 玩家感受不到“360 度旋转”存在的必要 |

因此爽感迭代顺序应是：

1. 操作映射、灵敏度、磁吸辅助等“摸起来顺”的问题。
2. 怪物轮廓、发光、眼睛状态、击中反馈等“看得清”的问题。
3. 技能质变、连杀、慢动作、暗角等“爽点放大”的问题。
4. 最后才是加新技能、加大招或调伤害。

如果核心差异化手感没被玩家感知，后面的 Lv5 质变和肉鸽深度都会变成“我知道你做了很多，但我没感到不同”。

## Boss 技能反馈必须补齐完整因果链

VolcanoBoss 的“吸收小怪回血”如果只在数值层生效，玩家会读不懂：小怪冲向 Boss、Boss 血条变多，但没有缩小、消失、音效、特效和回血缓冲，体验上就像 bug。

Boss 技能反馈要按完整因果链检查：

| 环节 | 玩家需要看到 / 听到什么 |
| --- | --- |
| 目标明确 | 小怪朝 Boss 的明确吸收点移动，而不是推着 Boss 根节点乱撞 |
| 被吸收过程 | 小怪缩小、禁用碰撞、向吸收点消失 |
| 命中反馈 | 蒸汽 / 火焰 / 吞噬 VFX 与死亡或吸收 SFX |
| 数值反馈 | Boss 血条出现回血变化，缓冲条跟上 |
| 战术反馈 | 玩家能理解“必须阻止小怪靠近 Boss” |

这类机制的爽感不是“特效越多越好”，而是每个因果节点都要可读。少一个节点，玩家就会把机制误判为穿模、卡住、无反馈或 Boss 莫名回血。

## 不要把所有表现问题都升级成新系统

同一份修复里，Boss 眼睛曾被讨论是否要旋转或拆成独立结构。最终更稳的判断是：如果眼睛没有独立受击、独立转向、独立技能等玩法行为，就先保留单张 Sprite，不为“未来可能需要”提前拆结构。

表现层迭代顺序：

1. 先补玩家能直接感知的缺失反馈。
2. 再修会破坏视觉辨识的材质 / 染色问题。
3. 最后才考虑拆对象结构、加独立动画或新系统。

这能避免把一个本来 0.5 天能解决的反馈问题，扩张成多部件 Boss 架构重做。

## 高频命中反馈要限频，不能每帧重置

持续激光类武器如果每帧命中都重置白闪协程，会让 Boss 长时间保持最亮白色，玩家看到的不是“受击反馈”，而是“画面糊成一片”。高频命中反馈必须有最小间隔或强度衰减。

可复用原则：

| 反馈类型 | 适合做法 |
| --- | --- |
| 单次重击 | 可用强白闪、屏幕震动、重音效 |
| 高频持续命中 | 白闪限频、低强度、用飘字/命中特效补足反馈 |
| 核心弱点命中 | 红色/大字/强闪，强调有效伤害 |
| 护甲命中 | 灰色/小字/弱反馈，强调“打到了但收益低” |

受击反馈要表达伤害层级：打护甲和打核心不能用同一种白闪；打到阻挡物导致 Boss 没伤害时，也要让阻挡物本身有足够反馈，否则玩家会误以为 Boss 飘字漏了。

## 特效作用范围要和玩家语义一致

VolcanoBoss 的问题不是“白闪本身不该有”，而是白闪作用到了玩家不期待的 body02 岩石护甲层。玩家语义里，熔浆液 body03 可以闪，核心 / 眼睛被打时 body02 和眼睛可以强反馈；但护甲被普通扫到时全身闪白，会让命中层级变模糊。

因此复杂角色的表现层要先按玩家语义分组，再决定特效作用范围：

1. 可持续命中的外壳层。
2. 关键弱点 / 核心层。
3. 装饰或特殊材质层。
4. 状态强化层，例如 `redBodyEffect`。

爽感不是所有 Renderer 一起亮，而是玩家一眼能读懂“我刚刚打中了哪里，造成了什么级别的效果”。

## 伤害飘字颜色要按伤害语义少量分层

飘字颜色不是越多越好。颜色太多会花，颜色太少又让玩家感受不到伤害来源差异。《光与朽》的可复用方案是控制在少数高辨识语义：

| 伤害语义 | 推荐表现 |
| --- | --- |
| 普通伤害 | 白色 |
| 暴击伤害 | 红色 + 暴击图标 |
| 冰裂 / 碎冰 | 蓝色系 |
| 连锁反应 | 黄色 / 电弧感 |
| 爆炸 / 自爆 AoE | 橙色 |
| Boss 护甲 | 灰色小字 |
| Boss 核心 | 更大、更亮的核心伤害字 |

处理优先级要明确，避免一个伤害同时满足多个标签时随机变色。可按“特殊机制 > 来源类型 > 普通/暴击”排序，例如先判定碎冰，再判定连锁，再判定爆炸，最后落到普通或暴击。

关键原则：飘字是在帮玩家理解“刚才是哪种机制生效”，不是给每个元素都配一个颜色表。

## 剩余威胁要可视化，不能让玩家心算

Frostcaster 的“3 次 / 7 次施法”如果只存在于数值字段里，玩家感知不到威胁什么时候结束。把身体上的水晶数量和剩余施法次数绑定后，机制立刻变得可读：每施法一次少一颗水晶，玩家能判断“还要撑几轮”。

可复用规则：

| 机制信息 | 更爽的表达 |
| --- | --- |
| 剩余施法次数 | 身体水晶、背包弹药、亮灯格数 |
| 充能进度 | 发光强度、环形蓄力、音效升调 |
| 即将孵化 / 爆炸 | 裂纹、跳动、倒计时粒子 |
| 精英更强 | 更多可见 charge，而不只是血量更厚 |

爽感不只来自击杀瞬间，也来自玩家提前看懂威胁、做出判断、然后验证判断正确。

## 周期孵化比一次性爆发更适合制造割草压力

冰墙从“一次性生成一批怪”改成“每 2.5 秒孵化一只，持续 15 秒”，体验从突然堵屏变成可预期的持续压力。玩家会形成节奏：看到墙出现、预判下一只 Slime、用激光扫掉一波，再等下一波。

设计上要区分两种爽感：

| 生成方式 | 体验 |
| --- | --- |
| 一次性爆发 | 适合惊吓、瞬间危机、Boss 大招 |
| 周期孵化 | 适合割草、持续收割、制造局部战线 |

如果目标是“多怪可扫、压力可读”，周期孵化通常比一次性堆怪更稳。
