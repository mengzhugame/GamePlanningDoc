# 00_工作流

## 这个分区放什么

这里放“小龙儿自己的小游戏生产系统”，不是单点知识。

它负责把 `01_游戏设计`、`03_美术与表现`、`05_数值与经济`、`06_发行与运营` 等分区串成可执行顺序：

- 立项前怎么判断
- 7 天原型验证什么
- Demo 阶段哪些是 P0
- 上线 72 小时看什么数据
- 什么时候继续迭代，什么时候止损
- 项目结束后怎么资产化和蒸馏

## 使用规则

1. 新项目立项前，先读本分区，再读具体领域知识。
2. 每个项目结束后，先写项目复盘，再更新工作流。
3. 工作流只保留被项目验证过的规则；未经验证的想法留在 `00_草稿/` 或 `30_市场分析/`。
4. `status=review` 表示已可用于下一项目决策，但仍需要后续项目继续验证。
