# 02_引擎与技术

## 这个分区放什么

**代码、引擎、工程化**层面的知识。和 `40_知识/代码模板库/` 互补——模板库是"可直接复制的生产级代码"，这里是**"什么场景下选哪个、为什么这么做、踩过什么坑"**。

## 当前状态

这个分区目前是正式知识层里最明显的缺口：代码模板库已经有可复制资产，但“什么时候用、为什么这么做、踩过什么坑”的工程方法论还没有沉淀成 knowledge 条目。

## 二次蒸馏候选（优先级）

1. **微信小游戏包体优化与加载策略** — 来源：`微信小游打包流程.docx`、两款项目的打包记录
2. **Unity 通用技术栈复用指南** — 来源：`40_知识/代码模板库/00_INDEX.md` 与 8 个模板
3. **小游戏上线 smoke test 清单** — 来源：光与朽上线日志、打包流程、真机调试记录
4. **数据埋点与 BattleLog 工程落地** — 来源：光与朽数据埋点文档和代码对话记录
