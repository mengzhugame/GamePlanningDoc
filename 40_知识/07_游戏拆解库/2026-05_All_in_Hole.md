# 拆解：《All in Hole》

## 来源: `10_流水/游戏拆解/all_in_hole.md` · 提取日期 2026-05-24

## 1. 一句话核心机制

玩家拖动黑洞先吞小物件变大，再按目标顺序吞掉更大的关键物件完成关卡；爽点来自“吃不下 → 变大 → 一扫而空”的体积反差和清盘满足感。

## 2. 核心循环

开局观察目标 → 吞小件成长 → 跨过体积断点 → 按顺序清目标 → 结算奖励 → 冲连胜 / 赛事 / 通行证 / 新关卡包 → 再开一局。

## 3. 玩法详解

- **黑洞移动**：核心操作极轻，拖动即可理解，适合短视频首屏展示。
- **体积断点**：小物件是成长燃料，大物件是目标与奖励；断点制造“我现在不行，但马上可以”的期待。
- **顺序规则**：不是无脑乱吞，而是要求玩家优先处理轻物、避开阻挡、按目标完成。
- **外层 Meta**：赛事、排行榜、队伍、装饰、配方、Boost、通行证和定期关卡包为回访提供理由。
- **连胜爆发**：连胜 10 关解锁 Super Black Hole 这类状态，比单纯给金币更有传播画面。

## 4. 数值/经济

核心经济不是复杂养成，而是关卡进度、连胜状态、Boost、赛季奖励和装饰收集。它的长线化方式是“强单局动作 + 轻外层目标”，不是重数值堆叠。

## 5. 美术与感官

重点不在题材深度，而在物理反馈：吸附要干净，吞入要有明确瞬间，盘面清空要有前后对比。题材可换成零食、蛋糕、房间、桌面等轻包装。

## 6. 变现路径

适合广告、Boost、通行证、赛事奖励和轻收集混合。外层不能太重，否则会把“放松一下”变成“被任务催促”。

## 7. 爽点与留存机制（**重点**）

| 爽点 | 机制来源 |
| --- | --- |
| 吞噬满足感 | 物件被吸入黑洞的瞬间反馈 |
| 成长反差 | 先吃小、再吃大，体积阈值清楚 |
| 清盘治愈 | 盘面从乱到空 |
| 轻策略 | 指定目标、吞噬顺序、路线规划 |
| 连胜爆发 | Super Black Hole 这类高情绪状态 |
| 回访理由 | 赛事、队伍、通行证、新关卡包 |

## 8. 风险点

“黑洞吞东西”强但不稀缺，缺少新障碍、新目标规则和稳定手感会很快同质化。轻策略深度有限，外层 Meta 又不能太重，产品必须在“轻松”和“有回访理由”之间保持平衡。

## 9. 跟用户已有项目的相邻度

对美妆叠叠乐的启发不是换皮成“美妆黑洞”，而是借鉴“先处理小目标 → 跨过能力断点 → 完成大目标”的关卡节奏。对 AI 视频反向立项更直接：吞、吸、清空、收纳、变大后反吃都是天然 3 秒钩子。

## 10. 可借鉴的 3 个点

1. 体积断点：让玩家明确感到自己从“不够强”变成“终于能处理”。
2. 爽动作加轻规则：解压动作必须叠目标、顺序或路线，避免第 3 局后变空。
3. 连胜奖励给玩法状态：高表现奖励最好改变体验本身，而不只是发资源。

## 11. 不该照抄的 1 个点（**防铁律 1 fail**）

不要照抄“黑洞吞噬”这个表皮。这个动词已经高度可见，新的项目必须在题材、断点规则、目标结构或反馈手感上回答 3 个核心差异点。
