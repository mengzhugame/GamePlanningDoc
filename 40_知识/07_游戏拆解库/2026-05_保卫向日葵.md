# 拆解：《保卫向日葵》

## 1. 一句话核心机制

塔防地图上，玩家用阳光在限定空间里刷植物，**同种同级合成升级**形成更强植物挡僵尸，每关 10 波怪在 25 秒间隔内打完。**爽点是"摆位 + 合成 + 刷新"三选一时找到最优解的策略爽 + "高级植物清屏"的视觉爽。**

## 2. 核心循环

进入关卡 → 阳光累积 → 刷植物到地块 → 同种同级合成升级 → 抗僵尸波次 → 关卡结算 → 主角/植物养成升级 → 解锁新关卡 / 副本 / 联合作战。

## 3. 玩法详解

- **空间管理 + 合成**：塔防地图限定植物可放置的格子，刷新到的植物随机，需要规划"刷在哪里能合成"。
- **同种同级合成**：两个同种同级植物碰一起 → 升一级，等级越高数值/特效越夸张（堆叠 like 核心）。
- **5 大元素属性**：物理 / 电 / 冰 / 火 / 毒，对不同僵尸有克制关系，逼迫玩家不能只堆一种。
- **每关 10 波怪 + 25 秒间隔**：节奏快但有间歇，给"决策→行动→观察"的标准 loop。
- **Roguelike 三选一刷新**：每次刷新塔随机给三选一，构筑感来自"哪一关抽到了什么"。
- **职业 × 占格**：不同等级植物占用 1×1 / 1×2 / 2×2 等不同格数，逼迫"占格 vs 强度"权衡。
- **主角养成 + 植物养成**：双轨外部成长线，主角等级解锁能力，植物图鉴解锁高阶单位。
- **副玩法**：日常副本、联合作战、深渊领主、精英挑战 4 类。

## 4. 数值/经济

- 局内资源：阳光（造植物）、时间（每波间 25 秒）。
- 局外资源：金币、钻石、植物碎片、主角经验。
- 高方差：合成到 5 星 / 6 星植物的输出比 1 星高数十倍 → 制造"运气合到大爹"的高光。
- 付费点：植物图鉴解锁、主角技能树、联合作战 buff、跳关 token。

## 5. 美术与感官

- 明亮卡通植物（明显视觉蹭《植物大战僵尸》记忆 → 降低教育成本）。
- 关键音效：植物合成时"叮咚"清脆音、阳光收集"叮——"金属感、僵尸群被高级植物清屏的爆裂感。
- UI 节奏：每波 25 秒间隔 → 玩家有时间深思熟虑摆位，节奏比纯"自动塔防"慢一拍但更耐玩。

## 6. 变现路径

- 主：混合变现。IAA（刷新三选一、复活、双倍阳光）+ IAP（植物礼包、主角通行证、联合作战门票）。
- 月流水预估：小游戏端首月 3000 万+ / APP 双端 4300 万+ / 合计 7000 万+。
- 微信小游戏畅销榜 12 月 25 日峰值 Top7，连续一周稳定 Top10。

## 7. 爽点与留存机制（**重点段**）

**留存类型：混合型（合成有运气成分 + 摆位有操作成分 + 养成有数值成分），是"运气×操作×养成"三合一的典型。**
**单局节奏：中局（每关约 5-10 分钟，10 波 × 25 秒 + 摆位时间）。**

为什么持续玩：

1. **合成时刻的"老虎机式"高光**：连续刷出同种植物 → 一路合成到顶级 → 屏幕清屏的瞬间，是"运气+决策+爆发反馈"的复合爽点。
2. **每波 25 秒的"思考-行动-观察"节奏**：比纯自动塔防慢、比解谜快——是塔防品类的"刚刚好"节奏，让玩家既不无聊也不窒息。
3. **5 元素 + 占格 + 职业的策略空间**：表面合成 like，实际有大量塔防策略沉淀，资深玩家有"build 优化"乐趣。
4. **怀旧 IP 钩子**：明显蹭《植物大战僵尸》视觉，给所有 25-40 岁玩家"我又能玩 PVZ 了"的情绪召回 → 这是它能 30 天破 7000 万的最大冷启动器。
5. **副玩法池 + 双养成线长线**：4 大副玩法 + 主角/植物双养成，把"中局塔防"延伸到"长线手游"的留存深度。

**跟 P0 对比**：
- 跟《噩梦守护战》（运气型 / 短局 3 分钟 / 弹球塔防）：两者都是塔防衍生，但保卫向日葵把单局拉长到 5-10 分钟，加入更多策略层（占格、元素克制）—— **"中局 + 混合型"**对比 P0 的"短局 + 运气型"，留存留存机制更厚。
- 跟《装备全靠转》（运气型 / 短局 / 高方差摇骰子）：保卫向日葵的随机性集中在"刷新到什么植物"，但摆位/合成顺序由玩家完全控制——**运气与操作各占 50%**，比装备全靠转更平衡。

**跟另外 2 款 P1 对比**：
- 跟《向僵尸开炮》（混合偏运气 / 中局 / 内容型长线）：两者都是塔防衍生 + 混合留存，但保卫向日葵保留了"放置/摆位"的空间策略层；向僵尸开炮把空间感弱化到只剩"防线 + 自动开火"。
- 跟《打个螺丝》（操作型 / 短局 / 解谜）：两者代表抖音/微信留存的两个极端——保卫向日葵是"运气×操作×养成"复合，打个螺丝是"纯操作"单一路径。

## 8. 风险点

- "缝合怪"标签明显：塔防+合成+背包 like+LD-like，做对了是爆款、做差了是大杂烩，复刻门槛极高（每个子机制都需要工业化打磨）。
- 蹭 PVZ 视觉记忆 → 美术差异化弱，长线靠内容更新维持。
- 大梦龙途系（一起梦游科技）的运营资源是其护城河，独立团队复刻"4 大副玩法 + 双养成线"会被运营成本压垮。
- 合成机制疲劳点：玩家见过所有植物等级后，新鲜感衰减明显。

## 9. 跟用户已有项目的相邻度

**跟「光与朽」相邻度：中。**
- 都是"防线 + 怪物波次"结构，但保卫向日葵是**自动攻击 + 摆位**塔防，光与朽是**手动激光射击**——核心操作完全不同（与向僵尸开炮的差异判断一致）。
- **可借鉴**：① 5 元素克制系统（光与朽可加激光属性 vs 怪物属性的克制层，增加构筑深度）② 每波间 25 秒间隔的"决策-行动-观察"节奏（光与朽如果加入波次塔防模式，可借鉴这种节奏）③ 三选一刷新的塔/能力（光与朽已有，可深化）。
- **不该学**：合成机制（与光与朽射击节奏冲突）、PVZ 视觉蹭法（光与朽是赛博风格）。

**跟「美妆叠叠乐」相邻度：中（合成机制可类比叠加机制）。**
- **可借鉴**：① 同种同级合成的"老虎机式"爽点设计（叠叠乐可考虑"同色妆容合并升级"）② 占格策略（叠叠乐可考虑"梳妆台空间限制 + 物品占格"维度）。
- **不该学**：5 元素塔防系统（与美妆主题割裂）、PVZ 视觉路径（美妆要走治愈风）。

**概念池**：直接命中"合成塔防"候选方向。但用户必须警惕——这个赛道护城河在"运营 + 内容产能"，不在玩法本身。

## 10. 可借鉴的 3 个点

1. **合成机制 + 元素克制 = 双层策略空间**：把单层"合成 like"加上元素克制，让"合什么"和"合到哪"都成为决策。这套方法论可以套到任何合成类小游戏上，立刻拉高玩法深度。
2. **每波 25 秒间隔的节奏设计**：自动塔防有"无聊感"问题，纯手操塔防有"窒息感"问题——25 秒间歇是经过验证的塔防舒适区。可移植到任何"波次抗压"类玩法。
3. **占格 × 强度的反向权衡**：不是单纯"等级越高越强"，而是"等级越高占地越多" → 逼迫玩家在"质"和"量"之间做策略——这种反直觉权衡是合成类留存的精华。

## 11. 不该照抄的 1 个点（**防铁律 1 fail**）

**不要照抄"明显蹭 PVZ 视觉 + 4 大副玩法堆叠"的工业化路径。**

PVZ 视觉蹭法依赖 EA 没有维权 + 大梦龙途的发行能力——独立小团队既没法律风险评估能力也没视觉打磨产能。4 大副玩法（日常/联合/深渊/精英）需要 5-8 人长期运营团队持续供给内容，独立团队上线 1 个月就会内容断供。铁律 1 要求"3 个核心不同点"——你照搬这套缝合怪框架，既比不过它的发行/运营资源，也吃不到它的怀旧 IP 红利。**真要做合成塔防，应当抓"合成 + 元素克制 + 占格"这 3 个核心策略层做差异化**，丢掉副玩法池和怀旧蹭 IP，单局做精反而能存活。
