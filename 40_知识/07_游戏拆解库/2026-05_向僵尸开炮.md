# 拆解：《向僵尸开炮》

## 1. 一句话核心机制

玩家放置防线、对涌来的僵尸潮自动开火，每次升级三选一构筑技能，靠枪械 + 幻形搭档 + 防线强化的局外养成在长线里持续变强。**爽点是"屏幕上几百只僵尸被技能连锁炸碎"的割草感 + "构筑出爆发流派那一局"的高光感。**

## 2. 核心循环

进入关卡 → 防线自动开火清怪 → 击杀升级 → 三选一新技能 → 技能连携 build → 通关结算 → 局外升级武器/幻形/防线 → 解锁更高难度关卡 / 远征堡垒副玩法。

## 3. 玩法详解

- **防线自动开火**：玩家不需要瞄准，主要决策是构筑（选什么技能）+ 阵容（带哪把枪、哪只幻形）。
- **三选一技能构筑**：每次升级弹出三选一卡牌，技能之间存在连携效果（属性/元素/范围联动），构筑深度是核心爽点。
- **枪械独立养成树**：枪械有专属技能树，可堆暴击率/暴击伤害/专属伤害，上限拉得很高。
- **幻形搭档**：类时装/精灵的随行系统（麟龙祈福、火龙战魂、折纸光阴等核心幻形），强化特定技能流派。
- **远征堡垒**：周期性轮换的副玩法集合，不消耗体力，提供长线"今天玩点新东西"的内容池。
- **MMORPG 社交层**：组队、团本、军团、帮派——把 MMO 的中重度社交搬进小游戏延长留存。

## 4. 数值/经济

- 资源：金币、钻石、装备碎片、技能卡碎片、幻形碎片。
- 养成线：枪械、防线、幻形、技能卡池——4 条平行养成线，每条都有内购加速点。
- 高消费玩家：通过幻形组合 + 枪械强化形成数倍输出差距。
- 0 氪/微氪通道：通过远征堡垒/活动慢速积累，保留泛用户。

## 5. 美术与感官

- 末世卡通 + 科幻僵尸，色彩明亮，不走暗黑写实路线（与同期国战/恐怖题材形成差异）。
- 关键音效：枪械连射、僵尸群被技能炸碎的爆裂感、升级三选一的清脆音。
- UI 节奏：屏幕同时数百只僵尸 + 数十个特效，"视觉过载"是爽感来源。

## 6. 变现路径

- 混合变现：IAA（激励视频复活/双倍/刷新）+ IAP（月卡、礼包、限定幻形、皮肤）。
- 分层付费：0 氪靠远征堡垒，微氪靠月卡，中重氪靠幻形/枪械礼包。
- iOS 端月流水 8200 万 - 1.4 亿，2024 年 12 月峰值 1.38 亿；微信小游戏畅销榜长期 Top2；MAU 4423 万。

## 7. 爽点与留存机制（**重点段**）

**留存类型：混合型偏运气（构筑随机 + 装备数值养成），但带有"构筑决策"成分。**
**单局节奏：中局（5-10 分钟单关 + 远征堡垒副玩法可拉长到 15+）。**

为什么持续玩：

1. **三选一构筑随机性**：每局技能不一样，连携可能性数百种 → 局内有"这局抽到强 build"的高光博弈感（运气 + 微决策）。
2. **局外多线性养成**：4 条平行养成线（枪械/防线/幻形/技能卡池），任意一条成长都让下一局变强 → 死了不想退游、想"再升一级试试"。
3. **MMO 社交延长线**：团本/帮派/军团把"小游戏"的短局转成"长线社交承诺"，这是它跟纯肉鸽塔防（如噩梦守护战）最大的留存差异。
4. **远征堡垒副玩法池**：周期轮换，避免主玩法腻味，等于"每周新内容"补给。

**跟 P0 对比**：
- 跟《噩梦守护战》（运气型 / 短局 3 分钟 / 弹球塔防）相比：本作走"内容型长线"——养成线更深、社交层加固、单局更长。**留存配方更接近"中重度手游"而非"抖音即开即玩"**。
- 跟《装备全靠转》（运气型 / 短局 / 高方差随机）相比：本作随机性集中在三选一构筑，不像装备全靠转那样把"摇骰子"做主玩法；爽点更靠"操作 + 构筑"组合，不是纯赌博式开箱。

**跟另外 2 款 P1 对比**：
- 跟《打个螺丝》（操作型 / 短局）：本作是"养成 + 构筑"主导，打个螺丝是"操作 + 关卡"主导。两者代表抖音/微信小游戏留存的两极。
- 跟《保卫向日葵》（混合型 / 中局 / 合成塔防）：同为塔防衍生，但本作弱化"摆放"、强化"构筑+养成"；保卫向日葵保留了空间策略，更接近经典塔防。

## 8. 风险点

- 内容型长线意味着持续内容产能要求高（每周/每月新关卡、新幻形）——独立小团队复制难度极大。
- 4 条养成线复杂度对新手不友好，留存漏斗在第 2-7 天。
- MMO 社交层依赖在线人数密度，DAU 一旦下降，社交价值崩塌。
- 抖音流量红利期可能见顶，新一代肉鸽塔防卷点已经从"玩法"转向"内容/IP/题材"。

## 9. 跟用户已有项目的相邻度

**跟「光与朽」相邻度：高（所有 P1/P0 中最高）。**
两者都是**怪物波次 + 射击 + 升级技能**的底层结构。但有 3 个关键不同点必须看清：
- **光与朽是手动激光射击**（玩家全程操作走位+点射+反射），向僵尸开炮是**自动开火**（玩家只构筑不操作）→ 操作密度差一个量级。
- **光与朽无放置/无塔防**（没有防线摆放），向僵尸开炮以"防线"为核心承载——结构上更像塔防，光与朽更像 Vampire Survivors 的反向（手动而非自动）。
- **光与朽是单人短局射击 + 高波动随机爽感**（已借鉴《装备全靠转》），向僵尸开炮是**长线养成 + 内容运营**——两条留存路线根本不同。

**可借鉴**：① 三选一技能构筑的连携设计（光与朽可加局内"激光属性三选一"）② 多养成线的"今天升一点点"留存钩 ③ 远征堡垒的副玩法池思路（活动期上线一些反常规小关卡）。
**不该学**：MMO 社交层（独立团队做不来）、4 条养成线的复杂度（光与朽要保持"打感"为主）、自动开火（与光与朽核心操作冲突）。

「美妆叠叠乐」相邻度低，仅"三选一+构筑"决策模式可类比；不该学末世射击题材（受众反向）。

## 10. 可借鉴的 3 个点

1. **三选一构筑的连携设计**：技能之间有元素/属性联动，让"选什么"成为玩法核心，构筑深度成为重玩动机。可移植到光与朽的"激光属性卡 + 关卡随机词条"。
2. **多线性局外养成的"小步前进"留存**：4 条平行养成线，任意一条都能让"今天再玩一局"有微小但确定的进步反馈——这是肉鸽塔防长线留存最稳定的机制。
3. **副玩法池（远征堡垒）做轮换内容**：用周期性副玩法填补主玩法疲劳，独立小团队也可以用"月度活动关卡"轻量复刻。

## 11. 不该照抄的 1 个点（**防铁律 1 fail**）

**不要照抄"MMO 社交层（团本/帮派/军团）"。**

这是大梦龙途用 MMORPG 老兵团队 + 多年长线运营经验做出的护城河，需要持续的活动策划、UGC 工具、客服、反作弊体系——独立团队上线第 1 个月就会被社交系统的运营复杂度压垮。铁律 1 要求"3 个核心不同点"——你照搬一套半成品 MMO 系统，既比不过它的成熟度，也吃不到它的 DAU 规模红利。**真要做长线，应当从内容/题材/差异化机制切入**（参考《打个螺丝》的"操作精度 + UGC 关卡"路径），而不是搬一套你养不起的社交系统。

## 13. 追加拆解：爆款成立靠“短局爽感 + 长线承接”双层结构

补充来源把本作拆成 MDA：爽快感、策略感、惊喜感、成长感。局内是击杀僵尸、随机技能、Build 成型和通关结算；局外是材料、装备、技能卡、体力和赛季系统。它的关键不是单点机制很新，而是每局都有明确反馈，每天都有确定成长，每个赛季又给长期玩家新目标。

值得注意的是，它不是单纯靠题材吃红利。补充来源提到团队测试过多种美术风格，最终用末世僵尸 + 明亮科幻卡通避开暗黑写实红海。对小游戏来说，题材和风格需要被数据验证，不应只凭主观喜好拍板。

## 14. 商业化补充

- IAP 是主收入，广告是辅助；广告点服务复活、奖励翻倍、刷新和资源补给，不应强行打断主体验。
- 赛季、体力和活动把“短局再来一局”接成“长期每天回来”。
- 付费原则不是推翻成长，而是加速成长、补齐资源和提供更舒服的目标推进。
- MMORPG 团队经验、社交和长线运营能力是本作护城河，独立小团队只能学习分层结构，不能照搬运营复杂度。

## 15. 对《光与朽》的增量启发

《光与朽》可学习“局内随机技能 + 局外轻 RPG + 赛季/活动”的层级，但早期必须降维：先证明 5-10 分钟局内爽感和三选一构筑，再决定是否加更深局外养成。美术上也应做多版本小样本测试，避免一开始把项目锁死在自嗨风格里。
