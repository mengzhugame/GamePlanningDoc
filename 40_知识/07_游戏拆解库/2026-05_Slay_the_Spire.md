# 拆解：《Slay the Spire》

## 来源: `10_流水/游戏拆解/game_analysis_slay_the_spire.md` · 提取日期 2026-05-25

## 1. 一句话核心机制

用明牌敌人意图、有限能量、卡牌奖励、删牌和遗物规则改写，让每次选路和出牌都变成风险收益计算。

## 2. 核心循环

地图选路 → 战斗 / 事件 / 商店 / 篝火 / 精英 → 获得卡牌、遗物、药水或删牌机会 → 精简和强化卡组 → 挑战 Boss → 进入下一层。

## 3. 玩法详解

敌人意图系统公开下回合动作，让策略从“猜敌人”变成“当前手牌如何最优应对”。删牌机制让构筑不只是加卡，而是主动提高核心 Combo 的出现频率。

## 4. 数值/经济

能量是每回合预算；遗物是改变规则的被动系统；精英、篝火、事件和商店共同构成地图层面的风险收益。卡组越精简，核心牌和遗物协同越稳定。

## 5. 美术与感官

攻击、技能、能力、状态 / 诅咒用清晰视觉分类降低认知负担。卡牌游戏的关键不是美术复杂，而是信息可读。

## 6. 变现路径

买断制适合高重玩、强口碑、低运营依赖的卡牌 Roguelike。它的长尾来自构筑深度和挑战心流。

## 7. 爽点与留存机制（重点）

- 敌人意图公开，使胜负归因更清晰。
- 删牌让“减法构筑”成为核心爽点。
- 遗物能改变规则，产生每局差异。
- 地图选路把战斗外也变成策略。

## 8. 风险点

如果遗物只给小数值，重玩会乏味；如果敌人意图不清，玩家会把失败归因为随机或黑箱。

## 9. 跟用户已有项目的相邻度

对《光与朽》可借鉴：高压波次提前明牌、局内升级允许“遗忘 / 排除低级项”、遗物式全局 Buff 改写规则，例如全塔攻速翻倍但射程减半。

## 10. 可借鉴的 3 个点

1. 明牌意图让策略更深，同时减少冤死感。
2. 构筑要有减法，不只是奖励越来越多。
3. 遗物应改变规则，而不是只加数值。

## 11. 不该照抄的 1 个点

不要把卡牌 UI 直接套到非卡牌游戏。真正可学的是意图公开、减法构筑和规则改写。
