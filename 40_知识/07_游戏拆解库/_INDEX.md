- 跟用户「光与朽」相邻度最高的是《向僵尸开炮》——但要警惕"自动开火/MMO 社交"两条不可照抄路径。
- 《保卫向日葵》"合成 + 元素克制 + 占格"3 层策略空间是合成 TD 的方法论核心。
- **真正可探索的方向**：用户**没踩过坑的格** = 运气×短局（噩梦/装备路径，但要差异化避恐怖题材）/ 操作×长局（待 P2 Merge 拆解填）/ 混合×中局轻量化版本。

**P2 关键发现**（2026-05-04 拆完前 3 款）：

1. **「操作×长局」格被填满**：Merge Gardens（合成进化路径）/ Lily's Garden（叙事悬念路径）/ 我的小家（自由搭配中国化路径）三款都填这一格，但路径完全不同 —— 用户的留存矩阵盲区被验证可探索。

2. **🚨 关键概念区分（必须澄清）**：
   - **Match（消除）**：东西越消越少最后清空（堆叠消除/滑动 Match-3/Blast 三消都属此类）—— 用户美妆叠叠乐踩的是堆叠消除子类的坑
   - **Merge（合成）**：东西越合越多越高阶，主板永不变空 —— **跟 Match 是完全不同的机制哲学**
   - 用户美妆叠叠乐 = Match（堆叠消除子类）已踩坑 → Merge（合成）是真正未探索方向

3. **2x2 矩阵完整状态（P0+P1+P2 = 8 款）**：
   - 运气×短局 ✅✅（噩梦守护战 / 装备全靠转）
   - 运气×中局 ❌（待探索，避恐怖题材）
   - 运气×长局 ❌（待探索）
   - 操作×短局 ✅⚠️（打个螺丝 / 美妆叠叠乐已踩坑同源）—— **用户失败地，避开**
   - 操作×中局 ❌（待探索，可能是用户最适方向之一）
   - 操作×长局 ✅✅✅（Merge Gardens / Lily's Garden / 我的小家）—— **新方向，多路径可选**
   - 混合×短局 ❌（待探索）
   - 混合×中局 ✅✅（向僵尸开炮 / 保卫向日葵）
   - 混合×长局 ❌（待探索）

4. **三大中国化障碍**：
   - 经典 Match-3 / 堆叠消除已红海，铁律 1 必 fail
   - 欧美重氪 IAP 模型水土不服 —— 中国必须 IAA 主导
