# 广告点与差一点通关数值原则

> 核心判断：好的 IAA 数值不是让玩家一直输，而是让玩家相信“我差一点就能过”，并愿意看广告补足最后一口气。

## 好广告点的体验

| 玩家感受 | 设计含义 |
| --- | --- |
| 我刚才差一点 | 失败点要可解释 |
| 我知道哪里错了 | 失败不能像随机惩罚 |
| 看一次广告就能补救 | 广告奖励要解决当前困境 |
| 我下次可能不用看广告 | 玩家保留掌控感 |

## 差一点通关的常见场景

| 类型 | 表现 | 适合广告奖励 |
| --- | --- | --- |
| 时间差一点 | 还差 3 秒完成清屏/逃脱/收纳 | 加时、冻结、减速 |
| 血量差一点 | Boss 只剩 5%-15% 血 | 复活、临时伤害、护盾 |
| 空间差一点 | 只差 1 格放下/清空 | 多 1 个槽位、撤销、换牌 |
| 资源差一点 | 金币/能量只差一点升级 | 补资源、免费刷新 |
| 操作失误 | 点错一个关键物件导致失败 | 撤销、重排、复活 |

## 光与朽的教训

| 问题 | 影响 |
| --- | --- |
| 需要手动跑很多局 | 数值迭代成本高，样本不足时容易凭感觉 |
| 数值“能玩”但不够好 | 玩家没有稳定形成“差一点”的心理 |
| 单局偏长 | 失败成本高，玩家不一定愿意看广告继续 |
| 爽感反馈不足 | 即使数值接近，也不觉得奖励值得 |

## 竞品给出的方向

从《噩梦守护战》《装备全靠转》《打个螺丝》《猪了个猪》《羊了个羊》《倒水杯》等小游戏体验看：

- 广告点往往出现在玩家已经投入几分钟后。
- 玩家看广告不是因为被强迫，而是觉得“我这局有希望”。
- 难度设计会制造卡点，但卡点必须让玩家觉得可被广告道具解决。

## 下一项目数值验证清单

| 阶段 | 要验证什么 |
| --- | --- |
| 纸面/原型 | 是否存在清晰失败条件 |
| 7 天原型 | 是否能制造“只差一点”的失败 |
| Demo | 失败后广告奖励是否正好解决问题 |
| 上线前 | 次留、失败率、广告触发率、广告完播率是否闭环 |

## 最小数据字段

| 字段 | 作用 |
| --- | --- |
| level_id | 识别关卡 |
| result | 胜利/失败 |
| fail_reason | 时间到、血量归零、槽位满、空间不够 |
| progress_at_fail | 失败时完成度 |
| time_spent | 单局时长 |
| ad_offer_shown | 是否出现广告救助 |
| ad_watched | 是否看广告 |
| result_after_ad | 看广告后是否通关 |

## 判断标准

- 如果失败时完成度常低于 50%，说明太难或教学失败。
- 如果失败时完成度常在 80%-95%，但广告观看率低，说明奖励不够有吸引力或玩家不相信能救回来。
- 如果广告后仍大量失败，说明广告奖励设计错了。
- 如果不看广告也轻松过，说明广告点不存在。

## 侦探寻物类广告点：提示要分层，不卖基础操作

寻物解谜的广告点不应直接卖“能不能玩”，而应解决玩家当下的具体卡点：

| 卡点 | 广告奖励 | 设计边界 |
| --- | --- | --- |
| 时间差一点 | 加时 30-60 秒 | 玩家已经接近找齐时最有效 |
| 找不到证物 | 分层提示 / 圈出可疑区域 | 不直接自动点完证物 |
| 紫外灯能量不够 | 立即充满或加速恢复 | 普通点击和放大镜仍应可用 |
| 指认错误 | 额外证词提示 / 重新指认 | 不用广告强制阻断主线 |

提示层级要从弱到强：场景弱异常 -> 工具揭示 -> 广告强提示。这样广告是“最后一口气”，不是把核心乐趣卖掉。

## IAA 版寻物需要足够多的可广告化卡点

如果一关只有 3 个证物和 3 个嫌疑人，错误空间很小，广告触发点也少，更像买断或 TapTap/Steam 的内容体验。要做纯 IAA，需要把关卡改成更密的“找破绽 / 找异常”结构：

- 每关 8-15 个异常点或证物。
- 至少 2-3 个较难隐藏点，用于提示广告。
- 支持加时、提示、跳过、看答案等自然救助。
- 剧情用文本和通用结算承接，不为每关制作重动画。

判断标准：玩家失败时应觉得“我只差几个破绽就能破案”，而不是“我根本不知道该推理什么”。前者能承接广告，后者会变成理解失败。
