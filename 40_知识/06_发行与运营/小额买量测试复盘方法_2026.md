# 小额买量测试复盘方法 2026

> 核心教训：早期买量不是为了证明“我能买到用户”，而是为了回答“我买到的用户是否能留下、是否会触发广告、是否值得继续买”。低 CPA 如果没有留存，是一个很甜的陷阱。

## 光与朽案例摘要

| 指标 | 数据 |
| --- | ---: |
| 投放周期 | 2026-04-26 至 2026-04-28 |
| 花费 | 403.88 元 |
| 曝光 | 40,776 |
| 点击 | 22,612 |
| CTR | 55.45% |
| CPC | 0.0179 元 |
| 目标转化 | 17,294 |
| 目标 CPA | 0.0234 元 |
| 微信后台买量日新增 | 17,375 |
| 微信注册 CPA | 0.0232 元 |
| 买量日平均停留 | 24.39 秒 |
| 买量日加权次留 | 0.16% |
| 买量日加权 7 日留存 | 0.03% |

结论：获客极便宜，但用户几乎没有留下。继续加预算没有意义。

## 买量漏斗三层

| 层级 | 看什么 | 错误解读 |
| --- | --- | --- |
| 广告层 | 曝光、点击、CTR、CPC、目标转化、CPA | “CPA 很低，所以买量成功” |
| 承接层 | 微信新增、首屏加载、开始游戏、首局完成、停留时长 | “用户进来了，所以产品没问题” |
| 产品层 | D1/D3/D7、失败点、广告触发、广告完播、广告后结果、收入 | “没有收入就是量不够” |

早期买量必须三层一起看。只看广告后台，会被低价转化误导。

## 低 CPA 陷阱

低 CPA 有三种可能：

| 可能性 | 表现 | 判断方法 |
| --- | --- | --- |
| 素材真的强 | CTR 高，停留长，D1 不差 | 继续小额测素材和定向 |
| 点击低意图或误触 | CTR 极高，但停留极短，D1 极低 | 停止扩量，重看广告位和素材表达 |
| 产品承接失败 | 点击和新增正常，但首局流失严重 | 修首屏、教学、前 30 秒爽点 |

光与朽更接近第二种和第三种：CTR 与转化极高，但停留和留存极差。

## 买量前检查表

在花钱前，先确认这些数据能记录：

| 检查项 | 必须有 |
| --- | --- |
| 来源识别 | 能区分自然量、CPS、腾讯广告、内容平台 |
| 首局漏斗 | 进入、加载完成、开始、第一次操作、第一次反馈、第一次失败 |
| 留存 | D1、D3、D7 按来源分 cohort |
| 广告点 | 广告展示、点击、完播、奖励发放、广告后是否过关 |
| 收入 | 按日期和广告位统计收入 |
| 素材编号 | 每条广告素材有唯一编号，能和后台数据对应 |

如果这些没有，买量只能买到“花了多少钱”的结果，买不到判断。

## 小额买量 SOP

### 阶段 1：目标设定

一次测试只回答一个问题：

- 素材是否能吸引点击？
- 点击后是否能进入游戏？
- 首局是否能留下来？
- 广告点是否能触发？

不要同时验证所有问题。

### 阶段 2：预算设置

| 目的 | 建议预算 |
| --- | ---: |
| 素材点击测试 | 50-100 元 |
| 首局承接测试 | 100-300 元 |
| 留存初筛 | 300-500 元 |
| ROI 测试 | 1000 元以上，且必须已有 D1 和广告数据基础 |

光与朽这次 403.88 元已经足够判断“不能扩量”，因为留存和停留太低。

### 阶段 3：素材分组

至少分两组：

| 素材类型 | 目的 |
| --- | --- |
| 真实玩法直给 | 验证玩家是否被核心玩法吸引 |
| 强视觉钩子 | 验证题材/爽点是否能停住用户 |

如果强钩子 CTR 高但留存低，说明素材可能吸来不匹配用户，或游戏承接没有兑现广告承诺。

### 阶段 4：投后 72 小时复盘

| 时间 | 看什么 |
| --- | --- |
| T+0 | 曝光、点击、CPC、进入游戏是否正常 |
| T+24h | D1、首局漏斗、停留时长 |
| T+72h | D3、广告触发、广告收入、评论反馈 |
| T+7d | D7、ROAS、是否继续 |

## 决策矩阵

| 数据表现 | 判断 | 动作 |
| --- | --- | --- |
| CTR 高、CPA 低、D1 低 | 低质量流量或承接失败 | 停止扩量，修素材表达和首局 |
| CTR 低、CPA 高、D1 尚可 | 素材吸引力弱，但产品可能还行 | 重做素材再测 |
| CTR 高、D1 尚可、广告触发低 | 产品能留人，但变现点弱 | 修广告点和奖励 |
| D1 高、广告触发健康、CPA 可控 | 具备加码条件 | 小额加预算，准备发行材料 |
| 样本太小 | 不能判断 | 补样本，不要强行下结论 |

## 下一次买量必须新增的字段

| 字段 | 为什么重要 |
| --- | --- |
| first_session_duration | 判断是否首局承接失败 |
| tutorial_complete | 判断教学是否卡住 |
| first_fail_reason | 判断是否“差一点”失败 |
| ad_offer_shown | 判断广告点是否出现 |
| ad_watched | 判断广告意愿 |
| result_after_ad | 判断广告奖励是否真的救回来 |
| source_channel | 区分腾讯广告、CPS、自然量、内容平台 |
| creative_id | 判断哪条素材带来的用户更有质量 |

## 核心原则

- 买量是买判断，不是买面子。
- 低 CPA 不是胜利，留存和广告收入才是胜利。
- 没有首局漏斗和广告后结果，不要进入大额买量。
- 下次买量前先修产品承接，再测素材，不要用预算掩盖首局问题。

## UA 补充：LTV/CAC、素材平台差异与验证链

### 买量只看 CPI/CPA 不够，必须回到 LTV/CAC

早期投放不是为了证明“我能买来用户”，而是判断：

```
用户终身价值 LTV > 获客成本 CAC
```

对 IAA 小游戏，LTV 主要来自：

- 人均广告展示次数。
- 广告填充率、eCPM、完播率。
- D1/D3/D7 留存。
- 后续活动、版本更新带来的回访。

如果只看到低 CPA，但用户不留存、不看广告，投放依旧不可放大。

### 平台差异决定素材表达

| 平台 | 更适合验证什么 | 素材重点 |
| --- | --- | --- |
| 腾讯广告 / 微信生态 | 陌生用户进入小游戏后的真实承接 | 真实玩法、首局爽点、低误导 |
| 抖音 / 巨量引擎 | 强钩子、短视频内容吸引力 | 前 3 秒冲突、夸张失败/逆转 |
| 小红书 | 开发者故事、人设、女性向题材和审美反馈 | 过程感、真实感、评论互动 |
| B 站 | 中长内容、开发过程、硬核玩家反馈 | 开发复盘、机制解释、长尾讨论 |

同一条素材不要机械跨平台复用。投放前先明确：这次是测“钩子”，还是测“产品承接”。

### 可投放验证包

每次正式投放前，准备一个最小验证包：

| 资产 | 最低要求 |
| --- | --- |
| 素材 | 至少 3 条真实玩法素材，编号管理 |
| 入口 | 进入链路稳定，能区分来源 |
| 埋点 | 曝光、点击、进入、首局、广告触发、广告完成 |
| 复盘表 | 能按素材、渠道、日期拆分 CPA、D1、广告触发 |
| 止损线 | 预算、D1、首局完成率、广告触发率提前写清 |

没有这套包，预算越大，浪费越快。

### 创作者白名单 / Spark Ads 的使用前提

KOC、达人授权、白名单投放适合在素材已经出现自然信号后放大，不适合替代产品验证。判断顺序应当是：

```
自然内容反馈 → 小额投放验证 → 白名单/达人放大 → ROI 复盘
```

不要先花钱找达人，再用达人数据倒推出产品成立。

## 微信小游戏投放补充：三阶段判断

### 阶段 1：链路可用性

先用小预算确认：

- 广告点击后能否稳定进入小游戏。
- 授权、加载、首屏是否有明显流失。
- 埋点能否识别来源与素材。

这一步不判断产品好坏，只排除技术和链路污染。

### 阶段 2：素材与首局承接

看三组指标：

| 指标 | 用途 |
| --- | --- |
| CTR/CPC | 判断素材是否有吸引力 |
| 激活成本 | 判断点击是否能变成真实进入 |
| 首局完成率 / 首局时长 | 判断产品是否兑现素材承诺 |

CTR 高但首局差，优先怀疑素材误导或首局体验不足。

### 阶段 3：混合 ROI

微信小游戏不能只看广告收入，还要把 CPS、内容平台、私域、发行合作放进同一张来源表，但必须分开统计。混合 ROI 可以综合看，原始来源不能混在一起。

## 微信广告后台分类的实操意义

微信广告后台的“游戏”行业分类不是形式项，会影响素材审核、投放定向、系统学习和后续数据归因。

选择分类时按真实核心玩法，而不是按最想吸引的人群：

| 游戏实际核心 | 后台分类倾向 |
| --- | --- |
| 堆叠、合成、排序、消除 | 休闲益智 / 益智解谜 |
| 跑酷、闯关、轻动作 | 动作冒险 / 休闲动作 |
| 装扮、美妆、穿搭 | 模拟经营 / 女性向休闲 |
| Roguelike、Boss 战、横版战斗 | 动作冒险 / 角色扮演相关分类 |

分类和素材表达要一致。若后台分类、广告素材、落地玩法三者不一致，短期可能提升点击，长期会伤害留存、审核稳定性和投放学习。

## 7 天原型和小额买量的关系

7 天原型不应该直接承担完整留存和商业化验证。它只验证三件事：

- 玩家是否能看懂。
- 核心动词是否产生爽感。
- 失败/重开是否有“差一点”的动机。

买量要等最小门槛过后再做。推荐顺序：

```
内部手感验收 -> 小样本外部试玩 -> 记录 3 分钟行为 -> 小额买量补样本
```

3 分钟留存必须自己埋点：

```
3 分钟留存 = 进入核心玩法后停留满 180 秒的人数 / 进入核心玩法人数
```

不要只看平台平均停留时长。

## 腾讯广告冷启动学习：先判断投放链路，再判断产品

《光与朽》早期买量第一轮出现低消耗、点击异常、年龄画像偏老的问题。这个数据不能直接判断产品失败，应先标记为“投放链路异常数据”。

冷启动测试建议：

| 项 | 首轮建议 |
| --- | --- |
| 优化目标 | 注册或首日变现 ROI，七日 ROI 第二阶段再测 |
| 版位 | 手动版位优先测试视频号 + 微信小游戏/小程序相关流量 |
| 年龄 | 先明确目标年龄，不让系统无限拓展 |
| ROI 目标 | 首轮放低，不追盈利，只拿样本 |
| 预算 | 300-600 元确认能否起量，不用一开始花满 1000 |

首轮目标不是赚钱，而是判断：能不能起量、素材能不能带来注册、首日广告点位有没有变现。

## 异常流量处理：低价注册不是胜利

当出现 CTR 极高、注册成本极低、停留极短、年龄严重错位时，不要把数据当成产品结论。

| 异常信号 | 含义 |
| --- | --- |
| CTR 远高于正常广告 | 可能是误点、版位问题或低意图流量 |
| 注册成本极低 | 系统可能只优化到“打开小游戏”的人 |
| 平均停留 20-30 秒 | 打开即走，不能代表目标玩家体验 |
| 50 岁以上占比过高 | 目标人群错位，需要检查定向和自动拓展 |

这类数据应该单独排除，不进入留存/产品好坏判断。下一轮必须按 cohort 分开看：自然用户、CPS、腾讯广告、内容平台、熟人测试。

## 买量前的“值得再测”信号不等于值得扩量

《光与朽》在熟人/自然样本阶段有 167 个注册用户、平均停留约 594 秒。这个信号说明核心循环可能能留住一部分人，但还不能证明买量可扩。

更稳的解释是：

| 信号 | 能说明 | 不能说明 |
| --- | --- | --- |
| 平均停留约 9.9 分钟 | 有玩家愿意打一整局或接近一整局 | 目标用户留存达标 |
| 熟人/朋友圈注册 | 链路能跑通，有初步反馈 | 市场需求成立 |
| 运营反馈“像竞品但不够精致” | 完成度和差异化可见性有问题 | 项目必死或必成 |

因此买量动作应从“扩用户”降级成“买判断”：先用 500-1000 元拿 300-500 个陌生样本，验证前 30 秒、首局完成、次留和广告触发，再决定是否继续。

## 早期预算要分层，不要一次押满

一个更健康的小额预算结构：

| 预算层 | 用途 |
| --- | --- |
| 500 元左右 | 素材与定向是否能带来正常意图用户 |
| 1000-2000 元 | 在首轮正常后补足 cohort，观察 D1/广告触发 |
| 500 元预留 | 用于紧急修正后的复测，而不是一开始花掉 |

早期买量的目标不是证明“我敢花钱”，而是让每一笔钱回答一个问题。若第一层数据已经显示链路异常或首局留不住，后面的预算应该暂停，而不是继续把样本做大。

## 买量视频不是教学片，前 3 秒必须制造欲望

早期买量素材不要从主界面、标题或完整流程开始。视频的任务是让陌生用户在 1-3 秒内看到冲突、异常或高风险局面，然后愿意点进来。对《光与朽》这类玩法，30 秒比 60 秒更适合作为首轮素材；如果素材不足，15 秒高密度片段也好过把一局完整玩法硬拉长。

可复用的 30 秒结构：

| 时间 | 内容 | 目的 |
| --- | --- | --- |
| 0-3s | 无人机/空投命中，立刻出现巨大增益或危险反转 | 用异常事件钩住注意力 |
| 3-12s | 硬切到激光/棱镜清屏，展示爽感结果 | 证明核心玩法有反馈 |
| 12-15s | Boss 警告、红屏、入场压迫 | 抬高风险 |
| 15-25s | Boss 与激光物理角力，被顶住或逼退 | 展示差异化机制 |
| 25-28s | 停在胜负未定前，不直接给胜利结算 | 留悬念 |
| 28-30s | Logo / CTA / 小程序入口 | 收束行动 |

素材录制要做“短片段拼接”，而不是录 13 分钟全流程再硬剪。可以用调试按键录 4 个完美片段：空投赌博、Boss 角力、棱镜清屏、幸运奖励。剪辑时用同一炮塔位置、连续激光方向、稳定 UI 位置和统一 BGM 做粘合，转场用硬切、白闪或 glitch，避免老式淡入淡出拖慢节奏。

## 算法时代，买量素材要设计“可识别情感向量”

批次 014 对 2026 全球手游营销趋势的观察提醒：买量从“人群标签匹配”转向“内容理解 + 语义匹配”。广告平台越来越像在理解素材表达的情绪、场景和欲望，再把它推给相似偏好的用户。

这对小团队的影响是：素材不只是展示游戏，而是在告诉算法“这是什么情绪”。每条素材要提前定义一个主向量，避免把爽感、情怀、危机、轻松、成长全部塞进 15 秒里。

| 素材向量 | 适合表达 | 检查问题 |
| --- | --- | --- |
| 轻松自动 | 放置、自动战斗、挂机收益 | 3 秒内能看出“不累”吗 |
| 高回报 | 开箱、爆装、清屏、连锁收益 | 奖励是否可视、足够密集 |
| 危机反转 | 差点失败、Boss 压迫、最后一击 | 风险和反转是否同屏出现 |
| 情怀召回 | 经典 IP、老画面、熟悉音效 | 是否先唤起记忆，再展示新玩法 |
| 民俗微恐 | 非遗、剪纸、夜晚、禁忌物 | 氛围是否服务玩法，而不是纯吓人 |
