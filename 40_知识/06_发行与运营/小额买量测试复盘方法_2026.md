# 小额买量测试复盘方法 2026

> 核心教训：早期买量不是为了证明“我能买到用户”，而是为了回答“我买到的用户是否能留下、是否会触发广告、是否值得继续买”。低 CPA 如果没有留存，是一个很甜的陷阱。

## 光与朽案例摘要

| 指标 | 数据 |
| --- | ---: |
| 投放周期 | 2026-04-26 至 2026-04-28 |
| 花费 | 403.88 元 |
| 曝光 | 40,776 |
| 点击 | 22,612 |
| CTR | 55.45% |
| CPC | 0.0179 元 |
| 目标转化 | 17,294 |
| 目标 CPA | 0.0234 元 |
| 微信后台买量日新增 | 17,375 |
| 微信注册 CPA | 0.0232 元 |
| 买量日平均停留 | 24.39 秒 |
| 买量日加权次留 | 0.16% |
| 买量日加权 7 日留存 | 0.03% |

结论：获客极便宜，但用户几乎没有留下。继续加预算没有意义。

## 买量漏斗三层

| 层级 | 看什么 | 错误解读 |
| --- | --- | --- |
| 广告层 | 曝光、点击、CTR、CPC、目标转化、CPA | “CPA 很低，所以买量成功” |
| 承接层 | 微信新增、首屏加载、开始游戏、首局完成、停留时长 | “用户进来了，所以产品没问题” |
| 产品层 | D1/D3/D7、失败点、广告触发、广告完播、广告后结果、收入 | “没有收入就是量不够” |

早期买量必须三层一起看。只看广告后台，会被低价转化误导。

## 低 CPA 陷阱

低 CPA 有三种可能：

| 可能性 | 表现 | 判断方法 |
| --- | --- | --- |
| 素材真的强 | CTR 高，停留长，D1 不差 | 继续小额测素材和定向 |
| 点击低意图或误触 | CTR 极高，但停留极短，D1 极低 | 停止扩量，重看广告位和素材表达 |
| 产品承接失败 | 点击和新增正常，但首局流失严重 | 修首屏、教学、前 30 秒爽点 |

光与朽更接近第二种和第三种：CTR 与转化极高，但停留和留存极差。

## 买量前检查表

在花钱前，先确认这些数据能记录：

| 检查项 | 必须有 |
| --- | --- |
| 来源识别 | 能区分自然量、CPS、腾讯广告、内容平台 |
| 首局漏斗 | 进入、加载完成、开始、第一次操作、第一次反馈、第一次失败 |
| 留存 | D1、D3、D7 按来源分 cohort |
| 广告点 | 广告展示、点击、完播、奖励发放、广告后是否过关 |
| 收入 | 按日期和广告位统计收入 |
| 素材编号 | 每条广告素材有唯一编号，能和后台数据对应 |

如果这些没有，买量只能买到“花了多少钱”的结果，买不到判断。

## 小额买量 SOP

### 阶段 1：目标设定

一次测试只回答一个问题：

- 素材是否能吸引点击？
- 点击后是否能进入游戏？
- 首局是否能留下来？
- 广告点是否能触发？

不要同时验证所有问题。

### 阶段 2：预算设置

| 目的 | 建议预算 |
| --- | ---: |
| 素材点击测试 | 50-100 元 |
| 首局承接测试 | 100-300 元 |
| 留存初筛 | 300-500 元 |
| ROI 测试 | 1000 元以上，且必须已有 D1 和广告数据基础 |

光与朽这次 403.88 元已经足够判断“不能扩量”，因为留存和停留太低。

### 阶段 3：素材分组

至少分两组：

| 素材类型 | 目的 |
| --- | --- |
| 真实玩法直给 | 验证玩家是否被核心玩法吸引 |
| 强视觉钩子 | 验证题材/爽点是否能停住用户 |

如果强钩子 CTR 高但留存低，说明素材可能吸来不匹配用户，或游戏承接没有兑现广告承诺。

### 阶段 4：投后 72 小时复盘

| 时间 | 看什么 |
| --- | --- |
| T+0 | 曝光、点击、CPC、进入游戏是否正常 |
| T+24h | D1、首局漏斗、停留时长 |
| T+72h | D3、广告触发、广告收入、评论反馈 |
| T+7d | D7、ROAS、是否继续 |

## 决策矩阵

| 数据表现 | 判断 | 动作 |
| --- | --- | --- |
| CTR 高、CPA 低、D1 低 | 低质量流量或承接失败 | 停止扩量，修素材表达和首局 |
| CTR 低、CPA 高、D1 尚可 | 素材吸引力弱，但产品可能还行 | 重做素材再测 |
| CTR 高、D1 尚可、广告触发低 | 产品能留人，但变现点弱 | 修广告点和奖励 |
| D1 高、广告触发健康、CPA 可控 | 具备加码条件 | 小额加预算，准备发行材料 |
| 样本太小 | 不能判断 | 补样本，不要强行下结论 |

## 下一次买量必须新增的字段

| 字段 | 为什么重要 |
| --- | --- |
| first_session_duration | 判断是否首局承接失败 |
| tutorial_complete | 判断教学是否卡住 |
| first_fail_reason | 判断是否“差一点”失败 |
| ad_offer_shown | 判断广告点是否出现 |
| ad_watched | 判断广告意愿 |
| result_after_ad | 判断广告奖励是否真的救回来 |
| source_channel | 区分腾讯广告、CPS、自然量、内容平台 |
| creative_id | 判断哪条素材带来的用户更有质量 |

## 核心原则

- 买量是买判断，不是买面子。
- 低 CPA 不是胜利，留存和广告收入才是胜利。
- 没有首局漏斗和广告后结果，不要进入大额买量。
- 下次买量前先修产品承接，再测素材，不要用预算掩盖首局问题。
