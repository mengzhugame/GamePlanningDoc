# 微信小游戏运营教训

> 来源：《光与朽》上线验证阶段的实际经历。这些教训很痛，但每一条都有数据支撑。

---

## 最重要的认知纠正：微信小游戏不会自动推流

**误区**：上线后等平台推量
**现实**：微信小游戏平台不会给新游戏自动推流，167 个注册用户全来自开发者朋友圈熟人

**后果**：
- 样本严重偏差（熟人反馈 ≠ 真实用户）
- 留存数据不具统计意义
- 在无效数据上做版本决策，浪费 2–3 周

**正确做法**：上线后立即自费小额买量（500–1000 元），用真实陌生用户数据做决策，不要等平台推流。

---

## DAU 门槛：流量主变现的硬条件

微信小游戏需要 **DAU ≥ 500** 才能开通流量主（广告变现）。

在达到这个门槛之前，不要用广告变现数据做产品判断，用的是噪声。

---

## 竞品认知：不要对标爆款体量

**光与朽的对手**：《我的防线》（网易持股 40%，海外版 2740 万美元流水，买量 3400+ 条创意）

**正确战略**：不对标爆款体量，而是成为"激光旋转射击细分品类的长尾代表作"

**独立游戏的生存位置**：细分 + 差异化 + 长尾，不是正面竞争

---

## 运营决策路线：方案 C 框架

当传统路线（等流量、找发行）不通时，执行方案 C：

```
方案 C 步骤：
1. 明确 2–4 周迭代周期
2. 自费 500–1000 元小额买量，获取真实数据
3. 用数据判断关卡质量（不是用主观感受）
4. 止损线：6 周 或 5000 元买量费用，两者先到先执行
5. 止损后选择：接入 IAA + CPS 合作，转变商业模式
```

---

## 止损线设置原则

不设止损线的迭代是无限的，会消耗时间和心力。

**建议格式**：
```
止损触发条件 = [时间上限] OR [资金上限]
触发后的下一步 = [提前定好，不要到时候再临时决策]
```

例：6 周或 5000 元 → 接入 IAA（广告变现）或 CPS（联运分成）合作

---

## 差异化保护：核心体验不能为了门槛而妥协

**案例**：《光与朽》的旋转激光手感是相对《我的防线》的核心差异
- 有人提议加"自动索敌"降低操作门槛
- 决策：否决，这会破坏核心差异化卖点

**规则**：差异化维度是护城河，宁可接受更高的上手门槛，也不能阉割核心体验。辅助功能只能辅助，不能替代。

---

## IAA（激励广告）触发时机优化

**更好的广告触发点**：
- 单局游玩 10 分钟后才死亡（损失了大量时间投入）
- 死亡时持有稀有装备（损失厌恶效应）

**低效的广告触发点**：
- 任意死亡立即弹出（玩家还没有足够的"损失感"）

**原理**：绝对损失厌恶是最强的广告点击驱动力，触发时机在"玩家感知到自己失去了什么"时效果最好。

## 游戏宣传视频：前 3 秒钩子框架

> 来源：Google_光与朽游戏宣传视频剪辑_2026-04-02.md

**核心原则**：视频不是介绍玩法，而是制造欲望。默认竖屏 + 静音可看。

**5 种钩子类型**：

| 类型 | 描述 | 适用游戏 |
|------|------|---------|
| **操作失误型** | "你肯定会选错" | 解谜、策略 |
| **极限翻盘型** | "不可能赢→居然赢了" | Roguelite、生存 |
| **策略反直觉型** | "你以为该这样，其实不对" | 塔防、卡牌 |
| **爽割草型** | 数量爆炸 / 连锁反应 | 割草、超休闲 |
| **高压失败型** | 倒计时 / 即将崩盘 | 任何有压迫感游戏 |

**标准剪辑结构（10 秒版）**：
```
0–1 秒：危险画面 + 强视觉冲突（让人停止滑动）
1–3 秒：错误选择 or 即将失败（情绪钩子）
3–6 秒：关键操作 / 反转（核心爽点）
6–8 秒：结果爆发（视觉高潮）
8–10 秒：戛然而止 - 不要给完整结局（激发下载欲）
```

**剪辑技巧**：
- 关键翻盘帧：减速 0.5x → 加白闪 → 停顿 0.3 秒
- 爽点帧：快切 + 音效卡点
- 不要展示"顺风局"的完整过程，只要"高风险时刻"和"决定性瞬间"

**《光与朽》适用钩子**：
- 敌人即将突破防线的 2 秒 → 极限激光扫清 → 爆炸粒子（爽割草型 + 极限翻盘型）

## 微信分享图：社交裂变的三力公式

> 来源：Google_光与朽美术_2026-04-01.md

**微信社交裂变核心动力（三力公式）**：
```
裂变力 = 好奇心（视觉反差）× 优越感（战绩炫耀）× 共情力（氛围沉浸）
```

**三类分享图设计方向**：

| 类型 | 设计理念 | 适用场景 | 文案示例 |
|------|---------|---------|---------|
| **极端反差型** | 画面对角线平分"朽"与"光"，视觉冲击强 | 好奇心驱动，诱导点击 | "黑暗已蔓延至 99%，救救这个世界" |
| **氛围叙事型** | 孤独角色面对宏大场景，大量留白，偏高审美 | 情绪共鸣，粉丝圈层传播 | "万物皆有裂痕，那是光照进来的地方" |
| **互动博弈型** | 展示玩家处于危机状态+战绩数据，激发挑战欲 | 竞技感，朋友圈社交比较 | "我坚持了 180 秒，你能比我更久吗？" |

**分享图设计铁律**：
1. 左上角预留微信头像/昵称位（让图看起来是玩家专属战绩）
2. 二维码融入游戏内元素（不要生硬贴角落）
3. 色彩：光用 2500K 暖金色（希望感），朽用深蓝紫/炭灰（高级感，非纯黑）

## 小红书内容运营：独立开发者 IP 策略

> 来源：Google_小红书文案_2026-04-21.md。适用于用小红书/抖音建立个人品牌的独立开发者。

**小红书的底层逻辑**：情绪优先，分享感至上。文案不是介绍产品，是让用户感受到"这个人和我有共鸣"。

### 5 大文案原则

| 原则 | 说明 | 错误示范 → 正确示范 |
|------|------|-------------------|
| **说人话** | 口语化，不用官方语言 | "融合消除、解谜与策略规划" → "把一堆乱七八糟化妆品整理好" |
| **情绪外露** | 具体化情绪，不要抽象描述 | "我很紧张" → "😭 手心冒汗，感觉孩子要去相亲了" |
| **格式优化** | Emoji + 分割线 + 短句，文字像图片一样好看 | 长段落叙述 → 每3句就一个 Emoji 或 `---` 分割 |
| **钩子 (Hook)** | 给用户"追更"的理由，放在结尾 | 结尾无呼吁 → "接下来会记录和发行商谈判的全过程，感兴趣的蹲后续！" |
| **明确 CTA** | 清楚说明你希望用户做什么 | 模糊结尾 → "会有姐妹愿意玩吗？评论区告诉我！" |

### 独立开发者 IP 的"养成系"模式

**核心策略**：坦诚 > 完美。真实感就是最大的流量密码。

- **直面缺点是必杀技**："美术有点一般，这是我没钱找美术大大的第一款游戏" → 瞬间拉近距离
- **冲突点 = 吸粉点**：没找到发行 + 决定还是发出来 = "逆境中坚持创作"的人设，比一帆风顺更吸粉
- **明确 IP 定位**：第一篇就说清楚"我准备在这里记录独立游戏开发的全过程"，给用户追更理由

### 独立开发者系列选题方向

```
记录型：
- 技术美术转独立开发的第 N 天
- 一个人做游戏第 N 个月，这周做了什么

反思型：
- 我犯的 3 个新手错误（游戏发行篇）
- 微信小游戏上线踩的坑（审核/广告/DAU门槛全复盘）
- 27家发行都不要，我学到了什么

开发流程型：
- 7天做一个小游戏原型的完整流程
- 从玩法思考到上线：独立小游戏开发的 9 个步骤

行业科普型：
- 微信小游戏的广告变现有多难（DAU ≥ 500 才能开通流量主）
- 个人开发者 vs 企业开发者：平台资质差异全解析
```

**发布技巧**：视频权重远高于图片，配最解压最丝滑的 15 秒录屏，效果远胜于截图。

## 复盘：三个最关键的早期决策失误

1. **等平台推流而不主动买量** → 浪费 2 周在无效数据上
2. **用朋友圈用户的留存数据做版本决策** → 样本偏差导致方向错误
3. **没有提前设置止损线** → 迭代周期无限延长，消耗心力
