# 独立游戏商业化路径（从上线到变现的完整框架）

> 来源：《游戏帝国创业战略规划》+ 《光与朽》冷启动战术推演。适用于个人/微型独立游戏工作室。

---

## 核心战略原则

**"数据说话，绝不恋战，先活下来，再谋扩张。"**

独立开发者的创业节奏：

```
生死大考（验证产品） → 资本借力（发行合作） → 主体合规（公司化） → 全球化
```

每个阶段进入下一阶段都需要**数据触发**，不能靠感觉跳级。

---

## 阶段一：生死大考（上线验证期）

### 关键指标（决定是否买量）

| 指标 | 惨败线 | 及格线 | 爆款线 |
|------|--------|--------|--------|
| **次日留存率（D1）** | < 20% | 20–35% | > 35% |
| **人均广告观看次数（IMP）** | < 2次 | 2–4次 | > 4–6次 |

**决策矩阵**：

| 情况 | 行动 |
|------|------|
| D1 < 20% | 立即停止推广，进入 Plan B（尸体分解 + 下款立项） |
| D1 20–35% | 暂停，针对性优化 1-2 周，优化后重新小量测试 |
| D1 > 35% + IMP > 4 | 立即投入 1000 元买量，测 ROI |
| ROI > 1 | 进入阶段二（联系发行商垫资买量） |

### 冷启动72小时战术（上线前3天）

**Day 1（蓄水期）**：
- 发布时间：10:00–11:30（午休前摸鱼高峰，避开早通勤盲区）
- 同步抖音/小红书发布预热内容（"一个人肝了N个月，今天上线"）
- 目标：靠自然流量 + 社媒引流拉入 **100 个真实种子用户**

**Day 2（补量与初判）**：
- 自然量 < 100 人 → 花 100–200 元强行补量到 100–300 人样本线
- 自然量已 > 100 人 → 停止操作，静观数据

**Day 3–4（生死大考）**：
- 查看种子用户的 D1/D3 留存 + 人均看广告次数
- 按上面的决策矩阵执行

---

## 阶段二：资本借力（发行合作期）

**触发条件**：ROI > 1，或 D1 > 35%

**谈判策略**：
- 拿着数据（40%次留 + ARPU 数据）找发行商垫资买量
- 合作模式：发行商垫资买量，利润按比例分成
- 目标分成：争取 5:5，最低接受 4:6
- **不强求 MG**（最低保证金），以做大流水盘为主

---

## 阶段三：主体合规（公司化）

**铁律：在拿到第一笔几万块利润之前，绝对不注册公司。**

### 何时注册？
- 发行商要求 B2B 合同 + 增值税发票时
- IAA 收入达瓶颈，准备接入微信内购（IAP）时

### 版号申请时机
- 拥有公司主体 + IAA 已赚到第一桶金
- 预算：1.5–3万元代理申请，等待 8–14 个月
- 等待期间用广告收入维持运转 + 开发下款游戏

---

## 阶段四：全球化（无版号出海）

- 海外市场（Google Play / App Store）不需要中国版号
- 国内表现良好后，同步打包英文版本
- 植入海外内购（去广告 + 基础道具礼包）
- 对接海外休闲发行商（Voodoo, Supersonic 等）测全球

---

## 终极预案：Plan B（Fail Fast 策略）

**触发条件**：1000 元买量测试 ROI < 1，或数据惨败

执行步骤：
1. **绝不恋战**：承认失败，不产生感情
2. **资产分解**：
   - 美术素材、UI 资源 → Asset Store / itch.io
   - 封装好的代码模块（如科技树、AdsManager）→ 打包上架
   - 这些资产的开发成本已经沉没，售卖是纯利润
3. **光速重启**：1 个月内做下一款 Demo，继续跑模型

---

## 变现架构（DAU 未达标期的混合方案）

微信广告/流量主开通门槛以小游戏后台当期规则为准，不要把旧门槛写死。美妆叠叠乐的实际经验是：满足后台要求后可以接入广告，但如果 DAU、留存和广告触发不足，收入仍然可能只有噪声级。

在广告收益不足以判断商业模型之前：

```
三层混合变现架构：
1. 广告 SDK 代码保留 → 开通流量主后零成本切换
2. Fallback 降级 → 广告不可用时自动切分享（统一 RewardManager）
3. 主页独立分享任务 → 与广告解耦的长期拉新
```

**重要认知**：早期买量的主要目标是买陌生样本和判断依据，不是为了面子上的用户数。是否需要冲广告门槛，要以后台规则和项目数据为准。

---

## 买量验证框架（自费小额）

**时机**：游戏已优化（爽感 + 引导 + 难度曲线完成）后

| 步骤 | 动作 | 预算 |
|------|------|------|
| 1 | 自费小额买量 | 500–1000 元 |
| 2 | 获取真实陌生用户数据 | — |
| 3 | 看次留和 IMP | — |
| 4 | 数据OK → 找发行垫资 | — |
| 5 | 数据差 → 执行止损线 | — |

**止损线设置**（方案C框架）：
```
触发条件 = 6 周 OR 5000 元买量费用（先到先执行）
触发后 → 接 CPS 合作 + IAA 放置 + 下款立项
```

---

## 可复用规则

1. 上线前不要靠熟人数据决策——朋友反馈 ≠ 真实用户，先买量获得陌生用户数据
2. D1 次留是生死线，低于 20% 不要花钱买量
3. 止损线必须提前设好，没有止损线的迭代会永无止境
4. Plan B 的资产分解是"止损后的正确动作"，不是放弃，是效率最优化
5. 出海不需要版号，只要有数据，同步准备英文版
6. 注册公司、申请版号、找发行——这三件事不要抢在赚到钱之前做

## 微信与抖音的变现分工：微信混变，抖音强 IAA

这份旧指南最值得吸收的不是单条政策数字，而是平台打法分化：

| 平台 | 更适合 | 产品设计含义 |
| --- | --- | --- |
| 微信小游戏 | 首发扶持 + 长线运营 + 混合变现 | 预留去广告、6 元首购、月卡/战令、复活、结算翻倍、局内 reroll、强单位试用 |
| 抖音小游戏 | 强素材钩子 + 内容裂变 + 偏 IAA 循环 | 先看 3 秒是否懂、7 秒是否反转、15 秒是否自然引出更爽奖励 |

**核心判断**：微信项目不要锁死成纯广告短命盘；抖音项目不要先堆系统，先让视频素材自己能带量。

### 高转化广告点位优先级

| 优先级 | 点位 | 为什么有效 |
| --- | --- | --- |
| P0 | 复活 / 续命 | 承接损失厌恶，当前痛点最强 |
| P1 | 局内 reroll / 补关键资源 | 运气差时的即时解药 |
| P2 | 结算翻倍 | 不打断战斗，收益清晰 |
| P3 | 未解锁强单位试用 | 同时做 IAA 和 IAP 预售 |

应避免：看完广告只给少量软资源、奖励延迟到账、奖励和当前失败原因无关。

### 广告系统设计要求

- 战斗中不强插。
- 新手保护期少广告或无广告。
- 广告按钮必须预加载，失败时隐藏，不让玩家点空。
- 预留用户分层频控：新手、低付费高广告、高付费低广告三套策略。
- 预留混合变现开关，不要后期再重构。

## IAA 周检查结论：内容转化链必须前置

这份周检查确认：本周没有更值得记录的新官方条文，真正要更新的是策略判断。

### 可执行策略

1. **微信默认按混合变现骨架立项**  
   最低配也要预留去广告、6 元首购、月卡/持续权益、复活、双倍结算、局内 reroll、强道具试用。

2. **抖音按素材先行型 IAA 立项**  
   先验证前 3 秒看懂、7 秒强反差、15 秒自然引出广告奖励，再谈局内广告密度。

3. **广告奖励必须是当前痛点解药**  
   失败了给续命，运气差给 reroll，差资源给关键补给，不要给无关小金币。

4. **把内容转化链纳入 IAA 设计**  
   评估小游戏时不只看广告渗透率，还要看素材是否一句话讲清、首局 30 秒内是否遇到高意图广告点。

### 对光与朽

- 微信版本继续按混合变现思路，不退回纯 IAA 幻想。
- 如果测抖音素材，视频不要讲世界观，直接打"基地要爆了 -> 激光塔逆转"。

## 海外发行最低限度框架

海外不是"把国内包翻译一下"。至少要提前处理四个层面：

| 层面 | 要点 |
| --- | --- |
| 平台合规 | Google Play / App Store 审核、隐私政策、GDPR / CCPA |
| 收款结汇 | PingPong / Payoneer 等第三方收款，避免收益卡住 |
| 本地化 | 不只是翻译，还包括 UI、文化、活动和商店页表达 |
| 买量平台 | Meta、Google UAC、TikTok 的素材逻辑完全不同 |

### 海外买量认知

- Meta 吃稳定转化素材系统和社交图谱。
- Google UAC 吃多尺寸、多比例、多长度素材资产包和稳定学习期。
- TikTok 吃前 0.5-2 秒钩子、原生感、UGC/挑战/反差。

**规则**：不要拿一条素材投三平台；这省下的不是钱，是回本机会。

## 休闲游戏发行运营的 8 个基本面

这份旧笔记较粗，但可以保留为发行运营检查清单：

1. 立项时同时判断吸量、留存、变现，不只看玩法。
2. 调优时分开看留存问题和变现问题，不要用广告点位掩盖核心体验差。
3. 发行变现依赖热点捕捉、数据验证、达人营销和效果广告组合。
4. 长线运营需要召回、活动、IP/内容联动，不是上线后等自然量。
5. 买量先判断 CAC 是否足够低，再谈规模化。
6. 素材创新能显著影响安装转化，试玩广告/互动素材要尽早纳入。
7. 广告位置要自然融入流程，频率过高会直接伤留存。
8. ASO 的图标、标题、预览视频必须与广告素材一致，不能承诺错位。

## 运营发行能力学习路线：现阶段补中级

用户当前已有基础指标意识：DAU、ARPU、LTV、留存率、ROI、ROAS、IAA 点位和基础买量。下一步不该泛学"运营大全"，而是补三个中级能力：

- 数据异常排查：为什么 D1 掉、为什么广告渗透低、为什么低 CPA 是烂量。
- A/B 测试：每轮只动 1-2 个变量，避免复盘失真。
- LTV/CAC 平衡：按渠道、系统、地区拆分，不看总平均。

**学习方式**：每次项目上线或小额测试后，只输出 1 条 200 字运营锦囊，直接服务当前项目，不做脱离项目的课程式学习。

## 平台选择：IAA、Steam、TapTap 的商业模型不能混用

平台选择不是“哪里更赚钱”，而是玩法、内容成本、变现方式是否匹配。

| 类型 | 更适合 | 不适合 |
| --- | --- | --- |
| 纯 IAA 小游戏 | 3 分钟短局、高频失败、广告救助自然、可低成本量产 | 剧情重、美术重、关卡内容不可模板化 |
| IAA + IAP 混变 | 有短局，也有成长、收集、升级、轻付费 | 没有主体/版号条件时盲目做内购 |
| Steam/TapTap 买断 | 剧情、美术、关卡内容、沉浸体验、愿望单验证 | 纯广告变现、只靠短局广告救助 |
| 公司级产品 | 多人、语音、UGC、社交网络、持续运营 | 当前单人 30 天切片 |

Steam 的核心价值是愿望单、Demo、长尾销售和全球曝光，不是广告变现。纯 IAA 广告小游戏不应直接搬到 Steam。

## 用户资产是第二条命

移动买量变贵、Steam 新游拥挤、AI 提升供给后，产品做出来只是入场。小团队真正要争的是：低成本、高意图、可反复触达的目标用户。

因此商业化路径要增加一层：

```
产品想法 -> 内容表达 -> 高意图用户池 -> 可测 Demo -> 留存/愿望单/买量数据 -> 商业化选择
```

没有用户池，每款游戏都会从 0 开始；有用户池，即使单款失败，也能把关注、反馈和测试者带到下一轮。

## 内容驱动推理游戏：买断与 IAA 不能混形

侦探寻物、轻推理、剧情案件类游戏要先判断商业模型，再决定内容量和广告点。它们通常不是靠同一套操作无限重复留存，而是靠案件、场景、美术、证物逻辑和叙事反转驱动。

两条路线的成本结构完全不同：

| 路线 | 产品形态 | 收入逻辑 | 设计含义 |
| --- | --- | --- | --- |
| Steam / TapTap 买断 | 12-20 个案件、3-5 小时体验、强题材包装 | 愿望单、Demo、买断定价、长尾销售 | 要把内容质量、节奏、真相反转和视觉风格做成卖点 |
| 微信 / 抖音 IAA | 找 8-15 个破绽 / 证物的短局关卡 | 高频失败、提示、加时、跳过、答案广告 | 要降低剧情成本，提高异常点密度和广告救助频率 |

危险中间态：用买断制的案件内容成本做游戏，却用 IAA 小游戏的广告收入回收。这样的项目会同时吃到内容成本高和变现效率低两边的压力。

立项前的验证方式应分开：

- 买断向视频：测试“这个题材、画风、案件体验是否让玩家愿意加愿望单 / 付费”。
- IAA 向视频：测试“找 10 个破绽、差一点找完、看提示广告继续”是否能形成短视频和广告点。

平台不是发布位置，而是商业模型。先选模型，再定关卡数量、内容深度、广告密度和美术成本。

## TapTap 预约页可以作为高意图验证窗口

TapTap 预约页不是正式发行承诺，而是介于 AI 概念视频和可玩 Demo 之间的高意图验证窗口。适合用来观察：是否有人愿意关注、预约、评论、追问试玩，而不是只在泛流量平台点个赞。

概念验证期的 TapTap 页面应保持克制：

| 模块 | 写法 |
| --- | --- |
| 游戏名 | 优先让玩家一眼看懂题材钩子，不要堆副标题 |
| 游戏简介 | 前 50 字讲清类型、核心循环和玩家目标 |
| 开发者的话 | 讲为什么做、当前验证到哪一步，不和简介重复 |
| 首页推荐语 | 一句话打核心动作，避免时效词、奖项、极限词 |
| 初始更新日志 | 说明当前公开的是概念演示 / 核心玩法展示 |
| 封面 / 首帧 | 直接展示核心玩法，不用纯氛围图或 Logo 开场 |

重要纪律：

- 文案里不要写外部群、外链、联系方式、诱导好评或兑换码。
- 视频和截图尽量对应真实核心玩法，避免让玩家误以为概念视频就是已完成实机。
- 页面状态应明确为“概念验证期”，不把预约页误当已经立项成功。
- 判断重点是高意图反馈：预约、评论、求试玩、收藏、持续追问，而不是单个平台的曝光量。
