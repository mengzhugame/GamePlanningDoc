# 发行商沟通经验（两款游戏实战总结）

> 来源：《美妆叠叠乐》接触 32 家发行商 + 《光与朽》接触 26 家发行商的真实反馈分析。

---

## 发行商看 Demo 的真实逻辑

发行商在 Demo 阶段最关注的 **4 件事**（按优先级）：

1. **美术品质**（第一印象）— "糊糊的" 直接关掉
2. **完成度**（是否像成品）— 没有动效、音效 = 不信任你能做完
3. **受众深度**（买量成本预判）— 太垂直意味着高 CPA
4. **玩法创新点**（是否有差异化）— 纯换皮直接拒绝

> **核心认知**：发行商的每一条"委婉拒绝"背后都是成本计算，不是对你的游戏设计有意见。

---

## 《美妆叠叠乐》发行反馈汇总（32 家，2026-02）

### 被拒绝的真实原因

| 问题 | 严重程度 | 发行商关注点 |
|------|---------|------------|
| 美术品质低（"糊糊的"） | P0 | 担心上线后用户第一眼就走 |
| 没有动效（完成度低） | P0 | 担心开发周期无法控制 |
| 受众垂直（20-40岁女性） | P1 | 担心买量 CPA 过高 |
| 手感延迟（点击响应慢） | P1 | 担心留存数据差 |

### 个人开发者必须过滤掉的"不合理建议"

| 发行商建议 | 为什么不合理 |
|-----------|------------|
| "玩法太老" | 消除玩法永不过时，核心是有无创新点 |
| "需要混变（内购）" | 个人开发者无法做微信内购，坚持 IAA |
| "出抖音版本" | 先跑通微信，分散精力是大忌 |
| "不适合欧美" | 国内产品，不需要考虑 |

**结论**：美妆叠叠乐被拒核心原因是"完成度低 + 美术差"，产品底子是好的，但"包装"不够。

## 《光与朽》发行反馈汇总（26 家，2026-02）

### 被拒绝/需改进的真实原因

| 问题 | 严重程度 | 来源 |
|------|---------|------|
| 难度太高，新手无法通关 | P0 | 腾讯游戏、内测玩家 |
| 操作不直观（不知道拖哪里） | P0 | 多位测试者 |
| 单局时间过长（15-20 分钟） | P1 | 游艺春秋、内测玩家 |
| Build 无差异（Chain 一家独大） | P1 | 游艺春秋、对战数据 |
| 怪物视觉辨识度低（"黑的一坨"） | P1 | 运营反馈 |
| 爽感不足（升级看不出变化） | P1 | 内测玩家 |

### 认可点（发行商真正说了"好"的）

- ✅ 玩法有新颖性（旋转激光 + Roguelite 是差异化）
- ✅ 核心机制与《我的防线》构成真正差异（操作范式不同）
- ✅ 留存信号存在（人均停留 594 秒 ≈ 10 分钟）

**结论**：光与朽的玩法核心被认可，问题集中在难度曲线 + 操作 + 视觉反馈，是可迭代的问题，不是底层设计错误。

## 发行商沟通流程与注意事项

### Demo 送审前的准备清单

- [ ] 美术统一精致（不要有"拼凑感"，分辨率 720p+）
- [ ] 完整动效（界面切换、按钮点击、消除/击中反馈）
- [ ] 完整音效和 BGM（没有音效 = 未完成品）
- [ ] 新手引导完整（前 3 关强制教学）
- [ ] 单局时间 ≤ 10 分钟（微信碎片化场景要求）
- [ ] 包体 < 4MB（微信小游戏包体限制）
- [ ] 录好游戏视频（最精彩的 30 秒核心玩法展示）

### 接触发行商的正确姿势

1. **先找聊得上来的**：冷联系成功率极低，通过社群/展会/内推效果更好
2. **Demo 要达到 80% 完成度**才去找发行，否则反馈是噪声
3. **一批同时联系 20-30 家**：不要等一家谈完再找下一家
4. **快速过滤无效反馈**：没有具体建议的拒绝 = 无信息量，不用分析

### 个人开发者的发行谈判底线

```
可接受：发行商垫资买量，净利润 5:5 分成（最低 4:6）
不接受：MG（最低保证金）要求（发行商担风险，不该要MG）
不接受：要求开发内购（个人主体无法接微信内购）
```

## 两款游戏的横向比较

| 维度 | 美妆叠叠乐 | 光与朽 |
|------|-----------|--------|
| 核心问题 | 完成度低 + 美术差 | 难度陡峭 + 操作不直觉 |
| 发行商态度 | 普遍不看好 | 部分认可玩法 |
| 改进成本 | 高（需重绘美术） | 中（调数值 + 优化） |
| 受众 | 垂直（女性） | 较广（塔防男女通吃） |
| 最终决策 | 放弃（精力集中光与朽） | 继续迭代 |

**最重要的跨项目经验**：
- 美术问题在立项时就要解决，不要指望后期发行商给钱再优化
- "玩法有创新"是进入下一轮谈判的入场券，其他问题都是可以谈的
- **個人开发者的核心竞争力不是体量，是差异化锐度**

## 竞品认知：遇到强竞品怎么办

**案例**：《光与朽》被运营拿来和《我的防线》（网易持股 40%，流水 2740 万美元）比较

**正确应对**：
1. **不要对标爆款体量**——对方 3400+ 条广告创意，几百万买量，追不上
2. **确认差异化是真的存在**——旋转激光 ≠ 左右平移炮台，操作范式根本不同
3. **差异化必须被前 2 分钟感知**——如果玩家 5 分钟内感知不到差异，等于没有差异
4. **定位细分长尾，不是正面竞争**——月流水几万到几十万 = 独立开发者的成功线

---

## 可复用规则

1. Demo 完成度 < 80% 不要送审，发行商的拒绝是噪声，不是反馈
2. 送审清单优先级：美术 > 完成度 > 难度曲线 > 玩法创新
3. 个人开发者坚持 IAA，不做内购，不做多平台（先跑通一个）
4. 被拒理由要过滤：有具体建议的 ≈ 20-30%，其余是套话
5. 强竞品出现时：不对标体量，只看差异化维度是否真实存在
6. 发行商认可玩法 + 问题是可迭代的 = 改了再找，不要放弃

## 发行商"捕猎"计划：先钩子，后长视频

光与朽 Demo 出来后，用户曾纠结要不要剪 3 分钟完整视频、发小红书、发微信群或直接发包。对话给出的结论很硬：

> 找发行不是做自媒体长内容，而是用 30 秒内的强钩子筛出有意向的人。

### 发行商视频分工

| 视频类型 | 用途 | 时长 |
| --- | --- | --- |
| 钩子视频 | 群发、朋友圈、发行对接群，用来钓第一批意向 | 15-30 秒 |
| 玩法说明视频 | 已经有合作意向后，辅助解释完整规则 | 2-3 分钟 |

不要把 3 分钟视频发到冷场景里。冷场景里，发行商只看前 5 秒。

### 光与朽钩子结构

1. `0-3 秒`：满屏黑油被激光清场，直接打视觉壁垒。
2. `3-10 秒`：展示旋转激光、折射、怪物压迫。
3. `10-20 秒`：展示一次险些失守后的翻盘。
4. `20-30 秒`：一句寻求发行，不要卑微求测试。

参考话术：

> Shader 写的流体怪物 + 旋转激光塔防，手机端 60 帧。现在想找懂解压/爽游赛道的发行聊聊。

### 交付物分层

- 安卓发行 / 买量发行：直接准备 APK。
- 微信小游戏发行：准备体验版二维码和白名单。
- 意向很高的发行：加微信后直接拉进体验白名单，减少技术阻力。

### 筛发行底线

| 类型 | 判断 |
| --- | --- |
| 靠谱发行 | 能立刻说清推过的案例、ROI、留存、买量方式 |
| 烂发行 | 只说"我们资源很多"，不给数据、不给案例 |

**规则**：烂发行比没发行更可怕。不要因为有人愿意聊，就把节奏交出去。

## 线下会和发行沟通：没有筹码就先不去

线下发行/投资/渠道会的价值取决于手里有没有能展示的筹码。概念阶段去参加，大概率只是重复去年“加微信 -> 发项目 -> 收到泛反馈 -> 回来焦虑”的循环。

值得去交流的筹码：

- 80% 完成度、能直接发包的小游戏 Demo。
- TapTap/Steam 等高意图平台出现明确预约、评论、愿望单信号。
- 真实玩家测试数据：完成率、留存、主动重开、反馈摘录。
- 买量或自然流数据能说明素材、产品或广告点有机会。

如果只有概念视频和少量预约，可以在线同步数据，等 Demo 出来再发包。不要为了“扩展视野”付出高时间和交通成本。
