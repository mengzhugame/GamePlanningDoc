# 游戏数据分析指标体系

## 来源: `10_流水/Openclaw知识库文件/data_analysis_guide.md` · 提取日期 2026-05-26

## 数据分析先服务决策，不服务报表好看

小游戏上线后的数据系统至少要回答三类问题：

| 问题 | 指标 |
| --- | --- |
| 用户有没有进来并理解玩法 | 新增、激活、首次游戏率、首局完成率、前 3 波 / 前 3 关通过率 |
| 用户有没有回来 | D1 / D3 / D7 / D30、Cohort 留存、回访频次 |
| 用户有没有商业价值 | 广告展示、广告点击 / 完播、ARPU、LTV、CPA、ROI |

不要只看 DAU、收入和新增。早期最关键的是把「获客 -> 首局 -> 失败点 -> 回访 -> 广告意愿」连成一条可解释漏斗。

## AARRR 在小游戏里的落地口径

| 阶段 | 看什么 | 小团队动作 |
| --- | --- | --- |
| Acquisition | CPA、点击、素材来源、新增 | 先小额验证素材，不把低 CPA 当成功 |
| Activation | 首次游戏率、前 3 波通过率、首局时长 | 修加载、教学、前 120 秒爽点 |
| Retention | D1 / D7 / D30、Cohort | 判断核心循环和短期目标是否成立 |
| Revenue | ARPU、广告触发、完播、广告后结果 | 广告只放在能解决当前卡点的位置 |
| Referral | 分享率、K 因子、战报传播 | 先做可截图 / 可转述的高光，不硬塞分享 |

核心公式仍然是 `LTV > CAC`，但早期不能直接用空想 LTV 证明买量可持续。必须按渠道 Cohort 追踪留存和收入。

## 留存曲线要看形状，不只看单点

| 曲线现象 | 常见含义 | 优先动作 |
| --- | --- | --- |
| D1 < 10% | 首局或核心玩法有致命问题 | 停止扩量，重修首局 |
| D1 10%-20%，D7 很低 | 体验勉强成立，但目标不足 | 加短期目标、失败复盘和回访理由 |
| D1 尚可，D3 掉光 | 玩懂了但没有继续计划 | 加局外成长、挑战、Build 探索 |
| D7 / D30 有长尾 | 有核心用户 | 找他们为什么留下，反向修新手漏斗 |

留存要按渠道、版本、Build 类型和注册日期分组看。全局平均会掩盖“某个渠道全是误触用户”或“某个 Build 让玩家更愿意回来”。

## LTV 用累积 Cohort 比拍脑袋更稳

早期最稳的 LTV 算法是按注册日期累加收入：

```text
LTV = 某 Cohort 在 D1 + D2 + ... + D30 的总收入 / 该 Cohort 新增人数
```

简化公式可以辅助估算，但不能替代 Cohort。尤其是 IAA 小游戏，广告收入、留存和局数强相关，单日 ARPU 很容易被渠道质量或偶发填充率扭曲。

分析时至少拆三张表：

| 表 | 用途 |
| --- | --- |
| 每日核心表 | 新增、DAU、花费、CPA、D1、D1 ARPU、LTV 预估、ROI |
| Cohort 留存表 | 按注册日期追踪 D1 / D3 / D7 / D30 |
| 渠道质量表 | 对比 CPA、D1、D7、LTV、ROI，决定是否加预算 |

## RFM 可改成游戏行为分层

小游戏不一定有高付费，但仍可以用 RFM 思路做玩家分层：

| 维度 | 游戏化口径 |
| --- | --- |
| R | 最近一次登录或最近一次游戏距离今天多久 |
| F | 过去 7 / 30 天玩了多少局 |
| M | 游戏时长、广告观看、付费或高价值行为 |

可复用分层：

| 玩家 | 判断 | 动作 |
| --- | --- | --- |
| 最近玩 + 高频 + 高价值 | 核心用户 | 少打扰，给挑战和身份感 |
| 久未回 + 曾高频 | 可召回用户 | 用新版本、回归奖励和新关卡召回 |
| 最近玩 + 低频 | 还没形成习惯 | 提供短期目标和下一局理由 |
| 低频 + 低价值 + 久未回 | 低成本处理 | 不为这类用户过度改产品 |

## 新手漏斗是上线第一周的优先级

推荐最小漏斗：

```text
广告点击 -> 激活 -> 登录 / 加载完成 -> 首次游戏 -> 通过第 3 波 -> 通过第 10 波 -> 次日回来
```

如果第 3 波前掉得厉害，通常是教学、操作、加载、首个反馈有问题；如果第 10 波掉得厉害，通常是难度峰值、Build 成型或失败反馈有问题。不要直接看总留存就调全局血量。

## 上线前三周复盘口径

| 周期 | 重点 | 动作 |
| --- | --- | --- |
| 第 1 周 | 新手体验、首局完成、D1 | 修教学、前 10 分钟、失败点 |
| 第 2 周 | Build 平衡、主流派使用率和留存 | 找过强 / 过弱组合，按数据改 |
| 第 3 周 | 买量 ROI、渠道质量、LTV | 调预算，不被低 CPA 诱惑 |

数据分析五步法：

1. 定义问题，例如 D1 < 20%。
2. 收集相关漏斗和行为数据。
3. 找到具体流失层级，例如第 10 波死亡率高。
4. 只改一个主要假设，例如降低第 9-10 波 EHP。
5. 用同一口径观察 3-7 天。

核心原则：趋势优先于单日波动，Cohort 优先于全局平均，AB 测试优先于主观争论。
