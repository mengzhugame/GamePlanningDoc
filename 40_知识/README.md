# 40_知识

## 这是什么

这里是长期知识层，只存放经过整理、验证、复盘或蒸馏后的内容。

## 分区

| 路径 | 用途 |
|------|------|
| `00_工作流/` | 创意验证 SOP、正式立项 SOP、原型、Demo、上线、复盘流程 |
| `01_游戏设计/` | 玩法、关卡、核心循环、付费点、立项铁律 |
| `02_引擎与技术/` | Unity、微信小游戏、技术模板、工程踩坑 |
| `03_美术与表现/` | AI 美术、风格统一、资源生产、表现反馈 |
| `04_音频与节奏/` | 音效、BGM、反馈、剪辑与资源搜索流程 |
| `05_数值与经济/` | 难度、广告点、经济系统、战斗数据分析 |
| `06_发行与运营/` | 买量、冷启动、发行商、上线数据复盘 |
| `07_游戏拆解库/` | 热门游戏和竞品拆解 |
| `08_软著与版号/` | 软著、版号、申请资料和踩坑 |

## 使用规则

- 不把 `10_流水/` 或 `30_市场分析/` 的原始材料直接当作知识。
- 项目内经验要经过复盘后再迁入这里。
- 文件应尽量有来源、适用场景、结论和行动建议。
