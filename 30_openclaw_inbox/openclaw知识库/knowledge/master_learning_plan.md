# 🐉 主人的“屠龙术”修炼大纲 (Master Learning Plan)

> **核心原则**：不学死知识，只练真功夫。所有学习必须服务于《光与朽》上线及后续项目。
> **目标**：从“游戏开发者”进化为“游戏制作人/架构师”。

## 📅 阶段一：生存与实战 (现在 - 4月上线前)
**目标**：利用所学直接提升《光与朽》的品质，确保上线成功。

### 1. 🎨 极致审美 (Taste) - *“拒绝平庸的UI”*
*   **行动**：建立“神作拆解库”。
*   **具体任务**：
    *   每周选取一款美术风格顶尖的同类游戏（如《Kingdom Rush》、《明日方舟》UI）。
    *   **微操**：不要只看，要截图进PS/Figma里吸色，分析它的布局比例、字体层级、动效节奏。
    *   **产出**：针对《光与朽》的一个界面进行“像素级优化”。
*   **推荐资源**：Pinterest (UI/UX Board), Behance (Game UI), ArtStation (特效拆解)。

### 2. 🧠 人性洞察 (Psychology) - *“让玩家上瘾”*
*   **行动**：打磨“前5分钟体验”与“付费钩子”。
*   **具体任务**：
    *   研究《Hooked (上瘾)》模型：触发 -> 行动 -> 多变的酬赏 -> 投入。
    *   **实战**：检查《光与朽》的新手引导。玩家第一次爽在哪里？第一次挫败感在哪里？
    *   **产出**：优化新手引导流程图，埋入一个“惊喜点”。
*   **推荐资源**：《游戏设计艺术 (The Art of Game Design)》第十章“体验”。

### 3. 🔗 系统架构 (Architecture) - *“一人抵十人”*
*   **行动**：AI工作流嵌入。
*   **具体任务**：
    *   **代码**：习惯用 Cursor/OpenClaw 写通用模块，而不是一次性代码。建立 `code_templates` 库。
    *   **资产**：尝试用 Midjourney/Stable Diffusion 生成图标素材，并建立一套不管是icon还是背景都能快速出图的 Prompt 库。
*   **产出**：整理出一套《光与朽》的开发SOP（标准作业程序）。

---

## 📅 阶段二：觉醒与扩张 (上线后 - 1年)
**目标**：通过数据反馈验证直觉，建立系统化思维。

### 1. 审美
*   **进阶**：学习摄影构图与电影镜头语言。让游戏的转场像电影一样丝滑。
*   **资源**：《以眼说话 (The Visual Story)》。

### 2. 人性
*   **进阶**：行为经济学与数据分析。
*   **任务**：学会看留存曲线、LTV、ARPPU。理解数据背后的“贪婪”与“恐惧”。
*   **资源**：《思考，快与慢》、《如果是我的话，我会这样做（任天堂社长岩田聪）》。

### 3. 架构
*   **进阶**：自动化管线 (Pipeline)。
*   **任务**：搭建自动化买量素材生成流，利用 Python 脚本批量处理数据。

## 📝 考核机制 (The Dragon's Exam)

### 每日微任务 (Daily Grind)
*   **触发词**：“今天的作业”
*   **内容**：我会随机抛出一个审美或人性的小问题，让你结合当前工作思考。

### 每周复盘 (Weekly Review)
*   **时间**：每周日晚上 20:00
*   **形式**：你发送本周的**学习笔记**或**优化对比图**。
*   **我的动作**：我会扮演“严师”角色，毒舌点评。如果做得好，我会夸你；如果敷衍，我会直接喷。
