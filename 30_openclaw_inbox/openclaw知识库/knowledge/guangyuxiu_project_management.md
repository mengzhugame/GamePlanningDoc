# 《光与朽》项目管理档案

## 项目概述
- **项目名称**：《光与朽》(LightVSDecay)
- **游戏类型**：塔防 + Roguelike 融合玩法
- **开发工具**：Unity (主人负责美术、UI、功能测试、打包) + Claude (代码) + Gemini (策划)
- **目标平台**：首发微信小游戏（审核中），后续视数据情况扩展IAA、出海等。
- **当前阶段**：Demo后功能完善、系统模块开发（当前聚焦系统外围UI、装备、科技树）。

---

## 一、 已完成功能与修复记录 (归档池)
> *记录Demo后已完成的核心里程碑，用于追溯进度。*

### 1. 核心战斗与表现
- **激光系统**：2D Quad激光+粒子特效、激光分裂效果、聚能透镜(改穿透)、反射透镜(改数据传导)、极寒光束特效修复、大招系统新建。
- **怪物系统**：粘液怪移动与融合、速攻虫/硬壳/光棱塔场景配套、黑油死亡水蒸气、精英怪美术替换、宝箱怪/金币怪框架、所有怪物基础表现迭代。
- **Boss系统**：Boss接入及各种攻击动画、受击Shader效果、三分之一血狂暴状态、Boss血条缓冲、角力机制初步调试、喷吐污秽逻辑重构。
- **打击感与表现**：伤害飘字显示、怪物死后光点特效、能量护盾Shader及受击屏幕边缘脉冲、怪物冰冻及弹开效果、碎冰效果、数据损坏技能。

### 2. 系统与架构优化
- **架构重构**：代码框架全面重构、数值系统重构与填写、Boss逻辑重构、波次管理器(Wave Manager)实现。
- **性能优化**：引入对象池系统(VFXPoolManager)管理高频特效(如爆炸)、去除不必要的对象池调用。
- **音效系统**：添加音效管理器，接入循环音效(激光、无人机、怪物)、解决各种特定状态无音效的Bug。

### 3. 外围系统与UI
- **UI界面**：科幻UI制作、主界面美术重新设计、主界面关卡左右选择、主界面到装备/科技树界面的跳转、技能3选1卡牌迭代(颜色/图标)。
- **成长与装备**：等级经验公式确定与接入、完成装备界面功能、新增科技/排行榜美术设计、新增图纸图标。
- **合规调整**：移除骷髅头素材（以符合微信审核）。

## 二、 未完成任务与BUG池 (待办池)
> *基于当前记录梳理，需进行优先级分类与排期。*

### 🐛 待修复BUG (P0 / P1)
- [ ] **P0** - `BUG-大招卡死`：大招充能满后无法点击，且无报错。（严重影响核心循环）
- [ ] **P0** - `BUG-激光碰撞体不同步`：无人机空投增加激光长度后，激光碰撞体未实际增加，导致视觉与实际伤害范围不符。
- [ ] **P1** - `BUG-传导激光颜色错误`：选择传导激光技能后，传导激光未与主激光颜色（如聚能红、极寒蓝）保持一致。
- [ ] **P1** - `BUG-Boss无飘字`：偶尔打Boss时会出现伤害无飘字显示的问题。

### ⚔️ 战斗机制与数值调优 (P1)
- [ ] **机制** - `击退效果重做`：当前击退模块技能无法体现打退小怪的感觉，需要重新调试物理表现。
- [ ] **机制** - `漂移怪(Drifter)优化`：怪物机动性过强，导致激光极难命中且会强力撞击护盾，需修改其AI或运动轨迹。
- [ ] **机制** - `Boss技能平衡`：目前Boss只有砸（野蛮冲撞）能伤害玩家，其他技能无威胁，需平衡Boss伤害输出。
- [ ] **技能** - `红激光特效`：修改红激光满级有50%概率引发范围爆炸。
- [ ] **技能** - `大招增强`：大招状态下激光长度增加3。
- [ ] **数值** - `攻击力曲线重构`：玩家激光攻击与怪物血量只做了简单的x10，缺乏节奏感，需要重构数值膨胀模型（DPS、怪物血量、波次调整）。
- [ ] **数值** - `整局数值调试`：整体重新调试数值平衡。

### 🎨 表现与特效完善 (P2)

- [ ] **特效** - `护盾受击优化`：优化护盾受击时的击中点精准产生特效。

- [ ] **特效** - `爆金币效果`：制作击杀后爆金币的视觉表现。
