## 第二章（熔岩/火山主题）怪物设计规范与归档
**核心原则**：纯 2D 矢量赛璐璐风格（2D vector art, cell shading），极其干净的外轮廓。严禁拟人化（不要手脚、不要头），严禁 3D 渲染感。必须符合 Unity 中 4 层拆分架构（底图流体 RT、特效层、挂件装甲层、眼睛层）。

**已敲定设计的怪物图鉴：**
1. **熔岩分裂怪 (Lava Splitter)**：机制为死后分裂 3 个小怪。剪影为倒三角/宽底座，带有滴落感，体内含 3 只眼睛或 3 块黑曜石核心。
2. **熔岩自爆怪 (Lava Bomber)**：机制为自爆并留下减速/减伤的岩浆斑。剪影为极度膨胀的球体，表面黑岩壳严重龟裂透出高热光芒，单只疯狂大眼。
3. **熔岩重甲/坦克怪 (Lava Tank)**：机制为超高血量的肉盾。剪影为极其厚重、边缘磨圆的巨型方块（Rounded Square），表面覆盖大块黑曜石装甲板，装甲缝隙透出两只大眼。
4. **熔岩炮手怪 (Lava Spitter)**：机制为远程发射。剪影为水滴形/锥形，前端有一个明显的边缘坚硬的“火山口”发射口（蓄力高亮），眼睛在发射口后方。
5. **精英怪变体 (Elite)**：不能只放大，要增加危险特征（如更多眼睛、高耸背刺）或临界高热状态（亮蓝/白炽色内核，悬浮碎裂的外壳）。
6. **熔岩巨兽 Boss (The Magma Furnace)**：
   - 绝不可违背 4 层分离逻辑。放弃拟真山体和肉壁大嘴。
   - 整体为一个巨大坚不可摧的六边形/盾形底盘（基础流体层）。
   - 正中心是一个巨大的正圆形白炽光核心（特效层），用于吸怪和对波。
   - 表面覆盖巨大对称的几何切割黑曜石厚板（装甲层），上面有散热孔用于发射陨石。
   - 装甲上方横向排列 3 只冷酷的发光眼（眼睛层）。
   - 极具整体感与 Boss 压迫感。
