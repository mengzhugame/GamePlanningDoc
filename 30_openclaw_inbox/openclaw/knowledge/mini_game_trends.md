# 小游戏玩法与题材趋势库

## 2026-04-30｜每周小游戏趋势调研

### 结论先说
- **微信小游戏**：头部仍由中重度 IAP 驱动，核心是“塔防/射击肉鸽/SLG/修仙养成”与长期数值付费。
- **抖音小游戏**：轻度/混合休闲明显更强，核心是“模拟经营/二合/消除/轻塔防 + 爽文/逆袭/女性向/沙雕短剧包装”。
- **海外超休闲/混合休闲**：下载王还是极简高复玩 Puzzle，但商业化正在往 **Hybridcasual Puzzle / Merge / Sort / Screw / Block Puzzle** 倾斜。
- **下一款优先方向**：不是再做传统重养成，而是做**3 秒看懂的视觉动词 + 强题材包装 + 轻中度成长**。主人最该盯的是 **微恐/逆袭/女性向经营/视觉解压 Puzzle** 四条线。

### 一、榜单与头部样本
#### 1）微信小游戏（参考 2026 年 3 月底榜单对比）
- 畅销 Top10：`向僵尸开炮 / 三国：冰河时代 / 无尽冬日 / 曙光重临 / 时光大爆炸 / 寻道大千 / 百炼英雄 / 灵画师 / 口袋奇兵 / 青云诀之伏魔`
- 结构判断：微信 Top10 里大部分是**中重度 IAP 产品**，题材集中在 **末日生存、三国/战争、修仙、英雄成长、塔防肉鸽**。
- 强势共性：
  - 长线成长 + 战力数值驱动
  - 强目标感（推关/守城/扩张/抽卡/构筑）
  - 题材辨识度高：末日、三国、修仙仍然吃香

#### 2）抖音小游戏（36Kr + DataEye + 新浪转引）
- 抖音畅销 Top10：`灵画师 / 向僵尸开炮 / 抓大鹅 / 跃动小子 / 时光杂货店 / 次神光之觉醒 / 浪漫餐厅 / 一步两步 / 百炼英雄 / 人类无限进化`
- 对比结论：Top10 仅 `向僵尸开炮 / 灵画师 / 百炼英雄` 与微信重合，说明**抖音和微信已经是两套玩法审美**。
- 抖音 Top100 中：**76 款为轻度产品，24 款为重度产品**；轻度主力品类为**塔防、模拟经营、消除**。
- 女性向/叙事经营样本：`浪漫餐厅 / 四季合合 / 梦幻旅行 / 守护世界 / 此生无白`
- 抖音平台数据：
  - 抖音小游戏用户 **超 1 亿**
  - 过去一年 **DAU +100%**
  - **流水 +130%**
  - **预付费人数 +320%**
  - 2026 年 2 月投放素材量 **超 324 万**，在投游戏 **超 1.2 万款**
- 头部案例：
  - `我的花园世界`：2 月 16 日登顶抖音畅销榜；春节期间**用户规模增长 3 倍**；#玩游戏送真花 话题播放 **27.3 亿**；官方直播间 PCU **破万**。
  - `疯狂水世界`：2 月抖音畅销榜 **第 4**，较 1 月提升 **13 名**；热投素材中 **AIGC 占比超 70%**。
  - `抓大鹅`：绑定节日热点，#抓大鹅助力好运开年 话题播放 **540 万+**。

  - 极简规则

  - 中后段成长/装修/经营/收集包裹层

### 二、当前最火玩法分类
#### A. 微信强势玩法
1. **射击/塔防 + 肉鸽构筑**
   - 代表：`向僵尸开炮`
   - 爆点：割草清屏、Build 波动、失败后再来一局的成长期待
   - 吸量点：僵尸潮、爆炸、数字飞升、技能组合
2. **SLG/末日生存/战争经营**
   - 代表：`无尽冬日 / 三国：冰河时代 / 口袋奇兵`
   - 爆点：扩张、建设、联盟、长期留存
   - 变现点：强 IAP、长期数值线
3. **修仙/古风放置成长**
   - 代表：`寻道大千 / 青云诀之伏魔 / 灵画师`
   - 爆点：境界突破、抽取养成、轻操作高成长反馈
4. **英雄养成 + 放置/轻战斗**
   - 代表：`百炼英雄 / 曙光重临`
   - 爆点：低门槛、养成驱动、强数值爽感

#### B. 抖音强势玩法
1. **二合 / 消除 / 模拟经营混合体**
   - 代表：`浪漫餐厅 / 四季合合 / 梦幻旅行`
   - 爆点：轻操作 + 剧情逆袭 + 女性代入
   - 吸量点：爽文桥段、破产翻身、装修前后反差
2. **轻塔防 / 轻割草 / 一键成长**
   - 代表：`向僵尸开炮 / 跃动小子 / 次神光之觉醒`
   - 爆点：短视频一眼看懂、战力飞升、连续奖励
3. **猎奇/社交传播型 IAA**
   - 代表：`抓大鹅`
   - 爆点：魔性、讨论感、节日话题绑定、低理解门槛
4. **逆袭/短剧叙事模拟器**
   - 代表：`我真没想逆袭啊 / 楚新钓 / 小心有诡 / 此生无白`
   - 爆点：剧情先行，玩法兜底；用户像在“刷短剧并顺手点玩”

#### C. 海外强势玩法
1. **Block / Sort / Screw / Logic Puzzle**
   - 爆点：单手操作、规则极简、连续过关、广告变现稳定
2. **Merge-2 + 经营/剧情壳**
   - 爆点：低认知负担、任务驱动强、可接中度 IAP
3. **轻经营/餐厅/装修/收纳 + 元进程**
   - 代表下载型样本：`Pizza Ready!`
   - 爆点：工位扩张、流水增长、轻自动化
4. **经典 Hypercasual 动词 + 中层成长壳**
   - 代表：`Hole.io` 这类吞噬/体量成长逻辑仍长期有效

### 三、当前最热题材偏好
#### 微信题材热区
- **末日/僵尸/废土生存**：吸量稳，适合塔防、射击、SLG
- **三国/战争策略**：适合中重度长线
- **修仙/玄幻/古风神怪**：低成本高包容，天然适合放置与成长
- **英雄/魔幻冒险**：适配轻养成和放置

#### 抖音题材热区
- **女性向逆袭/餐厅/装修/旅行**：和短视频传播天然契合
- **爽文打脸/都市翻身/底层逆袭**：CTR 强，用户代入快
- **沙雕短剧 / 网感猎奇**：容易破圈
- **中式微恐**：`无限轮回 / 咻咻勇者 / 小心有诡` 证明微恐正在从单点噱头变成可泛化题材

#### 海外题材热区
- **弱题材强动词**仍然有效，但更吃包装清晰度
- **家居/整理/餐厅/收纳/装修**：最容易承接轻经营
- **玩具感/积木感/颜色分类**：极适合 Puzzle 与短视频素材

### 四、收益预估与留存/吸量点判断
#### 微信
- **高收益带**：塔防肉鸽、末日 SLG、修仙养成、战争经营
- **判断**：虽然具体流水未公开，但从畅销榜结构看，微信仍是**高 ARPU / 长线留存 / 中重度 IAP** 主导。
- **留存钩子**：章节推进、Build 成长、抽卡、联盟、境界突破
- **吸量钩子**：僵尸潮、末日城建、修仙飞升、三国题材认知红利

#### 抖音
- **高效率带**：轻玩法 + 爽文题材 + 高密度素材投放
- **判断**：抖音不是不要付费，而是要先靠**题材和素材点开率**拿流量，再靠轻成长承接。
- **留存钩子**：剧情翻身、装修焕新、经营升级、短局反复成功
- **吸量钩子**：代入冲突、前后反差、猎奇反转、直播话题、AIGC 素材量产

#### 海外
- **高下载带**：Block Puzzle / Sort / Screw / 轻经营 / 吞噬成长
- **高收入带**：Puzzle、Merge、Hybridcasual Puzzle
- **留存钩子**：超短局成功、低失败惩罚、持续解锁、装饰/经营元层
- **吸量钩子**：看图即懂、单手操作、颜色分类、空间整理、数字膨胀

### 五、爆款密码（玩法 + 题材）
1. **轻玩法必须套强包装**
   - 现在不是“玩法新就赢”，而是**玩法熟 + 题材猛 + 素材强**更容易赢。
2. **抖音吃“剧情点开率”，微信吃“系统留存率”**
   - 抖音先看素材和爽文包装；微信先看成长深度和付费线。
3. **视觉动词比世界观更重要**
   - 切割、堆叠、合成、吞噬、清洁、旋转、分类、扩张，这些动词仍是最稳的跨平台语言。
4. **题材正在两极化**
   - 一边是 **末日/修仙/战争** 这种长线数值壳；另一边是 **女性逆袭/微恐/沙雕短剧** 这种传播壳。
5. **纯超休闲死不了，但必须混合化**
   - 海外和抖音都在证明：仅靠纯广告冲量越来越难，必须加成长、任务、经营、装修或收集层。

### 六、给主人的立项建议（直接可用）
#### 最值得试的 4 条方向
1. **微恐 + 轻塔防/解谜/合成**
   - 优点：题材有新鲜红利，素材容易出钩子
2. **女性向逆袭 + 二合经营/装修**
   - 优点：抖音传播强，低成本验证快
3. **视觉解压 Puzzle（Block/Sort/Screw）+ 中层经营**
   - 优点：海外验证强，也适合主人做视觉反馈护城河
4. **废土/僵尸 + 旋转/切割/清屏型轻肉鸽**
   - 优点：兼容主人 TA 强项，容易做出短视频级视觉爽点

#### 不建议的坑
- 纯文字/纯剧情模拟器：题材热，但生命周期短
- 纯重度 SLG：赚钱，但一人开发风险太高
- 只靠世界观、没有 3 秒动词的概念：大概率扑街

### 七、适合主人复用的机制清单
- 首局 10 秒给出一次“大清屏/大整理/大翻新”强反馈
- 用 `章节任务 + 轻成长树 + 保底解锁` 承接留存
- 所有素材都围绕一个视觉动词：`切 / 合 / 吞 / 旋 / 分 / 堆 / 喷`
- 题材包装优先选：`微恐 / 逆袭 / 废土 / 女性经营`
- 抖音版本优先准备：`剧情冲突素材 20 条 + AIGC 变体 100 条`
- 若走微信，必须从 Day1 就设计：`付费成长线 + 次留钩子 + 长线目标`
