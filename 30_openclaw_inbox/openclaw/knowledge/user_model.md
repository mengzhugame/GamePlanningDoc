# 用户模型

最后更新：2026-05-02

## 长期稳定画像
- 主人是技术美术出身的独立游戏开发者，长线目标不是单做一款游戏，而是建立可持续的一人游戏创业验证系统，最终创建游戏公司。
- 当前最核心的方法论主线是：市场素材信号 -> AI 视频反向立项 -> 7天垂直切片 -> 陌生用户测试 -> 小额买量/发行合作 -> 决定是否公司化。
- 对情报与知识沉淀的硬要求是：必须说明用途、决策相关性、行动价值；不能为了收集而收集。
- 默认工作平台与通知主阵地是 Discord，并通过分频道隔离不同工作上下文。

## 决策偏好
- 强偏好用真实数据和可验证证据做判断，不喜欢只凭感觉拍板。
- 评估项目时，更看重能否形成验证闭环，而不是概念是否好听。
- 对新方向的容忍前提是：能快速做小样本验证，过线再加码，不过线及时砍。
- 【2026-04-27 新增】做买量/渠道判断时，偏好“产品后台 + 投放后台”交叉验证，不接受只看单一面板下结论；当前最典型组合是微信小游戏后台 + 腾讯广告后台。
- 【2026-05-02 新增】近期明显偏好“先建统一标尺/模板，再比较、筛选和放量”；能统一换算的先统一换算，比如 EffectiveDPS、有效CAC、D1-D7预测LTV、7天回本线，而不是每条线都靠临场感觉拍板。

## 当前关注重点
- 《光与朽》已上线，当前关注重点不是继续堆功能，而是验证留存、爽点密度、渠道质量、买量可行性与商业闭环。
- 下一阶段重点是围绕 AI 视频、轻量休闲/解压/塔防方向做7天垂直切片，并尽快接入陌生用户测试。
- 【2026-04-27 新增】近期对《光与朽》的注意力明显前移到“渠道真实性判断、买量优化、广告侧数据补全”这一层，说明商业验证优先级正在高于泛复盘。
- 【2026-05-02 新增】当前素材验证形态进一步收束到“首秒抓人 + 10秒模板化批量实验”，尤其适合激光、Boss、清屏这类能快速切成传播单元的内容。

## 沟通与协作习惯
- 需要结论先行、废话少、能直接落地的建议。
- 愿意让 AI 继续深挖具体问题，但前提是结果能服务当前决策，而不是泛泛学习。
- 重要事项适合按频道分流，减少上下文污染。
- 【2026-04-27 新增】开始主动验证 Discord 内的角色提醒/消息触达，说明关键结果、异常和待决策事项应尽量保证“可提醒、可追踪、不会被淹没”。
- 【2026-05-01 新增】对回复完整性、消息投递可靠性、错误根因解释更敏感；不接受“任务失败”这种混合表述，更适合把产出失败、外网失败、投递失败分层说清。

## 禁忌与风险点
- 反感无用途的信息堆积，尤其是不能进入行动闭环的资料。
- 不希望在留存与核心体验尚未成立前，过早假设商业闭环已经成立。
- 不喜欢多线程乱开工；更接受短周期、强验收、可复盘的推进方式。
- 【2026-05-01 新增】对偏离当前主线的例行学习/并行任务容忍度更低；一旦判断不值钱，会直接要求停掉，不希望持续占用注意力。
