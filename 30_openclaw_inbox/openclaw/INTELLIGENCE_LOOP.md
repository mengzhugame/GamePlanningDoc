## 三、采集任务的合格标准

每条情报必须包含：

- `source_url`：原始链接，无法提供则说明原因。
- `topic_hint`：建议归属主题。
- `evidence_type`：行业数据 / 竞品案例 / 素材样本 / 平台规则 / 工具方法 / 个人观察。
- `decision_relevance`：它能辅助哪个决策，例如立项、买量、素材、IAA、软著、发行合作。
- `actionability`：high / medium / low。
- `distill_priority`：P0 / P1 / P2 / archive。
- `next_use`：下一步如何使用，例如“进入 AI 视频素材实验 Top 20”、“等待 `/distill` 合并到发行方法论”、“仅作背景观察”。

如果无法填写这些字段，说明这条信息大概率只是噪音，不应进入高优先级清单。

```markdown

- 是否值得人工阅读：是/否
- 是否值得进入 `/ingest-claw`：是/否

```

这节是为了防止“采集完成但没人使用”。

## 六、小游戏视频雷达特殊规则

当任务是收集小游戏、解压、休闲玩法视频时，不要只搜“最火/最热门”。

采用分层采样：

- 平台：抖音、小红书、B 站；必要时补 TikTok、YouTube Shorts、Instagram Reels。
- 搜索词：品类词 + 核心动词 + 用户情绪词。
- 核心动词示例：切割、清洁、旋转、合成、破坏、吸附、堆叠、吞噬、喷射、弹射、收纳。

每条视频额外记录：

- 疑似核心动词
- 视觉风格
- 爽点来源：操作 / 反馈 / 题材 / 数值成长 / 猎奇 / 剪辑
- 是否像真实游戏，还是纯广告素材
- 评论里是否有人问“在哪玩/游戏名/想玩”
- 是否适合小龙儿 TA 能力实现
- 是否适合做 7 天垂直切片
- 初步评分：1-5

最终只给 Top 20 候选，不直接给立项结论。

## 七、反噪音规则

以下内容默认降级：

- 只有情绪标题，没有原始链接。
- 只有大盘判断，没有具体数据或案例。
- 只适合大团队，不适合一人开发者。
- 无法服务当前 90 天目标：素材测试、7 天垂直切片、小额买量、发行合作。
- 和正式知识层已有结论重复，但没有新增证据。

---

## 八、当前 90 天主线

openclaw 的情报优先服务这条链路：

`市场素材信号 -> AI 视频反向立项 -> 7 天高质量垂直切片 -> 陌生用户测试 -> 小额买量/发行合作 -> 决定是否公司化`

如果情报不能帮助这条链路前进，就不要占用高优先级。
