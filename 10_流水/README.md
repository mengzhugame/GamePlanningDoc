# 10_流水/ — 每日 append-only 流水层

## 这是什么

参考 Karpathy 的 `append.md` 思路：**今天想到的任何东西都先写在这里，不分类、不修改历史、不追求结构**。等到周末，由 `/distill` skill 把这周的流水蒸馏到 `40_知识/` 里做成 schema 化的知识条目。

## 命名约定

- 一天一个文件：`YYYY-MM-DD.md`
- 文件顶部用 frontmatter 标 `date` 和 `type: daily-log`
- 每条内容用 `## HH:MM 标题` 起头

## 什么东西该写进这里

- 临时灵感、设计念头（哪怕只有一句话）
- 读到一篇文章的笔记摘录
- 和 AI 对话中冒出的 key insight
- 调试过程中的奇怪现象
- 某个数值试出来的结果

## 什么东西**不**写这里

- 项目正式文档（写进 `20_项目/NN_XX/`）
- 已经沉淀好的知识条目（写进 `40_知识/`）
- 外部工具抓的资料（先进 `30_openclaw_inbox/`）

## 为什么这么设计

人写东西分两种状态：**涌现** 和 **整理**。混在一起做两件事会互相打架——整理时总想回头改涌现的原话，涌现时又受格式约束不敢写脏。分开后，流水层负责接住所有原始素材不丢失，蒸馏层负责做结构化的二次加工。
