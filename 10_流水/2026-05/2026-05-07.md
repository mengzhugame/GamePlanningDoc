你这几个问题问得很准。我的判断是：**原来的 60 秒适合概念视频，不适合真实游戏主关卡。** 真实 Demo 应该改成：

> **3 分钟标准倒计时 + 3 个关键证物 + 1 次指认。**  
> 后期困难关可以到 4-5 分钟，但第一版不要超过 3 分钟。

**时间设计**

60 秒太短，会让玩家只顾乱点，侦探感出不来。3 分钟比较合理：

| 关卡阶段 | 时间 |
| --- | --- |
| 观察场景 | 20-30 秒 |
| 找第 1 个证物 | 30-40 秒 |
| 找第 2 个证物 | 40-50 秒 |
| 找第 3 个证物 | 40-50 秒 |
| 指认嫌疑人 | 15-20 秒 |

UI 上不要写得太死，可以叫 **“调查倒计时”** 或 **“现场封锁进度条”**。时间到不是马上死亡，而是弹出：`调查时间结束，是否观看广告延长 60 秒？`

**工具设计**

底部不应该是“每个工具只能用一次”。这会把游戏变成猜谜，而且一旦用错就死，很不休闲。

我建议底部固定 3 个核心工具，但它们不是消耗品：

| 工具 | 定位 | 是否限制 |
| --- | --- | --- |
| 手 / 普通点击 | 翻开、拉开、打开、移动物品 | 无限 |
| 放大镜 | 看细节：脚印、划痕、纤维、小物件 | 无限，但有 1 秒短冷却 |
| 紫外灯 | 看隐藏痕迹：指纹、口红印、暗纹、液体残留 | 有电量条，自动恢复 |
| 指纹粉 / 提示 | 强提示或直接高亮关键区域 | 限次数，广告点 |

也就是说：**通关必要工具不能硬限制次数，广告工具才限制次数。**

否则你说的问题会成立：如果紫外灯只能用一次，玩家扫错了，就无法通关。这是设计雷区。

**证物提示问题**

证物不能一直明亮提示，那太简单；但也不能完全无提示，那会变成乱点。

最好的方案是三层提示：

1. **弱视觉异常**：地毯鼓起、窗帘缝隙透光、酒杯颜色不自然。
2. **工具后显现**：放大镜扫到脚印，紫外灯扫出口红印。
3. **广告强提示**：直接圈出“可疑区域”。

所以平时不直接发光，只给“可疑感”。玩家靠观察和工具验证。广告提示才给强高亮。

**付费/广告点**

广告点不要卖“必要操作”，要卖“救命和省时间”：

| 场景 | 广告点 |
| --- | --- |
| 时间快到 | 看广告 +60 秒 |
| 卡住找不到 | 看广告高亮一个可疑区域 |
| 紫外灯没电 | 看广告立刻充满 |
| 指认错了 | 看广告获得一次重新指认 |
| 连续失败 | 看广告自动排除一个错误嫌疑人 |

这样不会让玩家觉得“不给钱不给过”，但商业点足够清楚。

**剧情结算**

你说得对，**每关做视频不靠谱**。30 关就是 30 段视频，包体、制作、人力全爆。

我建议用这套低成本结算：

> **证据板动画 + 嫌疑人立绘抖动 + 文字真相 + 1 个可复用 Spine 动作。**

结算流程：

1. 三个证物卡飞到证据板。
2. 红线自动连起来。
3. 嫌疑人卡片翻转 / 震动 / 变红。
4. 弹出 3-5 行文字真相。
5. 播一个通用动画：侦探拍桌、嫌疑人低头、案件盖章。

每关只需要：

- 1 张场景图
- 3 个证物小图
- 3 个嫌疑人头像或立绘
- 1 段文字真相
- 通用证据板动画

这就能量产 30 关。

**我建议的新核心规则**

最终可以收束为：

> 玩家在 3 分钟内调查一个 2D 案发现场，通过点击场景、使用放大镜和紫外灯找出 3 个关键证物。工具本身不消耗，但时间、电量和提示次数有限。证物集齐后进入证据板，玩家根据 3 条证据从 3 个嫌疑人中指认真凶。失败后可通过广告获得加时、提示或重新指认。

这比“60 秒 + 三个工具各用一次”稳很多，也更像能上线的小游戏。  
概念视频里仍然可以说“最后 60 秒翻案”，但真实关卡底层建议按 **3 分钟标准局** 来设计。

**推荐关卡 UI**

顶部：

- 左上角：暂停按钮
- 顶部中间：倒计时横条，建议显示 `03:00`
- 横条下方或右侧：`关键证物 0/3`

底部：

- 底部左/中：3 个证物槽位，初始是问号卡片
- 底部右：3 个工具按钮：放大镜、紫外灯、提示灯泡

不要完全学 `Find Out` 那种“底部灰色物品清单”。我们不是找指定物品，而是找证据。可以给玩家看：

> `证物 0/3` + 三个问号卡：`时间线索 ?`、`接触线索 ?`、`逃离线索 ?`

这样既有目标，又不剧透“找怀表、酒杯、脚印”。

**工具规则**

| 工具 | 规则 | 广告点 |
| --- | --- | --- |
| 普通点击 | 无限使用，翻开/拉开/打开物件 | 无 |
| 放大镜 | 无限使用，最多 1 秒短冷却，主要防狂扫 | 无或弱广告 |
| 紫外灯 | 不建议 10-15 秒硬冷却，改成“电量条”：连续使用 5 秒，自动慢慢恢复 | 看广告立刻充满 |
| 提示灯泡 | 点击后弹窗：看广告获得提示 | 看广告圈出一个未找到证物的可疑区域 |

提示灯泡不要一次性让所有证据高亮。太强了，等于“广告直接通关”。建议分层：

1. 第一次提示：圈出一个大区域，比如书桌附近。
2. 第二次提示：高亮一个具体物件，比如酒杯。
3. 第三次提示：直接显示该证物交互方式，比如“用紫外灯扫酒杯”。

**证据板怎么出现**

我建议流程是：

1. 玩家找到第 1 个证物，证物从场景飞到底部证物槽。
2. 找到第 2 个，飞到第二个槽。
3. 找到第 3 个，飞到第三个槽。
4. 底部证物槽向上展开，变成半屏或全屏“证据板”。
5. 工具栏暂时隐藏。
6. 弹出 3 个嫌疑人卡片，玩家指认。

也就是说，调查阶段底部是“证物槽 + 工具栏”；结算阶段才展开成证据板。

**红线是否必须**

红线可以去掉，但我建议保留为一个很轻的 UI 动画，不要在场景中连，在证据板里连。

红线的意义是：让玩家一眼知道“这 3 个证物组成了一条推理链”。例如：

`怀表` → `死亡时间矛盾`  
`酒杯口红` → `有人说谎`  
`窗台脚印` → `逃离路线`

但第一版 Demo 不需要做复杂逻辑。可以只是证物卡之间自动连一条红线，然后盖章：`证据链成立`。如果觉得画面乱，红线可以换成更简单的“3 张证物卡依次点亮”。

**以后是否需要多个证据**

需要，但第一版建议固定：

> **每关 3 个关键证物。**

后期可以扩展：

| 关卡阶段 | 证物数量 |
| --- | --- |
| 新手关 | 2 个 |
| 标准关 | 3 个 |
| 困难关 | 4 个 |
| Boss 案件 | 5 个 |

UI 必须显示数量，例如：`关键证物 1/3`。否则玩家不知道还差多少，会焦躁。

**嫌疑人表现**

你说得对，通用“嫌疑人低头”不能用具体男女高矮胖瘦。最省成本方案是：

- 嫌疑人卡片用当前案件头像。
- 结算动画用通用黑影。
- 正确指认后，黑影低头、卡片变红、盖章“已指认”。

这样每关只需要换头像和文本，不需要做 30 套嫌疑人动画。

我建议最终规则定成：

> 每关 3 分钟，找 3 个关键证物。玩家可无限普通点击和放大镜检查，紫外灯有电量，提示灯泡通过广告获得线索。证物飞入底部证物槽，集齐后展开证据板，自动点亮证据链，再从 3 个嫌疑人中指认。剧情结算用文字 + 通用黑影 Spine 动画，不做逐关视频。
