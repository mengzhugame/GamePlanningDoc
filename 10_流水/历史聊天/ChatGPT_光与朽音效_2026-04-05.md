## 3️⃣ 制作思路与教学步骤（示例）

### Step 1 — 点击音制作（Click_Cosmetic）

🎯 **目标**：制造“清脆、轻盈”的点击反馈
🧠 **心理原理**：短瞬态 + 高频强调，能刺激多巴胺形成即时满足
🛠️ **制作方法（Reaper / Audition）**：

* 用玻璃或塑料点击音素材（如“tap_plastic_01.wav”）
* 高通滤波：Cut below 300Hz
* 压缩器：Attack 5ms / Release 100ms
* 加一点 transient enhancer 提高击发感
  ⚙️ **响度控制**：Normalize -1.0dBFS
  🔊 **导出参数**：44.1kHz / 16bit / Mono / WAV
  ⚠️ **常见问题**：声音太“尖锐”可在5kHz削1~2dB。

---

### Step 2 — 飞入槽位音（Slot_In / Pack_Fly_In）

🎯 **目标**：制造“吸入-落点”的动线感
🧠 **原理**：短“whoosh”后叮声，模拟完成动作闭合
🛠️ **制作方法**：

* Layer1：短“air woosh”或“bubble fly”素材
* Layer2：轻“ding”或“chime”结尾
* 合成：在Logic Pro中Fade交叉重叠50ms
  ⚙️ **EQ**：低切200Hz，Boost 3kHz 约+3dB
  🔊 **导出建议**：WAV Mono，时长0.4~0.6s
  ⚠️ **错误修复**：若声音断尾，可加Tail 200ms淡出。

---

### Step 3 — 成功与失败音（Level_Success / Fail）

🎯 **目标**：结算时的情绪归因，成功要“闪亮”，失败要“柔和”
🧠 **原理**：Pitch上扬 = 胜利预期；Pitch下坠 = 温和失败
🛠️ **制作方法**：

* 成功：三音阶 C–E–G，Bell系合成音（用Ableton Operator或FM合成）
* 失败：低通处理 + Reverb长尾 (Decay 0.8s)
  ⚙️ **响度差异**：Success -3dB；Fail -8dB
  🔊 **导出建议**：44.1kHz / Mono / WAV
  ⚠️ **常见问题**：避免成功音过长（>1.2s）导致节奏断层。

# 🧪 SFX_Enemy_Split_Death

**分裂怪死亡 · 气泡爆裂 + 滚烫液体飞溅**

---

## 🎯 用途定位

* **用途**：分裂怪死亡瞬间 → 生成小怪
* **语义**：
  👉 *“爆开 → 分裂 → 危险升级（但爽）”*
* **情绪目标**：

  * 轻爽（Pop）
  * 生化（Wet）
  * 有一点“热感”
* **时长**：0.3 – 0.6 秒
* **播放方式**：One-shot（不可 Loop）

---

## 🧠 心理设计关键点

这个音效必须同时满足：

| 维度 | 要求            |
| -- | ------------- |
| 爽感 | 有“啵”的瞬间释放     |
| 信息 | 明确“分裂了”       |
| 风格 | 不恶心、不血腥（海外可用） |

👉 核心不是“爆炸”，而是**“张力释放”**

---

## 🎧 声音结构拆解（强烈推荐 3 层）

---

### 🔹 Layer 1：气泡爆裂核心（决定爽感）

> “啵”的来源

* 短、弹性
* 带一点低频空气

**关键词**

```

goo pop
soft burst
```

---

### 🔹 Layer 2：浓稠液体飞溅（关键差异点）

> 让它不是普通 Pop

* 粘稠感（slime）
* 带“拉扯 → 甩开”

**关键词**

```
slime splat
goo splash
wet impact
```

---

### 🔹 Layer 3：高温蒸汽 / sizzling（“热”的感觉）

> 提升独特性（非常加分）

* 高频轻 sizzle
* 很短（<150ms）

**关键词**

```
sizzle
hot liquid
steam burst
```
