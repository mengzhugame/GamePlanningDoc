推荐算法：1秒累积重置法

代码逻辑：

C#
// 在 WaveManager 或 StatisticsManager 中
private float _currentSecondDamage = 0f;
private float _dpsTimer = 0f;
public float PeakDPS { get; private set; } = 0f;

public void OnDamageDealt(float damageAmount)
{
    _currentSecondDamage += damageAmount;
}

void Update()
{
    _dpsTimer += Time.deltaTime;
    if (_dpsTimer >= 1.0f)
    {
        // 1. 结算这一秒的伤害，看看是不是历史新高
        if (_currentSecondDamage > PeakDPS)
        {
            PeakDPS = _currentSecondDamage;
        }
        
        // 2. 重置，开始记录下一秒
        _currentSecondDamage = 0f;
        _dpsTimer = 0f; // 或者 _dpsTimer -= 1.0f 以保持精确时间
    }
}
为什么这样做？ 你的流派A（爆炸流）是瞬间爆发。如果你用滑动窗口平均，数据会被摊平。我要看的就是那一瞬间的**“数值尖峰”**，因为它代表了你处理“怪海”的上限能力。
