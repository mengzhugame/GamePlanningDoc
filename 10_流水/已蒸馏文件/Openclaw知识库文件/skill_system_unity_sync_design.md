# 《光与朽》技能系统文档 (基于 Unity 实机配置优化版)

> **同步日期**: 2026-03-13
> **基准来源**: 结合 Unity 工程当前配置与玩家反馈的最终修订版

## 一、当前流派生态 (实机版)
目前的 Unity 实际配置已经演化为更加成熟的三个流派：
1. **穿透爆发流 (Focus + Power + Crit)**：主打无限穿透与高额面板，适合打一条直线上的怪潮和 Boss。
2. **闪电风暴流 (Chain + Prism + Wide)**：利用激光变宽增加命中率，通过分裂和传导形成全屏电网，清杂无敌。
3. **极寒碎冰流 (Frost + Shatter + 【新增第三技能】)**：利用减速和冰冻控场，再通过特定被动打出极高的条件增伤和冰爆。

## 二、核心迭代与优化方案

### 🔴 1. 极寒流派机制重构：前置解锁池 (Prerequisite Pool) 与 状态联动 (Synergy)
**现状与痛点**：目前极寒光束与寒霜蔓延存在功能同质化（纯叠加减速），且原“数据破碎”技能存在“寄生设计”问题（必须依赖极寒光束才能生效，否则污染技能池）。
**重构方案：冰系流派完美闭环**
采用“前置标签解锁逻辑”。只有当玩家明确选择了冰系基础技，才会将后续的冰系衍生技能加入随机池，避免污染前期卡池，极大提升玩家凑齐“套装羁绊”的爽感。

1. **基础技【极寒光束】（Base）**：
   * 默认存在于初始技能池中。
   * **机制**：持续照射单体，高频伤害并快速叠加直到将单体【彻底冰冻】（硬控点杀）。
   * **系统逻辑**：一旦玩家选择此技能，系统打上隐藏的 `[Ice]` 标签，解锁后续冰系衍生技卡池。

2. **衍生技A【寒霜蔓延】（状态传染）**：
   * **解锁条件**：需拥有 `[Ice]` 标签。
   * **机制**：由自身发射群体减速改为“传染引擎”。每当极寒光束将一个敌人【彻底冰冻】或照射中时，该敌人向周围散发寒气，使周围敌人减速。
   * **体验**：“我冻住大哥，小弟们全跟着挨冻”，解决群控问题。

3. **衍生技B【冰结碎灭】（终极爆杀，替代原寄生技能“数据破碎”）**：
   * **解锁条件**：需拥有 `[Ice]` 标签（作为冰系独占进化路线）。
   * **机制**：攻击处于冰冻状态的敌人必定暴击或造成额外碎冰真实伤害。
   * **Lv5 质变特效（冰霜新星）**：如果击杀了冰冻状态的敌人，怪物冰雕碎裂，伴随清脆“玻璃碎裂”音效，原地爆发【浅蓝色圆形气浪】。气浪扫过的敌人瞬间被施加高额减速和一次范围伤害（冰霜新星）。

**未来扩展（流派宇宙）**：该套底层架构（基础技挂状态 -> 状态衍生传染 -> 结算爆发）可直接复用于未来的火系（点燃->蔓延->爆燃）、电系（感电->静电->引雷）流派，实现低成本量产高质量内容。

### 🔵 2. 聚能透镜 (Focus) 的“变细”争议
**现状**：已移除变细的负面效果。
**策划验证**：**这个改动非常正确！** 玩家在局内升级是为了“变强”，选了广域变宽，再选聚能变细，这种“属性互冲”会给玩家带来极强的挫败感（觉得白升级了）。取消变细，让 Focus 成为纯粹的“穿透+伤害”放大器，完全符合重炮流的定位。

### 🟡 3. 致命暴击 (Crit) 的上限与收益计算
**现状与痛点**：激光是高频持续伤害（如每秒10次判定），如果暴击率叠加太高（技能+局外科技树+无人机），满屏全是红字，不仅没有惊喜感，还会导致伤害溢出。
**数值数学模型**：
*   假设玩家激光基础 Tick = 10次/秒。
*   如果暴击率达到 50%，每秒必定有 5 次暴击，这就不是“暴击”了，而是“常驻伤害”。
*   **【改进方案】：锁死暴击率上限，转为投放“暴击伤害”！**
*   **局内技能修改**：`Passive_Crit` 不再单纯给大量暴击率。
    *   **Lv1~Lv4**：每级增加 **3%** 暴击率，同时增加 **15%** 暴击伤害（Crit Damage）。
    *   **Lv5**：暴击率增加 5%，暴击伤害增加 30%，且**暴击时附带微弱的击退/打断效果**。
*   **全局阈值控制**：在代码底层（LaserController 或数值结算处），写死 **玩家面板总暴击率最高不能超过 60%**。剩下的收益全部交给爆伤。这样既保证了红字不至于糊满屏幕，又让暴击技能真正具有抓取的价值。

### 🟢 4. 关于“反射 (Reflex)”技能的去留
**现状**：游戏内有墙体，代码性能也扛得住，但玩家反馈作用不大，已替换为“传导 (Chain)”。
**策划验证**：**建议不要加入局内“三选一”的常规技能池。**
*   **原因**：塔防游戏的肉鸽池子（RNG Pool）非常宝贵。反射高度依赖地形，如果玩家在空旷关卡抽到反射，就是个废技能（污染了牌池）。而“传导”在任何关卡都适用。
*   **废物利用方案**：把它做成**局外特定无人机的专属被动**，或者作为**特定关卡/特殊武器的自带机制**。不要让它进升级的随机池。
