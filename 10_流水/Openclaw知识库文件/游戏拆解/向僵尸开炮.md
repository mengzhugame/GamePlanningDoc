## 一、MDA分析

### Aesthetics（体验）
- **爽快感**: 割草射击的即时反馈，弹幕满屏
- **策略感**: 塔防布局 + 技能构筑的决策深度
- **惊喜感**: 肉鸽随机掉落带来的"开盲盒"体验
- **成长感**: 轻RPG养成提供持续进步动力

### Dynamics（动态）
- 局内：击杀怪物→升级→随机获得技能→构筑流派→通关
- 局外：获得素材→养成角色/装备→提升数值→挑战更高难度
- 无论输赢都有奖励，降低挫败感

### Mechanics（机制）
- **核心战斗**: 塔防固定位射击 + 僵尸波次推进
- **技能系统**: 局内肉鸽随机技能选择，流派构筑
- **养成系统**: 局外轻RPG，装备/角色/数值成长
- **体力系统**: 鸡腿（体力值）控制游戏节奏
- **赛季制**: 周期性新玩法内容注入

---

## 二、核心循环

### 短循环（单局内 5-10分钟）
```
射击僵尸 → 获得经验升级 → 随机选技能 → 构筑流派 → 击杀Boss
```

### 中循环（多局间）
```
完成对局 → 获得养成素材 → 强化局外数值 → 挑战更高难度关卡
```

### 长循环（赛季级）
```
新赛季开启 → 新玩法/新内容 → 探索新流派 → 赛季奖励 → 等待下赛季
```

## 三、成功要素分析

### 1. 玩法融合做得好
- 塔防的策略深度 + 肉鸽的随机性 + 割草的爽快感
- 三种体验叠加，覆盖多种用户群（策略/射击/泛娱乐）

### 2. 低门槛高上限
- 上手极其简单（自动射击）
- 策略深度够（技能构筑、流派搭配）
- 不想动脑也能靠数值养成通关

### 3. RPG养成托底
- 肉鸽运气不好时，数值成长保证进度不卡死
- 保护非大R付费体验，避免断层

### 4. 题材空白 + 美术测试
- 市场上有三国割草、武侠割草，唯独没有僵尸割草
- 测试了5-6种美术风格，用数据选出Q版现代风

### 5. 赛季制长线运营
- 内容驱动型产品用赛季制注入新鲜感
- 玩家自主选择参与，不形成负担
- 回流成本低，账号保值

### 6. 团队MMORPG经验迁移
- 社交玩法（组队/团本/公会）维持活跃
- 数值设计经验保护付费体验
- 数据精细化运营（用户标签/回流管理）

## 四、变现模型

- **IAP为主**: 轻度付费，不逼数值
- **广告辅助**: 看广告获得额外奖励
- **赛季通行证**: BP式付费内容
- **首充/礼包**: 标准化商业化设计
- **关键原则**: 不颠覆玩家养成，不逼氪
