# 蒸馏批次记录

> 这是 `10_流水/` 下所有文件的蒸馏进度账本。
> 每次执行 `/distill` 时：
> 1. 扫描未入表的新文件，按文件名 + 首 30 行判断类型 + 一句话主题摘要 → 入表 `状态: 未蒸馏`
> 2. 挑 5 个 `状态: 未蒸馏` 的文件（默认按日期最旧优先）
> 3. 蒸馏 → 内容追加到主题目录的已有文件（或必要时新建）
> 4. 更新本表：填「沉淀去向」+ 批次 + 蒸馏日期 + 状态 → `已蒸馏`
> 5. 原文移到 `10_流水/已蒸馏文件/<原相对路径>/`
> 6. 末尾批次总报 + 思维盲区追加到 `70_用户信息/思维盲区与提升点.md`
>
> 完整工作流见 `90_系统/skills/skill-distill.md`。

## 字段说明

| 字段   | 含义                              | 取值                                                                                   |
| ---- | ------------------------------- | ------------------------------------------------------------------------------------ |
| 文件路径 | 相对 10_流水/ 的路径                   | 如 `2026-04/2026-04-21.md`                                                            |
| 类型   | AI 入表时判断的内容类别                   | `AI对话_项目` / `AI对话_战略` / `AI对话_工具链` / `游戏拆解` / `Openclaw知识库` / `日记流水` / `项目专项文档`      |
| 主题摘要 | AI 入表时一句话讲清这个文件主要讲什么            | 自然语言一句话                                                                              |
| 状态   | 蒸馏进度                            | `未蒸馏` / `蒸馏中` / `已蒸馏` / `无价值删除`                                                      |
| 沉淀去向 | 蒸馏后内容追加/新建到哪些目标文件（可多个，逗号分隔）     | 如 `50_商业/公司化目标.md, 70_用户信息/用户画像.md, 40_知识/07_游戏拆解库`, 或其它知识库相关文件内，如果知识库中没有相关文件，则新增文件夹 |
| 批次   | 批次 ID                           | `B-001` / `B-002` / ...                                                              |
| 蒸馏日期 | 实际处理日期                          | `YYYY-MM-DD`                                                                         |
| 备注   | 特殊说明（如「无价值删除」原因 / 「跨多文件主题合并」标记） | 自由文本                                                                                 |
