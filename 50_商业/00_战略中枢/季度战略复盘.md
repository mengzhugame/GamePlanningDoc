# 季度战略复盘

本文件用于检查当前行动是否仍服务“做出留存和盈利较好的产品，并在此基础上成立游戏公司”。

季度复盘不评判努力程度，只评判外部信号、系统效率和资源状态。

## 判断口径

### 加码

满足以下至少 2 项：

- 陌生人明确表达“想玩 / 在哪玩 / 求测试”。
- 可玩切片前 3 分钟有爽点，玩家能复述卖点。
- 用户池有增长，且不是朋友熟人凑数。
- 留存、时长、广告观看、预约、付费意愿等出现明确正信号。
- 发行或渠道给出具体下一步，而不是泛泛夸奖。

### 修正

有一个变量亮，但整体还不够：

- 有人停下看，但不想试。
- 想试，但上手不爽。
- 爽点存在，但表达模糊。
- 数据有一项亮眼，其余平庸。

修正原则：一次只改一个变量。不要同时改题材、玩法、美术、平台和商业化。

### 砍掉

满足以下任意 2 项：

- 连续 2 轮素材测试无明确想玩信号。
- Demo 前 10 分钟无法打出代表性高光。
- 玩过的人无法复述卖点。
- 指标差，而且看不出哪一项值得救。
- 继续做只是因为已经投入了很多。

砍掉后必须拆资产：

- 机制资产
- 美术 / 视频素材
- 技术模块
- 玩家反馈
- 发行反馈
- 失败原因

### 换轨

当创业系统连续 8-12 周无法产生有效外部信号时，启动现实期权：

- 投腾讯 / 网易 / 大厂获取市场反馈。
- 接 TA / Shader / Unity 外包维持现金流。
- 进入团队补产品、发行、运营和数据能力。
- 暂停多项目探索，保留低成本验证节奏。

换轨不是失败，是保护长期创造力和现金流。

## 2026-05-18 当前复盘

### 已经对齐目标

- 北极星已经从“开公司”修正为“先做出被市场验证且能赚钱的产品”。
- 5 月计划已经包含拆解、创意打分、铁律检查、AI 视频脚本。
- 个人 IP 已从旅行号回调到“真实失败 + 持续验证 + 开发日志”。
- 找工作被定义为期权，不再被理解成创业失败。

### 没做到

- 尚未稳定形成“视频信号 -> 试玩用户 -> 数据复盘”闭环。
- 个人 IP 尚未稳定导入测试池。
- 买量与发行反馈还没有成为每轮验证的固定动作。
- 旧文档过多，导致战略入口不清。

### 原因

- 过去习惯完整开发，而不是开发前证伪。
- 整理和战略讨论容易提供安全感。
- 搬家、活动和生活系统升级占用了验证窗口。
- 内容账号还没完全从《光与朽》旧叙事切换到“30 天切片 + 用户池”。

### 下一步

1. 每个方向必须有承接口。
2. 每周复盘只看外部信号。
3. 任何“完整开发”的冲动都先过视频 / 切片 / 用户池三道闸。

## 50_商业整理后的季度复盘口径

这次商业目录重构后，季度复盘要少评估“文档是否完整”，多评估“系统是否真的跑起来”。

未来每次季度复盘都要额外检查：

| 复盘项 | 要看的证据 |
| --- | --- |
| 市场信号 | 视频评论、收藏、预约、试玩报名、愿望单、发行具体下一步 |
| 用户池 | 是否有 20-50 个高意图用户可反复测试 |
| 数据闭环 | 是否记录了看懂、试玩、复玩、广告、留存或等价指标 |
| 商业入口 | 是否出现收入、合作、发行材料或买量判断 |
| 组织资产 | 是否沉淀了模板、AI_CONTEXT、代码、美术管线、素材脚本 |

如果 8-12 周结束时只有更多整理、更完整的战略和更多候选点子，而没有外部信号，就应判断为“系统未跑通”，而不是“还需要再规划一轮”。
