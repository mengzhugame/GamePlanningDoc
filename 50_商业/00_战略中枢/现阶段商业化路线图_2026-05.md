# 现阶段商业化路线图（2026-05）

## 一句话

当前目标要从“先开一家游戏公司”收窄为：

> 用自己的 TA / Unity / AI / 内容表达 / 旅行经历，连续做低成本商业验证，先跑出可收费能力、用户池、产品数据或合作机会。公司化是这些证据自然长出来之后的组织形态。

现阶段不是身份选择，而是证据选择：哪条路线能在 30-90 天内带来陌生用户、真实付费、合作邀约或可复用资产，就给它更多资源。

---

## 当前判断

已经成立的事实：

- 不缺独立做完小游戏并上线的能力。
- 缺的是开发前需求验证、陌生用户测试、留存 / 变现数据和稳定收入闭环。
- 个人 IP 已经证明“真实失败 + 具体数字 + 继续验证”比纯产品宣传更容易获得关注。
- 旅行不是纯逃避，它能恢复生命力，也可能成为体验设计、路线产品和真实社交的副线。
- 现金安全垫允许继续做 90 天低成本实验，但不支持无收入的大项目和情绪性扩张。

核心修正：

| 旧目标 | 新目标 |
| --- | --- |
| 我要成立游戏公司 | 我要先证明自己能持续创造收入和用户信号 |
| 再做一款完整小游戏 | 每 1-2 个月完成一轮小验证 |
| 个人 IP 帮游戏涨粉 | 个人 IP 帮每条路线拿到测试者、客户或合作线索 |
| 旅行内容会稀释游戏人设 | 旅行可以独立做成副线实验，但不能拖垮主线 |
| 找工作是失败 | 求职 / 接单是职业资本和现金流保险 |

---

## 路线总览

| 路线 | 定位 | 资源占比 | 30-90 天要拿到的证据 | 收入可能 |
| --- | --- | --- | --- | --- |
| A. AI + 小游戏验证主线 | 最高上限，承接公司化目标 | 50%-60% | 概念视频信号、7 天切片、20-50 个陌生试玩、留存 / 广告 / 预约 / 发行反馈 | IAA、混变、发行合作、模板授权、后续团队化 |
| B. AI 工具 / 工作流产品线 | 最快验证付费，补现金流和作品集 | 15%-25% | 3 个真实使用者试用，至少 1 个愿意付费或合作 | 模板包、定制工具、咨询、TA / AI Pipeline 接单 |
| C. 个人 IP 与用户池 | 所有路线的获客层，不单独当主业 | 10%-15% | 每周内容带来评论、私信、测试群、表单或合作线索 | 测试池、合作入口、长期信任 |
| D. 旅行内容 / 线下体验副线 | 低成本探索真实世界和潜在客户 | 10%-20% | 4 周稳定发布、有效私信 / 咨询、路线共创、潜在客户或同行合作 | 路线咨询、内容合作、AA 活动、与合规旅行社合作 |
| E. 求职 / 接单保险线 | 防止现金流和职业资本断档 | 10%-20% | 简历、作品集、面试反馈、外包报价或 offer 校准 | 工资、外包、行业资源 |

默认资源分配可以先按 `60 / 20 / 20`：

```text
60%：AI + 小游戏 / 工具应用验证
20%：职业资本、作品集、接单或岗位试探
20%：旅行内容与线下体验副线
```

---

## 路线 A：AI + 小游戏验证主线

这是当前最接近长期公司化的主线，但不能回到“闭门开发 4 个月”的旧模式。

### 1-2 个月一轮的最小闭环

```text
5-10 个创意候选
-> 3 个概念卡 + AI 反证
-> 2-3 条 10-15 秒真实玩法概念视频
-> 陌生人评论 / 表单 / 测试群
-> 1 个 7 天极小切片
-> 20-50 个陌生试玩
-> 数据复盘：Push / Pivot / Kill
```

### 适合优先测的方向

优先选择 TA 能力能变成玩法本身的方向：

- 清洁 / 修复 / 材质变化。
- 流体 / 粒子 / 触控玩具。
- 破坏 / 切割 / 挤压。
- 视觉错位 / 空间解谜。
- 程序化电子盆栽 / 治愈生成。

判断标准：3 秒看得懂，7 天做得出，失败后能留下 Shader、VFX、模板、素材或用户反馈。

### 加码闸门

满足至少 2 项才进入 1 个月 Demo：

- 陌生人明确问“在哪玩 / 想试 / 什么时候出”。
- 20 个以上高意图测试者愿意试玩。
- 前 3 分钟核心爽点能被复述。
- 有广告观看、重开、预约、愿望单、留存或发行具体下一步。
- 失败也能沉淀可复用技术 / 素材 / 数据资产。

## 路线 B：AI 工具 / 工作流产品线

这条线的价值不是转行做 SaaS，而是用更小交付验证“有人愿意为你的流程能力付费”。

优先顺序：

| 方向 | 第一版 | 验证对象 | 付费探针 |
| --- | --- | --- | --- |
| 旅行从业者 AI 工具 | 路线 / 报价 / 客户沟通生成模板 | 旅游朋友、领队、路线定制从业者 | 29 / 99 / 199 元模板或定制 |
| 小游戏立项验证工具 | 概念卡、铁律检查、竞品差异、视频脚本、Push / Pivot / Kill | 自己 + 独游朋友 + 小团队 | 模板包、咨询、工具页面 |
| TA / AI Pipeline 作品集 | AI 创意 -> JSON 配置 -> Unity 模板 -> 可玩首局 | 面试官、外包客户、潜在合伙人 | 岗位、外包、合作 |

第一版不要做登录、支付、复杂后台和完整网站。先用 Markdown / 网页 / 表单 / prompt 模板交付 3 个样例，拿真实人反馈。

## 路线 C：个人 IP 与用户池

个人 IP 的主账号仍然服务游戏与 AI 验证，不改成泛旅行生活号。

主账号推荐定位：

> 一个 36 岁、10 年 TA、做废两款微信小游戏后，开始用 30 天小切片和 AI 工作流重新验证商业路线的人。

内容结构：

| 类型 | 占比 | 作用 |
| --- | --- | --- |
| 产品验证 | 50%-60% | 招募测试者，记录外部信号 |
| 失败复盘 | 20%-25% | 建立真实可信的人设 |
| 技术 / AI 流程 | 10%-15% | 展示护城河和职业资本 |
| 生活 / 旅行 | 5%-10% | 绑定灵感、恢复、路线实验，不抢主线 |

每条内容必须有承接口：

- 评论关键词。
- 私信。
- 测试群。
- 表单。
- 预约 / 愿望单。
- 合作咨询。

不再用“我又发了一条内容”当进展，只看它带来了什么外部动作。

## 路线 D：旅行内容 / 线下体验副线

旅行副线可以做，但它必须是一个 4 周商业实验，不是情绪性改赛道。

### 是否新开账号

建议可以新开一个旅行副线账号，但只按实验号处理，不替代游戏 / AI 主账号。

原因：

- 旧游戏主账号需要保持“独立开发者 + AI 验证”一致性。
- 旅行素材可能适合更高频发布，不应冲掉游戏用户池。
- 新账号可以单独测试旅行人群是否愿意关注、咨询、约线下活动或购买路线产品。

### 账号定位

不要做纯风景号，建议做“体验设计型旅行账号”：

> 36 岁游戏开发者，把徒步、路线和真实世界体验拆成可复制的自由感。

可选表达：

- 游戏开发者的慢旅行实验。
- 小龙儿的自由路线笔记。
- 一个游戏 TA 的徒步与路线设计。
- 36 岁重新连接真实世界的旅行实验。

### 素材整理方式

先把旧照片和视频分成 4 类：

| 素材 | 内容方向 | 商业承接口 |
| --- | --- | --- |
| EBC / 高海拔徒步 | 最慢的人也能走到终点、路线复盘、装备和风险 | 徒步咨询、路线清单、同行兴趣 |
| 尼泊尔 / 东南亚 / 自然风景 | 低成本自由感、反孤独旅行、真实见闻 | 收藏、私信、路线问答 |
| 旅途人物 / 队友故事 | 旅行中的关系、被照顾、好队友 | 社群、线下活动 |
| 游戏灵感 / 开发者视角 | 风景如何变成 Boss、关卡、视觉体验 | 回流游戏主账号 |

### 4 周发布节奏

实验期可以每周 3-5 条，但只用库存素材，不为内容重新消耗大量精力。

每条控制在 30-45 分钟内完成：

```text
选素材 10 分钟
写标题和 3 行正文 10 分钟
剪 15-30 秒或拼图 15 分钟
结尾放一个动作 5 分钟
```

结尾动作示例：

- 想要这条路线清单，可以评论“路线”。
- 如果你也想走一次低成本徒步，可以私信“徒步”。
- 我在整理 EBC 路线预算表，想看的留言。
- 如果你是旅游从业者，我想找 3 个人试用 AI 路线模板。

### 不能直接跳到“带客户旅游”

正式收费带客户出行涉及资质、合同、保险和安全责任，不适合裸跑。根据《中华人民共和国旅游法》和《旅行社条例》，经营旅行社业务、组织旅游服务通常需要相应许可和合同规范。

更安全的验证顺序：

1. 内容号测试：是否有人问路线、预算、装备、同行。
2. 免费 / AA 朋友局：只做体验共创和路线复盘，不承诺商业服务。
3. 路线咨询产品：卖路线清单、预算表、准备清单、AI 定制行程，不先带团。
4. 与合规旅行社 / 领队合作：自己负责内容、社群和体验设计，对方负责资质、合同、保险和执行。
5. 有稳定客户线索后，再单独评估是否考证、合作或成立相关主体。

旅行副线的目标不是马上变旅游公司，而是验证：你的旅行经历能不能变成信任、咨询、路线产品和线下连接。

## 路线 E：求职 / 接单保险线

这条线不是退路，而是保护选择权。

保留 10%-20% 精力做：

- Unity TA / Pipeline TA / UGC 工具链作品集。
- AI + 游戏生产流程 Demo。
- 简历 A/B 版。
- 目标公司岗位映射。
- 小额外包报价测试。

判断口径：

- 如果创业路线 8-12 周无外部信号，求职 / 接单优先级上升。
- 如果拿到高质量 offer，且能补团队经验、发行认知、现金流和行业嵌入，可以把创业降级为周末实验。
- 如果 offer 只是高压救火、不能积累未来公司化筹码，不因焦虑接受。

## 90 天执行节奏

### 0-14 天

- 选 3 个游戏 / 工具候选，写玩家欲望假设和 AI 反证。
- 整理旅行素材 30 条，按 4 类打标签。
- 开一个测试表单：小游戏试玩 / AI 工具试用 / 旅行路线兴趣。
- 做 1 个 AI / Unity Pipeline 作品集小样。

### 15-30 天

- 发 2-3 条游戏概念视频或实机爽点。
- 旅行副线发 12-20 条库存素材内容。
- 找 3 个旅游朋友试用路线 / 报价 / 客户沟通模板。
- 招募 20 个陌生试玩或工具试用者。

### 31-60 天

- 只保留一个游戏方向进入 7 天切片。
- 旅行副线如果有咨询，做 1 个路线清单产品或 AA 朋友局。
- 小游戏立项验证工具或旅行工具做第 2 版。
- 同步更新求职作品集和外包报价页。

### 61-90 天

- 用数据决定主线：小游戏加码、AI 工具加码、旅行副线加码，或求职 / 接单优先。
- 如果任何路线只有内容更新、没有私信 / 试玩 / 付费 / 合作线索，降级或停掉。
- 写季度商业复盘，只看外部信号，不看自我感觉。

---

## 90 天后决策表

| 结果 | 决策 |
| --- | --- |
| 小游戏有试玩、留存、广告或发行正信号 | A 路线加码，进入 1 个月 Demo / 小游戏测试 |
| AI 工具有人愿付费或愿持续试用 | B 路线加码，做模板包 / 简单网页 / 小额定制 |
| 旅行副线有持续咨询和线下活动线索 | D 路线加码，但优先路线咨询和合规合作 |
| 三条线都无信号 | 求职 / 接单优先，创业降级为低成本周末实验 |
| 只有内容播放，没有承接口转化 | 调整内容，不把播放当商业信号 |

---

## 红线

- 没有视频信号，不进入游戏原型。
- 没有陌生试玩，不进入 Demo。
- 没有留存 / 付费 / 合作 / 用户池，不完整开发。
- 旅行副线没有咨询或线索，不投入实地重拍和长途旅行。
- 未核查资质、合同、保险前，不以商业带团形式收费。
- 任何内容账号如果连续 4 周没有带来承接口动作，就降级为生活记录。
- 每月总支出仍要围绕年度无收入支出 10W 内和现金红线复盘。

## 现金流优先时，先卖服务 Demo，不先做产品

2026-05-27 的商业判断把目标从“开游戏公司”进一步收窄到“先用个人能力产生第一笔持续性收入”。这不是放弃公司化，而是先补现金流、客户和真实需求验证。

当前最靠近钱的顺序：

| 路线 | 第一动作 | 验证标准 |
| --- | --- | --- |
| TA / Unity / 微信小游戏技术服务 | 做一页报价单，主动发给真实潜在客户 | 7 天内是否有人愿意约聊、报价或付款 |
| 旅游从业者 AI 代做服务 | 手工交付路线、报价单、客户话术、小红书文案 | 10 个从业者里是否有人愿付 99-499 |
| IAA 小游戏 | 降级为研发漏斗：概念卡、视频、7 天切片 | 有视频信号、陌生试玩和留存/广告信号才加码 |
| 小游戏立项验证工具 | 先只做给自己用 | 是否让自己少浪费时间，不作为短期收入 |
| 旅行/AI 内容产品 | 先发内容或落地页测需求 | 没有关注、预约、付费，不开发产品 |

可卖服务的初版报价可以粗糙，但必须发出去。例如：

- 微信小游戏适配 / 性能优化：1999 起。
- Shader / VFX 表现优化：2999 起。
- 7 天小游戏原型切片：4999 起。
- AI 辅助 Demo 快速开发：9999 起。
- 旅游路线方案 + 小红书文案：99 起。
- 3 天游行程 + 报价单 + 客户话术：299 起。

新的执行标准：

> 不先问“我能不能做出来”，先问“谁现在愿意为这个付钱”。

如果 7 天内没人愿意付钱，换 offer，不写大项目。

## 成人向和博彩方向只能进入研究期，不进入全职转向

同一日流水里提到成人向游戏、成人向悬疑和博彩/赌博类路径。可保留的判断是：成人向市场确实有购买力，但不能把“高收益、蓝海、游戏性要求低、小规模不用管风险”当成事实。

当前规则：

- 成人向可以研究和低成本验证，但不直接全职转向。
- 不从完整 HD2D 成人 RPG 起步，先做非露骨、可转成人向的 10-15 分钟玩法样片。
- 若做成人向悬疑，必须让成人向包装服务玩法机制，例如“黑色成人悬疑 + 案发重演 + 成年秘密关系”，而不是通关送 CG。
- 学校、未成年暗示、非自愿、胁迫、偷拍、公共性行为等高危方向不碰。
- 赌博 / 真钱博彩不作为个人当前路径推进，合规、支付和主体风险明显高于普通成人向内容。

这条线的可执行下一步不是开发，而是子品类深挖：采样目标平台对应品类，拆价格、销量/评论、Demo、CG 量、语言、玩法、标签和合规边界。没有这些表，不进入制作。

## 求职不是回旧生活，而是恢复选择权

2026-05-28 的事业判断进一步收敛：当前不该裸创业，也不该把旅行当人生答案。更稳的 12 个月主线是回到可变现职业资本，同时保留 AI 游戏管线项目和旅行实验。

最优结构：

```text
主线：求职 / 接单，恢复现金流、行业位置和职业资本
副线：AI 创意 -> 配置 JSON -> Unity 模板 -> 首局 Demo -> 数据记录
恢复线：每季度一次 7-14 天旅行实验，带内容和路线验证任务
```

90 天只做三件事：

1. 投 30 个高匹配岗位，面 5-8 家，用 offer 校准市场价值。
2. 做一个 AI 游戏生产流程作品集，证明“AI 接入游戏生产管线”的能力。
3. 做旅行小实验：拍内容、认识从业者、跑一次路线、记录成本和收入模型。

上班可以接受的条件：

- 薪资达到尊严线，低于 30K 要谨慎。
- 岗位能积累 TA / Pipeline / AI 工具链能力。
- 不是纯 996 救火杂活。

创业重新升为主线的条件：

> 30 天内能说清楚：做什么、给谁用、怎么验证、失败后留下什么资产。

旅行升为商业线的条件：

- 连续发 30 条旅行/生活内容，看自然关注和私信。
- 跟朋友跑一次真实路线，确认自己是否喜欢服务客户。
- 算清客源、成本、车、保险、安全责任和淡旺季。

这不是否定创业，而是防止继续无收入、无方向、无作品、无社交地消耗一年。

## 海外学习线要绑定远程现金流，不让自由感单独烧钱

2026-05-29 的判断把“上班 / 出国学英语 / 潜水 / 旅行内容”进一步压成实验组合。核心变化是：海外不是永久转身，也不是放弃技术能力，而是一个带预算和现金流目标的 90 天生活实验。

当前商业优先级：

| 方向 | 优先级 | 判断 |
| --- | --- | --- |
| TA / Unity / Shader 远程外包 | 最高 | 最快靠已有能力产生现金流，可覆盖低成本旅居 |
| 英语学习 | 高 | 不是消费项目，而是扩大接单、内容和全球市场半径 |
| 旅行 / 学英语内容 | 中 | 可积累用户池，但前三个月不能指望养活自己 |
| 潜水证 | 中低 | 适合作为生活与内容素材，短期不是赚钱主线 |
| 潜水教练 / 潜店工作 | 低 | 需要大量潜次、进阶证书和当地合法工作条件 |
| 非法临时工 / 未许可摆摊 | 删除 | 签证、遣返、剥削和合规风险不值得 |

新的 90 天判断口径：

```text
低成本海外生活 + 每天英语 + 每周运动/潜水准备 + 内容记录 + 远程外包报价/投递
```

90 天成功不是“找到终身职业”，而是证明：

1. 身体和行动力是否恢复。
2. 英语学习是否能持续。
3. 月支出能否控制在预算内。
4. 远程 TA / Unity / Shader 外包能否拿到询价或小单。
5. 内容是否带来自然关注、私信或咨询。

如果收入和内容都没有信号，就回到国内调整，不在海外硬耗。海外实验要服务现金流和生命力，不是把无收入焦虑换一个国家继续想。

## 诗悦 offer 只能是阶段性补给，不默认卖三年

如果广州诗悦终面给到接近 3 万/月，不能自动把它解释为“回到旧生活”，也不能把拒绝 offer 解释为“终于自由”。更稳的规则是：把 offer 当成 90 天或 12 个月的现金流实验。

接受条件：

- 薪资接近尊严线。
- 加班强度不吃掉英语、游泳、健身和生活恢复。
- 岗位能补 TA / Pipeline / AI 工具链能力。
- 试用期和前三个月交付边界清楚。

如果 3 个月后只剩麻木、加班、躺平和没有学习，就算薪资高，这条实验也失败。上班线和海外线都不是身份选择，而是实验：哪一条能同时保护现金流、身体、职业资本和生命感，哪一条才值得继续。

## 海外地点不是商业模式，远程收入才是验证主线

2026-06-02 的商业判断进一步收敛：巴厘岛、菲律宾、尼泊尔、泰国、澳洲或欧美都不是商业模式，它们只是生活地点、内容素材、社交场和英语环境。真正可验证的是：

```text
existing TA / Unity / Shader / AI 工作流能力
-> 远程服务清单
-> 内容获客
-> 客户触达
-> 小额付费或询价
-> 再决定去哪长期生活
```

低资金创业排序：

| 优先级 | 方向 | 规则 |
| --- | --- | --- |
| 1 | 远程 TA / Unity / Shader / AI 工作流接单 | 先卖已有能力，不换能力圈 |
| 2 | AI + 游戏生产流程咨询 | 用两款上线项目和 AI 协作系统建立差异 |
| 3 | Unity 模板 / Shader 包 / 工具脚本 | 适合作为长期资产，不承担短期生存 |
| 4 | 内容带接单 | 自媒体是获客入口，不是早期主收入 |
| 5 | 旅行路线咨询 / 合规合作 | 轻量试，不自己重资产开店或带团硬扛责任 |

不要一上来在海外开店、做民宿、做潜店、做当地旅行社或本地公司。当前最现实的 90 天目标是：证明自己在海外或异地环境里，仍能持续产出内容、触达客户、拿到远程小单或有效询价。

## 6 月 15 日前的路线决策：offer、英语和重启人生要按闸门判断

2026-06-04 的核心变化是：用户已经不再把游戏行业视为热爱主线，而是把它降级为赚钱手段和职业资本。英语、海外生活、AI、旅行内容和潜水则被提升为“重建生活方式”的组合。

6 月 15 日前的决策闸门：

| 结果 | 处理 |
| --- | --- |
| 拿到理想 offer，薪资、加班、岗位成长能接受 | 可以上班，但只作为阶段性补给；必须保留英语、运动和转型时间 |
| offer 薪资低于尊严线或仍是高压 996 | 不把它当作救命绳，优先考虑海外英语 / 异地重启 |
| 没拿到合适 offer | 可以启动菲律宾 3 个月英语计划，但必须绑定预算、设备、远程接单和内容输出 |

英语学习目标的顺序：

1. 前 3 个月：先打通生活交流，目标 A2 高段到 B1 低段。
2. 第 3 个月末：看是否能连续英文聊 10 分钟、介绍项目、处理住宿 / 交通 / 潜水 / 学校沟通。
3. 第 4-6 个月：如果明确转向澳洲、新西兰、爱尔兰等长期路径，再考虑雅思 / PTE。

设备购买要服务路线，不服务幻想：笔记本是移动生产工具；拍摄设备是内容生产工具。二者都应在学校、签证、机票和执行计划确认后购买或替换，而不是用装备购买“马上要重生”的感觉。
