# 现阶段商业化路线图（2026-05）

## 一句话

当前目标要从“先开一家游戏公司”收窄为：

> 用自己的 TA / Unity / AI / 内容表达 / 旅行经历，连续做低成本商业验证，先跑出可收费能力、用户池、产品数据或合作机会。公司化是这些证据自然长出来之后的组织形态。

现阶段不是身份选择，而是证据选择：哪条路线能在 30-90 天内带来陌生用户、真实付费、合作邀约或可复用资产，就给它更多资源。

---

## 当前判断

已经成立的事实：

- 不缺独立做完小游戏并上线的能力。
- 缺的是开发前需求验证、陌生用户测试、留存 / 变现数据和稳定收入闭环。
- 个人 IP 已经证明“真实失败 + 具体数字 + 继续验证”比纯产品宣传更容易获得关注。
- 旅行不是纯逃避，它能恢复生命力，也可能成为体验设计、路线产品和真实社交的副线。
- 现金安全垫允许继续做 90 天低成本实验，但不支持无收入的大项目和情绪性扩张。

核心修正：

| 旧目标 | 新目标 |
| --- | --- |
| 我要成立游戏公司 | 我要先证明自己能持续创造收入和用户信号 |
| 再做一款完整小游戏 | 每 1-2 个月完成一轮小验证 |
| 个人 IP 帮游戏涨粉 | 个人 IP 帮每条路线拿到测试者、客户或合作线索 |
| 旅行内容会稀释游戏人设 | 旅行可以独立做成副线实验，但不能拖垮主线 |
| 找工作是失败 | 求职 / 接单是职业资本和现金流保险 |

---

## 路线总览

| 路线 | 定位 | 资源占比 | 30-90 天要拿到的证据 | 收入可能 |
| --- | --- | --- | --- | --- |
| A. AI + 小游戏验证主线 | 最高上限，承接公司化目标 | 50%-60% | 概念视频信号、7 天切片、20-50 个陌生试玩、留存 / 广告 / 预约 / 发行反馈 | IAA、混变、发行合作、模板授权、后续团队化 |
| B. AI 工具 / 工作流产品线 | 最快验证付费，补现金流和作品集 | 15%-25% | 3 个真实使用者试用，至少 1 个愿意付费或合作 | 模板包、定制工具、咨询、TA / AI Pipeline 接单 |
| C. 个人 IP 与用户池 | 所有路线的获客层，不单独当主业 | 10%-15% | 每周内容带来评论、私信、测试群、表单或合作线索 | 测试池、合作入口、长期信任 |
| D. 旅行内容 / 线下体验副线 | 低成本探索真实世界和潜在客户 | 10%-20% | 4 周稳定发布、有效私信 / 咨询、路线共创、潜在客户或同行合作 | 路线咨询、内容合作、AA 活动、与合规旅行社合作 |
| E. 求职 / 接单保险线 | 防止现金流和职业资本断档 | 10%-20% | 简历、作品集、面试反馈、外包报价或 offer 校准 | 工资、外包、行业资源 |

默认资源分配可以先按 `60 / 20 / 20`：

```text
60%：AI + 小游戏 / 工具应用验证
20%：职业资本、作品集、接单或岗位试探
20%：旅行内容与线下体验副线
```

---

## 路线 A：AI + 小游戏验证主线

这是当前最接近长期公司化的主线，但不能回到“闭门开发 4 个月”的旧模式。

### 1-2 个月一轮的最小闭环

```text
5-10 个创意候选
-> 3 个概念卡 + AI 反证
-> 2-3 条 10-15 秒真实玩法概念视频
-> 陌生人评论 / 表单 / 测试群
-> 1 个 7 天极小切片
-> 20-50 个陌生试玩
-> 数据复盘：Push / Pivot / Kill
```

### 适合优先测的方向

优先选择 TA 能力能变成玩法本身的方向：

- 清洁 / 修复 / 材质变化。
- 流体 / 粒子 / 触控玩具。
- 破坏 / 切割 / 挤压。
- 视觉错位 / 空间解谜。
- 程序化电子盆栽 / 治愈生成。

判断标准：3 秒看得懂，7 天做得出，失败后能留下 Shader、VFX、模板、素材或用户反馈。

### 加码闸门

满足至少 2 项才进入 1 个月 Demo：

- 陌生人明确问“在哪玩 / 想试 / 什么时候出”。
- 20 个以上高意图测试者愿意试玩。
- 前 3 分钟核心爽点能被复述。
- 有广告观看、重开、预约、愿望单、留存或发行具体下一步。
- 失败也能沉淀可复用技术 / 素材 / 数据资产。

## 路线 B：AI 工具 / 工作流产品线

这条线的价值不是转行做 SaaS，而是用更小交付验证“有人愿意为你的流程能力付费”。

优先顺序：

| 方向 | 第一版 | 验证对象 | 付费探针 |
| --- | --- | --- | --- |
| 旅行从业者 AI 工具 | 路线 / 报价 / 客户沟通生成模板 | 旅游朋友、领队、路线定制从业者 | 29 / 99 / 199 元模板或定制 |
| 小游戏立项验证工具 | 概念卡、铁律检查、竞品差异、视频脚本、Push / Pivot / Kill | 自己 + 独游朋友 + 小团队 | 模板包、咨询、工具页面 |
| TA / AI Pipeline 作品集 | AI 创意 -> JSON 配置 -> Unity 模板 -> 可玩首局 | 面试官、外包客户、潜在合伙人 | 岗位、外包、合作 |

第一版不要做登录、支付、复杂后台和完整网站。先用 Markdown / 网页 / 表单 / prompt 模板交付 3 个样例，拿真实人反馈。

## 路线 C：个人 IP 与用户池

个人 IP 的主账号仍然服务游戏与 AI 验证，不改成泛旅行生活号。

主账号推荐定位：

> 一个 36 岁、10 年 TA、做废两款微信小游戏后，开始用 30 天小切片和 AI 工作流重新验证商业路线的人。

内容结构：

| 类型 | 占比 | 作用 |
| --- | --- | --- |
| 产品验证 | 50%-60% | 招募测试者，记录外部信号 |
| 失败复盘 | 20%-25% | 建立真实可信的人设 |
| 技术 / AI 流程 | 10%-15% | 展示护城河和职业资本 |
| 生活 / 旅行 | 5%-10% | 绑定灵感、恢复、路线实验，不抢主线 |

每条内容必须有承接口：

- 评论关键词。
- 私信。
- 测试群。
- 表单。
- 预约 / 愿望单。
- 合作咨询。

不再用“我又发了一条内容”当进展，只看它带来了什么外部动作。

## 路线 D：旅行内容 / 线下体验副线

旅行副线可以做，但它必须是一个 4 周商业实验，不是情绪性改赛道。

### 是否新开账号

建议可以新开一个旅行副线账号，但只按实验号处理，不替代游戏 / AI 主账号。

原因：

- 旧游戏主账号需要保持“独立开发者 + AI 验证”一致性。
- 旅行素材可能适合更高频发布，不应冲掉游戏用户池。
- 新账号可以单独测试旅行人群是否愿意关注、咨询、约线下活动或购买路线产品。

### 账号定位

不要做纯风景号，建议做“体验设计型旅行账号”：

> 36 岁游戏开发者，把徒步、路线和真实世界体验拆成可复制的自由感。

可选表达：

- 游戏开发者的慢旅行实验。
- 小龙儿的自由路线笔记。
- 一个游戏 TA 的徒步与路线设计。
- 36 岁重新连接真实世界的旅行实验。

### 素材整理方式

先把旧照片和视频分成 4 类：

| 素材 | 内容方向 | 商业承接口 |
| --- | --- | --- |
| EBC / 高海拔徒步 | 最慢的人也能走到终点、路线复盘、装备和风险 | 徒步咨询、路线清单、同行兴趣 |
| 尼泊尔 / 东南亚 / 自然风景 | 低成本自由感、反孤独旅行、真实见闻 | 收藏、私信、路线问答 |
| 旅途人物 / 队友故事 | 旅行中的关系、被照顾、好队友 | 社群、线下活动 |
| 游戏灵感 / 开发者视角 | 风景如何变成 Boss、关卡、视觉体验 | 回流游戏主账号 |

### 4 周发布节奏

实验期可以每周 3-5 条，但只用库存素材，不为内容重新消耗大量精力。

每条控制在 30-45 分钟内完成：

```text
选素材 10 分钟
写标题和 3 行正文 10 分钟
剪 15-30 秒或拼图 15 分钟
结尾放一个动作 5 分钟
```

结尾动作示例：

- 想要这条路线清单，可以评论“路线”。
- 如果你也想走一次低成本徒步，可以私信“徒步”。
- 我在整理 EBC 路线预算表，想看的留言。
- 如果你是旅游从业者，我想找 3 个人试用 AI 路线模板。

### 不能直接跳到“带客户旅游”

正式收费带客户出行涉及资质、合同、保险和安全责任，不适合裸跑。根据《中华人民共和国旅游法》和《旅行社条例》，经营旅行社业务、组织旅游服务通常需要相应许可和合同规范。

更安全的验证顺序：

1. 内容号测试：是否有人问路线、预算、装备、同行。
2. 免费 / AA 朋友局：只做体验共创和路线复盘，不承诺商业服务。
3. 路线咨询产品：卖路线清单、预算表、准备清单、AI 定制行程，不先带团。
4. 与合规旅行社 / 领队合作：自己负责内容、社群和体验设计，对方负责资质、合同、保险和执行。
5. 有稳定客户线索后，再单独评估是否考证、合作或成立相关主体。

旅行副线的目标不是马上变旅游公司，而是验证：你的旅行经历能不能变成信任、咨询、路线产品和线下连接。

## 路线 E：求职 / 接单保险线

这条线不是退路，而是保护选择权。

保留 10%-20% 精力做：

- Unity TA / Pipeline TA / UGC 工具链作品集。
- AI + 游戏生产流程 Demo。
- 简历 A/B 版。
- 目标公司岗位映射。
- 小额外包报价测试。

判断口径：

- 如果创业路线 8-12 周无外部信号，求职 / 接单优先级上升。
- 如果拿到高质量 offer，且能补团队经验、发行认知、现金流和行业嵌入，可以把创业降级为周末实验。
- 如果 offer 只是高压救火、不能积累未来公司化筹码，不因焦虑接受。

## 90 天执行节奏

### 0-14 天

- 选 3 个游戏 / 工具候选，写玩家欲望假设和 AI 反证。
- 整理旅行素材 30 条，按 4 类打标签。
- 开一个测试表单：小游戏试玩 / AI 工具试用 / 旅行路线兴趣。
- 做 1 个 AI / Unity Pipeline 作品集小样。

### 15-30 天

- 发 2-3 条游戏概念视频或实机爽点。
- 旅行副线发 12-20 条库存素材内容。
- 找 3 个旅游朋友试用路线 / 报价 / 客户沟通模板。
- 招募 20 个陌生试玩或工具试用者。

### 31-60 天

- 只保留一个游戏方向进入 7 天切片。
- 旅行副线如果有咨询，做 1 个路线清单产品或 AA 朋友局。
- 小游戏立项验证工具或旅行工具做第 2 版。
- 同步更新求职作品集和外包报价页。

### 61-90 天

- 用数据决定主线：小游戏加码、AI 工具加码、旅行副线加码，或求职 / 接单优先。
- 如果任何路线只有内容更新、没有私信 / 试玩 / 付费 / 合作线索，降级或停掉。
- 写季度商业复盘，只看外部信号，不看自我感觉。

---

## 90 天后决策表

| 结果 | 决策 |
| --- | --- |
| 小游戏有试玩、留存、广告或发行正信号 | A 路线加码，进入 1 个月 Demo / 小游戏测试 |
| AI 工具有人愿付费或愿持续试用 | B 路线加码，做模板包 / 简单网页 / 小额定制 |
| 旅行副线有持续咨询和线下活动线索 | D 路线加码，但优先路线咨询和合规合作 |
| 三条线都无信号 | 求职 / 接单优先，创业降级为低成本周末实验 |
| 只有内容播放，没有承接口转化 | 调整内容，不把播放当商业信号 |

---

## 红线

- 没有视频信号，不进入游戏原型。
- 没有陌生试玩，不进入 Demo。
- 没有留存 / 付费 / 合作 / 用户池，不完整开发。
- 旅行副线没有咨询或线索，不投入实地重拍和长途旅行。
- 未核查资质、合同、保险前，不以商业带团形式收费。
- 任何内容账号如果连续 4 周没有带来承接口动作，就降级为生活记录。
- 每月总支出仍要围绕年度无收入支出 10W 内和现金红线复盘。
