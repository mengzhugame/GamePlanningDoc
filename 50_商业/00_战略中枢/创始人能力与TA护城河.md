# 创始人能力与 TA 护城河

## 核心定位

小龙儿不是“什么游戏都能卷的全能制作人”，而是 TA 出身、Unity 技术管线强、能把视觉表现和玩法结合起来的独立开发者。

正确打法：

> 选择视觉表现本身就是玩法的一类游戏，让 Shader、VFX、程序化生成和技术落地能力成为护城河。

错误打法：

- 用原画、角色造型、UI 精修去拼专业美术团队。
- 做“玩法老、美术弱”的普通换皮。
- 用完整开发替代开发前验证。
- 把平台审核、软著、发行拒绝当失败主因，回避产品数据。

## 核心优势

| 能力 | 可转化为 |
|------|----------|
| Shader / 材质系统 | 材质变化、清洁修复、流体、光照、空间错觉 |
| 粒子与 VFX | 击中感、爆发反馈、爽点切片、短视频传播 |
| 性能优化 | 移动端高粒子、高反馈、60fps |
| Unity 工程能力 | 7 天切片、快速上线、可复用模板 |
| AI 工作流 | 概念视频、素材变体、代码辅助、市场扫描 |
| 复盘能力 | 失败后拆资产，形成下一轮规则 |

---

## 核心短板

- 原画设计。
- 角色造型。
- UI 视觉风格。
- 持续运营和投放经验。
- 陌生用户测试组织。
- 对“已经投入很多”的项目容易产生完成冲动。

选品时必须避开高度依赖这些短板的方向。

## 更适合的方向

| 方向 | 核心体验 | TA 杀手锏 | 验证方式 |
|------|----------|-----------|----------|
| 清洁 / 修复模拟 | 脏乱变整洁，强迫症满足 | Shader 遮罩、材质变化、粒子反馈 | 10-15 秒前后对比视频 |
| 流体 / 粒子玩具 | 手指触控带来的视觉愉悦 | Compute Shader、GPU 粒子、交互流体 | 触控爽点 + 评论“想玩” |
| 破坏 / 切割 / 挤压 | 软体、粉碎、切割爽感 | Mesh Deformation、SDF、粒子 | 单一破坏动词视频 |
| 视觉错位 / 空间解谜 | 视角欺骗、空间扭曲 | Stencil、Depth、SDF、相机技巧 | 一屏看懂的谜题奇观 |
| 程序化电子盆栽 | 观赏、建造、轻互动 | PCG、风格化 Shader、生成系统 | 分享欲和保存欲 |

## 合伙人与第一批团队

最需要补的不是程序，而是美术与运营。

优先级：

1. 全能美术 / 特效美术：补第一眼品质和视觉钩子。
2. 运营发行型伙伴：补测试池、发行、投放、数据、平台合作。
3. 程序：早期由本人 + AI 承担，除非项目复杂度明显超出个人维护能力。

寻找合伙人的前提：

- 先有能打动对方的技术 Demo 或视觉切片。
- 不是“我有想法你来做美术”，而是“我已经解决技术和工程难点，只差审美与内容表达放大”。

## 选品检查

每个新方向先问：

1. 这个方向是否让 TA 能力变成核心卖点？
2. 是否能用 10-15 秒视频展示最强爽点？
3. 是否避开原画和 UI 的正面硬卷？
4. 7 天内能不能做出可试玩核心切片？
5. 如果失败，能不能留下 Shader、VFX、模板或素材资产？
6. 是否有明确陌生用户验证入口？

答不上 2 项以上，不立项。
