# 旅游英语沉浸营商业规划方案

## 一句话结论

这是一个以“海外低成本自由行 + 英语沉浸陪伴 + 小团内容记录”为核心的待验证商业模式。

当前不是正式公司项目，而是一个可以用小红书 / 抖音内容获客、用 2-8 人小团测试付费意愿、用真实旅途素材继续生产内容的商业实验。

本模式最大风险不是路线，而是：

1. 外国朋友是否愿意长期合作。
2. 是否能持续拿到陌生客源。
3. 两个组织者在没有客源时的吃住、机票和现金流压力。
4. 现场交付是否能同时兼顾英语学习、旅行体验、天气变化、退款边界和团员情绪。

如果外国朋友不同意，当前版本直接 pass。若长期没有客源，则不能拖着两个人在海外空耗，必须各自打工、接单或转入低成本内容验证。

---

## 用户原始商业假设

用户希望与一位美国朋友合作。该朋友曾在中国做英语老师，中英文都好，也喜欢旅行。双方共同做一个旅游英语沉浸营：

- 用户负责：路线计划、中文用户沟通、小红书 / 抖音内容、招募、报名、拍摄、素材运营。
- 美国朋友负责：英语老师身份背书、英语课程设计、旅途中英语教学、双语沟通。
- 产品形式：尼泊尔、印度尼西亚等低消费国家 10-15 天自由行小团。
- 招募方式：通过小红书 / 抖音发布路线视频、招募帖、真实旅行英语内容。
- 客群规模：第一次尝试 2-8 人，优先小团。
- 收入方式：用户支付高于自由行成本的团费，差额覆盖两位组织者的机票、住宿、吃饭、交通，并争取产生利润。
- 后续内容：旅途中拍摄的视频、直播、学员反馈和英语场景，反哺后续账号内容与课程产品。

这个方向吸引人的核心不是“便宜旅行”，而是：

> 零基础或低基础英语学习者，在真实海外旅行场景里，被一个会中文的组织者和一个外国英语老师陪着完成第一次开口、第一次自由行、第一次跨文化交流。

## 为什么适合用户

### 高匹配点

1. 用户热爱旅行、徒步、潜水、滑雪和真实世界体验。
2. 用户想学习英语、换环境，并探索一种更自由的生活方式。
3. 用户擅长内容拆解、路线设计、社交平台表达和复盘。
4. 用户有游戏设计经验，可以把英语学习做成任务制、关卡制和体验设计。
5. 旅行英语沉浸营比纯线上课更符合用户性格：需要真实场景、真实人物、真实素材和行动感。

### 和当前商业系统的关系

这条线属于 `旅行内容 / 线下体验副线`，但如果没有合适工作、小游戏方向继续失败、旅行英语出现真实付费信号，它可以升级为创业主线候选。

当前优先级判断：

| 情况 | 处理方式 |
| --- | --- |
| 拿到高质量工作 offer，例如月薪 3 万 | 把旅行英语沉浸营降级为副业，周末做线上内容、本地英语活动、AA 徒步或咖啡馆活动 |
| 找不到合适工作 | 可以把旅行英语作为创业方向候选，但必须先用内容和订金验证客源 |
| 外国朋友不同意 | 当前双人版本 pass，不强行推进 |
| 有陌生人付订金 | 进入首团筹备 |
| 长期无客源 | 不出国空耗，回到求职、接单或低成本内容验证 |

## 产品定义

### 推荐产品名

候选名称：

- 旅行英语沉浸营
- 第一次出国不哑巴小团
- 尼泊尔旅行英语 15 天沉浸营
- 印尼自由行英语破冰营
- 和外国老师一起旅行学英语

### 核心卖点

1. 真实旅行场景，不是教室背单词。
2. 小团陪伴，降低第一次出国和开口说英语的恐惧。
3. 美国英语老师同行，提供真实外语环境。
4. 中文组织者负责沟通、路线、生活协助和安全感。
5. 每天都有英语任务：机场、酒店、餐厅、交通、问路、购物、结识当地人。
6. 旅途中拍摄学习过程，形成个人成长记录。

### 目标用户

| 用户类型 | 痛点 | 购买理由 |
| --- | --- | --- |
| 零基础 / 低基础英语学习者 | 学了很多年但不敢开口 | 想在真实海外环境里破冰 |
| 第一次出国自由行的人 | 怕签证、机票、住宿、沟通出错 | 需要有人带着走第一遍 |
| 喜欢旅行但缺旅伴的人 | 一个人出国不安全、不敢做决定 | 小团和中外双组织者提供安全感 |
| 想换生活方式的人 | 想看看海外生活、学习英语和自由行 | 购买的是人生体验，不只是旅行 |
| 内容型学习者 | 想要一段可记录、可分享的成长经历 | 旅行过程可被拍摄和复盘 |

## 首版路线假设

首版目的地优先选择低消费、路线成熟、素材强、英语使用场景足够多的国家。

| 目的地 | 优点 | 风险 |
| --- | --- | --- |
| 尼泊尔 | 用户已有旅行经验，低成本，徒步和人生故事强 | 高海拔 / 徒步风险不可低估，路线强度要克制 |
| 印度尼西亚 | 低消费，海岛、潜水、旅居素材强 | 岛屿交通复杂，潜水等项目需交给当地合规机构 |
| 泰国 | 旅游成熟，英语场景丰富，执行难度低 | 同质化强，需要靠英语沉浸和小团氛围差异化 |
| 马来西亚 | 成本适中，华人环境降低风险，英语环境可用 | 旅行故事性可能不如尼泊尔 / 印尼强 |

首团建议优先选择“路线简单、医疗和交通更成熟、可控性更高”的目的地，不碰高风险徒步、深潜、滑雪等项目。潜水、滑雪、徒步进阶营放到后续版本。

## 产品交付设计

旅游英语沉浸营不能做成“边旅行边随缘学英语”。如果没有固定节奏，很容易出现两个问题：

1. 英语没有学好，只是听了几节松散的课。
2. 旅游没有玩好，因为学习、拍摄、集合和情绪管理打断体验。

所以首版必须明确交付结构：每天有英语任务、旅行场景、复盘时间和天气预案，不把所有体验都压到户外出游上。

### 标准日节奏

推荐采用“上午训练、下午场景、晚上复盘”的结构。

| 时间 | 内容 | 目标 |
| --- | --- | --- |
| 上午 60-90 分钟 | 室内英语训练：当天句型、关键词、角色扮演 | 出门前降低开口恐惧 |
| 中午 / 下午 | 真实旅行场景任务：点餐、问路、买票、酒店、交通、购物 | 把英语用于真实场景 |
| 傍晚 | 自由活动 / 拍照 / 休息 | 保留旅行感，不把行程变成补习班 |
| 晚上 45-60 分钟 | 复盘：今天用了哪些句子、哪里卡住、明天预习 | 形成学习闭环 |

首团不追求每天高强度上课，而是追求“每天确实开口、确实用到、确实复盘”。

### 户外与课堂的关系

出游不是在景点硬上课，而是把景点当作英语任务场。

建议节奏：

1. 到达地点后先自由拍照、观察和体验。
2. 组织者集合 10-15 分钟，布置一个小任务。
3. 学员两人一组或跟老师完成任务。
4. 回到咖啡馆、餐厅或住宿点后复盘。

示例任务：

- 自己用英语点一杯饮料。
- 问当地人一个路线问题。
- 和酒店前台确认退房时间。
- 向潜店 / 雪场 / 徒步向导询问价格和注意事项。
- 用英语讲述今天最喜欢的一个地方。

核心原则：

> 旅行负责提供真实语境，英语课负责让用户敢开口；两者不能互相抢时间。

### 雨天和天气预案

天气不能只当突发事件处理，报名页和行前说明里就要写清楚：行程会根据天气调整，雨天不等于退款或失败，而是切换到室内英语任务。

可用雨天方案：

| 场景 | 可做内容 |
| --- | --- |
| 咖啡馆 | 点单英语、闲聊英语、陌生人问候、当天口语复盘 |
| 酒店 / 民宿公共区 | 角色扮演、发音纠正、行程英语、旅行问题演练 |
| 商场 / 超市 | 购物、问价、退换货、找商品 |
| 博物馆 / 展馆 | 看展描述、问工作人员、讲述一个展品 |
| 联合办公空间 | 数字游民主题英语、旅行计划展示 |
| 餐厅 | 点餐、过敏忌口、结账、AA、推荐菜 |

雨天判断规则：

- 小雨：保留近距离低风险行程，减少户外时长。
- 大雨：取消户外行程，改为室内任务 + 英语复盘。
- 极端天气：优先安全，取消或延期当天活动。

### 退款和取消规则草案

退款规则必须在报名页、付款前说明和服务协议里提前写清，不能等现场用情绪沟通。

以下是首版业务规则草案，正式收费前仍需单独核查法律与合同文本。

| 情况 | 建议规则 |
| --- | --- |
| 未达到最低成团人数 | 全额退订金，或用户自愿顺延到下一期 |
| 用户在确认成团前取消 | 订金可退 |
| 用户在确认成团后、组织者已产生不可退成本前取消 | 退还扣除必要手续费后的费用 |
| 用户在机票 / 住宿 / 当地项目已锁定后取消 | 只退还可退部分，不可退成本由用户承担 |
| 用户到达目的地后中途退出 | 已发生的课程、组织服务、住宿交通和第三方费用不退；未发生且可退部分按规则处理 |
| 因个人情绪、不适应、不想继续而退出 | 按中途退出规则，不做全额退款承诺 |
| 因组织者原因导致无法履约 | 退还未发生服务费用，并协助处理已发生第三方费用 |
| 因天气导致行程调整 | 不直接触发退款，改为室内课程或替代行程 |
| 因不可抗力导致无法继续 | 优先安全，按未发生且可退部分处理 |

核心原则：

1. 订金用于验证意向，必须写清可退截止时间。
2. 成团后不要替用户大额垫付不可退项目。
3. 第三方费用尽量让用户自己向平台或商家支付。
4. 组织服务费和英语教学费要与机票、住宿、项目费用分开写。
5. 到达目的地后第一天必须完成尾款确认，否则不进入正式服务。

### 情绪照顾和团员管理

小团服务最难的不是路线，而是人。2-8 人团里，只要有一个人持续不满，就会拖垮组织者、老师和其他学员体验。

首团必须做团员筛选，不是什么人都收。

适合的人：

- 接受小团试验性质。
- 能接受低成本自由行，不追求豪华保姆团。
- 英语基础弱但愿意开口。
- 愿意遵守集合时间和基本团队规则。
- 能接受天气导致行程调整。
- 对拍摄和内容记录边界能提前沟通。

不适合的人：

- 期待全程保姆式服务。
- 对住宿、餐饮、交通有高舒适要求但不愿提高预算。
- 完全不愿开口，只想被动听课。
- 强烈抗拒拍摄但又希望参与内容活动。
- 经常迟到、临时变卦、情绪勒索。
- 把 10000 元理解成“所有问题都应该由组织者兜底”。

情绪管理机制：

| 节点 | 动作 |
| --- | --- |
| 报名前 | 用问卷筛选动机、预算、英语水平、旅行经验和期望 |
| 出发前 | 开一次线上说明会，把行程强度、住宿标准、退款规则讲清楚 |
| 每天晚上 | 10 分钟匿名反馈或口头反馈，及时调整 |
| 出现不满 | 先区分是可解决问题、期望错位，还是个人情绪问题 |
| 严重冲突 | 以团队安全和整体体验优先，必要时停止对单人的额外照顾 |

### 服务边界

必须提前说明：这不是传统旅行社豪华团，也不是封闭式英语学校。

可承诺：

- 提供旅行英语课程设计。
- 提供每日英语任务和复盘。
- 提供路线建议、集合安排和基础协助。
- 提供低成本自由行经验分享。
- 提供中外双语沟通支持。
- 协助联系当地项目或服务商。

不能承诺：

- 保证英语水平显著提升。
- 保证旅行中每天都是好天气。
- 保证所有景点都能如期完成。
- 保证客户一定玩得开心。
- 保证当地项目、交通、住宿完全不出问题。
- 代替旅行社承担完整旅游履约责任。
- 代替保险、医院、使领馆处理所有突发事件。

产品宣传必须避免“包教会、包开心、包安全、包省心”这类表述。更准确的表达是：

> 我们提供一个低成本海外小团场景，让你在真实旅行中被陪伴着开口说英语；它不是豪华旅行团，也不是保证结果的英语培训班。

## 收入模型

### 原始定价假设

假设某低消费国家 15 天自由行的基础成本约为：

| 项目 | 单人成本 |
| --- | ---: |
| 往返机票 | 包含在 5000 元估算内 |
| 住宿 | 包含在 5000 元估算内 |
| 当地交通 | 包含在 5000 元估算内 |
| 基础餐饮 / 活动 | 包含在 5000 元估算内 |
| 合计 | 5000 元 |

对外收取 `10000 元 / 人`，则每名学员理论毛利为 `5000 元`。

### 组织者成本与利润测算

假设两位组织者自己的机票、住宿、交通、吃饭总成本合计为 `10000 元`。

| 报名人数 | 收入 | 学员旅行成本 | 学员毛利 | 组织者成本 | 经营利润 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2 人 | 20000 | 10000 | 10000 | 10000 | 0 |
| 3 人 | 30000 | 15000 | 15000 | 10000 | 5000 |
| 4 人 | 40000 | 20000 | 20000 | 10000 | 10000 |
| 8 人 | 80000 | 40000 | 40000 | 10000 | 30000 |

解释：

- 2 人报名可以覆盖两位组织者的出行成本，但严格说不是经营利润。
- 3-4 人报名才开始出现经营利润。
- 8 人报名才接近一个较健康的小团模型，但管理难度、风险和服务压力也会明显上升。

### 额外服务费

可选收入项：

| 服务 | 收费口径 | 注意 |
| --- | --- | --- |
| 签证 / 机票协助 | 100 元 / 人起 | 尽量定义为协助，不承诺办理成功 |
| 当地项目报名协助 | 固定服务费或合作返点 | 潜水、滑雪、徒步等必须交给当地合规机构 |
| 旅行英语课前训练 | 可包含在团费内，也可单独售卖 | 可沉淀为后续线上产品 |
| 视频记录 / 成长短片 | 作为赠品或升级包 | 要提前取得拍摄授权 |
| 后续线上复训 | 199-999 元 | 由第一次旅行素材反哺课程产品 |

## 合作分工

### 用户职责

- 目的地调研和路线计划。
- 小红书 / 抖音内容发布。
- 招募帖、报名表、私信转化。
- 学员中文沟通、需求筛选、群管理。
- 旅行素材拍摄、剪辑、发布和复盘。
- 预算表、行程表、装备表、风险提示。
- 与当地服务商、住宿、交通、活动方沟通。

### 美国朋友职责

- 英语课程设计。
- 每日旅行英语任务和复盘。
- 旅途中英语陪练。
- 外国人英语老师身份背书。
- 出镜拍摄、直播或短视频合作。
- 必要时协助跨文化沟通。

### 合伙前必须谈清楚

| 问题 | 必须明确 |
| --- | --- |
| 时间投入 | 一次首团至少预留多少天？是否能连续做？ |
| 收入分配 | 毛利如何分？是否先扣除双方成本？ |
| 无客源怎么办 | 几天 / 几周无报名就暂停？谁承担吃住？ |
| 内容权益 | 视频、肖像、账号素材归属和使用范围 |
| 退款责任 | 用户取消、航班变动、天气导致取消如何处理 |
| 事故责任 | 生病、受伤、财物损失、目的地风险由谁处理 |
| 长期方向 | 这只是一次旅行，还是准备连续做成业务？ |

## 最大风险

### 1. 合伙人风险

这是当前第一风险。

如果美国朋友不同意、时间不稳定、不愿出镜、不愿承担教学责任，当前版本不成立。用户一个人也可以继续做旅行内容和英语学习，但不能用同一个产品承诺。

防线：

- 先和朋友做一次深聊，不直接谈宏大创业，先谈一次 10-15 天首团试验。
- 用书面方式确认分工、预算、收益分配和退出机制。
- 不让朋友承担用户没有明确付费前的长期吃住压力。

### 2. 客源风险

没有客源，两个人在海外等报名会快速消耗现金。

防线：

- 先内容预售，不先出国。
- 至少拿到 2 个陌生人订金再启动。
- 订金建议可退，但要设明确退款截止时间。
- 30 天无有效留资或订金，暂停首团筹备。

### 3. 现金流风险

这个模式前期容易产生垫资：机票、住宿、签证、设备、拍摄、踩点、广告投放。

防线：

- 不提前替用户大额垫付。
- 用户机票、保险、部分住宿尽量让用户自己在平台下单。
- 团费分阶段收取：订金、确认款、出发前尾款。
- 设置最低成团人数，不成团即退款或延期。

### 4. 安全和责任风险

小团出国涉及疾病、交通、护照丢失、突发事件、极限项目和当地治安。

防线：

- 首团不做高海拔、高风险、深潜、滑雪等项目。
- 所有人必须自行购买境外旅行保险。
- 高风险项目只联系当地正规机构，不自行承诺教学和安全保障。
- 出发前签署服务边界、风险告知和拍摄授权。

### 5. 交付体验风险

旅行英语沉浸营可能出现“英语没学好，旅游也没玩好”的双输体验。

典型触发原因：

- 每天没有固定课程节奏。
- 户外行程和英语任务互相打架。
- 雨天没有室内替代方案。
- 学员期待豪华团或保姆式服务。
- 团员英语水平、旅行经验和消费预期差异太大。
- 退款边界没讲清，现场产生情绪拉扯。

防线：

- 报名前明确适合谁、不适合谁。
- 每天固定“训练 + 场景 + 复盘”结构。
- 所有户外行程都有雨天室内替代任务。
- 出发前完成服务边界、退款规则和拍摄授权确认。
- 首团控制在 2-4 人，不追求人数最大化。

### 6. 合规风险

即使不打旅行社或培训机构名义，只要公开招募、收费、组织出行、安排住宿交通和当地服务，就可能接近旅游经营边界。此风险不能简单视为不存在。

处理原则：

- 首版内部按“英语沉浸体验服务 + 自由行协助”设计，但仍需单独核查目的地、中国境内招募和收款的合规边界。
- 机票、住宿、当地项目尽量让用户直接向平台或当地机构支付。
- 后续如果做大，应考虑和有资质旅行社、当地持证机构或正规教育 / 旅游服务方合作。

## 验证路径

### 阶段 0：合伙人确认

过闸标准：

- 美国朋友明确同意做一次首团试验。
- 双方确认时间、分工、收益、成本、退出机制。
- 双方都接受“没有客源就暂停，不在海外空耗”。

不过闸动作：

- 外国朋友不同意：当前双人沉浸营版本 pass。
- 用户可保留旅行英语内容号，先作为个人英语学习和旅行内容实验。

### 阶段 1：内容预售

执行：

- 制作 1 条具体路线方案。
- 发 10-20 条小红书 / 抖音内容。
- 发布招募帖。
- 建立报名表。
- 设置 `499 元可退订金` 或等价意向确认。

过闸标准：

- 至少 2 个陌生人愿意交订金。
- 至少 10 个有效咨询 / 留资。
- 私信中有人能接受 `8000-12000 元` 的价格区间。

不过闸动作：

- 不出国。
- 复盘内容钩子、目的地、价格和人群。
- 继续低成本内容测试。

### 阶段 2：首团执行

建议首团规模：

- 最低：2 人。
- 舒适：3-4 人。
- 上限：6-8 人。

首团目标不是利润最大化，而是拿到：

- 完整行程执行经验。
- 学员真实反馈。
- 旅途英语教学素材。
- 小红书 / 抖音连续内容。
- 下一团报名线索。
- 可复用路线、预算、话术和清单。
- 可验证的课程节奏、雨天预案、退款规则和服务边界。

### 阶段 3：复盘与升级

复盘指标：

| 指标 | 判断 |
| --- | --- |
| 成团人数 | 是否达到最低 2 人 |
| 毛利 | 是否覆盖两位组织者成本 |
| 学员满意度 | 是否愿意公开评价或转介绍 |
| 内容产出 | 是否形成 20 条以上可发素材 |
| 下一团线索 | 是否有人询问下一期 |
| 合伙稳定性 | 双方是否还愿意做第二团 |
| 现金流 | 是否没有伤害个人生存桶 |
| 交付体验 | 是否没有出现“英语没学好、旅游也没玩好”的核心投诉 |
| 规则有效性 | 退款、天气、情绪和服务边界是否提前讲清并被接受 |

加码条件：

- 首团后至少 1 名学员愿意转介绍。
- 下一团有明确咨询或订金。
- 双方合作没有严重消耗。
- 内容带来持续私信。
- 学员认可课程节奏和旅行体验没有互相冲突。

砍掉条件：

- 首团体验混乱、投诉多、合伙人消耗大。
- 无法稳定获客。
- 毛利不足以覆盖组织者成本。
- 安全、合规或签证问题不可控。
- 学员普遍认为学习和旅行都不够满意。

## 内容策略

### 账号定位

推荐定位：

> 一个游戏开发者和美国英语老师，带零基础普通人去低成本国家完成第一次旅行英语破冰。

### 内容支柱

| 内容类型 | 示例 | 目标 |
| --- | --- | --- |
| 旅行英语场景 | 机场、酒店、餐厅、问路、打车、潜店、徒步 | 建立产品价值 |
| 路线计划 | 尼泊尔 15 天预算、印尼 10 天路线 | 测试收藏和咨询 |
| 合伙人故事 | 中国组织者 + 美国老师的组合 | 建立信任 |
| 英语破冰 | 零基础如何第一天开口 | 命中痛点 |
| 真实招募 | 首期 2-4 人小团测试 | 转化报名 |
| 旅行复盘 | 每天学了什么、用了什么英语 | 后续课程素材 |

### 招募帖结构

```text
标题：第一次出国不敢说英语？我们想招 2-4 个人去尼泊尔做一次旅行英语沉浸营

开头：点明痛点和目标人群。
中段：路线、天数、价格区间、适合谁、不适合谁。
信任：美国朋友英语老师身份 + 用户旅行经验。
边界：小团试验，不是豪华团，不适合追求全程保姆式服务的人。
动作：评论 / 私信关键词，填写报名表。
```

## 当前结论

这是一个可以直接进入“合伙人确认 + 内容预售”的商业实验。

但它不是靠想象成立，而是靠两个硬信号成立：

1. 美国朋友愿意投入一次真实首团。
2. 陌生人愿意为这条路线支付订金。

只要这两个信号没有出现，就不出国、不垫资、不让两个人一起陷入现金流风险。

最小下一步：

1. 和美国朋友认真谈一次。
2. 做一条尼泊尔或印尼路线草案。
3. 发 10 条旅行英语内容。
4. 发布一次首团招募。
5. 以 2 个陌生人订金作为是否启动的硬闸门。
