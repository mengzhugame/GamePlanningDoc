产品计划：

阶段一：7天冲刺 -> “可玩骨架”原型 (Playable Skeleton)

目标： 验证核心玩法的“手感”和“乐趣”。而不是给任何人看，是给你自己建立信心。

内容： 使用最简单的几何图形（圆形、方形）作为化妆品，实现三消的核心逻辑。你只需要验证：匹配消除的瞬间是否爽快？连续消除的反馈是否足够吸引人？这个阶段，速度高于一切，完美主义是敌人。

产出： 一个你自己玩的、可能很丑但核心玩法成立的APK。

阶段二：1个月迭代 -> “垂直切片”Demo (Polished Demo)

目标： 制作一个能够直接展示给发行商或投资人的、有吸引力的版本。这就是你说的“80%”。

内容：

美术落地： 基于我们之前讨论的“美术风格宪法”，将几何图形替换成风格统一的、精美的化妆品图标。

核心循环完整化： 包含完整的“一局”体验，从开始游戏 -> 游戏过程 -> 胜利/失败结算 -> 回到主界面。

加入Meta元素： 这是让你的三消与众不同的关键。比如，过关后可以获得一种“口红”，用来解锁一个虚拟化妆台上的一个新摆件。这个简单的“收集与装饰”系统，是你未来向B和C路径探索的种子。

音效与UI： 加上基础的UI和画龙点睛的音效（比如消除时的清脆声）。

产出： 一个任何人拿到手，都能在5分钟内get到游戏核心乐趣和长期潜力的APK。这个版本，才是你的“融资/发行敲门砖”。

商业计划：

·  阶段一：产品验证 (Proof of Product)。 这是我们讨论的7天冲刺和后续迭代的核心。在这个阶段，忘掉所有品牌。使用虚拟的、通用的化妆品。你的唯一目标，是证明你做的这款三消游戏本身是好玩的、有足够吸引力的、能让玩家留存下来的。你需要用数据（次日留存、七日留存、游戏时长）来证明你的产品价值。

·  ·  阶段二：案例验证 (Proof of Concept)。 当你的游戏拥有了第一批稳定的核心用户（比如，日活跃用户达到1万人）之后，启动你的商业计划。但此时不要去找欧莱雅或雅诗兰黛。你的目标，应该是一家互联网原生的、新锐的、渴望曝光度的小众美妆品牌。你可以向他们提供一个无法拒绝的条件：免费或以极低的“友情价”进行植入合作。你的目的不是赚钱，而是为了获得一个真实的、可以写进商业计划书的**“成功案例”**。

·  ·  阶段三：商业扩张 (Proof of Business)。 当你手握“一个数据优秀的产品”和“一个与真实品牌的成功合作案例”这两张王牌时，你才有资格和筹码，去与大品牌和投资人，讲述你那个“改变商品广告模式”的宏大故事。

第一阶段：产品打磨 (接下来的1个月)

唯一目标： 忘掉所有商务合作。将你的7日原型，打磨成一个美术精良、体验流畅、能完整体现核心玩法乐趣的**“可测试Demo”**。

第二阶段：发行测试 (第二个月)

唯一目标： 将你的Demo提交给2-3家广州的中小型、专注于小游戏的发行商。让他们用最标准、最常规的方式，去做第一轮数据测试（买几千块钱的量，跑一下CPI和次留数据）。

第三阶段：商务启动 (第二个月底，前提是数据良好)

唯一目标： 拿着发行商给你的、客观亮眼的数据报告，去接触一家你最心仪的新锐美妆品牌。

你的说辞： “我的游戏经过初步市场验证，用户数据很好。现在我准备启动一个‘玩游戏送样品’的营销活动，我将免费为您的品牌提供游戏内的所有植入，您只需要提供50-100套样品作为活动奖品，我们共同见证这次合作带来的品牌曝光。”

关键： 先和一家跑通这个合作模式，把它做成一个成功案例。

第四阶段：联合引爆 (第三个月及以后)

目标： 拿着“优秀的游戏数据”+“与XX品牌的成功合作案例”，你现在可以同时与发行商和更多品牌方去谈一个更大规模的、三方共赢的联合发行和营销计划。

盲区一：主导权的博弈——如何避免沦为“打工仔”？

常规做法： 拿着Demo去找发行商，发行商点头，你签约。此时，你的筹码最少。

反制策略： 创造你自己的“数据筹码”。在你去找发行商之前，自己花一笔小钱（比如1000-2000元），只做一件事：用你那个“玩游戏送口红”的创意，制作3-5个不同的15秒视频广告素材，在抖音上进行CPM（千次展示）或点击率(CTR)测试。你甚至不需要游戏能玩，你只需要测试这个“钩子”的吸引力。

你的谈判优势： 如果你的视频跑出了一个远超行业平均水平的点击率，你就拥有了第一个可量化的、极具说服力的筹码。你去找发行商时，说辞就变成了：“看，我的营销概念已经被市场初步验证，它的吸量能力极强。现在，我需要你们专业的发行能力，来验证它后续的留存和变现。” 这让你从一个“寻求机会者”，变成了一个“带着机会来合作”的人。

盲区二：利润的分配——如何守住你的核心蛋糕？

常规做法： 接受发行商50/50的流水（扣除渠道费和买量成本后）分成合同。

反制策略： “拆分收益模型”。在谈判时，你要极力主张，将游戏收益分为两部分：

游戏内生收益： 即内购(IAP)和广告变现。这部分，是发行商的核心价值所在（买量-变现），你可以接受标准的50/50分成。

品牌合作收益： 即你通过商务拓展，从美妆品牌方获得的赞助费/植入费。你要强调，这是你独有的、发行商无法提供的商业资源。因此，这部分收益需要采用一个对你更有利的分成比例（比如你70%，发行商30%）。

你的谈判优势： 这种拆分是合乎商业逻辑的。它能保护你最核心的商业模式创新，让你在出让游戏运营利润的同时，守住你的“根据地”。

盲区三：模式的复刻——如何跑得比模仿者更快？

常规做法： 担心自己的模式被发行商用到别的游戏上。

反制策略： 深度绑定，打造“样板工程”。你要让发行商和你合作的这个项目，成为他们内部的“明星项目”和“样板工程”。你要积极地、深度地参与到运营和市场策略的制定中，不断提供美妆行业的洞察，帮助他们把这个模式的潜力挖掘到极致。

你的护城河： 当别的公司开始模仿“送样品”这个点子时，你和你的发行商，可能已经和3-5个新锐品牌建立了深度合作，甚至开始探索“游戏内联名定制”等更高级的玩法。你的护城河不是这个想法，而是你与发行商、品牌方三者之间形成的、高效运转的合作生态

我们来重新定义你和发行商的角色分工：

你的核心任务 (CEO & 产品经理):

1.打造一个数据能打的顶级产品。 这是你所有谈判地位的基石。

2.成为商务拓展的先锋。 你去搞定第一家品牌合作，为这个“样品换流量”模型提供“弹药”。

发行商的核心任务 (市场部 & 数据部):

1.成为数据分析的“最强大脑”。 他们告诉你，什么样的用户最值钱，什么样的广告素材转化率最高。

2.成为买量投放的“特种部队”。 他们负责在复杂的流量平台（抖音、微信）上，用最高效的方式，将你的游戏精准地送到用户面前。

这个Demo必须能同时证明两件事：

1.游戏本身好玩： 即我们之前讨论的，一个拥有“锁与钥匙”核心玩法、美术精良、体验流畅的至少30关的版本。这能证明它的留存潜力。

2.商业模式有潜力： 游戏内必须做出一个完整的、即使没有真实品牌入驻的**“活动流程”。比如，一个“活动中心”的UI，点击后可以看到“玩XX关，赢取XX口红样品”的活动界面，点击领取后，会弹出“请关注XX公众号/抖音号领取”的提示。这能向发行商直观地展示你那个“样品换流量”模型的商业想象空间**。

·  什么游戏机制让我自己玩了停不下来？（核心乐趣）

·  这个机制可以套什么题材？（皮肤）

·  这个题材有商业价值吗？（变现）

·  如果留存率<10%，说明核心玩法不成立→该放弃

·  如果留存率>30%但发行商还是拒绝，说明是发行策略问题→该调整推广方式

·  如果女性用户占比>70%，说明题材方向对→继续深化美妆元素

·  如果美术评分很低，说明该升级视觉→找外包或学习

## 独立工作室商业模式：不是"做一款卖一波"

### 0. 核心结论（2024-2026 行业数据反推）

- 独立工作室收入结构必须多层化，不能只押首发销量。
- 盈利周期是「**长预热 + 短爆发 + 长尾回收 + 目录复利**」，不是线性回本。
- 真正稳定的工作室靠组合拳：首发现金流 / 折扣长尾 / DLC/版本更新 / 平台活动 / 旧作目录 / 必要时外包接案输血。
- **下一款比上一款更容易卖，才说明工作室真的在变强**。

### 0.1 Steam 独立游戏收入分层（VG Insights 2024）

| 层级 | 团队规模 | 销量量级 | 收入量级 |
|------|---------|---------|---------|
| Hobbyists | 1-2 人 | 2k-20k 份 | ~5 万美元 |
| Small teams | 3-15 人 | 20k-200k 份 | ~100 万美元 |
| Middle market | 15-50 人 | 20w-100w 份 | ~1000 万美元 |
| Triple-i | 50+ 人 | 100w+ 份 | ~5000 万美元 |

**关键发现**：第三款游戏平均收入 > 第二款 > 第一款。说明独立工作室真正的商业模式不是"单作梭哈"，而是**通过连续发售积累能力、受众与平台信任**。

### 0.2 愿望单是财务预测工具，不是万能护身符

- 愿望单转销量：保守按 10-20% 倒推首年销量
- 理想：**70%+ 愿望单来自自然且区域匹配的流量**，否则首发转化会虚胖
- 内容合作带来愿望单成本约 $0.5-3/个，付费社媒约 $1-5/个
- Early Access 的愿望单转销量约比正式版低 8%

### 0.3 营销预算必须从"回本模型"倒推

不要拍脑袋说"开发成本 20-30%"。真正算法：

```
1. 算 Steam 抽成 + 税费 + 退款后的净收入
2. 按愿望单转销量倒推需要多少愿望单
3. 再决定素材/demo/节庆/达人/社区分别投入多少
```

**预算不是成本表，是生死线**。

### 0.4 真正健康的工作室：目录复利

Devolver Digital 2024 财报：1.048 亿美元收入 / **88% 来自旧作目录**。
Team17 / Everplay 目录收入占比 ~92%。

**对独立工作室的硬要求**：
- 首作不是一次性项目，是未来折扣季 / 捆绑包 / DLC / 平台移植 / 续作导流的资产
- 哪怕首作体量不大，也要思考后续能否做版本更新 / 活动返场 / 世界观延展 / 素材复用
- **没有目录，工作室每次开新项目都像失忆重生，现金流会极其难看**

### 0.5 独立工作室四种商业模式组合

| 模式 | 适合 | 核心风险 | 补法 |
|------|------|---------|------|
| A. Premium 首发 + 折扣长尾 | PC/Steam 导向、完整度高 | 首发不佳就断气 | demo + Next Fest + 精准愿望单 |
| B. Premium + DLC/soundtrack/supporter pack | 世界观/美术/构筑可延展 | 本体没立住附加包卖不动 | 先把主作做稳 |
| C. 原创 + 接案/外包/工具收入 | 早期现金流脆弱 | 团队精力被吃光 | 外包只能当输血包，不能反客为主 |
| D. 工作室产品线 | 同题材/受众/技术栈持续产出 | — | 受众 + 素材 + 商店页 + 模板 + 社区全复用 |

### 0.6 盈利周期 6 段

1. **立项期**：无收入，验证题材和开发成本边界
2. **预热期**：商店页 + 内容传播 + demo + 试玩节，积累愿望单与社区
3. **首发期**：收入峰值，但退款 + 折扣 + 平台抽成 + 宣发回收一起发生
4. **修正期**：根据评价与数据快速补版本，避免首发势能浪费
5. **长尾期**：节庆折扣 + 版本更新 + 捆绑包 + 达人二次传播
6. **目录期**：旧作为新作导流，新作反过来抬旧作销量

### 0.7 一句话钉死

> **独立工作室真正的商业模式，不是靠一款游戏暴富，而是把每一款游戏都做成下一款更容易赚钱的资产。**

## 平台政策深度对比（微信 / 抖音 / Steam / Apple / Google）

> **核心认知**：平台不是收过路费的收费站，而是决定你产品长什么样、怎么赚钱、该先打哪场仗的"半个制作人"。

### 微信小游戏（2026 政策）

| 政策 | 内容 |
|------|------|
| 首发新游 IAP 激励 | 前 1000 万流水不分成；月流水破 1000 万可冲到「5000 万流水不分成」区间，阶段性按 **40% 激励金**结算 |
| 非首发新游 | 首 100 万流水不分成 |
| IAA 激励（2026.02 起） | 「前 30 天广告流水 40%」或「前 90 天广告流水 35%」；>45 天回流用户可重新计入激励 |
| 混合变现判断 | 内购流水 /（内购+广告）≥30% = 混合变现 |
| iOS 侧 | 符合 MAPP 计划的小游戏，开发者可获 ~88% 苹果内购流水 |

**真实打法**：
1. **首发价值远大于补量价值** — 别随便先丢小渠道把资格打烂
2. **买量逻辑是"回收广告金"** — ROAS 要把激励金 / 主体转移 / 365 天使用时效一起算
3. **长线活跃比短线洗量更值钱** — 30 天扩 90 天 = 平台奖赏"能留住人"的游戏

### 抖音小游戏

底层逻辑：**流量不是分给你，是你用内容抢来的**。

- 首发激励 + 暑期/春节档扶持
- 2026 主轴：内容生态 + 社交裂变 + AI 驱动创意
- 增长密码：**「魔性内容」+ 可被短视频切片传播的瞬间**

**核心规律**：
1. 先有可传播片段，后有稳定买量
2. 强题材钩子 > 复杂系统深度
3. 视频素材本身就是产品的一部分

### Steam

**愿望单很重要，但别当算法万能钥匙**：

- 曝光核心看玩家购买 / 游玩 / 评测等真实表现
- 愿望单通常不直接影响算法曝光（除非「热门即将推出」等少数场景）
- 愿望单价值：发行时触发通知 + EA 转正式版通知 + **20%+ 折扣持续 8 小时以上**触发通知

**真实策略**：
1. 先用商店页和节庆活动攒愿望单，再靠首发表现兑现曝光
2. 愿望单不是曝光因，是转化放大器
3. 决定后劲的是首发购买表现 + 评价 + 本地化覆盖 + 后续更新轮次

### Apple App Store

**Small Business Program**：
- 前一年 + 当年累计 proceeds ≤ 100 万美元 → 15% 抽成
- 超过 100 万后恢复标准抽成
- 次年再次低于阈值，可重新回 15%
- **关联开发者账号会被审查**，分壳公司不一定能绕过

**小团队默认应先把 15% 资格吃满**。账号归属 / 主体规划 / 应用转移都会影响资格判断，创业初期就要设计好。

### Google Play

**费率工具箱**：
- 前 100 万美元收入 15%，超出 30%
- 自动续订订阅 15%
- 「99% 付费开发者有资格通过不同项目获得 15% 或更低费率」
- 印度 / 韩国可下调 4%（需提供符合政策的替代支付）

**Google 比 Apple 更像费率工具箱，要主动报名、主动配置**。

### 横向对比

| 平台 | 平台奖励什么 | 最该盯指标 | 最容易犯错 |
|------|------------|-----------|----------|
| 微信小游戏 | 首发 + 留存 + 激励金回收 | 首发资格 + 30/90 天留存 + 回流激励 | 浪费首发资格；只算名义抽成不算补贴 |
| 抖音小游戏 | 内容传播 + 素材爆点 | 视频完播 + 试玩点击 + 评论传播 | 当传统买量产品做 |
| Steam | 首发表现 + 评价 + 标签 + 节庆 | 愿望单转化 + 首发销量 + 评价 | 迷信愿望单数字 |
| Apple | 账号合规 + 15% 资格 | proceeds 阈值 + 账号结构 | 不申请小企业计划 |
| Google Play | 费率方案组合 | 15% 档位 + 订阅占比 + 地区支付 | 以为默认就能吃到最低费率 |

**结论**：
- 放大社交裂变 + 现金激励 → **微信**
- 放大内容传播 + 爽点切片 → **抖音**
- 建立品牌口碑 + 愿望单池 + 长尾促销 → **Steam**

## 蓝海与红海战略：品类切口与市场进入

### 核心命题

不是问「做什么游戏」，而是问「**从哪个小门切进去，能先活下来，再逐步做大**」。

### 「切口五件套」框架

| 件 | 内容 | 标准 |
|----|------|------|
| 1. 认知熟悉度 | 玩家 3-5 秒能明白你大概是什么 | 塔防 / 肉鸽 / 卡牌构筑 / 生存建造 / 合成经营 等熟词 |
| 2. 差异钩子 | 凭什么值得点进来 | 强视觉奇观 / 强题材反差 / 强机制新鲜感 / 强社交主播传播性 |
| 3. Demo 可证性 | 差异钩子在 Demo 里被证明 | 不是写在商店页上自嗨 |
| 4. 渠道适配性 | 切口必须和渠道一起选 | Steam 吃标签转化；抖音吃 3 秒钩子；微信吃短局社交 |
| 5. 后续扩展性 | 第一眼够窄，做起来能往外扩 | 不要窄到锁死自己 |

### 关键发现（2025-2026 数据）

- **GameDiscoverCo 2025-06**：Steam 单日新作 16 天后多数卖不动；冲到 >$20k 毛收入的极少。「Genre choice is a game changer… Small, focused games in the right niche are the big winners.」
- **How To Market A Game 2025-03**：Next Fest 数据，预热前愿望单基数与活动结果相关系数 0.825。co-op 即便 demo 转化不高，仍能冲到 30K 愿望单（朋友局天然带动）。
- **How To Market A Game 2026-02**：Steam Popular Upcoming 板块约 5,000-7,000 愿望单可进。但一周同期发售游戏越多，被顶下去越快。
- **How To Market A Game 2025-11**：VS-like 头部三款已吃 75%+ 市场份额。**红海玩法形成寡头时，后来者只是「更像它」基本等死**。正确打法：(a) 还没完全寡头化前快速切进去；或 (b) 故意偏航，做相邻品类混血。

### 立项前的硬审判（每次迭代过 3 问）

1. 玩家看 5 秒视频，能不能秒懂「核心钩子」是主角？
2. 玩家玩 10 分钟 Demo，能不能至少完成一次「核心爽点」高光时刻？
3. 玩家看完后，能不能自然把它描述给朋友？而不是只能说「一个塔防，反正还行」？

三条有一条不成立，说明切口还没打透。

### 一句话结论

> **真正的蓝海，不是没人做，而是你能用一个足够窄、足够狠、足够好传播的切口，先把第一批玩家狠狠干下来。**

## 工作室品牌架构：从单作IP走向持续发售能力

### 核心命题

IP 品牌化解决的是「别人记住你」；产品矩阵解决的是「别人下一次还会继续买你」。

### 五种护城河（独立工作室真正有用的）

| 护城河 | 内容 | 案例 |
|--------|------|------|
| 1. 机制护城河 | 不是新，而是「被你做成招牌」 | Balatro = 扑克概率 + 构筑爆发 + UI 反馈 + 直播可读性 |
| 2. 审美护城河 | 低成本团队最容易建立，最容易被忽视 | Tiny Glade = 一眼能认出 |
| 3. 社区护城河 | 算法给流量，社区给复利 | 死亡细胞免费更新+付费 DLC 交替；苍翼联动提前半年公布愿望单+300% |
| 4. 叙事/IP 护城河 | 不是写世界观文档，是建立可扩展宇宙 | 角色短篇 / Discord RP / 日志设定碎片 / 周边试水 |
| 5. 业务护城河 | 发行关系 / 复用管线 / 信用口碑 | Outersloth / Pocketpair / Bigmode / Hooded Horse 等品类聚焦发行品牌 |

### 工作室品牌四层架构

```
第一层：母品牌承诺（Studio Promise）
  我们持续提供哪类体验？所有立项的过滤器
第二层：产品线（Product Line）
  围绕同主题/情绪/用户群扩同心圆
第三层：识别体系（机制 + 视觉 + 情绪 + 社区 + 商业 五层）
第四层：目录飞轮（旧作养新作，新作抬旧作）
```

### 目录复利不是大公司特权（2024-2026 数据）

- Devolver Digital 2024：1.048 亿美元收入，88% 来自 back catalog
- Team17 / Everplay：目录收入占比 ~92%

**对小团队的启发**：
1. 第一款产品不是一次性交付物，是目录资产
2. 第二款产品不是重新创业，是要接住第一款留下的认知
3. 每次发新作都像开新账号 = 根本没有品牌架构，只有项目尸体堆

### 一句话总结

> **爆款只能带来一次收入，护城河和 IP 品牌化，才能让下一款游戏还没出生就先赢半步。**

## 工作室产品矩阵设计：从单作 IP 到持续发售能力

**核心命题**：IP 品牌化解决「别人记住你」，产品矩阵解决「别人下一次还会继续买你」。

### 产品线三层结构

| 层 | 用途 | 风险 |
|---|------|------|
| **旗舰线** | 最能代表工作室的主品牌产品，立口碑 | 资源集中，失败代价大 |
| **实验线** | 低成本测试新机制 / 新题材 / 新商业化 | 容易失焦，需限制资源 |
| **衍生线** | 围绕现有世界观 / 角色 / 美术 / 玩法做 DLC / 番外 / 轻量衍生 | 不能稀释主品牌 |

### 三种实用产品矩阵打法

| 打法 | 适合场景 | 优势 | 风险 |
|------|---------|------|------|
| A. 单机制多表达 | 找到特别能打的核心机制 | 机制资产复用率高 | 容易被觉得重复 |
| B. 同审美/同情绪多品类 | 世界观/美术/气质极强 | 容易做 IP 外延 | 玩法质量不稳会空心化 |
| C. 同用户群多价格带 | 已知核心玩家是谁 | 商业结构健康 | 产品线太散用户不知最强是什么 |

### 工作室品牌架构成型的 5 个判断标准

1. 我们的下一款，能借到上一款什么资产？
2. 如果不是续作，玩家为什么仍会感到熟悉？
3. 社区内容是否能跨作品迁移？
4. 商店页和素材风格是否已经形成模板？
5. 目录之间是互相导流，还是彼此抢气？

## 目录资产现金流飞轮（5 环模型）

**核心**：让上一款持续养下一款。Devolver 2024 财报：88% 收入来自 back catalogue；Team17 ~92%。

```
[第 1 环] 首发建立种子盘：付费用户 / 评测 / 社区 / 素材 / 愿望单未转化
       ↓
[第 2 环] 更新制造二次峰值（首发后 4-8 周）：修关键体验 + 补显眼新内容点 + 配合活动
       ↓
[第 3 环] 折扣触发沉睡用户回流：20%+ 折扣 + 持续 8 小时 + 覆盖最低价包 → 触发愿望单通知
       ↓
[第 4 环] 组合销售拉高 ARPPU：DLC / 原声 / supporter pack / artbook / 捆绑包
       ↓
[第 5 环] 老作给新作输血：社区迁移 / 商店页互导 / 视觉语言延续 / 老玩家成下款种子
```

## 发行合作判断 4 问框架

> 真正稳的判断：**发行不是救命药。签约的唯一理由，是它能把你本来做不到的结果真的放大**。

### 4 问

1. **你缺的是钱，还是缺放大器？** — 缺基础开发资金 / QA / 主机移植 / PR / 平台商务 / 全球节奏 → 发行可能有价值；缺的只是「不敢做商店页」「不想学宣发」 → 该补团队能力短板。
2. **发行商能补的是不是「结果型能力」？** — 看品类近 2 年发过什么 + 商店页/Demo/愿望单/主播覆盖水准 + 平台窗口能力 + 把支持写进合同（不是写进嘴里）。
3. **这份钱是不是值得卖掉未来？** — 真正贵的不是分成，是续作优先权 / 衍生商品分成 / term 太长 / 自动续约 / 黑箱 recoup。
4. **如果不签，我们能不能自己把第一仗打完？** — 自发不是全能，至少要有：商店页 / Demo / Steam 节庆节奏 / devlog / 愿望单维护能力。

### 2026 发行合同市场数据（100+ 协议样本）

- 中位 advance ~27 万美元（最高 600 万，最低 2 万，分化极大）
- **84%** 协议绑定里程碑付款
- **94.7%** 协议要求 publisher recoup
- 但只有 **37%** 要求 publisher 完全 recoup 后开发者才分成
- **93.2%** 协议中 IP 仍归开发者
- **57.9%** 协议中发行方有续作优先谈判权
- 有 advance 协议平均 term 接近 **7 年**，多带自动续期

**结论**：今天签发行多数情况下不是「卖公司」，但很可能卖掉未来几年的现金流、续作谈判空间和项目节奏。

### 红旗清单（一看到就警惕）

1. 只说「我们会全力推广」，没有最低 marketing commitment
2. 只肯给小 advance，却要拿长 term、续作权或较重 IP 权利
3. recoup 口径模糊
4. 不给清楚的财务报表周期和 audit right
5. 在你品类里没有可验证的成功记录
6. 连商店页打法 / 节庆计划 / 达人名单 / 平台窗口都说不出方法论

## 独立游戏定价 4 层模型

| 层 | 内容 |
|---|------|
| 1. 身份价 | $4.99-$7.99 小品 / $9.99-$14.99 主流独立精品带 / $15.99-$19.99 需要明显系统深度 / $24.99+ 必须有强背书 |
| 2. 折扣空间 | 必须预留 launch discount + 30 天后首次正式折扣 + 半年大促阶梯空间 |
| 3. 区域弹性 | 至少盯中国 / 巴西 / 波兰 / 土耳其；波兰区通常值得在推荐价上再下调 20-25% |
| 4. 目录节奏 | 首发价定锚 → 首发折扣转化 → 首次 20%+ 折扣唤醒愿望单 → 大促深折 → DLC/Soundtrack 拉客单 → 新作上线时老作折扣给新作导流 |

**Steam 折扣规则（硬约束）**：
- 20%+ 折扣 + 持续 8 小时+ + 覆盖最低价包 → 触发愿望单通知
- 发售后 30 天内不能做普通折扣（首发折扣除外）
- Launch Discount 可配置 7-14 天
- 价格上调会重新触发 30 天折扣冷却

**2025-2026 市场现状**：
- 2025 年 Steam 21,273 款新作，**51% 付费游戏首发价 <$10** — 低价是最拥挤的垃圾堆
- 玩家心理锚点：**10-15 美元** = 大量独立精品；>$25 越来越难（玩家拿你和 10-15 美元精品比）

## 项目组合管理：5 层漏斗 + 70/20/10 原则

### 5 层漏斗（立项投资组合）

```
[第 1 层] 信号池：AI 视频 / 抖音 / Steam 榜 / 微信小游戏 / 机制兴趣 — 只收集分类假设
       ↓
[第 2 层] 概念筛：5 问审判 — 一句话钩子 / 3 秒视频爽点 / 7 天可测切片 / 生产优势 / 资产复用 — 2 项答不上不立项
       ↓
[第 3 层] 原型闸：可测原型（不是能跑） — 首爽点秒数 / 首败可复述 / 想再来一局 / 1-2 个可切素材瞬间
       ↓
[第 4 层] 市场闸：Demo / 试玩页 / 视频素材 = 商业测试件 — 4 类数据（点击 / 下载 / 愿望单 / 留存）
       ↓
[第 5 层] 加码层：只有跑过前 4 层才配拿长开发周期 / 完整内容 / 发行谈判 / 投放预算
```

### 70/20/10 资源分配原则（小团队）

- **70% 时间/预算**：投在已验证主线项目（光与朽优化、最有希望的切片）
- **20%**：投在近邻变体（同受众、同生产线、不同表达）
- **10%**：投在高风险新切口（AI 视频高信号但尚未验证）

## 渠道顺序：平台顺序三分法

> **核心**：平台不是并列菜单，而是验证顺序。先打错第一仗，后面每个平台都会替你放大错误。

| 平台类 | 代表 | 适合验证 |
|--------|------|---------|
| **内容验证平台** | 抖音 / 视频号 / B站 / 小红书 | 3 秒钩子是否成立 / 评论能否复述 / 有没有「想试」表达 |
| **产品验证平台** | Steam Demo / Next Fest / 愿望单页 | 玩家是否愿意为体验留下+记住+付钱 / Demo 能否兑现承诺 / 核心循环是否只适合看 |
| **商业化验证平台** | 微信小游戏（含视频号 / PC 衍生） | 留存能否支撑广告回收 / 轻 IAP/混变是否成立 / 首发身份值不值重押 |

### 选哪个先打的判断

| 最大不确定性 | 先上 |
|------------|------|
| 「有没有人看得懂/想点进来」 | 内容验证平台 |
| 「核心循环是不是只适合看，不适合付费玩」 | Steam Demo / 愿望单 |
| 「能不能在微信生态形成留存和回收」 | 微信版闭环验证 |

**一个核心，三种表达**：
- 内容平台卖「钩子」
- Steam 卖「值得买」
- 微信卖「留得住且回得本」

## 工作室经营仪表盘（绿灯阈值系统）

### 三层九格仪表盘

```
[钩子层] 停不停 / 懂不懂 / 想不想试
       ↓
[产品层] 90 秒讲清目标 / 120 秒打第一次爽点 / 首败可复述 / 想再来一局
       ↓
[经营层] 意向数（愿望单+加群） / 转化数（下载+试玩+购买） / 质量数（留存+评价+退款） / 回收数（广告 IAP 折扣唤醒目录）
```

### 绿灯/黄灯/红灯规则

| 状态 | 标准 | 处理 |
|------|------|------|
| 🟢 绿灯 | 素材稳定「想试」反馈 + Demo 前 10 分钟兑现核心高光 + 玩家自然复述卖点 + 愿望单与同层级对标不差 + 有明确第二波经营节点 | 继续加码 |
| 🟡 黄灯 | 有人停但不想试 / 想试但上手不爽 / 爽点存在但表达模糊 / 数据有一项亮眼其余平庸 | **一次只修一个变量**（钩子 OR 前 120s OR 页面 OR 商业化节点） |
| 🔴 红灯 | 连续 2 轮素材测试无明确「想玩」信号 + Demo 反复无法在前 10 分钟打出代表性高光 + 玩过的人无法复述卖点 + 指标差还看不出哪一项值得救 | 立刻砍 → 拆资产（机制 / 视觉 / 失败认知 / 素材经验）喂下一轮 |

### Steam Next Fest 愿望单分层（182 份问卷样本，r=0.825）

## 可拥有受众资产：三池两跳板模型

> **核心**：独立工作室最贵的不是流量，而是把一次注意力变成下一次还能叫得回来的用户资产。

### 三池

| 池 | 载体 | 任务 | 核心指标 |
|---|------|------|---------|
| 公域注意力池 | 抖音 / 视频号 / B站 / 小红书 / 广告素材 | 证明钩子能让陌生人停下并想试 | 有人停 / 有人复述 / 有人问「哪里能玩」 |
| 半私域互动池 | Discord / QQ群 / 微信群 / Steam 社区 / 测试表单 / 关注列表 | 把「有点兴趣」变成「愿意反复回来」 | 活跃种子数 / 每次更新唤回数 / 玩家自己的卖点表述 |
| 高意向可拥有池 | 邮箱名单 / Steam 愿望单 / Playtest 申请名单 / 预约表 | 商业回收 + 下一款冷启动 | 发售通知 / Demo 召回 / 节庆唤醒 / 下款种子导流 |

### 两跳板

- **第一跳**：公域 → 互动池。任何一条有希望的素材都必须有承接动作（进群 / 填表 / 关注 devlog / 加愿望单 / 留邮箱）
- **第二跳**：互动池 → 高意向池。1000 个沉默群友 不如 80 个会回测、会加愿望单、会转发试玩链接的人

### 每个项目只维护一条清晰漏斗

```
短视频/截图钩子 → 试玩群或表单 → 愿望单/邮箱 → 回访/更新/折扣通知
```

入口一乱，数据就废。

## 创作者分发网络（冷启动飞轮 5 步）

### 5 步模型

1. **先定义唯一传播钩子** — 一句能被复述的话（3-5 秒视频看懂 / 20 秒试玩验证 / 一句标题写清）
2. **先做「可播切片」再做长介绍** — 10-20 秒竖版爽点 + 1 句标题 + 1 个「卧槽瞬间」 + 1 个短 Demo
3. **分层外联**：
   - 种子层（20-50）：小而精准，愿回消息，能拿真实反馈
   - 放大层（20-30）：中腰部，固定受众，活动节点前后打波次
   - 锚点层（5-10）：可能带来大峰值的主播
   - 剪辑/二创层：能把素材变多次传播
4. **时间轴拉长，不许只打一枪**：
   - T-6~4 周：种子层试玩私测
   - T-3~2 周：Demo / 核心素材公开
   - T-7~1 天：高匹配创作者集中
   - 活动周/上线周：同步更新补丁
   - 活动后 1~3 周：第二波继续
5. **所有曝光都要沉淀回资产池** — 商店页访问 / 愿望单 / Demo 下载 / 入群 / 哪个创作者带的评论最像真玩家

### 关键事实（2025-2026 数据）

- 《Parcel Simulator》案例：Demo 前 2 年累计 ~7000 愿望单 → Demo 上线后日均从 11 拉到 362 → Next Fest 单次再拿 1 万
- Real Civil Engineer 单次主播覆盖约 7000 愿望单
- LORT 案例：Demo 前已 4.5 万愿望单 → Demo+创作者外联 → 6.8 万 → 活动后 8.5 万

**结论**：大创作者不是一枪爆头神器，是把电池充满的一次大充电。

## 工作室现金跑道：4 桶模型 + 50/30/10/10 原则

### 4 桶

| 桶 | 用途 | 规则 |
|---|------|------|
| 🛡 生存桶 | 生活成本 + 必要软件设备云 + 基础运营 + 税费/平台回款时差 | 至少锁 6 个月，理想 9-12 个月。锁住前不准多项目并行扩张 |
| 🔬 验证桶 | 核心原型 / 可投放素材 / Demo / 陌生人测试 / 创作者小试投 / 商店页落地页 | 每笔钱必须回答：买哪一个验证结果？失败就停 |
| 🚀 放大桶 | 扩大创作者合作 / 小额买量 / 节庆冲刺 / 本地化素材变体 / 完整宣发 | 只有前桶证明值得加码才能开。预算按阶段释放 |
| 🌱 复利桶 | 技术模板 / 美术视频生产线 / 邮箱 Discord / 创作者名单 / 商店页投放反馈模板 | 不追短期 ROI，但必须服务下一次更便宜的验证 |

### 50/30/10/10 现金分配

- 50% 生存桶
- 30% 验证桶
- 10% 放大桶
- 10% 复利桶

**当现金紧时宁可缩开发范围 / 并行项目数 / 美术野心 / 平台铺设，也不要砍验证桶**。验证桶被砍 = 在省死亡证明的钱。

### 三条跑道线（不只看一个数）

1. **断气线**：完全没收入还能活多久
2. **验证线**：还能支撑几轮 7 天切片 / Demo / 测试
3. **加码线**：哪怕方向跑通了，是否还有钱把它放大

很多团队的问题：断气线看上去还行，但验证线已经快空 → 真跑出信号却没钱冲第二段 = 把命花在证明前，把机会留给别人。

### 过闸拨款法（4 阶段）

| 阶段 | 投入 | 回答的问题 |
|------|------|----------|
| A. 钩子证明 | 3-10 条短素材 + 1 个承接口 + 少量陌生人验证 | 有没有人会停、问、想试 |
| B. 产品证明 | 可玩切片 + 首局节奏 + Demo 首爽点 + 留存反馈 | 只适合看，还是适合玩 |
| C. 经营证明 | 商店页 + 创作者批量触达 + 小额买量 + 平台节庆 | 是不是门生意 |
| D. 放大与目录化 | 版本扩展 + DLC 目录节奏 + 平台延展 + 品牌化资产 | — |

**只有 A 过了才开 B，B 过了才开 C，每段都有过闸标准**。

### 月度现金指挥盘（8 个数）

1. 可动用现金总额
2. 生存桶余额
3. 验证桶余额
4. 当月固定 burn
5. 当前真实跑道（月）
6. 本月已完成的验证数
7. 每个方向的下一闸门
8. 哪个项目在偷吃未来跑道

## 一个一以贯之的硬判断

> **未来 12 个月，最该建立的不是「再做一款游戏」的能力，而是「每 2-4 周筛掉错误方向、每 1-2 个月放大一个正确方向」的能力。**

谁能把立项做成组合管理，谁就更接近开公司；谁还在靠热情单点梭哈，谁就还停留在手工作坊阶段。
