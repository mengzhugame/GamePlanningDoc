# 50_商业

这里是商业化目标的战略中枢，不是口号区。

本目录只回答一个问题：**如何用自己的游戏 / TA / AI / 内容 / 旅行经历，先跑出可收费能力、用户池、产品数据或合作机会，然后顺势公司化。**

本目录存放商业规划、变现逻辑、公司化路线、账号策略、用户池规划和商业实验判断。它不承载具体产品的 PRD、开发计划、功能设计、版本迭代和工程执行。

当某个 AI 工具、Web / App 应用、SaaS、自动化工作流或游戏方向从商业想法进入实际制作时，应升级为 `20_项目/` 下的正式项目；`50_商业/` 只保留它为什么值得做、如何收费、如何获客、如何验证商业闭环的判断。

公司不是第一目标，营业执照也不是胜利条件。真正的目标是：产品或服务被陌生人验证、收入模型或合作模型跑通、用户池能支撑下一轮项目，公司只是这个结果的组织形态。

当前总入口：[[00_战略中枢/现阶段商业化路线图_2026-05]]

## 北极星

**长期目标**：成立 AI 驱动的小型游戏公司。

**现阶段目标**：先通过 90 天低成本实验，证明至少一条商业化路线能带来外部信号：试玩、留存、广告、付费、合作、咨询、测试池或职业报价。

**成立公司的前提**：至少有一款留存数据和盈利表现较好的产品，或已经拿到足够强的发行合作 / 用户池 / 收入 / 客户线索，证明公司化不是情绪决定，而是资源配置决定。

优先级从高到低：

1. 产品验证：陌生用户愿意玩、愿意回来、愿意看广告或付费。
2. 商业验证：LTV、ARPU、广告观看、ROI、发行合作或真实收入有正信号。
3. 可复制系统：能每 2-4 周筛掉错误方向，每 1-2 个月放大一个正确方向。
4. 用户资产：内容平台、TapTap / Steam / 微信预约、测试群、邮箱或表单能沉淀高意图用户。
5. 客户与合作：AI 工具、旅行路线、TA / Pipeline 能力是否有人愿意试用、付费或合作。
6. 团队与公司：只有前面几项跑出结果，才讨论注册公司、招聘、品牌命名和长期组织。

## 2026-05-27 当前商业化路线

当前不是从“游戏公司”降级，而是把公司目标拆成几条能验证收入和用户的现实路线。

| 路线 | 当前角色 | 资源占比 | 成功信号 |
|------|----------|----------|----------|
| AI + 小游戏验证 | 主线，承接未来公司化 | 50%-60% | 概念视频信号、7 天切片、20-50 个陌生试玩、留存 / 广告 / 发行反馈 |
| AI 工具 / 工作流产品 | 快速验证付费和作品集 | 15%-25% | 旅游朋友、小团队、TA 客户愿意试用或付费 |
| 个人 IP 与用户池 | 获客层，不单独当主业 | 10%-15% | 评论、私信、测试群、表单、合作线索 |
| 旅行内容 / 线下体验副线 | 低成本商业实验和社交恢复 | 10%-20% | 路线咨询、同行兴趣、AA 活动、合规合作机会 |
| 求职 / 接单保险 | 职业资本和现金流期权 | 10%-20% | 面试反馈、报价、外包、offer 校准 |

默认节奏参考：`60% AI + 小游戏 / 工具验证`、`20% 职业资本 / 接单保险`、`20% 旅行内容 / 线下实验`。

旅行副线可以开独立账号测试，但不能让游戏 / AI 主账号变成泛旅行号。正式收费带客户旅行前，必须单独核查资质、合同、保险和安全责任。

## 当前战略判断

截至 2026-05-18，当前不缺“能做出游戏”的证明，缺的是从市场信号到收入闭环的系统。

过去两款产品的核心教训：

- 《美妆叠叠乐》：先想品牌合作和商业故事，后验证玩家是否真想玩，顺序反了。
- 《光与朽》：研发与 TA 表现力得到证明，但朋友、运营、发行的“不错 / 新颖”不能替代陌生用户留存和买量数据。

当前 8-12 周应验证的方法：

```
选题观察
-> AI 概念视频 / 可播素材
-> 陌生人反馈
-> 7 天极小切片
-> 20-50 个高意图试玩者
-> 留存 / 广告 / 付费 / 预约 / 发行反馈
-> 加码、调整、砍掉或归档
```

判断标准：这件事是在产生市场数据，还是只是在增加安全感？

## 阶段路线

| 阶段 | 时间窗 | 核心目标 | 过闸标准 | 不过闸动作 |
|------|--------|----------|----------|------------|
| 方法验证期 | 2026-05-18 至 2026-08-16 | 验证“AI 视频 -> 极小 Demo -> 用户池”的创业系统是否成立 | 至少 1 个方向出现陌生人想试、可玩切片完成、20-50 个高意图用户、可解释的数据正信号 | 缩小范围、砍方向、转找工作 / TA 外包 / 进入团队补市场能力 |
| 单品数据期 | 2026 Q3-Q4 | 把一个方向推进到 Demo / 小游戏测试 / 平台预约 | D1、D7、平均时长、广告观看、预约、评论、试玩反馈至少一项明显优于前两款 | 不完整开发，拆资产喂下一轮 |
| 商业闭环期 | 2026 Q4-2027 Q1 | 跑通收入或发行合作 | 有真实流水、ROI 正向可能性、发行愿意放大、或稳定高意图用户池 | 回到方法验证期，减少烧钱 |
| 公司化准备期 | 2027 | 注册主体、组 2-3 人小团队、建立财务和协作流程 | 产品收入 / 合作合同 / 团队岗位需求已经真实出现 | 继续个人工作室，不为身份注册公司 |

## 周期复盘

### 每周指挥盘

每周只问 5 个数：

1. 本周新增了几个陌生用户信号？
2. 本周完成了几个可展示 / 可试玩验证物？
3. 本周有没有把任何人从公域带到测试池、预约、群或表单？
4. 本周花的钱买到了什么验证结果？
5. 本周有没有用研究、整理、搬家、社交、工具或内容更新逃避产品验证？

### 月度复盘

每月末写入 `60_计划/` 当月行动清单，格式固定：

```md
## 本月商业复盘

- 北极星推进：
- 已拿到的外部信号：
- 未做到的事：
- 为什么没做到：
- 下月只保留的 1 条主线：
- 下月必须砍掉或降级的事：
- 是否触发现金 / 找工作 / 停项红线：
```

### 季度复盘

每季度从 4 层判断是否继续：

| 层级 | 复盘问题 |
|------|----------|
| 产品 | 有没有陌生人玩后愿意再来？有没有前 3 分钟爽点？ |
| 商业 | 有没有广告、IAP、买量、发行或预约的正信号？ |
| 系统 | 下一轮验证是否比上一轮更快、更便宜、更清楚？ |
| 人 | 当前节奏是否还保护现金流、身体、社交和长期创造力？ |

季度结论只能是 4 种：

- **加码**：数据过闸，进入下一阶段。
- **修正**：只改一个变量，例如钩子、前 120 秒、页面、商业化节点。
- **砍掉**：连续 2 轮无外部信号，拆资产归档。
- **换轨**：创业系统未跑通，启动工作 / 外包 / 进入团队补课方案。

## 当前复盘

当前已经对齐的部分：

- 北极星已经从“我要开公司”修正为“先做出被市场验证且能赚钱的产品”。
- 5 月计划已经开始转向拆解、创意打分、铁律检查、AI 视频脚本和市场信号。
- 个人 IP 已经从泛旅行号回调到“真实记录失败、验证和迭代的独立游戏人”。
- 找工作、大厂、广州社交被重新定义为期权，不是创业失败标签。

当前没有做到的部分：

- 还没有形成稳定的“视频信号 -> 试玩用户 -> 数据复盘”闭环。
- 个人 IP 还没有稳定沉淀到高意图测试池。
- 买量和发行反馈还没有成为每轮验证的固定动作。
- 旧战略文档堆叠太多，历史判断、当前计划、商业方法、IP 内容混在一起。

主要原因：

- 过去更擅长做完整产品，不擅长在开发前用小信号证伪。
- 知识整理和战略讨论容易变成安全感来源。
- 搬家、活动、生活系统升级会占用创业验证窗口。
- 内容账号曾经围绕《光与朽》旧叙事，和当前“30 天切片 + 用户池”战略没有完全同步。

下一步调整：

1. `50_商业` 先建立清晰入口，只保留当前可执行战略。
2. 历史战略和 IP 材料已在 2026-05-18 提取、合并并删除，去向见历史材料索引。
3. 未来任何新游戏方向先进入 `00_草稿/游戏创意库/` 做概念卡和视频数据记录。
4. 每个方向必须有一个承接口：测试群、表单、预约、评论区引导或愿望单。
5. 每周复盘只看外部信号，不用“我又整理了很多东西”当进展。

## 个人 IP 的位置

个人 IP 不是独立目标。主账号也不是旅行号重启计划。它在商业系统中的作用只有三个：

1. 让陌生人知道你正在做什么。
2. 把一部分高意图用户沉淀到测试池。
3. 为每个游戏方向提供真实反馈、预约、试玩和上线前种子用户。

2026-05-30 起，个人 IP 执行区拆成两条线：

- [[20_个人IP与用户池/远程接单/README]]：主账号方向，用游戏制作、TA、Unity、Shader、AI 工作流和项目复盘建立信任，再承接远程外包与咨询。
- [[20_个人IP与用户池/旅游个人IP/README]]：独立旅行副账号方向，用旧旅行照片视频和路线经验测试旅行内容、路线清单、咨询与合规合作机会。

周一 / 周三发布提醒按 [[20_个人IP与用户池/小红书发帖Agent流程]] 执行。

内容发布前先问：

- 这条内容服务哪个项目或验证节点？
- 看完的人下一步能做什么：评论、试玩、进群、预约、填表、加愿望单？
- 它是在记录真实数据和真实困难，还是在表演“我还在努力”？
- 准备时间是否超过 30 分钟？如果超过，是不是在逃避开发？

当前主账号推荐定位：

> 一个 36 岁、10 年 TA、做废两款微信小游戏后，开始用 30 天小切片重新验证游戏创业的人。

旅行内容可以作为独立副线账号测试，目标不是发风景，而是验证路线咨询、同行兴趣、AI 旅行工具和线下体验设计。实验期建议每周 3-5 条库存素材内容，4 周后只看有效评论、私信、咨询、表单和线下活动线索。

## 神仙问题库

用于周复盘、季度复盘或战略摇摆时拷问自己。

1. 如果我不能提“成立公司”，这周我还做了什么更接近公司的事？
2. 哪一个陌生人的行为证明这个方向值得继续？
3. 我现在是在验证市场，还是在证明自己没有停下？
4. 这个项目失败后，能留下什么资产：用户、素材、代码、数据、发行关系，还是只有情绪？
5. 如果明天只能保留一个方向，我会保留哪个？为什么不是另一个？
6. 这周最该被砍掉的事是什么？
7. 现在最稀缺的是点子、Demo、用户、钱、时间、身体，还是外部反馈？
8. 如果腾讯 / 网易给 offer，这份工作能补我的产品、发行、运营、人脉哪一块？如果补不了，它只是止痛药。
9. 如果继续创业，接下来 14 天能拿到什么非主观信号？
10. 我是不是又把“做完整”当成“做正确”了？
11. 如果这条内容爆了，它能把人带到哪里？
12. 如果这款游戏赚了钱但我不喜欢，我是否愿意继续做同类？如果愿意，说明这是生意；如果不愿意，说明我还在做作品梦。

## 使用规则

- 讨论新游戏立项前，先读 `40_知识/01_游戏设计/立项铁律_2026-05.md`。
- 新方向先进入 `00_草稿/游戏创意库/`，不直接进正式项目。
- AI 辅助不改变验证顺序：原型和视频只能作为访谈、测试和数据收集工具，不能替代陌生人信号。
- 单个游戏、AI 工具、App / Web 应用、SaaS 或自动化工作流产品的具体制作资料放 `20_项目/`。
- `50_商业/` 只放商业规划、变现逻辑、获客策略、公司化路线和个人 IP / 用户池规划，不放具体项目 PRD、开发计划和工程文档。
- 未经用户明确同意不改 `20_项目/` 下已有正式项目文件。
- 行业、发行、买量方法论沉淀到 `40_知识/06_发行与运营/`。
- 月度计划和实际行动放 `60_计划/`，本目录只保留公司化战略、商业判断和复盘框架。
- 未来再做批量归档和删除时，先提取摘要，再读回验证，再按当次用户授权执行。
