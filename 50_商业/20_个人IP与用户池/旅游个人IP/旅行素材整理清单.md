## 印度尼西亚专题待补充

如果本月要做印度尼西亚系列，先补这几个问题：

```md
- 去过哪些地方：巴厘岛 / 龙目岛 / 日惹 / 雅加达 / 科莫多 / 其他？
- 总天数：
- 出行方式：一个人 / 朋友 / 跟团 / 自由行？
- 最值得推荐的 3 个地点：
- 最踩坑的 3 件事：
- 大概预算：
- 有哪些照片 / 视频素材：
- 这次旅行最想表达的主题：攻略 / 自由感 / 低成本 / 人生转折 / 数字游民？
```

未确认前，不把具体路线、价格和地点写成事实。可以先做“我准备整理印度尼西亚旅行素材”的预告型内容。

## 一条素材变三条内容

同一组素材可以拆成：

1. 攻略版：路线、预算、交通、避坑。
2. 故事版：当时发生了什么、我有什么感受。
3. 数字游民版：这段旅行如何影响自由、工作、生活选择。

示例：

```text
素材：某段海岛视频
攻略版：第一次去这个海岛，路线和预算怎么安排
故事版：那天我突然理解，旅行不是逃避而是恢复行动力
数字游民版：如果要边远程工作边住在这里，我会先检查 5 件事
```

## 每周整理动作

每周只做 45-60 分钟：

1. 找 10 组素材。
2. 选 3 组最有故事或实用价值的。
3. 给每组写 3 个标题。
4. 发 1-2 条。
5. 发布后把数据写入 [[线索与服务实验记录]]。
