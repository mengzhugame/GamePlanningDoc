# 20_个人IP与用户池

这里是个人 IP、内容发布、用户池和商业转化的执行区。

个人 IP 不是为了表演生活，而是为了把真实能力、真实经历和真实项目，转成陌生人的关注、咨询、试玩、合作和付费线索。

当前拆成两条长期线：

| 方向 | 账号角色 | 商业目标 | 入口 |
| --- | --- | --- | --- |
| 远程接单 | 游戏 / TA / Unity / AI 工作流主账号 | 用技术内容建立信任，再用合作帖承接外包、咨询和报价 | [[远程接单/README]] |
| 旅游个人IP | 独立旅行副账号 | 用旅行素材吸引关注，先验证路线咨询、清单产品和合规合作机会 | [[旅游个人IP/README]] |

---

## 总原则

1. 主账号不天天发“接包”，而是先发真实能力证据。
2. 旅行内容单独成线，不冲淡游戏 / TA / 独立开发者主账号。
3. 每条内容都要有承接口：评论、私信、表单、测试群、路线清单、合作咨询。
4. 每周只看外部动作，不用“又更新了内容”当进展。
5. 自动化先做辅助 Agent，不做全自动发布。真人仍负责选择、发布、评论和私信。

## 周节奏

默认小红书节奏：

| 时间 | 默认方向 | 目标 |
| --- | --- | --- |
| 周一 | 远程接单 / 游戏制作复盘 | 建立专业信任，吸引游戏开发、Unity、TA、小游戏客户 |
| 周三 | 旅游个人IP / 旅行素材内容 | 建立旅行副账号内容资产，测试路线咨询和同行兴趣 |
| 周五，可选 | 当周表现较好的方向 | 补发案例、回答评论、发布合作/接单转化帖 |

每周 2 篇是底线，3 篇是加速。没有明确想法时，按 [[小红书发帖Agent流程]] 从内容系列里选题。

## 本区指标

每周复盘只记录 6 个数：

- 发布了几篇内容。
- 有效评论数。
- 私信 / 咨询数。
- 表单 / 清单 / 测试群转化数。
- 合作 / 报价 / 约聊线索数。
- 哪类内容应该保留、加码或砍掉。

1000 个沉默关注，不如 3 个真实询价、10 个有效咨询或 20 个高意图试玩者。
