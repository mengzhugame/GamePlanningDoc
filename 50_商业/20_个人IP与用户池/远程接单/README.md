# 远程接单

这是数字游民的第一步：用已有的 TA、Unity、小游戏制作、Shader / VFX、AI 工作流和 App 原型能力，先获得可远程交付的现金流。

这个账号方向不是“天天发接包”，而是：

> 先用真实项目经验和技术解决过程建立信任，再在合适节点发布可合作、可接单、可报价的转化内容。

---

## 当前目标

30-90 天内验证：

1. 小红书、抖音等内容能否带来游戏开发、小游戏、Unity、Shader、App 原型相关咨询。
2. 是否有人愿意为诊断、原型、技术效果、性能优化或 AI 工作流付费。
3. 能否让远程接单成为低成本旅居和数字游民生活的第一层现金流。

成功信号不是粉丝数，而是：

- 有人私信问能不能做。
- 有人愿意发需求文档。
- 有人愿意约聊。
- 有人接受报价。
- 有人愿意为小额诊断、样例或原型先付费。

---

## 可卖能力

| 能力 | 可包装服务 | 适合客户 |
| --- | --- | --- |
| Unity / 微信小游戏 | 小游戏原型、微信小游戏适配、性能优化、上线问题诊断 | 独立团队、小工作室、内容团队 |
| TA / Shader | 材质变化、特效反馈、触控效果、移动端表现优化 | 游戏团队、互动营销、App 视觉效果 |
| VFX / 动效反馈 | 点击、合成、破坏、清洁、流体、收集反馈 | 休闲游戏、小游戏、广告互动 |
| AI 工作流 | 概念视频、素材变体、JSON 配置、快速 Demo 管线 | 游戏团队、个人开发者、创业验证 |
| App / 工具原型 | 小工具、内部流程页、可演示 Demo | 小团队、旅行从业者、个人创业者 |
| 项目复盘咨询 | 小游戏立项、上线、发行反馈、广告收入复盘 | 准备做小游戏的人、小团队 |

## 内容比例

不要把账号做成廉价广告栏。

推荐比例：

| 类型 | 占比 | 作用 |
| --- | --- | --- |
| 项目复盘 / 制作流程 | 40% | 用《美妆叠叠乐》《光与朽》证明真实经历 |
| 技术解决方案 | 25% | 展示 TA / Shader / Unity 能力 |
| AI 工作流 / 快速验证 | 20% | 展示未来交付效率 |
| 合作 / 接单转化帖 | 10% | 明确服务、报价和联系方式 |
| 数字游民 / 生活恢复 | 5% | 补人格，但不抢主线 |

接单帖建议每 6-8 条内容穿插 1 条。不要连续发布“接小游戏制作”“接外包”“可合作”，否则账号会变成低信任广告流。

## 可复用项目资产

《美妆叠叠乐》适合讲：

- 一个小游戏从策划、开发、上线到广告接入的完整流程。
- 女性向轻休闲项目为什么不能先讲品牌合作，要先验证玩家。
- 上线后 742 用户、广告收入 1.04 元带来的商业教训。
- 微信小游戏上线、CPS、广告接入和自然流量的真实踩坑。
- 如何把失败产品拆成可复用模板、内容和服务能力。

《光与朽》适合讲：

- Boss 战、塔防、肉鸽、数值体验如何验证爽点。
- TA 和表现力能做到什么，为什么仍然不能替代市场数据。
- 买量测试和投后数据如何决定是否继续加码。
- 发行反馈、差异化和陌生用户留存为什么比朋友夸奖更重要。
- 如何把战斗数据、数值分析和 Demo 经验沉淀成咨询能力。

## 30 天实验

| 周 | 任务 | 验证目标 |
| --- | --- | --- |
| 第 1 周 | 发 2 条项目复盘，1 条技术解决方案 | 是否有人评论、收藏、私信问技术或开发流程 |
| 第 2 周 | 发 2 条 Shader / Unity / AI 工作流内容 | 是否有人能复述你能解决什么问题 |
| 第 3 周 | 发 1 条合作 / 接单转化帖，1 条案例拆解 | 是否出现需求、约聊或报价请求 |
| 第 4 周 | 根据数据复盘，保留 1 个最容易变现的服务 | 是否值得做报价页、表单或作品集页 |

## 转化承接口

可用评论关键词：

- 评论“小游戏”：领取小游戏上线 / 验证清单。
- 评论“Shader”：看一个移动端 Shader 效果拆解。
- 评论“TA”：领取 TA / Unity 技术诊断问题表。
- 私信“合作”：发需求范围和预估时间，我先判断是否适合接。

早期不需要复杂官网。先用评论、私信、表单和一页报价草案验证。

---

## 红线

- 不承诺“包赚钱”“包上线后有流量”。
- 不接需求极不清楚、预算极低、无限修改的单。
- 不为接单连续发布低信任广告内容。
- 不把项目失败包装成成功学。
- 不未经允许暴露客户资料、项目源文件和商业敏感数据。
