## 接单转化帖模板

标题方向：

- 我现在开放 3 个小游戏技术诊断名额。
- 如果你的 Unity 小游戏卡在上线 / 性能 / 适配，可以找我看一眼。
- 10 年 TA，接一些 Shader / VFX / 小游戏原型外包。

正文结构：

```text
我能帮谁：
适合已经有想法、Demo 或项目，但卡在技术 / 表现 / 验证上的小团队。

我能做什么：
1. 微信小游戏适配和性能诊断。
2. Shader / VFX / 触控反馈效果制作。
3. 7 天小游戏原型切片。
4. AI + Unity 快速 Demo 工作流。

我不适合做什么：
不接“包爆款”、不接无限修改、不接需求不清楚的完整包干。

下一步：
私信“合作”，发我项目阶段、目标平台、当前问题和预算范围。我先判断适不适合接。
```
