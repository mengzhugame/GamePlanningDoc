# 线索记录

用于记录远程接单账号带来的咨询、私信、报价和合作线索。

不要只记粉丝和点赞。真正要追踪的是：对方是谁、有什么需求、预算是否真实、下一步是什么。

---

## 状态定义

| 状态 | 含义 |
| --- | --- |
| inbox | 新线索，未判断 |
| qualified | 需求清楚，有机会 |
| quoted | 已报价 |
| won | 成交 |
| lost | 丢单 |
| nurture | 暂不成交，但值得保持联系 |
| rejected | 不适合接 |
