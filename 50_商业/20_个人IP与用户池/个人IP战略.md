# 个人 IP 战略

个人 IP 不是独立目标。主账号也不是旅行号重启计划。它在商业系统中的作用只有三个：

1. 让陌生人知道你正在做什么。
2. 把一部分高意图用户沉淀到测试池。
3. 为每个游戏方向提供真实反馈、预约、试玩和上线前种子用户。

---

## 当前定位

推荐定位：

> 一个 36 岁、10 年 TA、做废两款微信小游戏后，开始用 30 天小切片重新验证游戏创业的人。

关键词：

- 真实。
- 不装成功。
- 失败后继续验证。
- 技术有料。
- 用数据修正自己。

主账号不再主打：

- 泛旅行生活号。
- 教别人做小游戏。
- 成功学创业号。
- 纯产品宣传号。

---

## 2026-05-30 执行分支

当前个人 IP 执行拆成两条线：

| 分支 | 定位 | 入口 |
| --- | --- | --- |
| 远程接单 | 用游戏制作、TA、Unity、Shader、AI 工作流和项目复盘引流，穿插合作 / 接包转化帖 | [[远程接单/README]] |
| 旅游个人IP | 独立旅行副账号，用旧旅行照片视频和路线经验测试关注、咨询、清单和合规合作机会 | [[旅游个人IP/README]] |

周一 / 周三的小红书提醒按 [[小红书发帖Agent流程]] 执行：先问有没有自己的想法；没有则从项目复盘、远程接单服务、旅行素材系列里选题。

---

## 爆款资产

已经验证过的内容资产：

- “被 27 家发行拒绝”有强情绪冲突和真实数字。
- 失败、挫折、不放弃，比成功展示更能建立人设。
- 旅行内容可以保留，但必须服务“游戏开发者如何获得灵感 / 调整状态 / 继续验证”，不能重新变成主账号的旅行号。

核心叙事不是“我很惨”，而是：

> 我失败了，我听劝，我继续用更小成本验证下一款。

## 旅行副线账号实验

可以新开一个旅行副线账号，但只作为 4 周商业实验，不替代主账号。

副线账号验证的问题：

1. 旧旅行照片和视频能否稳定吸引陌生人。
2. 是否有人因为路线、预算、装备、徒步经验、自由生活方式来私信。
3. 旅行经历能否转成路线咨询、AI 旅行工具试用、AA 朋友局或合规旅行社合作线索。
4. 旅行内容是否能恢复真实社交和生命力，而不是拖走主线精力。

副线账号定位建议：

> 36 岁游戏开发者，把徒步、路线和真实世界体验拆成可复制的自由感。

4 周实验节奏：

- 每周 3-5 条，只用库存素材。
- 每条准备不超过 30-45 分钟。
- 结尾必须有动作：评论“路线”、私信“徒步”、领取清单、试用 AI 路线模板、约 AA 活动。
- 每周复盘有效评论、私信、咨询、表单和线下线索。

加码标准：

- 连续 4 周后，至少有 10 条有效咨询 / 私信 / 评论。
- 至少 3 个潜在客户、旅游朋友或从业者愿意试用路线 / 报价 / 客户沟通模板。
- 至少 1 次低风险线下活动、AA 朋友局或合规合作机会。

降级标准：

- 只有播放和点赞，没有任何咨询、私信、表单或线下线索。
- 内容准备开始挤占小游戏 / AI 工具验证。
- 开始为了发内容而计划新旅行。

正式收费带客户旅行前，必须单独核查资质、合同、保险和安全责任。短期更适合做路线咨询、清单产品、AI 工具模板和合规伙伴合作。

## 平台分工

| 平台 | 角色 | 内容类型 | 承接口 |
|------|------|----------|--------|
| 小红书 | 情绪、真实故事、失败复盘、数据透明 | 图文 / 短视频 / 评论互动 | 评论、私信、测试群 |
| B站 | Devlog、技术分享、长线信任 | 3-8 分钟开发日志、技术拆解、复盘 | 关注、测试群、预约 |
| 抖音 / 视频号 | 3 秒钩子和视觉爽点 | 15-30 秒实机爽点、反差叙事 | 试玩链接、评论引导 |
| 公众号 | 深度复盘和长期档案 | 800-1500 字文章 | 用户池、合作入口 |

## 内容发布前 4 问

1. 这条内容服务哪个项目或验证节点？
2. 看完的人下一步能做什么：评论、试玩、进群、预约、填表、加愿望单？
3. 它是在记录真实数据和真实困难，还是在表演“我还在努力”？
4. 准备时间是否超过 30 分钟？如果超过，是不是在逃避开发？

---

## 内容红线

不发：

- 没有数据或事件支撑的心灵鸡汤。
- 纯旅行风景。
- 纯求安慰。
- 纯产品宣传。
- 白天黄金时间用长时间写内容逃避开发。

可以发：

- 真实数据。
- 真实困难 + 解决过程。
- 真实决策 + 思考过程。
- 用户反馈与下一步调整。
- 极小切片进展。
- 失败后拆资产。

---

## 用户池漏斗

每条内容都要尽量接入一个清晰漏斗：

```
短视频 / 图文钩子
-> 评论 / 私信 / 表单
-> 测试群 / 预约 / 愿望单
-> Demo 召回
-> 数据复盘
-> 下一轮内容
```

早期目标不是大量粉丝，而是 20-50 个高意图试玩者。

1000 个沉默关注，不如 30 个愿意回测的人。

---

## 内容比例

当前推荐：

- 60% 产品验证：切片、Demo、用户测试、数据反馈。
- 25% 失败复盘：踩坑、发行拒绝、数据不好、改法。
- 10% 技术 / TA：Shader、VFX、Unity、AI 管线。
- 5% 生活 / 旅行：必须和游戏灵感或创业续航绑定。

如果单独做旅行副线账号，副线账号可以在 4 周实验期内每周 3-5 条；主账号仍按上面的比例保持一致性。

---

## 节奏

默认低维护节奏：

- 小红书主账号：每周 1-2 条，优先远程接单、游戏制作复盘、技术和 AI 工作流。
- 旅行副账号实验期：每周 1-2 条，只用库存素材，不抢主线精力。
- 总节奏：周一、周三固定提醒，周五作为可选补发或转化帖。
- B站：有节点时发 Devlog，不硬凑周更。
- 抖音 / 视频号：只发强视觉素材，不发长散文。

当某个方向进入 7 天切片或测试期：

- 发布前：钩子和概念。
- 测试中：招募和过程。
- 测试后：数据和调整。

---

## IP 成功判断

不以粉丝数作为唯一指标。

更重要的指标：

- 有多少人问“在哪玩”。
- 有多少人进测试群。
- 有多少人愿意二测。
- 有多少人能复述卖点。
- 有多少内容能带来预约 / 表单 / 私信。

## 内容系统先半自动，不做全自动发布 Agent

现金流线和内容线的关键不是“自动发布”，而是内容定位、持续输出和私信转化。早期不建议先花 1-2 周搭全平台自动发布 Agent，因为没有验证的内容策略会被自动化放大。

更适合当前阶段的是内容辅助 Agent：

| 环节 | Agent 可做 | 人必须做 |
| --- | --- | --- |
| 选题 | 从游戏开发、旅行素材、技术经验里拆主题 | 选择本周服务哪个商业目标 |
| 脚本 | 生成标题、三行正文、短视频结构 | 判断是否真实、有料、不装成功 |
| 多平台改写 | 小红书 / B站 / 抖音 / 视频号版本 | 人工发布和处理评论私信 |
| 数据记录 | 记录播放、评论、私信、表单、测试群转化 | 判断是否值得继续自动化 |

自动化门槛：

1. 先连续发满 20 条内容。
2. 跑完 2 轮创意评审或测试招募。
3. 确认哪类内容能带来私信、约聊、测试者或客户。
4. 再自动化选题库、标题库、数据表和一稿多发。

当前辅助流程已落到 [[小红书发帖Agent流程]]，先跑 4 周和 8 条内容，再决定是否升级为 `90_系统/skills/` 下的正式 skill。

最重要的内容转向：

> 个人 IP 不是发生活，而是让别人知道你能解决什么问题。

内容要从“我在做什么”升级成“我能帮谁解决什么”。旅行可以作为人格补充，但主账号仍应围绕游戏开发者、TA/Unity 技术服务、AI 游戏生产流程和小切片验证展开。

## 个人 IP 进入“双账号获客”阶段

2026-05-30 的新增判断是：个人 IP 不再只服务“下一款小游戏”，而是服务未来的数字游民现金流。当前可以拆成两条并行账号线：

| 账号线 | 目标 | 内容原则 |
| --- | --- | --- |
| 远程接单 / 技术美术账号 | 吸引游戏制作、Unity、Shader、AI 工作流、小游戏 / App Demo 相关客户 | 以项目复盘、制作流程、问题解决、工具经验建立信任，偶尔发可合作 / 可接包帖 |
| 旅游个人 IP 账号 | 用库存旅行照片视频、路线、攻略、体验和人生转向吸引关注 | 先做旅行内容和真实故事，后续再测试路线咨询、旅行服务或合作线索 |

关键边界：

- 不要天天发“接包 / 做小游戏 / 可合作”，否则账号会像广告牌。
- 技术账号的信任资产是《美妆叠叠乐》《光与朽》的真实制作过程、失败复盘、问题解决和 AI 协作经验。
- 旅行账号先用旧素材分类整理，验证自然关注和私信，不先幻想变现。
- 小红书仍是第一平台；抖音、TikTok、YouTube 后续按视频素材能力再扩展。
- 每条内容都要服务一个长期人设，而不是临时发泄或随手发硬广。
