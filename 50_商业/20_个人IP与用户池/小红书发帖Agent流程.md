# 小红书发帖 Agent 流程

这个流程用于周一、周三的小红书发布提醒。

目标不是替你自动乱发，而是在你没有现成想法时，帮你从知识库里选一个能服务获客、用户池或变现的选题，并输出可直接发布前检查的草稿。

---

## 触发语境

当用户说：

- “今天小红书发什么？”
- “帮我写一篇小红书。”
- “这周远程接单账号怎么发？”
- “这周旅游账号怎么发？”
- “用《美妆叠叠乐》做一期内容。”
- “用印度尼西亚旅行素材做一期内容。”

就按本流程执行。

---

## 第一步：先问用户有没有想法

先问一句：

> 你今天有自己想发的主题、素材或项目吗？如果没有，我从远程接单 / 项目复盘 / 旅游素材里给你选 3 个标题。

如果用户已有想法，直接进入“草稿生成”。

如果用户没有想法，按以下优先级选题：

1. 本月正在推进的项目或接单目标。
2. [[远程接单/小红书内容系列_游戏制作与接单]] 中未发过的系列。
3. [[旅游个人IP/小红书内容系列_旅行IP]] 中未发过的系列。
4. [[内容素材库]] 中已有高可信标题公式。

---

## 第二步：判断本次账号线

| 账号线 | 适合内容 | 读哪些文件 |
| --- | --- | --- |
| 远程接单 | 游戏制作、Unity、TA、Shader、小游戏上线踩坑、外包服务 | [[远程接单/README]]、[[远程接单/小红书内容系列_游戏制作与接单]]、必要时只读 `20_项目/` 对应项目资料 |
| 旅游个人IP | 攻略、路线、素材整理、旅途中故事、数字游民生活 | [[旅游个人IP/README]]、[[旅游个人IP/旅行素材整理清单]]、[[旅游个人IP/小红书内容系列_旅行IP]] |

如果用户指定《美妆叠叠乐》或《光与朽》，可以读取 `20_项目/` 对应资料做内容，但不改动项目正式文件。

如果用户指定某个旅行地，例如印度尼西亚，先问：

- 去过哪些城市、岛屿或路线？
- 是一个人、朋友、跟团还是自由行？
- 预算、天数、最难忘的片段是什么？
- 手头素材是照片、视频还是笔记？

如果用户暂时不想补充，就只能生成“待用户核实版”，不能把未确认行程写成事实。

---

## 第三步：输出草稿

每次至少输出：

1. 3-5 个小红书标题。
2. 推荐标题。
3. 正文草稿，优先 300-800 字。
4. 配图 / 视频素材清单。
5. 结尾动作：评论关键词、私信关键词、表单、试玩、路线清单或合作咨询。
6. 话题标签。
7. 发布后数据记录模板。

输出格式：

```md
## 标题备选

- 
- 
- 

## 推荐标题


## 正文草稿


## 素材清单

- 封面：
- 图 2-4：
- 可选视频：

## 结尾动作


## 标签


## 发布后记录

- 发布日期：
- 平台：
- 标题：
- 内容目标：
- 承接口：
- 展示 / 播放：
- 点赞：
- 收藏：
- 评论：
- 私信：
- 进群 / 表单 / 清单 / 预约：
- 有效表达：
- 下一步：
```

---

## 第四步：内容判断

发之前过 5 个检查：

1. 这条内容是让别人更信任你，还是只是在喊“我想接单”？
2. 有没有真实项目、真实数据、真实问题或真实素材支撑？
3. 看完的人下一步能做什么？
4. 准备时间是否超过 45 分钟？超过就缩。
5. 这条内容是否服务本周的商业目标：测试者、客户、咨询、合作或素材整理？

---

## 第五步：系列选择规则

远程接单账号：

- 6-8 条信任内容后，穿插 1 条“可合作 / 可接包”转化帖。
- 优先发制作流程、踩坑、解决方案、项目复盘和技术小样。
- 接单帖必须说清服务边界、适合谁、不适合谁和下一步怎么联系。

旅游个人IP账号：

- 前 4 周只用库存素材，不为发内容重新安排远途旅行。
- 攻略 / 路线 / 费用 / 人物故事 / 感受内容要混合发。
- 旅行服务先从路线咨询、清单、AI 行程模板和合规伙伴合作验证，不直接跳到收费带队。

---

## 升级为正式 skill 的条件

先跑 4 周，至少完成 8 条内容和 2 次数据复盘。

如果确认这个流程能稳定带来私信、咨询、测试者或客户线索，再升级为 `90_系统/skills/skill-ip-content.md`，并同步更新协作入口。
