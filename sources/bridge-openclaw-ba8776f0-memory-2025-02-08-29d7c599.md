# 2025-02-08 投资理财学习日志

## 今日主题：指数基金和ETF

### 学习时间：约30分钟

### 学习内容：

1. **指数基金基本概念**
   - 被动型基金，追踪特定指数表现
   - 核心理念：获取市场平均收益，而非打败市场

2. **ETF vs 普通指数基金对比**
   - ETF：场内交易、实时成交、交易成本低、灵活性高
   - 普通指数基金：场外申赎、门槛低、适合长期持有
   - ETF联接基金：方便场外投资者参与

3. **主要宽基指数对比**
   - 沪深300：大盘蓝筹，稳健型，占A股60%市值
   - 中证500：中盘成长，科技属性强
   - 中证A500：新指数，更均衡配置
   - 创业板：高成长高波动

4. **定投策略**
   - 核心逻辑：摊平成本，无需择时
   - 建议：坚持3-5年，用闲钱投资，设置止盈目标

### 今日收获：

- 了解了不同类型指数基金的特点和适用场景
- 中证A500是较新的选择，可以作为沪深300和中证500之间的折中方案
- 定投最重要的是纪律，而非择时

### 下一步计划：

下次学习主题：**货币基金和余额宝类产品**
