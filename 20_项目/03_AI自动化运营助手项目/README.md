# 03_AI自动化运营助手项目

## 项目定位

AI 自动化运营助手是一个面向个人创业者、独立开发者、接单者和内容创作者的网页 SaaS 应用。

它不是一次性文案生成器，也不是自动评论、自动私信、矩阵截流工具，而是围绕长期账号人设和内容目标，帮助用户完成选题、内容包生成、发布数据记录、AI 复盘和下一轮迭代。

第一阶段先服务用户自己，用于小红书独立开发者获客线；流程跑通后，再扩展到旅行 IP、AI 工具创业、技术美术接单和更多平台。

## 当前状态

- 当前阶段：本地 Agent 工作流搭建。
- 第一条验证路径：小红书 + 独立开发者获客线。
- v0 产品形态：知识库内本地 Agent 工作流。
- 未来形态：流程验证有效后，再考虑本地网页工具或 SaaS。
- v0 使用者：wangyongcheng 自己。
- v0 付费 / API / 服务器：暂不接入，先用 Codex / Claude Code / ChatGPT 包月高能力模型验证自用闭环。

## 已确认原则

1. 产品主路径服务长期账号运营，不服务随机硬广。
2. 每条内容必须绑定运营档案、人设、平台和内容目标。
3. 内容生成必须基于档案、用户输入、竞品参考和历史数据，并标注来源。
4. v0 不做自动发布、自动评论、自动私信、养号、矩阵和截流。
5. v0 只支持文字描述素材，不支持图片上传、AI 读图、视频上传和视频解析。
6. v0 数据记录手动填写到本地 Markdown 文件。
7. v0 只保留本地复盘提醒规则，由用户或 Agent 在复盘时检查 24h / 7d 数据节点。
8. v0 不接 API，不部署服务器，不做数据库。
