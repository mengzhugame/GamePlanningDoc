# skill-weekly-review

## 目标

每周复盘一个运营档案的内容表现，并决定下一周内容方向。

## 输入

- 本周发布内容。
- 本周数据记录。
- 本周复盘结果。
- 当前运营档案。

## 步骤

1. 汇总本周发布数量。
2. 汇总本周复盘数量。
3. 按目标分类：曝光、涨粉、建立信任、获客、测试反馈、转化。
4. 找出最有效内容。
5. 找出最无效内容。
6. 判断账号阶段是否需要调整，只给建议，不自动修改。
7. 输出下周 3-5 个优先选题。

## 输出格式

```md
## 周复盘

- 周期：
- 运营档案：
- 本周发布：
- 本周复盘：
- 最有效内容：
- 最无效内容：
- 数据信号：
- 账号阶段建议：
- 下周重点目标：
- 下周选题建议：
- 需要同步到档案的变化：
```

## 禁止

- 不用“感觉不错”代替数据。
- 不因为单条浏览高就认定账号方向正确。
- 不把流水或临时反馈直接写入长期知识。
