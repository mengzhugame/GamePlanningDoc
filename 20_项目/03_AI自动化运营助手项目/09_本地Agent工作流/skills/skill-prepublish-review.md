# skill-prepublish-review

## 目标

发布前检查内容是否适合当前账号、是否有事实风险、是否像硬广、是否容易污染人设。

## 输入

- 待发布内容包。
- 对应运营档案。
- 平台。

## 检查项

1. 人设一致性。
2. 内容目标是否明确。
3. 是否有真实素材支撑。
4. 是否存在未核实事实。
5. 是否夸大收益、能力、经历或结果。
6. 是否像硬广。
7. 是否只有一个承接口。
8. 是否适合当前账号阶段。
9. 是否可能污染账号标签。
10. 是否需要用户补充截图、链接或数据。

## 输出格式

```md
## 发布前审核

- 结论：可发布 / 修改后发布 / 暂不发布
- 人设一致性：
- 事实风险：
- 硬广风险：
- 账号污染风险：
- 需要修改：
- 发布前必须核实：
- 建议最终标题：
```

## 禁止

- 不替用户确认未核实事实。
- 不因“更吸引人”而建议夸大。
