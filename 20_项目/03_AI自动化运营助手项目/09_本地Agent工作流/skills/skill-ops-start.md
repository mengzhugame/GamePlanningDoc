# skill-ops-start

## 触发

当用户说：

- 开始运营工作
- 今天发什么
- 生成本周选题
- 用某个档案做内容
- 复盘账号

先执行本 skill。

## 步骤

1. 读取 `../AGENTS.md`。
2. 确认本次使用哪个运营档案。
3. 读取对应 `../profiles/*.md`。
4. 判断是否需要读取档案中的 `source_of_truth`。
5. 明确本次任务类型：
   - 生成选题。
   - 分析竞品。
   - 生成内容包。
   - 发布前审核。
   - 数据复盘。
   - 周复盘。
   - 同步档案。
6. 如果用户目标和档案不匹配，先提醒账号污染风险。

## 输出

输出一个简短上下文确认：

```md
## 本次运营上下文

- 使用档案：
- 主平台：
- 账号阶段：
- 当前目标：
- 本次任务：
- 需要读取的来源：
- 账号污染风险：
```

## 禁止

- 不在未读取档案时直接生成内容。
- 不把用户临时想法自动写入档案。
- 不把未核实事实写成已发生。
