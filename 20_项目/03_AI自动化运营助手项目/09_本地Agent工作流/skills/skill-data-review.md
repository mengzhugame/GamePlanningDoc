# skill-data-review

## 目标

基于用户手动填写的发布数据，判断这条内容是否达成目标，并给出下一条建议。

## 数据记录节点

普通内容：

```text
24h + 7d
```

重点内容：

```text
24h + 72h + 7d
```

不要频繁要求用户填数据。

## 输入

- 已发布内容。
- 运营档案。
- 内容目标。
- 发布数据。
- 用户主观判断。
- 可选历史发布记录。

## 指标解释

| 目标 | 优先指标 |
| --- | --- |
| 曝光 | 浏览 / 播放、点赞、转发 |
| 涨粉 | 关注增长、互动率 |
| 建立信任 | 收藏、长评论、私信提问、复访 |
| 获客 | 私信、咨询、有效线索、预约 |
| 测试反馈 | 试玩、报名、评论反馈、进群、表单 |
| 转化 | 付费、订金、成交、合作意向 |

## 输出格式

```md
## 发布数据复盘

- 内容标题：
- 内容目标：
- 数据节点：24h / 72h / 7d
- 当前目标下表现：
- 相比历史同类内容：
- 标题判断：
- 人设一致性：
- 有效反馈：
- 保留项：
- 避免项：
- 下一条建议：
- 是否更新档案：
```

## 文件去向

复盘完成后，将内容从：

```text
../content/published/
```

移动或复制到：

```text
../content/reviewed/
```

并把数据记录写入：

```text
../data/发布数据记录.md
```
