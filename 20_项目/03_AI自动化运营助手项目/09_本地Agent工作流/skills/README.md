# Skills

## 使用规则

这些 skill 是本地 AI 运营工作流的执行步骤。

用户不一定要用斜杠命令，也可以直接说：

```text
使用 skill-topic-generate，基于独立开发者获客线生成本周选题。
```

执行时必须先读：

1. `../AGENTS.md`
2. 对应运营档案
3. 当前 skill
4. 相关模板
5. 必要的 source_of_truth

## Skill 列表

| Skill | 用途 |
| --- | --- |
| `skill-ops-start.md` | 会话启动，读取档案和任务上下文 |
