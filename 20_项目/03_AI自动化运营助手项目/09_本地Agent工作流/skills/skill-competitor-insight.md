# skill-competitor-insight

## 目标

分析用户手动提供的竞品内容或同类账号样本，提取可借鉴结构和差异化机会。

v0 不自动搜索全网，不假装已经看过平台数据。

## 输入

用户可以提供：

- 竞品标题。
- 竞品正文。
- 竞品链接。
- 截图文字描述。
- 公开数据：浏览、点赞、收藏、评论。
- 用户自己的观察。

## 步骤

1. 读取运营档案。
2. 区分“用户提供事实”和“AI 推断”。
3. 拆解竞品：
   - 标题钩子。
   - 内容结构。
   - 情绪点。
   - 用户痛点。
   - 信任来源。
   - 转化方式。
4. 对比当前档案：
   - 哪些可借鉴。
   - 哪些已经很卷。
   - 哪些不适合当前人设。
   - 当前账号差异化切口。
5. 给出本次选题建议。

## 输出格式

```md
## 竞品洞察

### 用户提供事实

-

### 竞品核心点

-

### 常见结构

-

### 信任来源

-

### 已经很卷的点

-

### 当前账号差异化

-

### 本次内容建议角度

-

### 风险提醒

-
```

## 禁止

- 不编造竞品数据。
- 不把竞品链接内容当成已读取，除非实际读取过。
- 不建议洗稿或伪原创。
