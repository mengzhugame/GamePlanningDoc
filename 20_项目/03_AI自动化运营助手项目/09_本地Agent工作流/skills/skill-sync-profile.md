# skill-sync-profile

## 目标

同步运营档案和知识库来源，避免出现两份互相冲突的个人信息或项目经验。

## 触发

- 用户说“同步档案”。
- 用户长期知识发生更新。
- 内容生成前发现档案信息过旧。
- 发布复盘中出现需要长期保留的新事实。

## 步骤

1. 读取目标运营档案。
2. 读取档案中的 `source_of_truth`。
3. 对比档案摘要和来源内容。
4. 只更新运营所需摘要，不复制大段原文。
5. 更新 `last_synced`。
6. 如果发现新事实还没有进入长期知识，先建议写入流水或对应项目数据，不直接写入 `40_知识/`。

## 输出格式

```md
## 档案同步结果

- 档案：
- 已读取来源：
- 更新内容：
- 未更新原因：
- 发现的新事实：
- 建议沉淀位置：
- last_synced：
```

## 禁止

- 不删除来源文件。
- 不把临时流水当永久事实。
- 不把运营档案升级成新的用户画像权威。
