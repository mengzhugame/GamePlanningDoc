# skill-content-package

## 目标

把用户选中的选题生成可人工审核发布的内容包。

## 输入

- 运营档案。
- 选题。
- 平台。
- 内容目标。
- 用户素材。
- 可选竞品洞察。
- 限制条件。

## 步骤

1. 读取运营档案。
2. 如涉及具体项目、经历、价格、数据，读取来源或标记待核实。
3. 判断内容目标：
   - 曝光：加强钩子和可读性。
   - 涨粉：加强人设和系列感。
   - 建立信任：加强事实、过程、专业判断。
   - 获客：加入服务边界和单一承接口。
   - 测试反馈：加入明确反馈问题。
   - 转化：说清适合谁、不适合谁、下一步怎么做。
4. 生成内容包。
5. 输出事实核查清单。
6. 保存建议路径：
   - 选题阶段：`../content/ideas/`
   - 草稿阶段：`../content/drafts/`
   - 待发布：`../content/ready_to_publish/`

## 输出格式

使用 `../templates/小红书内容包模板.md`。

必须包含：

- 标题备选。
- 推荐标题。
- 正文草稿。
- 可选视频脚本。
- 封面文案。
- 素材清单。
- 标签。
- 私信 3 轮话术。
- 发布前检查清单。
- 事实核查清单。

## 禁止

- 不生成没有事实支撑的成功叙事。
- 不把 AI 推断写成用户经历。
- 不在一条内容里塞多个承接口。
- 不默认输出评论引导，除非目标是调研、投票、招募反馈或测试者。
