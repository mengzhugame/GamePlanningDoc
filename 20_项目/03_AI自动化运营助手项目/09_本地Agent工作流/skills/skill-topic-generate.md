# skill-topic-generate

## 目标

基于运营档案、用户输入、历史内容、可选竞品洞察，生成 5-10 个可发布方向的选题。

## 输入

- 运营档案。
- 平台。
- 本次内容目标。
- 用户素材或想法。
- 可选竞品参考 / 竞品洞察。
- 可选历史发布数据。

## 步骤

1. 执行 `skill-ops-start.md`。
2. 读取对应运营档案。
3. 如果涉及具体项目或经历，读取 `source_of_truth`。
4. 判断当前账号阶段：
   - 初始化期 / 冷启动期：优先生成建立信任、真实经历、系列开头。
   - 定位校准期：生成 2-3 类可比较内容。
   - 建立信任期：生成案例、复盘、专业内容。
   - 获客转化期：允许生成承接内容，但不能硬广。
5. 如果用户提供竞品洞察，提取可借鉴结构和差异化点。
6. 生成 5-10 个选题卡。
7. 每个选题必须说明来源依据和风险。

## 输出格式

```md
## 选题候选

### 1. 选题标题

- 内容形式：
- 对应目标：
- 核心事件：
- 为什么用户会看：
- 需要素材：
- 来源依据：
- 风险提示：
- 推荐分：

## 推荐优先级

1. 最推荐：
2. 次推荐：
3. 暂缓：
```

## 质量标准

- 选题必须具体，不要泛泛写“分享经验”。
- 至少 3 个选题要绑定真实项目、真实经历或真实问题。
- 不生成脱离档案的随机硬广。
- 不承诺爆款。
