# 内容状态区

## 使用规则

这里存放本地 Agent 工作流生成和复盘的内容文件。

内容是运营执行材料，不是永久知识。只有经过复盘、确认有长期价值后，才考虑蒸馏到 `40_知识/` 或项目文档。

## 状态目录

| 目录 | 状态 | 用途 |
| --- | --- | --- |
| `ideas/` | idea | 选题候选 |
| `drafts/` | draft | 草稿内容包 |
| `ready_to_publish/` | ready | 已审核、待发布 |
| `published/` | published | 已发布，等待数据 |
| `reviewed/` | reviewed | 已复盘 |
| `archived/` | archived | 放弃、过期、归档 |

## 命名建议

```text
YYYY-MM-DD_平台_档案_短标题.md
```

示例：

```text
2026-06-03_小红书_独立开发者获客线_做废两款小游戏后我学到什么.md
```
