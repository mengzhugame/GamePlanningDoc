# 技术美术接单线

## 当前定位

一个有 Unity、TA、Shader、小游戏 Demo 和 AI 工作流经验的技术型执行者，能把想法快速做成可看的 Demo、效果样例或工程方案。

## 当前目标

先用专业内容建立可信度，后续承接：

- Unity Demo。
- 小游戏 Demo。
- Shader / VFX / 表现力优化。
- AI 应用或流程工具开发。
- 技术咨询和外包。

## 目标用户

- 有游戏或互动产品想法，但缺 Unity 落地能力的人。
- 小团队需要短期 TA / Shader 支援。
- 需要快速做 Demo 验证的创业者。
- 想用 AI 提高开发效率的个人或小团队。

## 可用真实素材

- 《光与朽》的战斗表现、Boss、数值和买量复盘。
- Unity / UGUI / Shader / VFX 相关技术经验。
- AI 代码 Agent 协作工作流。
- 小游戏上线踩坑。

使用具体项目或技术细节前，必须读取 `source_of_truth`。

## 内容风格

- 问题 -> 解决方案。
- 前后对比。
- 技术拆解。
- Demo 制作过程。
- 踩坑复盘。
- 服务边界说明。

## 禁忌表达

- 不承诺万能解决。
- 不夸大工期。
- 不写“什么都能做”。
- 不在没有评估需求前报价承诺。
- 不把接单帖写成硬广。

## 承接口

- 私信“Demo”沟通小游戏 / App / AI 工具 Demo。
- 私信“TA”沟通技术美术 / Shader / 表现力问题。
- 私信“需求”获取需求表。

## 账号污染提醒

不要发与技术能力、交付案例、项目复盘无关的纯生活内容。
