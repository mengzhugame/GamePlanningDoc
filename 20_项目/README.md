# 20_项目

## 这是什么

这里存放已经正式立项、正在制作、已上线、已测试或已结束复盘的**项目**。

项目不再限定为游戏，也包括 AI 工具、Web / App 应用、自动化工作流产品、技术产品、可交付的软件服务等。

判断标准不是“它是不是游戏”，而是：

- 是否已经从商业想法进入具体制作。
- 是否需要 PRD、开发计划、功能设计、版本迭代、数据验证和复盘。
- 是否有明确的用户、使用场景、交付物或上线目标。

## 不放什么

- 还没有验证的游戏创意。
- 只是想法阶段的题材。
- AI 概念视频测试前的灵感。
- 只停留在商业模式、变现逻辑、公司化路线、个人 IP 策略层面的内容。
- 与某个具体产品 / 工具 / 游戏制作无关的市场观察、战略判断或账号运营规划。

这些内容分别放到 `00_草稿/`、`30_市场分析/` 或 `50_商业/`。

## 公共模板

- `开发计划表模板.md`：每个新项目立项后复制到项目根目录，命名为 `02_开发计划表.md`，统一记录阶段计划、任务、Bug、数据验证和复盘。
- `上线数据复盘模板.md`：每个项目上线后复制到对应 `发行追踪/` 文件夹填写。

## 使用规则

- 这里只放已立项、已上线、已测试、正在制作或已结束复盘的项目。
- 游戏项目、AI 工具项目、App / Web 应用项目、SaaS 项目都可以放在这里。
- 商业规划、变现逻辑、个人 IP 策略和公司化判断放 `50_商业/`；只有进入具体产品制作后，才升级进入 `20_项目/`。
- 概念验证失败或未进入制作的方向留在 `00_草稿/游戏创意库/`。
- 项目内历史资料统一使用 Markdown，旧 Office 源文件不再保留。
