## 立项前概念验证规则（2026-05-01）

任何新游戏方向在进入正式项目或 7 天切片前，先放入 `20_项目/03_概念验证_YYYY-MM/` 做轻量验证。

核心纪律：

- 概念视频必须展示未来游戏中真实可玩的核心玩法，不做“广告骗玩法”。
- 没有视频信号，不进原型。
- 没有陌生人试玩信号，不进 Demo。
- 没有留存 / 买量信号，不进完整项目。
- 朋友、运营、发行说“新颖 / 不错 / 有潜力”，只解锁下一层验证，不解锁完整开发。

当前推荐漏斗：

概念方向 → 真实核心玩法视频 → 平台发布记录数据 → 选择高信号方向 → 7 天垂直切片 → 20 个陌生玩家 → Demo → 发行 / 运营反馈 → 微信小游戏上线 → 小额买量 → 留存 / 广告数据 → 继续或止损。

---

1.让 openclaw 搜 50-100 条小游戏/解压/休闲玩法视频，只做分类，不做结论。
2.选6个核心动词
3.根据6个核心动词 生成6个概念卡
4.根据概念卡制作AI概念视频 每个动词做 3-5 条 AI 视频，总计 24-30 条。每条 7-12 秒，统一结构：第一秒冲突、3 秒内看懂规则、最后 2 秒展示结果。
5.发布并记录数据，不改太多变量。
6.只迭代表现最好的 2-3 个方向，每个方向再做 3 条变体。


每周产出 5-10 个核心动词视频概念。
每周做 2-3 条短视频素材，先测观看和评论欲望。
每月只挑 1 个最强概念做 7 天垂直切片。
每个切片找 20 个陌生用户测试。
数据好，再进入 Demo；数据差，立刻分解资产，换下一个。

视频 1：荒废花园复苏

标题：这片死掉的花园，能救回来吗？

0-2s：
画面：灰色枯萎花园，地面裂开，只有一小块可用土地。
操作：手指拖动角色捡起种子和水壶。

2-5s：
画面：角色把种子放进苗床，浇水，长出第一朵小白花。
操作：点击收获花朵，花朵飞到背包。

5-8s：
画面：小摊前出现顾客订单“白花 ×2”。
操作：玩家把两朵花拖到订单框，获得金币。

8-12s：
画面：金币解锁旁边一块枯地，灰色土地变绿，花朵同时开放。
高潮：绿色光波扩散，花园复苏一小片。

关键生图：枯萎花园 / 第一朵花长出 / 顾客订单 / 土地复苏。



视频 2：最后一秒花束订单

标题：顾客快走了，最后一束花来得及吗？

0-2s：
画面：顾客头上订单“红花 ×2 + 蓝花 ×1”，倒计时 10 秒。
操作：玩家看到两个花圃，一个红花成熟，一个空地。

2-5s：
画面：玩家收割红花，同时在空地种下蓝花。
冲突：蓝花生长慢，倒计时只剩 5 秒。

5-9s：
画面：玩家把红花拖进花束台，蓝花最后一刻成熟。
操作：手指快速拖入蓝花，花束进度条填满。

9-12s：
画面：倒计时剩 1 秒，花束交付成功，顾客开心，金币爆出。
高潮：小摊升级，多一个花束台格子。

关键生图：订单倒计时 / 种花收花 / 花束台加工 / 最后一秒交付。


视频 3：杂草扩散反转

标题：杂草快把花园吞掉了。

0-2s：
画面：花园右侧黑色杂草一格格扩散，快碰到主花圃。
操作：玩家手动清掉一格杂草，但扩散继续。

2-5s：
画面：玩家卖花获得金币，商店弹出“园丁 / 洒水器”两个升级。
操作：选择园丁。

5-9s：
画面：园丁自动清杂草，玩家继续种花赚钱。
冲突：杂草扩散到主花圃边缘。

9-13s：
画面：玩家攒够金币解锁洒水器，一排水流扫过，杂草大片消失。
高潮：黑色区域变绿，花朵连片开放。

关键生图：杂草扩散 / 升级选择 / 园丁工作 / 洒水器反杀。


视频 4：最后一格防线

标题：基地只剩 1 点血，还能守住吗？

0-2s：
画面：三条路径怪物冲向核心，核心 HP 显示 1/10。
操作：波次暂停，屏幕下方出现 3 张卡：激光塔、减速塔、弹射炮。

2-5s：
画面：玩家拖动激光塔卡牌，放到拐角空位。
操作：点击“开始波次”。

5-9s：
画面：怪物冲到核心前一格，激光塔充能变亮。
冲突：最后一只怪即将撞上核心。

9-12s：
画面：激光贯穿整条路，怪物清空，金币飞入 UI。
高潮：显示“极限防守成功”。

关键生图：1 血基地 / 三张卡 / 激光塔放置 / 激光清场。


视频 5：怪物进化打断

标题：再晚一秒，它们就合成 Boss 了。

0-2s：
画面：两只特殊怪向中间靠近，头顶“进化倒计时 5 秒”。
操作：玩家看到普通怪很多，但两只特殊怪有红色连线。

2-5s：
画面：玩家把火力标记拖到特殊怪身上，防御塔集火。
冲突：普通怪趁机逼近基地。

5-8s：
画面：进化倒计时剩 1 秒，两只怪即将重叠。
操作：玩家点击右下角“冻结/打断”技能。

8-12s：
画面：进化失败，能量爆炸，周围怪物被炸掉。
高潮：金币掉落，基地解除危机。

关键生图：进化倒计时 / 红线靠近 / 点击技能 / 进化爆炸。


视频 6：三选一卡牌翻盘

标题：这 3 张卡，只能选 1 张。

0-2s：
画面：下一波预览：左路快怪，中路厚血怪，右路飞行怪。
操作：下方出现 3 张卡：激光塔、减速塔、弹射炮。

2-5s：
画面：玩家第一次选错，把激光塔放左路，快怪冲破防线。
字幕：选错，一波崩。

5-7s：
画面：时间回退到选卡瞬间。
操作：玩家改选减速塔，拖到左路关键格。

7-11s：
画面：快怪被减速，中路被弹射炮清掉，技能充能完成。
高潮：点击冻结，三路极限守住。

11-14s：
画面：金币飞入，显示“第 3 波通过”。
关键生图：三路怪物预览 / 三张卡 / 选错崩盘 / 选对翻盘。
