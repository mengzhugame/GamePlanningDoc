# 2026-05 概念验证池

> 本目录不是正式项目目录。这里存放立项前的概念验证材料：核心假设、真实玩法视频脚本、发布数据、测试结论。

---

## 核心规则

1. **没有视频信号，不进原型。**
2. **没有陌生人试玩信号，不进 Demo。**
3. **没有留存 / 买量信号，不进完整项目。**
4. 概念视频必须展示未来游戏里真实可玩的核心玩法，不做“广告骗玩法”。
5. 专业人士、朋友、运营说“新颖 / 不错 / 有潜力”，只解锁下一层验证，不解锁完整开发。

---

## 本轮验证目标

本轮不比较“哪个方向听起来更好”，只比较：

1. 玩家看到真实玩法视频后，是否愿意停留、点赞、收藏、评论或追问。
2. 玩家是否能在 3 秒内看懂核心玩法。
3. 这个方向是否值得进入 7 天垂直切片。

## 推荐验证节奏

1. 每个方向先做 3 条真实核心玩法视频脚本。
2. 用关键画面生图 + 图生视频 + 后期 UI 叠加制作 10-15 秒竖屏视频。
3. 发布到小红书 / 抖音 / B站等平台，记录数据。
4. 如果“看不懂”，先重做视频表达，不判定玩法失败。
5. 如果“看得懂但没人想玩”，最多换一次钩子或美术风格。
6. 两版视频都没有评论欲望 / 收藏 / 想玩反馈，则概念暂停，不进入切片。

## 进入 7 天切片的最低条件

至少满足其中两项：

1. 评论区出现明确“想玩 / 在哪玩 / 这是什么游戏”。
2. 收藏或转发明显高于普通开发记录内容。
3. 同方向 2 条视频中至少 1 条有正向反馈。
4. 用户能复述核心玩法，而不是只夸画面。
5. 小龙儿本人愿意在 7 天内做真实可玩切片，并能控制范围。
