# 02_光与朽项目

## 这是什么

《光与朽》项目资料区。这里包含策划、开发计划表、资产、发行追踪和大量对战数据。

## 需要重点复盘

- 玩法立项是否有足够差异化。
- Boss 战、塔防、肉鸽、数值体验是否形成稳定爽点。
- 买量测试投入与数据反馈是否支持继续扩张。
- 数值是否做到“差一点通关，从而愿意看广告”的体验。

## 关键入口

| 文件 | 用途 |
| --- | --- |
| `光与朽项目.md` | 项目概览 |
| `02_开发计划表.md` | 历史 Demo 计划、任务、Bug、美术优化和重启顺序归档 |
| `04_发行追踪/上线数据复盘_光与朽.md` | 自然宣传、腾讯广告买量、投后数据复盘填写表 |
| `04_发行追踪/游戏发行追踪.md` | 发行商对接与反馈记录 |
| `04_发行追踪/发行商反馈分析.md` | 发行反馈分析 |
| `06_对战数据/README.md` | 对战与数值数据入口 |
