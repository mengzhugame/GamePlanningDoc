## 一、核心设计原则

1. 继承 + 叠加：每章保留第一章 4 种基础怪（Slime/Rusher/Tank/Drifter）的换皮版本作为通用杂兵，新增 2~3 种章节特色机制怪混入波次。

2. 视觉区分 - RT 流体换色：第一章黑紫色 → 第二章暗红色 → 第三章冰蓝色。怪物形状、装饰层和眼睛图层提供进一步差异化。

3. 操作新鲜感：第二章引入「自爆 + 地形hazard」和「远程炮手 + 弹丸拦截」；第三章引入「辅助光环 + 优先击杀顺序」和「施法打断博弈」。

4. Boss 继承架构：所有 Boss 继承 BaseBossController 基类，仅替换表现和主动技能函数。共享入场动画、受击反馈、异常状态、阶段转换等底层逻辑。

5. 单一分裂限制：精英分裂者死后产出的子代为不可再分裂的小型怪，避免指数爆炸。

## 三、第二章：熔岩虚空 (Magma Void)

章节定位：高压战场，强调地形限制与目标优先级。

视觉基调：RT 流体统一暗红色。装饰件为橙黄色火星粒子、黑曜石碎片、岩浆裂纹 Sprite。

背景：深红至暗橙渐变底色，霓虹橙/亮黄色透视网格，向上飘散的橙色几何火星粒子。

## 五、新增系统需求清单

### 5.1 弹丸系统 (Projectile System)

服务对象：Artillery 的熔岩球、Frostcaster 的冰冻射线、Boss 技能弹丸（陨石、火球、冰封射线）。

| 组件 | 说明 |
| --- | --- |
| EnemyProjectile.cs | 敌方弹丸基类。字段：damage, speed, lifetime, canBeIntercepted, hp（可被激光拦截时的血量）。带 Rigidbody2D + CircleCollider2D |
| ProjectilePool.cs | 弹丸对象池管理器。按弹丸类型分池（MagmaBall, IceRay, Meteor 等） |
| MagmaBall.cs | 继承 EnemyProjectile。抛物线轨迹（模拟重力），命中塔后生成小型岩浆斑 |
| IceRay.cs | 继承 EnemyProjectile。直线射线（LineRenderer），持续 3 秒，命中塔后施加冻结 Debuff |
| Meteor.cs | 继承 EnemyProjectile。从屏幕上方坠落，带预警红圈 UI，1.5~2 秒反应窗口 |
| LavaPool.cs | 岩浆斑地形 hazard。圆形触发区域，存在期间激光穿过时伤害衰减 30%。带 DOTween 淡入淡出 |
