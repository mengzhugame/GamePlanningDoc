## 四、技能详细设计（已确认版）

---

### 技能1：冰墙构建 ✅

**描述**：Boss 身体蓄力发光，在场地随机位置召唤 2~3 堵冰墙，阻断玩家激光路径。

#### 蓄力阶段（1.5s）
- `RedBodyEffect` 蓝白光晕从暗到亮（alpha 0→1）
- 全身冰雾粒子特效（可选）

#### 释放阶段
- 随机生成 **2~3 堵冰墙**（使用 `EnemyType.IceWall` 对象池）
- 冰墙属性：**纯 30 秒自动消失，无 HP，不可被激光摧毁**
- 冰墙完全阻断激光（Raycast 停止穿透）
- 与霜冻施法者共用 IceWall 对象池

#### 蓄力结束
- `RedBodyEffect` 光晕淡出（1s）
- 进入冷却

---

### 技能2：冰封射线 ✅

**描述**：Boss 从自身中心发射持续 3 秒的蓝色冰封射线，固定指向光棱塔，不扫射，Boss 本体不旋转。

#### 蓄力阶段（1s）
- 顶部 `Body03` 水晶闪烁
- `Laser` LineRenderer 起点在 Boss 中心，末端收缩为 0

#### 射线阶段（3s）
- LineRenderer 从 Boss 中心延伸，固定朝向光棱塔方向
- 末端 `EndVFX`（Particle + Beam）跟随射线终点实时更新

#### 命中判断（每帧 Raycast）

| 命中目标 | 效果 |
|---|---|
| 光棱塔护盾（Shield 碰撞体） | 护盾扣血，**不冻结光棱塔** |
| 光棱塔本体（Tower 碰撞体） | 触发冻结 1.5 秒 |
| 冰墙 | 激光被阻断，不传递 |
| 其他 | 无效果 |

#### 光棱塔冻结表现
- 光棱塔显示**冰封覆盖图片**（半透明蓝白冰块叠加）
- 冻结期间：无法旋转，无法射击
- 默认持续 **1.5 秒**后自动解冻（图片渐隐消失）
- **玩家连续点击屏幕可加速解冻**（每次点击缩短约 0.1s，QTE 机制）

#### 结束
- 射线收缩消失，`Laser` 禁用，EndVFX 停止

### 技能4：绝对零度 ✅

**描述**：终结/低血量技能。全屏警告蓄力 3 秒，四枚冰刺旋转对准光棱塔后急速射出，玩家须在蓄力期打断或击落冰刺。

#### 蓄力阶段（3s）

| 时间 | 内容 |
|---|---|
| 0s | 全屏警告（边框闪烁 + 提示文字"冰封临界"） |
| 0~3s | BingCi01~04 SpriteRenderer 逐渐发光（alpha 增强） |
| 0~3s | 急促冰裂音效，频率递增 |

**打断条件**：3 秒内对 Boss 造成 ≥ 5,000 伤害
- 打断成功 → Boss 眩晕 2s，冰刺发光熄灭，技能取消

#### 释放阶段（打断失败时触发）

**Step 1：拔出（0.4s）**
- BingCi01~04 各自向外侧位移约 0.4 单位（远离 Boss 中心）
- Lerp 动画，模拟"从体内拔出"

**Step 2：旋转对准（0.6s）**
- 各冰刺用 Quaternion.Slerp 旋转，使刺尖指向光棱塔
- 四枚错开 0.1s 依次完成旋转

**Step 3：射出**
- 各冰刺位置生成独立**冰刺投射体 Prefab**（含 Rigidbody2D + CircleCollider2D + HP 组件）
- BingCi01~04 子节点 alpha 隐藏（= 0），保留位置不变
- 投射体朝光棱塔方向飞出，四枚错开 0.15s 依次发射

**冰刺投射体属性**：

| 属性 | 数值 |
|---|---|
| HP | 5,000 |
| 飞行速度 | 16 units/s |
| 可被激光摧毁 | 是（同第二章陨石逻辑） |
| 命中光棱塔（全部未被摧毁时） | 触发惩罚结算 |

**惩罚结算**（所有冰刺命中 或 超时未摧毁）：
- 光棱塔受当前血量 30% 真实伤害
- 光棱塔冻结 3 秒（可点击解冻）
- 额外怪物波次涌入

#### 再生阶段（射出后 2s）
- BingCi01~04 在原始相对位置，alpha 从 0 → 1 淡入（0.5s）
- 冰刺恢复，可进入下一轮绝对零度

## 五、技能循环

```
入场缓降
  └→ 普通待机（Boss 保持在屏幕上方）
       ├→ 技能1 冰墙构建（CD ~15s）
       ├→ 技能2 冰封射线（CD ~20s）
       ├→ [血量 < 50%] 技能3 极寒领域激活
       └→ [血量 < 25% 或 阶段切换] 技能4 绝对零度
```
