### 2.4 技能协同因子（Synergy Factor）

```
Synergy_Factor(N) = Effective_DPS(N) / Panel_DPS(N)
```

| 波次 | Synergy因子范围 | 中位数 | 说明 |
|------|----------------|--------|------|
| W1 | 0.48-0.55 | **0.50** | Panel高估实际（定位损耗、过杀） |
| W2 | 0.65-0.75 | **0.70** | 逐步提升 |
| W3 | 0.68-0.76 | **0.70** | |
| W4 | 0.42-0.80 | **0.65** | Tank吸收、高方差 |
| W5 | 1.10-4.50 | **1.26** | **技能协同触发** |
| W6 | 1.10-3.50 | **1.26** | |
| W7 | 0.70-2.20 | **0.94** | Rusher+Drifter，面积利用低 |
| W8 | 1.10-2.80 | **1.71** | |
| W9 | 1.20-4.80 | **1.81** | 高峰协同效果 |

**双制度模型**：
- **早期（W1-W4）**：Panel_DPS × 0.5~0.7 ≈ 实际DPS → 面板高估
- **后期（W5-W9）**：Panel_DPS × 1.1~4.8 ≈ 实际DPS → 技能协同大幅增益

这意味着低Panel_DPS的技能流派（如Frost+Shatter，面板仅1000-1100）在后期实际伤害可超过高Panel_DPS流派。

**进入Boss战时EHP分布**：
- 75th百分位（容易局）：1900-2000 EHP剩余
- 50th百分位（中位）：1500-1700 EHP剩余
- 25th百分位（危险局）：1040-1200 EHP剩余

### 4.2 败局分析

5次败局均发生在W10 Boss战：
| 败局特征 | 分析 |
|---------|------|
| Boss剩余HP：2-15% | Boss几乎被击杀，差之毫厘 |
| 推测进Boss时EHP：600-900 | W8-W9消耗过重导致本体耗尽 |
| Boss造成伤害：250-750 | 被Charge/Press命中2-3次即死 |

**设计结论**：败局体验良好——玩家不会感到"无从控制"，而是"再努力一点点就能赢"。这是Roguelike设计的理想败局模式。

### 4.3 W7的"护盾危机"

W7（Rusher×20+Drifter×5）是护盾受伤最不确定的波次。
- 部分Build：仅受20-40点护盾伤害（高DPS快速清场）
- 部分Build：受490-700点护盾伤害（低DPS拖延，Drifter反复撞击）

**阈值判断**：若W7 Effective_DPS < 800，则护盾损耗>300；若>1400，则护盾损耗<100。
这说明W7是个DPS门槛检测点——低于门槛的Build在W8进入"赤字模式"。

## 五、Deal契约经济学模型

基于数据中Deal箱子的使用记录分析：

### 5.1 契约ROI分析

典型Deal契约（护盾-100 → 激光攻击力+15%）：
- **成本**：100护盾（约300 EHP价值，因护盾是最前层防御）
- **收益**：15%激光DPS提升

若当前Panel_DPS = 1000：+15% = +150 DPS
累计10波 × 65s/波 = 650s输出时间
收益 = 150 DPS × 650s = **97,500点额外伤害**

即使按最低效率计算（50% synergy），实际收益 = 48,750额外伤害。
而敌人总HP = 所有波次合计约 ≈ 847,130。
单次契约DPS加成贡献 ≈ 5-10%的总伤害提升。

### 5.2 最高ROI局分析（文件：070642）

该局选了9次Deal箱子，总HP代价：
- 本体损失：-80×5 = -400 HP
- 护盾损失：-100×4 = -400 Shield
- 总代价：-800 EHP（从3000降至2200可用EHP）

回报：W9 Effective_DPS = **3,494**（全部25局最高单波DPS）
Boss击杀时间：**23s**（第二快）

**结论**：Deal契约是高风险高回报策略，适合熟练玩家。代价明确（直接扣HP/护盾），收益通过技能倍乘放大，设计正确。

## 六、Panel_DPS官方成长曲线（校准完成）

基于25局实机数据，以下为实现80%胜率的Panel_DPS成长目标：

```
W1  → W2  → W3  → W4  → W5  → W6  → W7  → W8  → W9
1000  1150  1300  1500  1800  2000  1720  1720  1800
```

成长系数：×1.15 → ×1.13 → ×1.15 → ×1.20 → ×1.11 → ×0.86 → ×1.00 → ×1.05

**注意**：W7-W9出现Panel_DPS不增长甚至下降，这是**设计正确**的现象：
- 原因1：玩家在后期选择Frost/Wide等非纯DPS技能，拉低面板均值
- 原因2：后期Synergy Factor大幅提升（1.7-1.8×），实际效率反而更高
- 结论：用Panel_DPS成长曲线设计技能奖励时，W7-W9不需要强制提升面板DPS

## 七、设计结论与行动建议

### 7.1 验证通过的设计决策

| 设计决策 | 实测验证 |
|---------|---------|
| Boss HP = 120,000 | ✅ 80%胜率精准，败局为"惜败" |
| W5为技能爆点 | ✅ 清场时间最稳定（±0.8s），Synergy首次>1 |
| W6+W8为高压波 | ✅ HP量是前一波2-3倍，有效制造压迫感 |
| W3+W7为休息波 | ✅ HP回落，玩家喘息 |
| Deal契约为高风险高回报 | ✅ 最高DPS局就是Deal频繁选用局 |

### 7.2 发现的潜在设计问题

| 问题 | 数据依据 | 严重程度 | 建议 |
|------|---------|---------|------|
| **W4方差过大** | 清场时间54s~138s（2.5倍差距） | ⚠️ 中 | W4是"Build成熟度测试"，考虑在W3结束时给予一次"保底"的有效技能奖励 |
| **冰冻流面板误导** | Panel=1000但Effective可达4500+，信息差 | ⚠️ 中 | 可考虑在UI中显示"实时DPS"而非仅面板值 |
| **W7护盾危机不可预测** | 受伤范围20-700（35倍差距） | ⚠️ 中 | 考虑给W7出怪引入伤害上限机制，或确保玩家对Drifter危险性有视觉预警 |
| **Boss Summon阶段**（冰冻流弱势） | Summon时爆炸无效，导致冰冻流最长100s | ℹ️ 低 | 属于策略深度，保留。可以在UI提示Boss阶段行为 |

### 7.3 下一步行动项

按优先级排序：
1. **[数值]** 确认W4奖励池是否包含足够的"快速成型"选项（让弱流派在W4前完成核心技能构建）
2. **[UI]** 评估是否增加"实时DPS"显示，减少冰冻流玩家的面板困惑
3. **[数值]** 基于本模型为第二章设计HP锚点（建议W6+W8 HP各提升20-30%作为起点）
4. **[测试]** 增加样本至50局，重点关注Deal流派的生存率（当前样本中Deal流仅1局）
