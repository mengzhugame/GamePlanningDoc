# 《光与朽》怪物与 Boss 美术设计文档

本案确立了游戏第一章至第三章的全部美术视觉规范，为 AI 生图（Nanobanban / 即梦等工具）与 Unity 实机拆层拼装提供标准蓝图。

---

## 🎨 核心美术规范
*   **全局画风**：纯 2D 矢量赛璐璐平涂（2D vector art, cell shading）。
*   **质感要求**：极简休闲风格，高对比度，明显的果冻感/流体高光，纯净的白底，部分怪物需配备极粗的纯黑色外描边。
*   **设计禁忌**：**严禁拟人化（绝不能长出人类的头、手、脚）**，严禁使用渐变色或 3D 渲染质感，严禁复杂的背景与光影投射。
*   **Unity 层级拆分架构（4 层标准）**：
    1.  **底图层 (Body RT)**：模拟流体的纯色异形底座（作为底层 Metaball 融合的基础）。
    2.  **核心特效层 (Effect/Aura)**：光环、高亮发光核心或光束口。
    3.  **挂件/装甲层 (Accessories/Armor)**：覆盖在流体表面的固体残骸、石头或冰晶，必须具备极其清晰的独立边缘，方便在 PS 中单独抠出。
    4.  **眼睛层 (Eyes)**：代表生物情绪特征的卡通眼或高亮缝隙眼。

---

## 🟢 第一章：深暗虚空 (Dark Void)

**视觉基调**：纯黑色流体（柏油/石油）、废土机械感、呆萌与诡异结合的冲突美学。

### 1. 流体黑油怪 (小怪系列)
*   **基础形状**：被磨圆边缘的纯几何体（方形、圆形、水滴形等），边缘有向外迸发或黏稠拉丝的液态特征。
*   **层级拆分**：
    *   **底图流体**：极其光滑、反光强烈的纯黑果冻态底盘，带有极粗黑描边。
    *   **挂件层**：插入或黏附在体表的生锈废土垃圾（如铁钉、破损齿轮、扭曲的钢筋管、骨头等）。
    *   **眼睛层**：极其突兀的、带有大片眼白、瞳孔极小、显得“呆滞又诡异”的卡通大眼。

### 2. 第一章 Boss：贪食魔蟾 (The Abyssal Toad)
*   **基础形状**：极度臃肿、肥胖、扁平的巨大半圆形/大水滴形，趴在地上呈现出类似巨型蟾蜍或史莱姆之王的重力下坠感。
*   **层级拆分**：
    *   **底图流体**：瘫在地上横向铺开的巨大黑油泥。
    *   **挂件层**：背部插着巨大的废弃物（如折断的高压电线杆、巨大的警戒线黄黑相间路牌、生锈的大齿轮）。
    *   **嘴巴特效层**：正面有一道极其夸张的、横跨整个身体的月牙形深渊裂缝大嘴，用于实现【污秽喷吐】与【重力碾压】的动画张力。
    *   **眼睛层**：嘴巴裂缝上方，顶着两只外突的、充满血丝的青蛙式呆滞大眼。

## 🔥 第二章：熔岩火山 (Magma Void)

**视觉基调**：沸腾、极度不稳定、高温白炽光、暗红/亮橙色流体、坚硬厚重的黑曜石。

### 1. 熔岩分裂怪 (Lava Splitter)
*   **基础形状**：粗壮的倒三角形 / 扁平微型火山状，底盘宽，边缘有滴落的半融化岩浆。
*   **层级拆分**：
    *   **底图流体**：纯红橙色的半融化流体。
    *   **挂件层**：身体表面嵌着 3 块巨大的黑色冷却黑曜石装甲板。
    *   **眼睛层**：装甲缝隙里排列着 3 只（一大两小）发光黄色竖瞳，暗示体内有 3 个待分裂子体。

### 2. 熔岩自爆怪 (Lava Bomber)
*   **基础形状**：极度膨胀肿胀的球体（Swollen Sphere），边缘有随时爆开的沸腾气泡。
*   **层级拆分**：
    *   **底图流体**：亮红到近乎白炽色（White-hot）的高压球体。
    *   **挂件层**：覆盖全身但被内部高压撑出巨大裂纹的薄脆黑岩壳。
    *   **眼睛层**：中心单只巨大的、瞳孔极小、充满血丝或光丝的“疯狂大眼”。
*   **衍生资源**：需要单独输出一张纯顶视视角的“岩浆斑 (Lava Pool)”平面贴图，作为自爆后遗留地形。

### 3. 熔岩坦克怪 (Lava Tank)
*   **基础形状**：极其厚重、边缘磨圆的巨型方块（Rounded Square），视觉上如同一块踢不烂的铁板。
*   **层级拆分**：
    *   **底图流体**：暗红色的高密度岩浆，仅在边缘漏出。
    *   **挂件层 (重点)**：表面 80% 以上被极其厚重的、类似拼图般拼接的黑曜石大厚板完全包裹，装甲间有深沟壑。
    *   **眼睛层**：在正面装甲的宽阔缝隙中，露出一双明亮巨大的双眼（或如护目镜般的长条眼）。

### 4. 熔岩炮手怪 (Lava Spitter)
*   **基础形状**：水滴形或锥形（Cone），尖端朝向正前方/下方。
*   **层级拆分**：
    *   **底图流体**：尾部圆润、前端收窄的暗橙色流体。
    *   **挂件/炮口层**：最前端是一个边缘包裹着坚硬岩石的“微型火山口”，内部极其白炽刺眼（代表弹药蓄力）。
    *   **眼睛层**：炮口后方的两侧，长着两只细长、聚焦感强烈的狙击手眼睛。

### 5. 精英怪视觉强化 (Elite Variations)
*   **精英分裂怪**：体型更大，体内密密麻麻挤着 5-6 只眼。背部向外刺出极其锋利、巨大的黑曜石结晶尖刺（如王冠/剑龙背刺）。
*   **精英自爆怪**：核心变为极其危险的【亮蓝色/白炽色（Plasma态）】。外层的黑色碎壳已经完全脱离本体，像卫星一样悬浮环绕在亮蓝岩浆球周围，单眼瞳孔变为燃烧的十字星。

### 6. 第二章 Boss：熔炉巨兽 (The Magma Furnace)
*   **设计核心**：抛弃拟真山体与巨口设计。呈现出一个充满绝对对称几何感、坚不可摧的“古代重装熔炉”。
*   **基础形状**：极其庞大、沉重的圆角六边形或盾形 (Hexagon / Shield shape) 对称结构。
*   **层级拆分**：
    *   **底图流体**：巨大的暗红岩浆底盘。
    *   **核心特效层**：底盘正中心是一个极其巨大、完美的【正圆形白炽光高能核心】（绝非眼睛，是能量熔炉口）。
    *   **装甲层**：极其厚重对称的黑曜石大板覆盖四周，前部包裹巨大撞角盾牌。装甲上方带有 3 个深邃的圆形散热孔（用于喷发陨石）。
    *   **眼睛层**：在中心核心上方的黑色装甲上，横向排列 3 只狭长、冷酷的发光黄眼。

## ❄️ 第三章：极寒虚空 (Glacial Void)

**视觉基调**：凝滞、绝对零度、机械几何切割感、深蓝/青色厚重流体，高透明折射冰晶。

### 1. 冰甲巨兽 (Frost Tank)
*   **基础形状**：被冻结迟缓的巨大圆球体。
*   **层级拆分**：
    *   **底图流体**：颜色偏暗蓝、运动极其迟缓的巨大流体球。
    *   **挂件装甲层**：几块极其巨大、表面带有划痕和极强高光折射反光的“半透明多边形厚重冰晶”。
    *   **眼睛层**：透过半透明冰层，显露出极小瞳孔的幽蓝色凝视眼。

### 2. 极寒光环者 (Aura)
*   **基础形状**：极其轻盈、微小的悬浮柱状体或水滴。
*   **层级拆分**：
    *   **底图流体**：浅蓝色的微型流体。
    *   **核心特效层**：流体中心镶嵌一颗完美的六角形高亮冰晶。它的正下方（地面）带有一个极其庞大、缓慢旋转的【几何雪花法阵图层】。
    *   **眼睛层**：带有细长睫毛、紧闭双眼，呈冥想祈祷状。

### 3. 霜冻施法者 (Frostcaster)
*   **基础形状**：高挑细长如法师塔般的液体柱。
*   **层级拆分**：
    *   **底图流体**：细长的深青色柱状流体。
    *   **挂件/武器层**：在流体顶部上方，悬浮着一颗散发浓烈寒气光晕的高亮冰封法球。
    *   **眼睛层**：充满魔力光芒的锐利倒三角眼。

### 4. 第三章 Boss：极寒之核 (Glacial Core)
*   **设计核心**：与流体产生极致反差的绝对防御要塞，极具冷酷与几何结晶感。
*   **基础形状**：长满锐利冰刺的巨大多边形/菱形晶体。
*   **层级拆分**：
    *   **底图流体**：深邃如深渊大海的巨大暗蓝流体球（被禁锢在内部）。
    *   **装甲层**：极其规则、极其坚硬的巨型透明菱形/多边形冰盾外壳，像一个绝对防御的笼子把流体锁在里面，表面不发生任何软体形变。
    *   **特效核心**：冰层内部折射冷酷的青色光晕。没有常规生物眼睛，只有一道散发绝对零度刺眼蓝光的“几何形核心裂缝”，作为全场的弱点聚焦处。
