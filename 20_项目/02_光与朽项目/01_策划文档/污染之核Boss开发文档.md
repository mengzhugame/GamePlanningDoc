## 项目文档：BOSS 战 "The Corruptor" 开发规范

### 1. 基础设定 (Base Stats)

名称： The Corruptor (污染之核)

HP / Shield: 使用大数值体系 (如 50,000)。

弱点机制：

Body (护甲): 始终存在，30% 伤害，无击退，不产生推力。

Core (眼睛): 特定状态开启，200% 伤害，计算物理推力。

### 2. 核心状态机 (Main State Machine)

逻辑流： Spawn -> Idle -> Check_Summon -> Choose_Skill -> (Charge OR Press) -> Stun -> Idle ...

#### 🟢 State: Spawn (入场)

行为： 屏幕震动，BOSS 从屏幕上方外侧缓缓降落至 战斗锚点 (Y=3.0)。

表现： 播放咆哮音效。眼睛闭合。

时长： 约 3秒。结束后进入 Idle。

#### 🔵 State: Idle (待机/游走)

行为： 在屏幕上方区域 (X: -2 到 2) 进行平滑的正弦波左右游走。

时长： 随机 3.0s ~ 5.0s (狂暴时减半)。

眼睛： 闭合 (无弱点)。

子系统检查： 在此状态下，每帧检测 Summon 和 Pollution 的计时器。

### 3. 被动技能 (Sub-Skills during Idle)

这两个技能不占用 BOSS 的主要动作回合，由独立计时器触发。

#### 🟡 技能 1: 召唤爪牙 (Summon)

触发条件： 拥有独立冷却计时器 (15秒)。当倒计时归零，且 BOSS 处于 Idle 时触发。

动作： BOSS 身体短暂停顿 1.0秒，剧烈收缩震动。

生成： 在 BOSS 左右下方 (-3, -1) 和 (3, -1) 对称生成 4 只 Rusher。

注意： 召唤不打断 BOSS 当前动作，只在 Idle 间隙插入。

#### 🟣 技能 2: 污秽喷吐 (Pollution)

触发条件： 仅在 Idle 状态下，每 4秒 发射一次。

弹道逻辑： 惰性追踪 (Inertial Homing)。发射一颗紫色光球，飞向玩家，但转向半径大。

拦截机制： 1 Hit Kill。激光触碰即爆炸。

命中惩罚： 扣除玩家 100 Shield。

### 4. 主动技能 (Active Skills - The 50/50 Mixup)

当 Idle 时间结束，BOSS 随机选择以下两个技能之一。

#### 🔴 技能 A: 野蛮冲撞 (Savage Charge)

类型： 快招 / 反应测试

Phase 1: 预警 (Telegraph) - [1.0s]

视觉： 全身高频红光闪烁，身体后缩。

听觉： 尖锐啸叫 (急促)。

眼睛： 睁开 (弱点暴露)。

玩家对策： 准备瞬间打断。

Phase 2: 冲锋 (Dash)

动作： 瞬间高速冲向塔。

Phase 3: 结算

打断成功： 在 Phase 1/2 被 Impact Lv.5 命中核心 -> BOSS 眩晕。

打断失败： 撞塔 -> 玩家扣血 -> BOSS 弹回。

免疫： 免疫冰冻。可被强击打断。

#### 🟣 技能 B: 重力碾压 (Gravity Press)

类型： 慢招 / 物理角力 / 骑脸惊吓

Phase 1: 突进 (Jump Scare) - [0.5s]

动作： 瞬移/极速 冲到塔前 1米处急刹车。无伤害。

Phase 2: 施压 (The Glare) - [1.5s]

视觉： 悬停不动，尾焰喷射，颜色转深紫/深红。

听觉： 沉闷引擎声 (轰鸣)。

眼睛： 缓缓睁大 (弱点暴露)。

Phase 3: 碾压 (The Crush)

物理： 持续施加向下的力。

玩家对策： 持续射击核心，施加向上的推力。

Phase 4: 结算

推回去了： BOSS Y轴 > 3.5 -> BOSS 眩晕。

没推住： 撞塔 -> 玩家扣血 -> BOSS 弹回。

免疫： 完全免疫眩晕/打断。免疫定身（但冰冻可减弱引擎推力）。

### 5. 通用状态 (Common States)

#### 🟡 State: Stun (僵直/奖励时间)

触发： 冲撞被打断 OR 碾压被推回。

时长： 3.0 秒。

表现： BOSS 颜色灰暗，停止一切动作，垂头丧气。

眼睛： 保持睁开 (最大化玩家输出)。

结束后： 返回 Spawn (飞回上方) 或直接 Idle。

#### ☠️ State: Low HP Enrage (低血量狂暴)

触发条件： HP < 30%。

视觉变化： 身体常驻淡淡的红光 (Emission)，BGM 变快。

数值变化：

Idle 时间缩短： 改为 1.5s ~ 2.5s (攻击频率加快)。

召唤冷却缩短： 改为 10s。

碾压引擎增强： PressForce 增加 20% (更难推回)。

#### 2. 关于“闭眼”的视觉实现：缩放 vs 换图？

对于一个 Synthwave/机械风格 的 BOSS，你完全不需要专门画一张“闭眼”的图片。

✅ 推荐方案：修改 Y 轴缩放 (Scale Y) + 调整亮度 (Emission)

这种做法会让 BOSS 看起来像是有“机械眼睑”或“光圈收缩”，非常符合你的美术风格，而且用代码（DOTween）就能实现，极其丝滑。

##### 具体做法：

A. 变形 (Transform):

睁眼： Scale.y = 1.0 (圆形/原本形状)

闭眼： Scale.y = 0.1 (变成一条细缝/横线)

注意： 不要缩放到 0，留一点点（0.05 或 0.1），看起来像是一个闭合的机械缝隙，更有质感。

B. 变色 (Color/Material):

这也是关键！单纯压扁可能看起来像个压扁的灯泡。

睁眼： 颜色 = 高亮红/紫 (Intensity 高)。

闭眼： 颜色 = 暗淡灰/黑 (Intensity 低)。

##### Q1: 最后一波 BOSS，是直接打 BOSS，还是刷新小怪和 BOSS 一起？

✅ 建议方案：清场 -> 警告 -> BOSS 登场 -> BOSS 召唤小怪

清场 (Clear): 第 11 波结束，屏幕上没有怪了。

警告 (Warning): 播放 UI_Wave_Start 警报声，屏幕变红。

登场 (Enter): BOSS 独自从屏幕上方降落（配合 Boss_Roar 吼叫）。

战斗 (Combat):

刚开始 3 秒是 1v1（让玩家看清 BOSS 的样子，建立压迫感）。

3 秒后，BOSS 使用 Summon (召唤技能)，自己招出 4 个小弟。

理由： 如果一开始就刷一堆怪和 BOSS 混在一起，场面太乱，玩家会忽略 BOSS 的登场演出。让 BOSS 自己招小弟，更有排面。

#### 3. BOSS：表现形式

✅ 肯定： 你的“大球+红色裂缝”设想非常完美。

视觉参考： 就像一个即将爆炸的黑暗星球，或者《魔兽世界》里的艾泽拉斯伤口。

制作方案：

Layer 1 (Fluid): 一个巨大的圆球（RT）。

Layer 2 (Crust - Order 20): 一个巨大的、圆形的黑色岩石外壳 Sprite，中间是镂空的。

Layer 3 (Glow - Order 19): 在外壳下面，放一张红色的发光图。

动态效果：

让黑色的外壳缓慢旋转。

让红色的光忽明忽暗（呼吸灯）。

裂缝机制： 你的激光必须打中红色的区域（裂缝）才算暴击，打中黑色的岩石算刮痧。这在美术上就非常直观了。

#### BOSS 眼睛动画：需要 Spine 吗？

❌ 坚决不要用 Spine。 ✅ 方案：Unity 原生动画 (Animator) 或 代码控制 (Tweening)。

理由：

杀鸡焉用牛刀： Spine 是为了解决复杂骨骼运动（如人跑步、挥刀）。你的 BOSS 只是一个大球，眼睛只是缩放或变色，引入 Spine 会增加巨大的工程量（导入、Runtime库、性能开销）。

网格扭曲没必要： 对于超休闲游戏，“缩放 (Scale)” 和 “变色 (Color)” 足以表达攻击前摇。

建议做法：

攻击前摇（蓄力）： 代码控制眼睛 Sprite 的 transform.localScale 逐渐变小（眯眼），颜色变红。

攻击瞬间： transform.localScale 瞬间变大（怒目圆睁），然后震动。

待机： 使用 Unity 自带的 Animation 录制一个简单的“上下浮动”或“缓慢眨眼”，Loop 播放即可。

#### BOSS 攻击方式：只是靠近就够了吗？

❌ 仅仅“靠近+召唤”太无聊了，且没有压迫感。 ✅ 方案：物理系的“野蛮冲撞” + “环境污染”。

结合你的物理流体玩法，建议 BOSS 的行为如下（按阶段）：

Phase 1 (缓慢压迫):

体积巨大，慢慢往下沉。

每隔 5 秒，身体抖动，甩出 3-5 个小粘液怪（召唤）。

Phase 2 (野蛮冲撞 - 关键技能):

预警： 眼睛闪红光，身体轻微后退（蓄力）。

冲锋： 突然给 BOSS 的 Rigidbody 一个向下的巨大冲量（Impulse）。

后果： 玩家必须立刻用激光（特别是带有“击退”技能的激光）死死顶住它。如果推力不够，BOSS 会直接撞碎护盾。

爽点： 这就是“对波”的感觉，看谁力气大。

Phase 3 (污染喷吐):

BOSS 向光棱塔喷出一团紫色污泥。如果不切碎它，污泥会附着在塔上，降低光棱塔的旋转速度（Debuff），持续 3 秒。

#### 激光如何打到内部弱点？（核心技术问题）

你问到点子上了。普通的 OnCollisionEnter 或 Raycast 确实会被最外层的碰撞体挡住。

✅ 解决方案：穿透检测 (Physics2D.BoxCastAll)

不要用“挡住即停”的逻辑，要用 “穿透激光” 的逻辑。

碰撞体设置 (Setup):

BOSS 外壳 (Body): 一个巨大的 CircleCollider2D，Tag = "BossArmor"。

BOSS 弱点 (WeakPoint): 一个较小的 CircleCollider2D（或多边形），放在裂缝位置，Tag = "BossCore"。注意： 两个 Collider 都要挂在 BOSS 上。

代码逻辑 (Code):

使用 Physics2D.BoxCastAll（如果是扇形检测，就是获取范围内所有的 Collider，而不是最近的那个）。

这个函数会返回一个数组 RaycastHit2D[] hits，里面包含了激光路径上的所有东西（外壳、核心、小怪）。

扇形检测同理： 你计算出激光的角度，然后判断 BOSS 核心的位置是否在这个角度范围内。如果是，直接判定命中核心，无视 外壳阻挡。

#### Rigidbody2D 和 Collider2D 是必须的吗？

✅ 必须的，缺一不可。

Collider2D (碰撞体):

没有它，激光打不到怪，怪也撞不到塔。

圆形 (Circle Collider 2D): 性能最好，最适合流体怪。

Rigidbody2D (刚体):

没有它，你的“击退 (AddForce)”技能就无法实现。

防止重叠的关键： 正如你所说，如果只有 Collider 没有 Rigidbody，Unity 默认是可以穿模的（或者那是 Trigger）。加上 Rigidbody 后，物理引擎会计算**“体积挤压”**，强行把重叠的怪推开。

对于 Metaballs 的好处：

Metaballs 最怕的就是“完全重叠”（因为那样看起来就像一个怪）。

Rigidbody 会让怪物们**“挨在一起但互不重叠”，就像一袋弹珠。这时候 Metaballs 的融合效果是最好看**的（边缘融合，核心独立）。

这也完美解决了“眼睛和铁板重叠”的问题，因为刚体保证了怪物之间有物理间隙。

⚠️ 设置小贴士：

把怪物的 Gravity Scale (重力) 设为 0（如果你是顶视图逻辑）。或者你需要自己写移动逻辑。

Linear Drag (阻力): 设大一点（比如 5~10）。这样被激光推开后，怪物会很快停下来，而不是像冰球一样滑出屏幕。我们要的是“粘稠”的手感。

Freeze Rotation Z: 勾选它。防止怪物像车轮一样乱滚，导致眼睛倒过来。

#### 资深策划总结

BOSS眼睛： 代码控制缩放/变红，别用 Spine。

BOSS攻击： 召唤 + 物理冲撞（考验击退力）。

穿透判定： 用 BoxCastAll 获取路径上所有物体，代码区分打中的是 Armor 还是 Core。

物理组件： 全员 Rigidbody2D + CircleCollider2D，阻力设大，锁定旋转。

这些设置能保证你的游戏既有漂亮的流体画面，又有扎实的物理碰撞手感。可以开工了！

### 核心系统：Boss 通用状态机架构 (Base Boss Controller)

为了最大化开发效率，所有章节的 Boss 均继承此底层架构，仅在具体表现和技能数值上做差异化替换。

[基础状态]

入场 (Intro)： 播放特定的 DOTween 缩放/降落动画，伴随屏幕震动和专属音效，期间无敌。

待机/寻敌 (Idle/Move)： 缓慢向光棱塔移动的默认状态。

[受击与异常状态 (Hit-Reactions)]

受击僵直 (Hit-Stun)： 受到单次高额伤害或破甲时，流体产生剧烈的反向扭曲，打断当前非霸体动作。

减速/冻结 (Slow/Freeze)： 受到极寒流派攻击时，移速和动画播放速度 (timeScale) 按比例下降。若被完全冻结，材质变为冰蓝，停止一切动作并丢失霸体。

[防御机制 (Defense Systems)]

甲壳机制 (Carapace)： 覆盖在流体表面的额外防护层。拥有独立血量或减伤逻辑，未破除前 Boss 免疫大部分异常状态。

霸体系统 (Super Armor)： 释放强力技能时身体泛红/发光。霸体期间免疫物理击退和受击僵直，但仍受伤害。

[阶段转换 (Phase Transition)]

狂暴触发 (Enrage)： 生命值跌破 30%（或 50%）时强制触发。清空所有 Debuff，体型变大，核心高频闪烁，技能释放频率与威力大幅提升。
