# 《光与朽》全章节怪物与Boss零件拼装说明书

> **美术制作最高准则**：
> 停止让AI直接生成完整怪物！将AI视为“零件素材加工厂”。
> 所有怪物 = **基础流体底座 (Shader控制) + 独立挂件贴图 (AI生成后抠图) + 独立眼睛贴图**。

---

## 🎨 全局公用流体底座 (RT图库)
为减少开发工作量并保证流体动画稳定，全游戏小怪共用以下 **4 种基础流体剪影**。章节的差异完全由“Shader颜色”和“挂件”决定。
1.  **形态 A【正圆球】**：基础形态，最容易做均匀缩放动画。
2.  **形态 B【圆角方块】**：极其厚重，适合做坦克肉盾。
3.  **形态 C【圆角倒三角形】**：前端收窄，适合做远程/冲锋怪。
4.  **形态 D【菱形】**：弹球怪。

## 🟢 第一章：深暗虚空 (Dark Void)
**材质基调**：纯黑柏油、高反光。
**专属零件库**：废旧钢管、生锈齿轮、白眼球。

### 【小怪拼装配方】
*   **流体黑油怪 (近战)** = `形态A[正圆球]` (黑色) + `眼睛[呆滞大白眼]` + `挂件[生锈钉子/钢管]`
*   **分裂怪 (待定)** = `形态D[圆角倒三角形]` (黑色) + `眼睛[多只挤在一起的小黄眼]`
*   *(注：若现有第一章怪物已符合“流体+挂件+眼睛”的分层逻辑，可直接保留；若不符合，建议用此配方快速重构以保证全游戏极其统一的美术管线。)*

### 【第一章 Boss：深暗虚空之眼】
*   **Boss 独占剪影**：**【巨大纯圆球】**
*   **视觉辨识度**：完美的黑暗几何体，压迫感来源于极度的纯粹。
*   **拼装配方**：
    *   **底层**：占据屏幕 1/3 的巨大纯黑流体圆球。
    *   **挂件层**：围绕圆球边缘，悬浮/镶嵌着巨大龟裂的黑色岩石外壳。
    *   **核心特效层**：中心透出暗红色的深渊裂缝光芒。
    *   **眼睛层**：正中心极其醒目的**“索伦之眼（巨大的红色狭缝独眼）”**。

## 🔥 第二章：熔岩火山 (Magma Void)
**材质基调**：暗红/亮橙色岩浆、沸腾气泡 Shader。
**专属零件库**：冷却的黑曜石块、熔岩裂纹片、发光黄眼。

### 【小怪拼装配方】
*   **熔岩分裂怪** = `形态C[锥形]` (#D34304) + `挂件[小黑曜石片]` + `眼睛[3只小黄眼]`
*   **熔岩自爆怪** = `形态A[正圆球]` (白炽亮橙色, 边缘Shader高频抖动) + `挂件[带有巨大裂纹的薄岩壳]` + `眼睛[单只狂躁黄瞳]`
*   **熔岩坦克怪** = `形态B[圆角方块]` (暗红色) + `挂件[极其巨大、厚重的拼接黑曜石大板]` (几乎盖住全身) + `眼睛[护目镜式的长条黄眼]`
*   **熔岩炮手怪** = `形态C[水滴形]` (前端极亮) + `挂件[一个空心的微型火山口贴图，挂在尖端]` + `眼睛[狙击手眯眯眼]`

### 【第二章 Boss：熔炉巨兽】
*   **Boss 独占剪影**：**【厚重六边形 / 巨型盾牌】**
*   **视觉辨识度**：绝对对称的工业几何感，与第一章的“圆”形成极强反差。没有拟人的嘴脸。
*   **拼装配方**：
    *   **底层**：六边形的巨大岩浆底盘。
    *   **挂件层 (装甲)**：左右完全对称的超大黑曜石厚板，像铠甲一样锁住底盘，正面带有巨大的冲撞盾角。
    *   **核心特效层**：正中心不是眼睛，而是一口**完美正圆形的高亮白炽熔炉（反应堆）**。
    *   **眼睛层**：装甲上方横向排列 3 只冷酷无情的黄眼。

这是一幅自上而下的二维矢量图形，描绘了一只巨大的火山首领怪兽。其轮廓是一个巨大的、锥形的火山，朝前延伸。主体部分覆盖着极其厚实、锯齿状、深灰色的玄武岩脊状物。在前方/顶部有一个巨大的火山口，喷出炽热的熔岩。在火山口下方，嵌在深色岩石中的是一对令人恐惧的恶魔眼睛，发出纯黄色的光芒。这是二维游戏素材、平面矢量艺术、极简风格、线条简洁、无阴影、白色背景、高质量、风格化、超休闲游戏风格。



## ❄️ 第三章：极寒虚空 (Glacial Void)
**材质基调**：深蓝/青色厚重流体、运动迟缓。
**专属零件库**：半透明折射冰块、完美六角雪花、幽蓝无机质细眼。

### 【小怪拼装配方】
*   **冰甲巨兽 (肉盾)** = `形态A[正圆球]` (深蓝色) + `挂件[几大块极其通透的锐利冰晶]` + `眼睛[幽蓝极小瞳孔]`
*   **极寒光环者 (辅助)** = `形态A[微型正圆球]` (浅蓝色) + `挂件[底部的巨大雪花几何法阵贴图]` + `眼睛[闭目祈祷眼]`
*   **霜冻施法者 (远程)** = `形态C[水滴形拉长/柱状]` (深青色) + `挂件[悬浮在头顶的发光冰法球]` + `眼睛[锐利倒三角眼]`

### 【第三章 Boss：极寒之核】
*   **Boss 独占剪影**：**【巨大锐利菱形 / 晶体要塞】**
*   **视觉辨识度**：抛弃流体外观，展现绝对零度下流体被彻底凝固的“冰封王座”形态，尖锐、刺骨。
*   **拼装配方**：
    *   **底层**：被压缩在菱形中心的深海蓝流体。
    *   **挂件层 (绝对防御)**：一个极其巨大、严丝合缝的**半透明菱形冰盾牢笼**，表面长满向外的冰刺。不发生任何软体形变。
    *   **核心特效层**：冰层深处透出刺眼的青色核心光晕。
    *   **眼睛层**：无常规生物眼，仅有一道散发绝对零度蓝光的几何裂缝。

### 💡 总结：AI 生图实操规范
1.  **永远不要**在提示词里写 `monster`, `creature`, `boss`。
2.  **只要零件**。去 Lovart / 即梦 跑图时，提示词必须是：`A single piece of dark obsidian rock, 2d game asset, pure white background`。
3.  **PS 组装**。抠出石头、抠出眼睛，扔进 Unity 或者 PS，贴在你的底座上。
4.  **效率飞升**。建立一套“挂件库”和“眼睛库”，三章的所有怪物只需半天即可拼装完毕！
