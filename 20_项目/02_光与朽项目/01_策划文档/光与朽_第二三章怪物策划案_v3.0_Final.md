## 一、核心设计原则

1. 角色位填充：每章必须覆盖 4 个战斗角色位（炮灰、快速威胁、肉盾、特殊机制），新机制怪优先接管角色位，而不是在换皮怪之外额外叠加。

2. 每章 7 个怪物：4 基础 + 2 精英 + 1 Boss。精简阵容，每个怪都有存在意义。

3. 视觉重做 ≠ 纯换皮：沿用旧机制的怪物（如熔岩坦克、冰霜史莱姆）必须在形状、装饰层、粒子特效上有显著视觉差异，而不是仅换颜色。

4. RT 流体换色：第一章黑紫色 → 第二章暗红色 → 第三章冰蓝色。全章统一切换。

5. Boss 继承架构：所有 Boss 继承 BaseBossController 基类，仅替换甲壳表现和主动技能函数。

6. 单一分裂限制：分裂子代不可再分裂，避免指数爆炸。

## 三、第二章：熔岩虚空 (Magma Void)

章节定位：高压战场，强调地形限制（岩浆斑）与目标优先级（必须先杀 Exploder）。

视觉基调：RT 流体统一暗红色。装饰件为橙黄色火星粒子、黑曜石碎片、岩浆裂纹。

背景：深红至暗橙渐变底色，霓虹橙/亮黄色透视网格，向上飘散的橙色几何火星粒子。

### 3.1 分裂岩浆怪 (Splitter) — 炮灰位

| 属性 | 值 / 描述 |
| --- | --- |
| EnemyType | Splitter (枚举值 7) |
| 角色位 | 炮灰 — 大量刷新，死后分裂制造割草数量感 |
| MaxHealth | 40（比 Slime 的 30 稍高，因为分裂前需要承受一定伤害） |
| MoveSpeed | 0.8（比 Slime 的 1.0 稍慢，体型更大移动更笨重） |
| Mass | 2.0（比 Slime 重，不易推开） |
| ContactDamage | 25 |
| 分裂机制 | HP 归零时，实例化分裂为 3 个小型岩浆怪（SplitterChild）。子代 HP=12, Speed=1.5, Mass=0.5, Damage=10。子代不可再分裂。分裂时向四周散开（AddForce 随机方向） |
| 分裂子代经验 | 每个子代提供标准 Slime 经验的 50%，防止经验通胀 |
| 体型 | 比 Slime 大约 1.3 倍（暗示「里面有东西」） |
| 视觉表现 | 暗红色流体，表面有隐约可见的裂缝纹理（暗示分裂）。形状偏椭圆/不规则（区别于 Slime 的正圆）。身体内部有微弱的橙色脉动光 |
| 眼睛 | 呆呆的圆眼（炮灰感），但比 Slime 的眼睛稍小、间距更宽 |
| 死亡特效 | 分裂瞬间：身体膨胀 → 炸开 → 3 个小球向四周弹射 + 橙色飞溅粒子 |

## 四、第三章：极寒虚空 (Glacial Void)

章节定位：极致生存，强调破防与控制应对。

视觉基调：RT 流体统一冰蓝色。装饰件为半透明冰晶碎片、六边形雪花、冰霜纹理。

背景：深海蓝至暗青渐变底色，冷青色/冰蓝色透视网格，缓慢下落的白色几何六边形雪花。
