# 《光与朽》新手引导系统设计文档 V2.0

> **文档状态**：待确认
> **更新说明**：V2.0 重构引导方案。战斗内（激光操控/大招）使用纯 Prefab 轻量指引；科技树/装备界面使用「SpotlightOverlay 挖孔遮罩 + FingerPointerWithRing Prefab」组合，防止玩家点击错误区域。引导参数统一由 `TutorialStepConfigSO` 配置文件驱动。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **最小干预** | 只在玩家第一次接触系统时介入，之后永不重复 |
| **情境触发** | 引导在最自然的时机出现，不中断游戏流程 |
| **分级遮罩** | 战斗内引导：纯 Prefab（不遮挡操作）；主界面系统引导：挖孔遮罩 + Prefab（防误操作）|
| **配置驱动** | 每步引导的 Prefab 路径、位置、挖孔参数均由 ScriptableObject 配置 |
| **单次存档** | 每个引导步骤完成后写入存档，重启游戏不再重复 |

---

## 二、引导流程总览

```
首次启动
  └─ 进入战斗场景
       ├─ [Step 1] 激光操控引导（手指+左右弧线箭头）→ 玩家拖动屏幕即结束
       └─ [Step 2] 大招引导（手指戳向大招按钮）→ 玩家点击大招即结束
           └─ 第一局结束 → 返回主界面
                └─ [Step 3] TipsPanel：「科技树系统已解锁！永久强化你的战力！」
                    └─ [Step 4] 科技树引导（挖孔遮罩 + 手指光圈，4步状态机）
                        └─ 通关第二章难度1 → 返回主界面
                             └─ [Step 5] TipsPanel：「装备系统已解锁！强化你的光棱塔！」
                                 └─ [Step 6] 装备引导（挖孔遮罩 + 手指光圈，3步状态机）
```

## 三、各步骤详细设计

### Step 1：战斗内 — 激光操控引导

| 属性 | 内容 |
|------|------|
| **触发条件** | 首次进入战斗场景，`hasViewedLaserTutorial == false` |
| **特效 Prefab** | `Effects/Tutorial/FingerSwipeGuide`（手指 + 左右弧线双向箭头） |
| **挂载位置** | 战斗 Canvas 屏幕中央偏下（激光控制区上方） |
| **结束条件** | 检测到玩家**手指在屏幕上滑动**（`Touch.deltaPosition.magnitude > 阈值`，约 10px），即实际拖动激光旋转 |
| **结束动作** | 销毁 Prefab，`hasViewedLaserTutorial = true` 写入存档 |
| **无遮罩** | 不使用挖孔遮罩，不阻挡操作 |

**特效 Prefab 规格（`FingerSwipeGuide`）**：
- 节点结构：`Root` → `FingerIcon`（带左右循环移动 Animator，±80px，1.2s）+ `ArrowLeft`（左弧线箭头）+ `ArrowRight`（右弧线箭头）
- 左右箭头随手指移动方向交替淡入淡出
- 不阻挡 Raycast，不影响游戏操作

---

### Step 2：战斗内 — 大招引导

| 属性 | 内容 |
|------|------|
| **触发条件** | 首次大招能量条充满（`OverloadManager` 能量达到100%），`hasViewedOverloadTutorial == false` |
| **特效 Prefab** | `Effects/Tutorial/FingerPointer`（手指向下戳动画 + 上下浮动） |
| **挂载位置** | 大招按钮正上方，偏移量由 `TutorialStepConfigSO.localPosition` 配置 |
| **结束条件** | 玩家点击大招按钮（监听 `OverloadManager.OnOverloadActivated`） |
| **结束动作** | 销毁 Prefab，`hasViewedOverloadTutorial = true` 写入存档 |
| **无遮罩** | 不使用挖孔遮罩 |

**特效 Prefab 规格（`FingerPointer`）**：
- 节点结构：`Root` → `FingerIcon`（向下指，上下浮动 Animator，±10px，0.8s）

---

### Step 3：主界面 — 科技树系统解锁提示

| 属性 | 内容 |
|------|------|
| **触发条件** | 首次返回主界面且 `IsTechTreeUnlocked == true`，`hasShownTechTreeUnlockTip == false` |
| **实现** | `TipsPanelController.Instance.ShowTip("科技树系统已解锁！永久强化你的战力！")` |
| **配合效果** | 科技树按钮红点（已有功能） |
| **存档标记** | `hasShownTechTreeUnlockTip = true` |

### Step 4：科技树引导（挖孔遮罩 + Prefab 组合，4步状态机）

> **设计理由**：进入科技树界面后若不加遮罩，玩家可能点击其他节点或返回，导致引导状态机混乱。使用挖孔遮罩将玩家操作限定在当前引导目标上。

**遮罩方案**：`TutorialSpotlightOverlay`（SDF Shader 圆角挖孔）+ `FingerPointerWithRing` Prefab 叠加显示。

| 步骤 | 触发事件 | 挖孔目标 | Prefab 位置偏移 | 提示文案 |
|------|----------|---------|----------------|---------|
| SelectNode | 进入科技树界面 | 第一个火力节点 | 节点右上方 (+60, +60) | "点击第一个火力节点，开始第一次科技强化。" |
| UpgradeNode | 节点详情面板弹出 | 升级按钮 | 按钮上方 (0, +50) | "点击升级按钮，强化这个节点。" |
| CloseDetail | 节点升级成功 | 关闭按钮 | 按钮上方 (0, +50) | "升级完成，关闭当前窗口。" |
| BackToMain | 详情面板关闭 | 返回按钮 | 按钮下方 (0, -50) | "点击返回按钮，回到主页面。" |

**完成条件**：BackToMain 步骤点击返回按钮。
**存档标记**：`hasViewedTechTreeTutorial = true`（已有）。

---

### Step 6：装备系统引导（挖孔遮罩 + Prefab 组合，3步状态机）

> **设计理由**：同科技树，防止玩家进入装备界面后点击错误区域（其他装备、功能按钮等）导致引导状态紊乱。

**遮罩方案**：`TutorialSpotlightOverlay` + `FingerPointerWithRing` Prefab。

| 步骤 | 触发事件 | 挖孔目标 | Prefab 位置偏移 | 提示文案 |
|------|----------|---------|----------------|---------|
| SelectItem | 进入装备界面 | 背包第一个装备格 | 格子右上方 (+50, +50) | "点击背包里的装备，查看详情。" |
| EquipItem | 装备详情面板弹出 | 装备按钮 | 按钮上方 (0, +50) | "点击装备按钮，穿上这件装备。" |
| BackToMain | 装备成功后 | 返回按钮 | 按钮下方 (0, -50) | "装备完成，点击返回回到主页面。" |

**装备成功时的额外 UI 反馈**（EquipItem → BackToMain 切换瞬间）：
- **Scale Punch（Q弹缩放）**：属性数字 Scale 1.0 → 1.2 → 1.0，时长 0.2s（`EquipmentPanel` 已有，无需新增）
- **Rolling Number（数字滚动）**：属性数字 0.5s 内从旧值滚动到新值（`EquipmentPanel` 已有，无需新增）

**完成条件**：BackToMain 步骤点击返回按钮。
**存档标记**：`hasViewedEquipmentTutorial = true`（已有）。

## 五、TutorialStepConfigSO 配置文件设计

> 参考 BeautyStacking 的 `TutorialConfigSO`，为光与朽定制。
> **创建方式**：右键 → Create → LightVsDecay → Tutorial Step Config
> **存放路径**：`Assets/Resources/Data/Tutorial/`

```
Data/Tutorial/
├── BattleLaserTutorial.asset
├── BattleOverloadTutorial.asset
├── TechTree_SelectNode.asset
├── TechTree_UpgradeNode.asset
├── TechTree_CloseDetail.asset
├── TechTree_BackToMain.asset
├── Equipment_SelectItem.asset
├── Equipment_EquipItem.asset
└── Equipment_BackToMain.asset
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `stepID` | string | 步骤唯一ID，如 `tech_select_node` |
| `prefabPath` | string | Resources 相对路径，如 `Effects/Tutorial/FingerPointerWithRing` |
| `parentPath` | string | 挂载父节点场景路径，如 `Canvas/TechTreePanel` |
| `localPosition` | Vector3 | Prefab 相对父节点的位置偏移 |
| `localScale` | Vector3 | 默认 (1,1,1) |
| `useSpotlightOverlay` | bool | 是否启用挖孔遮罩（战斗内为 false，系统界面引导为 true） |
| `holePadding` | Vector2 | 挖孔扩展边距（像素），默认 (24,24) |
| `cornerRadius` | float | 圆角半径（像素），默认 20 |
| `overlayMessage` | string | Spotlight 显示的文案（可与 Prefab 同时显示，也可留空） |

## 七、UI Scale Punch（Q弹缩放）统一说明

> 项目中 `EquipmentPanel.cs` 和 `HUDPanel.cs` 各有一套独立实现，逻辑相同。
> **V2.0 行动**：提取为通用工具类 `UIAnimationHelper.cs`（`LightVsDecay.UI` 命名空间）。

**提取后提供的接口**：

```csharp
// Q弹缩放（Scale Punch）
// rect: 目标 RectTransform
// punchScale: 放大系数（默认 1.2）
// duration: 总时长（默认 0.2s）
UIAnimationHelper.PlayScalePunch(RectTransform rect, float punchScale = 1.2f, float duration = 0.2f);

// 数字滚动（Rolling Number，整数版）
UIAnimationHelper.RollIntValue(TextMeshProUGUI text, int from, int to, float duration = 0.5f, string prefix = "", string suffix = "");

// 数字滚动（Rolling Number，浮点版）
UIAnimationHelper.RollFloatValue(TextMeshProUGUI text, float from, float to, float duration = 0.5f, string format = "F1", string prefix = "", string suffix = "");
```

**后续调用约定**：凡是需要 Q弹缩放 或 数字滚动 的 UI，直接调用上述接口，无需重复实现。
