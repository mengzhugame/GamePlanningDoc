## 一、建模方法说明

本文档所有数值**100%基于工程真实数据**，推演逻辑公开透明，主人可自行验证。

### 1.1 数据来源清单

| 数据类型 | 来源文件 | 关键字段 |
|---------|---------|---------|
| 玩家基础属性 | `GameSettings.asset` | baseDPS, tickRate, critRate, critMult, maxHull, maxShield |
| 怪物属性 | `MonsterData/*.asset` | maxHealth, moveSpeed, contactDamage, xpReward |
| 波次配置 | `LevelWave01_Normal.asset` | totalWaves=8, waveInterval=10, spawnGroups |
| 技能数值 | `SkillData/*.asset` | damageMultiplier, slowPercent, splitCount, levelData |
| 无人机奖励 | `DroneRewardConfig.asset` | gachaResults概率分布, supplyRewards, dealEntries |

### 1.2 核心计算公式

```
TTK（击杀时间） = 怪物有效HP ÷ 玩家有效DPS
有效HP = 基础HP × difficultyMultiplier
玩家期望DPS = baseDPS × (1 + critRate × (critMult - 1))
            = 1000 × (1 + 0.10 × 1.0) = 1100
```

## 三、第一核心结论：一章应该几波？

### 3.1 推导公式

```
总局时长 = (波次数N-1) × (每波内容时间 + 间隙时间) + Boss战时间 + 结算时间
         = (N-1) × (60s + 10s) + 40s + 15s
         = (N-1) × 70 + 55 秒
```

**参数来源**：
- 每波内容时间60s：来自LevelWave01_Normal实际spawnGroup时间轴（最后一组spawnTime约50-60s）
- 波次间隙10s：`waveInterval: 10`（含无人机选择交互时间）
- Boss战40s：目标值（见第四节推导）
- 结算15s：通关动画+奖励展示缓冲

### 3.2 各波次时长对照表

| 波次数N | 总时长(秒) | 总时长(分钟) | 评价 |
|--------|-----------|------------|-----|
| 6波 | 405s | 6.8分钟 | ✅ 可接受（偏轻度） |
| 7波 | 475s | 7.9分钟 | ✅ 偏长但可接受 |
| **8波** | **545s** | **9.1分钟** | ✅ **当前配置，合理** |
| 10波 | 685s | 11.4分钟 | ⚠️ 偏长（轻度玩家流失） |
| 12波 | 825s | 13.8分钟 | ❌ 过长（微信场景不适合） |

### 3.3 结论

**保留8波设计（含Boss波）是正确的。**

- `LevelWave01_Normal.asset`的`totalWaves=8`是经过实测后的合理配置
- `WaveConfig_12`的12波会导致单局**13.8分钟**，远超微信小游戏用户的耐心阈值
- **之前我错误地坚持用12波推演，这个建议是错的，已纠正**

## 四、第二核心结论：玩家成长曲线是否合理？

### 4.1 技能三选一DPS期望提升（精确量化）

从技能配置文件读取真实数值：

| 技能名 | 类型 | Lv1效果 | 等效DPS提升 | 备注 |
|--------|------|---------|------------|------|
| 功率超频 | 直接倍率 | ×1.2 | **+20%** | 最直接的数值技能 |
| 聚能透镜 | 直接倍率 | ×1.3 | **+30%** | 单体最强 |
| 致命爆击 | 暴击率+3%/级 | +3%暴击 | **+3%** | 积累型 |
| 广域透镜 | 激光宽+20% | ×1.2宽度 | **+12%** | 群怪密集时更高 |
| 极寒光束 | 减速40% | 减速40% | **+67%！** | 公式：1/(1-0.4)=1.67 |
| 分裂棱镜 | 副激光×2 | 各25%伤害 | **+30~50%** | 群怪场景 |
| 连锁反应 | 弹射×1 | 衰减20% | **+10~20%** | 视怪物密度 |

**极寒光束是数值最强的技能**，减速让怪物在射程内停留时间翻倍，等效DPS翻1.67倍。

**三选一综合期望DPS提升**：
```
前期（有强力技能可选）：约+22%/次
中期（核心技能已拿）：约+15%/次
全局平均：+18%/次
```

### 4.2 无人机补给期望DPS提升（精确量化）

从`DroneRewardConfig.asset`读取真实概率分布：

```
结果类型概率：
  正面属性(50%)：攻击+10%/+150，暴击+3%，宽+10%，长+10%
               → 平均等效DPS +8%
  大奖(15%)：  攻击+25%/+500，暴击+16%，宽+12%，长+20%
               → 平均等效DPS +20%
  负面/怪物增强(15%)：不选，但存在被迫削弱概率约5%
  金币(20%)：  不提升DPS

净期望 = 0.50×8% + 0.15×20% - 0.05×5% = 6.75%
```

**每次无人机补给的净DPS提升约+6.75%**

### 4.4 成长曲线诊断

**整体结论：LevelWave01_Normal的8波设计节奏良好，但有两处需要优化：**

**问题A（W1-W2压力偏高）**：
- W1进场DPS只有1100，但血池高达5万（清场需45秒）
- W2血池8万（清场41秒），新手连续两波高压容易劝退
- **根本原因**：W1有50只粘液（每只HP=1000），血池过大

**问题B（W4后半段节奏下滑）**：
- W5、W7已经是"轻松割草"级别（TTK<20s），而W6又回到高压
- 节奏应是平稳上升，而非剧烈振荡

## 五、具体数值修改建议

### 修改A：W1降低压力（新手引导波）

**原配置：** 粘液×50，总血池50,000
**问题：** TTK=45秒，新手第一波太难

**修改方案：**
```
W1第一组（spawnTime=0）：粘液 count: 15 → 8
W1第二组（spawnTime=20）：粘液 count: 20 → 12
W1第三组（spawnTime=40）：粘液 count: 15 → 10
修改后总血池：30,000，TTK≈27秒  ★★★☆☆ 合理压力
```

### 修改B：精英坦克HP过高 🔴P0

**原配置：** `Enemy_EliteTank.asset maxHealth: 40000`
**问题：** W5出现时有效HP=40000×1.3=52,000，玩家DPS≈6,400，单杀TTK=8.1秒  
单杀8秒×出现数量，同时群怪涌入，极易崩盘

**修改方案：**
```
Enemy_EliteTank.asset:
  maxHealth: 40000 → 18000
修改后有效HP=18000×1.3=23,400，TTK≈3.6秒  ✅ 有压力但不崩盘
```

### 修改C：精英弹球接触伤害过高 🔴P0

**原配置：** `Enemy_EliteDrifter.asset contactDamage: 750`
**问题：** 玩家总血池3000，接触4次必死。W7首次出现时没有足够预警，容易突然死亡

**修改方案：**
```
Enemy_EliteDrifter.asset:
  contactDamage: 750 → 250
修改后碰12次才死，给玩家足够的反应时间，但仍然危险
```

### 修改D：Boss血量调整

**原配置：** `bossHealth: 500000`，`difficultyMultiplier: 1.5`
**有效HP：** 750,000，TTK = 750,000 / 30,032 = **25秒** ✅

**结论：Boss血量当前设置合理！** 无需修改。
（之前V1.0文档建议降到30万是基于错误的12波DPS数据，已纠正）
