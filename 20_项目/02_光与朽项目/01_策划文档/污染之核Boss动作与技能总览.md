## Boss "污染之核" 动作与技能总览

### 📊 状态机结构

BossState 枚举:

├── Spawn    → 入场

├── Idle     → 待机/游走（含被动：污秽喷吐）

├── Summon   → 召唤爪牙（被动技能）

├── Charge   → 野蛮冲撞（主动技能A - 快招）

├── Press    → 重力碾压（主动技能B - 慢招/角力）

└── Stun     → 僵直/虚弱

### 🎬 各状态动画详细描述

#### 1. Spawn（入场）

| 阶段 | 动画表现 |
| --- | --- |
| 移动 | Boss 从屏幕顶部（Y=10）缓慢下沉到战斗锚点（Y=3），使用 EaseOutQuad 缓动，持续约 2.5 秒 |
| 眼睛 | 完全闭合（ScaleY 压缩到 0.1，颜色暗淡） |
| 红光特效 | 关闭（redBodyEffect.SetActive(false)） |
| 到达后 | 播放"咆哮"，触发屏幕震动（强度 0.5，持续 1 秒） |
| 过渡 | 震动结束后进入 Idle 状态 |

#### 2. Idle（待机/游走）

| 阶段 | 动画表现 |
| --- | --- |
| 眼睛 | 闭合状态（防御态） |
| 红光特效 | 关闭 |
| 移动 | 在水平范围内（屏幕 80% 宽度）左右缓慢游走，速度约 1.5 单位/秒 |
| 被动技能 | 每隔 4 秒发射一枚 污秽投射物（惰性追踪弹） |
| 持续时间 | 根据血量动态调整（血量越低持续越短，约 2-4 秒） |
| 退出条件 | ① 召唤冷却完成 → 进入 Summon ② 时间到 → 50%概率 Charge / 50%概率 Press |

污秽投射物动画：

从 Boss 身体下方 0.5 单位处生成

紫色拖尾粒子效果，缓慢追踪玩家塔

命中护盾/塔时播放爆炸粒子，造成 100 点护盾伤害

#### 3. Summon（召唤爪牙） - 被动技能

| 阶段 | 动画表现 |
| --- | --- |
| 触发条件 | 召唤冷却完成（15秒，狂暴时10秒），可打断 Idle |
| 眼睛 | 短暂眨眼（Blink 0.75秒，快速睁开再闭合，表示弱点窗口） |
| 身体 | 高频震动（强度 0.1，频率 30Hz），持续约 1 秒 |
| 召唤效果 | 在 Boss 左右两侧各生成 2 只 Rusher（钳形攻势） |
| 左侧位置 | Boss 位置 + (-3, -1) |
| 右侧位置 | Boss 位置 + (+3, -1) |
| 过渡 | 召唤完成后返回 Idle，重置召唤冷却 |

#### 4. Charge（野蛮冲撞） - 主动技能A【快招/反应测试】

| 阶段 | 时长 | 动画表现 |
| --- | --- | --- |
| Phase 1: Telegraph（蓄力预警） | 1.0秒 | 眼睛猛然睁开 + 全身红光特效亮起 + 身体向后缩 0.5 单位（像拉弓） |
| 眼睛状态 | - | 完全睁开，弱点暴露，可被攻击 |
| 可打断窗口 | - | Impact Lv.5 或 大招 可打断，触发 "INTERRUPTED!" 飘字 |
| Phase 2: Dash（冲锋） | 0.3秒 | 极速 Lerp 移动冲向玩家塔（Y=-10），使用 EaseOutQuad |
| 连体Buff加速 | - | 场上 Rusher 数量越多，冲锋速度越快 |
| 命中玩家 | - | 造成 300 伤害 + 屏幕震动（强度 0.8，向下冲击感） |
| 弹回 | 0.5秒 | 弹回战斗锚点（Y=3），眼睛闭合，短暂停顿 1 秒后返回 Idle |

被打断动画：

显示 "INTERRUPTED!" 黄色飘字

直接进入 Stun 僵直状态

#### 5. Press（重力碾压） - 主动技能B【慢招/物理角力】

这是 Boss 最核心的角力技能，分为 3 个阶段：

| 阶段 | 时长 | 动画表现 |
| --- | --- | --- |
| Phase 1: Jump Scare（突进贴脸） | 0.5秒 | 眼睛闭合（黑脸），极速冲到塔前悬停位置（Y=-5），使用 EaseOutExpo（快冲+急刹车） |
| Phase 2: The Glare（施压） | 1.5秒 | 悬停不动，眼睛缓缓睁开（从 ScaleY=0.1 渐变到 1.0），红光特效亮起，制造压迫感 |
| Phase 3: Crushing（角力） | 最长15秒 | 物理对抗！Boss 持续向下施加力（100 力），玩家用激光向上推 |

Phase 3 角力详细动画：

眼睛：完全睁开，持续暴露弱点

红光：持续亮起

物理：使用 Rigidbody2D 真实物理，Boss 和激光推力实时对抗

摩擦伤害：当玩家持续抵抗超过阈值时间，触发摩擦伤害事件

角力结果动画：

| 结果 | 条件 | 动画表现 |
| --- | --- | --- |
| 玩家胜利 | Boss 被推到 Y > 3.5（安全线） | 显示 "STOPPED!" 绿色飘字 + 屏幕震动 + 进入 Stun |
| 玩家失败 | Boss 压到 Y < -10（塔位置） | 造成 300 伤害 + 屏幕冲击震动 + Boss 弹回 |
| Boss疲劳 | 玩家高DPS触发过载 | 显示 "EXHAUSTED!" 飘字 + Boss 主动撤退 |
| 超时 | 15秒未分胜负 | Boss 弹回锚点 |

弹回动画：

0.5 秒 Lerp 返回战斗锚点（Y=3）

眼睛闭合

红光特效关闭

短暂停顿后返回 Idle

#### 6. Stun（僵直/虚弱）

| 阶段 | 动画表现 |
| --- | --- |
| 触发条件 | ① Charge 被打断 ② Press 被推回安全线 ③ 污秽球反弹击中 Boss |
| 眼睛 | 保持睁开（奖励攻击窗口！） |
| 身体颜色 | 所有 SpriteRenderer 变暗（乘以 0.5 灰度） |
| 持续时间 | 默认 3 秒，短僵直 1.5 秒 |
| 飘字 | 根据触发原因显示 "INTERRUPTED!" / "STOPPED!" / "OVERLOAD!" |
| 过渡 | 僵直结束后眼睛闭合，颜色恢复，返回 Idle |

### 🎨 视觉特效汇总

| 特效名称 | 触发时机 | 表现 |
| --- | --- | --- |
| redBodyEffect（红光特效） | Charge Phase1、Press Phase2/3 | 全身红色发光，表示危险/攻击态 |
| 眼睛睁开 | 攻击预警、角力期间 | ScaleY 从 0.1→1.0，颜色变亮 |
| 眼睛闭合 | 防御态、移动态 | ScaleY 压缩到 0.1，颜色暗淡 |
| 眨眼（Blink） | Summon、发射污秽球 | 快速睁开→保持→快速闭合，表示短暂弱点窗口 |
| 身体震动 | Summon、入场咆哮 | DOShakePosition 高频抖动 |
| 身体变暗 | Stun 僵直 | 所有 Sprite 颜色 × 0.5 灰度 |
