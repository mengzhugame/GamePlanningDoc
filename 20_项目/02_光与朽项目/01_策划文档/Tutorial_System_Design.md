# 《光与朽》新手引导系统 (Tutorial System) 策划文档

> **文档状态**: V1.0 (2026-03-23)
> **编写人**: 小龙儿主脑
> **游戏类型**: 割草塔防 + Roguelike

## 一、 设计理念 (Design Philosophy)

《光与朽》作为一款主打“解压”、“爽快”的轻量化小游戏，新手引导必须遵循**“弱干预、渐进式、不打断心流”**的原则。
绝对**不要**使用传统的“全屏遮罩+强制指引手势点击”的死板教学（这极易引发玩家的逆反心理和早期流失）。我们要采用**“情境触发式” (Context-Sensitive)** 的无缝引导。

---

## 二、 局内渐进式引导 (第一局游戏)

玩家第一次进入游戏（Chapter 1-1）时，按以下条件逐步触发提示。

### 阶段 1：核心操作教学 (游戏开始 0~3 秒)
*   **触发条件**：进入第一波，第一只怪物刷出时。
*   **表现形式**：
    *   在屏幕中下方（不遮挡主战场）出现一个半透明的手势滑动动画。
    *   配合一行简洁的文字提示：`“滑动屏幕，控制激光扫射！”`
*   **解除条件**：检测到玩家产生了拖拽屏幕的 Input 行为（持续时间 > 0.5秒），手势动画与文字立刻淡出消失。

### 阶段 2：Roguelike 升级与羁绊教学 (玩家第一次升到2级)
*   **触发条件**：玩家吃够经验，第一次触发“三选一”升级面板时。
*   **表现形式**：
    *   在原本的“三选一”UI上方，弹出一行高亮文字：`“选择同颜色的晶体，可触发强力流派羁绊！”`
    *   (可选) 稍微高亮显示三个选项右上角的颜色/流派 Icon。
*   **解除条件**：玩家点击任意选项后，提示随面板一起消失。此后升级不再显示该文字。

### 阶段 3：超载大招教学 (第一次 Overload 充能满 100%)
*   **触发条件**：玩家击杀怪物，第一次将大招能量槽充满时。
*   **表现形式**：
    *   `Time.timeScale = 0.1f` (触发极短暂的子弹时间，持续约1秒，引起玩家注意)。
    *   大招按钮开始**剧烈闪烁发光**，并在按钮旁弹出文字框：`“能量已满！点击释放【超载模式】！”`
*   **解除条件**：玩家点击大招按钮后，释放全屏特效，文字消失。（如果玩家一直不点，文字在闪烁 5 秒后自动淡出，不强迫玩家必须在此时使用）。

### 阶段 4：濒死抢救与 IAA 变现预埋 (基地血量首次 < 20%)
*   **触发条件**：玩家基地血量首次跌破警告线（屏幕边缘泛红报警）。
*   **表现形式**：
    *   屏幕上方弹出红色警告文字：`“警告！核心受损严重！”` (不强制中断操作，仅渲染高压气氛)。
*   *(注：第一局通常是死在第 5 波的精英怪手上，死亡结算时将自然引入“看广告复活”的机制。)*

## 三、 局外养成引导 (第一次战斗结算后)

当玩家结束了第一局游戏（无论是通关还是死亡），进入结算界面并返回主菜单。

### 阶段 1：结算资源认知
*   **触发条件**：第一次弹出战斗结算面板。
*   **表现形式**：
    *   掉落的“科技点/图纸”飞入玩家的资产栏（配合清脆的收金币音效）。
    *   显示文字：`“战斗结算：获得了局外研发资源！”`

### 阶段 2：科技树升级引导 (返回主界面后)
*   **触发条件**：第一局结束后，玩家回到主界面，且拥有足够的资源点亮第一个科技节点。
*   **表现形式**：
    *   主界面的【科技树】按钮出现一个引人注目的“小红点”或“高亮呼吸边框”。
    *   弹出提示文字：`“基地需要强化，前往科技树升级防线！”`
    *   进入科技树界面后，唯一能点亮的起始节点高亮，并提示：`“消耗资源解锁基础属性，下一次你会更强！”`
*   **解除条件**：玩家成功点亮第一个科技节点后，所有新手引导正式宣告全部结束。

## 四、 开发实现要点 (Unity 落地方案)

1.  **引导状态持久化 (PlayerPrefs / SaveData)**：
    *   建立枚举或布尔值标识位（如 `HasDoneMoveTutorial`, `HasDoneUpgradeTutorial`, `HasDoneTechTutorial`）。
    *   一旦触发并完成，立刻写入本地存档。确保玩家重登游戏不会反复看到这些基础教学。
2.  **UI 预制体 (Prefab) 设计**：
    *   做一个通用的 `TutorialHintUI` Prefab（包含文字框、简单的打字机效果、渐入渐出动画）。
    *   在游戏控制器 (`GameController` 或 `TutorialManager`) 中监听对应的事件（如 `OnPlayerLevelUp`, `OnUltimateReady`）来动态实例化这个提示 UI。
3.  **防卡死机制**：
    *   引导 UI 的层级 (Sorting Order) 必须极高，但**绝对不能拦截玩家射线 (Raycast Target = false)**（除了科技树强制点击的那一下），以免 Bug 导致屏幕无法操作。
