# 《光与朽》· 伤害飘字颜色设计规范

**版本**：V1.0
**日期**：2026-04-01
**对应代码**：`FloatingTextType.cs` / `FloatingTextConfig.cs` / `FloatingTextManager.cs` / `EnemyBlob.cs` / `ChainLightningManager.cs`

---

## 一、设计原则

1. **颜色即语义**：玩家一眼扫过飘字，颜色直接告诉他"是什么打的"。
2. **克制数量**：敌方受击飘字只用 **4 种主色**（含现有白色、红色），不超过 5 种，避免视觉噪音。
3. **大小即重要性**：伤害越高/越特殊，字越大，动画越强。颜色和大小双重编码，保证可读性。
4. **一致性**：同一游戏语境的元素用同一色系（冰系全用蓝系，雷电系全用黄系）。

---

## 二、现有伤害来源梳理

| 来源 | 触发方式 | `DamageSource` | 现状 |
|---|---|---|---|
| 主激光普通段 | 激光扫射 | `MainLaser` | 白色 Normal / 红色 Crit |
| 副激光（分裂/反射）| 技能效果 | `SubLaser` | 同上（复用）|
| 碎冰伤害（Shatter Lv5）| 打冻结敌人额外爆发 | `MainLaser` + `isShatter=true` | **亮蓝 Shatter** ✓ |
| 碎冰+暴击 | 同上 | — | **冰蓝 ShatterCrit** ✓ |
| 处决（Execute Lv5）| 打冻结小血量敌人 | — | **冰蓝+紫描边 Execution** ✓ |
| 连锁闪电（Chain） | 闪电弹跳 | `Chain` | **❌ 当前复用白色，无区分** |
| 聚焦爆炸（Focus Lv5）| 击杀触发 AoE | `Explosion` | **❌ 当前复用白色/红色，无区分** |
| 漏洞扩散（Shatter Lv5 AoE）| 击杀时扩散范围爆炸 | — | 同上 |

> **冰系普通激光伤害**（极寒光束命中但未触发 Shatter）：
> - 本质是普通激光伤害，只是附带减速效果
> - **结论：不需要单独蓝色。** 减速是控制效果而非独立伤害类型，用白色/红色即可
> - 一旦 Shatter 触发才显示蓝色，反而强化了"触发特效"的反馈感

## 三、伤害飘字颜色方案（最终）

共 **5 种敌方受击颜色**，从最常见到最少见排列：

### 3.1 完整对照表

| 类型 | 颜色 | Hex | 适用场景 | 大小 | 状态 |
|---|---|---|---|---|---|
| **Normal** | 纯白 | `#FFFFFF` | 普通激光命中 | 标准（1×）| 现有 ✓ |
| **Crit** | 霓虹红 | `#FF0055` | 任何来源暴击 | 大（1.5×）| 现有 ✓ |
| **Shatter** | 极光蓝 | `#00BFFF` | 碎冰伤害爆发 | 中大（1.15×）| 现有 ✓ |
| **Chain** | 电弧黄 | `#FFD700` | 连锁闪电每跳伤害 | 小中（0.9×）| **新增** |
| **Explosion** | 烈焰橙 | `#FF6A00` | 聚焦爆炸/漏洞扩散 AoE | 中（1.0×）| **新增** |

### 3.2 颜色选择理由

```
白色  →  激光：中性、科技感，大量出现需低调
红色  →  暴击：全游戏通用的"高伤害警报"，玩家天然理解
蓝色  →  冰：颜色即元素，极光蓝温度感强
黄色  →  闪电：物理世界联想最直接（雷 = 黄）
橙色  →  爆炸：火/爆炸感，与游戏熔岩主题协调，且与红色暴击区分明显
```

> **不添加的颜色**：
> - 冰系普通攻击蓝色 → 减速不是伤害类型，不需要颜色
> - 地形伤害（熔浆液）→ 已禁用飘字（`disableHitFlash = true`）
> - 副激光分裂 → 和主激光一样性质，复用白/红即可

## 四、各类型详细样式规格

### Chain（连锁闪电）
- **颜色**：电弧黄 `#FFD700`，描边深金 `#806000`
- **大小**：比普通小 10%（`sizeMultiplier = 0.9`），闪电是"副效果"，不该抢主激光的视觉
- **动画**：快速出现快速消失（`duration = 0.5s`），闪电本身是瞬间感，停留太久反而拖沓
- **缩放**：小幅弹出（`peakScale = 1.15`），轻微电击感

### Explosion（爆炸/AoE）
- **颜色**：烈焰橙 `#FF6A00`，描边暗橙 `#7A3000`
- **大小**：标准大小（`sizeMultiplier = 1.0`），与普通相当
- **动画**：中速扩散（`duration = 0.7s`），比闪电慢，有"爆炸扩散"的开阔感
- **缩放**：中幅弹出（`peakScale = 1.3`），爆炸冲击感

## 五、调用关系变更

### EnemyBlob.TakeDamage 现状
```
isShatter=true  → ShowShatterDamage → Shatter/ShatterCrit
否则            → ShowDamage        → Normal/Crit
```

### 修改后
```
isShatter=true               → ShowShatterDamage → Shatter/ShatterCrit
damageSource=Chain           → ShowChainDamage   → Chain（新增方法）
damageSource=Explosion       → ShowExplosionDamage → Explosion（新增方法）
其余                         → ShowDamage        → Normal/Crit
```

### 优先级（冲突时）
当同时满足多个条件（如 Chain 打冻结怪触发 Shatter），优先级：
`Shatter/ShatterCrit > Crit > Chain > Explosion > Normal`

实现方式：`isShatter` 判断最先，`damageSource` 其次，暴击最后叠加颜色不变（Shatter/Chain/Explosion 暴击时直接升级为 Crit 样式）。

## 七、视觉效果快速参考（设计师用）

```
普通激光命中     →  白色小字，快速飘走
暴击             →  红色大字，弹跳消失
冰晶爆破         →  蓝色中字，轻微弹出
连锁闪电每跳     →  黄色小字，快速闪现消失（轻盈）
爆炸AOE          →  橙色中字，扩散感消失
处决             →  冰蓝大字+紫描边，强调感
```

**飘字节奏感**：同一帧大量不同颜色飘字同时出现时（如连锁闪电弹 8 次），黄色小字密集出现
反而有"电弧连绵"的弧线感，视觉上优于统一白色。
