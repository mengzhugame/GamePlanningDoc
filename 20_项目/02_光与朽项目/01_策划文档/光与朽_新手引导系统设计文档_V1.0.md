# 《光与朽》新手引导系统设计文档 V1.0

> **文档状态**：待实装
> **核心原则**：新手引导的本质不是内容堆砌，而是对玩家学习节奏的精准把控。让玩家在每一步都清晰感受到"我能掌控这个游戏"，在合适的认知曲线上建立起持续游玩的信心。

---

## 一、设计目标与原则

### 1.1 核心目标

| 目标         | 说明                                  |
| ---------- | ----------------------------------- |
| **零门槛上手**  | 玩家无需阅读任何文字说明，靠引导动作本身学会操作            |
| **渐进认知**   | 每个系统在玩家有足够游戏经验后再解锁，不提前过载            |
| **断点续引导**  | 玩家任何时候退出游戏，下次进入后从未完成的引导步骤继续，不遗漏     |
| **保留探索乐趣** | 技能流派、装备组合等核心深度内容不强制引导，用视觉语言辅助而非代替决策 |

### 1.2 系统解锁节奏

```
首次启动
    ↓
战场引导（激光·技能·大招·无人机）
    ↓
第一局结束（胜/败）→ 解锁科技树
    ↓
科技树引导
    ↓
通关第二章·难度1 → 解锁装备系统
    ↓
装备系统引导
```

**设计依据**：
- **科技树先于装备解锁**：第一局结束时玩家需要"变强的理由"，科技树提供永久强化，直接回答"死亡有意义"；装备系统需要积累道具才有体验，过早解锁反而是空壳
- **装备在第二章后解锁**：此时玩家已有多局经验和足够装备积累，能充分体验系统深度

## 二、引导进度追踪系统

### 2.1 标记字段（新增至 MetaData 类）

```csharp
// 首次启动：跳过主菜单标记
// 第一次进入战斗后立即置 false，仅控制"是否跳过主菜单"，与引导完成度无关
public bool isFirstPlay = true;

// 战场引导——各步骤独立记录
// false = 未完成，下次满足触发条件时自动继续触发
public bool hasSeenLaserTutorial    = false;  // 击杀第1个敌人后置 true
public bool hasSeenSkillTutorial    = false;  // 完成第1次技能选择后置 true
public bool hasSeenOverloadTutorial = false;  // 点击大招按钮后置 true
public bool hasSeenDroneTutorial    = false;  // 击中任意无人机后置 true

// 系统界面引导——首次打开对应面板时触发
public bool hasViewedTechTreeTutorial  = false;
public bool hasViewedEquipmentTutorial = false;
```

### 2.2 断点续引导规则

| 引导步骤 | 中途退出后的行为 |
|---------|---------------|
| Step1 激光 | 下次进入战斗，W1 开始时重新触发 |
| Step2 技能三选一 | 下次升级时重新触发 |
| Step3 大招 | 下次大招就绪时重新触发 |
| Step4 无人机 | 下次波次间隙重新触发 |
| 科技树引导 | 下次点击科技树按钮时重新触发（与场次无关）|
| 装备系统引导 | 下次点击装备按钮时重新触发（与场次无关）|

## 三、阶段一：首次启动

**触发条件**：`MetaData.isFirstPlay == true`

**行为**：
- 跳过主菜单，直接加载**第一章·难度1**战斗场景
- 进入场景后将 `isFirstPlay` 置为 `false`（此后永久走主菜单）

**设计意图**：消除首次体验的摩擦——玩家从微信点击游戏到看见激光射击，中间不需要任何额外操作。

---

## 四、阶段二：战场引导（第一局内）

> 战场引导共 4 步，各步骤独立触发与记录，不互相依赖。

---

### Step 1 — 激光操控引导

**触发**：`OnGameStart` 后约 1 秒（首批怪物出现，但尚未接触基地）
**前提**：`hasSeenLaserTutorial == false`

**UI 表现**：

```
        ┌─────────────────────────────────┐
        │  ← 左右拖动旋转激光，消灭入侵者！  │
        └─────────────────────────────────┘
                       👆
                  （循环动画）
               ←  手指左右滑动  →
```

- 屏幕中央显示手指图标 + 左右弧形箭头循环动画
- 文字提示："左右拖动旋转激光，消灭入侵者！"
- 轻微半透明遮罩压暗背景，突出引导元素
- **不暂停游戏**：怪物继续正常移动，保持紧张感

**消失条件**：
1. 玩家成功击杀第 1 个敌人（优先触发）
2. 或 8 秒后自动消失

**完成标记**：`hasSeenLaserTutorial = true`

---

### Step 2 — 升级·技能三选一引导

**触发**：`GameEvents.OnLevelUp` 首次触发，`SkillChooseOnePanel` 打开后
**前提**：`hasSeenSkillTutorial == false`

#### 2a. 一次性横幅提示（仅首次）

**控池规则**：确保三张技能牌分别来自三个不同流派
- 🔴 暴力流（Focus/Power 系）
- 🔵 冰冻流（Frost 系）
- 🟣 分裂流（Chain/Prism 系）

**UI 表现**：
```
┌────────────────────────────────────────────────────┐
│  💡 同流派技能搭配效果更强！选择一个流派开始构筑！      │  ← 3秒后自动消失
└────────────────────────────────────────────────────┘

  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
  │ 🔴 暴力流    │  │ 🔵 冰冻流    │  │ 🟣 分裂流    │
  │  [技能名称]  │  │  [技能名称]  │  │  [技能名称]  │
  │  [技能描述]  │  │  [技能描述]  │  │  [技能描述]  │
  └──────────────┘  └──────────────┘  └──────────────┘
```

**完成标记**：`hasSeenSkillTutorial = true`（玩家选择任意技能后置true）

#### 2b. 永久流派 UI（常驻，非引导专属）

> 以下 UI 改动永久生效，不区分新手与老玩家。

**流派色标签**：每张技能卡左上角显示流派图标与颜色边框
| 流派 | 颜色 | 标签 |
|------|------|------|
| 暴力流 | 🔴 红色 | 🔴 暴力 |
| 冰冻流 | 🔵 蓝色 | 🔵 冰冻 |
| 分裂流 | 🟣 紫色 | 🟣 分裂 |
| 通用 | ⚪ 灰色 | ⚪ 通用 |

**协同发光**：当玩家已持有某流派 ≥1 个技能时，三选一中同流派技能卡自动触发：
- 边框金色流光高亮
- 卡片右上角显示小字："▲ 协同加成"

**设计意图**：不强制流派选择，用视觉语言让玩家自己发现"同色更强"的规律，保留探索乐趣。

---

### Step 3 — 大招引导

**触发**：`OverloadManager` 状态首次变为 `Ready`（游戏开始约 60 秒后）
**前提**：`hasSeenOverloadTutorial == false`

**UI 表现**：
- 大招按钮持续脉冲发光（金色光圈向外扩散动画，循环）
- 按钮上方显示文字气泡："大招蓄满！点击释放超载模式！"

**消失条件**：玩家点击大招按钮释放后，气泡消失，按钮恢复正常状态

**完成标记**：`hasSeenOverloadTutorial = true`

---

### Step 4 — 无人机引导

**触发**：第一次 `GameEvents.OnWaveComplete` 后，无人机出现时
**前提**：`hasSeenDroneTutorial == false`

**UI 表现（仅首次）**：

```
         ❤️             ⚡            🔄
       血量恢复        随机属性        增强属性
         ↓               ↓               ↓
      [无人机]        [无人机]        [无人机]

  ┌──────────────────────────────────────────┐
  │  击落无人机获取奖励，选择你需要的！          │  ← 顶部提示，3秒后消失
  └──────────────────────────────────────────┘
```

每架无人机上方显示浮动说明卡：
| 位置 | 图标 | 标签 | 说明 |
|------|------|------|------|
| 左 | ❤️ | 血量恢复 | 恢复基地血量 |
| 中 | ⚡ | 随机属性 | 随机获得 1 项属性强化 |
| 右 | 🔄 | 增强属性 | 消耗血量换取更强的属性强化 |

**消失条件**：玩家击中任意一架无人机后，三张说明卡全部消失

**后续波次（常态）**：不再显示说明卡，仅在无人机上方保留小图标（❤️ / ⚡ / 🔄）作为永久提示

**完成标记**：`hasSeenDroneTutorial = true`

## 六、阶段四：科技树引导

**触发**：`hasViewedTechTreeTutorial == false` + 玩家点击科技树按钮
**解锁前提**：第一局结束（`SystemUnlockManager` 已记录解锁）

### Step 1 — 分支介绍（自动播放，约 4 秒）

依次聚焦高亮四个分支，每支停留约 1 秒并显示说明：

| 分支    | 颜色  | 说明文字        |
| ----- | --- | ----------- |
| 🔴 火力 | 红色  | 提升激光伤害与大招效果 |
| 🟢 生存 | 绿色  | 提升基地血量与护盾上限 |
| 🟡 资源 | 黄色  | 增加金币收益与掉落率  |
| 🔵 战术 | 蓝色  | 加快大招充能与击退效果 |

### Step 2 — 引导升级第一个节点

- 高亮火力分支第一个节点（高压电容 I）
- 手指指向节点升级按钮
- 提示文字："消耗金币解锁，**永久生效，不因失败消失**。"
- 等待玩家点击升级

### Step 3 — 完成

- 已升级节点的属性加成数值动画弹出
- 提示："科技树强化永久保留，每局游戏都能积累更强的基础实力！"
- 引导结束，玩家自由探索
- **完成标记**：`hasViewedTechTreeTutorial = true`

---

## 七、阶段五：装备系统引导

**解锁时机**：通关第二章·难度1（`ProgressManager.CompleteChapterDifficulty(chapter=1, difficulty=0)`）
**触发**：`hasViewedEquipmentTutorial == false` + 玩家第一次点击装备按钮

**解锁通知**：通关结算界面显示解锁动画："⚙️ 装备系统已解锁！强化你的战舰！"

### Step 1 — 槽位说明

- 高亮三个装备槽
- 提示："装备分为三个槽位，不同部位提供不同属性加成"

| 槽位 | 名称 | 主要属性 |
|------|------|---------|
| 武器槽 | 棱镜核心 | 激光攻击力 |
| 防具槽 | 塔基 | 基地血量 / 护盾 |
| 配件槽 | 逻辑芯片 | 暴击率 / 大招充能 |

### Step 2 — 装备安装

- 高亮背包中品质最高的可用装备
- 提示："点击装备，安装到对应槽位"
- 等待玩家完成安装

### Step 3 — 属性对比

- 高亮右侧总属性面板（攻击 / 血量 / 护盾 / 暴击 / 充能）
- 提示："装备属性实时叠加显示，点击单件装备可查看详情"

### Step 4 — 合成预告（条件触发）

**触发条件**：背包中存在 3 件相同品质的同类装备
- 高亮"自动合成"按钮
- 提示："集齐 3 件同品质装备可合成更高稀有度！"

> 若无可合成装备，跳过此步。

### Step 5 — 完成

- 提示："战斗结算后可获得新装备，持续强化你的战舰！"
- 引导结束，玩家自由操作
- **完成标记**：`hasViewedEquipmentTutorial = true`

## 八、技术实现规范

### 8.1 新增文件

**`Assets/Scripts/Logic/Tutorial/TutorialManager.cs`**（单例）

```
职责：
- 维护所有引导标记的读写（对接 MetaData 持久化）
- 对外提供 ShowTutorialStep(TutorialStep step) / CompleteTutorialStep(TutorialStep step) 接口
- 订阅 GameEvents 中的相关事件，在满足条件时自动触发对应引导步骤
- 管理引导 UI 层的显示 / 隐藏动画（淡入淡出，约 0.3 秒）

TutorialStep 枚举：
  LaserControl        // Step1 激光操控
  SkillFirstChoice    // Step2 技能三选一（一次性横幅）
  OverloadReady       // Step3 大招引导
  DroneIntro          // Step4 无人机引导
  TechTreeBranch      // 科技树分支介绍
  TechTreeFirstNode   // 科技树第一个节点引导
  EquipmentSlot       // 装备槽位说明
  EquipmentInstall    // 装备安装引导
  EquipmentMerge      // 装备合成预告
```
