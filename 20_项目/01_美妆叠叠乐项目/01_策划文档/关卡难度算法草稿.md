## 《美妆叠叠乐》关卡生成算法设计草案（适配现有编辑器）

### 🎯 一、算法目标

通过输入一组可控参数（DifficultyProfile），自动生成符合你前15关风格的关卡：

堆叠结构 有层次、有可视遮盖；

订单构成 有策略性与节奏；

临时槽张力 自然形成；

难度曲线 可通过参数控制（线性上升 / 中期峰值 / 波动式节奏）。

### 🧩 二、输入结构定义

LevelID: int,

TotalItems: int,          // 总化妆品数

TypeCount: int,           // 种类数

LayerCount: int,          // 层数（平均堆叠深度）

PackageMix: [int],        // 每个订单包的件数（例：[3,3,4,5]）

TempSlotCount: int,       // 临时槽位数量（默认5）

DifficultyCurve: string,  // "Linear" | "MidPeak" | "Wave"

DependencyDepth: int,     // 连锁依赖深度 (0–3)

InterferenceRate: float,  // 干扰布局比例 (0.0–1.0)

ClusterDensity: float,    // 聚簇密度 (0.0–1.0)

KeyItemDepthBias: float,  // 关键物品下沉权重 (0.0–1.0)

HasTrophy: bool,          // 是否奖杯关

Theme: string,            // 品牌主题

RandomSeed: int           // 随机种子（保证可重现）}

### ⚙️ 三、生成核心逻辑流程（伪代码）

#### Step 1：生成订单结构

规则：

PackageMix 控制关卡节奏，例如：

简单关：[3,3,3,3]

复杂关：[2,3,4]

大宗关：[3,4,5,5]

系统优先保证每种类型被完整分配（无冗余）

#### Step 2：确定堆叠结构

规则：

ClusterDensity 控制“聚簇感”：

低（0.2–0.4）：分散堆叠，解谜轻

中（0.5–0.7）：局部堆高，策略明显

高（0.8+）：压迫感强，容易卡槽

#### Step 3：嵌入“连锁依赖”关系

参数说明：

DependencyDepth：

0：无依赖（纯休闲）

1：A→B（简单逻辑）

2：C→B→A（中级）

3：E→D→C→B→A（终极推理）

KeyItemDepthBias：

控制关键物件倾向埋得更深（0.6–0.9）

#### Step 4：注入干扰元素

0.0：无干扰（教学关）

0.3：轻微混色（中段）

0.6：强视觉迷惑（高手关）

#### Step 5：控制节奏曲线（关内难度波动）

这是实现“前后轻松，中期困难”的关键逻辑。

ApplyDifficultyCurve(grid, DifficultyCurve):

if DifficultyCurve == "Linear":

# 层级越深越难

GraduallyIncreaseDependency()

elif DifficultyCurve == "MidPeak":

# 中期难峰

MakeMiddleLayersMostDense()

SimplifyTopAndBottomLayers()

elif DifficultyCurve == "Wave":

# 难易波动式

AlternateLayerDensityPattern()

例：

MidPeak → 典型第10关、第15关结构

Wave → 可用于带节奏感的随机生成关（如第7–9关）

#### Step 6：放置奖杯（如HasTrophy = True）

奖杯置于底层中央位置，被2–3层交错覆盖。

### 📈 四、难度控制参数建议表（用于前后期自定义）

| 参数 | 初期 (关1–3) | 中期 (关4–9) | 后期 (关10–15) |
| --- | --- | --- | --- |
| LayerCount | 3–4 | 5–7 | 8–9 |
| TypeCount | 4–10 | 10–15 | 15–20 |
| ClusterDensity | 0.3–0.4 | 0.5–0.7 | 0.7–0.9 |
| DependencyDepth | 0–1 | 2 | 3 |
| InterferenceRate | 0.0 | 0.3 | 0.5 |
| KeyItemDepthBias | 0.3 | 0.6 | 0.8 |
| DifficultyCurve | "Linear" | "MidPeak" | "MidPeak" / "Wave" |
