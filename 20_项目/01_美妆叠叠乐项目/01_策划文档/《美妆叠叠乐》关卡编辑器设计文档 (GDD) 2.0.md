#### 《美妆叠叠乐》关卡编辑器设计文档 (GDD) 2.0

版本: 2.0

1.设计目标 (Design Goals)

本编辑器旨在为关卡设计师提供一个直观、高效、所见即所得的创作环境 。其核心目标是：

赋能创意：允许设计师在程序化生成的高品质基底上，专注于创造“锁与钥匙”等精妙谜题，实现设计意图 。

提升效率：通过“程序化生成+手动微调”的混合工作流，结合清晰的UI分区和便捷操作，极大缩短高品质关卡的制作周期 。

保障体验：内置强大的验证系统，确保所有产出的关卡逻辑自洽、100%有解，并符合游戏的核心玩法需求 。

迭代友好：支持关卡的快速创建、保存、加载和修改，便于进行测试和调优 。

2.核心工作流程 (Core Workflow)

关卡设计师将遵循“结构化生成+手动微调”的黄金流程，以最高效率创造兼具随机性和设计感的关卡。

前期准备：在Unity工程指定文件夹下，创建好所有需要用到的化妆品和化妆包预制件(Prefabs) 。每个化妆包预制件需预设好2-5个不等的槽位挂点 。

创建/加载关卡：在LevelEditor.unity场景中 ，点击

New Level按钮创建新的关卡数据文件，或点击Load Level按钮加载已有文件进行编辑 。

程序化生成布局：

（可选）手动从**[化妆品库]**拖入本关的最终“奖杯”物品，并将其层级设置为0 。

在**[堆叠区]**的设置面板中，输入本关所需的“化妆品总数”、“种类数量”和“堆叠层数” 。

点击GenerateCosmeticsBtn按钮，编辑器将根据参数，在堆叠区随机生成所有化妆品的初始布局 。

设计师手动微调：设计师可以在此程序化生成的基底上，进行手动的、画龙点睛的调整，包括移动、旋转、修改层级，或手动替换某些物品，以植入“完美订单捷径”或“克制力陷阱”等特定设计意图 。

生成订单包：

在**[订单区]**，通过OrderBagToggleGroup勾选本关希望包含的订单包“配方”，如“简单X2”、“标准X3”等，可多选 。

点击GenerateOrderBagBtn按钮，编辑器会根据堆叠区的物品总量和您选择的“配方组合”，自动计算出能消耗掉所有物品的“最优解组合”，并生成所有订单包 。如果存在无法被配方整除的余数，设计师可手动使用AddX2BagBtn等按钮进行补齐 。

关卡难度定序：

点击GenerateOcclusionDataBtn按钮，编辑器首先分析并生成堆叠物的“遮挡依赖数据文件” 。

在**[订单区]**的DifficultyToggleGroup中，选择一个难度等级（1-5） 。

编辑器会根据您选择的难度（检索N层），对上一步已生成的订单包进行智能排序，以构建出符合预期挑战节奏的订单流 。

验证与保存：

点击PlaytestButton按钮，编辑器会模拟玩家操作（允许使用4个临时槽），验证当前关卡是否存在至少一种解法 。验证失败时，会打印日志提示设计师进行调整 。

验证通过后，点击Save Level按钮，保存所有关卡数据 。

##### 3. UI 布局与功能分区 (UI Layout & Functional Areas)

3.1. 化妆品库 (Prefab Library)

位置：屏幕底部 。

功能：以可滚动的列表或网格形式，加载并显示所有化妆品预制件 。提供搜索框 和拖拽操作支持 。

3.2. 堆叠区 (Stacking Area / Canvas)

位置：屏幕中央核心区域 。

功能：

关卡布局的主要操作与预览区域 。支持点选、多选、移动、旋转、缩放等手动调整 。

设置面板：

CosmeticsCount输入框：定义化妆品总数量 。

CosmeticsTypeCount输入框：定义化妆品类型数量 。

CosmeticsLayer输入框：定义堆叠层数 。

操作按钮：

GenerateCosmeticsBtn：根据上方参数程序化生成堆叠布局 。

ClearCosmeticsBtn：清空当前堆叠区 。

检视器联动：选中任意化妆品，可在Unity检视器中看到其详细信息，并可勾选“Is Lock”将其标记为“奖杯” 。

3.3. 订单区 (Order Area)

位置：堆叠区上方 。

功能：关卡订单的生成、配置与排序区域 。

配置面板：

OrderBagToggleGroup：多选框，用于选择本关订单包的“配方组合”（如：简单X2, 标准X3, 困难X4等） 。

DifficultyToggleGroup：单选框，用于选择关卡难度，此选项将决定订单包的出现顺序 。

核心操作按钮：

GenerateOrderBagBtn：核心按钮，根据“配方组合”和“堆叠区物品”自动计算并生成所有订单包 。

手动调整工具：

AddX2BagBtn / AddX3BagBtn...：手动添加指定槽位数量的空订单包，用于处理余数或特殊设计 。

DeleteOrderBagBtn：删除选中的订单包 。

支持对已生成的订单包进行

手动拖拽排序，作为对算法排序的最终微调 。

3.4. 关卡设置区 (Level Settings Area)

位置：屏幕顶部 。

功能：提供关卡的全局工具 。

NewLevelButton：创建并保存一个新的空关卡文件 。

LoadLevelButton：加载已有的关卡文件进行编辑 。

SaveLevelButton：保存当前关卡的所有设计数据 。

PlaytestButton：启动关卡合法性与可解性验证 。

##### 4.优化与风险管理 (Optimizations & Risk Management)

视觉辅助：为编辑器增加一个“层级视图”模式，允许设计师只显示特定层级的物品，便于检查和调整复杂的遮挡关系 。

流程保障：当前“程序化生成基底+手动微调+智能订单生成+最终验证”的工作流，从根本上确保了生产效率和关卡品质，避免了纯随机设计的不可控性和纯手动设计的低效率。
