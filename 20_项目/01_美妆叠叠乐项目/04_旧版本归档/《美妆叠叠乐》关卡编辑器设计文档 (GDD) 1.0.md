#### 《美妆叠叠乐》关卡编辑器设计文档 (Level Editor GDD)

版本: 1.0

##### 1. 设计目标 (Design Goals)

本编辑器旨在为关卡设计师提供一个直观、高效、所见即所得的创作环境。其核心目标是：

赋能创意：允许设计师像艺术家一样，在画布上自由布局，专注于创造“锁与钥匙”的精妙谜题。

提升效率：通过清晰的UI分区、便捷的拖拽操作和批量生成功能，极大缩短关卡制作周期。

保障体验：确保所有通过编辑器产出的关卡，其数据结构都符合游戏核心玩法的需求，特别是“层级(z)”和“锁(Is Lock)”的设定。

迭代友好：支持关卡的快速保存、加载和修改，便于进行测试和调优。

##### 2. 核心工作流程 (Core Workflow)

关卡设计师将遵循以下步骤完成一个新关卡的创建：

在unity中 Assets/Art_Resource/Prefabs/Cosmetics文件夹和OrderBag文件夹下分别创建化妆品预制体和化妆包预制体。

每个化妆包预制体需要提前制作好对应的槽位挂点，例如（A化妆包2个槽位挂点，B化妆包3个槽位挂点 等等）

在Unity中，打开LevelEditor.unity场景。

运行unity，会从对应的工程文件夹下获取所有的化妆品预制体和化妆包预制体。

所有化妆品预制体会加载显示到下方的化妆品库里，也就是LevelEditor场景里UI界面的Canvas节点下-Viewport节点下-Content节点下-CosmeticsArea节点下-Scroll View节点下-Viewport节点下-Content节点下-加载显示所有化妆品。

点击New Level按钮，创建关卡数据文件。或点击Load Level按钮，打开一个关卡数据文件进行编辑。

（可选）从化妆品区放置最终获得这个“奖杯”或者一个终极订单包里化妆品，并且设置0层，也就是最底层。也可以不放置这个“奖杯”。

输入这一关的化妆品总数量，再输入化妆品种类数量，再输入堆叠层数，点击GenerateCosmeticsBtn按钮，在堆叠区内随机生成所有化妆品。

可以手动调整堆叠区的化妆品，包括设置层级，位置，旋转等。

点击GenerateOcclusionDataBtn按钮，生成堆叠区遮挡和层级依赖关系数据文件。

选择生成订单区的所有订单包的类型，有几种选项，可以单独勾选，也可以组合勾选，选项有 简单X2 标准X3 困难X4 复杂X5等。例如我勾选 标准X3，那这一关的所有订单包都是3个槽位的，根据这个我就可以计算出订单包的数量，如果最后的数量和堆叠区匹配不上，那剩下1个或者2个，可以手动配置X1的订单包或者X2的订单包。 如果我勾选 简单X2 ,再勾选 标准X3，再勾选困难X4，复杂X5，完美订单，那就根据这个配比方案帮成最优解组合。

选择难度，选择难度一，订单包顺序是根据每一层所需要的化妆品和订单包匹配顺序排列，选择难度二，会根据每2层所需要的化妆品和订单包匹配顺序排列，依次类推，至多检索5层内的物品生成难度五.

然后点击GenerateOrderBagBtn按钮，根据需要的订单包的类型生成所有所需的订单包,然后再根据之前堆叠区生成的遮挡和层级依赖关系数据文件和难度选项，排列订单包的顺序。

关卡验证，点击PlaytestButton按钮，验证是否可以通关，可以用到临时槽4个来计算，算上4个临时槽至少会有1个有解的方案。根据之前堆叠区生成的遮挡和层级依赖数据文件，根据化妆包的顺序，从每2个化妆包需要的物品，从堆叠区的最上层开始验证消除，如果是被遮挡的化妆品玩家点击不到的，则存到临时槽，如果临时槽都存满则游戏失败，证明这个关卡是无解的，并且需要打印日志，告诉制作者是那一层的什么东西导致订单包无解。然后檢查場上物品是否足夠完成所有已定義的訂單。如果全部满足则游戏有解并验证通过。需要打印验证成功的日志。

点击某个化妆品，或者某个订单包可以再unity的inspector中修改数据，然后保存关卡的时候，需要保存修改后的这些物品的数据。

保存关卡，最后再完成设计后，点击Save Level按钮，保存这一关的所有数据，包含堆叠区的所有化妆品的数据和相应层级，订单区的订单包数据等。这样便于游戏正式加载数据的时候，根据关卡的数据直接加载相应的美术资源就可以了。

##### 3. UI 布局与功能分区 (UI Layout & Functional Areas)

编辑器界面分为以下五个核心区域：

3.1. 化妆品库 (Prefab Library)

位置：屏幕底部。

功能：

以滚动列表或网格形式，显示指定文件夹下的所有化妆品预制件缩略图。

提供搜索框，可按名称快速筛选预制件。

支持拖拽操作，将任意预制件拖入中央的[堆叠区]。

3.2. 堆叠区 (Stacking Area / Canvas)

位置：屏幕中央核心区域。

功能：

关卡布局的主要操作区域。

支持对区域内的化妆品进行点选、多选、移动、旋转、缩放。

CosmeticsCount输入框：化妆品总数量

CosmeticsTypeCount输入框：化妆品类型数量

CosmeticsLayer输入框：关卡层数

GenerateCosmeticsBtn按钮：点击按钮后，根据 化妆品总数、化妆品类型数量、关卡层数，自动在区域内生成随机布局。

ClearCosmeticsBtn按钮：点击后清除堆叠区的所有化妆品数据

提供选中某个化妆品，再检视器里显示这个化妆品的信息并可以勾选“Is Lock”的勾选项。

3.3. 订单区 (Order Area)

位置：堆叠区上方。

功能：

关卡订单包的生成区域。

支持对区域内的订单包进行选择、手动拖拽排列订单包顺序。

OrderBagToggleGroup选项组：订单包类型组合选择，有简单X2,标准X3,困难X4,复杂X5，可以单选或多选，组合成为这一关所有订单包的类型。

DifficultyToggleGroup选项组：难度选项组，只能单选，可以根据选择的难度，对订单包排序。

GenerateOrderBagBtn按钮：点击生成这一关所有订单包。

AddX2BagBtn按钮：点击生成一个2个槽位挂点的订单包。

AddX3BagBtn按钮：点击生成一个3个槽位挂点的订单包。

AddX4BagBtn按钮：点击生成一个4个槽位挂点的订单包。

AddX5BagBtn按钮：点击生成一个5个槽位挂点的订单包。

DeleteOrderBagBtn按钮：选中订单区内的订单包，点击按钮则删除。

3.4. 关卡设置 (Level Settings Area)

形式：屏幕顶部

功能：

关卡的工具功能区

SaveLevelButton按钮：点击按钮，保存关卡数据。

LoadLevelButton按钮：点击按钮，弹出文件选择框，选择关卡数据并根据数据加载生成堆叠区所有化妆品和订单区的所有化妆包。

NewLevelButton按钮:点击按钮，弹出文件保存框，选择目标路径，输入关卡名称，点击保存，生成新的一个关卡配置。

PlaytestButton按钮:点击按钮，进行关卡数据验证。

##### 第一关：建立认知

教学目标：让玩家无痛上手，掌握“点击物品-飞入订单”的核心操作。

堆叠区设定：

化妆品总数：9个

化妆品种类：3种 (例如：红色口红x3, 粉色腮红x3, 黑色睫毛膏x3)

堆叠层数：1层 (所有物品完全平铺，无任何遮挡)

“锁/奖杯”：无

订单区设定：

生成方式：使用编辑器的**“X3按钮”**自动生成。

订单包数量：3个。

订单需求：1个订单包需要3个红色口红，1个需要3个粉色腮红，1个需要3个黑色睫毛膏。

过关解法：玩家只需按顺序点击场上任意物品即可轻松过关。

玩家体验：纯粹的正反馈，建立“三消”的初步认知，感受流畅的动画与音效。

##### 第二关：理解遮挡与临时槽

教学目标：引入“层级”概念，让玩家首次使用“临时槽”解决“遮挡”问题。

化妆品总数：12个

化妆品种类数：3种

红色口红 (Lipstick_Red) x 4

粉色腮红 (Blush_Pink) x 4

黑色睫毛膏 (Mascara_Black) x 4

堆叠层数：2层

订单包数量：4个

订单需求：

订单包1: 需要 红色口红 x 3

订单包2: 需要 粉色腮红 x 3

订单包3: 需要 黑色睫毛膏 x 3

订单包4: 需要 红色口红 x 1, 粉色腮红 x 1, 黑色睫毛膏 x 1 (此为用于处理剩余物品的收尾订单)

关键布局与过关解法：

初始布局：将3支口红、3块腮红、2支睫毛膏随意放置在最顶层（Layer 2）。将第4支口红（伪钥匙A）放置在（Layer 1）。将第3支睫毛膏（真钥匙B）放置在底层（Layer 1），并确保它被伪钥匙A完全覆盖。将第4块腮红随意放置。

玩家思考：玩家可以轻松完成口红和腮红的3单位订单。当他们开始做睫毛膏订单时，会发现只有2支可点，第3支（真钥匙B）被一支多余的口红（伪钥匙A）压住了。

核心解法：玩家为了拿到急需的睫毛膏B，必须先点击并移除压在它上面的口红A。由于口红的3单位订单已满，口红A会自动飞入下方的临时槽。

收尾：玩家拿到睫毛膏B，完成睫毛膏订单。此时场上还剩下临时槽里的口红A，和场上某处的第4块腮红，以及解法过程中可能放入临时槽的睫毛膏。最后一个“混合订单包”的作用就是将这些剩余物品全部清空，达成胜利。

玩家体验：“Aha! 原来多出来的东西要先放到下面那个槽里，才能拿到被压住的。我懂了。” 玩家通过一次简单的“腾挪”操作，无压力地理解了游戏的核心矛盾和“临时槽”的关键作用。

##### 第三关：目标驱动 (“锁/奖杯”)

教学目标：引入“锁/奖杯”作为胜利条件，让玩法从“清空”升级为“寻宝”。

化妆品总数：19个

化妆品种类数：4种

圣罗兰限定眼影盘 (Trophy_YSL_Palette) x 1 [此为奖杯]

迪奥口红 (Lipstick_Dior) x 6

香奈儿眉笔 (Pencil_Chanel) x 6

粉色腮红 (Blush_Pink) x 6

堆叠层数：4层

订单包数量：4个

订单需求：

订单包1: 需要 迪奥口红 x 3

订单包2: 需要 香奈儿眉笔 x 3

订单包3: 需要 粉色腮红 x 3

订单包4: 需要 迪奥口红 x 3,

订单包5: 香奈儿眉笔 x 3,

订单包6: 粉色腮红 x 3

(终极订单): 需要 圣罗兰限定眼影盘 x 1 (此订单在场上只剩奖杯时出现)

关键布局与过关解法：

布局：将“眼影盘”置于最底层(Layer 1)。将订单1和2所需的6个“钥匙”（3口红，3眉笔）直接覆盖在“眼影盘”之上（Layer 2-3）。将剩余的其它物品放置在最顶层（Layer 4）。

解法：玩家必须先清理顶层的杂物，完成订单3和4的一部分。然后才能接触到覆盖着“奖杯”的6个“钥匙”，并完成订单1和2。清空所有物品后，场上只剩“奖杯”，终极订单出现，点击通关。

玩家体验：首次被一个明确、具象的“宝物”所吸引，整个过程目的性极强。

##### 第四关：感受变化 (引入可变订单)

教学目标：首次引入“2单位”小订单，带来惊喜和节奏变化。

化妆品总数：20个

化妆品种类数：5种 (祖马龙香水x2, 其余4种物品共18个)

堆叠层数：4层

订单包数量：7个

订单需求：

订单包1: 需要 祖马龙香水 x 2 [关键订单]

其余6个订单包: 由剩余18个物品构成3单位组合。

关键布局与过关解法：

布局：将2瓶“祖马龙香水”放在最顶层(Layer 4)最显眼的位置。

解法：玩家开局即可立刻完成这个2单位的订单，获得一次快速、强烈的正反馈。

玩家体验：感受到规则的有利变化，觉得轻松有趣，对后续关卡产生新鲜感。

##### 第五关：初尝策略 (抉择)

教学目标：首次引入“4单位”大订单，迫使玩家进行策略抉择。

化妆品总数：25个

化妆品种类数：6种 (含1个“奖杯”)

堆叠层数：5层

订单包数量：~8个 (包含一个关键的4单位订单)

订单需求：

订单包A: 需要 物品甲 x 4 [关键大订单]

订单包B: 需要 物品乙 x 2 [诱饵小订单]

其余订单...

关键布局与过关解法：

布局：将4个“物品甲”散布在通往“奖杯”的关键路径上，且被其它物品覆盖。将2个“物品乙”放在顶层，触手可及。

解法：玩家需要抵制住完成简单“订单包B”的诱惑，因为它会占用宝贵的临时槽，且对解开主路径无益。正确的做法是规划路线，有策略地为困难但关键的“订单包A”腾出空间和物品。

玩家体验：首次感受到“鱼与熊掌不可兼得”的决策压力，通关后为自己的正确选择感到满足。

##### 第六关：“完美订单”的捷径

教学目标：教学“完美订单”作为“隐藏捷径”的价值。

化妆品总数：30个

化妆品种类数：6种 (含1个“奖杯”，以及同品牌的“娇兰”系物品x3)

堆叠层数：6层

订单包数量：~10个

订单需求：包含一个需要3个“娇兰”系物品的订单。

关键布局与过关解法：

布局：将3个“娇兰”系物品相邻堆叠，形成视觉上的“组合”暗示。关卡整体设计得较为困难，常规解法会频繁触及临时槽上限。

解法：玩家若能发现并优先完成这个“完美订单”，获得的“清空临时槽”奖励将极大缓解后续压力，形成一条通关的捷径。

玩家体验：发现“秘密”并利用它获得巨大优势的狂喜，觉得自己“技高一筹”。

##### 第七关：“连锁依赖”谜题

教学目标：引导玩家进行“剥洋葱”式的多步逻辑推理。

化妆品总数：35个

化妆品种类数：7种 (含1个“奖杯”)

堆叠层数：7层

订单包数量：~12个

订单需求：包含订单A, B, C。

关键布局与过关解法：

布局：将订单A所需的物品A1，置于订单B所需的物品B1之下；将B1置于订单C所需的物品C1之下；将C1置于顶层。

解法：玩家无法直接拿到A1，必须通过观察，推理出“先拿C1完成订单C -> 拿到B1完成订单B -> 最后拿到A1完成订单A”的唯一正确顺序。

玩家体验：享受纯粹的逻辑推理快感，通关后成就感爆棚。

##### 第八关：“道具”的必要性

教学目标：创造明确需求，教学道具的成功通关。

道具有“清空临时槽”、“解锁新订单包”、“重新洗牌”

分别从“空间资源”、“目标资源”和“布局结构”三个维度，为玩家解困，覆盖了玩家卡死的主要场景。

化妆品总数：40个

化妆品种类数：7种 (含1个“奖杯”)

堆叠层数：8层

订单包数量：~13个

订单需求：包含一个需要“红色口红”的订单。

关键布局与过关解法：

布局：将最后一支“红色口红”深埋在底层，并用一个外形和颜色都极为相似的“粉色口红”将其完全覆盖。

解法：

玩家体验：从困惑到豁然开朗，深刻理解“信息”的价值。

##### 第九关：“克制力”谜题

教学目标：培养玩家的资源规划和“延迟满足”能力。

化妆品总数：40个

化妆品种类数：6种 (含1个“奖杯”，和YSL口红x8)

堆叠层数：6层

订单包数量：~13个

订单需求：

订单A (早期出现): 需要 YSL口红 x 2

订单B (晚期出现): 需要 YSL口红 x 3

订单C (晚期出现): 需要 YSL口红 x 3

关键布局与过关解法：

布局：将8支“YSL口红”全部放在最顶层，极具诱惑力。

解法：玩家看到订单A只需要2支口红，但顶层有8支可点。如果贪图清爽，将多余的口红点入临时槽，将导致后续空间不足而失败。正确的解法是保持克制，只拿2支。

玩家体验：因为贪婪而失败，或因为克制而成功的强烈对比，让玩家对策略思考有了更深的理解。

##### 第十关：毕业大考

教学目标：综合运用所有技巧，完成一次复杂的解谜，给予顶级成就感。

化妆品总数：50个

化妆品种类数：8种 (含1个设计最华丽的“奖杯”)

堆叠层数：10层

订单包数量：~16个 (各种大小组合)

订单需求：复杂多样。
