# 🔍 视觉清晰度系统（逐项分析）

## 形状 / 轮廓

* 主交互元素（按钮、卡片、数值框）使用**简洁的矩形或圆角矩形**，角度采用中等圆角（8–16px）保持柔和但稳重。
* 装饰性元素（花纹、闪粉、丝带）用**有机曲线**，并置于更低层级（视觉 z-index 较低）。
* 关键图标/操作采用**强可读的轮廓**（轮廓宽度统一），避免复杂剪影。

## 色彩 / 对比

* 以**中性 / 纯白背景** + 1–2 个主色（高级腮红粉/柔金/深海灰）构成。主色用于关键CTA与稀缺情绪点。
* 文本对比：正文建议对比比率≥4.5:1（可读性标准）。正文色推荐深炭灰而非纯黑（例如 #1F2B37），次文本用中灰 #6B7280。
* 装饰色（粉金、珍珠光）仅点缀，不用于表达功能性信息（避免用色传达关键状态）。

## 层次 / 留白

* 使用**8px 栅格＋24px 大间距作为区分模块的标准**。主要操作区周围留白更大以增强可点性与识别。
* 元素用阴影/描边/色差做微弱区分（轻微阴影优于强渐变），以保持“干净”感。

## 信息密度与可读性

* 关键数值（剩余步数、货币、冷却）采用**更大字号、高对比色**。
* 避免在重要数值上叠加装饰（例如光斑、纹理），若必须叠加，使用蒙层将装饰透明度降至 ≤12%。

# 🖼️ 美术元素设计建议（逐项、可落地）

## 卡片（卡牌 / 装备 / 化妆品卡）

* 布局（移动端示例）：卡片总宽度 ≈ 280px（在 375pt 画幅下），内边距 16px；图片区高 140–160px；下方信息行高度 48px。
* 圆角：12px；描边：1px 淡灰（#ECEFF3）；投影：`0 6px 18px rgba(30,40,50,0.06)`（非常柔和）。
* 视觉层级：图像（英雄） > 名称（SemiBold 16–18px）> 属性/稀有度（小号 12px）> CTA（次要/主要按钮）。
* 高级感处理：避免复杂渐变；用**单色渐变 + 微粒高光**或 **布面纹理（opacity ≤6%）**营造质感。

## UI（导航 / 按钮 / 面板）

* 主按钮：高度 48px（触控面积至少 44–48px），圆角 22px（pill）或 12px（常规）视场景。
* 按钮状态：默认（主色填充）、悬停/高亮（微放大 1.03、阴影加强）、按下（scale 0.98、阴影减弱）。动画时长 120–180ms。
* 辅助按钮：线框或文字按钮，线宽 1–1.5px，保持高对比文本。
* 面板分割：使用细线（1px）或 6px 高的分隔空白代替复杂分割线。

## 图标 / 文字符号

* 样式：**极简线性图标 + 必要时填充**。线宽 1.5–2px（保证在低分辨率仍清晰）。
* 尺寸：小图标 16px、常规 24px、强调 32px。
* 图标与文字配对：图标只做视觉提示，所有关键动作需有文字标签（避免仅靠图形表达）。

## 背景 / 装饰

* 背景层次：最下是**纯净/极淡纹理**→中层是模糊的氛围插画（opacity ≤20%）→最上层是功能性元素（完全不被遮挡）。
* 装饰提案：局部丝带高光、柔和渐变条或小颗粒（粒度细、透明度低）。**不要在牌面或数值区使用装饰**。

# 📈 信息优先级与布局（清单式优先级）

1. **主要元素（最高）**：玩家直接操作点（主要 CTA、出牌/确认、移动/交互按钮）——必须最大化对比与触控面积。
2. **核心玩法视觉（高）**：牌面主图、当前回合指示、倒计时/步数、关键资源（货币/能量）。
3. **状态反馈（中）**：获得奖励、升级提示、错误提示（用明确色彩区分成功/失败）。
4. **次要控制（低）**：背包、设置、社交入口（图标小、位于屏幕边缘或隐藏菜单）。
5. **装饰/氛围（最低）**：背景插画、光斑、粒子，用以增强品牌感但不得影响 1–3。

布局建议：把主要操作集中在 **易拇指区域（底部中心/右下）**，核心玩法放在视线中央，次要入口收纳在顶部或侧边。

# ⚠️ 潜在风险提醒（哪些会破坏清晰度）

* **过多渐变/金属质感覆盖数值或图标** → 会降低数字识别速度。
* **过细字体＋薄描边图标** 在低分辨率或压缩后会失真。
* **将功能性信息仅靠颜色区分**（无图标或文本）→ 色盲/弱视玩家无法识别。
* **大量粒子或不停闪动的装饰** 会干扰玩家注意力，影响决策（尤其是快节奏玩法）。
* **在低配设备上启用复杂后处理（强模糊、多个RT、重叠半透明）** 导致帧率下降和输入延迟。

## 🎯 一、为什么会出现“阴影”和“星星”

1️⃣ **Midjourney 的“语义权重”机制**

* Midjourney不会“完全禁止”某些元素，而是“尽量减少”。
* 词语 like `no shadows`、`no stars` 只是**弱约束**，AI 仍然会根据学习到的“化妆品美术素材”风格默认添加柔光、高光、闪光点。
* 特别是在“chic and clean + cosmetics”主题下，它会自动联想到闪亮、反光、星光点缀（代表精致或奢华感）。

2️⃣ **“flat design”与“gradient”的组合冲突**

* 你同时使用了 `flat design` 和 `gradient`。

  * `flat` 暗示无阴影、纯色块；
  * `gradient` 暗示有光影变化。
* 模型通常会优先执行“渐变”指令，于是出现了“柔光阴影感”。

3️⃣ **训练集风格偏差**

* “luxury cosmetics” 这个关键词常常被训练在带有闪光、星点、镜面反光的素材上。
* 即使你写了 “no stars”，AI 仍然倾向于自动补“闪亮的星点”作为视觉符号。

---

## 🧭 二、解决方案（优化提示词）

想真正去掉星星和阴影，需要：

* 用更“强语义”的禁止词（用描述法代替否定法）
* 降低奢侈感关键词的“闪光”倾向
* 指定“纯色面、干净背景、无视觉特效”

## 🧠 Nano Banana Prompt 写法技巧总结（便于你快速构造）

| 技巧                      | 说明                                                                         | 举例 / 可套用结构                                                                                     |
| ----------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **主体 + 风格 + 限定材质 / 效果** | 明确告诉模型“是什么 + 要怎样表现 + 材质 / 禁止项”                                             | “[makeup item], chic & clean style, flat minimalist design, matte finish, no sparkle, no glow” |
| **编辑维持一致性**             | 在编辑图片时，强调“保持主体特征 / 不破坏面部 / 保持整体风格”                                         | “preserve facial features, same lighting, same style across variations”                        |
| **场景 / 背景定位**           | 即使是产品或图标素材，也要设定一个简单环境（如白底 / 台座 / 柔光摄影棚）                                    | “place on pure white background, subtle shadow under base only, studio light”                  |
| **禁止词 / 反向描述强化**        | 用具体否定（shine, sparkle, lens flair, glow, texture）胜过笼统“no shadows, no stars” | “no lens flare, no sparkle, no glow, no texture, no watermark, no text”                        |
| **材质 / 光照描述**           | 指明光源、材质（哑光 / 光泽 / 半哑光）帮助模型理解高光处理                                           | “soft studio light, matte surfaces, subtle highlights”                                         |
| **一致性 / 系列风格提示**        | 若要一组图保持统一风格，要在 prompt 中加 “consistent style / same lighting / same palette” | “generate icon set in same style, consistent lighting and color palette”                       |
| **高分辨 / 精细级别**          | 要求“high resolution / detailed / crisp edges / clean vector look”           | “high resolution, crisp outline, vector style clarity”                                         |
| **排版 / 布局提示**           | 对界面素材（卡片、按钮、图标）可加布局提示                                                      | “centered, balanced composition, margin whitespace”                                            |
| **不要 / 禁止项明确化**         | 将禁止项拆成多个简单词，以防模型部分忽略                                                       | “no watermark, no logo, no text on object, no noise/grain”                                     |
