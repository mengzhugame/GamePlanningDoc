伸長 (Stretching) + 競賽 (Racing): 賽跑遊戲，但你可以伸長你的腿來跨越障礙或更快到達終點。

合併 (Merging) + 手工藝 (Crafting): 合併基礎的顏料來創造新的顏色，並用它來為陶器上色。

發射 (Launching) + 整理 (Sorting): 用彈弓把不同顏色的衣服精準地發射到對應顏色的洗衣籃裡。

繪製 (Drawing) + IO: 在一個共享的畫布上，通過繪製來圈地，把別人的畫作變成自己的顏色。

駕駛 (Driving) + 消除 (Matching): 駕駛一輛車在倉庫裡移動，將三個相同顏色的貨箱推到一起來消除它們。

聚集 (Gathering) + 金錢 (Money): 控制一塊磁鐵，在城市裡滾動，吸附地上的硬幣，讓錢球越滾越大。

圈地 (Enclosing) + 物理 (Physics): 畫一個圈，圈住下落的物理小球，讓它們在你的圈內碰撞得分。

下落 (Falling) + 交通工具 (Vehicles): 控制一輛下落的汽車，在空中左右移動，穿過一層層的圓環。

雕刻 (Carving) + 食物 (Food): 在一個巨大的起司輪或黃油塊上，根據虛線雕刻出指定的形狀。

攻擊 (Attacking) + 音樂 (Music): 敵人會跟隨音樂節拍出現，你需要準確地在節拍點上點擊屏幕來攻擊它們。

奔跑 (Running) + 繪畫 (Painting): 你的角色跑過純白的地面時，會留下彩色的足跡，目標是跑遍所有路徑，完成一幅巨大的畫。

跳躍 (Jumping) + 整理 (Sorting): 在傳送帶上跳躍，通過跳躍踩踏開關，將不同物品分流到正確的箱子裡。

滑行 (Sliding) + 武俠 (Kung Fu): 在結冰的湖面上滑行，利用慣性撞擊敵人，有點像冰壺但主題是武俠。

堆疊 (Stacking) + 人群 (Crowd): 像啦啦隊一樣，將小人一個個向上拋，讓他們在空中堆疊成盡可能高的人塔。

傾倒 (Pouring) + 抽象 (Abstract): 將不同顏色的流沙從容器中傾倒出來，創造出富有層次感的沙畫藝術。

扇巴掌 (Slapping) + 競賽 (Racing): 與對手賽跑，但可以通過扇巴掌使其短暫眩暈，從而超車。

消除 (Matching) + 建造 (Construction): 消除特定顏色的方塊來獲取對應的建築材料，然後用這些材料來建造你的城市。

分裂 (Splitting) + 跑酷 (Parkour): 在跑酷中遇到岔路時，可以將角色分裂成兩個，分別跑不同的路徑來收集所有獎勵。

點擊 (Tapping) + 寵物 (Pets): 屏幕上會快速出現地鼠洞，但鑽出來的是可愛的小貓小狗，點擊撫摸它們而不是敲打。

按壓 (Pressing) + 食物 (Food): 模擬製作果汁，長按屏幕將水果壓入榨汁機，要注意不能按太久導致機器過熱。

畫線 (Line Drawing) + 街頭文化 (Street Culture): 畫出一條完美的塗鴉線條，一筆完成整個字母或圖案。

解開 (Untangling) + 物理 (Physics): 解開纏繞在一起的鏈條，解開時它們會因為重力而產生有趣的物理擺動。
