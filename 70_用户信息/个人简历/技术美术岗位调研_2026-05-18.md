# 技术美术岗位调研与投递建议

## 结论

王永成当前简历最适合的定位不是“会画画/会建模的美术向 TA”，而是：

- 技术美术（程序向）
- Unity TA
- Pipeline TA / 美术工具链 TA
- UGC 工具链 TA
- Shader / 渲染表现 / 移动端性能优化 TA
- AIGC / AI Pipeline TA（需要补作品集证据）

核心卖点应从“我懂美术并能做一些美术内容”调整为“我理解美术生产流程，能用 Unity、Shader、脚本工具、资源规范和性能优化解决项目落地问题”。

## 适合方向

### 高匹配

1. Unity / UGC 工具链 TA
   - 匹配点：Unity、Editor 工具、AssetDatabase、Shader、资源规范、移动端优化、玩法与美术资产映射。
   - 当前最像腾讯《王者荣耀》UGC-技术美术（TA）。

2. Pipeline / 美术工具链 TA
   - 匹配点：Python、C#、MaxScript、Unity/3ds Max/Blender 批处理工具、资源检查、批量导出、流程文档、跨部门沟通。
   - 可投腾讯光子 Pipeline 向、网易 TA 技术美术、网易 AI Pipeline TD 的部分方向。

3. Unity / URP / 风格化渲染 TA
   - 匹配点：URP、NPR、卡渲、Outline、Rim Light、Ramp、UI 虚化、后处理、移动端性能优化。
   - 可投网易在研风格化渲染 TA、腾讯光子程序向的 Unity/Shader 子方向。

### 中匹配，需要补强

1. AIGC 技术美术 / AI Pipeline TA
   - 需要补强：AI 工作流落地案例、ComfyUI/本地推理/工具封装、DCC/Unity 与 AI 资产流转示例、前后端或后台工具证据。

2. 高级渲染 TA / 渲染向 TA
   - 需要补强：RenderDoc、Frame Debugger、GPU/CPU profile 截图、Shader 复杂度优化案例、图形 API 基础、C++ 或 UE 经验。

## 不建议优先投递

- 技术美术（美术向）
- 贴图向 TA
- 灯光向 TA
- 角色材质 / 角色渲染深度向 TA
- 需要主导建模、角色资产、Substance 贴图、灯光 LookDev 的岗位
- Houdini PCG 向 TA（除非后续补 Houdini/VEX/PCG 作品）
- 纯 UE5 / C++ 图形程序化很重的高级渲染岗位

不要在简历里写“我不会画画和建模”。更好的表达是：

> 主要定位为技术实现、工具链、Shader、资源规范与性能优化，不以原画、建模、贴图生产为主。

## 简历需要优化的地方

### 1. 求职意向要更精准

当前“技术美术 / Unity TA / 渲染管线与工具链”方向正确，但建议改为：

> 技术美术（程序向） / Unity TA / Pipeline TA / UGC 工具链 / Shader 与移动端性能优化

### 2. 弱化“美术制作与管理”

当前简历中“美术制作与管理”“2D/3D 动画、场景搭建、视频宣传动画、外包审核”等内容会让招聘方误以为你是美术向 TA 或美术组长。建议保留经历，但放到次级位置，主线改成工具链、Shader、资源规范和性能优化。

### 3. 技能要改成岗位关键词矩阵

建议新增一段“岗位匹配能力”：

- Unity 工具链：EditorWindow、Editor Scripting、AssetDatabase、批处理、资源检查、导入导出规范。
- Shader / 渲染：URP、NPR、HLSL/CG、Outline、Rim Light、Ramp、UI Blur、后处理。
- 性能优化：DrawCall、Shader 复杂度、纹理/内存、包体、移动端适配、微信小游戏性能控制。
- DCC 工具：3ds Max / Blender / Python / MaxScript 批量处理与导出。
- Pipeline：资源规范、流程文档、资产库、材质库、动作库、Demo 库、跨部门落地。
- 独立项目：两款微信小游戏从立项到上线，证明完整闭环和问题定位能力。

### 4. 作品集入口必须重做

“微信小游戏搜索《美妆叠叠乐》《光与朽》”只能作为上线证明，不够支撑大厂 TA 面试。

建议做一个飞书文档/Notion/个人网页，至少包含：

- 两款小游戏的短视频或动图。
- URP/NPR/Shader 效果前后对比。
- Unity 工具截图：资源检查、批处理、导出工具、材质/动画预览工具。
- 性能优化证据：Profiler、Frame Debugger、RenderDoc、DrawCall/内存/包体变化。
- Pipeline 图：美术资源从 DCC 到 Unity 到微信小游戏发布的流程。
- 代码片段：Shader、Editor 工具、Python/MaxScript 工具。
- 每个项目明确写“我的职责”和“解决的问题”，不要只放成品。
