# 系统策划案：装备组装系统 (Assembly System) V2.0

## 1. 系统综述 (System Overview)
### 1.1 设计目的
*   **长线养成**：为玩家提供局外的数值验证、成长目标和个性化外观反馈。
*   **商业化锚点**：承载广告变现（开宝箱）的核心系统，用稀有度刺激重复点击。
*   **流派特化**：通过引入“套装属性(Set Bonus)”，让玩家有目的地收集特定装备，而非简单的数值比拼。

### 1.2 解锁时机
*   **错峰解锁**：通关第1章后**仅解锁装备栏位UI**（不弹强引导）；玩家在第2章第1局游戏结束（或首次获得装备掉落）时，再触发实物的【穿戴/合成】强引导。

## 2. 界面与交互 (UI/UX)
*   **展示区（上部）**：光棱塔侧视图模型，周围环绕3个基础装备槽（预留扩展到6个槽位的空间）。
*   **功能区（中部）**：
    *   【一键合成】：自动将背包内满足条件的同名同品质装备升阶。
    *   【一键装备】：自动穿戴战力最高/品质最高的装备。
*   **背包区（下部）**：网格背包，按品质、部位、套装排序显示。

## 3. 物品、部位与套装 (Itemization)
### 3.1 装备部位定义 (核心三件套)
*   **棱镜核心** [武器]：主加基础攻击力。改变塔顶水晶形状。
*   **塔身底座** [防具]：主加生命/护盾上限。改变底座模型(履带/浮空/支架)。
*   **运算芯片** [饰品]：主加暴击/充能效率等策略属性。仅图标变化。

### 3.2 品质稀有度 (Rarity)
*   白(普通) -> 绿(优秀) -> 蓝(精良) -> 紫(史诗) -> 橙(传说) -> 红(神话)。
*   **进阶词条**：蓝装开始激活副词条，橙装激活特殊被动（如：复活后全屏清怪）。

### 3.3 ⚠️ 【新增】套装系统 (Set Bonus)
为解决“3个部位池子太浅，玩家极易毕业”的问题，引入套装概念。
即使同为紫装，不同的前缀拥有不同的套装加成。
*   **【掠夺者套装】**：
    *   (2件套)：对精英怪伤害+15%
    *   (3件套)：击杀敌人后，金币掉落范围增加，局内金币收益+10%。
*   **【绝对零度套装】**：
    *   (2件套)：冰冻效果持续时间+0.5秒。
    *   (3件套)：热休克协议(冰爆)的基础伤害倍率从200%提升至250%。

## 4. 资源产出与消耗逻辑优化 (Economy)
### 4.1 获取途径
*   **核心途径**：广告宝箱（每日免费1次，随后看广告抽取，限制次数）。
*   **次要途径**：挂机收益、通关特定无尽模式节点。

### 4.2 ⚠️ 升级与合成逻辑 (取消资源冲突)
原案中“分解装备得图纸”与“一键合成低级装备”存在严重的资源争夺（玩家若分解了，就没法合成升品质）。
*   **横向升阶 (合成品质 / Merge)**：
    *   **规则**：3个同名、同部位、同品质的装备 = 1个更高品质的装备（3合1）。
    *   **消耗**：仅消耗装备本身，不消耗金币。
*   **纵向强化 (提升等级 / Level Up)**：
    *   **规则**：点击单件装备，消耗 **【金币】 + 【通用金属零件(局内普通掉落)】** 提升等级(Lv1 -> Lv50)。
    *   **优点**：材料完全剥离。垃圾装备用来“3合1升阶”，局内刷图获得的“金币+零件”用来“无脑升级”。
*   **无损重置**：一件强化到Lv20的装备，可以花费极少钻石进行重置，100%返还金币与通用零件，鼓励玩家随时更换套装。
