# 系统策划案：科技树系统 (Tech Tree System) V2.0

## 1. 系统综述 (System Overview)
### 1.1 设计目的
*   **金币回收**：建立巨大的金币消耗池，防止通货膨胀，控制游戏进度。
*   **活跃留存**：通过微小的属性积累与阶梯式的卡点，让玩家每天都有明确的变强目标。
*   **功能解锁**：将核心机制（如复活、大招回血）作为中后期奖励，循序渐进释放复杂度。
*   **碎片化叙事**：利用科技节点的文案包装，低成本补全赛博废土的世界观。

### 1.2 目标用户与解锁时机
*   **解锁条件**：玩家**通关第1章的第1波**后，无论胜负，立即强制解锁并引导加点（降低新手认知负荷，第一时间提供死亡补偿）。

## 2. 界面与交互 (UI/UX)
### 2.1 界面布局 (神经网格)
*   **背景**：暗色调的赛博朋克电路板风格，能量线在节点间隐约流动。
*   **结构**：采用“中心辐射式”布局。屏幕中心为起点（核心节点 Level 0），向 上、下、左、右 四个方向延伸出四条主电路。
*   **操作**：支持单指拖拽平移视图，双指缩放。点击节点弹出详情弹窗；**长按节点可连续升级**。

## 3. 分支设计与节点详解 (加入了叙事Flavor Text)

### 3.1 🔴 上行电路：火力投射 (Firepower) - 红色系
*定位：纯粹的输出提升。*
*   **第1层**：【高压电容 I】(基础攻击力)。 *“最初的棱镜并非为了杀戮，而是为了驱散阴霾。”*
*   **第2层**：【弱点解析】(暴击率) / 【高压电容 II】(攻击力%) / 【透镜校准】(爆伤)。
*   **第3层(终极)**：【过载射击】 / 【终极超载】(大招强化) / 【高能穿透】。 *“当过载达到临界点，光即是真理。”*

### 3.2 🟢 下行电路：生存防护 (Survival) - 绿色系
*定位：增加容错率。*
*   **第1层**：【复合装甲 I】(生命上限)。 *“活着，才有资格谈论净化。”*
*   **第2层**：【护盾发生器】 / 【复合装甲 II】 / 【动能缓冲】(减伤)。
*   **第3层(终极)**：【紧急防卫】 / 【备用系统】(复活次数+1) / 【纳米修复】(大招回血)。 *“在最深的黑暗里，我们也必须留下最后一颗火种。”*

### 3.3 🟡 左行电路：资源循环 (Resources) - 黄色系
*定位：局外养成与经济基础。*
*   **第1层**：【幸运协议 I】(金币掉落)。 *“旧世界的废铁，新世界的黄金。”*
*   **第2层**：【离线算力】(挂机收益) / 【幸运协议 II】 / 【商会声望】(商店刷新)。
*   **第3层(终极)**：【初始资金】(开局爆金币) / 【赏金猎人】(精英怪掉宝箱)。

### 3.4 🔵 右行电路：战术辅助 (Tactics) - 蓝色系
*定位：优化战斗手感与控制。*
*   **第1层**：【快速充能】(大招充能速度)。 *“时间是我们唯一无法制造的资源。”*
*   **第2层**：【击退增强】(推力) / 【杀戮回能】(击杀减CD) / 【战术延长】(Buff时间)。
*   **第3层(终极)**：【黑客密钥】(三选一免费刷新) / 【启动冲击】(大招全屏震晕)。

## 4. 数值模型与消耗卡点 (Economy Model)
### 4.1 阶梯式消耗公式
禁止使用完全平滑的指数增长，必须设计**卡点**刺激商业化。
*   **平时升级（Lv1-9, Lv11-19等）**：平滑递增，消耗较少金币。
*   **突破升级（Lv10, Lv20 整数关卡）**：金币消耗**突然飙升 3-5 倍**，或者需要消耗特定掉落材料。
*   **目的**：当玩家卡在 Lv19 升 Lv20 时，强烈的沉没成本会促使他去点击【结算双倍金币】的广告。

### 4.2 前置解锁逻辑
*   必须点亮前置节点至少 Lv1，才能解锁下一圈层的后置节点。内圈 → 中圈 → 外圈。
