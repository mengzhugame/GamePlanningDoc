## 三、核心计算模型（TTK模型）

### 3.1 TTK（Time To Kill，击杀时间）公式

```
TTK（秒） = 怪物有效HP / 玩家有效DPS

有效HP = 基础HP × difficultyMultiplier（波次难度系数）
有效DPS = 当前DPS（含升级加成 + 无人机加成 + 暴击期望）
```

**TTK体验标准（参考Vampire Survivors等同类游戏）：**

| TTK范围 | 体验评价 | 设计目标 |
|---------|---------|---------|
| < 0.5秒 | 爆炸割草 ✅ | 纯群怪波、爽感波 |
| 0.5~1.5秒 | 舒适割草 ✅ | 普通群怪标准 |
| 1.5~3秒 | 有压迫感 ✅ | 精英怪、特殊怪 |
| 3~8秒 | 高压集火 ⚠️ | 仅Boss适用 |
| > 8秒 | 刮痧/坐牢 ❌ | 必须避免 |

### 3.2 防线总血池压力计算

```
单波总血池 = Σ(每组怪物数量 × 怪物HP × 该组healthMultiplier × 波次difficultyMultiplier)
清场理论时间 = 单波总血池 / 玩家有效DPS
```

**注意**：这是理论值。实际游戏中：
- 怪物是分批生成的（有spawnTime延迟），不是同时全场
- 玩家激光宽度有限，同时覆盖怪物数量有限
- 激光射程有限，只能打到进入范围的怪

所以真实清场时间 ≈ 理论值 × 1.3~1.8（修正系数，取决于激光宽度和场地布局）

### 3.3 玩家局内成长推算

每波结束后玩家会获得：
1. **技能三选一（升级）**：平均每波提升有效DPS约 **+12%**
   - 数值类技能（伤害+20%、暴击+10%等）：直接提升DPS
   - 机制类技能（冰冻）：等效DPS提升，因为冰冻让怪物停止移动，延长输出窗口
   - 激光加宽：提升同时命中数量，等效提升DPS
   - 保守取12%是因为三选一有随机性，玩家不一定每次都拿到最优选项

2. **无人机属性补给（波次间隙）**：平均提升有效DPS约 **+8%**
   - 这是固定的加成，不依赖运气

3. **累计成长公式**：
```
第N波时的玩家DPS = 基础DPS × (1.12)^(升级次数) × (1.08)^(无人机次数)
```

## 四、关于波次数量与单局时间的设计建议

### 4.1 主人的历史决策
- 最初设计：12波（含Boss）
- 后改为：8波（感觉12波太长）
- 我上次推演用：10波（折中，但没有跟主人确认）
- 目前工程中：WaveConfig_12（12波）

### 4.2 单局时间的设计标准

根据微信小游戏的用户习惯研究：

| 游戏类型 | 推荐单局时长 | 原因 |
|---------|------------|------|
| 碎片化轻度玩家 | 3~5分钟 | 等车/上厕所场景 |
| 核心玩家 | 8~12分钟 | 沉浸式一局 |
| 《光与朽》定位 | **5~8分钟** | 解压割草，不宜太长 |

### 4.3 每波平均时长推算

```
每波时长 = 波次间隔(waveInterval=3秒) + 实际清场时间
```

根据当前数值推演：
- 清场时间约 15~35秒/波
- 波次间隔 3秒

**波次数量推荐：**

| 波次数 | 预计单局时长 | 评价 |
|--------|------------|------|
| 8波 | ~3~4分钟 | 偏短，Boss战来得太快 |
| 10波 | ~4~6分钟 | ✅ 推荐（轻度玩家友好） |
| 12波（含Boss） | ~6~8分钟 | ✅ 推荐（核心玩家友好） |

**结论：保留12波设计，但把节奏控制好。前5波轻松，后5波有压力，第12波Boss战。**

## 六、问题清单与修改建议

### 问题1：W4-W5 压力感缺失 🔴优先级高

**现象**：W4和W5的理论清场时间只有11-12秒，玩家体感过于轻松，Rusher偷袭没有压迫感。

**根本原因**：
- Rusher血量400过低，玩家DPS在2000+时，一次扫射即可消灭
- diff系数1.1/1.2提升有限，没有充分体现"节奏加速"

**修改方案（二选一）：**

方案A（推荐）：增加W4-W5的怪物数量
```
W4：Rusher从5只改为 10只，并增加 spawnTime=5 时额外一组粘液×10
W5：Rusher从7只改为 12只，弹球怪从6只改为 10只
```

方案B：调高diff系数
```
W4 difficultyMultiplier: 1.1 → 1.4
W5 difficultyMultiplier: 1.2 → 1.6
```

---

### 问题2：精英坦克HP过高 🔴优先级高

**现象**：W6出现的精英坦克，有效HP=52,000，当时玩家DPS≈3,200，单杀需要16秒。

**影响**：
- 16秒内，其余20+只怪物继续推进，防线极易被突破
- 对新手玩家来说，这是一个不合理的难度墙

**修改建议**：
```
Enemy_EliteTank.asset:
  maxHealth: 40000 → 20000
```
修改后有效HP=26,000，TTK≈8秒，仍有压迫感但不会崩盘。

### 问题3：精英弹球是隐形秒杀陷阱 🟡优先级中

**现象**：精英弹球接触伤害750，玩家总血池3000，接触4次必死。

**影响**：
- 第一次遇到精英弹球的玩家，大概率会在毫无预兆的情况下突然死亡
- 这不是"有难度的挑战"，而是"缺乏预警的突然死亡"，会直接导致差评

**修改建议**：
```
Enemy_EliteDrifter.asset:
  contactDamage: 750 → 300

同时：W9的精英弹球出现前（spawnTime=25时）
      在hintText加入提示文字
      或通过UI闪烁警告玩家
```

### 问题4：Boss血量过高，战斗时间过长 🟡优先级中

**现象**：Boss有效HP=125万，玩家DPS≈15,700，理论需要80秒。

**推荐标准**：Boss战30~45秒

**修改建议**：
```
WaveConfig_12.asset:
  bossHealth: 500000 → 300000

修改后有效HP = 300000 × 2.5 = 750,000
预计TTK = 750000 / 15700 ≈ 47.8秒（合理范围内）
```
