# 《光与朽》第二章与第三章怪物与Boss美术策划案（拆件落地版）

为配合 AI 美术生成（如 nanobanban / 即梦）以及 Unity 实际拼装落地，本案严格遵循“流体底层 + 挂件贴图 + 表情贴图”的分层（Layer）设计逻辑。

---

## 🔥 第二章：熔岩虚空 (Magma Void)
**视觉基调**：沸腾、极度不稳定、高温。流体颜色以暗红/白炽/亮黄为主。

### 1. 分裂岩浆怪 (Splitter)
**表现形式**
❌ **误区**： 不要直接画成三个小怪强行粘在一起的形状。
✅ **正解**： “包裹着多个核心的沸腾岩浆泡”。
**视觉逻辑**：
像一个超载的巨型细胞，随时准备分裂。外部是一层流体，里面隐约看到即将分离的独立核心。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 较大的深红色/暗橙色圆球，渲染到黑油 RT 上（只需改变该怪物的材质着色参数）。
*   **Layer 2 (Cores - Order 19)**: 内部半透明悬浮的3个“亮黄色发光小球” Sprite，挂在流体内部。
*   **Layer 3 (Eyes - Order 20)**: 3对挤在一起的**“惊恐、东张西望的小眼睛”** Sprite。
**组合与最终效果**：
在 Unity 中，外部是深红的流体，透出里面三个高亮核心，配上惊恐的眼睛。一旦血量归零，销毁母体，实例化生成三个独立的小怪流体。

### 2. 自爆爆裂者 (Exploder)
**表现形式**
❌ **误区**： 不要画成带引线或金属外壳的炸弹。
✅ **正解**： “过度膨胀的白炽化流体”。
**视觉逻辑**：
极度不稳定，温度极高，膨胀到了极限。颜色必须非常刺眼，警告玩家远离。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 白炽色/亮黄色的中型圆球。
*   **Shader 技巧**: 将该流体材质的 Noise 参数调到极大，边缘要像沸水一样疯狂抖动。
*   **Layer 2 (FX - Order 19)**: 怪物身上挂载一个简单的火星往上飘的 Particle System（粒子特效）。
*   **Layer 3 (Eyes - Order 20)**: 眼睛是瞳孔涣散、极度痛苦或愤怒的 **“><”** 形状 Sprite。
**组合与最终效果**：
一个极其亮眼、疯狂抖动并冒着火星的液体炸弹，视觉上极具威胁性。

### 3. 熔岩喷吐者 (Artillery)
**表现形式**
❌ **误区**： 不要给它画上拿着武器的手。
✅ **正解**： “移动的微型活火山口”。
**视觉逻辑**：
底盘稳固，不怎么移动，但顶部有极高的热量汇聚，像一座正在蓄力的火山。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 底部宽大、顶部收缩的暗红色锥形流体（类似水滴形）。
*   **Layer 2 (Crater - Order 19)**: 顶部叠加一个“高亮岩浆喷发口”的 Sprite。
*   **Layer 3 (Eyes - Order 20)**: 眼睛长在身体下半部分的暗色区域，是**“半眯着的专注狙击手眼神”** Sprite。
**组合与最终效果**：
下半部分厚重，眼睛专注，顶部开口处闪烁高光，完美符合远程炮台的定位。

### 4. 第二章 BOSS：熔岩之核 (Magma Core)
**表现形式**
✅ **肯定**： “濒临爆炸的微型恒星 + 黑曜石外壳”。
**视觉参考**： 太阳表面的黑子斑块与日珥爆发现象。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 极度明亮的巨大黄白色恒星流体球（RT渲染）。
*   **Layer 2 (Crust - Order 20)**: 几块巨大的、不规则的、龟裂的**“黑色黑曜石护甲板”** Sprite，环绕并部分遮挡流体。
*   **Layer 3 (Glow - Order 19)**: 护甲缝隙透出的极致红色/白色高光底图。
*   **Layer 4 (Eyes)**: 没有传统卡通眼睛。弱点核心是一个极其刺眼的**“白热化十字裂缝”** Sprite。
**动态效果**：
*   黑曜石外壳（Crust）缓慢且互相错位地旋转。
*   中心十字裂缝的白光伴随心跳频率产生“呼吸感”缩放。
**BOSS 攻击方式设计（物理+流体特性）**：
*   **Phase 1 (汲取融合)**: 召唤一圈自爆怪向自己聚拢，玩家必须在半路用激光切碎它们，否则Boss吸收后回血。
*   **Phase 2 (熔岩冲撞)**: 闪烁剧烈白光（蓄力），随后带着霸体向光棱塔发动冲锋，路径上留下灼烧的岩浆斑迹。玩家需全力“对波”阻挡。
*   **Phase 3 (陨石雨)**: Boss 核心裂缝张开，向屏幕上方抛射流体火球，随后带预警红圈的火球砸下，玩家需旋转激光半空拦截。

## ❄️ 第三章：极寒虚空 (Glacial Void)
**视觉基调**：凝滞、冰冷、几何感。流体颜色以深蓝/青色为主，搭配半透明冰晶。

### 1. 冰甲巨兽 (Frost Tank)
**表现形式**
❌ **误区**： 不要把流体本身画成一块冰，那就失去 Metaball 融合流体的形变特色了。
✅ **正解**： “被冻在半透明冰晶装甲里的迟缓流体”。
**视觉逻辑**：
内部是柔软但极其迟缓的液体，外部套着坚不可摧的冰冻外壳。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 颜色偏暗蓝的巨大流体球。
*   **Layer 2 (Armor - Order 20)**: 几块巨大的、表面带有划痕和折射反光的**“半透明多边形冰晶”** Sprite。
*   **Layer 3 (Eyes - Order 21)**: 透过冰层显露的眼睛，呈现**“冰冷、无情、极小瞳孔的幽蓝色凝视”** Sprite。
**组合与最终效果**：
玩家打上去先是清脆的砸冰块特效（Particle），打破冰甲（隐藏Layer 2）后，里面迟缓的深蓝流体才会受到物理击退。

### 2. 极寒光环者 (Aura)
**表现形式**
❌ **误区**： 不要画出具象的腿或法杖，不要像个人形法师。
✅ **正解**： “悬浮的冰雪圣物”。
**视觉逻辑**：
轻盈、高贵，本身没有攻击力，但底盘法阵能给周围怪群提供巨额减伤。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 浅蓝色的微小流体，体积很小。
*   **Layer 2 (Core - Order 20)**: 中心镶嵌一颗极其精致、高亮的**“六角形完美冰晶”** Sprite。
*   **Layer 3 (FX - Order 0)**: 脚下垫着一个巨大的、缓慢旋转的**“冰雪几何法阵”** Sprite（作为光环范围的视觉提示）。
*   **Layer 4 (Eyes - Order 21)**: **“紧闭的双眼，眼角带有细长睫毛”** Sprite，像是在冥想或祈祷。
**组合与最终效果**：
一个在巨大冰蓝光环中心闭目祈祷的圣物，视觉上极具引导性，告诉玩家“必须先杀它”。

### 3. 霜冻施法者 (Frostcaster)
**表现形式**
❌ **误区**： 不要做得太宽大，要体现出“脆皮远程”的特点。
✅ **正解**： “顶着寒气法球的细长液柱”。
**视觉逻辑**：
像一座微型的移动法师塔，蓄力施放直线冰封射线。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 细长的、类似柱状的深青色流体。
*   **Layer 2 (Weapon - Order 20)**: 在它的流体头顶上方，悬浮着一颗**“散发寒气光晕的冰球”** Sprite。
*   **Layer 3 (Eyes - Order 21)**: **“锐利、散发魔力光芒的倒三角眼”** Sprite。
**组合与最终效果**：
蓄力时头顶冰球高频闪烁，随后从冰球处射出直线激光冻结光棱塔。

### 4. 第三章 BOSS：极寒之核 (Glacial Core)
**表现形式**
✅ **肯定**： “长满锐利冰刺的巨大晶体要塞”。
**视觉参考**： 《魔兽世界》冰封王座，绝对的冷酷与机械几何感，与流体形成强烈反差。
**制作方案 (Unity)**：
*   **Layer 1 (Fluid)**: 深邃如深渊大海的巨大暗蓝流体球（RT渲染）。
*   **Layer 2 (Crust - Order 20)**: 极其规则的**“巨型透明菱形/多边形冰盾外壳”** Sprite，像一个笼子把流体锁在里面。
*   **Layer 3 (Glow - Order 19)**: 冰层内部折射出的冷酷青色光晕。
*   **Layer 4 (Eyes)**: 同样没有卡通眼睛，而是一道**“散发绝对零度蓝光的几何形核心裂缝”** Sprite。
**动态效果**：
*   冰盾外壳极其稳定，不产生软体形变（表现其绝对防御）。
*   内部流体在笼子里压抑地涌动。
**BOSS 攻击方式设计（物理+流体特性）**：
*   **Phase 1 (冰墙构建)**: BOSS不再召唤小怪，而是在场景中直接拉起 2-3 堵静态的流体冰墙，完全阻断玩家激光，自己躲在后面。
*   **Phase 2 (绝对零度角力)**: BOSS 移动到场地中央，冰层爆发出极寒光芒。玩家必须在 3 秒内将全部推力（激光）打在核心裂缝上将其击退打断，否则光棱塔将被直接冻结 5 秒并扣除半血。

## 🛠 资深策划的 AI 出图拆件建议
主人，在使用 nanobanban 或 即梦 时，**千万不要让 AI 一次性画出完整的怪物**。你应该这样指挥 AI 帮你拆件生图：

1.  **抽流体底图**：不需要带眼睛和装甲，只要“纯粹的黑色/红色/蓝色高光液体团”。（作为参考定调，实际游戏中主要靠 Unity 材质 Shader 实现）
2.  **抽装甲图（重点）**：单独生成“生锈废土铁板”、“黑曜石龟裂碎片”、“透明几何冰盾”。生成后在 PS 里抠出来（存为 PNG 透明图）。
3.  **抽眼睛图（极简）**：单独生成“惊恐的卡通眼睛”、“半眯着的憨厚眼睛”、“十字发光裂缝”。存为极小的 PNG 挂件。
4.  **在 Unity 中拼装组合**：将抠出来的装甲和眼睛挂载到流体圆球节点下，调整 Order in Layer 和旋转角度。

这种做法能保证所有怪物底层的 Metaball 流体效果依然丝滑，而外挂的贴图又能赋予它们极强的个性和辨识度！可以毫无阻力地进行程序落地了！
