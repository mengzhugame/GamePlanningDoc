# 《光与朽》技能系统文档 (基于 Unity 实机配置优化版)

> **同步日期**: 2026-03-12
> **基准来源**: Unity 工程当前配置 (`Resources/Data/SkillData/`)
> **核心修订**: 确立“传导”替代“反射”，拆分“冲击”与“碎冰”的耦合，修复数值异常。

## 一、当前流派生态 (实机版)
目前的 Unity 实际配置已经演化为更加成熟的三个流派：
1. **穿透爆发流 (Focus + Power + Crit)**：主打极细光束、无限穿透与高额面板，适合打一条直线上的怪潮和 Boss。
2. **闪电风暴流 (Chain + Prism + Wide)**：利用激光变宽增加命中率，通过分裂和传导形成全屏电网，清杂无敌。
3. **极寒碎冰流 (Frost + Shatter + 冲击模块?)**：利用减速和冰冻控场，再通过特定被动打出极高的条件增伤和冰爆。

## 二、技能详细配置与【优化建议】

### 🔴 1. 主动技能 (Active Skills)

#### 1. 聚能透镜 (Skill_Focus) - 穿透流核心
*   **当前效果**：增加伤害乘区 (1.3 -> 2.5)，增加穿透数量 (1 -> 2 -> 3 -> 4 -> 无限)，Lv5 对 Boss 造成真实伤害。
*   **⚠️ 发现的问题**：Lv1 配置了 `widthMultiplier: 0.5`（变细变红），但 Lv2~Lv5 配置又回到了 `widthMultiplier: 1.0`（恢复正常宽度）。这会导致玩家升到2级时，激光突然变粗，丢失了“高压水枪”的视觉特点。
*   **✅ 改进建议**：将 Lv2~Lv5 的 `widthMultiplier` 全部改为 `0.5`，保持“极细光束”的视觉特征。

#### 2. 连锁反应 (Skill_Chain) - AOE流核心 (替代了反射)
*   **当前效果**：激光可在敌人间传导，次数 (1 -> 5)，伤害衰减 (20% -> 0%)。
*   **✅ 策划点评（关于反射）**：**绝对不要加回反射技能！** 反射需要地图边缘有“墙壁”支撑，但我们是虚空场景，怪从四面八方来。传导（Chain）不需要墙壁，且视觉表现（闪电链）更契合塔防割草。传导的设计非常完美。

#### 3. 分裂棱镜 (Skill_Prism) - AOE流副核心
*   **当前效果**：击中目标后产生副激光。数量 (2 -> 6)，长度 (8 -> 16)，伤害 (25% -> 50%)。
*   **✅ 改进建议**：数值平滑，表现优秀。无需修改。只需注意代码中副激光千万别再触发分裂，否则会死机。

#### 4. 极寒光束 (Skill_Frost) - 控制流核心
*   **当前效果**：减速 (40% -> 70%)，持续时间 (0.5s -> 1.2s)。Lv5 解锁“绝对零度”（照射1s后冰冻2s）。
*   **✅ 改进建议**：设计合理。冰冻2s给玩家留出了极好的转移目标时间。

#### 5. 冲击模块 (Skill_Impact) - 【亟需拆分重构】
*   **当前效果**：击退力乘区 (1.5 -> 5.0)。**同时附加了** 碎冰伤害加成 (1.5 -> 4.0)，且 Lv5 拥有秒杀冰冻小怪的能力。
*   **⚠️ 发现的问题（系统耦合）**：冲击模块把“物理击退”和“冰冻增伤”强行绑定了。如果玩家不想玩冰冻，只想玩物理穿透流，选这个技能会觉得亏了一半属性；如果玩家玩冰冻，又被强制塞了击退。
*   **✅ 改进建议（拆分）**：
    *   **冲击模块（回归纯物理）**：移除所有 `shatterDamageMultiplier` 和秒杀设定。改为单纯的推力增加，且附加**“撞击伤害”**（如果怪物被推移的速度过快，或者撞到其他精英怪，受到基于最大生命值的额外伤害）。

### 🔵 2. 被动技能 (Passive Skills)

#### 1. 广域透镜 (Passive_Wide) - 激光变宽
*   **❓ 主人疑问**：激光变宽真的有用吗？
*   **✅ 策划解答**：**极其有用！** 塔防中玩家是“扫射”操作，变宽意味着你的**扫射面积（扇形覆盖率）呈几何倍数增加**。变宽配合传导/分裂，能极大地提升刷怪效率。
*   **当前效果**：宽度乘区 (1.2 -> 2.0)。建议保留！

#### 2. 数据破碎 (Passive_Shatter) - 【承接冰冻增伤】
*   **当前效果**：对受损敌人增伤 (0.3 -> 1.5)。Lv5 击杀引发范围爆炸。
*   **✅ 改进建议**：把刚才从“冲击模块”里剥离出来的【秒杀冰冻小怪】机制，转移到这个技能的 Lv5 里！让 Shatter 成为冰冻流唯一的、纯粹的终极输出被动。

#### 3. 致命暴击 (Passive_Crit) - 【数值太弱】
*   **当前效果**：暴击率增加 (5% -> 25%)。默认暴击伤害是 200%（2倍）。
*   **⚠️ 发现的问题**：按期望伤害计算，满级 25% 概率打 2 倍伤害，总 DPS 仅提升 25%。但 `Passive_Power (功率超频)` 满级直接给 +100% 伤害！暴击技能现在变成了纯纯的“陷阱选项”。
*   **✅ 改进建议**：
    *   方案A：暴击率提升至 (10% -> 50%)。
    *   方案B：暴击不仅造成双倍伤害，还能**无视怪物的护甲/减伤机制**（真伤暴击）。

#### 4. 功率超频 (Passive_Power)
*   **当前效果**：基础 DPS 增加 (20% -> 100%)。
*   **✅ 改进建议**：简单粗暴，万金油，保留。

## 三、总体行动指南 (Action Items)

1.  **体力系统**：已设计完成并记录于 `knowledge/stamina_system_design.md`。
2.  **聚能透镜 (Focus)**：去 Unity 里把 Lv2~5 的 `widthMultiplier` 统一改回 0.5。
3.  **冲击模块 (Impact) 拆分**：将冰冻增伤和执行（Execution）属性从 Impact 中清空。
4.  **数据破碎 (Shatter) 加强**：把秒杀机制做到 Shatter 的满级效果里。
5.  **暴击 (Crit) 加强**：去 Unity 里把暴击率的成长曲线调高（比如满级给 40% 或 50%）。
6.  **反射机制**：保持现状，坚决用“连锁传导 (Chain)”代替“反射 (Reflex)”。
