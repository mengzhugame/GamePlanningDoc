# routines

## 这是什么

这里存放可重复执行的任务提示词，例如定期扫描用户痛点、行业趋势或复盘材料。

## 使用规则

- routine 是“任务提示词”，不是知识结论。
- 执行后产生的原始材料进入 `30_市场分析/` 或 `10_流水/`。
- 沉淀后的结论进入 `40_知识/`。

## routine 输出不直接给结论，只给可消费摘要

旧 OpenClaw 协议里最该保留的是“采集后必须说明怎么使用”。因此任何市场、用户痛点、视频雷达或趋势扫描 routine 的输出末尾都应有一节：

```markdown
## 给小龙儿的使用建议

- 是否值得人工阅读：是/否
- 是否值得进入蒸馏：P0/P1/P2/否
- 可能影响的决策：
- 建议下一步：
```

routine 的角色是把外部信号整理成可判断材料，不是替用户立项，也不是把原始市场材料直接升级成知识结论。高优先级材料进入 `30_市场分析/`，经过复盘或 `/distill` 后才进入 `40_知识/`。

反噪音规则：

- 没有来源链接或样本说明，降级。
- 只有大盘判断，没有具体案例，降级。
- 只适合大团队、不能服务 90 天主线，降级。
- 和现有知识重复且没有新证据，降级。

当前 routine 仍优先服务这条链路：市场素材信号 -> AI 视频反向立项 -> 7 天垂直切片 -> 陌生用户测试 -> 小额买量/发行合作 -> 是否公司化。
