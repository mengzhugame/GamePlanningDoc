# 游戏关键词库

> 用途：沉淀每日分析里出现的高价值机制词、包装词与结构词，避免重复拆解时总从零开始。

## 2026-05-01｜由《Schedule I》新增

### 题材与包装词
- **身份升级感**：玩家不只是更强，而是社会位置/组织层级明显上升。
- **地下帝国幻想**：从底层起家到掌控整条链路的成长叙事。
- **高识别一句话题材**：玩家 3 秒就能理解目标、风险和爽点。

### 玩法结构词
- **手动→半自动→全链路自动化**：经营游戏里最稳的长期成长骨架。
- **生产-分销-扩张飞轮**：制造产品、卖出赚钱、扩张资产，再反哺更高产能。
- **风险驱动升级**：外部威胁不是纯惩罚，而是逼玩家扩张系统的推进器。
- **配方变体深度**：通过组合、配方、属性差异提供中层策略空间。
- **分工式合作经营**：多人各管一段链路，放大社交传播与内容节目效果。

### 商业化与传播词
- **买断式 Early Access 经营**：先卖高完成度核心循环，再靠版本更新延长生命周期。
- **题材自传播**：猎奇/危险/灰色地带题材天然带讨论度，能降低获客成本。
- **主播整活友好**：容易出现翻车、暴富、混乱协作的可传播瞬间。

### 对小龙儿体系的可迁移用法
- 优先寻找能做出“我从打工人变成系统操盘手”的小游戏成长结构。
- 设计切片时，先验证“身份反差”和“自动化升级”的视频表达力。
- 以后遇到经营类爆款，优先检查是否具备：
  1. 一句话高识别题材
  2. 明确扩张飞轮
  3. 手动到自动的成长阶梯
  4. 外部风险推动升级
  5. 可被主播或短视频放大的社交/翻车瞬间

## 2026-05-02｜由《R.E.P.O.》新增

### 玩法结构词
- **物理失误可视化**：失败不是后台扣数值，而是玩家亲眼看着物品摔碎、翻车、掉落。
- **搬运式撤离循环**：找到高价值目标→高风险搬运→成功撤离变现→投入下一轮强化。
- **收益-保命拉扯**：玩家持续在“再贪一点”与“赶紧撤”之间做即时决策。
- **局内打工，局外强化**：单局高压执行，局外把现金转成长期成长，形成双层留存。
- **易碎高价值目标**：通过脆弱物体提升操作张力，让价值感和风险感绑定。

### 传播与体验词
- **合作混乱资产化**：误伤、抢位、指挥混乱、翻车本身就是内容，不必强行抹平。
- **近距离语音沉浸**：语音距离限制同时强化恐怖氛围、沟通失真和真实社交戏剧性。
- **翻车驱动传播**：越容易出现可笑事故，越容易形成主播切片和短视频传播。
- **低门槛高节目性**：规则一句话能懂，但每局都可能因为人和物理系统互动产生新名场面。

### 对小龙儿体系的可迁移用法
- 以后拆多人爆款时，优先检查“混乱是否被设计成爽点”，别默认混乱就是缺陷。
- 做短视频导向原型时，优先加入会被镜头看懂的失败形态，而不是只做后台数值失败。
- 评估一个玩法值不值得做素材测试时，可以先问三句：
  1. 失败能不能被一眼看懂？
  2. 合作会不会自然制造戏剧性？
  3. 撤离那一刻有没有明显贪婪抉择？
