# 数值学习积累总纲

更新时间：2026-04-30

## 已建立共识
1. 数值不是堆感觉，先定目标体验，再反推公式。
2. 核心战斗必须用统一标尺衡量，不然不同属性无法比较。
3. 《光与朽》这类塔防 Roguelite，最关键的不是单点伤害，而是：
   - 首个爽点出现时间
   - 压力波次位置
   - 首败原因是否可理解
   - 构筑补救是否有机会
4. 任何战斗数值都最好回到三件事：
   - 输出：DPS
   - 生存：EHP
   - 节奏：TTK（击杀时间）

## 既有方法论
- 先定玩家目标体验，再反推怪物血量、攻击、波次压力。
- 优先使用可解释的成长模型：线性、等比、分段、软上限。
- 波次设计必须服务于体验节奏，而不是单纯越来越难。
- 失败必须能归因到“构筑选择/操作判断/资源分配”，不能像纯随机暴毙。

## 下一步研究方向
- 用 EHP 统一衡量 HP、护甲、减伤、回复、护盾的价值。
- 用 TTK 反推《光与朽》前中后期怪波压强。
- 给破甲、易伤、穿透建立严格的结算顺序。
