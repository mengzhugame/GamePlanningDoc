# /research — Structured Research Skill

## Trigger
User invokes `/research` with a topic or draft reference.

## Procedure
1. Read context (referenced draft or topic description)
2. Check `70_资源/` for any existing source materials on topic
3. Generate a research note using research-note template
4. Structure into: Core Question → Findings → Open Questions → Next Steps
5. Update source draft status to `researched`
6. Write to `30_研究/`
7. READ BACK and verify

## Constraints
- Preserve original text from sources exactly (source priority rule)
- Do not hallucinate citations
- Flag areas that need more source material
