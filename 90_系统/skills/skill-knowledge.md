# /knowledge — Knowledge Distillation Skill

## Trigger
User invokes `/knowledge` with a research note or resource reference.

## Procedure
1. Read the source material (from 30_研究/ or 70_资源/)
2. Distill into a knowledge note following knowledge-schema
3. Preserve all original definitions, formulas, terms EXACTLY
4. Set status to `draft`
5. Write to `40_知识/`
6. Update source note status to `knowledged`
7. READ BACK and verify

## Constraints
- NEVER paraphrase definitions, theorems, or technical terms
- Original book's phrasing is the standard
- Must include source_book and source_page
- Each knowledge note covers ONE concept
