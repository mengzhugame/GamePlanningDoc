## 创意到项目的流转

1. **创意收集**：先进入 `00_草稿/游戏创意库/`。
2. **概念验证**：满意的创意继续留在 `00_草稿/游戏创意库/`，用 `创意名_概念卡.md` 和 `创意名_概念视频数据记录.md` 管理真实玩法 AI 概念视频与数据。
3. **市场信号测试**：发布到小红书、B 站、微信视频号、抖音，观察评论、收藏、点赞、转发等信号。
4. **正式立项**：只有验证通过的方向才进入 `20_项目/`。
5. **项目制作与上线**：项目资料、开发计划、资产、发行追踪、数据复盘都保留在对应项目目录。
6. **复盘沉淀**：项目结束后，把方法、踩坑、模板沉淀到 `40_知识/`。

## 维护规则

- 新建重要文件前，先看 `90_系统/schemas/` 和对应目录 README。
- `10_流水/` 和 `30_市场分析/` 只是原始材料，不直接当作权威结论。
- `40_知识/` 是长期知识层，应该经过筛选、归纳、验证后再沉淀。
- `20_项目/` 只放正式立项或已上线项目；概念验证失败的方向留在 `00_草稿/游戏创意库/`。
- 行业情报由 Claude Code / Codex 或用户手动收集到 `30_市场分析/`。
